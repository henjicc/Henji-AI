## 公共结果契约

SDK 返回 `metadata.outputTimings: GenerationOutputTimings`，数组项为 `{ outputIndex, timings: { granularity: 'char' | 'word' | 'sentence', items: [{ text, startMs, endMs, confidence? }] } }`。outputIndex 对应输出媒体序号，时间是源音频毫秒；confidence 为供应商可选的 0–1 数值。没有时间戳时省略，不能把空音频或非法区间伪装成可用结果。火山当前单音频输出序号为 0，按流帧收集 `sentence.words`，保留原音频拼接路径；非法时间拒绝并取消响应流，不重发生成。

Seed-TTS / ICL 的 catalog 自动开启字幕并声明 `timestamps` 标签，宿主模型 schema 和搜索沿同一 meta.tags 投影。只覆盖合成，不为音色训练伪造字幕。仅中英文的官方限制仍成立。

官方响应 fixture：`packages/ai-sdk/tests/fixtures/tts/volcengine-subtitle.json`，正文和秒数取自官方示例，音频占位替换为 ID3 三字节；异常 fixture 为测试构造，未冒充线上采样。两模型的请求参数和解析都有精确测试。

## 资料缺口及最小核验

百炼 MiniMax 的公开页声明 subtitle_enable，却没有字幕返回字段；Fal Eleven v3 的返回类型是 list<void>；KIE Turbo 示例开关没有相应结果字段。本次不猜字段名或时间单位，尚未完成这些原生适配。总管理者可先向官方取得带字幕的响应 schema/脱敏响应样本；需付费调用时另行授权。

火山最小合成参数：`{prompt:'你好，语音测试',volcSeedTtsSpeaker:'zh_female_vv_uranus_bigtts'}`。ICL 使用已有已激活音色，`{prompt:'你好，语音测试',volcSeedIclSpeaker:'已有音色ID',volcIclActivationConsent:true}`；此处只是后续测试建议，没有执行。核查跨句时钟是否连续、是否重复 sentence、中英混读标点覆盖和音频实际对齐精度。当前公开文档未给出重复帧与句时钟重置规则，因此不擅自加偏移或去重。

未遇到需要用户登录的资料页面。未切换 Qwen/CosyVoice 到流式或 WebSocket，没有 npm publish。
