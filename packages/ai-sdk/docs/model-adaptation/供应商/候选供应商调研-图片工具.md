# 图片工具候选供应商调研

> 状态：调研完成，尚未适配
> 核验日期：2026-08-29
> 范围：高清放大、重打光、图片视角变化、扩图、照片修复、背景移除，以及图片/视频/音频生成、价格优惠和中国内地访问条件。

## 结论

推荐顺序：

1. **Segmind（P0）**：目标图片工具覆盖最完整，异步协议统一，适合先做完整 provider。
2. **WaveSpeedAI（P0）**：模型池最大、公开折扣最明显，多角度/放大/重打光/修复/抠图均有明确独立入口。
3. **PiAPI（P1）**：放大、抠图、扩图价格低，提供简体中文站和 USDT 优惠，适合作为低价补充。
4. **Replicate（P2）**：长尾能力强，但社区模型版本、许可证、下架风险和结果落盘时限需要额外治理。
5. **Novita AI（P3）**：多模态齐全，但当前没有足够独立图片工具覆盖，本轮暂缓。

公开资料不足以把任何一家写成“已确认中国内地友好”。正式选型前必须从中国移动、联通、电信网络分别测试 API 域名和结果媒体域名；DNS/TLS/未鉴权请求可先做零费用探测，付费生成另行授权。

## 1. Segmind（P0）

### 已核验能力

- 多角度：[Qwen Image Edit Plus Multiple Angles](https://www.segmind.com/models/qwen-image-edit-plus-multiple-angle)，支持镜头移动、旋转和远近控制。
- 重打光：[Segmind Relighting V2](https://www.segmind.com/models/segmind-relighting-v2)，支持方向、类型、颜色和强度控制。
- 高清放大：[Bria Increase Resolution](https://www.segmind.com/models/bria-increase-resolution)，支持 2×/4× 与 Alpha。
- 扩图：[Flux Fill Pro](https://www.segmind.com/models/flux-fill-pro)。
- 背景移除：[Bria RMBG 2.0](https://www.segmind.com/models/bria-remove-background)。
- 照片修复：[SUPIR](https://www.segmind.com/models/supir)。
- 另有独立的[视频模型目录](https://www.segmind.com/models/all/best-video-models)和[音频模型目录](https://www.segmind.com/models/all/text-to-speech-models)。

### 公共协议

- Base URL：`https://api.segmind.com`
- 鉴权：`x-api-key`，见[官方鉴权文档](https://docs.segmind.com/docs/get-started/authentication)。
- 同步：`POST /v1/{model-slug}`。
- 异步：`POST /v2/{model-slug}`；提交返回 `request_id`、`status_url`、`response_url`。
- 查询：`GET /v2/requests/{id}/status`、`GET /v2/requests/{id}`。
- 终态：`COMPLETED` / `FAILED`。多角度请求形状见其[官方 API 页面](https://www.segmind.com/models/qwen-image-edit-plus-multiple-angle/api)。

### 价格、优惠与内地访问

- [官方价格页](https://www.segmind.com/pricing)明确提供 volume discounts，并写有“The more you buy, the more you save”。
- 公开计划存在月付积分溢价和企业年付折扣；最终适配必须按模型页实时价格逐项记录。
- 未发现中国内地节点、备案域名、本地支付或网络 SLA；示例媒体依赖云存储域名，访问结论为**未知、待实测**。

### 建议首批

多角度、Relighting V2、Bria Increase Resolution、Flux Fill Pro、Bria RMBG 2.0、SUPIR。v2 公共轮询层只实现一次，各模型保持独立 schema。

## 2. WaveSpeedAI（P0）

### 已核验能力

- 多角度：[Qwen Image Edit Multiple Angles](https://wavespeed.ai/models/wavespeed-ai/qwen-image/edit-multiple-angles)。
- 重打光：[Bria Fibo Relight](https://wavespeed.ai/models/bria/fibo/relight)。
- 高清放大：[Clarity Pro Upscaler](https://wavespeed.ai/models/clarity-ai/pro-upscaler)、[WaveSpeed Image Upscaler](https://wavespeed.ai/models/wavespeed-ai/image-upscaler)。
- 背景移除：[WaveSpeed Background Remover](https://wavespeed.ai/models/wavespeed-ai/image-background-remover)。
- 照片修复：[Bria Fibo Restore](https://wavespeed.ai/models/bria/fibo/restore)。
- 官方目录已发现视频扩图，但尚未核到明确的独立**图片** outpaint endpoint，因此不得用泛化编辑能力替代确认。

### 公共协议

- Base URL：`https://api.wavespeed.ai/api/v3`
- 鉴权：`Authorization: Bearer ...`，见[鉴权文档](https://wavespeed.ai/docs/api-authentication)。
- 提交：`POST /api/v3/{model_id}`，见[提交文档](https://wavespeed.ai/docs/submit-task)。
- 查询：`GET /api/v3/predictions/{task-id}/result`，见[结果查询](https://wavespeed.ai/docs/get-result)。
- 终态：`completed`；失败类终态包括 `failed`、`cancelled`、`timeout`、`deleted`。
- 支持 webhook，部分模型支持同步模式。

### 价格、优惠与内地访问

- 官方模型目录直接展示 5%–50% OFF，且[价格页](https://wavespeed.ai/pricing)提供企业 volume discounts。
- 官网提供中文版本提示，但未发现中国节点、内地 API SLA 或支付宝/微信支付证据；访问结论仍为**未知、待实测**。

### 建议首批

多角度、Fibo Relight、Image Upscaler、Background Remover、Fibo Restore；图片 Outpaint 等官方确认独立端点后再加入。

## 3. PiAPI（P1）

### 已核验能力

- 高清放大：[Super Resolution API](https://piapi.ai/docs/image-editing-api/super-resolution-api)，支持 2/4/8×与人脸增强。
- 背景移除：[Remove Background API](https://piapi.ai/docs/image-editing-api/remove-background-api)，支持 RMBG-1.4、RMBG-2.0、BEN2。
- 扩图：[Flux Outpaint](https://piapi.ai/docs/flux-redux-fill-variation-inpaint-outpaint)。
- 当前官方文档索引未发现独立重打光、照片修复或图片多角度；[WanX Camera Control](https://piapi.ai/docs/wanx-api/camera-control.md)是视频镜头控制，不能计入图片视角能力。

### 公共协议

- Base URL：`https://api.piapi.ai`
- 鉴权：`x-api-key`
- 统一提交：`POST /api/v1/task`
- 统一查询：`GET /api/v1/task/{task_id}`
- 请求主体统一为 `model`、`task_type`、`input`，支持 webhook。见[Quickstart](https://piapi.ai/docs/quickstart)和[统一 API schema](https://piapi.ai/docs/unified-api-schema)。

### 价格、优惠与内地访问

- 放大和背景移除页面公开价均很低；落地前仍需按实际输出 MP 与任务返回账单校对。
- [Benefits](https://piapi.ai/benefits)公开 USDT 大额充值 5%/8%/11%/15% 赠送档位，部分模型另有活动折扣。
- 有[简体中文站](https://piapi.ai/zh-CN)且支持 USDT，支付可达性线索最好；但没有中国备用 API 域名、内地节点或 SLA，网络访问仍需实测。

## 4. Replicate（P2）

### 已核验能力

- 高清放大：[Recraft Crisp Upscale](https://replicate.com/recraft-ai/recraft-crisp-upscale)、[Google Upscaler](https://replicate.com/google/upscaler)。
- 重打光：[IC-Light Background](https://replicate.com/zsxkib/ic-light-background)（社区模型）。
- 多视角：[Zero123++](https://replicate.com/jd7h/zero123plusplus)（社区模型）。
- 背景移除：[Bria Remove Background](https://replicate.com/bria/remove-background)。
- 扩图：[FLUX Fill Pro](https://replicate.com/black-forest-labs/flux-fill-pro)。
- 照片修复：[Microsoft Old Photos](https://replicate.com/microsoft/bringing-old-photos-back-to-life)。
- 图片、视频、音频均有大规模目录，例如 [Seedance 2.0](https://replicate.com/bytedance/seedance-2.0) 与 [Stable Audio 2.5](https://replicate.com/stability-ai/stable-audio-2.5)。

### 公共协议与风险

- Base URL：`https://api.replicate.com/v1`，Bearer 鉴权。
- 官方模型：`POST /v1/models/{owner}/{name}/predictions`；社区模型：`POST /v1/predictions` 并固定 version hash。
- 查询：`GET /v1/predictions/{id}`；状态为 `starting`、`processing`、`succeeded`、`failed`、`canceled`。见[HTTP API](https://replicate.com/docs/reference/http)和[预测说明](https://replicate.com/docs/topics/predictions/create-a-prediction)。
- 预测输入、输出和日志默认在一小时后清理；结果域名 `replicate.delivery` / `*.replicate.delivery` 必须纳入媒体下载白名单并及时落盘。
- 社区模型必须锁定 version、审计许可证并处理作者更新/下架，不应首版开放任意 owner。

### 价格与内地访问

- [价格页](https://replicate.com/pricing)按输出或 GPU 秒计费，[企业方案](https://replicate.com/enterprise)提供 volume discounts，个别模型有临时折扣。
- 无中文站、中国节点或内地 SLA；API 与结果媒体域名都需要实测。

## 5. Novita AI（P3）

- 官方 [llms.txt](https://novita.ai/llms.txt)显示其覆盖图片、视频、音频和 LLM。
- Base URL：`https://api.novita.ai`，Bearer 鉴权；v3 异步任务通过 [`GET /v3/async/task-result`](https://novita.ai/docs/api-reference/model-apis-task-result)统一查询。
- 统一状态包括 `TASK_STATUS_QUEUED/PROCESSING/SUCCEED/FAILED`，结果可包含 images/videos/audios。
- 当前目录未核到独立 relight、图片视角、背景移除、outpaint 或完整照片修复 endpoint；[V2→V3 迁移文档](https://novita.ai/docs/guides/model-apis-v2-to-v3-migration)中的 `hires_fix.upscaler`、`restore_faces` 只是生成参数，不等于独立图片工具。
- 媒体图片工具未核到稳定折扣，中国内地访问条件同样未知。因此本轮暂缓。

## 适配前置验证清单

1. 从中国移动、联通、电信分别测试主 API 域名的 DNS、TLS、首包时间与失败率。
2. 同时测试上传域名和结果媒体域名；只测官网不能代表生成链路可用。
3. 用不产生模型费用的鉴权失败/模型列表请求先验证网络和错误结构。
4. 获得付费授权后，每家只选择 1 个低价工具做提交、轮询、取消、失败、落盘和实扣金额验证。
5. 按真实结果再决定 Segmind 与 WaveSpeedAI 的先后顺序；PiAPI 作为价格/支付补充，不替代多角度和重打光主供应商。
