## 1. Base URL 和区域

百炼的 API Key、业务空间和 Base URL 有区域绑定，不能混用。

| 区域 | 推荐 DashScope Base URL | 历史公共地址 |
|---|---|---|
| 华北2（北京） | `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1` | `https://dashscope.aliyuncs.com/api/v1` |
| 新加坡 | `https://{WorkspaceId}.ap-southeast-1.maas.aliyuncs.com/api/v1` | `https://dashscope-intl.aliyuncs.com/api/v1` |
| 美国（弗吉尼亚） | `https://{WorkspaceId}.us-east-1.maas.aliyuncs.com/api/v1` | 按当前官方地域文档 |

`WorkspaceId` 需从百炼控制台的业务空间详情获取。官方目前仍保证历史地址可用，但推荐迁移到空间专属域名以获得更稳定的访问。

实时 WebSocket 同样受地域约束：

```text
Fun-ASR-Realtime: wss://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api-ws/v1/inference
Qwen3-ASR-Realtime: wss://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api-ws/v1/realtime?model=<model_id>
```

新加坡使用 `{WorkspaceId}.ap-southeast-1.maas.aliyuncs.com`。API Key、Workspace、地域必须一致。

## 2. 生成端点

### 2.1 同步多模态生成（当前项目使用）

```text
POST /api/v1/services/aigc/multimodal-generation/generation
```

该契约适用于当前 Qwen Image 3.0 等同步图片模型。主要结果路径：

```text
output.choices[].message.content[].image
```

图片 URL 通常仅保留 **24 小时**，需及时转存。

### 2.2 异步生成（按模型支持）

百炼的异步接口并非所有模型共用同一个提交路由。以历史 Qwen Image 异步文生图为例：

```text
POST /api/v1/services/aigc/text2image/image-synthesis
X-DashScope-Async: enable
```

查询任务：

```text
GET /api/v1/tasks/{task_id}
```

通用状态包括 `PENDING`、`RUNNING`、`SUCCEEDED`、`FAILED`、`CANCELED`、`UNKNOWN`。但每个模型是否支持异步、提交路由与结果结构必须查询单模型文档，不得仅因为供应商有 tasks API 就强行切换。

## 3. 上传本地文件

百炼提供免费临时存储，用于将本地图片、视频或音频转为 `oss://` 地址。

### 3.1 获取上传凭证

```text
GET https://dashscope.aliyuncs.com/api/v1/uploads?action=getPolicy&model=<model-name>
Authorization: Bearer <API Key>
```

返回 `data.upload_host`、`upload_dir`、`policy`、`signature`、`oss_access_key_id`、`x_oss_object_acl`、`x_oss_forbid_overwrite` 等字段。凭证通常只在 `expire_in_seconds` 内有效。

### 3.2 上传到 OSS

`POST {data.upload_host}`，multipart 字段包含：

- `OSSAccessKeyId`
- `Signature`
- `policy`
- `x-oss-object-acl`
- `x-oss-forbid-overwrite`
- `key`
- `success_action_status=200`
- `file`（必须放在最后）

生成给模型使用的地址：`oss://<upload_dir>/<filename>`。

### 3.3 使用临时 URL

- 调用模型时必须加 `X-DashScope-OssResourceResolve: enable`。
- 文件有效期 **48 小时**。
- 上传时必须指定后续调用的精确模型名，不同模型不能共享该文件。
- 上传和生成使用的 API Key 必须属于同一阿里云主账号。
- 单文件上传接口上限 1 GB，具体模型通常有更低的输入限制。
- 临时存储不用于生产长期托管，高并发建议使用自有 OSS。

## 4. 在线 ASR 三类协议

### 4.1 Fun-ASR-Realtime WebSocket

1. 建立 WSS，握手头带 `Authorization: Bearer <API Key>`。
2. 发 `run-task`（客户端生成 UUID `task_id`）。
3. 等 `task-started` 后发单声道二进制音频，持续接收 `result-generated`。
4. 发 `finish-task`，等 `task-finished` 后才可复用连接或关闭。
5. `task-failed` 后服务端关闭连接，该连接不可复用；完成后 60 秒内无新任务会自动断开。

音频格式 `pcm/wav/mp3/opus/speex/aac/amr`，采样率任意，时长无限制；输入必须单声道。

### 4.2 Qwen3-ASR-Flash-Realtime WebSocket

该系列不复用 `run-task` 协议，而是会话事件：`session.created` → `session.update` → 多个 `input_audio_buffer.append` →（Manual 模式发 `input_audio_buffer.commit`）→ `session.finish` → `session.finished`。

- VAD 模式由服务端断句；Manual 模式由客户端 `commit`。
- 最终文本为 `conversation.item.input_audio_transcription.completed`，中间文本为 `.text`，失败为 `.failed` / `error`。
- 推完音频必须先发 `session.finish` 并等 `session.finished`，直接断开会丢弃未完成结果。每次会话后主动断开，不支持连接复用。
- `pcm/opus`，8kHz/16kHz，单声道；单个 `append` 的 Base64 `audio` 最大 15 MiB，实时使用应分小块。

### 4.3 短音频同步 HTTP

| 系列 | 端点 | 输入 | 上限 | 结果 |
|---|---|---|---|---|
| `fun-asr-flash-2026-06-15` | `POST /api/v1/services/aigc/multimodal-generation/generation` | `input.messages[].content[].input_audio.data` 为公网 URL 或 Data URI | 5 分钟 / 2 GB | `output.text` / `output.sentence` + `usage.duration` |
| `qwen3-asr-flash*` | OpenAI 兼容 `POST /compatible-mode/v1/chat/completions`；或上述 DashScope 同步端点 | URL 或 Base64；OpenAI 兼容额外参数放 `asr_options` | 5 分钟 / 10 MB | OpenAI `choices[].message.content`；DashScope `output.choices[]` |

`fun-asr-flash` 协议支持 `X-DashScope-SSE: enable`；音频不少于 1 分钟时才会多次返回中间结果。

### 4.4 文件异步 HTTP

```text
POST /api/v1/services/audio/asr/transcription
X-DashScope-Async: enable
GET  /api/v1/tasks/{task_id}
```

- `fun-asr` 提交 `input.file_urls` （单次 1 个公网 URL）；`qwen3-asr-flash-filetrans` 提交 `input.file_url`。
- 两者上限均为 12 小时 / 2 GB；说话人分离场景建议不超过 2 小时。
- 状态：`PENDING/RUNNING/SUCCEEDED/FAILED/UNKNOWN`。`fun-asr` 成功结果在 `output.results[].transcription_url`，需再下载 JSON；内含 `transcript/sentences/words/speaker_id`。
- 异步任务支持查询最近 24 小时提交的任务；必须将转写结果及时落地，不得把签名 URL 当长期资源。

## 5. Qwen-MT 翻译

Qwen-MT 可通过 OpenAI 兼容 `POST /compatible-mode/v1/chat/completions` 或 DashScope `POST /api/v1/services/aigc/text-generation/generation` 调用。请求只支持 User Message，译文在 `choices[0].message.content`。

`translation_options` 必填：

- `source_lang`：源语言英文全称，或 `auto`。
- `target_lang`：目标语言英文全称。
- `terms` / `tm_list` / `domains`：可选术语干预、翻译记忆、英文领域提示。

`qwen-mt-flash` / `qwen-mt-lite` 流式返回是增量片段；`qwen-mt-plus` 为累积序列，消费时不能一律字符串追加。

## 6. 计价查询

百炼生成模型没有一个可以用 DashScope API Key 查询全部图片/视频当前单价的稳定公开 API。项目使用以下优先级：

1. 当前官方模型价格页。
2. 单模型 API 文档中的计费规则。
3. 调用返回的 `usage`，用于对账输出数量/像素/等效用量。
4. 最终账单与用量明细。

价格与可用模型都可能按区域不同，文档必须同时记录地域。

## 7. 错误边界

- WebSocket 握手时 Key 缺失/无效返回 HTTP 401/403；任务层 Fun-ASR 为 `task-failed`，Qwen3-ASR 为 `error` / `conversation.item.input_audio_transcription.failed`。
- HTTP 同步错误通常在顶层 `code/message/request_id`；异步还需读 `output.task_status/code/message` 与每个 `results[].subtask_status/code/message`。
- 需显式分类：模型 ID 不存在/服务未开通（不重试）、Key/空间/地域错配（不重试）、空音频/格式或时长不合法（不重试）、媒体 URL 下载失败（替换输入或上传后重试）、限流/网络/服务端错误（受控退避）。
- 用户取消要在错误归一前优先识别：WS 停止送音频并关连接，HTTP/SSE 中止 fetch，异步停止轮询；不得转成“网络失败”后自动重试。

## 8. 余额

余额/账单属于阿里云财务体系，通常需要云账号 AccessKey 和 OpenAPI 签名，不是 DashScope 生成 API Key 的同一契约。按当前优先级，Henji-AI 只保存 Key 并标记“未在线验证”，暂不接入云财务权限。
