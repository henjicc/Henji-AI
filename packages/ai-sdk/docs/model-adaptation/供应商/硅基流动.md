## 1. ASR 端点与请求

```text
POST https://api.siliconflow.cn/v1/audio/transcriptions
Authorization: Bearer <SILICONFLOW_API_KEY>
Content-Type: multipart/form-data
```

| 字段 | 类型 | 要求 |
|---|---|---|
| `file` | binary file | 必填；时长不超过 1 小时，文件不超过 50 MB |
| `model` | enum string | 必填；`FunAudioLLM/SenseVoiceSmall` 或 `TeleAI/TeleSpeechASR` |

官方端点参考目前只公开了 `file` 和 `model`，没有公开 `language`、`prompt`、
`response_format`、词级时间戳、说话人分离或热词参数。cURL 使用 MP3 为示例，但页面未给出
完整 MIME/容器白名单；不应仅根据开源上游模型能力自行扩展公开云 API 参数。

成功响应是 `application/json`：

```json
{
  "text": "<string>"
}
```

响应头 `x-siliconcloud-trace-id` 是服务端生成的请求追踪标识，可在排障时提供给官方，
不应当成稳定业务 ID。官方未公开独立 WebSocket、SSE、异步任务或实时麦克风 ASR
协议；本端点应按同步文件转写建模。

## 2. 模型、价格与免费政策

| 平台模型 ID | API 明确列举 | 当前价格证据 | 结论 |
|---|---:|---|---|
| `FunAudioLLM/SenseVoiceSmall` | 是 | 公开价格页语音模型标注“免费” | 自有 Key 调用按当前免费模型政策处理 |
| `TeleAI/TeleSpeechASR` | 是 | 通用价格页当前未找到该 ID；官方“说点啥”用例将它列入该客户端的免费服务 | **自有 Key 的通用计费未确认**，上线前必须在控制台/账单复核 |

免费模型不是一次性试用金：官方 Rate Limits 页明确说免费模型调用账单消耗为 0，
同时要求账号完成实名认证。免费模型使用固定 Rate Limits，但公开页未给这两个 ASR
模型的精确数值；不应把其它模型的 RPM/RPD 直接套用。模型转写页还明确保留定期上下线
和调整服务能力的权利，因此发布前应再做模型可用性查询。

## 3. 错误契约

官方转写 API 参考和通用错误页表明错误体并非始终同一形状：

- JSON 形状可为 `{ "code": 20012, "message": "...", "data": null }`；
- 部分鉴权/权限/路由错误在 API 参考中展示为纯字符串；
- 429 错误示例含 `message` 和 `data`，需从 `message` 区分 RPM/RPD/TPM/TPD/IPM/IPD；
- 503/504 通常表示服务高负载，500 是未知服务异常。

常见 HTTP 状态：400 参数，401 凭证，403 余额/权限/实名，429 限流，500 未知服务错误，
503/504 过载。SDK 的 `provider_http_error` 诊断文本需保留 HTTP status、可用的
`code/message/data`、纯文本 fallback 和脱敏后的 `x-siliconcloud-trace-id`；当前通用
`AiRuntimeError` 不提供结构化供应商错误 metadata，不可只按一种 JSON 错误结构解析。

## 4. Say-It/SDK 接入边界

接入复杂度低：标准 Bearer Key + `multipart/form-data` + JSON 或文本错误，无 HMAC、无二进制
私有帧。与 OpenAI/Groq 语音转写形状接近，但当前公开字段仅有 `file/model`，不能把
OpenAI 的 `language/prompt/response_format/temperature` 透传过来。

中国大陆使用 `api.siliconflow.cn`，需 SiliconCloud 账号与 API Key；免费模型需实名认证。
本轮没有发起真实或付费请求，运营商网络可达性、账户实际限流和 TeleSpeechASR 自有 Key
计费均未实测。

# 2026-09-11：Embedding / Rerank 核查

官方公开 API：https://api-docs.siliconflow.cn/docs/api/embeddings-post 、https://api-docs.siliconflow.cn/docs/api/rerank-post 。国内根地址 `https://api.siliconflow.cn/v1`，Bearer，同步 JSON POST `/embeddings` 或 `/rerank`。

- 文本 Qwen3 Embedding 8B/4B/0.6B：`Qwen/Qwen3-Embedding-{8B,4B,0.6B}`，32768 token，支持 dimensions 枚举。8B：64/128/256/512/768/1024/1536/2048/2560/4096；4B 去掉4096；0.6B 到1024。发送 input 字符串数组、encoding_format=float，读取 data[].index/embedding。BGE/BCE 也有 API 字段说明，暂不机械加入所有历史模型。
- 文本 Qwen3 Reranker 同尺寸 ID `Qwen/Qwen3-Reranker-*`：query、documents、top_n、instruction；不能发送仅 BGE/BCE 支持的 overlap_tokens/max_chunks_per_doc。读取 results[].index/relevance_score，usage 可能位于 meta.tokens（与 billed_units 分开，不能混为实际用量）。
- 公开国内价格页 https://siliconflow.cn/pricing 未列文本嵌入/重排；国际站 https://www.siliconflow.com/models/qwen3-embedding-8b 标明 0.04 美元/百万输入 token，不作为国内价格。国内数值待确认，不能猜测或写为免费。
- 多模态 Qwen3-VL-Embedding/Reranker-8B 另有接口变体；本次文本能力不宣称支持图片/视频。发布公告 https://www.siliconflow.cn/news/gnuv7wmztvwaq78ozfhjybmi 标明文本0.7元/百万、视觉1.8元/百万；不能借用该价格给纯文本 Qwen3。
- 同步终态与验证：非2xx/非法JSON/供应商error拒绝；向量非空且索引完整唯一；重排索引有效唯一且分数有限；取消/超时由 capability client 统一传递。官方示例与字段构造正例、synthetic-negative 分开标注。
