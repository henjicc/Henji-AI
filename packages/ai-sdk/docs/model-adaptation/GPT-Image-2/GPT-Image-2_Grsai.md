| 项目 | 内容 |
|---|---|
| 最后更新 | 2026-08-26 |
| 模态 | 图片 |
| 供应商 | Grsai（聚合中转，详见 [Grsai 基础文档](../供应商/Grsai.md)） |
| 平台模型 ID（渠道） | `gpt-image-2`（普通渠道）、`gpt-image-2-vip`（VIP 渠道） |
| 接口形态 | 提交 `POST /v1/api/generate` + 轮询 `GET /v1/api/result`（新版统一接口，`replyType` 三选一） |
| 文档可见性 | 公开，无需登录 |

| 项目当前状态 | 已接入，[catalog/grsai/gpt-image-2.model.ts](../../../src/catalog/grsai/gpt-image-2.model.ts)，`canonicalModelId: gpt-image-2` |

> Grsai 的 GPT-Image-2 只有**两个渠道**，不像 Nano Banana 系列拆出一堆 `-cl`/`-vip` 变体。两个渠道的核心差异是**分辨率参数形态不同**（比例字符串 vs 像素值）和**价格差 3~4 倍**。两个渠道都不是 OpenAI 官方直连，是 Grsai 自己的两条转发线路，所以选项没有套用「普通/官方」那套文案（那只适用于「第三方 vs 官方」的场景），代码里用自定义标签「标准/VIP」；字段名按项目约定仍走 `sharedFieldText('apiChannel')` 并声明 `role: 'channel'`，统一显示为「渠道」。

## 1. 请求参数（新版统一接口）

`POST /v1/api/generate`，`model` 字段二选一：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `model` | string | 必填 | `gpt-image-2` 或 `gpt-image-2-vip` |
| `prompt` | string | 必填 | 提示词 |
| `images` | array\<string\> | 可选 | 参考图，base64 或 URL 混填，无需单独上传 |
| `aspectRatio` | string | 可选 | **两个渠道取值形态不同**，见下 |
| `replyType` | string | 可选 | `json` / `stream` / `async` |

`imageSize` 字段在这个模型上**不使用**——分辨率信息直接编码进 `aspectRatio` 的像素值里（见下）。

### 1.1 `gpt-image-2`（普通渠道）分辨率参数

只支持 **1K** 档，`aspectRatio` 可传比例字符串（如 `16:9`）或直接传 1K 像素值：

| 比例 | 像素值 |
|---|---|
| `auto` | — |
| `1:1` | 1024×1024 |
| `16:9` | 1672×941 |
| `9:16` | 941×1672 |
| `4:3` | 1443×1090 |
| `3:4` | 1090×1443 |
| `3:2` | 1536×1024 |
| `2:3` | 1024×1536 |
| `5:4` | 1408×1120 |
| `4:5` | 1120×1408 |
| `21:9` | 1920×832 |
| `9:21` | 832×1920 |
| `1:2` | 896×1792 |
| `2:1` | 1792×896 |

### 1.2 `gpt-image-2-vip`（VIP 渠道）分辨率参数

**只支持 1–4K 像素值，不支持比例字符串**；支持自定义像素值，约束：

- 最大边长 ≤ 3840px
- 两条边都必须是 16 的倍数
- 长边:短边 ≤ 3:1
- 总像素数 ∈ [655,360, 8,294,400]

| `21:9` | 1456×624 | 2912×1248 | 3840×1648 |

### 1.3 仅旧版接口存在的 `quality` 参数

旧版 GPT Image 专用接口 `POST /v1/draw/completions`（见 [Grsai 基础文档 §3.5](../供应商/Grsai.md)）多一个 `quality` 参数：`auto` / `low` / `medium` / `high`，新版统一接口没有这个字段。若要暴露画质档位，需要评估走旧接口还是等新接口补齐——**接入前需二次确认新接口是否已隐性支持 quality（比如通过像素值间接控制），不要凭旧接口文档直接假定新接口也支持**。

## 3. 价格

来源：[dashboard 模型列表](https://grsai.com/zh/dashboard/models)（2026-08-26 实测，未登录可见）。价格区间由「积分消耗 × 积分单价区间」得出，区间下限对应 ¥999 最高档充值套餐（约 5 折），上限对应无优惠单价，详见 [Grsai 基础文档 §5.1](../供应商/Grsai.md)。

| 渠道 | 积分消耗 | 价格区间 | 支持分辨率 |
|---|---|---|---|
| `gpt-image-2` | 600/次 | ¥0.03~¥0.06/次 | 1K |
| `gpt-image-2-vip` | 2000/次 | ¥0.1~¥0.2/次 | 1K / 2K / 4K |

代码里 `pricing.calculator` 按产品决定取**区间上限（无优惠价）**，即标准 ¥0.06、VIP ¥0.2，理由是不清楚用户的充值档位时按上限估算不会低报成本；用户按更高档位充值时实际扣费会更低。

### 3.1 价格变动历史（公告原文摘录，供判断稳定性参考）

- 2026-04-22：新增 `gpt-image-2`，¥0.03/次
- 2026-04-30：新增 `gpt-image-2-vip`，最低价 ¥0.045/张，支持 1K/2K/4K 与 `quality`（`low`/`medium`/`high`，默认 `auto`）
- 2026-05-08：因 OpenAI 官方风控成本上升，`gpt-image-2-vip` ¥0.045 → ¥0.065
- 2026-06-19：`gpt-image-2-vip` 的 2K/4K 分辨率一度不可用，同日恢复
- 2026-08-11：`gpt-image-2-vip` 的 2K/4K 分辨率再次回归，同时**所有分辨率价格统一调整为 ¥0.1/张**（此前分辨率越高价格越高）

`gpt-image-2-vip` 上线以来价格上调、分辨率短暂下线各发生过至少一次，均由官方（OpenAI）侧风控或成本变化触发，印证「VIP/付费渠道也不是绝对稳定」。

## 4. 适配要点

- 本项目默认**绝对不显示**：`seed`、负面提示词。两个渠道文档都没有这两个字段。
- `gpt-image-2` 与 `gpt-image-2-vip` 的分辨率参数**形态不同**（比例字符串 vs 纯像素值），代码用同一个「比例」下拉呈现给用户，`request.builder` 按渠道分别转换成对应格式再发送。
- VIP 渠道当前只暴露 1K/2K/4K 三档预置像素值（第 1.2 节表格），**没有**开放自定义像素输入，因此不需要实现四条约束校验；表格里 `1:3`/`3:1` 缺 2K 官方数据，选中这两个比例时代码回退到 1K 像素值，不是虚构一个折中值。
- `quality` 只在旧版接口出现，新旧接口是否等价未实测，代码没有暴露 `quality` 参数，若未来要补齐需要先用真实任务验证新接口是否隐性支持。
- 图片输入统一走 `images` 字段，本地文件由公共媒体预处理层转 base64 内联，不需要接入供应商级别的上传 API。
