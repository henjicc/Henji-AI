## 决定
- 工作仅在 task/06-导出按输出分辨率 分支；保留指定基线，不拉取无上游的分支，不推送。交付一个提交。
- 渲染器增加 setOutputScale(scale, renderAtOutputResolution)，取代独立网页倍率入口。完整分辨率回退仍让网页沿用 ticket 03 的输出倍率。连续比例不写进预览偏好。
- 沿用现有渲染 Worker、合成器、作者 runtime 与画面尺寸计算；内部 divisor 接受正有限数，预览入口继续校验枚举。已存在及之后创建的嵌套、代码输入、相邻帧会话均继承比例，切换清理受影响帧缓存。
- 整数预览视频快照继续用现有 box 缩小；任意比例视频快照保留原始采样，在现有 GPU 合成绘制中缩放，不引入自研重采样算法或依赖。作者生成器与合成目标按任意比例分配，避免完整分辨率中间合成。
- 比例由原导出 source/destination 几何求出，缩放后的源坐标按实际舍入画布宽高分别换算；同画幅直接编码渲染画布，不经过 drawImage。异画幅只在输出画布补黑边或中心裁切，保持原几何。若裁切前的中间画幅超过既有合成规格，则自动走完整序列合成路径，保证合法横竖规格可交付。
- 放大导出遇到原生尺寸较大的作者或子序列时，若放大目标超过既有合成规格，则保留该输入的原生采样与逻辑放置尺寸，由父合成器缩放；结构化图形保持现有原生栅格路径。
- 不改变 usePreviews 的输出规格准入与失败回退，不改变缓存内容身份与失效规则。
- 开关复用现有 UiFormRow/UiCheckbox。既有导出设置 schema 是界面、队列、预设反射与导出能力的唯一声明；不新增 MCP 工具。只扩展既有设置与说明。
- 持久格式：剪辑内容 43→44、录制会话 46→47、本机导出预设 2→3；只加可选字段，最低可读版本不变；逐版本纯迁移保留旧值，新增黄金样本并更新基线和发布承诺。
- 精确测试覆盖任意尺寸/舍入、作者比例、网页及嵌套输入比例、导出几何和两条路径、250ms 调度、预览复用准入、旧样本迁移与字段保留。L2 变更由干净上下文独立审查后提交。
- 对比复用正式单帧渲染会话和同一几何辅助函数，通过同目录 compare-frame.js 在应用开发控制台调用；两条路径同一快照、同一前帧预热，不使用预览文件，分别记录初始化、预热、渲染与拷贝耗时；PNG 留在内存。不启动应用，不连接 9334，不读写 D:\视频制作，不导出成片，不跑 Reality，不动 node_modules 联接点。
