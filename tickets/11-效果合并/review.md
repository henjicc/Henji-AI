# 11 审查记录
摘要：Codex 只读交叉审查 1 轮：重要 3、小问题 1；Claude 目视预览页通过（模糊四方式、暗角、颗粒、马赛克、锐化）。裁定见下，交回实现子代理修复。

## 交叉审查与裁定
1. 重要：贝塞尔模糊曲线带 easeRange/easeValues 时，非线性换算破坏连续性（σ 0.05 → 下一帧 0.026，应 ≈0.0575）→ 修：非线性换算时按帧重采样成等价关键帧或在换算后保持曲线连续，补该回归测试。
2. 重要：本机预设库含一条旧 ID 或负数暗角就整库读取失败、禁止保存；工程含一处未迁移旧 ID（即使已停用）整份打不开 → **不改决定 6（不做数值迁移），但读取不能失败**：已删除的内置效果作为“已移除的效果”原样保留（数据不丢、渲染跳过并给一次提示、可删除），预设库与风格包、模板同理；负数暗角等越界值按新范围钳制并记录。补“含旧 ID 的工程能打开、其余内容正常”的测试。
3. 重要：调色合并没有基础项的等价映射（饱和度 −100 灰度不同；整体色相旋转、亮度/明度无对应）→ 不做映射（决定 6）；全能调色缺“整体色相旋转”记为后续项（改图片编辑共用参数与格式，单独排期），在 result 写明能力差异。
4. 小：旧高斯 σ 超新范围被静默截断改变画面 → 硬范围放宽到覆盖旧合法最大值（软范围不变），迁移不截断。
