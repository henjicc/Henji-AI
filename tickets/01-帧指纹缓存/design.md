# 01 帧指纹缓存 · 设计
窗口键里代码片段的部分由“代码版本摘要”换成“窗口内各帧指纹的散列”。
帧指纹在预渲染 Worker 里逐帧求，只跑作者代码不栅格化，按（片段、代码身份、参数摘要、帧）缓存在内存。

## 决定
- 两条求法：可录制的 Canvas 图层录绘制指令；作者声明 `frameKey(params, w, h, info)` 时直接用返回值（纯函数、可 JSON 序列化，描述这一帧整个曝光区间）。
- `dataFiles`：只有声明了 frameKey 的模块，代码身份才排除这些文件；它们对画面的影响必须全部体现在 frameKey 返回值里。漏报会留下旧画面，用“删除渲染文件”恢复。
- 退回版本摘要的情况：原生 GPU 且无 frameKey、读像素、音频依赖、作者报错、未知网页内容、序列输入等，原因进 render_cache 日志 context。
- 指纹按窗口就绪：窗口内全部代码片段的帧指纹算好即可用；从播放头附近往外算，播放中按预算继续，打断后空闲恢复。
- 片子侧：四个模块拆成“先算清单再画”，frameKey 返回同一份清单；入口声明 film/yuanbao-v2 下的数据文件。
