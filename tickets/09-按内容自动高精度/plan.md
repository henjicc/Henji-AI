摘要：发光、相加/滤色混合、大面积渐变或暗角等内容所在的帧自动整帧走 rgba16float 合成并在交接处保留浮点，其余帧保持 8 位、逐像素与现在相同；预览、预渲染、导出用同一条规则。

## 范围
1. 高精度判定加入内容：挂发光、相加/滤色等会超白或累积误差的混合、大面积渐变或暗角等效果的图层与片段算高精度输入；同一帧有一个就整帧 rgba16float，最后固定抖动转画布格式。
2. 交接保留浮点：高精度图层的栅格、效果链中间与输出、作者图层栈目标用 rgba16float，效果之间不写回 8 位；评估零 alpha 光的 carriesLight 特殊处理能否在浮点路径里简化（能简化就简化，保持结果不变）。
3. 预渲染缓存键带上精度（按内容决定）；导出复用预览判定照旧。不改已登记的持久格式：精度并入现有帧指纹即可。
4. 导出仍是 8 位 H.264/H.265。

## 不做
全局 8/16 位开关；10 位 HEVC 导出；效果库新效果。

## 验收
- 8 位内容的帧与现在逐像素相同、耗时不变（真实 GPU 测试 + 基准对比）。
- 发光段同一帧预览、预渲染、导出像素一致；高光不再被 8 位交接截掉（测试断言超白累积不丢）。
- 光效段显存峰值与每帧耗时记录在 result.md（1080p 与 4K）。
- `npm run test:gpu -- <相关>`、`npm run verify:changed -- --level L2 <本次文件...>` 通过。
