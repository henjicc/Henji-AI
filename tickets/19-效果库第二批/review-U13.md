# 19-U13 音频审查记录
摘要：合并审查 1 轮（Opus high）：无重要问题，小 6；声音逐位等价、迁移精确已核实。裁定见下。

1. 迁移后音频内容与整段处理配方的身份变了（声音不变），会让嵌套序列文字稿失去绑定、未回填字幕报“内容已变”、整段离线处理重算 → 迁移时同步重算并改写这些存储的身份/绑定，声音不变就不得触发重识别或重处理；补测试。
2. 合并后效果的悬停说明只写了第一种方式、拼接痕迹明显、引用已不存在的“参数均衡” → 说明文案由 Claude 侧（Opus）按“参数与说明规范”逐方式重写（Codex 修完 1/3/5/6 后进行）。
3. 均衡器“参数”方式 21 个参数含重复搁架 → 把旧参数均衡的 simple_* 拆成单独方式（例如“简易”），保持逐位等价。
4. design.md 版本表同步 U13 实际升的版本（本机效果库 4、预设包 12、风格库 8、风格包 11），U14 在其上顺延。
5. 立体声合并后 audio_stereo 空分组删掉。
6. 带关键帧时逐样本新建参数对象 → 复用对象或只在参数变化时更新。

## 第 1 条裁定（11-01）
同意：迁移时为音频内容与整段处理配方记录迁移前的身份（别名），字幕、文字稿绑定与离线处理缓存比较时接受当前身份或该别名；只加可选字段，按 persistence.md 登记。声音不变就不得触发重识别或重处理。
