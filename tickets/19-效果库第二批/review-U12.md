# 19-U12 过渡审查记录
摘要：合并审查 1 轮（Opus high）：重要 4、小 6；裁定见下。合并顺序：U13 先合，U12 后合并重新登记版本。

1. 重要：合并后参数键名由比较来源参数整段 JSON（含说明文字）推出，改说明、升级 shaders 包或插入方式都会改动已存的键 → 改为显式固定映射表，作为持久契约；新方式只能在末尾追加。
2. 重要：设置 video_edit.default_transitions 只认来源 ID，助手按目录 ID 写会被拒，说明与读回仍是旧 ID → 接受并读回目录 ID，说明列目录 ID。
3. 重要：设默认时存成第一种方式的来源 ID，isDefault 比较恒为 false（11 个条目）→ 统一用目录 ID 存与比较，与效果库面板同一个换算函数。
4. 通用创建路径仍能新建已删除或被合并掉的来源 ID → 在通用写入入口统一拦截，报错说明“已移除/已合并到某条目”并给出可用条目。
5. 本机效果库收藏与评分里的旧过渡/旧效果 ID 没迁移 → 迁移到条目 ID；本机效果库格式在 U13 合并后的版本上顺延。
6. 技能里 transition:shaders.* 的写法同步为新目录。
7. 合并条目的“方式”参数说明逐个写清选项含义（事实性描述，Claude 复核措辞）。
8. 面板“种类”下拉对已删除/未迁移 ID 显示为空 → 显示“已移除的过渡（按交叉溶解播放）”。
9. 重要：与 U13 撞号 → U13 先合；U12 在主线最新版本上重新登记剪辑/录制版本（最低可读随之），重新生成样本，U13 的样本不动。
10. 溶解点阵、半调与统一亮边等 ticket 12 合并后只在末尾追加。
