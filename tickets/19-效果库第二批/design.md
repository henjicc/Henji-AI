### 2.1 模糊：补“旋转”方式与“范围”（U1）

方式 `mode` 增加 `spin`（旋转）；`center_x/y`（中心）的显隐改为 `mode ∈ radial, spin`。新增：

| 键 | 名称 | 组 | 单位 | 软 | 硬 | 默认 | 显隐 |
|---|---|---|---|---|---|---|---|
| `range` | 范围 | 范围 | 选项：整幅 `full` / 渐进 `progressive` / 移轴 `tilt` | | | 整幅 | mode ∈ uniform, lens |
| `range_x`、`range_y` | 位置（水平 / 垂直） | 范围 | % | 0–100 | −100–200 | 50 / 50 | 同上且 range ≠ full |
| `range_angle` | 角度 | 范围 | ° | −180–180 | −180–180 | 90 | 同上 |
| `range_width` | 清晰范围 | 范围 | % | 0–100 | 0–100 | 30 | 同上且 range = tilt |
| `range_falloff` | 过渡 | 范围 | % | 0–100 | 0–100 | 40 | 同上 |

说明：
- 方式（补一句）：旋转让画面绕中心转着糊开，像转盘、车轮。
- 模糊度（补一句）：旋转方式下按转过的角度算，40（默认）约 18°，100 约 45°。
- 范围：哪里糊、哪里清楚。整幅（默认）处处一样；渐进从“位置”开始沿“角度”越来越糊；移轴只留一条清楚的带，两边渐糊，像微缩模型。
- 位置：渐进从哪里开始变糊，移轴清楚带的中心。50%、50%（默认）在正中。
- 角度：越来越糊的方向。90°（默认）渐进往下加重、移轴是一条水平带；0° 往右加重、带是竖的。
- 清晰范围：移轴时清楚的带有多宽。30%（默认）约画面高度的三成；10% 只剩一窄条，微缩感最强。
- 过渡：从清楚到最糊经过多远。40%（默认）柔和；10% 很快糊到底；100% 拉满整个画面慢慢变。

显隐要两个条件同时成立：U0 给 `visibleWhen` 加“全部满足”写法 `{ all: [条件, 条件] }`，作者参数共用同一写法。

工序：
- 旋转：照 ticket 11 放射方式，第一道 16 点沿圆弧取满 θ = 0.45° × 模糊度，之后每道角距除以 16，迭代到离中心最远的内容角上弧步不到 1 像素；取样在内容坐标按像素等比计算，不随画幅长宽比变形。外扩 = 内容四角绕中心转 ±θ/2 后超出 bounds 的最大值。
- 范围·均匀：13 点降采样金字塔（发光同法）；每像素目标 σ(x) = σ × m(x)，按 log2(σ(x)/σ₀) 在相邻两层之间插值；低层取样用双三次 B 样条（4 次双线性实现，Sigg & Hadwiger 2005），大半径处不出方块。m(x)：渐进 `ramp(0, 过渡, 沿角度的距离)`，移轴 `ramp(宽/2, 宽/2 + 过渡, |到带中心线的距离|)`，距离按画面高度归一。
- 范围·镜头：现有 96 点圆盘，每像素半径乘 m(x)。
- 删除：着色器 ChannelBlur、DiffuseBlur 从目录撤下；AngularBlur、ProgressiveBlur、TiltShift 进 `SAME_AS_BUILTIN`。

观感目标：移轴在城市航拍上像微缩模型，清楚带边缘没有一条“糊与不糊”的硬线；渐进从上到下平滑加重，不出一级一级的台阶；旋转中心清楚、外圈拖成圆弧，静止时不抖。

| `mode` | 方式 | — | 选项：双色 `two` / 三色 `three` | | | 双色 | — |
| `dark_color` | 暗部颜色 | — | 颜色 | | | #000000 | — |
| `light_color` | 亮部颜色 | — | 颜色 | | | #ffffff | — |
| `mid_color` | 中间调颜色 | 映射 | 颜色 | | | #808080 | mode = three |
| `mid_point` | 中间调位置 | 映射 | % | 0–100 | 0–100 | 50 | mode = three |

| `white_point` | 白场 | 映射 | % | 0–100 | 0–100 | 100 | — |
| `interpolation` | 插值 | 映射 | 选项：感知 `perceptual` / 标准 `srgb` | | | 感知 | — |

说明：方式——双色（默认）从暗部颜色过渡到亮部颜色；三色多一个中间调颜色。暗部 / 亮部颜色——最暗、最亮处换成的颜色；黑、白（默认）就是按人眼明暗变黑白。中间调位置——中间调颜色落在多亮处，50%（默认）正中。黑场 / 白场——比黑场还暗的都用暗部颜色、比白场还亮的都用亮部颜色；把黑场调到 20%，暗部更实。插值——颜色之间怎么过渡；感知（默认）中间不发灰发脏；标准与网页 CSS 渐变一致。

工序：逐点一道。反预乘 → 线性光 → OkLab L → `t = ramp(黑场, 白场, L)` → 按插值方式在 OkLab 或 sRGB 编码值里插颜色 → 乘回 alpha。OkLab 与插值函数放进 U0 的共用着色器数学（渐变也用）。不要求浮点。

**色调分离 `posterize`**。效果说明：把颜色压成几个台阶，做出海报、丝网印刷般的扁平色块。

| 键 | 名称 | 组 | 单位 | 软 | 硬 | 默认 |
|---|---|---|---|---|---|---|
| `levels` | 色阶 | — | 数值，步长 1 | 2–16 | 2–64 | 6 |
| `by` | 分离方式 | — | 选项：按通道 `channels` / 按亮度 `luminance` | | | 按通道 |
| `smooth` | 平滑 | 色阶 | % | 0–100 | 0–100 | 0 |

说明：色阶——每个颜色留几级。2 只剩最亮最暗；6（默认）明显的色块；16 接近原画。分离方式——按通道（默认）颜色和明暗都分级；按亮度只分明暗、保留原色相。平滑——台阶之间硬切还是柔和过渡；0%（默认）硬边；50% 色块边缘柔一些。

**胶片模拟 `film_look`**（封装 shaders FilmStock，片段）。效果说明：套用十种经典胶片的颜色，带高光周围的红色光晕和片门晃动。适合素材调色；在 8 位里算，暗部大面积渐变上可能有色带。主参数：胶片（十种，名称译成通行中文名）、强度（0–100，默认 100）；光晕组：光晕（0–100，默认 30）、光晕半径（0–100，默认 40）；晃动组：片门晃动（0–100，默认 0）。数值按组件属性的范围线性换算到 0–100，软硬范围相同。

观感目标：渐变映射黑→白时与“黑白”效果人眼无差别；三色深蓝 / 灰 / 暖白时透明底文字边缘不出暗边。色调分离 6 级在照片上成干净的色块，静止时边缘不闪。

### 2.3 质感（U3）

**半调网点 `halftone`**。效果说明：把画面变成一格一格的网点，像印刷品。适合给照片、卡片和文字加印刷质感；网格始终正着排。

| 键 | 名称 | 组 | 单位 | 软 | 硬 | 默认 | 显隐 |
|---|---|---|---|---|---|---|---|
| `size` | 网点大小 | — | 强度（格子尺） | 0–100 | 0–100 | 40 | — |
| `mode` | 方式 | — | 选项：单色 `mono` / 彩色印刷 `cmyk` | | | 单色 | — |
| `shape` | 形状 | 网点 | 选项：圆点 `dot` / 线条 `line` | | | 圆点 | — |
| `contrast` | 对比度 | 网点 | 强度 | 0–100 | 0–100 | 50 | — |
| `color_mode` | 颜色 | 颜色 | 选项：原色 `original` / 双色 `duo` | | | 原色 | mode = mono |
| `ink` | 墨色 | 颜色 | 颜色 | | | #000000 | color_mode = duo |
| `paper` | 纸色 | 颜色 | 颜色（可透明） | | | #ffffff | color_mode = duo |
| `misregister` | 套色偏移 | 颜色 | 强度（距离尺） | 0–100 | 0–100 | 0 | mode = cmyk |

说明：网点大小——每个网点格子多大。0 细到接近原画；40（默认）约画面高度的 0.9%；100 约 8%，一颗颗大圆点。方式——单色（默认）一层网点；彩色印刷四色网点叠印，近看有玫瑰斑。形状——圆点（默认）或一排排粗细变化的线条。对比度——网点大小随明暗变化得多明显；50（默认）；调高暗处更实、亮处更空。颜色——原色（默认）网点用原画颜色、亮处网点大、网点之间透明，适合暗底；双色是墨印在纸上，暗处墨点大。墨色 / 纸色——双色时墨和纸的颜色，纸色可以设成透明。套色偏移——四色版错开多少，像没对准的印刷；0（默认）对齐。

工序：两道。① 盒式降采样到“每格 2×2 像素”的小纹理（取每格平均色与 alpha）；② 逐点：取最近 4 个格心（Gustavson 2011），覆盖半径 `r = 0.71g × √(调后亮度或暗度)`，抗锯齿宽 `0.7 × fwidth`，覆盖再乘该格 alpha；彩色印刷按 CMYK 四版、标准网角 15°/75°/0°/45°，减色叠印在纸色上。单色网格角度固定 0°，不开放角度。图层空间、格子锚在内容坐标，外扩 0。

观感目标：圆点干净圆润、边缘利落不发虚；推近按栅格倍率重算仍清楚；静止时网点不闪、不出摩尔纹；暗底上原色网点像点阵屏。

**抖动点阵 `dither_pattern`**。效果说明：用规则排列的像素点把画面压成几种颜色，像老式电脑与掌机画面。别名：抖动、仿色、dither、1-bit。

| `pattern` | 图案 | — | 选项：方格 `bayer` / 蓝噪声 `blue_noise` | | | 方格 | — |
| `levels` | 色阶 | 颜色 | 数值，步长 1 | 2–8 | 2–16 | 2 | — |

**纸张 `paper`**。效果说明：给画面加一层纸面的纤维和颗粒，只改表面、不做凹凸立体。适合卡片、手写感标题和静态背景；纹理跟着图层走。

### 2.4 故障 `glitch`（U4）

效果说明：让画面像信号出错一样断裂、错位、串色。适合科技感标题、转场前后的一两下冲击；给“强度”打关键帧做出一下一下的爆发。

| 键 | 名称 | 组 | 单位 | 软 | 硬 | 默认 | 显隐 |
|---|---|---|---|---|---|---|---|
| `amount` | 强度 | — | 强度 | 0–100 | 0–100 | 40 | — |
| `mode` | 方式 | — | 选项：数字故障 `digital` / 条带错位 `bars` / 压缩失真 `compression` | | | 数字故障 | — |
| `rhythm` | 变化频率 | — | % | 0–100 | 0–100 | 60 | — |
| `block_size` | 块大小 | 块 | 强度（格子尺） | 0–100 | 0–100 | 40 | mode ≠ bars |
| `bars` | 条带数 | 块 | 数值，步长 1 | 2–40 | 2–200 | 12 | mode = bars |
| `angle` | 角度 | 块 | ° | −180–180 | −180–180 | 0 | mode = bars |
| `rgb_split` | 色彩分离 | 颜色 | 强度（距离尺） | 0–100 | 0–100 | 40 | mode ≠ compression |
| `seed` | 随机种子 | 块 | 数值，不做动画 | 0–9999 | 0–9999 | 0 | — |

说明：强度——出错有多凶。0 没有；40（默认）几块明显错位；100 大半个画面碎掉。方式——数字故障（默认）一块块横向错开、红蓝分离；条带错位把画面切成平行条带各自偏移；压缩失真像码率不够时的方块与串色。变化频率——多久换一种错法；0% 定住不变；60%（默认）约每 6 帧一变；100% 每帧都换。块大小——错位块多大，40（默认）约画面高度 0.9%。条带数——切成几条；12（默认）。角度——条带走向，0°（默认）水平。色彩分离——红蓝错开多远，40（默认）约画面高度 2%。

工序：逐点 / 邻域一道。时间段长 `1 + round(30 × (1 − 频率)²)` 帧（频率 0 为一段到底），按帧号与种子取 hash，预览与导出一致。数字故障：4:1 横向块网格，强度 × 30% 的块水平偏移 0.5–3 个块宽，块内红、蓝按色彩分离反向取样；强度 > 60 时每段最多一块反相。条带：沿角度法向分 N 条，每条偏移 `hash × 强度 × 0.05H`。压缩失真：亮度按块平均与原画按强度混合，色度按 2×2 块平均（4:2:0 拖色），块边不做柔化。取样越界为透明；外扩 = 最大偏移（压缩失真为 0）。

观感目标：块边利落、横平竖直；透明底文字错位的碎片飞出原位但不留黑边；变化频率 0 时完全静止。

### 2.5 光（U5）

两个都是画面空间（片段、代码调整层），产出光：片段上相加，代码调整层与图层栈里走零 alpha 光（05 裁定 C1）；判高精度。

**镜头光晕 `lens_flare`**。效果说明：在画面里放一个强光源，带光晕、星芒和横向拉丝，像镜头正对着灯。鬼影（一串圆形光斑）默认关闭。

## 3. 防色带标准件：渐变、暗角、柔和阴影（第 16 项做法 2）

### 3.1 规则

- **判高精度**：效果定义新增 `precision(params, plan) → boolean`（U0），由 `videoEditEffectNeedsFloat` 统一读取，取代现在的白名单。渐变在非纯色时为真；暗角数量 > 0；投影按 ticket 12 以规划判定；镜头光晕、漏光亮度 > 0；模糊沿用 ticket 11。同一帧有一个为真，整帧在 rgba16float 里合成（ticket 09 已实现的按帧判定、作者栈遇到首个触发层升 16f）。
- **按最终画面半级亮度抖动**：高精度帧的末道转换已经加固定的交错梯度噪声抖动，幅度是输出格式的 ±0.5 级（`VIDEO_EDIT_PRESENT_SHADER`，Jimenez 2014）。这正是“按最终画面算”：抖在最终颜色上，与下面是什么底色无关。所以标准件**不在效果内部抖动**：
  - 删去 ticket 11 暗角内联的 ±0.5/255 抖动、ticket 12 投影加在 alpha 上的抖动（后者正是《以后再做》第 16 项实测“按透明度半级抖动、换算到画面不到一级的十分之一，没效果”的写法）。ticket 12 尚未实现，实现时直接不写；暗角在 U8 里删。
  - 发光现有“质量·抖动”参数不动（它在效果里按光的改动加，是已上线的用户参数）。
- **边界**（写进技能）：shaders 框架的生成器与封装效果出口是 8 位，作者 Canvas2D 渐变是 8 位栅格，这两处的色带在合成前已经定型，宿主补不回来。暗底大面积的光与渐变一律用渐变、漏光、镜头光晕、发光、投影这些原生标准件。

### 3.2 渐变 `gradient`（生成器，原生，图层空间）

效果说明：生成平滑的颜色渐变，做背景、卡片底色或叠在内容上。在高精度里算，暗底上的大面积渐变也不出色带。

| 键 | 名称 | 组 | 单位 | 软 | 硬 | 默认 | 显隐 |
|---|---|---|---|---|---|---|---|
| `mode` | 方式 | — | 选项：线性 `linear` / 径向 `radial` / 角向 `conic` / 菱形 `diamond` / 多点 `points` | | | 线性 | — |
| `start_color` | 起点颜色 | — | 颜色（可透明） | | | #000000 | mode ≠ points |
| `end_color` | 终点颜色 | — | 颜色（可透明） | | | #ffffff | mode ≠ points |
| `start_x`、`start_y` | 起点（水平 / 垂直） | 位置 | % | 0–100 | −100–200 | 50 / 0 | mode ≠ points |
| `end_x`、`end_y` | 终点（水平 / 垂直） | 位置 | % | 0–100 | −100–200 | 50 / 100 | mode ∈ linear, radial, diamond |
| `angle` | 起始角度 | 位置 | ° | −180–180 | −180–180 | 0 | mode = conic |
| `p1_color`…`p4_color`、`p1_x/y`…`p4_x/y` | 点 1–4：颜色、位置 | 点 1 … 点 4 | 颜色 / % | 0–100 | −100–200 | 黑、深灰、浅灰、白，四角 | mode = points |

| `repeat` | 重复 | 颜色 | 选项：不重复 / 重复 / 往返 | | | 不重复 | mode ≠ points |
| `drift` | 漂移 | 颜色 | %，不做动画 | 0–100 | 0–100 | 0 | mode = points |
| `blend_mode` | 混合模式 | 输出 | 选项：正常 / 正片叠底 / 滤色 / 叠加 / 柔光 | | | 正常 | — |

说明：方式——线性（默认）从起点到终点；径向从起点向外一圈圈；角向绕起点转一圈；菱形向外成菱形；多点四个颜色点按远近融合，像网格渐变。起点 / 终点颜色——两端的颜色，默认黑到白。起点 / 终点——按内容框百分比；默认从上到下。起始角度——角向渐变从哪个方向开始。点 1–4——多点方式下每个颜色点的颜色与位置。中点——两种颜色各占一半的位置，50%（默认）居中；调到 20% 终点颜色占得多。插值——感知（默认）中间不发灰；标准与网页 CSS 渐变一致。重复——走到终点之后怎样：不重复（默认）停在终点颜色，重复从头再来，往返来回。漂移——多点方式下颜色点缓慢游动，做流动的背景；0（默认）静止。混合模式——叠在内容上的方式，正常（默认）在内容范围内直接换成渐变。

工序：逐点一道，输出 rgba16float，`precision` 恒为真（两色相同除外）。t 的算法：线性投影、径向 `|q − 起点| / |终点 − 起点|`、菱形 L1 距离、角向 `atan2`；中点 `t' = t^(ln 0.5 / ln m)`；多点为 Shepard 反距离加权（幂 1.5，OkLab 里加权），漂移按时间给位置加 3% 幅度的低频噪声。用作效果时只在内容 alpha 内按混合模式替换；用作图层画面来源（3.4）时铺满 bounds。8 个来源组件（LinearGradient、RadialGradient、ConicGradient、DiamondGradient、MultiPointGradient、MeshGradient、FlowingGradient、ColorWheel）进 `SAME_AS_BUILTIN`；色轮用角向 + 起止同色的写法在说明里给出。

### 3.3 暗角与柔和阴影

- 暗角（ticket 11 已有）：补 `space: 'frame'`（只能上片段与代码调整层）、`precision`（数量 > 0）、作者工厂 `vignette`；删内联抖动。
- 柔和阴影就是投影（ticket 12）大柔和度的用法，不另设效果。技能配方：录屏窗口、卡片在暗台面上的阴影写 `shadow({ distance: 8, softness: 90, opacity: 50 })`，图层要给 bounds（外扩自动算）。

### 3.4 作者用法（henji-effects）

```js
import { gradient, vignette, grain, shadow } from 'henji-effects'
layers: (p, w, h) => [
  // 背景：图层画面来源用生成器，不写 draw
  { id: 'bg', bounds: [0, 0, w, h], fill: () => gradient({ mode: 'radial', start_color: '#16171a', end_color: '#0d0e10', start_x: 50, start_y: 40, end_x: 50, end_y: 110 }) },
  // 窗口：柔和阴影
  { id: 'window', bounds, draw, effects: () => [shadow({ distance: 8, softness: 90, opacity: 50 })] },
  // 代码调整层：暗角、颗粒作用于下方全部图层
  { id: 'look', adjust: () => [vignette({ amount: 25 }), grain({ amount: 15 })] },
]
```

- `fill`：新的图层画面来源（与 `draw` 二选一），只接受原生生成器的描述（本批只有渐变），宿主按 bounds 在 GPU 里画，可再接 `effects`、`pose`、`clip`。
- 复核（U8，`codeEffectReview` 的静态检查）：作者 Canvas2D `createLinearGradient / createRadialGradient / createConicGradient` 的填充范围超过画面四分之一，或动态 `shadowBlur`，提示改用 `gradient()` / `shadow()`；ticket 07 的取帧色带检测保持原样。
- 技能（`color-texture.md`、`recipes`）：渐变、暗角、阴影、光一律用标准件；暗部改过后取帧拉高对比度 6 倍看一遍。

### 3.5 验收

真实设备着色器用例：4K 台面 14/255 上叠柔和度 90 的投影，以及 #16171a→#0d0e10 径向渐变，导出 8 位后用 ticket 07 的色带检测（`bandingReview`）不报；同一帧预览与导出像素一致；暗角删抖动后在 16f 帧里与原观感人眼无差别。按画质导出（ticket 08，FFmpeg CRF 重压）后的文件同样拉暗部检查，结果记入 result（有损压缩可能抹掉抖动，若复现就记为导出侧问题，不在效果里加大抖动）。

## 4. 代码调整层（U9）

- 作者接口：图层新增一种 `{ id, name?, adjust: (t) => EffectDescriptor[], clip?, pose? }`，与 `draw` / `fill` / `effects` 互斥。它作用于本模块里排在它下方、已合成好的全部图层，按整幅作者画面算（H = 作者画幅高度）。`pose` 只取 `opacity`（与原画按不透明度混合），`clip` 限定作用范围。
- 可用效果：`space` 为 `frame` 或 `layer` 的效果。`frame` 效果（暗角、颗粒、镜头光晕、漏光、划痕）只能出现在 `adjust` 与片段效果链里，放进普通图层的 `effects` 时报错：“暗角按整幅画面算，请放进调整层 adjust。”颗粒、暗角补 `space: 'frame'` 与作者工厂；整体调色、放射色差是 `layer` 效果，在调整层里按整幅算。
- 执行：`VideoEditAuthorRuntime.renderFrame` 图层循环遇到调整层时，把已有图层栈目标作为输入，在同一个帧编码器里跑效果链，结果写回栈目标（opacity < 1 时与原栈混合）；精度沿 ticket 09“遇到首个触发层升 16f 并拷贝此前内容”。
- 限制（写进技能）：下方图层的零 alpha 光在调整层里按透明像素处理，会被调色等反预乘的效果去掉；模块里有不透明背景时光已经叠进背景，不受影响。透明底模块要对光调色，在产生光的那一层 `effects` 里调。
- 读回：取帧观察里调整层作为一个元素出现（`kind: 'adjust'`，带实际效果与参数）；没有画面范围，不在画面上点选，从源码定位或按 id 选中。
- 静止分组：声明了 `adjust` 的位置把静止批组切开，与 ticket 05 对 `effects` 层的处理相同。

## 9. 片段效果链换新执行器（U10）

三步，每步量过才保留（与 ticket 12 描边细路径同一规则：不更快就撤回）：

1. **一条链一次提交**：片段效果链改用 ticket 05 拆出的 `preparePlan / encodePlan` 内核，整条链（含强度混合、区域遮罩）编进同一个命令编码器、一次提交；uniform 槽与 scratch 占用按整条编码批次计。
2. **逐点合并**：`stage: 'point'`、无遮罩、规划只有一道且不用查找表的相邻效果合成一道 `point_chain`：预编译的通用着色器按 uniform 里的工序表（每道最多 8 项，每项操作码 + 3 个 vec4）循环 `switch` 执行。每个逐点效果的 WGSL 拆出 `fn op_<名>(c, p, pos) -> vec4f`，单独一道与合并一道调用同一函数，算法只有一份。全能调色（带 LUT 与曲线表）不进合并。
3. **alpha 金字塔共用**：投影与发光·轮廓在同一输入内容上时共用一次 alpha 降采样（按纹理身份 + 写入代次在一次编码批次内缓存）。颜色金字塔共用本批不做。

测量：显卡空闲后用诊断会话的 timestamp-query 记 GPU 时间，三类真实画面（标题发光 + 投影、调色 + 颗粒 + 暗角、录屏 + 色差 + 锐化），报 P50 / P95 / 最大值；8 位帧逐像素与改前相同。

## 11. 点选画面元素来调整

### 11.1 人怎么用

1. 选择工具点中画面上的代码元素（现有 `codeElementSelection`），效果控件出现这个元素，依次三块：**变换**（现有位置、缩放、旋转、不透明度、隐藏）、**属性**（绑定到这个元素的作者参数：颜色、文字样式、圆角、间距……）、**效果**（这个元素的效果链，面板与片段效果完全一样：分组、软硬范围、一份说明、关键帧、fx 开关、重置）。
2. 改过的值旁边显示“已改”标记与重置按钮；重置回到代码给的值。
3. 从效果面板把效果拖到选中的元素上（画面或效果控件），追加到它的效果链末尾。
4. 代码给的效果可以用 fx 开关关掉，代码不动。
5. 风格件（`look()`）在效果块里显示为一项，只露出它的旋钮；要改风格件里定好的效果参数，去改风格件本身。

### 11.2 宿主能力（U15a）

- **效果的稳定身份 key**：描述新增可选 `key`（工厂第二个参数 `glow({...}, { key: 'titleGlow' })`）。缺省 key = 效果 id，同一元素里第二个同 id 的为 `glow#2`；look 为 `look:<名称>`；同一元素内重复报错。
- **元素覆盖值扩展**（`codeElementOverrides.ts`）：
  ```ts
  effects?: Record<key, { enabled?: boolean; values?: Record<参数键, 值>; curves?: Record<参数键, 关键帧[]> }>
  addedEffects?: Array<{ key: string; id: string; params: Record<string, 值>; curves?: Record<string, 关键帧[]> }>
  ```
  曲线与现有覆盖一样锚在素材时间，修剪、变速、倒放不错位。look 项的 `values` 只接受旋钮键。
- **应用顺序**：`resolveAuthorEffects`（代码给的值）→ 按 key 叠上覆盖值（素材时间求值）→ `enabled: false` 的跳过 → 末尾接 `addedEffects` → `pose.blur` 仍在最后。写入按硬范围严格校验，读取按 ticket 11 的容错（越界钳制、已移除效果跳过）。
- **找不到**：代码里已没有某个元素或某个 key 时，覆盖原样保留，状态为 missing（沿用 `codeElementOverrideStatus`），效果控件显示“代码里已没有这个效果，改动已保留”。
- **缓存与指纹**：覆盖值进入图层效果输出键与片段渲染指纹；核对 `videoEditCodeFingerprint` 是否已含 `elementOverrides`，未含则补。
- **手动修改记录**：片段新增
  ```ts
  edits?: Record<string, { by: 'user' | 'assistant'; at: number }>
  ```
  键：`param:<参数键>`、`element:<元素>:<属性>`、`element:<元素>:effect:<key>:<参数键>`、`element:<元素>:effect:<key>:enabled`、`element:<元素>:added:<key>`。只留最后一次。写入点就是共用的写入函数（`setVideoEditCodeParameter` 及曲线、重置，元素覆盖与元素效果的写入），新增必填参数 `actor`，界面传 `user`，应用能力层按操作来源（`operationOrigin.actor` 为 embedded / external）传 `assistant`。重置删掉对应记录；助手重写代码不碰 edits。
- **读回**：取帧观察里每个元素的效果带 `key`、代码值、覆盖后的实际值、哪些参数被覆盖、是否追加；元素与参数一并带 edits（“用户 10-31 14:20 手动改过”）。
- **助手写入**：按 henji-application-capability 做覆盖分级，代码元素注册成实体属性（变换、属性、效果三组），读改走通用动词；`video_edit.document.selected_code_element` 继续表示当前选中。不新增专用工具。
- **撤销**：所有写入都经 `editVideoProject` / `updateVideoEditGesture` 或正式事务，进同一个撤销栈；拖动滑块是一个手势一步。

### 11.3 作者约定（U15c，写进 video-edit-code-creation 技能）

1. 人可能想改的元素都给稳定 `id`；同一元素里有两个同类效果时给 `key`。改代码时保持 id 与 key 不变。
2. 画在 draw 里、用户可能想改的视觉属性（颜色、文字与文字样式、字号、粗细、圆角、间距、描边宽度）写成作者参数，用 `layer` 绑定到元素，数据卡用 `data` 绑定到行；参数按组写（与效果参数同一种分组与显隐写法）。
3. 尺寸由内容算：底板、框、连线的大小用 `henji-layout` 的文字测量与 `layoutBoxes`，前后元素用布局排，不手算坐标。
4. 重写代码前先读 edits：用户手动改过的值保留（覆盖值独立存放，重写代码不会丢）；要改这些值、或把覆盖值写回代码，先问用户。
5. 复核：`authoringHints` 加 `UNBOUND_VISUAL`（有 id 的元素除文字外没有任何绑定参数，提示“点中它时改不了颜色、字号”）；文字撑框沿用 ticket 04 的 `text_box_overflow`。

### 11.4 界面（U15b，Claude，henji-ui-surface）

效果控件的元素视图三块布局、“已改”标记、重置、元素上 fx 开关、拖放追加、missing 提示。面板安静：标记用中性小点，不用强调色。

### 11.5 持久格式

元素覆盖值 `effects`、`addedEffects` 与片段 `edits` 都是新增可选字段：剪辑内容、录制会话（按 schema 指纹实际变化的容器）升版本、写逐版本迁移与黄金样本，最低可读版本不提高（旧程序忽略它们，其余内容含义不变）。效果 `key` 进作者 API 新版本（第 12 节）。

## 14. 显存与 1080p 耗时目标

N = 图层纹理像素数（含外扩），1080p 整幅约 2.07M；8N ≈ 16.6 MB（rgba16float）。耗时为 GPU 时间目标（timestamp-query），预览页墙钟含约 3 ms 提交等待，不能直接对比。显卡空闲后实测（决定 5），超出目标按缺陷查，不调参数掩盖。

| 效果 | 工序 | 额外显存 | 1080p 目标 |
|---|---|---|---|
| 模糊·旋转 | 2–3 道 × 16 点 | 8N | ≤ 0.8 ms |
| 模糊·范围（均匀） | 金字塔 + 合成 | ≈ 8N / 3 | ≤ 1.0 ms |
| 渐变映射、色调分离、反相 | 1 道 | 0 | ≤ 0.15 ms |
| 半调网点 | 降采样 + 1 道 | 每格 2×2 小图 | 单色 ≤ 0.4 ms，彩色 ≤ 0.8 ms |
| 抖动点阵 | 降采样 + 1 道 | 小图 + 32 KB 蓝噪声（共用） | ≤ 0.3 ms |
| 纸张、划痕 | 1 道 | 0 | ≤ 0.3 ms / ≤ 0.15 ms |
| 故障 | 1 道 | 0 | ≤ 0.3 ms |
| 镜头光晕 | 光源 + 发光金字塔 + 拉丝 + 合成 | 与发光默认相当 + 1/16 N | 与发光默认相当 + 0.2 ms |
| 漏光 | 1/4 分辨率 1 道 + 放大合成 | N / 2 | ≤ 0.3 ms |
| 镜像、膨胀、旋转扭曲、波动、边角定位、置换 | 1 道 | 0 | ≤ 0.3 ms |
| 重复阵列 | 1 道，每像素 N 次取样 | 0 | 网格 ≤ 0.2 ms；环形 12 个 ≤ 1 ms |
| 渐变 | 1 道 | 输出 16f | ≤ 0.1 ms |
| 主体抠像 | 蒙版滤波 + 模糊 + 1 道 | 蒙版尺寸 | ≤ 0.5 ms（不含识别） |
| 执行器逐点合并 | 相邻 k 个逐点效果 1 道 | 少 (k − 1) 张中间纹理 | 比逐个执行快才保留 |
