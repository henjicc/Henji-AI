# 分辨率面板配置不规范

本文档对以下问题有帮助：分辨率面板显示混乱，比例和质量档位分离显示，质量选择器不显示，分辨率参数命名不规范，不符合统一的设计模式。

## 问题现象

适配新模型后，分辨率相关参数显示不正确：
- 比例和质量档位分别显示为独立参数
- 质量档位选择器不显示
- 参数 label 使用"比例"而不是"分辨率"
- 切换比例时质量选择被重置

## 根本原因

未按照**分辨率面板设计规则**配置参数，导致：
1. 缺少 `resolutionConfig` 配置
2. 缺少 `qualityOptions` 和 `qualityKey` 配置
3. 质量参数未正确隐藏
4. 参数 label 命名不符合规范

## 标准设计模式

痕迹 AI 使用**模式 A：比例 + 质量档位**作为视频模型的标准分辨率面板设计。

### 正确的配置结构

```typescript
// 比例参数（显示为"分辨率"）
{
  id: 'aspectRatio',
  type: 'dropdown',
  label: '分辨率',  // 组件显示名称
  defaultValue: '16:9',
  resolutionConfig: {
    type: 'aspect_ratio',
    smartMatch: true,           // 启用智能匹配
    visualize: true,            // 显示可视化预览
    extractRatio: (value) => {
      if (value === 'smart') return null
      const [w, h] = value.split(':').map(Number)
      return w / h
    },
    qualityOptions: [           // 质量档位选项
      { value: '720P', label: '720P' },
      { value: '1080P', label: '1080P' }
    ],
    qualityKey: 'resolution',   // 指向质量参数 ID
    defaultQuality: '1080P'     // 默认质量
  },
  options: [
    { value: '16:9', label: '16:9' },
    { value: '9:16', label: '9:16' },
    { value: '1:1', label: '1:1' }
  ]
}

// 质量参数（隐藏，通过 resolutionConfig 管理）
{
  id: 'resolution',
  type: 'dropdown',
  label: '质量',
  defaultValue: '1080P',
  options: [
    { value: '720P', label: '720P' },
    { value: '1080P', label: '1080P' }
  ],
  hidden: () => true  // 必须隐藏
}
```

## 常见错误

### 错误 1：缺少 qualityOptions 和 qualityKey

```typescript
// 错误：只配置了 type 和 smartMatch
{
  id: 'aspectRatio',
  type: 'dropdown',
  label: '比例',  // 错误：应该是"分辨率"
  resolutionConfig: {
    type: 'aspect_ratio',
    smartMatch: true
    // 缺少 qualityOptions
    // 缺少 qualityKey
  },
  options: [...]
}

// 质量参数独立显示（错误）
{
  id: 'resolution',
  type: 'dropdown',
  label: '质量',
  options: [...]
  // 未隐藏，会独立显示
}
```

**结果**：比例和质量分别显示为两个独立参数，不符合设计规范。

### 错误 2：质量参数未隐藏

```typescript
// 配置了 qualityOptions，但质量参数未隐藏
{
  id: 'aspectRatio',
  resolutionConfig: {
    qualityOptions: [...],
    qualityKey: 'resolution'
  }
}

// 错误：质量参数未隐藏
{
  id: 'resolution',
  type: 'dropdown',
  options: [...]
  // 缺少 hidden: () => true
}
```

**结果**：质量档位会显示两次（一次在分辨率面板内，一次作为独立参数）。

### 错误 3：label 命名不规范

```typescript
// 错误：使用"比例"作为 label
{
  id: 'aspectRatio',
  type: 'dropdown',
  label: '比例',  // 错误
  resolutionConfig: {
    qualityOptions: [...]
  }
}
```

**正确**：当有质量档位时，label 应该使用"分辨率"。

## 修复步骤

### 步骤 1：修改比例参数的 label

```typescript
// 修改前
label: '比例'

// 修改后
label: '分辨率'
```

### 步骤 2：添加 qualityOptions 和 qualityKey

```typescript
resolutionConfig: {
  type: 'aspect_ratio',
  smartMatch: true,
  visualize: true,
  extractRatio: (value) => { /* ... */ },
  // 添加以下配置
  qualityOptions: [
    { value: '720P', label: '720P' },
    { value: '1080P', label: '1080P' }
  ],
  qualityKey: 'resolution',      // 指向质量参数 ID
  defaultQuality: '1080P'        // 默认质量
}
```

### 步骤 3：隐藏质量参数

```typescript
{
  id: 'resolution',
  type: 'dropdown',
  label: '质量',
  defaultValue: '1080P',
  options: [
    { value: '720P', label: '720P' },
    { value: '1080P', label: '1080P' }
  ],
  hidden: () => true  // 添加此行
}
```

## UI 效果

修复后的分辨率面板应该显示为：

```
┌─────────────────────────────┐
│  分辨率                      │  ← 组件显示名称
├─────────────────────────────┤
│  比例                        │  ← 面板内部标签
│  [智能] [16:9] [9:16] [1:1] │
├─────────────────────────────┤
│  质量                        │  ← 面板内部标签
│  [720P]  [1080P]            │
└─────────────────────────────┘
```

## 命名规范总结

| 面板内容 | 组件 label | 面板内部显示 |
|---------|-----------|------------|
| 比例 + 质量档位 | **分辨率** | 比例 + 质量 |
| 仅比例 | **比例** | 比例 |
| 仅质量档位 | **分辨率** | 分辨率 |

## 快速检查清单

适配新模型时，检查分辨率参数配置：

- [ ] 比例参数的 label 是否为"分辨率"（有质量档位时）
- [ ] resolutionConfig 是否包含 `qualityOptions`
- [ ] resolutionConfig 是否包含 `qualityKey`
- [ ] resolutionConfig 是否包含 `defaultQuality`
- [ ] 质量参数是否设置了 `hidden: () => true`
- [ ] 质量参数的 defaultValue 是否与 defaultQuality 一致
