# 参数面板不显示问题

本文档对以下问题有帮助：模型的参数显示不正确，不该显示的参数显示了，改显示的参数没有显示，或者看不到任何参数

## 问题现象

适配新模型后，选择该模型时：
- 应该显示的参数一个都不显示
- 或者显示了不该显示的通用参数

## 根本原因

`ParameterPanel.tsx` 中存在**三层渲染逻辑**，新模型必须在正确的位置添加渲染分支：

1. **第一层**：特殊模型独立渲染（如 `vidu-q1`）
2. **第二层**：通用视频/图片参数块（第 98-501 行左右）
3. **第三层**：其他独立模型渲染（如 `kling-2.6-pro`、`wan-2.6`）

## 常见错误

### 错误 1：只添加了渲染分支，未排除通用参数块

```typescript
// ❌ 错误：新模型会进入通用参数块，但里面没有对应逻辑
if (currentModel?.type === 'video' &&
    selectedModel !== 'vidu-q1' &&
    selectedModel !== 'kling-2.6-pro') {  // 缺少新模型排除
  return (
    <>
      {/* 通用视频参数 */}
    </>
  )
}

// 新模型渲染分支（永远不会执行到）
if (selectedModel === 'new-model') {
  return <SchemaForm ... />
}
```

### 错误 2：渲染分支放在了被排除的代码块内

```typescript
// ❌ 错误：新模型被排除后，内部的渲染逻辑永远不会执行
if (currentModel?.type === 'video' && selectedModel !== 'new-model') {
  return (
    <>
      {selectedModel === 'new-model' && (  // 永远不会执行
        <SchemaForm ... />
      )}
    </>
  )
}
```

## 解决方法

### 步骤 1：确定渲染位置

根据模型特点选择合适的位置：

- **独立渲染**：参数结构特殊，需要完全独立的渲染逻辑
  - 位置：在通用参数块**之前**或**之后**
  - 示例：`vidu-q1`、`kling-2.6-pro`、`wan-2.6`

- **通用参数块内**：可以复用通用参数（负面提示、随机种子等）
  - 位置：在通用参数块**内部**添加条件分支
  - 示例：`minimax-hailuo-2.3`、`pixverse-v4.5`

### 步骤 2：添加排除条件

如果选择独立渲染，必须在通用参数块的条件中排除新模型：

```typescript
// ✅ 正确：在通用参数块条件中排除新模型
if (currentModel?.type === 'video' &&
    selectedModel !== 'vidu-q1' &&
    selectedModel !== 'new-model' &&  // 添加排除
    selectedModel !== 'kling-2.6-pro') {
  return (
    <>
      {/* 通用视频参数 */}
    </>
  )
}

// 新模型独立渲染分支
if (selectedModel === 'new-model') {
  return (
    <SchemaForm
      schema={newModelParams}
      values={{ /* ... */ }}
      onChange={onChange}
    />
  )
}
```

### 步骤 3：排除不需要的通用参数

如果新模型不需要负面提示或随机种子，需要在对应的排除列表中添加：

```typescript
// 排除负面提示（约第 408 行）
{selectedModel !== 'minimax-hailuo-2.3' &&
  selectedModel !== 'new-model' &&  // 添加排除
  selectedModel !== 'wan-2.5-preview' && (
    <TextInput label="负面提示" ... />
  )}

// 排除随机种子（约第 455 行）
{selectedModel !== 'kling-2.5-turbo' &&
  selectedModel !== 'new-model' &&  // 添加排除
  selectedModel !== 'pixverse-v4.5' && (
    <NumberInput label="随机种子" ... />
  )}
```

## 快速检查清单

适配新模型时，检查 `ParameterPanel.tsx` 的以下位置：

- [ ] **第 98 行左右**：通用视频参数块条件 - 是否排除了新模型？
- [ ] **第 408 行左右**：负面提示排除列表 - 是否需要排除新模型？
- [ ] **第 455 行左右**：随机种子排除列表 - 是否需要排除新模型？
- [ ] **适当位置**：是否添加了新模型的渲染分支？

## 调试技巧

如果参数不显示，按以下顺序排查：

1. **检查条件判断**：在浏览器控制台打印 `selectedModel` 值，确认模型 ID 正确
2. **检查排除列表**：搜索 `selectedModel !==`，确认新模型在所有必要的排除列表中
3. **检查渲染分支**：确认渲染分支的条件判断能够匹配到新模型
4. **检查 Schema 导入**：确认参数 Schema 已正确导入到 `ParameterPanel.tsx`
