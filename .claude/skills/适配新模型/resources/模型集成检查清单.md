### 2. 供应商特有差异 (路由实现关键)

在实现 **步骤 7 (模型路由)** 时，请根据供应商套用以下模式：

#### PPIO (派欧云)
*   **路由文件**: `src/adapters/ppio/models/{model-id}.ts`
*   **图片处理**: 路由收到 `params.images` 已是 **Base64**。直接用。
*   **视频处理**: 路由收到 `params.video` 已是 **公开 URL** (Adapter 已自动上传)。直接用。
*   **端点**: 异步任务必须以 `/async/` 开头。

```typescript
// PPIO 视频处理范例
buildVideoRequest: async (params) => {
  // params.video 已经是上传好的 URL，直接传给 API
  return { endpoint: '/async/xxx', requestData: { video: params.video } }
}
```

#### Fal
*   **路由文件**: `src/adapters/fal/models/{model-id}.ts`
*   **图片/视频**: 路由收到 `params.images`/`params.videos` 已是 **Fal CDN URL**。直接用。
*   **ID**: `modelId` 不含子路径 (如 `/edit`)，`submitPath` 可含子路径。
*   **禁忌**: **禁止**传 `'smart'`/`'auto'` 给 API。

```typescript
// Fal 图片/视频处理范例
buildImageRequest: (params) => {
  // params.images 已经是 CDN URL
  return { 
    submitPath: 'fal-ai/xxx', 
    modelId: 'fal-ai/xxx', 
    requestData: { image_url: params.images[0] } // 直接赋值
  }
}
```

#### KIE
*   **路由文件**: `src/adapters/kie/models/{model-id}.ts`
*   **图片/视频**: 路由收到 `params.images`/`params.video` 已是 **KIE CDN URL**。直接用。
*   **端点**: 统一为 `/api/v1/jobs/createTask`。

### 2. OptionsBuilder 配置模板
*(OptionsBuilder 负责将 UI 参数映射给 Adapter)*
```typescript
export const {provider}{Model}Config: ModelConfig = {

  type: 'video',
  provider: '{provider}',
  paramMapping: {
    // UI 参数名 -> API 字段名

  }
}
```

### 2.1 启用视频上传功能

如果模型需要用户上传视频（如"参考生视频"、"视频编辑"、"动作控制"模式），需要：

**(A) 在 OptionsBuilder 配置中添加 `videoUpload`**

```typescript
features: {
  videoUpload: {
    enabled: true,
    maxVideos: 1,        // 最大视频数
    paramKey: 'video'    // 最终传给 Adapter 的字段名
  }
}
```

**(B) 如果视频上传与模式绑定，使用 `modeSwitch`**

```typescript
features: {
  modeSwitch: {
    modeParamKey: '{provider}{Model}Mode',
    configs: {
      'text-to-video': {
        // 文生视频模式：不需要视频
      },
      'motion-control': {
        // 动作控制模式：需要视频
        features: {
          imageUpload: { enabled: true, maxImages: 1, paramKey: 'images' },
          videoUpload: { enabled: true, maxVideos: 1, paramKey: 'video' }
        }
      }
    }
  }
}
```

**(C) 在 `customHandlers.afterBuild` 中处理视频保存**

```typescript
customHandlers: {
  afterBuild: async (options, context) => {
    const uploadedVideoFiles = (context.params as any).uploadedVideoFiles || []
    
    if (uploadedVideoFiles.length > 0) {
      const { saveUploadVideo } = await import('@/utils/save')
      const setUploadedVideoFilePaths = (context.params as any).setUploadedVideoFilePaths
      const uploadedVideoFilePaths = (context.params as any).uploadedVideoFilePaths || []
      
      // 保存视频到本地（用于历史记录）
      const paths: string[] = [...uploadedVideoFilePaths]
      if (!paths[0]) {
        const saved = await saveUploadVideo(uploadedVideoFiles[0], 'persist')
        paths[0] = saved.fullPath
      }
      
      // 传递 File 对象给 Adapter（Adapter 负责上传）
      options.video = uploadedVideoFiles[0]
      setUploadedVideoFilePaths(paths)
      options.uploadedVideoFilePaths = paths
    }
  }
}
```

### 3. PPIO 模型路由模板 (最复杂的一个)
```typescript
import { GenerateVideoParams } from '@/adapters/base/BaseAdapter'

export const {model}Route = {
  matches: (id: string) => id === '{model-id}',
  buildVideoRequest: async (params: GenerateVideoParams) => {
    // 1. 获取处理好的数据 (Adapter 层已处理 Base64/上传)
    const images = params.images || []
    const video = params.video
    
    // 2. 根据输入构建请求
    if (video) {
        // params.video 这里已经是 URL 了
        return { endpoint: '/async/xxx-ref', requestData: { video: video } }
    } else {
        return { endpoint: '/async/xxx-t2v', requestData: { prompt: params.prompt } }
    }
  }
}
```

### 5. 价格配置模板
*(添加到 `src/config/pricing.ts` 的 `pricingConfigs` 数组中)*

```typescript
{
    providerId: '{provider}',
    modelId: '{model-id}',
    currency: '¥', // 或 '$' (会自动转换)
    type: 'calculated',
    calculator: (params) => {
        // 1. 获取参数 (优先使用专用参数名)
        const duration = params.{provider}{Model}Duration || 5
        
        // 2. 计算价格
        let price = 0
        if (duration === 5) price = 0.5
        if (duration === 10) price = 1.0
        
        // 3. 返回格式化价格 (如果是美元需 * USD_TO_CNY)
        return formatPrice(price)
    }
}
```
