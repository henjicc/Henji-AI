## 第二部分：开发实施步骤

> 按照以下步骤依次进行开发。每完成一步请勾选。

### 阶段 1: 参数 Schema 定义
- **目标**: 定义模型参数结构。
- **操作**:
  - [ ] 新建 `src/models/{provider}/{model}.ts` (定义 `ParamDef[]`)
  - [ ] 修改 `src/models/index.ts` (注册到 `modelSchemaMap`)

### 阶段 2: 状态管理与类型
- **目标**: 将新参数加入 React 状态管理与 TypeScript 类型系统。
- **操作**:
  - [ ] 修改 `src/hooks/useMediaGeneratorState.ts` (添加 `useState`)
  - [ ] 修改 `src/components/MediaGenerator/builders/core/types.ts` (`BuildOptionsParams`)
  - [ ] 修改 `src/config/presetStateMapping.ts` (`PresetSetters` & map)

### 阶段 3: UI 渲染逻辑
- **目标**: 确保参数面板正确显示新模型参数，并处理通用参数的显示/隐藏。
- **操作**:
  - [ ] 修改 `src/components/MediaGenerator/components/ParameterPanel.tsx`
    - [ ] 排除通用参数干扰 (如适用)
    - [ ] 添加 `<SchemaRenderer />` 独立分支
    - [ ] 处理负面提示词/种子等通用控件可见性

### 阶段 4: 参数传递管道
- **目标**: 确保参数从 UI 状态流转到生成函数。
- **操作**:
  - [ ] 修改 `src/components/MediaGenerator/index.tsx`
    - [ ] `handleParamChange` (setterMap)
    - [ ] `createPresetSetterMap`

    - [ ] `PriceEstimate` props

### 阶段 5: OptionsBuilder 配置
- **目标**: 配置 UI 参数到 API 参数的映射规则。
- **操作**:
  - [ ] 新建 `src/components/MediaGenerator/builders/configs/{provider}-models.ts` (如文件已存在则修改)
    - [ ] 配置 `paramMapping`
    - [ ] 配置 `features` (smartMatch, uploads, etc.)
  - [ ] 修改 `src/components/MediaGenerator/builders/configs/index.ts` (注册配置)

### 阶段 6: 适配器路由实现
- **目标**: 实现 API 请求构建逻辑。
- **操作**:
  - [ ] 新建/修改 `src/adapters/{provider}/models/{model}.ts`

    - [ ] 实现 `buildRequest` 逻辑 (处理 API 特有格式)
  - [ ] 修改 `src/adapters/{provider}/models/index.ts` (注册路由)
