# 适配新模型

按照指定步骤给痕迹 AI 适配新的模型

## 什么时候使用这个技能

- 当用户要求适配新模型的时候

## 如何使用这个技能

严格按照以下步骤一步步执行。
如果用户要求其中的具体某一步骤，直接执行该步骤。
常见问题部分只有在用户明确要求时才需要执行。
在需要停下来与用户沟通的地方，必须停下来与用户沟通！
禁止在未与用户确认时执行后续步骤！

### 生成配置文件
1. 分析当前项目代码、用户提供的 API 文档与信息以及 /resources/配置模板.yaml
2. 与用户确认疑问点以及所有需要确认的关键信息，如果有需要补充的信息，一并告知用户
3. 按顺序输出配置文件的关键部分
    - 模型显示名称
    - 模型功能
    - 显示的参数
    ```yaml
    序号: 
        参数名: 
        参数类型: 
    ```
    - 隐藏的参数，输出格式
    ```yaml
    序号: 
        参数名:
        是否传递: 
    ```
4. 依据 /resources/配置模板.yaml，正式生成 yaml 文件，按照“供应商_模型显示名称.yaml”命名，放在 /resources/配置文件 目录下

### 制定开发计划
1. 依据用户提供的 API 文档，判断模型供应商：
    - 如果是 fal，从以下路径下找到对应的适配指南
    resources/适配指南/ai-guide-fal.md
    - 如果是 kie，从以下路径下找到对应的适配指南
    resources/适配指南/ai-guide-kie.md
    - 如果是派欧云 PPIO，从以下路径下找到对应的适配指南
    resources/适配指南/ai-guide-ppio.md
    - 如果未找到对应的适配指南，停下来询问用户要怎么做
2. 结合用户提供的 API 文档、上一步生成的 yaml 文件以及对应供应商的模型适配指南，按照 resources/新模型适配开发计划模板.md 以及 resources/分辨率面板设计规则.md ，制定一个详细的开发计划

### 编写代码
1. 根据开发计划，一步步编写代码

### 检查代码
1. 依据 /resources/检查清单.md 逐一检查代码
2. 一一列举出存在的问题
3. 按顺序修复所有的问题
4. 重复步骤 1-3，直到所有检查项都符合要求

### 常见问题
请依据用户提到的问题，查阅合适的文档进行修复，修复时需要结合实际情况

1. 如果用户提到 模型的参数显示不正确，不该显示的参数显示了，改显示的参数没有显示，或者看不到任何参数，请参考 resources/常见问题/参数面板不显示问题.md
2. 如果用户提到 运行时报错 "param.hidden is not a function"，参数 hidden 属性配置错误，质量参数需要隐藏但不知道如何正确设置，条件隐藏参数的正确写法，请参考 resources/常见问题/hidden属性类型错误.md
3. 如果用户提到 分辨率面板显示混乱有问题，比例和质量档位分离显示，质量选择器不显示，分辨率参数命名不规范，不符合统一的设计模式，请参考 resources/常见问题/分辨率面板显示问题.md
