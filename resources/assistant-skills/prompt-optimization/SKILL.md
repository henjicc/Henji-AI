# 提示词优化

把用户目标转成可执行描述。优化不是扩写；保留明确风格、数量、动作、文字及修改范围。要求原文提交时不改写。

## 选择本次需要的内容

通过 `load_assistant_skill` 的 `name: prompt-optimization` 和 `path` 读取下列文件。按当前动作选择，不按所在页面选择；通常只需一份。不是必读清单，不跟随链接展开全部文件。已在上下文中完整存在的内容直接复用。

| 当前任务 | 读取 |
| --- | --- |
| 从零生图或普通参考生图 | [图片基础](references/image.md) |
| 替换、添加、删除图片内容 | [图片编辑](references/image-edit.md) |
| 三视图、人物设定或系列组图 | [角色与组图](references/character-sheet.md) |
| 有真实蒙版、标记或点框定位 | [图像定位](references/image-location.md) |
| 单段视频或让图片动起来 | [视频基础](references/video.md) |
| 多种素材分别控制动作、外观或声音 | [视频参考绑定](references/video-reference.md) |
| 跨镜头保持人物、道具与方向 | [视频连续性](references/video-continuity.md) |
| 修改已有视频 | [视频编辑](references/video-edit.md) |
| 延长或连接已有片段 | [视频延续](references/video-extension.md) |
| 任务涉及对白、声音或字幕 | [声音与文字](references/video-sound.md) |

只有当前问题涉及多个独立维度时才加读对应模块，不自动补读基础课。完整制作也逐阶段读取，不开头全量加载。

## 执行边界

- 只写提示词不生成；执行生成使用现有工具，保留消息原项目和落点。
- 使用当前默认模型或用户明确指定模型，能力、参数及价格查询正式工具，不从技能猜测。不额外调用优化模型。
- 参考素材使用真实引用并核对用途与顺序；画布、历史、编辑预览不必先收藏。没有看过素材就不杜撰内容。
- 所有指南按功能适用于模型，不绑定品牌。技能不授予工具权限，不改变费用设置。
