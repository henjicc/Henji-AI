# 提示词优化

把用户的目标转成适合当前生成模型执行的描述。优化不等于扩写：简短输入补齐关键事实，完整输入主要消除冲突与重复。用户要求原文提交时保留原文。

## 按需读取

使用 `load_assistant_skill`，`name` 为 `prompt-optimization`，`path` 为以下相对路径，并简述 `reason`。先判断任务再读；不要一次加载全部文件。

- 图片生成、参考生图、组图或图片编辑：读取 [图片指南](references/image.md)。
- 视频生成、编辑、延长或连接：读取 [视频指南](references/video.md)。
- 选定 Seedream 且涉及组图、标记或坐标编辑时，再读取 [Seedream 补充](references/seedream.md)。
- 选定 Seedance 且涉及多模态参考、声音或视频编辑时，再读取 [Seedance 补充](references/seedance.md)。

已加载的适用指南仍在上下文中时直接复用；换任务类型或内容已被压缩掉时再读取。

## 共用原则

1. 先分清从零生成、参考生成、编辑、延续，以及用户要“写提示词”还是“执行生成”。只写提示词不提交生成。
2. 保留明确主体、数量、身份、关键动作、风格、文字、语言、画幅和编辑范围。合理补足次要信息，不自行增加故事、角色或强风格。必要且无法推断的关键歧义才询问。
3. 模型未指定时走当前默认模型选型；读取所选模型实际能力与参数。技能不提供价格、数量上限或 API 参数的另一份真相。不能因为指南提到 Seedream/Seedance 就改用它们。
4. 参考素材先确认真实业务引用及用途；历史结果、画布节点、编辑预览不必先收藏。提示词中的图号和素材顺序须对应实际提交输入。业务 ID、文件路径不是生成模型能理解的素材标签；没有看过素材就不能杜撰画面内容。
5. 单一素材直接描述；复杂任务用少量稳定特征定义角色或对象，每个参考关系单独一行。说明各素材用于身份、服装、构图、动作或音色；正文持续使用一致称呼。模型要求的引用标记仍须保留，不能机械删除。
6. 抽象意图转成可见或可听事实：情绪落到表情动作，质感落到材质光线。不要用质量口号、无关摄影参数或大量负面词代替具体描述。写实不是默认强制风格，也不强制美化、加动作、加旁白或背景音乐。
7. 生成任务沿现有工具准备、提交、跟踪并验证，保留当前消息的项目与落点。不要额外调用一次优化模型、自动多生成几张或更改费用设置。供应商自带提示词优化选项与本技能不同，遵循当前设置及工具 schema。

## 输出前检查

核对用户约束、素材对应、编辑保持项、图片瞬间或视频时序、模型兼容性及冲突。只写提示词时默认输出可直接使用的正文；用户要求解释时可解释。执行生成时把正文交给正式工具，聊天中简洁报告实际进展，不把技能的“只输出正文”当作整个助手的回复规则。
