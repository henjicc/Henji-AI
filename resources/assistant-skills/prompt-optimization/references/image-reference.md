# 参考生图（单图或多图）

参考图提供素材，提示词决定新画面。先写清每张图取什么，再写要生成的画面。

## 写法

1. **逐张绑定**：`@图片1` 提供人物身份，`@图片2` 提供服装，`@图片3` 提供光影与色调。只取部分时写明取哪一部分（如“只参考 @图片2 的外套款式，不参考其颜色”）。
2. **再写新画面**：按文生图的骨架写主体在做什么、在哪、什么风格。参考图已经说明的外观不必再逐项复述，只补参考图里没有的内容。
3. **融合关系说清楚**：多图合成写成一句明确的动作，如“让 @图片1 的女孩穿上 @图片2 的连衣裙，站在 @图片3 的海边栈道上”。不要笼统地写“融合所有图片”。

## 要点

- 风格参考只借风格（笔触、色调、质感），不把风格图里的人物、物件一起复制进来；需要时写“不沿用 @图片N 的画面内容”。
- 同一角色在多张图里统一称呼，外观冲突时说明以哪张为准。
- 参考图尽量清晰、主体完整；参考图分辨率不必高于输出。
- 参考图数量和总张数受模型限制，以 schema 为准。
