# 图片编辑：最小必要修改

先说编辑哪张图、改什么，再说保持什么。描述的是变化，不是把整张图重新写一遍。

## 写法

`编辑 @图片1：<改动>。保持 <不变的部分> 不变，<新内容如何融入原图>。`

- **替换**：写清旧东西和新东西（“把黑色皮夹克换成浅灰色羊毛大衣”），新对象要适配原图的透视、遮挡、阴影和材质。
- **添加**：写清位置、大小、朝向和与周围的接触关系（“在桌面右侧放一只白瓷咖啡杯，杯口朝上，投影与桌上其他物件一致”）。
- **删除**：指出要去掉的东西，并要求自然补全被遮挡的背景。这是改画面内容，不是删除软件里的素材或节点。
- **改风格、材质、色调、视角**：说明从什么变到什么，以及保持构图、人物姿势等。
- **跨图编辑**：“把 @图片1 的服装换成 @图片2 的服装”，两张图各自的角色写清楚。

## 要点

- 保持项要具体：面部、发型、姿势、构图、背景、光线，按任务挑关键的写，不写一长串。
- 一次只改一两处；改动多时分几次编辑，每次读回结果再继续。
- 局部修改要用真实的蒙版、标记或坐标（见标记与坐标定位），不凭空编位置。
- 改画幅比例属于扩图，用扩图能力，不靠提示词让模型自己补画面。

例：编辑 @图片1：把人物的黑色外套换成浅灰色羊毛大衣。保持面部、发型、姿势、构图和背景不变，大衣褶皱顺着原来的姿势，光线和阴影与原图一致。
