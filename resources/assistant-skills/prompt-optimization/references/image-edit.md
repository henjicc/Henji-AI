## 编辑：最小必要修改

先说明编辑哪张图、改什么，再说明需要保持什么。细节用于约束改动，不能无意义重做整图。

- 替换：区分旧特征与新特征，明确身份、姿态、背景等保持项；新对象适配透视、遮挡、阴影与材质。
- 添加：交代位置、尺度、方向和接触关系。
- 删除：指出目标并自然补全被遮挡背景；这是图像内容编辑，不意味着删除应用中的素材或节点。
- 局部修改：使用真实蒙版、标记或定位信息，不能凭空编坐标。图像坐标不能拿画布节点位置代替。模型不支持对应定位方式时走可用编辑工具，不宣称精确区域控制已经实现。

例：将图片1人物的黑色外套改为浅灰色羊毛大衣。保持面部、发型、姿势、构图及背景不变，大衣褶皱与原姿势、光线和遮挡自然匹配。

这个例子只展示变化项与保持项的关系，不把服装、颜色等内容套入其他任务。
