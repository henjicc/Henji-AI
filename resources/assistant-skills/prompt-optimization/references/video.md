# 文生视频

视频写的是随时间发生的变化。用导演的思路写：**谁在哪里、发生了什么、镜头怎么拍、听到什么**。核心公式是 **主体 + 运动，背景 + 运动，镜头 + 运动**：每样东西都写它怎么动。

文生视频随机性大，适合探索和找灵感。用户对画面已有明确预期时，建议先生成满意的图片，再用首帧生视频（见首帧与首尾帧）。

## 结构

按需取用，短视频一两句也可以：

1. **一句话概述**：主体 + 地点 + 事件 + 风格（+ 特殊运镜）。
2. **情节**：一个连续事件写成连贯的一段。确有镜头切换或节奏变化时，按“镜头1、镜头2”或时间段（`0-3秒`、`3-8秒`）切开，每段写画面内容、动作、运镜，有声音时一起写。
3. **贯穿细节**（可选）：全程不变的机位风格、环境、光线、声音氛围放在最后统一交代。

例：写实纪录片风格，森林斜坡上，一只圆滚滚的熊猫幼崽从坡顶滚下来。0-3秒，幼崽趴在坡顶，顺着斜坡慢慢滚落，压弯沿途的小草；3-8秒，滚到坡底停下，仰面躺着，抬起一只前爪晃了晃，又翻身趴好。低机位，轻微手持感，镜头跟着幼崽缓慢下移，前景树叶微微虚化。温暖午后阳光透过树冠，林间有鸟鸣和草叶摩擦声。

## 时间与镜头

- 时间段要连续（`0-3秒…3-7秒…7-15秒`），不要跳着写。每段内容与时长相称：太少模型会自己发挥，太多会被剪碎或丢情节。
- 不用时间控制频率（如“一秒摇头三次”）。
- 精确时间点和相对时间都可以写：“第5秒快速向左横移转场”“按下快门后画面定格1秒”。模型对逐秒的响应程度不同，不承诺逐秒精确；有的模型只认“镜头1、镜头2”。
- 一个镜头通常一种主要运镜，不同时写推近又拉远。

## 镜头语言

- 景别（大全景、全景、中景、近景、特写）、运镜（推、拉、摇、移、跟、环绕、升降、手持）、机位（低角度、俯拍、第一人称）直接写。
- 常见手法直接写：一镜到底、航拍、FPV、希区柯克变焦、子弹时间。
- 小众术语写成“名词 + 描述”：“移焦，焦点从前景的树枝平滑转到背景的人物，前景逐渐虚化”。
- 转场写清时间点和方式：“第5秒向左擦除并自然叠化到室内”。

## 动作与表情

- 动作优先概括（“连续做了几组高抬腿和空翻”），只给少数有记忆点的动作写细节；不重复写同一个动作。保留用户要的奔跑、跳跃、打斗，不为稳定改成慢走。
- 动作需要时补方向、幅度、速度、力度，以及起始和结束状态。
- 表情写具体可见的样子，不用成语：“津津有味”写成“脸上带着满足的笑，大口吃饭”。
- 情绪用常规描述，过激的词（狂热、极度震惊）容易让模型做出眼睛发光之类的特效；需要时注明“人物眼睛正常、不发光”。
