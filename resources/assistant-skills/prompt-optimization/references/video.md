# 视频生成、编辑与延续

视频表达状态随时间的变化。先确定任务类型、主体、开始状态和结束目标，再写动作与镜头。时长、声音生成、首尾帧及参考输入能力以所选模型为准。

## 生成与参考

- 一个连续事件用连贯段落，不强制分镜。确有镜头切换时才按“镜头1、镜头2”组织，镜头数量与实际时长和动作复杂度匹配。
- 每个镜头写必要的机位/主要运镜、主体动作、空间变化和衔接。一个镜头通常一种主要运镜，避免同时向前推近又向后拉远等冲突。
- 动作按需要补部位、方向、幅度、速度、力度，以及起始、过渡和结束。保留用户要求的奔跑、跳跃、打斗；不要为了稳定性把动作一律改成慢走或微动。
- 按“开始、随后、最后”表达顺序；用户需要精确时序时保留，但不承诺模型逐秒精确执行。不要给普通短视频机械加时间码。
- 用少量外在动作表现情绪，不把每种情绪都写成一串表情清单。
- 参考素材明确用途：身份、场景、动作、运镜、风格、音色或节奏。多素材同一角色使用统一称呼，不混合相互矛盾的外观。图生视频应从输入图的可见状态自然发展。

例：以参考图中的人物为主角，从原图姿态开始。人物将杯子轻放到桌面，短暂停顿后转头望向窗外。镜头固定中景，保留原有服装、室内布局与窗侧光，动作前后自然衔接。
