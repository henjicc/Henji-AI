# 商品展示

先判断要的是白底图、使用场景、材质特写还是广告主视觉。有真实产品图时用 `@图片1` 固定产品的结构、比例、材质和标识，背景与道具不能改变产品本身。

- 构图让关键卖点可见（接口、纹理、刻字），主体占画面主要位置。
- 反光材质写光源方向和软硬；透明物体保留边缘和透光；接触面保留自然阴影。
- 不给所有产品机械加镜面地板、漂浮零件或金光。
- 只换背景时写“保留产品及其边缘不变，只替换背景为……”。
- 系列图保持产品身份、颜色和视觉语言，只换场景或角度。张数和画幅用参数设置。

例：以 @图片1 的保温杯为主体，放在晨光里的木质桌面上，旁边一本摊开的书和一片绿叶。保持杯身颜色、logo 和比例不变，柔和侧光在金属杯身上形成一道细长高光，杯底有自然投影。浅景深，写实产品摄影。
