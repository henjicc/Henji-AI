# 图片生成与编辑

图片表达一个视觉状态或冻结的瞬间。按需要组织“主体与状态 → 环境和空间关系 → 构图 → 光线材质 → 风格与文字”，不是每张图都必须填满这些项。

## 从零或参考生成

- 简单目标用短段落。只在影响结果时补主体数量、位置、尺度、视线、姿态、前后遮挡与画面重点。
- 动作图明确冻结的阶段、接触关系与重心，不把一张图片写成先后发生的长剧情。产品、建筑、海报和静物不强制增加动作。
- 写清有来源的光与关键材质；风格服从用户意图。不要强制固定色数、负空间比例、混合技法或“电影感”。纪实画面保留合理生活痕迹，不擅自磨皮、棚拍化。
- 参考图只取指定维度：如身份来自一图、服装来自另一图。不要含糊要求“融合全部图片”，也不要把风格参考变成复制全部内容。
- 文字任务保留文字原文、大小写和语言，必要时说明位置与层级。用户要文字、标志或字幕时，不能追加互相冲突的“禁止任何文字”。

## 编辑：最小必要修改

先说明编辑哪张图、改什么，再说明需要保持什么。细节用于约束改动，不能无意义重做整图。

- 替换：区分旧特征与新特征，明确身份、姿态、背景等保持项；新对象适配透视、遮挡、阴影与材质。
- 添加：交代位置、尺度、方向和接触关系。
- 删除：指出目标并自然补全被遮挡背景；这是图像内容编辑，不意味着删除应用中的素材或节点。
- 局部修改：使用真实蒙版、标记或定位信息，不能凭空编坐标。图像坐标不能拿画布节点位置代替。模型不支持对应定位方式时走可用编辑工具，不宣称精确区域控制已经实现。

例：将图片1人物的黑色外套改为浅灰色羊毛大衣。保持面部、发型、姿势、构图及背景不变，大衣褶皱与原姿势、光线和遮挡自然匹配。

这个例子只展示变化项与保持项的关系，不把服装、颜色等内容套入其他任务。

## 组图与角色设定

先分清“同一张图内多个视角/分格”与“多张独立输出”，不能把三视图默认变成三次请求。统一身份、比例、服装、道具、风格，再分别说明各视图或各张输出的变化。

连续画面可先固定角色参考，再描述每幅情节。系列数量与多图输出能力以当前模型及用户要求为准；模型不支持时说明可行方案，不静默增加任务。

## 标记和坐标定位

具备对应定位功能的图片模型均可使用。标记应实际存在于提交图片中；区分原图、标记图与参考图的用途，说明结果是否需要去掉辅助标记。

定位信息始终绑定到具体图片。保留用户或正式工具提供的有效坐标；换算由已有定位工具根据图片实际区域、缩放及裁剪处理，不能用屏幕位置或画布节点坐标猜测图像区域。

例如，支持点框标签的模型可使用 `<point>x y</point>` 或 `<bbox>x1 y1 x2 y2</bbox>` 表达位置；采用 0–999 归一化坐标的接口应限制到该范围。标签格式和坐标范围必须匹配当前模型，不把例子当成所有模型的固定协议。

点定位不等于严格蒙版。需要像素级保留区域外内容时，结合正式蒙版或合成工作流，不能仅凭提示词承诺精确保持。

多图输出要使用模型实际支持的输出参数，写“生成多张”不能代替参数设置。模型端自带的提示词优化模式沿用当前设置，不自动追加字段或切换模式。

## 自检

主体和数量是否正确？参考用途是否清楚？修改是否越界？画面空间是否成立？文字是否准确？删除重复和不改变画面的形容词。指南的段落结构不是最终提示词必须遵守的模板。
