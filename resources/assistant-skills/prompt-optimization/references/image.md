# 文生图

一张图是一个冻结的瞬间。骨架是 **主体 + 行为/状态 + 环境**，对画面有要求时再补 **风格、色彩、光影、构图**。不是每张图都要填满这些项。

## 写法

1. **主体**：是谁或什么、数量、关键外观（年龄感、服装、材质、颜色）。多个主体写清各自位置、大小关系和前后遮挡。
2. **行为或状态**：此刻在做什么，冻结在哪个阶段（如“刚把杯子放到桌上”），姿态、视线、接触关系。不把一张图写成先后发生的剧情。静物、建筑、海报不强加动作。
3. **环境**：地点、时间、天气、周围的关键物件。
4. **美学**（按需）：画风或媒介（写实摄影、水彩、3D 渲染、扁平插画）、色调、光源方向与软硬、景别与机位（特写、俯拍、中画幅、浅景深）。用户已定的风格照搬，不擅自加“电影感”。

## 要点

- 具体胜过堆形容词：“侧逆光勾出发丝轮廓”比“光影绝美”有用。删除重复和不改变画面的词。
- 重要内容放前面；约 300 字以内，超了先删次要细节。
- 纪实、生活类画面保留合理的生活痕迹，不擅自磨皮或棚拍化。
- 要文字时写出原文，用引号标出，说明位置与层级（详见文字海报）。要文字时不要另加“画面不要任何文字”。

例：清晨的老街早点铺，一位六十多岁的师傅正把一笼刚出锅的包子端到柜台上，蒸汽扑在他的眼镜上。木质柜台上摆着竹蒸笼和一碗豆浆，背景是排队的两三位顾客，略微虚化。暖色晨光从左侧门口斜射进来，写实摄影，中景，平视。
