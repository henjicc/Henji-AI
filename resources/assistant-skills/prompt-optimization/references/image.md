# 图片生成与编辑

图片表达一个视觉状态或冻结的瞬间。按需要组织“主体与状态 → 环境和空间关系 → 构图 → 光线材质 → 风格与文字”，不是每张图都必须填满这些项。

## 从零或参考生成

- 简单目标用短段落。只在影响结果时补主体数量、位置、尺度、视线、姿态、前后遮挡与画面重点。
- 动作图明确冻结的阶段、接触关系与重心，不把一张图片写成先后发生的长剧情。产品、建筑、海报和静物不强制增加动作。
- 写清有来源的光与关键材质；风格服从用户意图。不要强制固定色数、负空间比例、混合技法或“电影感”。纪实画面保留合理生活痕迹，不擅自磨皮、棚拍化。
- 参考图只取指定维度：如身份来自一图、服装来自另一图。不要含糊要求“融合全部图片”，也不要把风格参考变成复制全部内容。
- 文字任务保留文字原文、大小写和语言，必要时说明位置与层级。用户要文字、标志或字幕时，不能追加互相冲突的“禁止任何文字”。

## 自检

主体和数量是否正确？参考用途是否清楚？修改是否越界？画面空间是否成立？文字是否准确？删除重复和不改变画面的形容词。指南的段落结构不是最终提示词必须遵守的模板。
