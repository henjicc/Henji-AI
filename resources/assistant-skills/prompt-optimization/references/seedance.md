# Seedance 补充

本文件提炼用户提供的 Seedance 2.0 多模态提示词指南。应用所选版本与渠道的实际能力优先；不要假设所有 Seedance 模型均支持视频编辑、延长、混合参考或音频生成。

## 区分任务

- 多模态参考：从素材提取明确维度来生成新视频，例如角色外观、动作、运镜或音色。
- 编辑视频：明确编辑哪段原视频，改变什么及保持什么。
- 延长：明确向前还是向后，描述边界承接与新增内容。
- 混合任务：例如用图片中的服装编辑原视频，分别说明参考源和被编辑对象，不能含糊写“参考所有素材”。

## 素材绑定

用两三个稳定特征识别主体，再给一致称呼；同一角色的多张图统一绑定。模型收到的“图片1/视频1/音频1”等称呼必须与实际输入顺序或正式参考标签一致，不能拿素材库 ID 替代。

已定义角色后主要使用角色称呼，必要时保留目标模型要求的素材标记。教程中的 @、括号和标签是组织提示的示例，不是跨渠道通用协议；不得凭空假设它们会自动上传或绑定文件。

## 动作与声音

动作给出可理解的起点、变化和终点，复杂动作补充惯性、支撑与接触关系。明确要求的快速动作保留；每个镜头集中一种主要运镜，不靠堆叠运镜术语增加表现力。

对话说明谁说什么、使用何种语言与语气。区分音色参考与台词参考，必要时写明“不继承参考音频的原台词”。音乐、音效、字幕各自说明时机和作用，只有当前模型支持时才请求；不强制套用教程里特定括号形式。

镜头顺序通常比机械时间切片更清楚。总时长仍由参数控制；提示词中的时间描述不保证逐帧精确。用户需要严格剪辑节奏时，应结合软件现有编辑能力，而不是承诺单次生成必然达到。
