# Seedream 补充

本文件提炼用户提供的 Seedream 系列、5.0 pro 与交互编辑教程。属于提示词经验，不是各版本或各供应商的能力承诺；输入类型、输出数量、参数与可用编辑方式以当前应用模型 schema 为准。

## 简洁描述与组图

优先用自然语言写清主体、行为、环境及必要美学。教程建议短而集中的表达；不把字数建议当硬上限，不为缩短而删除关键文字或编辑约束。

多图融合逐图指明用途。组图先说明是多张输出还是单张分格，统一角色、场景和风格，再说明每幅差异。模型的多图输出模式由正式参数控制，写“生成多张”不能代替参数设置。

## 标记和坐标编辑

只有目标版本与当前调用方式确实支持时使用。标记必须实际存在于提交图片中；有原始图、标记图和参考图时明确每张的用途，并说明辅助标记是否需要从结果移除。

教程中的定位语法为 `<point>x y</point>` 和 `<bbox>x1 y1 x2 y2</bbox>`，点或框坐标范围为 0–999。例：修改图1 `<bbox>120 180 640 760</bbox>` 中的对象，保持区域外内容不变。示例数值不能用于真实任务。

保留用户或正式工具提供的有效坐标与图片绑定关系。需要换算时应由已有定位工具根据实际图片区域、缩放与裁剪处理，并限制到有效范围；不能用屏幕位置或画布节点坐标猜测图像区域。点定位不等于严格蒙版，模型生成不保证像素级区域外完全不变；需要精确保持时使用正式蒙版/合成工作流。

## 供应商提示词优化

教程中的 standard/fast 是特定模型端选项，与本技能的文本整理不同。不要自动追加 API 字段或切换模式；沿用当前参数，仅在用户要求且工具支持时调整。
