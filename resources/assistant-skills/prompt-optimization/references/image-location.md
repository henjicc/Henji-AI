# 标记与坐标定位

适用于支持“在图上标记位置”或“坐标定位”的图片模型，以 schema 和模型说明为准。

## 标记方式

在待编辑图上用涂鸦、圈选、箭头或草图标出区域，提示词用自然语言指向这些标记：

“按图上的手绘标记编辑：在左下角圈出的区域放一叠杂志，在右侧箭头指向处放一杯带杯碟的咖啡。去掉所有标记线条，保持构图不变，新物体自然融入原场景。”

- 标记必须真的画在提交的图上；分清原图、标记图和参考图各自的用途。
- 结尾写明去掉辅助标记，否则线条可能留在结果里。

## 坐标方式

支持坐标标签的模型可以用点或框指定位置，如 `<point>x y</point>`、`<bbox>x1 y1 x2 y2</bbox>`。标签写法和坐标范围（常见为 0–999 归一化）必须与当前模型一致，不把例子当成所有模型的固定协议。

- 坐标始终绑定到具体图片，可以跨图：“把 @图片1 中 `<bbox>…</bbox>` 的主体放到 @图片2 的 `<bbox>…</bbox>` 位置”。
- 坐标来自用户或正式定位工具，按图片实际区域换算；不用屏幕位置或画布节点坐标去猜。

## 边界

点和框不等于像素级蒙版。要求区域外严格不变时，结合正式蒙版或合成流程，不能只凭提示词承诺。模型自带的提示词优化模式沿用当前设置，不自动切换。
