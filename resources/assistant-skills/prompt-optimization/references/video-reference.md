# 参考生视频（多素材）

图片、视频、音频分别提供外观、动作、运镜、风格或声音，模型据此生成新视频。素材越多，**绑定关系越重要**。

## 结构

1. **素材绑定**（放在最前）：逐个写清每个素材是谁、提供什么。人多时列清单。
   - “@图片1 是主角林夏，@图片2 是她的搭档老周；@音频1 是林夏的音色。”
   - “@图片1、@图片2 是人物一的正面和侧面，对应 @音频1；@图片3 是人物二，对应 @音频2。”
2. **一句话概述**：发生了什么、在哪、什么风格。
3. **情节**：按镜头或时间段写动作、运镜、台词（写法同文生视频）。
4. **贯穿细节**：机位风格、光线、声音氛围。

## 写清“参考什么”

- 部分参考要点明维度：“参考 @视频1 中施法的动作，@视频2 的环绕运镜”“参考 @图片3 的光影和色调”。
- 风格或运镜参考写明不沿用其画面内容，避免把参考视频里的人和场景搬过来。
- 参考素材本身已经足够精确时，只做指代，不再复述细节：“严格按 @视频1 的动作和运镜顺序”，不必再写“先抬手、再转身……”。

## 要点

- 编号按传入或连线顺序，按人物**首次出场顺序**排列素材最不容易错位。
- 对应关系写在提示词里，不要只写在图片上（在角色图上写名字、提示词里直接用名字，容易混淆或重复角色）。
- 同一角色全篇用同一个称呼，不混用相互矛盾的外观。
- 主体越多越不稳定：一般 1–5 个主体效果较好；多视角最好拆成几张单视角图。
- 一次同时做多项参考和编辑效果不稳定，拆成几步完成。
- 素材数量、时长上限和是否支持音频单独参考以 schema 为准；含真人人脸的素材可能被模型拒绝。
