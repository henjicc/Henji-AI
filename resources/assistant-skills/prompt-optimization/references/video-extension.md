# 延长与连接

## 延长

写明方向（向前或向后）和新增的内容，并承接边界处的姿势、动作惯性、视线、机位、光线和环境声。

例：向后延长 @视频1，女孩把伞收起，抬头看向放晴的天空，镜头保持原来的平视中景缓缓上摇，雨声渐渐停下，传来远处的鸟叫。

- 可以同时引入新角色或参考：“向后延长 @视频1，@图片1 的角色从天而降落在女孩身边”。
- 输出画幅跟随原视频；延长段时长由参数决定。

## 连接两段视频

按“前一段结束 → 过渡动作或画面 → 后一段开始”组织，说明过渡方式（自然衔接、镜头穿过某物、叠化）。

## 要点

- 写之前要知道边界处的画面；没看过原片就先取得可用信息，不杜撰。
- 想延续另一个模型的画面风格时，用延长而不是重新生成，风格保持得更好。
