# 文字海报

文字原文、语言和大小写一字不改，用引号标出。先定层级：主标题、副标题、补充信息、品牌标识各在哪里、多大。

例：竖版音乐节海报，上方大号粗体主标题“夏夜回声”，下方一行小字“2026.08.16 · 江边草坪”，右下角放 @图片1 的 logo。背景是黄昏的江面和远处的舞台灯光，标题区域留出干净的天空。

- 字多时分组、留白、拉开字号层级，背景和装饰不挤占正文。
- 修改已有海报只写替换哪段文字，以及要保持的字体、颜色和布局。字数变化大时允许必要重排。
- 文字容易写错：越短越稳。必须准确的长文字或标识，优先做成图片作为参考，或交给软件的可编辑文字与合成能力，不承诺生成模型百分百拼写正确。
- 检查文字需要实际看结果；看不了图时说明没有核对文字，不把生成成功当成排版通过。
