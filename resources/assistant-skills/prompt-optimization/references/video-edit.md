# 视频编辑

在原视频上增、删、改画面或声音，其余保持。写清**改哪里、从什么改成什么、什么时间段、哪些不变**。

## 写法

- 指令编辑：“把 @视频1 中 4-6 秒男人喝咖啡的动作改成拖地，其余内容不变。”
- 参考图编辑：“把 @视频1 右侧的女生换成 @图片1 中的女生，保留原动作、走位、运镜和原声。”
- 声音编辑：“只修改 @视频1 中男人的台词为‘你别过来啊’，口音改为东北口音，画面不变。”“去掉 @视频1 的背景音乐，保留环境音和对白。”
- 有多段视频时写明哪一段是被编辑的原视频，哪些只是参考。

## 要点

- 编辑任务的输出画幅和时长一般跟随原视频，参数可能被锁定；时长可能有零点几秒误差，以 schema 和结果为准。
- 不要靠编辑去改画幅比例：模型会为新画幅补画面，内容和时序容易走样。要换画幅时改用参考生视频，并逐镜头写清原有内容和时序。
- 一次编辑只做一两处改动；改动多或同时涉及参考与编辑时拆成几步。
- 当前模型不支持视频编辑时说明情况，不把全新生成说成原片编辑。
