# 镜头设计

先找本段故事发生了什么变化：观众获得信息、人物作出选择、关系改变或情绪得到回应。以这一变化决定镜头，不为凑数量切镜。

每镜记录：故事职责、可见起点、主要动作、终点、景别与机位、必要运镜、声音和预期时长。已有参考和上游决定只引用，不重新设计。

- 建立镜头交代空间；特写用于需要被看清的动作、反应或线索。不要把所有信息都压进远景。
- 机位、焦距和景深服务于信息与关系；无需机械填写镜头毫米数。固定镜头也是有效选择。
- 一个镜头优先一种主要运镜，动作复杂时减少无关运镜。时长根据动作和对白估算，再核对模型实际范围；不把某个模型的固定秒数当成通则。
- 竖屏重新安排主体和纵深，不能把横屏方案默认居中裁切。
- 输入已经是单一连续动作时，不强制拆成建立、中景、特写三次生成。

例：发现桌上的信 → 看清信封上的名字 → 人物停下伸出的手。三个信息节拍可以用一个推近镜头完成，也可根据叙事需要切镜；节拍数不等于生成请求数。
