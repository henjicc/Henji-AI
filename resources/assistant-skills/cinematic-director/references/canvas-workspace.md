# 画布制作工作区

用于制作、落地分镜或保存可编辑工程。仅解释、评价或改写提示词时直接回答，不创建项目；分镜设计不等于授权生成媒体。

用户明确指定的项目优先，否则继续发送任务时所在的画布项目。没有这两种目标时，新建画布项目并打开，让用户看到制作变化。不要挪用后台残留项目，也不在每轮重复创建。创建成功但打开失败时，恢复打开原项目，不再次创建。后续操作绑定该项目；必须去其他界面处理时才临时进入，结果仍关联回来。

先读取已有节点摘要和位置，沿现有布局追加，不重排无关内容。新工程按以下约定组织，当前阶段需要多少就建立多少：

- 上方放简要说明及共享角色、场景参考；原剧本已有就引用，不复制全文。
- 场景从上到下分区，每个镜头占一行；从左到右放镜头文本、参考素材、生成节点和结果。按节点实际尺寸留间距，用通用位置属性调整，避免覆盖。
- 名称如“场景01 · 镜头02 · 转头”。镜头文本记录动作、起终状态、相关对象的稳定引用及用途，不把所有信息塞进名称。
- 图片、视频、音频复用现有节点和正式生成流程。生成工具已经建立的结果节点不重复创建；素材不必先收藏。

连线必须符合端口输入用途。文本连到文本会同步正文，不能用它表示角色归属或镜头顺序；这些创作关系记录在镜头说明。场景分区用空间与文本标题表达，不虚构分组或时间线功能。

保存后回读目标内容、位置和引用。局部修改只动相关镜头。画布包含可编辑素材不等于视频已剪辑合成。
