# 局部返修诊断

先读取用户指出的结果、对应输入和任务状态。网络、余额、参数失败走软件错误恢复，不归因于画风或导演方案。

| 现象 | 检查与最小调整 |
| --- | --- |
| 像幻灯片 | 是否有明确主体动作、环境响应和结束状态；不靠堆“电影感”修复 |
| 人物/衣服漂移 | 参考是否绑定正确、是否混入冲突外观；优先修引用和保持项 |
| 动作或持物跳变 | 起终状态、接触过程是否完整；简化无关同时动作 |
| 镜头看不懂 | 是否遗漏关键反应或线索；必要时补一个有职责的镜头 |
| 风格不符 | 以用户描述和参考为准，只调整光线材质/线条等相关维度 |

只修实际失败的镜头或区域；保留满意部分。需要生成时沿现有工具准备、提交和等待，不盲目重跑全片，不把重试次数当成质量保证。

不能观察成片时，说明依据来自用户反馈或静帧，不能声称声音、运动、口型全部检查通过。修复后更新工程采用的素材引用，并核对直接受影响的衔接。
