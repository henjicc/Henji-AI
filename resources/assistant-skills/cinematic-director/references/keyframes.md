# 关键帧

首帧是动作尚未完成时的一个瞬间。先确定这一帧看见哪些人物、道具、位置与接触关系，再绑定真实参考。不能把镜头终点才出现的动作写进首帧。

尾帧仅在模型支持且结束状态需要控制时制作；简单动作不要无条件多生成一张。首尾之间必须存在可完成的动作路径，不能只追求两张图各自漂亮。

每张参考注明控制维度：身份、服装、场景、构图或风格。角色多视图只是身份依据，不能让拼版人物变成镜头中多个角色。历史结果、画布素材及编辑预览直接引用，不要求先收藏。

模型无法观察输入图片时，使用已知设定并明确观察缺口，不能声称已经核对脸、手或文字。生成成功和画面符合设定是不同结论。

把已采用的关键帧与相应视频节点关联；同一镜头修改参考后，检查视频配置是否仍指向旧图。生成参数从工具读取，不在本指南复制字段名。
