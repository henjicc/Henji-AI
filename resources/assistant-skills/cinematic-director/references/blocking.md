# 走位与表演

把“紧张、强势、犹豫”转成能看见的行为：距离改变、视线回避、手停住、身体挡住出口。不要把所有情绪写成夸张表情。

多角色先确定位置、面向、视线、出入口、遮挡及关键道具，再写起点 → 路径/动作 → 终点。只有会影响结果的关系需要记录，不为简单动作建立整张空间图。

接触动作描述接近、接触和结果：谁把什么交给谁、哪只手接住、物件最后在哪。需要真实物理衔接时，不用“瞬间出现在手中”掩盖缺失动作。

机位选择应保留必要接触与反应。反打时核对人物屏幕方向和视线，不无理由跨越动作轴线；确需越轴，用可读的运动或中性机位建立新方位。

例：甲在门口挡住乙，乙先看向出口，再侧身绕过甲。写清门、双方和相机的关系，比反复写“气氛紧张”更能控制画面。
