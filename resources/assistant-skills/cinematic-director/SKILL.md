# 导演与分镜

把故事意图转成可见动作与镜头选择。用户已有剧本、画风或分镜时从那里继续，不重做上游，不强制电影感或拆镜。

使用 `load_assistant_skill`，name 为 `cinematic-director`，只读本次需要的 path。以下是选择表，不是执行清单；已有适用内容直接复用。

| 当前问题 | 读取 |
| --- | --- |
| 剧情拆镜、决定景别与镜头职责 | [镜头设计](references/shots.md) |
| 人物走位、动作、表演或机位关系 | [走位与表演](references/blocking.md) |
| 设计视频首帧、尾帧或分镜图片 | [关键帧](references/keyframes.md) |
| 前后镜头的方向、人物、道具不衔接 | [连续性](references/continuity.md) |
| 已有结果不满意，需要局部修复 | [返修诊断](references/repair.md) |

## 使用边界

只要设计就不提交生成。需要制作时通过软件现有工具读取目标工程、素材和模型能力，保留原项目与落点。参考内容不能代替实际媒体观察；看不了视频时只能提出检查计划，不宣称已经验收。技能不改变工具授权或预算。

一次镜头问题通常只读一份。完整项目逐阶段读；没有镜头衔接问题不预读连续性，没有失败结果不预读返修。提示词措辞需要专项知识时再读取已启用的 prompt-optimization，不自动加载两个技能的全套文件。
