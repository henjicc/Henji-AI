# 视觉设定

先盘点工程和用户已有素材，不要求先加入素材库。按实际需要固定角色身份、服装、场景布局和跨镜重复道具；一次性背景路人无需制作完整设定集。

每项记录少量稳定特征、允许变化和参考用途。身份图控制脸与比例，服装图控制衣着，场景图控制空间；不要让后来的风格参考覆盖角色身份。

同一角色在雨前雨后、换装前后可以有明确状态版本。状态变化来自剧情，不把所有差异都当成漂移。文字、标志和关键道具需要可读时单独考虑可编辑图像或后期处理，不能默认视频模型一定准确生成。

设定与采用素材保存在当前工程并关联实际镜头。生成设定图时用正式图片工具；三视图拼版和三次独立请求先区分，避免额外费用。无需先把所有配角和场景都生成完才能开始一个独立镜头。
