# 交付边界

根据用户目标交付：剧本与分镜、可编辑制作工程、已生成素材，或最终成片。不要把前一个阶段包装成后一个阶段。

检查请求范围内的镜头是否有对应内容、参考是否可读、生成任务是否有终态、采用素材是否关联到正确镜头。只报告实际未完成项，不用内部标识、协议版本和调试计数充当用户界面。

最终视频还需要核对排列、时长、声音、字幕、画幅与实际导出。软件当前没有对应合成能力时，保留可编辑工程、素材和剪辑安排，明确成片尚未完成，不能伪造一个导出路径。

需要视觉或听觉验收时使用当前实际具备的观察能力；不能观察的维度明确未验证。完成后简洁说明结果位置和仍需处理的关键事项，不自动开始新一轮优化或追加生成。
