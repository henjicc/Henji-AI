# 工程与素材生产

读取消息原项目和相关选中对象，用户指定目标优先；不要因为当前切换了页面就把任务投到其他工程。没有合适工程时通过正式项目能力建立目标，不猜项目标识。

复用画布项目、文本内容、生成节点和连线表达剧本、设定、镜头及依赖。先通过通用实体发现读取实际可写属性和节点类型，再用现有操作写入并回读；不要把自然语言计划声称为已保存工程。

每镜只准备实际需要的参考，按身份、构图、首尾帧等用途绑定。参考来自画布、历史或预览时直接使用稳定引用，不额外收藏。标准生成任务通过现有生成入口创建可见节点与参考连线，查询当前模型参数后提交；不要直接调用供应商。

独立镜头可在现有并发和费用范围内执行。依赖前镜终点的镜头等待对应素材后再准备，不能把未生成的占位对象当成有效参考。

提交后使用正式等待工具等待终态，不短间隔轮询模型、不重复提交。失败先区分未提交、已提交待恢复和生成失败；依据任务返回的恢复信息处理。成功后核对结果引用及原工程落点；有文件不等于画面质量已经验收。
