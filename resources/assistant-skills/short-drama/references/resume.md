# 续做与局部依赖

重新读取工程当前状态，聊天历史仅作线索。先列出相关场景、镜头和素材摘要，再读取待继续镜头及其直接依赖；不要整份剧本、所有设定、所有历史结果一起读取。

检查实际参考连线，以及镜头说明中记录的对象引用；不要把文本节点之间的输入连线当作普通依赖线。准备写入时先打开明确目标工程，再回读待修改内容；保持其他工程不变。

区分计划、已创建节点、任务进行中、生成成功、用户采用和已导出。生成成功由任务与结果证明，采用由用户决定或其授权范围内的实际选择记录证明，导出由真实导出结果证明。

修改某个角色服装或镜头结尾时，查找使用这一参考或状态的直接下游镜头。先标明需要检查的范围；如果变化确实传到更后镜头，再沿依赖继续检查。无关镜头不重新生成。

局部返修保留满意素材和旧结果，更新实际采用引用，回读保存状态。中断后先恢复原任务或读取已完成结果，不凭“对话没回复”再生成一次。项目事实保留在工程，不进入跨项目用户偏好摘要。
