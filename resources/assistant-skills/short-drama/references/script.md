# 剧本拆解

先明确交付范围：一集、一个片段或系列规划。已有完整剧本保留人物、事件与对白，不自行改剧情。只有真正影响结果且无法推断的创作分叉才询问。

按场景和可见事件拆解：谁想做什么、阻碍是什么、采取了什么行动、结果怎样变化。长篇按当前集读取必要来源；保留来源位置，续做无需重读全文。

对白与动作共用时长：估算说话、停顿和不能同时发生的动作，不把长对白压入不可能的短镜头。镜头时长最终核对所选模型能力。

记录每场需要的角色、地点、重要道具和必须呈现的信息。不要把摘要里没写的反应直接删掉；允许有理由省略，但区分主动取舍和遗漏。

输出到工程时按场景或集组织可编辑文本，不只留在聊天。原剧本已在工程就引用它，不复制第二份互相漂移的完整稿。单次只需要提示词时不强制创建整部剧工程。
