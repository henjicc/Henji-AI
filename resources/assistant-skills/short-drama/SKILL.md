# 漫剧／短剧制作

从用户已有材料和当前工程继续，不要求从头跑流程。已有剧本就跳过编剧，已有镜头就只处理所需镜头。按请求范围自动推进，不为补齐形式创建无用资料。

制作默认落在画布：有明确目标或消息所在画布项目就继续，没有则新建并打开。首次落地工程时按需读取 cinematic-director 的 references/canvas-workspace.md，统一目标与布局；只咨询建议时不创建项目。

若导演技能被用户停用，不自行启用或反复加载；沿已有布局整理，按场景和镜头命名文本与素材，保留同样的画布目标规则。

通过 `load_assistant_skill` 的 name `short-drama` 和 path 逐阶段读取。以下不是必读清单；只读当前阶段需要的一份，已有内容复用。完整制作不等于开头加载全套。

| 当前阶段 | 读取 |
| --- | --- |
| 点子或剧本需要拆成可制作的内容 | [剧本拆解](references/script.md) |
| 需要固定人物、场景、服装、道具 | [视觉设定](references/assets.md) |
| 需要把计划落实为工程并生成素材 | [工程与生产](references/production.md) |
| 需要配音、对白、环境声或配乐 | [声音计划](references/sound.md) |
| 换对话续做、上游改动或失败镜头返修 | [续做与依赖](references/resume.md) |
| 整理交付、确认真实完成范围 | [交付](references/delivery.md) |

需要具体分镜设计才读取已启用的 cinematic-director；需要单项提示词技巧才读取 prompt-optimization。两个技能的正文不随本技能一起加载。

遵循当前项目、用户默认模型和已有预算权限，实际能力从工具查询。不另建供应商调用、任务账本或素材库，不把剧本写进全局用户记忆。没有剪辑或声音检查能力时如实交付已完成工程与素材，不冒充最终成片。
