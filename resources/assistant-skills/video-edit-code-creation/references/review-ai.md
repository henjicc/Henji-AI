# AI 味：症状、原因与具体改法

与 review 的三遍看片、评分和交付自检一起用。按核心表达的影响排序；每轮只集中改最关键的一到三处，不限制工程和批注数量。

| 症状 | 改法与复查点 |
| --- | --- |
| 深渐变＋居中标题＋辉光＋漂浮粒子，没有想法 | 回 brief-concept 找能解释核心的视觉动作和母题；删掉不承担信息的装饰 |
| 开场只有标题慢慢淡入 | 第一拍给强画面：大字动势、真实产品特写或有动机的揭示；短宣传前2秒入题 |
| 产品界面凭想象重画 | 换真实截图／录屏并聚焦操作区；缺素材说明占位，不冒充官方界面 |
| 所有元素同时淡入 | 重要性错峰0.06–0.12秒，标题先、辅助后；完整阅读期从最后必要信息落定开始 |
| 每项都上移加淡入 | 按职责：标题遮罩揭示、数字滚动、图标描边生长、卡片位移；通常控制在三种主要入场语法内 |
| 全部0.5秒、同一曲线 | 按距离与主次分档，入场Out、离场In、搬运InOut；检查快慢约3:1的对比是否成立 |
| 大卡片从0缩放、持续弹跳 | 克制档从90–95%配20–60px位移与透明度，用expoOut落地；花字／促销可一次过冲，不能整屏都弹 |
| 小字漂在大片空白中央 | 放大主焦点至画幅约40–60%，锚网格边缘；留白有职责才保留 |
| 所有东西居中对称 | 用三分线、左锚与尺度对比；中心保留给单一标题、Logo或落版 |
| 纯黑＋霓虹紫蓝＋强辉光 | 带冷暖倾向的暗底、单一强调角色，光只给一个焦点；品牌指定色优先 |
| 每项都描边、投影、玻璃 | 质感只给主体或背景一个层级，其余干净；逐项删装饰比较可读性 |
| 全片呼吸、漂浮、噪声晃动 | 落地静止；最多保留一个贯穿镜头的极慢推进（100→103–105%），不逐元素乱动 |
| 到处打字机 | 仅表达输入／终端；正常标题改逐词或遮罩揭示，停留读完 |
| 一屏堆全文，正文与字幕重复 | 画面关键词与关系，全文留口播／字幕；静音版本重排信息拍，不偷偷删原文 |
| 每次转场不同、旋转翻页套预设 | 母题推出一两种语法重复；用匹配切、速度交接、覆盖擦除、必要时硬切 |
| 整组二维缩放冒充镜头推进 | 背景、主体、前景分别求位移与尺度形成视差；需要侧面厚度／遮挡时用三维镜头参考或授权AI素材，明示代码伪3D边界 |
| 玻璃仅半透明渐变板 | 先放可辨背景，再用Glass折射／模糊，边光与投影分离；检查背景确实弯折，不将Frost冰霜生成器当毛玻璃滤镜 |
| 首尾正确，中途闪字／复现 | 转场连取8–12帧，查进度端点、源码显隐与实例旧关键帧；新旧内容交接要完整覆盖 |

这些是创作诊断，不是固定禁令：综艺可以回弹、纪实可以慢镜、知识图形可以多种类别色。选择要能回答“它怎样帮助观众记住核心”，仍保证一个焦点、可读、真实素材、统一规则。
