# 没想清楚时的常见症状

与 review 的看片和交付自检一起用。下表是“随手做出来”时最常见的样子，用来诊断，不是审美禁令：同一个手法，有意为之就是风格，顺手套上就是 AI 味。

先问一句：**这是说明书或需求要的，还是我没想就用了？** 前者照做，不按本表改回去；后者再看“可以试”，从中挑适合本片的，或者自己想别的。每轮集中改最影响核心的一到三处。

| 症状（无意为之时） | 常见原因 | 可以试 |
| --- | --- | --- |
| 深渐变＋居中标题＋辉光＋粒子，看完记不住 | 没有想法，用装饰填空 | 回 brief-concept 找能解释核心的动作或比喻；粒子、辉光留下来时让它成为母题本身 |
| 开场只有标题慢慢淡入 | 第一拍没设计 | 大字动势、真实产品特写、有动机的揭示、一个声画重音 |
| 产品界面凭想象重画 | 缺素材 | 用真实截图或录屏；缺素材就标明占位 |
| 所有元素同时淡入 | 没有主次 | 按重要性错峰、换入场方式、或干脆让主焦点单独出现 |
| 每项都上移加淡入、全部 0.5 秒同一曲线 | 一种动作套到底 | 按职责给不同动作（遮罩揭示、数字滚动、描边生长、位移、缩放、形变），快慢拉开对比 |
| 小字漂在大片空白中央 | 尺度没定 | 放大焦点、锚到网格边缘，或让留白承担职责（安静、呼吸、悬念） |
| 每个画面都居中对称 | 没想构图 | 试不对称、三分、出血；对称适合仪式感、Logo、落版 |
| 每项都描边、投影、玻璃，但谁也不突出 | 质感没有层级 | 让质感分主次；繁复风格也要有一个最亮的点 |
| 阅读时字在晃、看不清 | 持续运动落在主文字上 | 主文字稳住或放慢；背景、光效、粒子照样可以一直动 |
| 打字机用在普通标题上 | 套用手法 | 打字机适合输入、终端、悬念；其他文字试逐词、遮罩或直接出现 |
| 一屏堆全文，正文与字幕重复 | 信息没分拍 | 画面放关键词与关系，全文给口播或字幕；不偷删原文 |
| 每句话推一次，推近、框选、压暗叠在同一处 | 把每句都当重点 | 事件按理由和预算重排：只在口播点名或看不清时推近，强调手段只用一种，相邻同向运镜合并（attention） |
| 缓推有明显的起步和停下 | 承载运动做成了事件 | 从镜头第一帧匀速跑到最后，入场叠在上面，接点不降到零 |
| 处处缓推、处处冲入、处处视差 | 学到一招全片套用 | 按每个镜头要观众做什么选；要读、要停顿、要落版处静止往往更好 |
| 元素各自呼吸乱晃 | 拿元素微动充当“活着” | 持续运动来自镜头缓推、漂移与图层视差；元素微动极小、极慢、彼此不同步 |
| 镜头不动，元素原地淡入、出完整屏静止等翻页 | 没有镜头与元素的配合 | 元素被运动带进来、被镜头甩出去；停下处要么有轻微运动、要么是有意静止（camera） |
| 换场先全部收走再全部出现，中间空一下 | 离场入场没有重叠 | 离场与入场重叠，背景层贯穿换场 |
| 镜头在走，纯色背景上看不出来 | 背景缺参照 | 背景加低亮度点阵、网格或纹理并分层，镜头一动就有视差 |
| 转场花样多但彼此无关 | 随手挑预设 | 统一一套语法，或者让每次变化都有节奏上的理由（混剪、综艺常常每次不同） |
| 整组二维缩放冒充镜头推进 | 没做纵深 | 分前中后景做视差；要真正侧转与遮挡时用内置 three（recipes-3d）、自写 WGSL 或三维镜头参考 |
| 玻璃只是半透明渐变板 | 背后没东西可折射 | 先放可辨的背景，再用 Glass 折射或模糊；边光与投影分开 |
| 首尾正确，中途闪字或复现 | 可见区间或进度边界错 | 转场连取 8–12 帧，查进度端点、源码显隐与实例旧关键帧 |

判断标准始终是：它是否帮观众理解或感受核心；关键信息是否读得清、读得完；素材是否真实；整体是否像同一部作品。

## 文字撑框、连续性、口播与效果

`query_video_edit_review` 的 `motion:{}` 还检查：

- `text_box_overflow`：原生 Canvas 文字或排版库墨迹超绘制矩形/自身图层 bounds，持续至少 0.3 秒；`motionEvidence.canvas` 给原文及作者画幅坐标的墨迹/框。跨层绘制矩形按几何位置关联，候选不是卡片语义；先取帧核对，再增宽卡片、缩字或换行。GPU 内部文字、无关联框、直接 Canvas 绘制仍需读图。
- `visibility_dip`：同一作者元素的外接范围可见度与透明度中途降到此前的一半以下，随后恢复到至少一半。检查 hidden/opacity、位置轨提前结束或换目标两端空窗；不根据图层名字识别高亮，不检测 draw 内部清除或其他图层遮挡。正常入场、末尾收起不报。
- `shadow_outside_source`：源图形完全在图层栅格外、用 shadowOffset 投回的风险；改成层内绘制后 blur，或扩大 bounds，详见 author-api-layers 的“Canvas 阴影的源图形范围”。它不等于已测得像素缺失。

启用 `visual:{}` 会按每段字幕的句首渲染合成帧，`narration_alignment` 逐条给出时间、原文和该时刻的片段/图层/可观察文字清单。逐页读完，不以 checkpoints 的少量抽样代替逐句核对；用返回 documentVersion 与该记录帧号调用 observe_video_edit_frame 读图，判断这句话说的主体有没有出现。工具不自动判断句意与画面相符，未看到/未遮挡不能由结构清单证明。查询从句中开始时不伪造句首。

`visual.effects` 默认 true，给已启用且 amount 非零的画面效果，在查询放置区间首/中/末帧做单变量“开→关→开”全尺寸像素比较，包括代码滤镜/WebGPU。`effect_unchanged` 是该帧无差异，可能效果未绘制、被遮挡、裁切或本帧自然为零；`effect_visible` 是有像素差异，仍要读图判是否符合预期；`effect_unstable` 是重复开启也不同，先处理确定性或输入就绪问题再查。每条都有时间和改法。

作者生成器参数没有统一的关闭值；通过 `visual.probes` 指定 `{clipRef,frame,parameter,offValue}` 比较一个数值/布尔参数。工具按真实源时钟读取当前曲线，在临时副本里设关闭值并去掉该参数曲线；不改作品和播放头。用参数声明判断 offValue，不能假设任意数值参数都能设零。重复引用同一嵌套实体时开关影响该实体全部实例。分页复用已完成证据，文件/字体/作品变化后重新查询。网页取帧是否就绪不在本检查保证内。

图层效果复核：公共取帧及元素读回中的 effects 是已成功绘制帧的真实解析参数，含 look 展开项、amount 和兼容 pose.blur；失败帧不能作为成功证据。源码检查的 suggestions 仅为 AST 静态证据，带文件行列和工厂建议；shadowBlur 不等于投影可被 blur 直接替换。检查全幅效果层是否可补 bounds。深色／浅色／彩色背景都看主体外光晕，独立下方片段只能被提亮；比较强度零、source_opacity 零、层 opacity 零、遮挡和 clip。连续参数跨外扩档位、半分辨率、旋转及推近时检查光形和噪声相位，不能只看停帧。pose.blur 的 GPU 高斯与 Canvas 旧高斯做相同像素半径 A/B，lens 另看散焦，数值测试不代替观感。
