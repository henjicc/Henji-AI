# 标准样片：分镜与样片代码

写或改风格样片（sample）时读：所有风格用同一套分镜和文案演示基础组件，方便并排比较。说明书怎么写见 style-kit。

## 分镜

新建风格默认 1920×1080、30 fps、11 秒；用户偏好里写了常用规格（如 4K60）就按偏好设（3840×2160、60 fps），最大 3840×2160、60 fps。竖屏风格对调宽高。标准分镜约 11 秒；说明书组件较多、要在标准分镜后多演示几种（推近录屏、局部放大、来源标注、对比、步骤等）时可以延长，最长 30 秒。锚点帧每段一张、最多 10 张，落在这一段完全落定、还没开始离场的停留处（数字已经停在终值、高亮已经到位），缩略图取标题那一张。

| 时段 | 基础组件 | 演示什么 | 文案 |
| --- | --- | --- | --- |
| 0–2 s | 标题 | 标题框（或替代结构）怎么搭起来、文字怎么显现、停留时的细节 | 主标题“把想法变成画面”；不加副标题和装饰英文，风格允许的小字只放日期、编号这类信息 |
| 2–3.7 s | 花字与关键词 | 提炼成短语后怎么排、重点用什么手段强调 | “风格不走样”，重点是“不走样” |
| 3.7–6.3 s | 图片与录屏容器＋高亮 | 容器怎么落位、镜头怎么推拉；容器落定后高亮指向画面里的一处 | 容器里是代码画的示意画面（如一个编辑界面或一张风景），角上标“示意画面” |
| 6.3–8.2 s | 数据 | 数字、单位与标签怎么排，数字怎么变化 | 87%，“一次通过率” |
| 8.2–9.6 s | 人名条 | 名字与职位的结构 | “痕继痕迹”，“动效设计师”（内置样片也统一用它；用户给了名字就用用户的） |
| 9.6–11 s | 收尾 | 片尾一句话怎么落版 | “一个风格，处处一致” |

运动规律（曲线、档位、错峰、换场方式）贯穿六段，照说明书的“动效”与“镜头与转场”做：相邻两段交接略有重叠（旧内容退到一半时新内容进来、版面不相撞；硬切风格用扫线、遮挡这类转场完成交接），任何一帧都不空；元素出场就带着速度，不做原地淡入上浮、清屏翻页。风格还有自己特有的组件（如知识讲解的要点卡、电商促销的卖点清单）时，写进说明书“组件”栏，不挤进标准分镜。

## 样片代码

默认导出 `{ name, kind: "generator", mode: "dynamic", params: [], motionBlur: { shutter: 180 }, layers(params, width, height, assets, info) }`（见 author-api）。不动的背景、颗粒做成没有 pose 的层；会位移缩放的元素各成一层，内容只画一次，位姿写进 `pose(t)`；计数、逐字这类内容变化在 `draw(ctx, t)` 里按 t 画。画面完全由时间决定（随机用固定种子），最底层画满不透明背景，以画面高度为单位换算尺寸（`u = height / 720`，按 4K 写坐标时用 `height / 2160`），代码与分辨率无关，换规格不改画面，文字用排版库 `layoutText`/`drawText` 排版绘制（author-text-motion），渐变两端用同一 RGB 只改透明度。
