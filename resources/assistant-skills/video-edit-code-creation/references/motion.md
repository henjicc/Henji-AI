# 运动手感与编排

先决定动作解释什么，再选曲线与时长。每帧由时间、参数和尺寸直接求出；不累计状态、不依赖播放顺序，任意取帧都应得到同一画面。

## 缓动语义

| 用途 | 速度形状 | 设计曲线例子 |
| --- | --- | --- |
| 入场、落定 | 先快后慢，末端停住 | expoOut／quartOut 强减速，cubicOut 温和 |
| 离场 | 先慢后快，干脆离开 | cubicIn／expoIn |
| 两位置间搬运 | 起止平缓，中间快 | cubicInOut／quartInOut |
| 机械持续运动 | 匀速 | linear |
| 切换内容或状态 | 保持到切点再跳变 | hold |

名称描述手感，不保证它们都是当前枚举。代码参数关键帧按 parameters-curves 的真实插值；作者语言里的 tween／keyframes 仅在当前 author-api 已公开时使用。若只有有限插值，就用合法时间表达式或已支持的关键帧组合表达相近速度，不把 expoOut 填入未声明字段。

同一动作只设一个明确的起止段。中途点若无停顿含义，不对每个点重新缓入缓出，否则会打滑。速度过冲仅用于明确的活泼档，透明度和颜色不能跟着越过有效范围。

## 时长、幅度与重叠

以下以短边 1080、30fps 为起点；秒数按真实帧率对齐整数帧，不把 29.97 当 30。离场可取入场的 60–75%，远距离动作适当延长。

| 动作 | 时长秒 | 尺度建议 |
| --- | --- | --- |
| 点亮、下划线 | 0.2–0.3 | 强调局部，不移动全部版式 |
| 标签、辅助元素 | 0.35–0.5 | 位移 20–40 |
| 标题、卡片 | 0.5–0.8 | 位移 20–80；缩放 92–96% 到 100% |
| 大位移、主体揭示 | 0.8–1.2 | 按真实路径，先保证不遮挡信息 |
| 转场 | 0.4–0.8 | 覆盖完整画幅再换内容 |
| 情绪慢移 | 2 秒以上 | 只在揭示或空间关系需要时使用 |

同组错峰可从 0.04–0.12 秒起步；逐词 2–4 帧、卡片 3–5 帧。后一个在前一个完成约 30–50% 后进入，整组揭示约 0.6 秒起步；内容多时分信息拍，不把长列表压成不可读闪动。

透明度在前 40–60% 完成，位移贯穿全程；需要缩放时与同一主进度协调。主焦点先动、幅度最大，辅助动作小且稍晚。落地后静止，重要信息读完再离场；大动作后可留至少 0.5 秒安静。第一拍可直接给信息，只有蓄力有用时才留 0.1–0.3 秒，不能强制空白开头。

## 动作之间要有关系

写“触发者→动作→被带动者”：片段条抵达后文字显现，连线抵达后数字更新，色块扫过后新内容出现。接力可在前动作完成 60–80% 时开始；这是因果接力，比一般列表错峰更晚，不混成同一规则。

同组动势保持一致；要逆向对抗必须能解释。抛物与绕行适合弧线，界面排队适合直线。分组共享进度和局部坐标，避免每个元素单独运动造成散乱；分组写法以作者接口为准。

## 转场由两镜共同完成

母题可变成覆盖色块、共同轮廓或位置匹配。用一套主转场语法贯穿，重要节点再变化，不每镜更换花样。硬切适合重音；叠化用于延续或时间流逝，可从 8–15 帧起步。

速度匹配切：前镜加速出画、后镜同方向减速落定，在快段交接；核对焦点位置与速度，不只匹配方向。覆盖转场在盖满那帧切内容。结束点前后逐帧看，防止空帧、新旧字重叠和旧元素复现。运动模糊只有正式能力支持才使用；缺少它时调整速度或改清晰转场，不能承诺模拟了真实快门。
