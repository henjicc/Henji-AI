# 运动手感与编排

先决定动作解释什么，再选曲线与时长。每帧由时间、参数和尺寸直接求出；不累计状态、不依赖播放顺序，任意取帧都应得到同一画面。

## 缓动语义

| 用途 | 速度形状 | 设计曲线例子 |
| --- | --- | --- |
| 入场、落定 | 先快后慢，末端停住 | expoOut／quartOut 强减速，cubicOut 温和 |
| 离场 | 先慢后快，干脆离开 | cubicIn／expoIn |
| 两位置间搬运 | 起止平缓，中间快 | cubicInOut／quartInOut |
| 机械持续运动 | 匀速 | linear |
| 切换内容或状态 | 保持到切点再跳变 | hold |

作者曲线以 motion.ts 的 CODE_EASE_NAMES 为准：linear；sine/quad/cubic/quart/quint/expo/circ 各有 In、Out、InOut；另有 backOut/elasticOut/bounceOut。quintOut 比 quartOut 更利落，expoInOut／quintInOut 适合戏剧性大位移，sineInOut 适合慢移。hold 不在作者曲线名中：源码定格用时间条件，实例定格按 parameters-curves 的 hold 插值。tween／keyframes 用曲线名；自定义用 cubicBezier(x1,y1,x2,y2,p) 或 easing 参数＋ease。不要把作者曲线名写进实例的 interpolation 字段。

同一动作只设一个明确的起止段。中途点若无停顿含义，不对每个点重新缓入缓出，否则会打滑。速度过冲仅用于明确的活泼档，透明度和颜色不能跟着越过有效范围。

## 时长、幅度与重叠

以下以短边 1080、30fps 为起点；秒数按真实帧率对齐整数帧，不把 29.97 当 30。离场可取入场的 60–75%，远距离动作适当延长。

| 动作 | 时长秒 | 尺度建议 |
| --- | --- | --- |
| 点亮、下划线 | 0.2–0.3 | 强调局部，不移动全部版式 |
| 标签、辅助元素 | 0.35–0.5 | 位移 20–40 |
| 标题、卡片 | 0.5–0.8 | 位移 20–80；缩放 92–96% 到 100% |
| 大位移、主体揭示 | 0.8–1.2 | 按真实路径，先保证不遮挡信息 |
| 转场 | 0.4–0.8 | 覆盖完整画幅再换内容 |
| 情绪慢移 | 2 秒以上 | 只在揭示或空间关系需要时使用 |

同组错峰从 0.04–0.12 秒起步；逐字 1–2 帧、逐词 2–4 帧、卡片 3–5 帧。错峰跨度＝最后开始时刻−最先开始时刻，建议收在 0.6 秒内；完整落定还需加单项动作时长。文字多时降低间隔或分信息拍，不把长列表压成不可读闪动。后一个在前一个完成约 30–50% 后进入，不能等每项完全落地再开始。

同一元素属性不要齐起齐停：透明度在前 40–60% 完成，位移贯穿全程；缩放晚 1–2 帧开始；可将图形 blur 从 8–20px 随位移收到 0（不是 perChar 字段）。主焦点先动、幅度最大，辅助动作小且晚 1–3 帧。落地后静止，重要信息读完再离场；大动作后留至少 0.5 秒安静。第一拍可直接给信息，只有蓄力有用时才留 0.1–0.3 秒静止，不能强制空白开头。

距离翻倍，时长可增加约 30%，不必翻倍。全片最快与最慢动作可拉开至少 3:1。尺度按短边/1080 换算：精致位移 20–80px，旋转通常不超过 10°，缩放 92–96%→100%；大卡片从 0 放大通常廉价，小点／贴纸或花字才适合。活泼档过冲 3–8% 后一次回落，回落 6–10 帧；花字档可更强。需要力量感才在大动作前反向移 2–5%，用 2–4 帧蓄力。跟随用同一运动函数在 t−1～3帧求值，不能调用延迟表达式或读取上一帧。

阅读期不让所有元素呼吸、漂浮或噪声抖动。需要生命感时只给整镜极慢推进 100%→103–105%，贯穿镜头，用 linear 或 sineInOut；完全静止也是有效选择。

## 动作之间要有关系

写“触发者→动作→被带动者”：片段条抵达后文字显现，连线抵达后数字更新，色块扫过后新内容出现。接力可在前动作完成 60–80% 时开始；这是因果接力，比一般列表错峰更晚，不混成同一规则。

同组动势保持一致；要逆向对抗必须能解释。抛物与绕行适合弧线，界面排队适合直线。分组共享进度和局部坐标，避免每个元素单独运动造成散乱；分组写法以作者接口为准。

错峰形状按语义选：阅读顺序用于文字／列表；焦点向外扩散用于点击或揭示，延迟可按到焦点距离归一化再乘 0.6 秒；无序粒子／碎片才用 random(i) 固定种子错峰。不能用帧号作随机种子，让寻帧改变编排。弧线用 x/y 的 sin/cos 或二次插值直接求出，不虚构空间切线接口。

镜头运动要跟焦点或揭示下一信息；同一镜头通常只选推、拉、平移之一。前后景分别移动形成视差，不能整体缩放冒充三维（见 recipes-3d）。

## 转场由两镜共同完成

母题可变成覆盖色块、共同轮廓或位置匹配。用一套主转场语法贯穿，重要节点再变化，不每镜更换花样。硬切适合重音；叠化用于延续或时间流逝，可从 8–15 帧起步。

速度匹配切：前镜用 expoIn／cubicIn 加速出画，后镜 expoOut 减速落定，在快段同方向交接；核对焦点位置与速度，不只匹配方向。匹配切也可接共同形状、颜色、位置。覆盖色块 expoInOut 扫满，在盖满那帧切内容再同向扫出。缩放穿越可从 100%→400% 配模糊，下一镜从 60–80% 落定，须检查读字与边缘。旋转、立方体、翻页预设只有概念需要才用；从母题推出一两种转场语法反复使用。

## 拖影与核对

一帧位移超过约 20px（1080p）时检查是否过于生硬。作者接口没有运动模糊开关、快门角度或自动跨帧积累：图形 blur 只是空间柔化。沿运动方向的拖影优先用内置 effect:directional_blur（direction 为度，length 0–100，30 约为画高 3%）；用 video_edit.effect.frame_curves 在快段增强、落地归零，参数键不等于像素。

需精确局部拖影可在代码滤镜用 average 与多个 sample／sampleOffset 沿方向取样，或 shaderFilter 的 LinearBlur；生成器可 repeat 少量半透明副本，分别在略早时刻求位置再叠加。它们都不是物理快门；增加采样／绘制成本，静字不必糊，先试一帧。没有合适方案就缩短快段或改清晰切换，不编造 shutter 字段。

改实例曲线前先回读全部旧键与源码：新增首尾不会自动删除中间旧键，可能亮→灭→亮。只替换本次范围并保留其他曲线。按 timeline-check 的源时间映射，在开始、30%、60%、落地取帧；因果接力处逐帧看是否空拍、双停或两个独立动作抢焦点。真实速度与声音未看／听过时不宣称已通过动态验收。
