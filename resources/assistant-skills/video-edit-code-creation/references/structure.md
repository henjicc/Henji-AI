# 结构、节拍与声画

用于多段代码画面、讲解或与既有视频叠加。先粗排完整信息，再精修局部；结构错了，精致动画也不能救回理解。

## 能量曲线

按段记录 1–5 的创作能量：运动量、信息压力和声音强度的综合。用于规划，不是软件状态或品质评分。先命名节奏，如“快揭示→慢解释→短对比→静结论”，再决定具体时长。

| 段落 | 职责 | 粗排起点 |
| --- | --- | --- |
| 钩子 | 核心问题或最有力画面 | 短宣传前 2 秒内，能量 4–5 |
| 铺垫 | 解释观众为何在意 | 总时长约 20–30%，能量 2–3 |
| 推进 | 展开证据、步骤或变化 | 约 30–40%，能量 3–4 |
| 高潮 | 最关键变化／结论 | 约 10–20%，能量 5 |
| 收尾 | 让信息落定 | 至少 1.5 秒清楚停留，能量 1–2 |

比例是起点，不必凑满五段。只有一个标题条时保留进入、阅读、离开即可。教程以说清楚为先，纪实允许长静镜；不能为了“每 2–4 秒变化”给静段加无用动作。短宣传可每 2–4 秒检查是否有新的信息或焦点，超过时标明阅读／情绪停留的理由。

高潮前减小运动量或留短停顿形成对比；快慢动作可从约 3:1 的时长差试起。所有镜头等长、所有动作 0.5 秒都会抹平层级，但不能用夸张变速挤掉用户信息。

## 节拍表

在当前对话记录，必要时沿已发现的正式标记属性保存到序列；不另建工程状态文档。

| 时间范围 | 焦点 | 观众得到什么 | 入场／停留／交接 | 声音 |
| --- | --- | --- | --- | --- |
| 0–2 秒 | 散开的片段条排齐 | 从混乱到有序 | 0.6 秒接力；标题稳定后阅读 | 已有重音对齐排齐的那帧 |
| 2–5 秒 | 一个配置模块 | 原来只需一步 | 模块展开，文字最后到；读完再切 | 配音说到时出现 |

每拍只讲一件事，揭示顺序就是阅读顺序。下一拍焦点尽量承接上一拍位置，跨屏移动要用动作引导。秒数用于设计，落位时换成真实序列帧；代码局部时钟、源时钟和序列时钟按 timeline-check／parameters-curves 核对，尤其修剪、移位和变速后。

## 信息变画面

| 信息类型 | 形式 | 动作职责 |
| --- | --- | --- |
| 定义 | 比喻物件＋关键词 | 先建立对象，再出现名字 |
| 对比 | 同尺度分屏或前后对照 | 高亮同一属性的变化 |
| 步骤 | 编号模块、节点连线 | 完成上一步再引出下一步 |
| 数量／增长 | 大数字、条形、折线 | 同一基线与尺度，落定显示真实数据 |
| 层级 | 嵌套块或树状图 | 从整体到局部展开 |
| 历程 | 时间轴 | 当前节点成为焦点，其余退后 |
| 因果 | 箭头或连锁动作 | 动作确实从原因传到结果 |
| 软件操作 | 真实录屏／截图 | 聚焦真实按钮与变化，不画假界面 |
| 结论 | 金句或短强调 | 核心词先被看到，其余解释后到 |

画面用关键词和关系补足声音，不和字幕重复整段正文。数字与关系必须有来源，不能为了“科技感”捏造读数。静音观看时，核心仍应靠可见文字与变化说清。

## 声画协作与粗排

先读已有音频与文字时刻，把动作落地对齐真实重读词或节拍；未分析或未听过时只能写计划，不声称逐拍同步。音乐、音效、人声分别保留可编辑内容，不能把所有声音混成不可改文件。人声优先，音乐退后；不因画面创作自动生成配音、加音乐或调用付费接口。

先用色块、真实关键词与简单起止动作粗排全段，取 program 帧从头检查信息顺序、阅读时间和高潮位置。骨架成立后才细化字体、曲线与质感。剪辑单段时保留邻段和音轨，检查入口、出口、字幕与声音直接依赖；不用修一个标题的理由重排整条时间线。

## 调度与落点细查

第二项在第一项完成30–50%时开始；因果接力可到60–80%，不要混用。读字期从最后必要文字完全可见开始：中文每字约0.25秒＋0.5秒、至少1.2秒，再按难度／语速修正。信息拍超过4秒可以是刻意的阅读或情绪静止，在节拍表说明理由。

方向有语义：从左到右可表示时间／前进，从下向上可表示增长。同组力向统一；跳到另一侧前用连线、主体移动或构图交接带视线。背景、主体、前景三层速度分开，近景更快；不堆无用途前景装饰。

讲解细节：定义先物件后关键词；对比双方同属性同高度／同尺度；步骤一次一卡、连线抵达再点亮；条形从共同基线长出，数字落点对齐真实数据；时间轴节点多则分段或平移；录屏放大操作区，框选真实按钮、其余压暗，不用整屏缩图。

节拍表把入场、停留、退场分别写出，重音对齐落地帧而非起始帧。按语义选短click／hit、转场whoosh、高潮前riser或半拍静默；没有素材／生成授权只写计划。配音、音效、音乐分轨可独立调整，音轨号按当前序列读取，不照搬固定A2/A3。结构小样先看拖、乱、高潮，再细化，不为单镜精致牺牲整片顺序。
