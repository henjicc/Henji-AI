# 色彩与质感

用于定颜色角色、控制背景和焦点的分寸。这里设计的是作品，不修改痕迹AI界面主题；颜色的作者表达与取值范围按当前 author-api，不复制其他软件的色彩设置。

## 先定角色，再选颜色

先确定背景、主文字、辅助文字、强调色；需要类别或正负含义时再加语义色。每种颜色必须能解释职责。默认背景／主体／强调的面积可从 60／30／10 起步，不必精确量面积；目的是让强调有稀缺性，而非整屏都在强调。

品牌色和用户指定颜色优先，不能为套档位把浅色片改成深色片。统一角色映射：同一强调色始终代表当前焦点，同一类别色始终代表同一类别；动画中也不随机换色。

## 明度、饱和度与可读性

- 无品牌约束时，避免大面积纯黑和刺眼纯白：暗底保留少量冷暖倾向，亮底可带纸色。以归一化 RGB 为设计起点，暗中性通道约 0.04–0.10，亮中性约 0.92–0.97；不是固定配方，按真实帧调。
- 大面积低饱和，强调处较高饱和；高饱和大底只有在促销或综艺语义明确时使用。
- 正文与实际背景对比度以 4.5:1、大字以 3:1 为初步目标。这是可读性参考，不能凭声明的颜色证明压缩后清楚；复杂底图要取最不利区域检查。
- 辅助文字“退一档”不是调到看不见：先改字号、字重或位置，再轻降明度。不能只靠颜色区分对比双方，要加文字标签或位置。

对比计算可按 sRGB 相对亮度：通道 c≤0.04045 时 c/12.92，否则 ((c＋0.055)/1.055)^2.4；L＝0.2126R＋0.7152G＋0.0722B；比值＝(较亮L＋0.05)/(较暗L＋0.05)。这是检查算法，不是作者函数；没有计算能力时做实际缩小帧审查并说明未量化。

## 渐变与颗粒

剪辑片段的全能调色使用效果引用 effect:color_grade，参数通过 `video_edit.effect.parameters` 通用读写（整体替换，局部调整时先读取并合并保留其余参数），不编写另一个代码滤镜模拟它。基本校正可先调用 `analyze_video_edit_color` 返回建议，再按当前参数合并或参考匹配的完整结果写入；LUT 只使用 `video_edit.document.color_luts` 中的文档引用。

HSL 辅助在同一效果里选中颜色范围再局部校正：hsl_hue_start/end 为 0–360°，起点大于终点可跨红色 0°；肤色可从 15–50°、饱和度 20–85%、亮度 15–85% 起步，天空参考 190–250°，红色参考 340–20°。饱和度和亮度区间的起点必须不大于终点，选区按三者联合求交；柔和度先用 5–20，依据实际帧微调。先开启 hsl_show_mask 观察灰度选区（白选中、黑未选中），反向用 hsl_invert；检查后关闭显示蒙版，否则导出也会显示蒙版。hsl_denoise/blur 为 0–100 的画面比例强度，0 关闭。hsl_temperature/tint/contrast/saturation 为 -100–100，hsl_sharpen/grade_strength 为 0–100，色轮还可写 hsl_grade_hue 与 hsl_grade_luminance，校正默认中性。数值关键帧沿 `video_edit.effect.frame_curves`，显示蒙版不设关键帧；所有调整可读回并撤销。

先试纯色或局部明暗层次。要渐变时优先同色相／邻近色，起止明度差可从 5–12% 试，避免无语义的紫蓝霓虹底。大片低对比渐变容易在编码后出现色带；不能只看预览就宣称导出无色带。

需要颗粒时从低强度单色纹理起步，约1–3%（深渐变可试2–4%）视觉变化，检查小字和肤色。可用FilmGrain／内置颗粒，按video_edit.builtin_effect查实际参数单位，不把视觉百分比当组件strength。确定性纹理固定种子，不依赖上一帧或实时随机数；不用密集碎图形代替成熟颗粒效果。

## 投影、辉光与边缘

以短边 1080 为参照：

| 手段 | 起步尺度 | 为什么与检查 |
| --- | --- | --- |
| 柔投影 | 透明度 20–30%；距离 8–16，柔化 24–48 | 同一光向，避免黑糊边；暗底可改亮度层次 |
| 硬投影 | 距离约字号 0.08 倍 | 仅花字等明确风格，不能把正文也立体化 |
| 辉光 | 只围绕当前焦点，覆盖不侵入邻近文字 | 以能读出字形为准，不用泛白代替冲击 |
| 卡片边缘 | 圆角 16–32，线宽 2–4 | 同类统一，缩小后细线仍可见 |
| 暗角 | 边缘视觉压暗约 10–15% | 只为聚焦，不压死产品或人脸 |

数值按尺寸换算，核对真实单位。作者图形已有shadow/glow/blur；shader本身不接受这三项，可放group上。片段用effect:glow_pro／高斯模糊等；不能把半透明色块称为真实玻璃，玻璃路线见recipes-glass-lines。质感只承担一两个明确角色，移除后仍读得懂。

交付检查主停留帧、小屏帧、最复杂底图与快速运动帧；用户要求编码输出时再核对实际输出的颜色和色带。未导出时只报告合成帧检查，不能宣称最终编码质量通过。

## 常用组合的分寸

阴影可试透明度20–35%、柔化30–60px、距离8–20px，暗底看不见就用亮度／描边分层；背景局部虚化10–40px起试，不能把主体也糊。轻暗角压暗约10–20%；辉光高阈值、适度半径、只给一个焦点，强度量纲按具体效果，不把“≤1”强塞给0–100控件。

渐变用linearGradient／radialGradient，邻近色相明度差5–12%；柔光晕可用低透明度径向渐变ellipse／shader，放主体后、背景前，透明度约12–20%。采样边界要留余量，若出现硬切边，扩画幅／调整clip与效果范围后试帧；不搬其他宿主“形状模糊必裁边”的结论。本项目输出颜色与着色器线性混合沿正式渲染链，不虚构workingSpace／线性化开关；品牌RGB准确与最终编码仍需真实像素核对。
