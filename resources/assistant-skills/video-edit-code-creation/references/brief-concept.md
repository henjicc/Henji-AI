# 简报与概念

用于从一句需求找到可见的想法，或拆解用户参考。已有方向时只补真正缺的决定，不重新提案。

## 简报五问

| 问什么 | 落成什么决定 | 为什么 |
| --- | --- | --- |
| 给谁看、在哪看 | 观众、横竖屏、观看距离、是否静音 | 决定字号、安全区与开场速度 |
| 看完记住哪一句 | 一句核心，尽量在 20 字内 | 每个镜头必须帮助观众理解它 |
| 要什么感觉 | 2–3 个词，转换成风格坐标 | “高级”本身不能指导排版 |
| 必须出现什么 | 原文、产品、标志、数据与真实素材引用 | 防止漂亮却漏掉信息或虚构事实 |
| 不要什么 | 用户明确排除的颜色、动作与内容 | 在样张阶段就排除错误方向 |

结合目标序列读回画幅、帧率、落点和可用时长。用户没指定的低风险项自行定并简短说明；仅对会改变做法的缺口提问，例如交付是透明标题条还是完整片头。品牌宣传先盘点真实标志和界面素材；缺素材可提出占位方案，必须标明占位，不能靠代码重画假产品界面。

简报留在当前对话，不默认另建文档。开工先读相关共享记忆；当前指令、品牌约束、长期偏好、技能默认值按此顺序处理。

## 概念＝视觉想法＋母题

视觉想法是“用一个动作或比喻解释核心”，母题是反复出现、承担不同职责的形状或运动。母题至少能解释开场、推进／转场、结尾怎样关联；不要把重复贴一个标志当作概念。

| 核心 | 可见想法 | 母题与推进 |
| --- | --- | --- |
| 从杂乱到有序 | 散开的片段条逐步对齐 | 片段条开场错位、讲解时排队、结尾组成完整时间线 |
| 三步完成配置 | 三块模块依次扣合 | 同一连接口从空缺到闭合，最后显出完整系统 |
| 数据同步 | 数值沿连线传到另一端 | 连线连接真实对象，抵达后更新数字；不画无目的光束 |

先用一句话解释母题的作用，再决定形状、运动方向与转场。解释不通就换概念，不用粒子、辉光、漂浮卡片填补。代码图形是表达手段；涉及真实三维、复杂纹理或未公开语法时先查当前能力，不承诺靠受限语言实现任意效果。

## 方向与对标

出 1–3 个方向；明确品牌或参考时一个即可。每个方向三行：想法与母题；风格坐标及关键版式；参考来源、实现风险与取舍。差异应在比喻、构图或材质上，不能只是换三种颜色。

选方向看：核心是否清楚、是否摆脱惯性模板、已有素材与正式能力是否足够、阅读与动作能否在要求时长内完成。不要把短片塞满卖点；宁可提议减少信息或延长停留，也不静默删用户文案。

参考拆成可观察的特征：主体占幅、对齐锚点、字体粗细、色彩角色、动作起止与接缝。用户参考素材按 source 目标取帧并读图；落入作品后按 program 目标核对。没有真正看过参考就标明依据来自用户描述，不虚构品牌规则或镜头细节。

## 先做关键画面

选全片最重要的停留画面，用真实文案和素材完成静态版式；在原目标允许的范围内制作，不擅自新建无关工程。取帧读图后给用户看，并用一句话解释概念与取舍，等待方向确认。用户已明确“不用停”时自行选定继续。

选定后用 3–6 行固定视觉方向：概念与母题；五轴与主风格；颜色角色；已查询字体；主动作、时长与错峰；禁止项。后续每拍对照这些决定；小改只检查受影响项。
