# 取帧、批注与交付审查

编译验证运行，回读验证状态，读图验证画面。结论限定于看过的范围，抽帧不能代替播放与听感。

## 三遍看

1. 整体：沿节拍取帧看信息顺序、拖沓、高潮；可从 0.25–0.5 秒间隔起步，长片按段分批，不截掉后段。没有连续播放证据时称为“节奏抽样”。
2. 可读：每拍主停留帧在小屏尺寸读图，核对焦点、原文、背景遮挡、安全区、阅读时长。
3. 细节：转场、快动作和换字处逐帧看，检查空帧、闪烁、重叠、跳出和落地漂移。

## 本项目取帧

用 `observe_video_edit_frame`，documentRef 从正式结果取得：

| 目标 | target 形状 | 用途 |
| --- | --- | --- |
| program | `{kind:"program", sequenceRef, frame}` | 序列整数帧，检查叠层、字幕与转场 |
| source | `{kind:"source", itemRef, timeUs}` | 源素材整数微秒，盘点参考／原素材 |

maxWidth 为 256–3840，默认 1920；整体可用 960，小屏用 360–720，细节用目标原宽或允许的最大宽。它不是联系表总宽，不虚构 region、times 或批量取帧参数。大于可取宽度的原件不能声称已原分辨率核验。

resultRef 交给 `read_application_media`，续读到 eof 并看图；引用不算视觉证据。取帧不改变播放头。记录目标、时间、宽度与改动，避免误用旧帧；期间状态变化就重读受影响段。

单动作取开始、30%、60%、落地、停留中、离场前；接缝从前一帧开始连续取 8–12 帧，30fps 每次 frame＋1。秒数按真实帧率换算；N 帧的末帧是 N−1，不能取终点黑帧当缺陷。循环并排看末帧与第 0 帧。source 的 timeUs 不能直接当序列秒数，修剪／变速后查实际映射。

## 批注与 A/B

每条写：目标片段／时间或帧｜问题｜对观众的影响｜具体改法｜复查点。

例：标题／2.3 秒｜副标题抢先出现｜视线分裂｜延后 4 帧、幅度减半｜复查进场到落地。

每轮先修最影响理解的 1–3 处，再看邻接缝，不限制批注总量。批注留当前对话；写进应用前发现正式标注／标记的可写字段，不猜工具或格式，不把正文塞进素材名字。

A/B 在同文案、同背景、同画幅、同语义时刻取帧，比较尺度、可读性和概念。改前先保留实际参数／版本引用；不要为比较删除旧素材。结构不同就按落地时刻对齐，不能只取同秒数。选一版写出依据，未获授权不清理落选内容。

## 评分锚点

每项写分数和一条带时间的证据；不评分未观察的声音或运动。

| 维度 | 4 分 | 6 分 | 8 分 |
| --- | --- | --- | --- |
| 概念 | 只有装饰 | 只开头有想法 | 母题贯穿且解释核心 |
| 开场／节奏 | 空等或全满 | 有内容但起伏弱 | 主题及时出现、快慢动静有理由 |
| 可读／构图 | 小字溢出、焦点不明 | 能读但要找 | 小屏清楚、锚点统一、停留足够 |
| 运动 | 乱动、打滑 | 起止正确但机械 | 有因果、错峰、落地静止 |
| 对标／一致 | 假素材、样式杂 | 配色像但气质偏 | 真实素材、同类规则一致 |
| 声画 | 各走各的 | 大致对应 | 真实重音与落点核对 |

通常以 8 分为目标，10 分需有超出目标的证据。满足范围且关键缺陷解决就交付；已知缺陷如实报告，不靠轮数宣布通过。

## 自检与常见 AI 味

- 已确认方向或获“不用停”；核心与母题清楚，真实文案／数据准确。
- 字体已查或明确缺口；安全框、小屏、量字与压力文案通过。
- 动作起止和相邻接缝已取帧；末段读完后才结束。
- 参数、绑定、落点和保存已回读；导出仅在要求时执行，入队不等于交付。

| 症状 | 具体改法 |
| --- | --- |
| 渐变底＋居中标题＋粒子 | 找能解释核心的母题，删除无职责装饰 |
| 每项上移淡入、全是 0.5 秒 | 按重要性与距离分档，主次错峰 |
| 所有卡片都发光、持续呼吸 | 质感集中焦点，读字时停住 |
| 小字漂在大片空白中 | 放大主体，锚到网格边缘 |
| 转场每次不同 | 由母题推一套交接语法 |
| 只有首尾正确，中途闪字 | 加密连续帧，修可见区间与进度边界 |

交付说明位置、检查过的帧、未检查的声音／播放／编码；抽样不等于整片验收。
