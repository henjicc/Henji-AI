# 取帧、批注与交付审查

编译验证运行，回读验证状态，读图验证画面。结论限定于看过的范围，抽帧不能代替播放与听感。

## 三遍看

1. 整体：沿节拍取帧看信息顺序、拖沓、高潮；可从 0.25–0.5 秒间隔起步，长片按段分批，不截掉后段。没有连续播放证据时称为“节奏抽样”。
2. 可读：每拍主停留帧在小屏尺寸读图，核对焦点、原文、背景遮挡、安全区、阅读时长。
3. 细节：转场、快动作和换字处逐帧看，检查空帧、闪烁、重叠、跳出和落地漂移。

## 本项目取帧

用 `observe_video_edit_frame`，documentRef 从正式结果取得：

| 目标 | target 形状 | 用途 |
| --- | --- | --- |
| program | `{kind:"program", sequenceRef, frame}` | 序列整数帧，检查叠层、字幕与转场 |
| source | `{kind:"source", itemRef, timeUs}` | 源素材整数微秒，盘点参考／原素材 |

maxWidth 为 256–3840，默认 1920；整体可用 960，小屏用 360–720，细节用目标原宽或允许的最大宽。它不是联系表总宽，不虚构 region、times 或批量取帧参数。大于可取宽度的原件不能声称已原分辨率核验。

resultRef 交给 `read_application_media`，续读到 eof 并看图；引用不算视觉证据。取帧不改变播放头。记录目标、时间、宽度与改动，避免误用旧帧；期间状态变化就重读受影响段。

单动作取开始、30%、60%、落地、停留中、离场前；接缝从前一帧开始连续取 8–12 帧，30fps 每次 frame＋1。秒数按真实帧率换算；N 帧的末帧是 N−1，不能取终点黑帧当缺陷。循环并排看末帧与第 0 帧。source 的 timeUs 不能直接当序列秒数，修剪／变速后查实际映射。

## 批注与 A/B

每条写：目标片段／时间或帧｜问题｜对观众的影响｜具体改法｜复查点。

例：标题／2.3 秒｜副标题抢先出现｜视线分裂｜延后 4 帧、幅度减半｜复查进场到落地。

每轮先修最影响核心理解的 1–3 处，再看邻接缝，不限制批注总量。批注留当前对话或 video_edit.annotation：按 annotations 查 frame/end_frame、target、text/thread；时间范围用 range，局部问题用 region 或稳定 element。不要把正文塞进素材名字。用户 open 批注的内容修改、thread 回复与 addressed 同事务提交，resolved 只由用户确认。

A/B 在同文案、同背景、同画幅、同语义时刻取帧，比较尺度、可读性和概念。改前先保留实际参数／版本引用；不要为比较删除旧素材。结构不同就按落地时刻对齐，不能只取同秒数。选一版写出依据，未获授权不清理落选内容。

## 评分锚点

每项写分数和一条带时间的证据；不评分未观察的声音或运动。

| 维度 | 4 分 | 6 分 | 8 分 | 10 分 |
| --- | --- | --- | --- | --- |
| 开场 | 空等，3秒后才有内容 | 2秒内有内容但不抓眼 | 前2秒抓眼并入题 | 第一拍就想看下去且点明主题 |
| 可读 | 小屏不清／读不完 | 能读但要找、眯眼 | 小屏清楚、停留足够 | 一眼读懂，阅读顺序自然 |
| 运动 | 乱动、同时进场、打滑 | 曲线对但全片同节奏 | 错峰、静止、无跳帧 | 有因果和重量，整体传力 |
| 节奏 | 一直空或一直满 | 有变化但起伏平 | 2–4秒信息拍、动静有理由 | 高潮前有静，能量清楚、收尾干净 |
| 构图 | 小字漂浮、焦点不明 | 有焦点但边距乱 | 每刻一焦点、网格统一 | 有张力，停留帧可当海报 |
| 概念 | 只有装饰 | 想法只在开头 | 母题贯穿开场转场结尾 | 母题本身解释核心 |
| 对标 | 假素材／气质不像 | 配色像、气质偏 | 真实素材、气质一致 | 放进品牌正式物料也合适 |
| 声画 | 各走各的 | 重音大致对应 | 落地帧对齐真实重音 | 静默、音效、音乐一起讲故事 |

逐项 1–10 分＋一句依据，再列最严重三处及时间；拿不准不打高分，无声音则不评声画，只有抽帧则注明运动证据局限。通常以 8 分为目标，10 分需有超出目标的证据。约三轮后评估继续返修收益，不能靠轮数宣布通过；交付写没到目标的项、取舍和未验证项。记录留对话／正式批注，不私建审阅文件。

## 自检与常见 AI 味

- 已确认方向或获“不用停”；核心与母题清楚，真实文案／数据准确。
- 字体已查或明确缺口；安全框、小屏、量字与压力文案通过。
- 动作起止和相邻接缝已取帧；末段读完后才结束。
- 参数、绑定、落点和保存已回读；导出仅在要求时执行，入队不等于交付。

- 有参考就对齐节拍点与转场比较尺度、气质，不只比颜色；产品 Logo／界面来自真实素材。
- 纵深镜头有前景快、远景慢的视差；代码近似与真实三维边界说明清楚。
- 主标题与正文通常至少约2:1；读字从完全可读时开始算，中文每字0.25秒＋0.5秒、至少1.2秒；结论／Logo落定后至少1.5秒。
- 曲线与方向有职责，错峰跨度、动静、长短一致；信息多就分拍，不删除原文。
- 同类字体、圆角、描边、间距和强调色统一；模板压力文案通过。
- 按可见区间安排片段／源码透明度，离场后不复现；背景和连续声音不能随装饰误裁。
- 素材／片段中文名能说明职责；组件是否共享与“改一处要不要全变”一致，固定版本与实例参数已核对。
- 质感检查：快段拖影不过度糊字；深渐变加低强度颗粒并在要求导出时查编码色带；玻璃确实处理背后内容；光与影集中焦点。
- 不用高频闪白制造冲击，闪烁按每秒不超过3次的保守设计起点审查，不把它称作医学安全保证。
- 交付可定位结果及可编辑参数；未做最终编码／完整播放／试听须说明，不改变宿主渲染器或新建制作说明来冒充交付。

| 症状 | 具体改法 |
| --- | --- |
| 渐变底＋居中标题＋粒子 | 找能解释核心的母题，删除无职责装饰 |
| 每项上移淡入、全是 0.5 秒 | 按重要性与距离分档，主次错峰 |
| 所有卡片都发光、持续呼吸 | 质感集中焦点，读字时停住 |
| 小字漂在大片空白中 | 放大主体，锚到网格边缘 |
| 转场每次不同 | 由母题推一套交接语法 |
| 只有首尾正确，中途闪字 | 加密连续帧，修可见区间与进度边界 |

交付说明位置、检查过的帧、未检查的声音／播放／编码；抽样不等于整片验收。

完整症状与改法见 review-ai。用户说“感觉不对”先用 A/B 把问题落实到尺度、动作或气质；一次取舍留当前对话／标注，明确“以后都这样”的口味才按 preferences 保存。不能把自己评分当作用户满意。

## 怎样看得更准

眯眼看缩略帧辨焦点，再想象灰度检查明暗层级；小于约40px的字／线和玻璃边缘不要凭缩图判断。先全帧再局部：已有关联标注时用 cropAnnotationId，没有则先按正式字段创建有意义的 region 标注，不能伪造任意 crop 输入。原宽超过3840时诚实说明观察分辨率限制。

参考 source 与成片 program 分别取帧后读图，按相同语义节点比较；工具没有 compareWith 或自动联系表，按段逐帧收集，不编造批量接口。落地位置对了还要看动作中间和相邻接缝；循环须查接缝两侧的方向与速度，不只首尾颜色。
