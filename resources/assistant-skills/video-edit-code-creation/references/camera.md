# 镜头感：扁平纵深、镜头带动元素、别像 PPT

做多场景动态图形、人物或信息介绍、“一镜到底”时读；看片觉得像翻 PPT、画面轻飘飘、换场空了一下时读。这是一套审美思路，不是模板：说明书与需求优先。但“无意的翻页感”任何风格都要避免；这不等于每个画面都要一直动，有意的静止同样是好画面（attention）。下文的冲入、甩出、推进都是注意力事件，用多少按 attention 的理由和预算定，克制的风格要明显收着做。

## 两种连续空间

- 真空间：所有画面摆在同一张大画布的不同位置（相邻、嵌套、远近），镜头在上面走。观众记得“刚才那个在左边”，空间关系本身在讲信息关系。适合讲解、产品、结构说明。
- 假空间：前后场景不在同一空间，但视线一直被某个东西接着（人物、线条、色块），换景那一刻被运动、遮挡或变形藏起来，观众自己把它们缝成连续空间。适合人物介绍、叙事、情绪片。

两种可混用。共同点是任何时刻都在一个连续的运动里，没有“翻页”；这个连续运动大部分时间是察觉不到的承载运动，只在有理由处才变成明显的镜头动作。

## 扁平纵深：画面是平的，空间有深度

元素本身保持扁平（无透视变形、无厚度、不靠光影塑形），但分布在不同距离的图层上，镜头一动近快远慢，层次就出来了。

| 层（远→近） | 内容 | 作用 |
| --- | --- | --- |
| 远背景 | 点阵、网格、极淡纹理或大字 | 镜头移动的参照；纯色底上镜头怎么走都看不出，这是“没有镜头感”最常见的原因 |
| 中景装饰 | 地图、线框、编号、大几何 | 和主体拉开距离，产生第二层视差 |
| 主体 | 人物、产品、图表 | 镜头焦点，构图以它为准 |
| 文字与标注 | 姓名、说明、数据 | 比主体再近一点，先离开、后到达，不像贴在同一张纸上 |
| 前景点缀 | 微尘、细线、虚化形状 | 最快掠过；很少、很淡，不挡主体 |

三到五层就够，关键是层间距离拉开。景深虚化要克制，轻微或只给前景（pose 的 blur，镜头散焦用 blurShape lens），强虚化会推向三维质感。背景点阵亮度要低，镜头大幅移动或转场时可稍提亮。

代码做法：在源码里算一个镜头，每层有自己的距离，位姿＝镜头投影 × 元素自己的运动（投影倍率见 recipes-3d）；会移动、缩放的内容都放进带 pose 的图层，运行时据此做运动模糊，文字也不抖。

## 镜头带动元素

- 同向叠加：元素入场方向与镜头造成的画面方向一致，速度叠加，冲击更强，一起减速落定。
- 新元素从镜头前进的方向进来：镜头右移，旧元素向左离开，新元素从右侧冲入，视线被顺势带过去。
- 新元素在镜头减速时到达，最后到的是细节（编号、标签）；不要等镜头完全停住才开始出现。
- 离场跟随镜头但有先后：离镜头近的层（文字）先被甩出，主体稍后，背景最慢。
- 元素对镜头有反应：开始推进时非焦点变暗或退让，停稳后焦点细节再补进来。
- 每段一种主运动（推、拉、横移、升降），可带轻微转向；底下通常留一层极慢推进或漂移，要专心看或稳住停顿时可不加。

## 先冲后缓，出场即在动

- 入场急速冲进来，再用远长于冲入段的时间减速贴近终点（expoOut 或落地侧很重的 cubicBezier）。冲入给力量，长尾巴给高级感；镜头感片子里减速尾巴可延续到 1.5–2.5 秒。
- 不硬停：到位前有减速尾巴；尾巴后可以接微动，也可以稳稳停住。
- 出场即在动：元素出现时自己的动作（旋转、展开、流动、组装）已在进行，不能先出现、停住、再开始动。入场和持续动作同一时刻开始，入场尾巴把速度交给持续动作；组装时每个部件落位时整体的转动或漂移已在进行。逐帧看出场那几帧，任何部件“位置不变”的帧都要改。
- 画面的持续运动主要来自镜头的缓推漂移，其次是图层视差；单个元素的微动只是点缀，幅度远小于字号、很慢、彼此不同步，不影响阅读。持续的小信号（扫描线、滚动编号、脉冲定位点、闪烁光标）每画面最多一两个、低对比、节奏稳，读字时不在旁边闪。

## 为什么显得轻

- 曲线太温和、太对称：落地一侧要重，速度差越大越有质量感。
- 没有运动模糊：快动作每帧都清晰，像在频闪。带 pose 的图层自带快门曝光（模块 motionBlur），这是重量感最大的来源之一。
- 所有东西一起动：整块平移像一张纸在滑。层与层速度不同、跟随元素晚 1–3 帧，才像有质量的东西被带动。
- 缩放线性插值：100%→400% 线性插值会越推越慢、拉远越拉越快。按对数插值（scale＝a·(b/a)^p），推拉速度感才均匀。
- 时长和距离不匹配：大位移太短抽搐，小动作太长拖沓。
- 像素抖动：在 draw 里用 translate、scale 移动文字和细线，慢速时会一像素一像素地跳；写成带 pose 的图层。

## 推近加平移：取景框同进度插值

推近、平移写成一张镜头表（时刻、取景框中心与宽度），按时间查当前段直接求值。取景框的宽（1/缩放）和中心用同一个缓动进度插值；“中心不出画”的限制只在两端预先算好，运行时不再夹取，否则平移会晚于缩放启动，出现怪异的缩放感。高亮框写元素本身的边界，代码统一外扩边距，让元素在框里居中。

## 场景交接：任何一帧都不空

- 旧场景元素还在离开，新场景元素就开始进来，两者在时间上重叠；背景层贯穿换场，不跟着清空。
- 两个全屏代码场景相接：后一个放上层轨道、提前几帧开始淡入，前一个不淡出；或干脆合成一个场景。两个都淡入淡出时，中间会透出下层（比如白底占位就是一次闪白）；被完全盖住的占位素材要禁用。
- 全屏代码场景接实拍或录屏：代码片段比切点多出约 0.35 秒，淡出叠在素材上；从素材切进代码场景时直接切，代码场景第一帧镜头已在动。
- 蒙太奇里每段素材都缓推时用匀速，同方向同速度、每段一开始就在动；缓入缓出会让每段开头速度为 0，像停了一下再起步。
- 检查：换场前后一秒密集取帧（每 2–3 帧一张），任何一帧都不能只剩空背景。

## PPT 感清单：命中先问是不是有意的

元素原地淡入淡出、上浮出现作为主要入场；镜头不动、元素在固定位置逐个冒出、出完整屏静止等翻页；换场先全部收走再全部出现、中间有空帧；每个元素等上一个完全结束才开始，全部同一时长同一曲线；元素先出现停住再开始自己的动作；离场就是入场倒放；幻灯片版式（左标题右配图、居中标题加三要点），文字贴在屏幕平面上和画面世界无关；用预设推入、翻页连接两个不相干的画面。

克制档里遮罩升起后稳住、纪实的定镜头、落版的静止都可能是对的；没有理由的才改。反过来动得太多同样要改，见 attention 的过度清单。

## 例：神秘档案感人物介绍（用户认可过的方向，非模板）

黑底白色元素，只有一个高亮色用在状态、扫描线、识别框和地点标记上；人物是低多边形灰阶半身像，右侧档案信息（编号、姓名、代号、字段，个别字段涂黑，编号像解密一样滚动后定格）。第一段镜头带推进冲入，人像同向冲入，文字逐行长尾减速进来，停下后仍缓推、扫描线扫过、识别框后补。第二段镜头横移到第二人：近层文字先被甩出、人像随后，背景点阵变亮、三层错开；第二人从右侧同向冲入，在镜头减速时落位。第三段镜头拉远，两人缩到两侧相对，地图线条铺开，两条连线从两人脸部连到同一地点。

## 自检

1. 原速看：有没有像翻 PPT 的时刻；停下处是有意静止还是无意僵住；有没有太忙的段落。
2. 换场前后密集取帧：无空帧，离场与入场重叠。
3. 只看背景层：镜头移动时看得出它在动；看不出就是缺参照或层距不够。
4. 入场是冲进来再长减速，没有硬停。
5. 停稳构图里文字、人脸都在安全框内（layout）；运动途中可以越过边缘，落定构图和拉远后的全景单独检查。
6. 逐帧看小字慢移、缩放的片段：位置不抖。
