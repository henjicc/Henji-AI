# 模板：把做得好的元素沉淀成可复用的组件

模板是做好的元素，换文字、颜色、图片就能反复使用，让同一支片子、同一个系列里的同类元素长得完全一样。内容可以是带参数的作者代码，也可以是原生文字图形组合。用户说“这个不错”“后面会复用”“做成模板”时读这里；做标题、人名条、对话框、标注、开场、片尾这类会反复出现的元素之前，先查有没有现成模板。

## 三种复用的区别

| | 风格预设 | 模板 | 效果预设 |
| --- | --- | --- | --- |
| 是什么 | 写给你的风格引导加样片 | 做好的元素，可改的部分是参数 | 一组效果与参数值 |
| 复用方式 | 你读了以后自己画，每次不完全一样 | 直接拿来换内容，长得完全一样 | 每次应用复制成独立效果 |
| 改动 | 不追着改已有内容 | **联动**：改模板，工程里所有实例一起变 | 各自独立 |
| 范围 | 风格库，工程里带副本 | 工程模板跟着工程走；也可设为全局 | 本机预设库 |

## 什么时候登记

- 用户明确说要复用、要做成模板时登记。
- 同一类元素第二次出现、而且两次应该长得一样时，问一句要不要存成模板，不擅自登记。
- 只用一次、或每次都要明显不同的东西，不做模板。

## 登记前先整理：换了内容不能坏

直接把当时的效果登记，换一句长一点的文案就会坏。按下面整理代码，再用 `create_video_edit_template` 登记：

1. **该改的都做成参数**：文字（标题、姓名、说明）、图片、主色、需要时的开关和对齐。默认值就是现在画面上的内容，登记后外观不变。不改的（动效、比例、质感）留在代码里，不要什么都开放。每段文字声明 `text` 与 `textStyle` 参数并用 `layer` 绑定图层。
2. **尺寸跟着内容走**：底板、框、线、图标的位置大小按文字实际宽度和字号算（`ctx.measureText`，与绘制同字体、字距、换行）；内边距、圆角、描边按字号比例算（如左右 0.45s、上下 0.22s、圆角 ≤ 高度一半）；整体按画面高度换算。逐字揭示时底板按完整定版文案测量，不随新字抖动。
3. **极端内容要兜住**：一两个字时底板不比高度还窄；太长先按语义换行、再等比缩小，不出安全框、不截字；空字符串时 pose 返回 null，整组连同投影和装饰一起隐藏。
4. **时间跟着片段走**：入场从片段开头算，离场落在片段末尾；用 `info.clip.time` / `info.clip.duration`，片段拉长缩短时离场跟着移动，不写死第几秒。
5. **会动的文字放进运动层**，不在 draw 里直接平移缩放文字（author-text-motion）。
6. **压力测试**：至少用这几组内容各取一次定版帧和入场中途帧，坏了先修再登记——最短（一两个字）、最长（预期上限的 1.5 倍）、中英混排带数字与 g/y/p、空字符串；再换字号减半与翻倍、换画幅、裁短时长各看一次。通过后恢复交付文案并重新取帧。
7. **背景**：字幕条、人名条、标注这类只有前景的模板，模板本身不画背景（透明），预览和缩略图统一铺软件自带的那张实拍背景图（雾中山林），不要为了好看在模板里自己画底或另找图片。整画面的开场、片尾这类自己画满的模板，以及风格样片，不加这张背景。

## 名称和说明

- 名称说清是什么：“档案人名条”“对话框·左侧气泡”“章节开场”，不用“模板 1”。
- 说明一句话写用途和适用场合，如“人物首次出场时介绍姓名和代号，压在人像右侧”，以后靠这句判断该不该用。
- 登记时记下属于哪个风格（`styleId`，省略时用序列绑定的风格）。

## 复用

1. 先列模板：工程模板 `video_edit.project_template` 优先，其次库模板 `video_edit.template`，看说明是否适用。
2. 适用就 `apply_video_edit_template` 加到目标位置，只改 `parameters`（代码模板的参数）或 `texts`（原生模板按顺序替换文字）。不要为了改一句文字去复制代码。
3. 需要一点变化时：能用参数表达的（换颜色、换对齐），给模板加参数、默认值保持原样；结构上不同的（多一行、换版式），另登记一个新模板，各自命名。
4. 模板属于别的风格时，先告诉用户，再用参数调色换字体，或照它的思路按当前风格重做。
5. 风格的“组件”一栏写了会反复出现的元素：用户要“按风格生成模板”时，逐个写成作者代码、按上面整理和压力测试，再登记（`styleId` 写这个风格，`global` 为 true 存进风格库）。

## 修改模板：先说影响范围

模板是联动的，改了内容，工程里所有实例都会变：

- 改之前读 `video_edit.project_template.instance_refs`，告诉用户会影响几处。用户只想改一处时，先 `detach_video_edit_template_instance` 把那一处分离成独立内容再改。
- 代码模板：在它的代码定义（`video_edit.project_template.code_material_ref`）下创建新源码版本，再 `update_video_edit_template`（content.kind=version）；原生模板：改好一组实例后用 content.kind=clips 登记为新内容。内容变了版本加 1，只改名称、说明不升版本（通用属性写 name/description）。
- 改完逐个抽查实例的定版帧，确认每处文字仍然放得下。

## 工程模板与全局模板

- **工程模板**跟着工程走；代码模板的源码就是工程里那个代码定义，不另存一份。
- **全局模板**放在风格库，不跟工程走。在工程里第一次使用时复制一份成为工程模板，记下来源与版本；同一工程再次使用复用这一份，保持联动。
- 用户说“设成全局”“以后别的项目也用”时，才 `promote_video_edit_template`（默认更新来源库模板，mode=new 另存）。
- 库模板更新后工程副本不会自动变：`video_edit.project_template.library_version` 不为 null 时告诉用户影响几处，同意再 `update_video_edit_template`（content.kind=library，confirmed=true）。
- 删除工程模板只取消登记，代码和实例都保留；删除库模板不影响已经复制进工程的副本。打开别人分享的工程时，本机没有对应的库模板只是一条提示，不影响使用。
- 用户可以在模板面板点击或拖入应用、右键设为全局与升级、保存所选为模板、分离所选；改用户的模板前先读它当前的内容和说明，以现状为准。
