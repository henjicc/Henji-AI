# 可换字的模板与自适应

用于标题条、花字、标签、人名条及文字驱动图形。模板不是默认文案漂亮，而是内容、字号、画幅和时长改变后仍正确。

## 先查真实量字能力

按当前 author-api 查询文字测量、排版与分组的实际输出及坐标语义；只有公开的测量函数或应用能力才能调用。这里用“量字结果”描述需求，不发明函数名，也不在受限源码里调用 DOM、Canvas、字体下载或任意方法。

量字必须与渲染使用相同的字体、字重、字号、字距、行距、文本和限宽，字体加载后才有效。字段应区分实际行宽、行数、行距与字形上下范围；不能用“字数 × 字号”估计中英混排、标点和下伸字母。

当前接口没有量字或自动换行时，不能宣称自适应模板已完成。可按明确的一次性文案取帧校正固定版式，并报告限制；不要用猜测的测量 API 或无限试缩来掩盖缺口。接口升级由实际载入的作者参考决定。

## 尺寸由内容驱动

以下是设计关系，不是可直接提交的源码：

- 字号 s；左右内边距从 0.45s、上下从 0.22s、圆角从 0.30s 起步。
- 底板宽＝最宽行实际宽＋左右内边距；短标签可令宽不小于高，避免单字像细竖条。
- 底板高＝稳定一行字高＋(行数−1)×行距＋上下内边距。不要因英文 aaa 与中文笔画高度不同使底板上下跳。
- 字形测量不足以提供稳定行框时，采用正式排版返回的行框或经验证的参考字范围，并加足 g／y／p 的下伸余量；不能假设测量字段含有行框。
- 圆角不超过底板高度一半；描边可从 0.02–0.04s、硬投影距离从 0.08s 起步，同类共用比例。
- 名字＋头衔的底板取两行较宽者；头衔放名字下方约 0.3s，头衔为空不保留多余第二行。

字号翻倍后边距、线宽和投影也同比变；画幅变化先换算安全宽高，再排文本。左锚向右长，居中锚向两侧长，底部字幕按最后一行向上长；取帧核对锚点，不能只看宽高正确。

## 动画与布局分开

底板按完整定版文案测量，逐词揭示只改变可见内容，不能让每个新字使底板抖动。给主进度、位置或不透明度做动画，几何由内容与字号求出，不给底板旧像素尺寸写死关键帧。

主文字、底板、线条与图标共用同一组变换或明确关联的进度；分组不可用时仅用当前语法支持的共享常量关系，不伪造父子 API。空字符串隐藏整个相关组，包括投影、角标与线条，不留下空底板。

保持固定入场／离场时长，中段用于阅读。片段裁短后检查是否仍容得下进入、阅读、退出；不能假设作者能读取片段终点。接口未提供终点时，用已公开时长参数或重排实例曲线表达；只改时间线 duration 不保证源码自动适应。

## 超宽处理

按语义换行，中文按合适边界、英文按词；优先换行，再等比缩小字号。若小于小屏可读尺度，分拍、调整版式或提议延长，不截字、不横向压扁、不偷偷缩成小字。手动换行不会因字号变小减少行数，停止条件应基于实际总高度，避免无效反复缩小。

## 压力测试

| 文案 | 要证明的关系 |
| --- | --- |
| 1 个字 | 最小底板、锚点与圆角正确 |
| 24 个字 | 限宽、换行、字号与安全区成立 |
| 三行 | 行距稳定，不遮挡字幕或人脸 |
| 中英混排，含 g／y／p 和数字 | 实际行宽、下伸与基线不溢出 |
| 空字符串 | 全组消失，无残留装饰 |

再测实际最长文案、换已查询字体、字号减半／翻倍、改画幅与裁短时长。用授权范围内的测试实例或可恢复参数逐项检查，保留原实例引用和设置；不擅自删除用户素材。每项取定版帧，至少在最长文案的入场中途加取帧，检查底板与文字是否同步。通过后恢复交付文案并重新读图；只回读恢复值不能证明恢复画面。
