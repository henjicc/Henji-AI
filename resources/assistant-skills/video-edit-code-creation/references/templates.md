# 可换字的模板与自适应

用于标题条、花字、标签、人名条及文字驱动图形。模板不是默认文案漂亮，而是内容、字号、画幅和时长改变后仍正确。

## 先查真实量字能力

本项目 v3 已有 measureText 与 group。measureText 返回可读 width、height、lines；height 是行数×字号×lineHeight 的稳定行框，不是字形墨迹范围。量字使用 author-text-motion 的排版字段，不在受限源码里调用 DOM、Canvas、字体下载或任意方法。

量字必须与渲染使用相同的字体、字重、字号、字距、行距、文本和限宽，字体加载后才有效。字段应区分实际行宽、行数、行距与字形上下范围；不能用“字数 × 字号”估计中英混排、标点和下伸字母。

measureText 不含 perChar 变换：按完整文案量出的框天然不随揭示抖动。text 与测量要给同样的 maxWidth／wrap／maxLines；有 maxLines 时宿主可能缩字号，不能仍用原字号猜实际字形。缺字体回退或无法取得正式度量时报告限制，不用“字数×字号”假装自适应已验证。

## 尺寸由内容驱动

以下是设计关系，不是可直接提交的源码：

- 字号 s；左右内边距从 0.45s、上下从 0.22s、圆角从 0.30s 起步。
- 底板宽＝最宽行实际宽＋左右内边距；短标签可令宽不小于高，避免单字像细竖条。
- 底板高＝measureText.height＋上下内边距；本项目行框稳定，不搬“隐藏参考字层”方案。使用 baseline:top／bottom 与一致行距定位，并取帧看 g／y／p 和中文笔画不贴边。
- 圆角不超过底板高度一半；描边可从 0.02–0.04s、硬投影距离从 0.08s 起步，同类共用比例。
- 名字＋头衔的底板取两行较宽者；头衔放名字下方约 0.3s，头衔为空不保留多余第二行。

字号翻倍后边距、线宽和投影也同比变；画幅变化先换算安全宽高，再排文本。左锚向右长，居中锚向两侧长，底部字幕按最后一行向上长；取帧核对锚点，不能只看宽高正确。

## 动画与布局分开

底板按完整定版文案测量，逐词揭示只改变可见内容，不能让每个新字使底板抖动。给主进度、位置或不透明度做动画，几何由内容与字号求出，不给底板旧像素尺寸写死关键帧。

主文字、底板、线条与图标放在 group 的局部坐标里，共用组变换与进度；opacity 在整组完成后应用一次，无须各层模拟父子透明度。空字符串用条件令整组 opacity 为0，包括投影、角标与线条，不留下空底板。每实例独立参数，不按素材名互相引用。

保持固定入场／离场时长，中段用于阅读。片段裁短后检查是否仍容得下进入、阅读、退出；不能假设作者能读取片段终点。接口未提供终点时，用已公开时长参数或重排实例曲线表达；只改时间线 duration 不保证源码自动适应。

作者 ctx 没有片段 outPoint 或总时长。公开“展示秒数”参数，退场从该参数减离场秒数开始；时间线 duration、source_in_us、变速和参数须一起核对。源码 durationSeconds 是源可用范围，不会因片段裁短自动改值；没有 MOGRT 保护区域功能。

## 超宽处理

按语义换行，中文按合适边界、英文按词；优先换行，再等比缩小字号。若小于小屏可读尺度，分拍、调整版式或提议延长，不截字、不横向压扁、不偷偷缩成小字。手动换行不会因字号变小减少行数，停止条件应基于实际总高度，避免无效反复缩小。

## 压力测试

| 文案 | 要证明的关系 |
| --- | --- |
| 1 个字 | 最小底板、锚点与圆角正确 |
| 24 个字 | 限宽、换行、字号与安全区成立 |
| 三行 | 行距稳定，不遮挡字幕或人脸 |
| 中英混排，含 g／y／p 和数字 | 实际行宽、下伸与基线不溢出 |
| 空字符串 | 全组消失，无残留装饰 |

再测实际最长文案、换已查询字体、字号减半／翻倍、改画幅与裁短时长。用授权范围内的测试实例或可恢复参数逐项检查，保留原实例引用和设置；不擅自删除用户素材。每项取定版帧，至少在最长文案的入场中途加取帧，检查底板与文字是否同步。通过后恢复交付文案并重新读图；只回读恢复值不能证明恢复画面。

## 参数、组件与复用

| 改动维度 | 本项目做法 |
| --- | --- |
| 文字／字体／字号 | text、font、number 参数；字形自带fill/stroke，底板、线、图标位置从同一测量框推导 |
| 画幅／相邻元素 | ctx.width/height 与安全边距计算；副标题在名字行框下方0.3字号，底板取两者较宽者；空头衔取消第二行 |
| 色彩／圆角／线宽 | color和比例参数或ctx.style；不用逐个修改同类图形 |
| 多组同结构样式 | types声明组件类型（如名字／头衔的字体、颜色、大小），parameters以类型名引用；字距、行距与节奏分组，低频参数advanced |
| 一份素材多次插入 | 相同固定源码版本，各片段code_parameters／code_curves独立，不复制整份实现 |
| 一个素材的复杂部件 | files/entry拆部件、配色、WGSL，导出纯函数并具名导入 |
| 跨剪辑复用部件 | 发布video_edit.code_component；description说清导出与意图参数，组件函数接收props；旧素材钉版本，更新须创建新素材版本 |

只开放用户真正会改的量，标题／名称用意图词和单位；布局从内容推导，别开放几十个像素补丁。完整人名条见 recipes-captions，组件发布见 multifile-components；参数型与项目组件是两种概念，前者组织值，后者复用源码。
