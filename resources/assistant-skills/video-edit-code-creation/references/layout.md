# 版式与构图

用于搭关键画面、标题叠层和知识图形。所有比例以目标序列为准，读回宽高和帧率后再换算作者画布像素，不用应用窗口尺寸排画面。

## 画幅与安全框

横屏常见 1920×1080、竖屏 1080×1920，方形与 4:5 适合信息流；继续已有序列时保持实际规格，不擅自改帧率。横屏转竖屏应重新排主体、注释与文字，不能只居中裁切。

关键文字默认离四边至少各边长的 5%；横屏左边距可从宽度的 6% 起步，留出清晰锚线。字幕预留底部 15–17% 的空间。竖屏初排可预留顶部 8%、底部 20%、右侧 12%，这是平台遮挡的经验起点，不是统一标准；最终对照用户平台与真实观看区。

标题条和人名条先看底层画面，避开人脸、手部动作、已有字幕。透明素材在 program 合成帧上检查，单看 source 的透明底无法证明遮挡安全。

## 层级与网格

先写三层信息：第一眼核心、第二眼解释、第三眼可删点缀。用至少两种手段建立层级，例如字号约 2:1 加出场先后，或粗细加位置。不能把所有文字都做成同等大小的中心标题。

横屏可取 8／12 列，竖屏可取 4／6 列；内边距与间距从同一刻度取。以短边 1080 为例，刻度 8、16、24、32、48、64、96；其他尺寸等比换算。无需画出网格，它用于对齐边缘、基线和注释。

主焦点可以从画面宽度 40–60% 起试，短标题可占 60–80%；这是测试尺度，不要求所有镜头填满。留白用于引导视线或表现安静，不能让小字孤零零悬浮再靠装饰填空。

## 版式原型

| 原型 | 内容与做法 | 防止的问题 |
| --- | --- | --- |
| 满版大字 | 开场／章节；短句占宽 70–90%，只保留核心 | 大字旁再塞完整说明 |
| 杂志左对齐 | 标题、细线、说明共用左锚点；另一侧留给素材 | 每行都有不同边距 |
| 中心物件＋标注 | 主体占宽 40–60%；引线连接真实部位 | 注释小、引线交叉或指向空处 |
| 分屏对比 | 两侧同尺度、同属性基线，差异处高亮 | 对比双方字体和构图完全不同 |
| 卡片列表 | 同类尺寸统一，按阅读顺序逐张强调；长列表分拍 | 所有卡片同时抢焦点 |
| 大数字 | 数字最大，单位贴近，解释退一档 | 单位远离数值，数字滚动导致抖动 |
| 时间轴 | 节点沿一条路径，当前节点高亮；必要时分段展示 | 压缩节点到无法阅读 |
| 金句 | 大字、明确断句、出处小一档 | 加无用途的引号图形和底图 |
| 界面特写 | 真实截图放大操作区域，其余压低对比 | 整屏缩图文字读不清 |
| 人名条 | 安全区内名字＋头衔，文字量驱动底板 | 压字幕、人脸或长头衔溢出 |
| 片尾落版 | 结论／标志稳定停留，默认至少 1.5 秒 | 最后一个动作刚落地便结束 |

## 构图张力

不对称用网格一侧的大焦点配另一侧的小解释；大与小的对比比几个中等元素更鲜明。出血裁切仅用于装饰性大字或非必要物体边缘，不能裁掉价格、姓名、结论。前后遮挡可以形成层次，但二维分组不等于真实三维空间。

连接线要能指出起点对象、终点对象与职责：解释流程、对应部位或强调结论。删线不损失理解就删掉。图标只取已提供或正式能力可用的统一素材；不靠符号字符、emoji 假装图标，不虚构外部下载工具。

取缩小帧检查：能否一眼指出焦点、左右边距是否统一、小字是否靠近对应对象。删掉一个装饰后画面没损失就删；与前后镜头并排看锚点，避免接缝处视线突然跨全屏寻找信息。

## 规格与检查刻度

新作可从横屏1920×1080／4K3840×2160、竖屏1080×1920、信息流1080×1350或1080×1080起步；24／25偏影片节奏、30通用、60适合流畅界面演示，但现有素材／交付帧率优先，不靠改帧率制造高级感。国内25fps素材先核对，不混时钟。

90%标题区、93%动作区可作初排参考：1080p文字左右至少96、上下54px，横屏统一约120px边距更容易形成锚线；平台覆盖仍按真实场景检查，不声称是本应用预设。间距刻度还可用128px，正文与标题可同时用2–3倍字号差、700对400字重、位置／明度形成至少两种对比。

分屏可1:1或1:2，但两侧同一比较对象尺度一致；列表别卡片套卡片，长列表分拍；金句约30字内是粗排建议，长原文分拍而非删除。画中画／窗口框能聚焦，不能用边框补救整屏小字。眯眼后再按灰度关系看层级，检查强调去色后仍可辨。
