## 技术要点

### 1. apiField 映射模式
大多数模型使用简单的 apiField 映射：
```typescript
{
  id: 'ppioWan26Mode',
  type: 'dropdown',
  apiField: 'mode'  // ← 添加的映射
}
```

### 2. request.builder 模式
复杂模型（如 Seedream）使用 request.builder 处理参数转换：
```typescript
request: {
  builder: (params) => {
    // 复杂的参数转换逻辑
    return requestData
  }
}
```

### 3. 参数命名规范
- 参数 ID 使用驼峰命名：`ppioWan26Mode`
- API 字段使用下划线命名：`aspect_ratio`, `enable_prompt_expansion`
- 部分 API 使用驼峰命名：`aspectRatio`, `keepAudio`
