# 新系统完全替代adapters迁移计划

本计划旨在将当前的双系统架构（新系统模型定义 + 旧系统adapters）完全迁移到纯新系统架构，实现"每个供应商一个文件控制，添加模型只需创建一个文件"的理想架构。

迁移目标：
- 删除 src/adapters/ 目录及其所有 Adapter 类
- 创建轻量级 Provider 系统
- 实现完全配置驱动的架构
- 添加新模型只需1个文件，最多修改2个文件

执行策略：
- 先建立完整的新系统框架（任务01-02）
- 再实现PPIO供应商并完整测试（任务03-04）
- PPIO验证通过后，迁移其他供应商（任务05-06）
- 最后清理旧系统（任务07）
- 旧代码均备份完毕，所以可以随意修改文件删除文件
- 如果需要参考旧代码，可以去根目录下 old-Henji-AI 文件夹内查找
