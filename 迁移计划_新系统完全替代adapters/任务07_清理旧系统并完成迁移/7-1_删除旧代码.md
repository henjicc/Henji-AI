## 可能的问题和解决方案

### 问题1：编译错误 - 找不到模块

```
Error: Cannot find module '@/adapters/...'
```

**解决**：
1. 找到引用的文件
2. 更新导入语句使用新系统
3. 或删除该引用（如果已废弃）

### 问题2：运行时错误 - ApiService 未定义

```
ReferenceError: apiService is not defined
```

**解决**：
1. 查找使用 apiService 的代码
2. 替换为 GenerationService.getInstance()
3. 应该在任务02已完成，如果还有遗漏，现在修复

### 问题3：类型错误

```
Type 'XXX' is not assignable to type 'YYY'
```

**解决**：
1. 检查是否使用了旧的类型定义
2. 更新为新的类型（从 @/core/providers/base 导入）
