# 适配前确认清单

在任何编码前，先给用户输出下面清单并等待确认。

## 输出模板

```markdown
我先确认适配范围，请你确认/修改：

1) 场景类型
- [ ] A 新增供应商
- [ ] B 现有供应商新增模型
- [ ] C 新模型且供应商未接入（先 A 后 B）

2) 供应商信息
- providerId:
- 显示名称(zh/en):
- API Key 获取入口链接:
- 鉴权方式(Bearer/Key/Header):

3) 模型信息
- modelId:
- 模型显示名(zh/en):
- 模型类型(image/video/audio):
- 能力标签(tags):
- 是否同家族已有模型可复用(给出参考文件):

4) 接口契约
- 提交接口(route/method):
- 是否异步轮询:
- 轮询接口/状态字段/成功失败状态值:
- 结果 URL 字段路径:

5) 参数清单（按顺序）
- 每个参数：order / id / type / 默认值 / 是否显示 / 是否请求 / 说明
- 额外标注：
  - 不显示且不请求
  - 不显示但固定请求（写明固定值）

6) 多媒体输入约束
- 图片数量限制:
- 视频数量限制:
- 模式切换下的规则:
- 是否需要公网 URL 上传:

7) 交付与校验
- 将修改的文件范围：
- 必跑命令：npm run build
```

## 阻断规则

- 若第 2~5 项缺失关键字段，不进入编码。
- 若用户描述与 API 文档冲突，优先指出冲突并请求确认。
- 若用户只给出“模型名”，至少补齐 providerId、模型类型、提交/轮询契约。
