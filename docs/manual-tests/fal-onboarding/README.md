# Fal 与首次设置手动验收

本清单只覆盖必须由真人观察的点击与布局，不执行真实模型生成。

## 1. Fal 模型

1. 打开「生成」，分别筛选 Fal 的图像与视频模型，确认新模型可见且名称正常。
2. 打开「画布」，新增任一 Fal 图像节点和视频节点。
3. 确认「比例」与「分辨率」是两个独立控件；支持明确档位的模型优先显示 `1K / 2K / 4K`。
4. Kling 等官方接口没有字面分辨率时，确认分辨率控件显示官方 `标准 / Pro` 档位，而不是伪造 K 值。
5. 切换比例或分辨率，确认另一个控件的当前选择不会被覆盖。

## 2. 首次设置

1. 点击标题栏问号，确认欢迎页出现；「稍后继续」、关闭按钮、返回和跳过均可用。
2. 切换中文、英文和跟随系统，确认界面文案立即变化。
3. 依次选择 KIE、Fal、APIMart、派欧云，确认差异说明和后续密钥平台同步变化。
4. 在密钥步骤输入测试文本，确认默认遮挡、显示/隐藏按钮正常；不要保存无效文本。
5. 使用真实密钥时可点击「保存并测试」：只读检测不得创建生成任务，结果应区分成功、无效密钥、余额不足、限流、超时和网络错误。
6. 到首次任务步骤点击「准备首个任务」，确认生成页已选择主供应商下的图像模型并填入示例提示词；本轮不要点击「生成」。
7. 打开「设置 → 通用 → 首次设置」，确认能修改主供应商、打开平台密钥、重新运行引导，且已保存密钥未被清除。

## 3. 打包产物

1. 安装或打开本次构建产物，确认首次启动无白屏。
2. 已有用户配置的升级环境不应自动弹出欢迎页；标题栏问号与设置分区仍可主动打开。
