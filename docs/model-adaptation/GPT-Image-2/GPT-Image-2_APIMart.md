> APIMart 上 GPT-Image-2 有**两个不同的模型与两份文档**，参数与计费方式都不同，适配时必须分开对待：
>
> - **`gpt-image-2`（EXT 渠道）**：按张按分辨率档位固定计费，参数较少
> - **`gpt-image-2-official`（官方渠道）**：直连 OpenAI 官方模型，参数最全（quality / background / mask / output_format 等），按 **token** 计费

## 1. 接入协议

- **Base URL**：`https://api.apimart.ai`
- **鉴权**：`Authorization: Bearer <API_KEY>`
- **提交**：`POST /v1/images/generations`（基于 OpenAI Images 兼容协议）→ `{ code, data: [{ status: "submitted", task_id }] }`
- **查询**：`GET /v1/tasks/{task_id}`，读 `result.images`
- **任务结果只返回 `url`**——需要 base64 请自行下载转换
- 其它 OpenAI 标准字段（`response_format`、`style`）**不支持，会被忽略**

## 2. 渠道 A：`gpt-image-2`（EXT）

### 2.1 能力

- 文生图 / 图生图（参考图最多 **16 张**，URL 与 base64 可混填）
- 15 种比例 + `auto`
- `1k` / `2k` / `4k` 三档分辨率

### 2.2 请求参数

| 字段 | 类型 | 必填 | 默认 | 取值与说明 |
|---|---|---|---|---|
| `model` | string | 必填 | `gpt-image-2` | `gpt-image-2`；兼容别名 `gpt-image-2-ext`（等价、效果一致） |
| `prompt` | string | 必填 | — | 支持中英文。提交前经平台敏感词/安全审核，命中直接报错 |
| `n` | integer | 可选 | `1` | **取值只能是 1**。必须传纯数字，加引号会报错 |
| `size` | string | 可选 | `1:1` | 15 种比例 + `auto`：`1:1`、`3:2`、`2:3`、`4:3`、`3:4`、`5:4`、`4:5`、`16:9`、`9:16`、`2:1`、`1:2`、`3:1`、`1:3`、`21:9`、`9:21`。也支持直接传像素（如 `1881x836`）。**`auto` 时默认比例为 `1:1`** |
| `resolution` | string | 可选 | `1k` | `1k` / `2k` / `4k` |
| `image_urls` | array | 可选 | — | 传入后走图生图。**最多 16 张**（超过返回 `image_urls exceeds max 16`）；单张 ≤ 20 M，总体 ≤ 256 M；URL 与 `data:image/png;base64,...` 可混填。**不传 `size` 时输出分辨率 = 输入图分辨率**；传 `size` 则强制按指定尺寸出图 |
| `official_fallback` | boolean | 可选 | `false` | `true` 时使用官方渠道兜底 |
| `nsfw_check` | boolean | 可选 | `false` | `true` 时用 `omni-moderation-latest` 预审 |

## 3. 渠道 B：`gpt-image-2-official`（OpenAI 官方渠道）

### 3.1 能力

文生图 / 图生图 / **局部重绘（mask）**三合一；支持 PNG / WebP **透明背景（Alpha 通道）**；15 种比例 × 1K/2K/4K；单次最多 **4 张**；参考图最多 16 张。文档称与 `gpt-image-1.5-official` 接口 95% 对齐，迁移只需改模型名。

### 3.2 请求参数

| 字段 | 类型 | 必填 | 默认 | 取值与说明 |
|---|---|---|---|---|
| `model` | string | 必填 | `gpt-image-2-official` | 固定值 |
| `prompt` | string | 必填 | — | 支持中英文 |
| `size` | string | 可选 | `1:1` | 同 15 种比例 + `auto`（服务端按 prompt / 参考图自动选择） |
| `resolution` | string | 可选 | `1k` | `1k`（1024 基准）/ `2k`（2048 基准）/ `4k`（3840 基准） |
| `quality` | string | 可选 | `auto` | `auto`（**通常等同 `low`**）/ `low` / `medium` / `high`。**4K + high 耗时 > 120 s** |
| `background` | string | 可选 | `auto` | `auto` / `opaque` / `transparent`（输出含 Alpha 通道） |
| `moderation` | string | 可选 | `auto` | `auto` / `low`（更宽松） |
| `output_format` | string | 可选 | `png` | `png`（支持透明）/ `jpeg`（无 Alpha）/ `webp`（支持透明）。**`background: transparent` 时只能选 `png` 或 `webp`** |
| `output_compression` | integer | 可选 | — | `0–100`，**仅对 `jpeg` / `webp` 有效** |
| `n` | integer | 可选 | `1` | **1–4**。必须传纯数字 |
| `image_urls` | array | 可选 | — | 最多 **16 张**；单张 ≤ 20 M，总体 ≤ 256 M；须是公网可直接访问的稳定 URL |
| `mask_url` | string | 可选 | — | 局部重绘遮罩图。**必须搭配 `image_urls`**；遮罩图**必须有 Alpha 通道**，且**尺寸需与首张参考图一致** |
| `nsfw_check` | boolean | 可选 | `false` | 同上 |

## 4. 适配要点

- 本项目默认**绝对不显示**：`seed`、负面提示词。两条渠道都没有这两个字段。
- `output_format` 默认不显示、不请求（官方渠道有该字段）。
- **两条渠道不要合成一个模型**：计费口径（按张 vs 按 token）、参数集合、`n` 上限（1 vs 4）都不同。
- EXT 渠道 `n` 只能是 1；`n` 必须是数字类型。
- 图生图不传 `size` 时会**继承输入图分辨率**（EXT 渠道），产品若期望固定比例必须显式下发 `size`。
- 局部重绘（mask）是官方渠道独有，且对遮罩图有硬性要求（含 Alpha、尺寸与首图一致），要作为独立能力分支处理。
- 15 种比例里 `3:1` / `1:3` / `9:21` 等在其他供应商上大多不支持，跨供应商比例集合必须分别裁剪。
