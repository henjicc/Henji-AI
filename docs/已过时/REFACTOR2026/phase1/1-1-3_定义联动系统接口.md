# 1-1-3 定义联动系统接口

## 目标

定义参数联动系统的 TypeScript 接口，支持所有联动效果类型

## 背景

参数联动是新架构的关键特性，需要支持：
- reset：重置参数
- filterOptions：过滤选项
- filterRange：过滤范围
- setValue：设置值
- autoSwitch：自动切换
- disable：禁用参数
- hide：隐藏参数
- custom：自定义处理

## 测试方法

创建各种联动示例：

```typescript
// 示例1：重置联动
const resetLinkage: ResetLinkage = {
  trigger: 'mode',
  effect: 'reset',
  targets: ['images', 'videos']
}

// 示例2：过滤选项
const filterLinkage: FilterOptionsLinkage = {
  trigger: 'resolution.quality',
  effect: 'filterOptions',
  target: 'duration',
  filter: (quality, options) => {
    if (quality === '1080P') {
      return options.filter(o => o.value <= 10)
    }
    return options
  }
}

// 示例3：自动切换
const autoSwitchLinkage: AutoSwitchLinkage = {
  trigger: 'images',
  effect: 'autoSwitch',
  target: 'resolution.aspectRatio',
  condition: (images) => images?.length > 0,
  value: 'smart',
  noRestore: false
}
```

验证 TypeScript 类型检查通过

## 风险与注意事项

### 风险
- 联动逻辑过于复杂，难以调试

### 注意事项
- 每种联动类型应有明确的必需字段
- filter、condition、handler 函数应有清晰的签名
- 支持嵌套触发器（如 'resolution.quality'）
- 考虑循环依赖检测

## 联动接口设计参考

```typescript
type LinkageEffect =
  | 'reset'
  | 'filterOptions'
  | 'filterRange'
  | 'setValue'
  | 'autoSwitch'
  | 'disable'
  | 'hide'
  | 'custom'

interface BaseLinkage {
  trigger: string | string[]
  effect: LinkageEffect
  priority?: number
  debounce?: number
}

interface ResetLinkage extends BaseLinkage {
  effect: 'reset'
  targets: string[]
}

interface FilterOptionsLinkage extends BaseLinkage {
  effect: 'filterOptions'
  target: string
  filter: (triggerValue: any, options: any[], allParams: any) => any[]
}

interface AutoSwitchLinkage extends BaseLinkage {
  effect: 'autoSwitch'
  target: string
  condition: (triggerValue: any, allParams: any) => boolean
  value: any | ((triggerValue: any, allParams: any) => any)
  noRestore?: boolean
}

type Linkage =
  | ResetLinkage
  | FilterOptionsLinkage
  | FilterRangeLinkage
  | SetValueLinkage
  | AutoSwitchLinkage
  | DisableLinkage
  | HideLinkage
  | CustomLinkage
```
