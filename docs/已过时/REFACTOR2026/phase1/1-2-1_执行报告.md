### 1. 创建模型验证器

**文件路径**: `src/core/validators/modelValidator.ts`

**功能**:
- 创建 `ModelValidationError` 错误类
- 实现 `validateModel()` 主验证函数
- 实现 5 个子验证函数：
  - `validateMeta()` - 验证元数据（id, provider, type, name, aliases, tags, polling）
  - `validateParams()` - 验证参数定义数组和参数 ID 唯一性
  - `validateParam()` - 验证单个参数定义（必需字段、组件类型特定字段）
  - `validateLinkages()` - 验证联动规则（触发器和目标参数存在性）
  - `validateEndpoints()` - 验证端点配置（default/rules/selector 至少一个）
  - `validatePricing()` - 验证价格配置（fixed/calculator 至少一个）

**验证覆盖**:
- ✅ 必需字段检查
- ✅ 数据类型验证
- ✅ 枚举值验证（type, component）
- ✅ 参数 ID 唯一性检查
- ✅ 联动引用完整性检查
- ✅ 特定组件类型的字段验证（dropdown 必须有 options，slider 必须有 min/max）

### 2. 创建 ModelRegistry 核心类

**文件路径**: `src/core/ModelRegistry.ts`

**架构设计**:
- 使用单例模式确保全局唯一实例
- 使用 Map 数据结构提高查询性能
- 建立多维索引（按 ID、provider、type、tag）

**核心数据结构**:
```typescript
class ModelRegistry {
  private models: Map<string, ModelDefinition>              // 主索引（ID + 别名）
  private modelsByProvider: Map<ProviderId, Set<string>>    // 按供应商索引
  private modelsByType: Map<ModelType, Set<string>>         // 按类型索引
  private modelsByTag: Map<ModelTag, Set<string>>           // 按标签索引
}
```

**实现的核心方法**:

1. **注册功能** (2 个方法):
   - `register(model)` - 注册单个模型
     - 验证 ID 唯一性
     - 调用 validateModel() 验证配置
     - 注册主 ID 和所有别名
     - 构建多维索引
   - `registerBatch(models)` - 批量注册模型
     - 返回成功注册的数量
     - 失败时记录错误但不中断

2. **查询功能** (8 个方法):
   - `getModel(id)` - 按 ID 或别名查询模型定义
   - `hasModel(id)` - 检查模型是否存在
   - `getSchema(id)` - 获取参数 Schema
   - `getDefaultValues(id)` - 获取参数默认值对象
   - `getModelsByProvider(provider)` - 按供应商查询
   - `getModelsByType(type)` - 按类型查询
   - `getModelsByTag(tag)` - 按标签查询
   - `listAllModels()` - 列出所有模型（去重别名）

3. **价格计算** (1 个方法):
   - `calculatePrice(modelId, params)` - 计算价格
     - 支持固定价格（pricing.fixed）
     - 支持动态计算（pricing.calculator）
     - 异常时返回 0 并记录错误

4. **端点选择** (1 个方法):
   - `selectEndpoint(modelId, params)` - 选择 API 端点
     - 支持固定端点（字符串）
     - 支持函数选择器（endpoints.selector）
     - 支持规则选择器（endpoints.rules）
     - 支持默认端点（endpoints.default）

5. **调试支持** (3 个方法):
   - `getModelInfo(id)` - 获取模型详细信息
     - 返回完整的模型元数据、参数数量、联动数量等
   - `getStats()` - 获取统计信息
     - 返回模型总数、别名数、各供应商模型数、类型分布、热门标签
   - `clear()` - 清空所有模型（仅用于测试）

6. **辅助方法** (2 个私有方法):
   - `evaluateCondition()` - 评估端点规则条件
   - `getTopTags()` - 获取使用次数最多的标签

**单例实例导出**:
```typescript
export const registry = ModelRegistry.getInstance()
```

## 技术亮点

### 1. 多维索引设计
使用 4 个 Map 建立索引，实现 O(1) 查询复杂度：
- 主索引：models（支持 ID 和别名查询）
- 供应商索引：modelsByProvider
- 类型索引：modelsByType
- 标签索引：modelsByTag

### 2. 单例模式
确保全局只有一个 ModelRegistry 实例，避免重复注册和状态不一致：
```typescript
private constructor() {}
static getInstance(): ModelRegistry
```

### 3. 别名支持
每个模型可以有多个别名，方便兼容旧代码：
```typescript
meta: {
  id: 'nano-banana',
  aliases: ['fal-nano-banana', 'nano-banana-fal']
}
```

### 4. 健壮的错误处理
- 注册时验证配置，抛出 ModelValidationError
- 查询不存在的模型返回 undefined（不抛错）
- 价格计算和端点选择失败时返回默认值并记录错误

### 5. 完整的调试支持
- `getModelInfo()` 获取单个模型详情
- `getStats()` 获取注册中心整体统计
- `listAllModels()` 列出所有模型（去重）

### 6. 批量注册
`registerBatch()` 支持一次注册多个模型，失败时不中断：
```typescript
const count = registry.registerBatch([model1, model2, model3])
console.log(`Successfully registered ${count}/3 models`)
```

## 性能优化

### 1. 使用 Map 而非对象
- 查询性能：O(1)
- 支持任意类型的键
- 自带 size 属性

### 2. Set 去重
索引值使用 Set 存储模型 ID，自动去重

### 3. 延迟计算
价格计算和端点选择只在需要时执行，不在注册时预计算

### 4. 别名存储
别名直接指向原模型对象（引用），不复制数据
