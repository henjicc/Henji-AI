# Phase 1.5 集成方案设计

## 方案概述

采用**渐进式替换策略**，分 3 个阶段完成 MediaGenerator 与新系统的集成。

## 阶段 1: 替换参数管理（核心）

### 目标
将 160+ 个 useState 替换为 useModelParams Hook

### 实现步骤

**1.1 修改 MediaGenerator 主组件**

```typescript
// 旧代码
import { useMediaGeneratorState } from './hooks/useMediaGeneratorState'
const state = useMediaGeneratorState()

// 新代码
import { useModelParams } from '@/hooks/useModelParams'
const { params, updateParam, resetParams } = useModelParams(selectedModel)
```

**1.2 保留必要的 UI 状态**

以下状态不属于模型参数，需要保留：
- `input` - 提示词输入
- `selectedProvider` - 选中的供应商
- `selectedModel` - 选中的模型
- `uploadedImages` - 上传的图片
- `uploadedFilePaths` - 文件路径
- `modelFilterProvider` - 模型筛选
- `favoriteModels` - 收藏模型

**1.3 参数访问方式变更**

```typescript
// 旧方式
const duration = ppioKlingO1VideoDuration

// 新方式
const duration = params.ppioKlingO1VideoDuration || 5
```

### 影响范围
- `src/components/MediaGenerator/index.tsx`
- `src/components/MediaGenerator/hooks/useMediaGeneratorState.ts` (可删除)

### 验证标准
- ✅ 参数值正确读取
- ✅ 参数更新正常工作
- ✅ 联动效果正常触发
- ✅ 默认值正确加载

## 阶段 2: 替换参数面板

### 目标
使用新的 ParamsPanel 替换旧的 ParameterPanel

### 实现步骤

**2.1 替换组件导入**

```typescript
// 旧代码
import ParameterPanel from './components/ParameterPanel'

// 新代码
import { ParamsPanel } from '@/components/params/ParamsPanel'
```

**2.2 更新组件使用**

```typescript
// 旧代码
<ParameterPanel
  selectedModel={selectedModel}
  // ... 传递 160+ 个 props
/>

// 新代码
<ParamsPanel
  modelId={selectedModel}
  params={params}
  onParamChange={updateParam}
/>
```

### 影响范围
- `src/components/MediaGenerator/index.tsx`
- `src/components/MediaGenerator/components/ParameterPanel.tsx` (可删除)

### 验证标准
- ✅ 所有参数正确渲染
- ✅ 参数类型正确（dropdown, slider, switch 等）
- ✅ 参数顺序正确
- ✅ 联动效果正常

## 阶段 3: 替换请求构建

### 目标
使用新的 RequestBuilder 替换 buildGenerateOptions

### 实现步骤

**3.1 替换请求构建逻辑**

```typescript
// 旧代码
import { buildGenerateOptions } from './builders/optionsBuilder'
const options = buildGenerateOptions(selectedModel, state)

// 新代码
import { RequestBuilder } from '@/core/request/RequestBuilder'
const builder = new RequestBuilder()
const options = builder.build(selectedModel, params)
```

**3.2 更新 onGenerate 调用**

```typescript
// 保持接口不变
onGenerate(input, selectedModel, modelType, options)
```

### 影响范围
- `src/components/MediaGenerator/index.tsx`
- `src/components/MediaGenerator/builders/optionsBuilder.ts` (可删除)

### 验证标准
- ✅ API 请求参数正确
- ✅ 端点选择正确
- ✅ 图片/视频上传正常
- ✅ 所有模型都能正常生成
