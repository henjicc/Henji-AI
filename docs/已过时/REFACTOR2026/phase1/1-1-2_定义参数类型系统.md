# 1-1-2 定义参数类型系统

## 目标

定义完整的参数类型系统，支持所有参数组件和配置

## 背景

参数系统是新架构的核心，需要支持：
- 基础组件（text, number, slider, dropdown, switch, radio）
- 复合组件（panel, image-upload, video-upload）
- API 字段映射（apiField, apiTransform, apiMapping）
- 显示条件（visible, disabled）
- 智能匹配（smartMatch）

## 测试方法

创建各种参数示例：

```typescript
// 示例1：基础参数
const durationParam: SliderParamDef = {
  id: 'duration',
  component: 'slider',
  name: { zh: '时长', en: 'Duration' },
  order: 1,
  valueType: 'number',
  default: 5,
  min: 5,
  max: 15,
  step: 5,
  apiField: 'duration'
}

// 示例2：条件显示
const imageUploadParam: ImageUploadParamDef = {
  id: 'images',
  component: 'image-upload',
  name: { zh: '图片', en: 'Images' },
  order: 10,
  maxCount: 1,
  visible: {
    condition: 'mode !== "reference-to-video"'
  },
  apiField: 'img_url'
}
```

验证 TypeScript 类型检查通过

## 风险与注意事项

### 风险
- 参数类型过于复杂，难以理解和使用

### 注意事项
- 使用 discriminated union 确保类型安全
- 每个组件类型应有明确的必需字段
- 可选字段应有合理的默认值
- JSDoc 注释应包含使用示例

## 参数类型设计参考

```typescript
type ComponentType =
  | 'text'
  | 'number'
  | 'slider'
  | 'dropdown'
  | 'switch'
  | 'radio'
  | 'panel'
  | 'image-upload'
  | 'video-upload'

interface BaseParamDef {
  id: string
  order: number
  name: I18nText
  tooltip?: I18nText
  component: ComponentType
  valueType: 'string' | 'number' | 'boolean'
  default: any
  apiField?: string
  apiTransform?: (value: any) => Record<string, any>
  visible?: VisibleCondition
  disabled?: DisabledCondition
}

interface SliderParamDef extends BaseParamDef {
  component: 'slider'
  valueType: 'number'
  min: number
  max: number
  step: number
  unit?: string
  marks?: Array<{ value: number; label: string }>
}
```
