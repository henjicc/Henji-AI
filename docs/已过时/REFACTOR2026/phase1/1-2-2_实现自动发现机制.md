# 1-2-2 实现自动发现机制

## 目标

实现模型文件自动发现功能，无需手动注册 `*.model.ts` 文件

## 背景

当前问题：
- 每个新模型需要在 `src/models/index.ts` 手动注册
- 容易遗漏，导致模型不可用
- 维护成本高

新架构目标：
- 自动扫描 `src/models/**/*.model.ts` 文件
- 自动注册到 ModelRegistry
- 开发者只需创建 `.model.ts` 文件即可

## 风险与注意事项

### 风险
- Vite glob 导入在生产环境可能有不同行为
- 文件扫描性能可能随模型数量增长
- 热更新可能导致状态丢失

### 注意事项
- 使用 `import.meta.glob` 而非动态 import，确保构建时包含
- 生产环境使用 eager 加载，开发环境可使用 lazy
- 错误处理应该详细，帮助开发者定位问题
- 考虑添加加载缓存，避免重复加载
- 热更新时需要清理旧的注册信息
- 文件路径应使用正斜杠，兼容 Windows

## 实现参考

```typescript
// src/core/loaders/modelLoader.ts

import { registry } from '../ModelRegistry'
import type { ModelDefinition } from '../types'

interface ModelModule {
  default: ModelDefinition
}

/**
 * 加载所有模型文件
 */
export async function loadAllModels(): Promise<void> {
  console.log('[ModelLoader] Loading models...')

  const startTime = performance.now()
  const modules = import.meta.glob<ModelModule>(
    '@/models/**/*.model.ts',
    { eager: true }
  )

  let successCount = 0
  let errorCount = 0

  for (const [path, module] of Object.entries(modules)) {
    try {
      if (!module.default) {
        throw new Error('Model file must export default')
      }

      const model = module.default

      // 验证模型格式
      if (!model.meta?.id) {
        throw new Error('Model must have meta.id')
      }

      // 注册到 registry
      registry.register(model)

      console.log(`[ModelLoader] ✓ Loaded: ${model.meta.id}`)
      successCount++
    } catch (error) {
      console.error(`[ModelLoader] ✗ Failed to load ${path}:`, error)
      errorCount++
    }
  }

  const duration = performance.now() - startTime
  console.log(
    `[ModelLoader] Complete: ${successCount} loaded, ${errorCount} failed (${duration.toFixed(2)}ms)`
  )
}

/**
 * 列出所有已加载的模型（调试用）
 */
export function listLoadedModels(): void {
  const models = registry.listAllModels()
  console.table(
    models.map(m => ({
      id: m.meta.id,
      provider: m.meta.provider,
      type: m.meta.type,
      params: m.params.length
    }))
  )
}

// 开发环境下暴露到 window
if (import.meta.env.DEV) {
  (window as any).__listModels = listLoadedModels
  (window as any).__reloadModels = loadAllModels
}
```

initApp()

## 回滚方案

1. 删除自动加载代码
   - 删除 `src/core/loaders/` 目录
   - 从 `src/main.tsx` 移除 `loadAllModels()` 调用

2. 恢复手动注册
   - 恢复 `src/models/index.ts` 的手动注册代码
   ```typescript

   registry.register(wan26)
   // ...
   ```
