### 4. 使用示例

#### 4.1 基础 AutoSwitch 示例

**场景**: 当上传图片时，自动切换 aspectRatio，移除图片时恢复原值

```typescript
{
  trigger: 'image',
  effect: 'autoSwitch',
  targets: ['aspectRatio'],
  switchValue: async (triggerValue, params, schema) => {
    const paramDef = schema.find(p => p.id === 'aspectRatio')
    const options = paramDef?.options || []
    const availableRatios = options.map(opt => opt.value)

    return await smartMatchImageRatio(triggerValue, availableRatios)
  },
  condition: (value) => value !== null && value !== '',
  priority: 3
}
```

**执行流程**:
1. 用户上传图片 → `image` 参数变化
2. 条件满足（image 不为空）
3. 记录 `aspectRatio` 的原始值
4. 调用 `smartMatchImageRatio` 计算最佳比例
5. 自动设置 `aspectRatio` 为计算结果
6. 用户移除图片 → `image` 变为 null
7. 条件不满足，恢复 `aspectRatio` 为原始值

#### 7.2 智能比例匹配算法

通过计算差值找到最接近的比例：

```typescript
export function findClosestRatio(targetRatio: number, ratios: string[]): string {
  let closestRatio = ratios[0]
  let minDiff = Infinity

  for (const ratio of ratios) {
    const [w, h] = ratio.split(':').map(Number)
    const r = w / h
    const diff = Math.abs(r - targetRatio)

    if (diff < minDiff) {
      minDiff = diff
      closestRatio = ratio
    }
  }

  return closestRatio
}
```

#### 7.3 异步图片加载

使用 Promise 封装图片加载，支持异步获取尺寸：

```typescript
export async function getImageSize(
  dataUrl: string
): Promise<{ width: number; height: number }> {
  return new Promise((resolve, reject) => {
    const img = new Image()
    img.onload = () => resolve({ width: img.width, height: img.height })
    img.onerror = () => reject(new Error('Failed to load image'))
    img.src = dataUrl
  })
}
```

#### 7.4 自动清理机制

恢复原值后自动清理记录，避免内存泄漏：

```typescript
private restoreOriginalValue(paramId: string): any | null {
  const state = this.originalValues.get(paramId)
  if (state) {
    this.originalValues.delete(paramId)
    return state.value
  }
  return null
}
```
