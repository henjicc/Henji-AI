### 2. 创建联动引擎核心

**文件路径**: `src/core/linkage/LinkageEngine.ts`

**核心功能**:

#### 2.1 LinkageEngine 类
```typescript
export class LinkageEngine {
  private linkages: Linkage[]
  private executionDepth: number
  private readonly maxDepth = 10
}
```

**特点**:
- 构造时自动按优先级排序联动
- 防止循环联动（最大深度 10 层）
- 递归执行联动链

#### 2.2 核心方法

**`execute()` - 执行联动**:
```typescript
execute(
  changedKey: string,
  params: Record<string, any>,
  schema: ParamDef[]
): Record<string, any>
```

**执行流程**:
1. 检查执行深度，防止循环联动
2. 查找触发的联动（trigger 匹配 changedKey）
3. 按优先级顺序执行联动
4. 调用 `executeEffect()` 处理效果
5. 如果有参数变更，递归执行新的联动
6. 返回最终参数状态

**`getFilteredOptions()` - 获取过滤后的选项**:
```typescript
getFilteredOptions(
  paramId: string,
  params: Record<string, any>,
  schema: ParamDef[]
): any[]
```

**功能**:
- 查找 `filterOptions` 类型的联动
- 检查条件是否满足
- 返回过滤后的选项数组
- 如果没有联动，返回原始选项

**`isParamDisabled()` - 检查参数是否禁用**:
```typescript
isParamDisabled(paramId: string, params: Record<string, any>): boolean
```

**`isParamHidden()` - 检查参数是否隐藏**:
```typescript
isParamHidden(paramId: string, params: Record<string, any>): boolean
```

### 7. 技术亮点

#### 7.1 循环联动防护

通过 `executionDepth` 计数器和 `maxDepth` 限制，防止无限递归：

```typescript
if (this.executionDepth >= this.maxDepth) {
  console.warn('[LinkageEngine] Max execution depth reached')
  return params
}
```

#### 7.2 优先级自动排序

构造时自动按优先级排序联动，确保执行顺序正确：

```typescript
constructor(linkages: Linkage[]) {
  this.linkages = [...linkages].sort((a, b) => {
    const priorityA = a.priority ?? getDefaultPriority(a.effect)
    const priorityB = b.priority ?? getDefaultPriority(b.effect)
    return priorityA - priorityB
  })
}
```

#### 7.3 递归联动执行

支持联动链式触发，一个联动的结果可以触发新的联动：

```typescript
// 执行联动效果
const changes = executeEffect(linkage, triggerValue, newParams, schema)

if (changes) {
  newParams = { ...newParams, ...changes }

  // 递归执行新触发的联动
  for (const key of Object.keys(changes)) {
    newParams = this.execute(key, newParams, schema)
  }
}
```

#### 7.4 类型安全的效果分发

使用 TypeScript 判别联合类型确保类型安全：

```typescript
export function executeEffect(
  linkage: Linkage,
  triggerValue: any,
  params: Record<string, any>,
  schema: ParamDef[]
): Record<string, any> | null {
  switch (linkage.effect) {
    case 'reset':
      return executeResetEffect(linkage, triggerValue, params, schema)
    case 'setValue':
      return executeSetValueEffect(linkage, triggerValue, params)
    case 'autoSwitch':
      return executeAutoSwitchEffect(linkage, triggerValue, params, schema)
    case 'custom':
      return executeCustomEffect(linkage, triggerValue, params)
    default:
      return null
  }
}
```
