# 1-4-2 实现端点选择器

## 目标

实现端点选择系统，根据参数和上下文自动选择正确的 API 端点

## 背景

当前问题：
- 某些模型有多个端点（如 Wan 2.6 有 t2v, i2v, v2v 三个）
- 端点选择逻辑散落在各个 Adapter 中
- 难以维护和测试

新架构方案：
- 在模型定义中声明端点选择规则
- 支持规则选择器和函数选择器
- 统一的端点选择接口

## 风险与注意事项

### 风险
- 条件表达式求值可能有安全风险（使用 Function 构造函数）

### 注意事项
- 规则按顺序匹配，第一个匹配的生效
- 应提供默认端点（最后一个规则无条件）
- 上下文应包含足够信息供选择器使用
- 条件表达式应简单，避免复杂逻辑

## 实现参考

```typescript
// src/core/endpoint/EndpointSelector.ts

interface SelectResult {
  endpoint: string
  route: RouteDefinition
}

interface SelectContext {
  uploadedImages?: string[]
  uploadedVideos?: string[]
  [key: string]: any
}

class EndpointSelector {
  constructor(private config: EndpointConfig) {}

  select(params: Record<string, any>, context: SelectContext): SelectResult {
    const endpointKey = this.selectEndpoint(params, context)
    const route = this.getRoute(endpointKey)

    if (!route) {
      throw new Error(`Endpoint route not found: ${endpointKey}`)
    }

    return { endpoint: endpointKey, route }
  }

  private selectEndpoint(
    params: Record<string, any>,
    context: SelectContext
  ): string {
    // 简化配置：直接字符串
    if (typeof this.config === 'string') {
      return 'default'
    }

    // 函数选择器
    if (typeof this.config.select === 'function') {
      return this.config.select(params, context)
    }

    // 规则选择器
    if (this.config.select?.rules) {
      for (const rule of this.config.select.rules) {
        if (!rule.condition || this.evaluateCondition(rule.condition, params, context)) {
          return rule.endpoint
        }
      }
    }

    throw new Error('No endpoint matched')
  }

  private evaluateCondition(
    condition: string,
    params: Record<string, any>,
    context: SelectContext
  ): boolean {
    try {
      // 创建安全的求值环境
      const fn = new Function('params', 'context', `
        with (params) {
          with (context) {
            return ${condition}
          }
        }
      `)
      return fn(params, context)
    } catch (error) {
      console.error('Condition evaluation error:', error)
      return false
    }
  }

  private getRoute(endpointKey: string): RouteDefinition | undefined {
    if (typeof this.config === 'string') {
      return { path: this.config, method: 'POST' }
    }

    if (endpointKey === 'default' && typeof this.config.default === 'string') {
      return { path: this.config.default, method: 'POST' }
    }

    return this.config.routes?.[endpointKey]
  }
}

// src/core/endpoint/ContextBuilder.ts

class ContextBuilder {
  static build(params: Record<string, any>): SelectContext {
    const context: SelectContext = {}

    // 提取上传的图片
    if (params.images?.length > 0) {
      context.uploadedImages = params.images
    }

    // 提取上传的视频
    if (params.videos?.length > 0) {
      context.uploadedVideos = params.videos
    }

    return context
  }
}

export { EndpointSelector, ContextBuilder }
```
