### 1. 创建 RequestBuilder 核心类

**文件路径**: `src/core/request/RequestBuilder.ts`

**核心功能**:

#### 1.1 RequestBuilder 类

```typescript
export class RequestBuilder {
  build(
    modelId: string,
    params: Record<string, any>,
    options: BuildOptions = {}
  ): BuildResult

  private hasNewConfig(model: ModelDefinition): boolean
  private buildWithNewConfig(model, params, context, debug): BuildResult
  private buildWithOldConfig(modelId, params, context): BuildResult
  private mapParam(paramDef, value, endpointKey, allParams, debug): Record<string, any>
  private convertType(value: any, type: string): any
  private getEndpoint(model, endpointKey): { path: string; method?: string }
}
```

**特点**:
- 支持新旧配置双引擎架构
- 自动检测模型配置类型
- 优先使用新配置，降级到旧系统
- 完整的调试日志支持

#### 1.2 核心方法

**`build()` - 构建 API 请求**:

**执行流程**:
1. 获取模型定义
2. 检查是否有新配置
3. 使用新配置引擎或降级到旧系统
4. 返回构建结果

**`buildWithNewConfig()` - 使用新配置构建**:

**执行流程**:
1. 选择端点（调用 ModelRegistry.selectEndpoint）
2. 获取端点配置
3. 添加基础参数（request.base）
4. 映射参数（遍历 params，应用映射规则）
5. 应用预处理（request.preprocess）
6. 返回请求对象

**`mapParam()` - 映射单个参数**:

**优先级**: apiMapping > apiTransform > apiField

**映射规则**:
- **apiMapping**: 端点相关映射，根据不同端点应用不同转换
- **apiTransform**: 通用转换函数，返回参数对象
- **apiField**: 简单字段映射，直接映射到 API 字段名

**`getEndpoint()` - 获取端点配置**:

**支持两种配置**:
- 单端点简化配置：`{ default: '/api/generate' }`
- 多端点配置：`{ routes: { t2v: { path: '/t2v', method: 'POST' } } }`

### 6. 技术亮点

#### 6.1 双引擎架构

支持新旧配置系统共存，渐进式迁移：

```typescript
private hasNewConfig(model: ModelDefinition): boolean {
  return model.params.length > 0 && model.endpoints !== undefined
}
```

**优势**:
- 向后兼容，不影响现有模型
- 新模型可以立即使用新配置
- 降低迁移风险

#### 6.2 参数映射优先级系统

三级映射优先级确保灵活性：

```typescript
// 1. apiMapping（端点相关）
if ('apiMapping' in paramDef && paramDef.apiMapping?.[endpointKey]) {
  return mapping.transform(value, allParams)
}

// 2. apiTransform（通用转换）
if ('apiTransform' in paramDef && paramDef.apiTransform) {
  return paramDef.apiTransform(value, allParams)
}

// 3. apiField（简单映射）
if ('apiField' in paramDef && paramDef.apiField) {
  return { [paramDef.apiField]: this.convertType(value, paramDef.valueType) }
}
```

**优势**:
- 支持端点特定映射（不同端点不同格式）
- 支持复杂转换逻辑（apiTransform）
- 支持简单字段映射（apiField）

#### 6.3 完善的参数验证

多层次验证确保数据质量：

```typescript
// 1. 必需参数检查
if ('required' in paramDef && paramDef.required) {
  if (value === undefined || value === null || value === '') {
    errors.push({ paramId, message: '...', type: 'required' })
  }
}

// 2. 类型检查
if (!isValidType(paramDef, value)) {
  errors.push({ paramId, message: '...', type: 'type' })
}

// 3. 范围检查
if (!isValidRange(paramDef, value)) {
  errors.push({ paramId, message: '...', type: 'range' })
}
```

**优势**:
- 提前发现参数错误
- 友好的错误消息
- 支持多种验证规则
