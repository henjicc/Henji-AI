#### 1.2 条件显示逻辑

```typescript
const isVisible = useMemo(() => {
  if (!paramDef.visible) return true

  if (typeof paramDef.visible.condition === 'function') {
    return paramDef.visible.condition(allParams)
  }

  if (typeof paramDef.visible.condition === 'string') {
    try {
      const fn = new Function('params', `
        with (params) {
          return ${paramDef.visible.condition}
        }
      `)
      return fn(allParams)
    } catch (error) {
      console.error('Visible condition evaluation error:', error)
      return true
    }
  }

  return true
}, [paramDef.visible, allParams])
```

#### 1.3 禁用状态逻辑

```typescript
const isDisabled = useMemo(() => {
  if (externalDisabled) return true
  if (!paramDef.disabled) return false

  if (typeof paramDef.disabled.condition === 'function') {
    return paramDef.disabled.condition(allParams)
  }

  return false
}, [paramDef.disabled, allParams, externalDisabled])
```

## 技术亮点

### 1. 配置驱动的 UI 渲染

ParamRenderer 完全基于 ParamDef 配置驱动，无需手动编写 UI 代码：

```typescript
// 只需提供参数定义
const paramDef: TextParamDef = {
  id: 'prompt',
  component: 'text',
  order: 1,
  name: { zh: '提示词', en: 'Prompt' },
  valueType: 'string',
  default: '',
  multiline: true,
  maxLength: 1000
}

// ParamRenderer 自动渲染对应的 UI
<ParamRenderer
  paramDef={paramDef}
  value={value}
  onChange={onChange}
  allParams={allParams}
/>
```

### 2. 灵活的条件显示

支持两种条件表达式：

**函数形式**:
```typescript
visible: {
  condition: (params) => params.mode !== 'reference-to-video'
}
```

**字符串表达式**:
```typescript
visible: {
  condition: 'mode !== "reference-to-video"'
}
```

### 3. 类型安全的组件映射

使用 TypeScript 的 discriminated union 确保类型安全：

```typescript
const COMPONENT_MAP = {
  text: TextInput,
  number: NumberInput,
  // ...
} as const

// TypeScript 会自动推断组件类型
```


### 4. 国际化支持

使用 `getI18nText` 工具函数自动处理多语言文本：

```typescript
const label = getI18nText(paramDef.name, i18n.language)
const tooltip = paramDef.tooltip ? getI18nText(paramDef.tooltip, i18n.language) : undefined
```

### 5. React.memo 性能优化

使用 React.memo 避免不必要的重渲染：

```typescript
export const ParamRenderer: React.FC<ParamRendererProps> = React.memo(({
  paramDef,
  value,
  onChange,
  allParams,
  getFilteredOptions,
  disabled
}) => {
  // ...
})
```
