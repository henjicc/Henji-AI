### 1. 类型定义 (types.ts)

**文件路径**：`src/components/params/panels/ResolutionPanel/types.ts`

**代码行数**：90 行

**主要内容**：
- 定义了 4 种分辨率模式：aspect-quality、preset、custom、hybrid
- 创建了各种选项接口：AspectRatioOption、QualityOption、PresetOption
- 定义了 ResolutionConfig 配置接口，支持多种模式组合
- 定义了 ResolutionValue 值接口，统一值的结构

**关键类型**：
```typescript
export type ResolutionMode = 'aspect-quality' | 'preset' | 'custom' | 'hybrid'

export interface ResolutionConfig {
  mode: ResolutionMode
  aspectRatios?: { options: AspectRatioOption[]; default: string; smartMatch?: boolean }
  qualityTiers?: { options: QualityOption[]; default: string; availableFor?: Record<string, string[]> }
  presets?: { options: PresetOption[]; default: string }
  customSize?: { enabled: boolean; minWidth: number; maxWidth: number; minHeight: number; maxHeight: number; step: number; lockRatio?: boolean }
}

export interface ResolutionValue {
  mode: ResolutionMode
  aspectRatio?: string
  quality?: string
  preset?: string
  width?: number
  height?: number
}
```

## 技术亮点

### 1. 组件化设计
- 将复杂的分辨率面板拆分为 4 个独立的子组件
- 每个子组件职责单一，可独立使用和测试
- 便于维护和扩展

### 2. 配置驱动
- 通过 ResolutionConfig 配置不同模式
- 支持 4 种模式满足不同模型需求
- 配置灵活，易于为新模型创建配置

### 3. 类型安全
- 完整的 TypeScript 类型定义
- 编译时类型检查
- 良好的 IDE 智能提示

### 4. 用户体验优化
- 比例锁定功能提升自定义输入体验
- 动态过滤质量选项避免无效选择
- 可视化图标帮助理解比例
- 平滑的动画过渡

### 5. 国际化支持
- 所有文本使用 I18nText 类型
- 通过 getI18nText 工具函数获取当前语言文本
- 便于后续多语言扩展
