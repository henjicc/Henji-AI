# 2-1-1 实现基础输入组件

## 目标

实现所有基础参数输入组件，支持文本、数字、滑块等基本类型

## 背景

新架构的参数系统需要一套可复用的基础组件库，这些组件将根据参数定义自动渲染。基础组件包括：
- TextInput（文本输入）
- NumberInput（数字输入）
- SliderInput（滑块）

这些组件需要：
- 支持 i18n 显示
- 支持值类型转换
- 支持禁用和条件显示
- 统一的样式和交互

## 参考实现

### TextInput 示例

```typescript
import React from 'react'
import { I18nText } from '@/core/types'
import { useI18n } from '@/hooks/useI18n'

interface TextInputProps {
  value: string
  onChange: (value: string) => void
  label: I18nText
  tooltip?: I18nText
  placeholder?: I18nText
  maxLength?: number
  multiline?: boolean
  disabled?: boolean
}

export const TextInput: React.FC<TextInputProps> = ({
  value,
  onChange,
  label,
  tooltip,
  placeholder,
  maxLength,
  multiline = false,
  disabled = false
}) => {
  const { t } = useI18n()

  const handleChange = (e: React.ChangeEvent<HTMLInputElement | HTMLTextAreaElement>) => {
    const newValue = e.target.value
    if (maxLength && newValue.length > maxLength) return
    onChange(newValue)
  }

  const Component = multiline ? 'textarea' : 'input'

  return (
    <div className="param-input">
      <label>
        {t(label)}
        {tooltip && <span className="tooltip" title={t(tooltip)}>?</span>}
      </label>
      <Component
        type={multiline ? undefined : 'text'}
        value={value}
        onChange={handleChange}
        placeholder={placeholder ? t(placeholder) : undefined}
        maxLength={maxLength}
        disabled={disabled}
        className="param-input-field"
      />
      {maxLength && (
        <span className="char-count">{value.length}/{maxLength}</span>
      )}
    </div>
  )
}
```

### SliderInput 示例

```typescript
import React, { useState } from 'react'
import { I18nText } from '@/core/types'
import { useI18n } from '@/hooks/useI18n'

interface SliderInputProps {
  value: number
  onChange: (value: number) => void
  label: I18nText
  min: number
  max: number
  step: number
  unit?: string
  marks?: Array<{ value: number; label: string }>
  disabled?: boolean
}

export const SliderInput: React.FC<SliderInputProps> = ({
  value,
  onChange,
  label,
  min,
  max,
  step,
  unit,
  marks,
  disabled = false
}) => {
  const { t } = useI18n()
  const [isDragging, setIsDragging] = useState(false)

  return (
    <div className="param-slider">
      <label>{t(label)}</label>
      <div className="slider-container">
        <input
          type="range"
          min={min}
          max={max}
          step={step}
          value={value}
          onChange={(e) => onChange(Number(e.target.value))}
          onMouseDown={() => setIsDragging(true)}
          onMouseUp={() => setIsDragging(false)}
          disabled={disabled}
          className={isDragging ? 'dragging' : ''}
        />
        <div className="slider-value">
          {value}{unit}
        </div>
      </div>
      {marks && (
        <div className="slider-marks">
          {marks.map(mark => (
            <span key={mark.value} style={{ left: `${(mark.value - min) / (max - min) * 100}%` }}>
              {mark.label}
            </span>
          ))}
        </div>
      )}
    </div>
  )
}
```
