### 2. 面板注册中心 (PanelRegistry.ts)

**文件路径**：`src/core/panels/PanelRegistry.ts`

**代码行数**：94 行

**主要内容**：
- 实现了 `PanelRegistry` 类，使用单例模式管理所有面板组件
- 提供了完整的注册、查询、渲染、注销功能
- 使用 `Map<PanelType, React.ComponentType<any>>` 存储面板组件
- 开发模式下提供详细的警告和错误信息

**核心方法**：
- `register(type, component)`：注册面板组件
- `get(type)`：获取面板组件
- `has(type)`：检查面板是否已注册
- `render(config)`：渲染面板组件
- `listRegistered()`：列出所有已注册的面板类型
- `unregister(type)`：注销面板组件
- `clear()`：清空所有注册的面板

**关键实现**：
```typescript
class PanelRegistry {
  private panels: Map<PanelType, React.ComponentType<any>> = new Map()

  register(type: PanelType, component: React.ComponentType<any>): void {
    if (this.panels.has(type)) {
      if (process.env.NODE_ENV === 'development') {
        console.warn(`Panel type "${type}" is already registered. Overwriting.`)
      }
    }
    this.panels.set(type, component)
  }

  render(config: SpecialPanelConfig): React.ReactNode {
    const Component = this.panels.get(config.type)
    if (!Component) {
      if (process.env.NODE_ENV === 'development') {
        console.error(`Unknown panel type: ${config.type}. Available panels:`, this.listRegistered())
      }
      return null
    }
    return React.createElement(Component, config)
  }
}

export const panelRegistry = new PanelRegistry()
```

**验证规则**：

- 类型特定配置验证：resolution、voice-selector、composite 面板需要 config
- 回调函数类型验证：onChange 必须是函数

**关键实现**：
```typescript
export function validatePanelConfig(config: SpecialPanelConfig): ValidationResult {
  const errors: string[] = []

  if (!config.type) {
    errors.push('Panel type is required')
  }

  if (!config.label) {
    errors.push('Panel label is required')
  }

  if (!config.onChange || typeof config.onChange !== 'function') {
    errors.push('Panel onChange callback is required and must be a function')
  }

  // Type-specific validation
  if (config.type === 'resolution' && !config.config) {
    errors.push('Resolution panel requires config')
  }

  return {
    valid: errors.length === 0,
    errors
  }
}
```

## 技术亮点

### 1. 单例模式
- PanelRegistry 使用单例模式，确保全局只有一个注册中心实例
- 避免了多个实例导致的状态不一致问题

### 2. 类型安全
- 使用 TypeScript 严格类型定义，确保编译时类型检查
- PanelType 使用联合类型，限制可用的面板类型
- SpecialPanelConfig 使用联合类型配置，确保类型安全

### 3. 开发体验优化
- 开发模式下提供详细的警告和错误信息
- 重复注册时给出警告提示
- 未找到面板时列出所有可用面板类型
- 配置验证提供详细的错误列表

### 4. 扩展性设计
- 支持动态注册和注销面板组件
- 支持多种面板类型和配置
- 预留了 custom 类型用于自定义面板
- 支持组合面板（composite）用于复杂场景

### 5. 配置验证
- 提供独立的验证函数，可在注册前验证配置
- 支持类型特定的配置验证
- 返回详细的错误信息列表，便于调试
