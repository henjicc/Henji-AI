**核心逻辑**:
1. **组件值变化处理**: `handleComponentChange` 函数处理子组件值变化并执行联动
2. **组件渲染**: `renderComponent` 函数根据配置渲染子组件
3. **布局样式**: `layoutStyle` 根据配置生成布局样式

**联动处理示例**:
```typescript
const handleComponentChange = useCallback((componentId: string, componentValue: any) => {
  const newValue = { ...value, [componentId]: componentValue }

  // 执行联动
  if (config.linkages) {
    for (const linkage of config.linkages) {
      if (linkage.source === componentId) {
        const targetComponent = config.components.find(c => c.id === linkage.target)
        if (targetComponent) {
          const updatedValue = linkage.handler(
            componentValue,
            targetComponent.config,
            newValue
          )
          newValue[linkage.target] = updatedValue
        }
      }
    }
  }

  onChange(newValue)
}, [value, config.linkages, config.components, onChange])
```

## 技术亮点

### 1. 配置驱动的组件系统

CompositePanel 采用完全配置驱动的设计，通过配置对象即可定义面板的布局、组件和联动关系：

```typescript
const config: CompositePanelConfig = {
  layout: 'vertical',
  gap: 16,
  components: [
    {
      id: 'aspect',
      type: 'aspect-ratio',
      label: { en: 'Aspect Ratio', zh: '画面比例' },
      config: { options: [...] }
    },
    {
      id: 'quality',
      type: 'quality-tier',
      label: { en: 'Quality', zh: '质量' },
      config: { options: [...] }
    }
  ],
  linkages: [
    {
      source: 'aspect',
      target: 'quality',
      effect: 'filter',
      handler: (sourceValue, targetConfig, compositeValue) => {
        // 根据比例过滤质量选项
        return filterQualityOptions(sourceValue, targetConfig)
      }
    }
  ]
}
```

### 2. 单例注册中心模式

ComponentRegistry 采用单例模式，确保全局只有一个组件注册中心实例，避免重复注册和状态不一致：

```typescript
export const componentRegistry = new ComponentRegistry()
```

### 3. 灵活的布局系统

支持三种布局模式，通过配置即可切换：

- **vertical**: 垂直布局，适合表单式界面
- **horizontal**: 水平布局，适合工具栏式界面
- **grid**: 网格布局，适合多列展示

### 4. 强大的组件联动机制

支持 5 种联动效果：

- **filter**: 过滤目标组件的选项
- **reset**: 重置目标组件的值
- **update**: 更新目标组件的值
- **disable**: 禁用目标组件
- **hide**: 隐藏目标组件

### 5. 条件渲染支持

支持基于状态的条件显示和禁用：

```typescript
{
  id: 'custom-size',
  type: 'custom-size',
  showWhen: (value) => value.mode === 'custom',
  disabledWhen: (value) => value.locked === true
}
```

### 6. 组件复用

通过 ComponentRegistry，ResolutionPanel 的子组件可以被 CompositePanel 复用，避免代码重复。
