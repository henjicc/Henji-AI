**文件路径**: `src/core/defineToolNode.ts`

**核心功能**:

```typescript
export function defineToolNode(def: ToolNodeDefinition): ToolNodeDefinition {
  // 验证定义
  if (!def.type) throw new Error('Tool node type is required')
  if (!def.name) throw new Error('Tool node name is required')
  if (!def.execute) throw new Error('Tool node execute function is required')

  // 自动注册
  toolNodeRegistry.register(def)

  return def
}
```

**设计亮点**:
- 自动验证
- 自动注册
- 返回定义便于导出

### 5. 实现文本处理工具节点

#### 5.1 提示词模板节点

**文件路径**: `src/core/tools/text/PromptTemplateNode.ts`

**功能**: 使用模板生成提示词，支持变量替换

**输入端口**:
- template (string) - 模板
- variables (object) - 变量

**输出端口**:
- output (string) - 生成的提示词

**实现逻辑**:
```typescript
execute: (inputs) => {
  const { template, variables = {} } = inputs
  let result = template

  // 简单的变量替换
  for (const [key, value] of Object.entries(variables)) {
    result = result.replace(new RegExp(`{{${key}}}`, 'g'), String(value))
  }

  return { output: result }
}
```

```typescript

console.log('Image processing nodes:', imageNodes)
```

### 执行工具节点

```typescript
import { promptTemplateNode } from '@/core/tools'

// 执行提示词模板节点
const result = promptTemplateNode.execute({
  template: '一个{{subject}}，{{style}}风格',
  variables: {
    subject: '可爱的猫咪',
    style: '卡通'

})

console.log('Generated prompt:', result.output)
// 输出: 一个可爱的猫咪，卡通风格
```
