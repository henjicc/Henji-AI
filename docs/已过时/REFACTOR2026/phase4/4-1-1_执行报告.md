### 2. I18nText 类型定义增强

**文件路径**: `src/core/types/I18nText.ts`

**修改内容**:
- 扩展 `I18nText` 类型支持任意语言
- 增强 `getI18nText` 函数，添加降级策略
- 新增 `TranslateI18nText` 函数类型
- 新增 `isI18nTextObject` 辅助函数

**核心代码**:
```typescript
export type I18nText = string | {
  zh: string
  en: string
  [lang: string]: string  // 支持未来扩展其他语言
}

export type TranslateI18nText = (text: I18nText) => string

export function getI18nText(text: I18nText, locale: string = 'zh'): string {
  if (typeof text === 'string') {
    return text
  }

  // 优先使用指定语言
  if (text[locale]) {
    return text[locale]
  }

  // 降级到中文
  if (text.zh) {
    return text.zh
  }

  // 降级到英文
  if (text.en) {
    return text.en
  }

  // 返回第一个可用的值
  const firstKey = Object.keys(text)[0]
  return text[firstKey] || ''
}
```

const tText = (text: I18nText): string => {

    return text

  const lang = i18n.language

  if (text[lang]) {

## 技术亮点

### 1. 命名空间组织

**设计思路**:
- 按功能模块划分命名空间（common、models、params、errors）
- 避免单个翻译文件过大
- 便于按需加载和维护

**优势**:
- 清晰的文件组织结构
- 易于查找和修改翻译
- 支持未来扩展更多命名空间

### 2. 降级策略

**多层降级机制**:
```
当前语言 → 中文 (zh) → 英文 (en) → 第一个可用值 → 空字符串
```

**优势**:
- 确保始终有可显示的文本
- 避免显示翻译 key
- 提供良好的用户体验

### 3. I18nText 类型灵活性

**支持两种使用方式**:
1. 直接字符串: `"确定"`
2. 多语言对象: `{ zh: "确定", en: "Confirm" }`

**优势**:
- 向后兼容现有代码
- 渐进式迁移
- 灵活适应不同场景

### 4. 语言持久化

**实现方式**:
- 使用 localStorage 存储语言选择
- 键名: `henji-language`
- 自动检测顺序: localStorage → 浏览器语言

**优势**:
- 用户选择持久化
- 下次启动自动恢复
- 良好的用户体验
