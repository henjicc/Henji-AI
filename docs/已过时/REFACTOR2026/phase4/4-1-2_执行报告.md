### 2. 更新 i18n 配置

**文件路径**: `src/i18n/config.ts`

**修改内容**:
- 添加新命名空间的导入语句
- 更新 resources 对象，包含新的翻译资源
- 更新 ns 配置，添加 'ui', 'history', 'settings'

**关键代码**:
```typescript
import zhCN_ui from './locales/zh-CN/ui.json'
import zhCN_history from './locales/zh-CN/history.json'
import zhCN_settings from './locales/zh-CN/settings.json'

const resources = {
  'zh-CN': {
    common: zhCN_common,
    models: zhCN_models,
    params: zhCN_params,
    errors: zhCN_errors,
    ui: zhCN_ui,
    history: zhCN_history,
    settings: zhCN_settings,
  },
  // ... en-US 同理
}

i18n.init({
  ns: ['common', 'models', 'params', 'errors', 'ui', 'history', 'settings'],
  // ...
})
```

### 3. 抽取示例组件文本

**组件**: CustomModelManager

**文件路径**: `src/components/CustomModels/CustomModelManager.tsx`

**修改内容**:
1. 导入 useI18n Hook
2. 使用 t 函数替换所有硬编码中文文本
3. 保持组件逻辑不变

**修改前**:
```typescript
export function CustomModelManager() {
  // ...
  return (
    <div className="p-4">
      <h2 className="text-xl font-bold">自定义模型管理</h2>
      <button>添加模型</button>
      <p>还没有添加自定义模型</p>
    </div>
  )
}
```

**修改后**:
```typescript
import { useI18n } from '@/hooks/useI18n'

export function CustomModelManager() {
  const { t } = useI18n('ui')
  // ...
  return (
    <div className="p-4">
      <h2 className="text-xl font-bold">{t('customModels.title')}</h2>
      <button>{t('customModels.add')}</button>
      <p>{t('customModels.empty')}</p>
    </div>
  )
}
```

## MVP 范围说明

### 为什么选择 MVP 方式

Phase 4-1-2 的完整任务涉及：
- 扫描所有组件文件（数百个文件）
- 抽取所有硬编码中文文本
- 修改大量组件
- 添加完整的英文翻译

**风险**:
- 一次性修改过多文件容易引入 Bug
- 翻译工作量巨大
- 难以验证和测试

**MVP 策略**:
- ✅ 创建必要的翻译文件结构
- ✅ 抽取 1 个示例组件作为参考
- ✅ 验证 i18n 系统在实际组件中的工作情况
- ✅ 建立文本抽取的标准流程
