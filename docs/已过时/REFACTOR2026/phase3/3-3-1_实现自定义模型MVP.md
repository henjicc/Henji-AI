# 3-3-1 实现自定义模型 MVP

## 目标

实现自定义模型管理的 MVP（最小可行产品），允许用户添加 ModelScope 平台的自定义模型，使用简化配置模板。

## 背景

### 当前问题

当前系统存在 `ModelscopeCustomModelManager.tsx`，但功能有限：
1. 只支持 ModelScope 平台
2. 参数配置不够灵活
3. 与新架构未集成
4. 存储在内存中，刷新丢失

### 新架构方案

**MVP 阶段目标**（Phase 3）：
- 简化版配置（固定模板）
- 只支持 ModelScope 平台
- 存储到 SQLite 数据库
- 与 ModelRegistry 集成

**核心功能**：
1. 添加自定义模型（输入 ModelScope URL）
2. 自动获取模型信息
3. 使用固定参数模板
4. 动态注册到系统
5. 启用/禁用管理

**延后功能**（Phase 2/3）：
- 可视化参数配置 UI
- 支持更多平台（Fal、Hugging Face）
- 完整的 YAML/JSON 配置导入
- 参数验证和测试

### 步骤 2: 实现 ModelScope API 客户端

**文件**: `src/services/modelscope/ModelscopeApiClient.ts`

```typescript
/**
 * ModelScope API 客户端
 */
export class ModelscopeApiClient {
  private static BASE_URL = 'https://modelscope.cn/api/v1'

  /**
   * 从 URL 提取模型 ID
   *
   * @example
   * extractModelId('https://modelscope.cn/models/iic/cv_unet_person-image-cartoon')
   * // => 'iic/cv_unet_person-image-cartoon'
   */
  static extractModelId(url: string): string | null {
    const patterns = [
      /modelscope\.cn\/models\/([^\/]+\/[^\/\?#]+)/,
      /^([^\/]+\/[^\/]+)$/  // 直接输入 owner/model 格式
    ]

    for (const pattern of patterns) {
      const match = url.match(pattern)
      if (match) {
        return match[1]
      }
    }

    return null
  }

  /**
   * 获取模型信息
   */
  static async getModelInfo(modelId: string): Promise<ModelscopeModelInfo> {
    try {
      // 注意：ModelScope API 可能需要认证，这里简化处理
      const response = await fetch(`${this.BASE_URL}/models/${modelId}`)

      if (!response.ok) {
        throw new Error(`Failed to fetch model info: ${response.statusText}`)
      }

      const data = await response.json()

      // 解析模型类型（从标签推断）
      const type = this.inferModelType(data.tags || [])

      return {
        id: modelId,
        name: data.name || modelId,
        type,
        description: data.description,
        owner: data.owner,
        tags: data.tags
      }
    } catch (error) {
      console.error('Failed to fetch model info:', error)
      // 降级：返回基本信息
      return {
        id: modelId,
        name: modelId.split('/')[1] || modelId,
        type: 'image'  // 默认为图片
      }
    }
  }

  /**
   * 从标签推断模型类型
   */
  private static inferModelType(tags: string[]): 'image' | 'video' | 'audio' {
    const lowerTags = tags.map(t => t.toLowerCase())

    if (lowerTags.some(t => t.includes('video') || t.includes('vid'))) {
      return 'video'
    }
    if (lowerTags.some(t => t.includes('audio') || t.includes('sound') || t.includes('tts'))) {
      return 'audio'
    }
    return 'image'  // 默认
  }

  /**
   * 验证模型是否可访问
   */
  static async validateModel(modelId: string): Promise<boolean> {
    try {
      const info = await this.getModelInfo(modelId)
      return !!info.id
    } catch (error) {
      return false
    }
  }
}
```

### 步骤 4: 实现自定义模型服务

**文件**: `src/services/customModels/CustomModelService.ts`

```typescript
import { nanoid } from 'nanoid'
import { CustomModel, AddCustomModelInput } from '@/core/types/CustomModel'
import { DatabaseService } from '../database/DatabaseService'
import { ModelscopeApiClient } from '../modelscope/ModelscopeApiClient'
import { createModelscopeTemplate } from './templates/modelscopeTemplate'
import { registry } from '@/core/ModelRegistry'

/**
 * 自定义模型管理服务
 */
export class CustomModelService {
  private db: DatabaseService

  constructor(database: DatabaseService) {
    this.db = database
  }

  /**
   * 添加自定义模型
   */
  async addCustomModel(input: AddCustomModelInput): Promise<CustomModel> {
    // 1. 提取模型 ID
    const modelId = ModelscopeApiClient.extractModelId(input.modelscopeUrl)
    if (!modelId) {
      throw new Error('Invalid ModelScope URL or model ID')
    }

    // 2. 获取模型信息
    const modelInfo = await ModelscopeApiClient.getModelInfo(modelId)

    // 3. 创建配置（使用模板）
    const config = createModelscopeTemplate(modelInfo)

    // 4. 创建自定义模型记录
    const customModel: CustomModel = {
      id: `custom-${nanoid()}`,
      name: input.customName || modelInfo.name,
      providerId: 'modelscope',
      baseModel: modelId,
      config,
      isEnabled: input.enableImmediately !== false,
      createdAt: new Date().toISOString(),
      updatedAt: new Date().toISOString()
    }

    // 5. 保存到数据库
    await this.db.insertCustomModel(customModel)

    // 6. 如果启用，注册到 ModelRegistry
    if (customModel.isEnabled) {
      this.registerToRegistry(customModel)
    }

    return customModel
  }

  /**
   * 获取所有自定义模型
   */
  async getCustomModels(): Promise<CustomModel[]> {
    return await this.db.getCustomModels()
  }

  /**
   * 获取单个自定义模型
   */
  async getCustomModelById(id: string): Promise<CustomModel | null> {
    return await this.db.getCustomModelById(id)
  }

  /**
   * 更新自定义模型
   */
  async updateCustomModel(
    id: string,
    updates: Partial<CustomModel>
  ): Promise<void> {
    await this.db.updateCustomModel(id, updates)

    // 如果修改了 isEnabled，需要同步 Registry
    if ('isEnabled' in updates) {
      const model = await this.getCustomModelById(id)
      if (model) {
        if (model.isEnabled) {
          this.registerToRegistry(model)
        } else {
          this.unregisterFromRegistry(model)
        }
      }
    }
  }

  /**
   * 删除自定义模型
   */
  async deleteCustomModel(id: string): Promise<void> {
    const model = await this.getCustomModelById(id)
    if (model) {
      // 从 Registry 注销
      this.unregisterFromRegistry(model)
    }

    await this.db.deleteCustomModel(id)
  }

  /**
   * 启用自定义模型
   */
  async enableCustomModel(id: string): Promise<void> {
    await this.updateCustomModel(id, { isEnabled: true })
  }

  /**
   * 禁用自定义模型
   */
  async disableCustomModel(id: string): Promise<void> {
    await this.updateCustomModel(id, { isEnabled: false })
  }

  /**
   * 加载所有启用的自定义模型到 Registry
   */
  async loadEnabledModels(): Promise<void> {
    const models = await this.getCustomModels()
    for (const model of models) {
      if (model.isEnabled) {
        this.registerToRegistry(model)
      }
    }
  }

  /**
   * 注册到 ModelRegistry
   */
  private registerToRegistry(customModel: CustomModel): void {
    const modelDef = this.convertToModelDefinition(customModel)
    registry.register(modelDef)
    console.log(`Registered custom model: ${customModel.id}`)
  }

  /**
   * 从 ModelRegistry 注销
   */
  private unregisterFromRegistry(customModel: CustomModel): void {
    registry.unregister(customModel.id)
    console.log(`Unregistered custom model: ${customModel.id}`)
  }

  /**
   * 转换为 ModelDefinition 格式
   */
  private convertToModelDefinition(customModel: CustomModel): any {
    return {
      meta: {
        id: customModel.id,
        provider: customModel.providerId,
        type: customModel.config.meta.type,
        name: { zh: customModel.name, en: customModel.name },
        description: customModel.config.meta.description
          ? { zh: customModel.config.meta.description, en: customModel.config.meta.description }
          : undefined,
        icon: customModel.config.meta.icon,
        tags: ['custom']
      },
      params: customModel.config.params,
      linkages: [],
      endpoints: customModel.config.endpoints,
      pricing: customModel.config.pricing
    }
  }
}

// 单例导出
let customModelServiceInstance: CustomModelService | null = null

export function getCustomModelService(db: DatabaseService): CustomModelService {
  if (!customModelServiceInstance) {
    customModelServiceInstance = new CustomModelService(db)
  }
  return customModelServiceInstance
}
```

```typescript
import React, { useState, useEffect } from 'react'
import { CustomModel } from '@/core/types/CustomModel'
import { getCustomModelService } from '@/services/customModels/CustomModelService'
import { getDatabaseService } from '@/services/database/DatabaseService'
import { AddCustomModelDialog } from './AddCustomModelDialog'

export function CustomModelManager() {
  const [models, setModels] = useState<CustomModel[]>([])
  const [loading, setLoading] = useState(true)
  const [showAddDialog, setShowAddDialog] = useState(false)

  const service = getCustomModelService(getDatabaseService())

  useEffect(() => {
    loadModels()
  }, [])

  const loadModels = async () => {
    setLoading(true)
    try {
      const data = await service.getCustomModels()
      setModels(data)
    } catch (error) {
      console.error('Failed to load custom models:', error)
    } finally {
      setLoading(false)
    }
  }

  const handleAdd = async (url: string, customName?: string) => {
    try {
      await service.addCustomModel({
        modelscopeUrl: url,
        customName,
        enableImmediately: true
      })
      await loadModels()
      setShowAddDialog(false)
    } catch (error) {
      console.error('Failed to add custom model:', error)
      alert('添加模型失败：' + (error as Error).message)
    }
  }

  const handleToggle = async (id: string, enabled: boolean) => {
    try {
      if (enabled) {
        await service.enableCustomModel(id)
      } else {
        await service.disableCustomModel(id)
      }
      await loadModels()
    } catch (error) {
      console.error('Failed to toggle model:', error)
    }
  }

  const handleDelete = async (id: string) => {
    if (!confirm('确定要删除此自定义模型吗？')) {
      return
    }

    try {
      await service.deleteCustomModel(id)
      await loadModels()
    } catch (error) {
      console.error('Failed to delete model:', error)
    }
  }

  if (loading) {
    return <div className="loading">加载中...</div>
  }

  return (
    <div className="custom-model-manager">
      <div className="header">
        <h2>自定义模型管理</h2>
        <button onClick={() => setShowAddDialog(true)}>
          + 添加 ModelScope 模型
        </button>
      </div>

      <div className="model-list">
        {models.length === 0 ? (
          <div className="empty-state">
            <p>还没有添加自定义模型</p>
            <p className="hint">
              你可以添加 ModelScope 平台上的任何模型，只需提供模型 URL
            </p>
          </div>
        ) : (
          models.map(model => (
            <div key={model.id} className="model-item">
              <div className="model-info">
                <h3>{model.name}</h3>
                <p className="model-id">{model.baseModel}</p>
                <span className="model-type">{model.config.meta.type}</span>
                {model.config.meta.description && (
                  <p className="description">{model.config.meta.description}</p>
                )}
              </div>

              <div className="model-actions">
                <label className="toggle">
                  <input
                    type="checkbox"
                    checked={model.isEnabled}
                    onChange={e => handleToggle(model.id, e.target.checked)}
                  />
                  <span>{model.isEnabled ? '已启用' : '已禁用'}</span>
                </label>

                <button
                  className="delete-btn"
                  onClick={() => handleDelete(model.id)}
                >
                  删除
                </button>
              </div>
            </div>
          ))
        )}
      </div>

      {showAddDialog && (
        <AddCustomModelDialog
          onAdd={handleAdd}
          onClose={() => setShowAddDialog(false)}
        />
      )}
    </div>
  )
}
```

### 步骤 6: 实现添加模型对话框

```typescript
import React, { useState } from 'react'
import { ModelscopeApiClient } from '@/services/modelscope/ModelscopeApiClient'

interface AddCustomModelDialogProps {
  onAdd: (url: string, customName?: string) => Promise<void>
  onClose: () => void
}

export function AddCustomModelDialog({ onAdd, onClose }: AddCustomModelDialogProps) {
  const [url, setUrl] = useState('')
  const [customName, setCustomName] = useState('')
  const [validating, setValidating] = useState(false)
  const [isValid, setIsValid] = useState<boolean | null>(null)

  const handleValidate = async () => {
    const modelId = ModelscopeApiClient.extractModelId(url)
    if (!modelId) {
      setIsValid(false)
      return
    }

    setValidating(true)
    try {
      const valid = await ModelscopeApiClient.validateModel(modelId)
      setIsValid(valid)
    } catch (error) {
      setIsValid(false)
    } finally {
      setValidating(false)
    }
  }

  const handleSubmit = async () => {
    await onAdd(url, customName || undefined)
  }

  return (
    <div className="add-custom-model-dialog">
      <div className="dialog-overlay" onClick={onClose} />

      <div className="dialog-content">
        <h3>添加 ModelScope 模型</h3>

        <div className="form-group">
          <label>模型 URL 或 ID</label>
          <input
            type="text"
            value={url}
            onChange={e => {
              setUrl(e.target.value)
              setIsValid(null)
            }}
            placeholder="https://modelscope.cn/models/owner/model-name"
          />
          <button
            onClick={handleValidate}
            disabled={!url || validating}
            className="validate-btn"
          >
            {validating ? '验证中...' : '验证模型'}
          </button>
          {isValid === false && (
            <p className="error">无法访问此模型，请检查 URL 是否正确</p>
          )}
          {isValid === true && (
            <p className="success">✓ 模型验证成功</p>
          )}
        </div>

        <div className="form-group">
          <label>自定义名称（可选）</label>
          <input
            type="text"
            value={customName}
            onChange={e => setCustomName(e.target.value)}
            placeholder="留空则使用模型原始名称"
          />
        </div>

        <div className="help-section">
          <h4>如何使用？</h4>
          <ol>
            <li>访问 <a href="https://modelscope.cn" target="_blank">ModelScope 平台</a></li>
            <li>找到你想使用的模型</li>
            <li>复制模型页面的 URL</li>
            <li>粘贴到上方输入框</li>
          </ol>
          <p className="note">
            <strong>注意</strong>：目前只支持图片、视频、音频生成类模型
          </p>
        </div>

        <div className="dialog-actions">
          <button onClick={onClose}>取消</button>
          <button
            onClick={handleSubmit}
            disabled={!url || isValid !== true}
          >
            添加模型
          </button>
        </div>
      </div>
    </div>
  )
}
```

## 风险与注意事项

### 风险

1. **ModelScope API 不稳定**
   - API 可能需要认证
   - API 格式可能变化
   - 缓解：降级处理，使用默认值

2. **模型兼容性**
   - 并非所有模型都适合生成任务
   - 参数模板可能不匹配
   - 缓解：提供验证和错误提示

3. **性能问题**
   - 加载大量自定义模型可能影响启动速度
   - 缓解：异步加载，延迟注册

### 注意事项

1. **用户体验**
   - 提供清晰的添加流程指引
   - 验证模型可访问性
   - 显示模型信息预览

2. **数据安全**
   - 自定义模型配置存储在数据库
   - 删除模型时同时清理相关数据

3. **错误处理**
   - 网络错误友好提示
   - 模型加载失败不影响应用启动
   - 提供详细的错误日志

4. **限制说明**
   - MVP 阶段功能有限
   - 明确告知用户当前限制
   - 提供反馈渠道

## 回滚方案

如果自定义模型功能出现问题：

1. **禁用自定义模型加载**
   ```typescript
   // src/App.tsx
   // 注释掉加载逻辑
   // await service.loadEnabledModels()
   ```

2. **清空自定义模型表**
   ```sql
   DELETE FROM custom_models;
   ```

3. **从 Registry 移除**
   ```typescript
   const allModels = registry.getAllModels()
   for (const model of allModels) {
     if (model.meta.id.startsWith('custom-')) {
       registry.unregister(model.meta.id)
     }
   }
   ```

4. **删除相关文件**
   - 删除 `src/services/customModels/` 目录
   - 删除 `src/components/CustomModels/` 目录
   - 恢复旧的 `ModelscopeCustomModelManager.tsx`
