## 技术亮点

### 1. Base64 数据完全隔离

**问题**: 旧系统的 `history.json` 可能包含大量 Base64 数据，导致文件膨胀到数十 MB。

**解决方案**:
- 数据库表中完全不存储 Base64/URL 数据
- 只存储相对文件路径
- 迁移时强制过滤 Base64 数据

**预期效果**:
- 文件大小从 50 MB 减少到 500 KB
- 空间节省 99%

### 2. 全文搜索支持

使用 SQLite FTS5 实现高效的提示词搜索：

```sql
CREATE VIRTUAL TABLE IF NOT EXISTS history_fts USING fts5(
  id UNINDEXED,
  prompt,
  content=history,
  content_rowid=rowid
);
```

**优势**:
- 支持中文分词
- 搜索速度快（毫秒级）
- 自动同步（通过触发器）

### 3. 自动时间戳更新

使用触发器自动更新 `updated_at` 字段：

```sql
CREATE TRIGGER IF NOT EXISTS update_history_timestamp
  AFTER UPDATE ON history
BEGIN
  UPDATE history SET updated_at = CURRENT_TIMESTAMP WHERE id = NEW.id;
END;
```

**优势**:
- 无需手动维护
- 保证数据一致性
- 减少代码复杂度

### 4. 灵活的预设系统

支持两种预设类型：

```sql
model_id TEXT,  -- NULL = 全局预设，非 NULL = 模型级预设
```

**查询示例**:
```typescript
// 获取全局预设
getPresets({ modelId: null })

// 获取特定模型的预设（包括全局预设）
getPresets({ modelId: 'wan-2.6' })
```

### 5. 完整的类型安全

TypeScript 类型定义与 SQL schema 完全对应：

```typescript
// SQL: provider_id TEXT NOT NULL
// TypeScript: providerId: string

// SQL: is_favorite INTEGER DEFAULT 0
// TypeScript: isFavorite: boolean

// SQL: params TEXT (JSON)
// TypeScript: params: Record<string, any>
```
