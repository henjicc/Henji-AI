### 2. ModelScope 自定义模型模板 (modelscopeTemplate.ts)

**文件路径**: `src/services/customModels/templates/modelscopeTemplate.ts`

**代码行数**: ~95 行

**核心功能**:
- 为 ModelScope 模型生成标准配置
- 根据模型类型（image/video/audio）自动添加参数
- 提供默认的参数定义（prompt、negativePrompt、width、height 等）

**关键实现**:
```typescript
export function createModelscopeCustomModelConfig(
  modelId: string,
  modelName: string,
  modelUrl: string,
  type: 'image' | 'video' | 'audio'
): CustomModelConfig {
  const baseParams: ParamDefinition[] = [
    { id: 'prompt', label: '提示词', type: 'textarea', ... },
    { id: 'negativePrompt', label: '负面提示词', type: 'textarea', ... }
  ]

  if (type === 'image') {
    baseParams.push(
      { id: 'width', label: '宽度', type: 'number', ... },
      { id: 'height', label: '高度', type: 'number', ... }
    )
  }

  return { meta, params: baseParams, endpoints, request, pricing }
}
```

**优势**:
- 模板化配置生成
- 易于扩展到其他 provider
- 自动适配不同模型类型

## 技术亮点

### 1. MVP 设计原则

**最小可行产品特点**:
- ✅ 只支持 ModelScope 平台（最常用）
- ✅ 只支持 image 类型（最基础）
- ✅ 使用模板化配置（简化用户操作）
- ✅ 基础 CRUD 功能完整

**优势**:
- 快速实现，验证可行性
- 易于扩展到其他平台和类型
- 用户体验简单直观

### 2. 模板化配置生成

**问题**: 用户不熟悉模型配置格式

**解决方案**: 提供 ModelScope 模板
```typescript
createModelscopeCustomModelConfig(id, name, url, type)
// 自动生成完整的 ModelDefinition 兼容配置
```

**优势**:
- 用户只需提供 URL 和名称
- 自动生成标准参数（prompt、width、height 等）
- 配置格式与内置模型一致

### 3. 与 ModelRegistry 无缝集成

**集成流程**:
```
用户添加模型 → 保存到数据库 → 注册到 Registry → 立即可用
应用启动 → 加载启用的模型 → 注册到 Registry → 自动可用
```

**优势**:
- 自定义模型与内置模型使用相同的 API
- 无需修改现有代码即可支持自定义模型
- 启用/禁用实时生效

### 4. 数据库层与业务层解耦

**设计思路**:
- CustomModelRecord: 数据库层类型
- CustomModel: 业务层类型
- convertToCustomModel: 转换方法

**优势**:
- 数据库结构变化不影响业务逻辑
- 业务需求变化不影响数据库设计
- 易于维护和扩展
