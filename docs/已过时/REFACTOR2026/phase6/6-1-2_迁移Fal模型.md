# Phase 6-1-2: Fal Models Migration Plan

## 执行概况

**目标**: 迁移 17 个 Fal 模型到新的统一 `.model.ts` 配置系统

## 模型清单

### 图片模型 (4个)
1. Z-Image Turbo - 简单
2. Nano Banana - 简单
3. Nano Banana Pro - 简单
4. Kling Image O1 - 中等

### 视频模型 (13个)

6. Seedream V4.5 - 简单
7. Seedance - 中等
8. Kling Video O1 - 复杂
9. Kling Video V2.6 Pro - 复杂
10. Hailuo 2.3 - 中等

12. PixVerse V5.5 - 中等

15. LTX 2 - 中等

## 迁移策略

按复杂度从简单到复杂依次迁移，先完成图片模型，再完成视频模型。

## 执行步骤

1. 创建 Fal 模型目录和工具函数
2. 迁移简单图片模型（Z-Image, Nano Banana）
3. 迁移 Seedream 系列
4. 迁移 Kling 系列
5. 迁移 Hailuo 系列
6. 迁移其他视频模型
7. 验证编译
8. 更新执行报告
