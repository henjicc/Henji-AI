## 迁移模式总结

### Pattern 1: AutoSwitch → AutoSwitchLinkage

**旧模式**:
```typescript
autoSwitch: {
  watchKeys: ['uploadedImages'],
  condition: (values) => values.uploadedImages?.length > 0,
  value: 'smart'
}
```

**新模式**:
```typescript
{
  trigger: 'uploadedImages',
  effect: 'autoSwitch',
  target: 'aspectRatio',
  condition: (images, allParams) => images?.length > 0,
  value: 'smart'
}
```

### Pattern 2: hidden → HideLinkage

**旧模式**:
```typescript
hidden: (values) => values.mode === 'video-edit'
```

**新模式**:
```typescript
{
  trigger: 'mode',
  effect: 'hide',
  targets: ['duration'],
  condition: (mode) => mode === 'video-edit'
}
```

### Pattern 3: Dynamic Options → FilterOptionsLinkage

**旧模式**:
```typescript
options: (values) => {
  if (values.mode === 'reference-to-video') {
    return [{ value: 5, label: '5s' }, { value: 10, label: '10s' }]
  }
  return [{ value: 5, label: '5s' }, { value: 10, label: '10s' }, { value: 15, label: '15s' }]
}
```

**新模式**:
```typescript
// In params: static options
options: [
  { value: 5, label: '5s' },
  { value: 10, label: '10s' },
  { value: 15, label: '15s' }
]

// In linkages: filter
{
  trigger: 'mode',
  effect: 'filterOptions',
  target: 'duration',
  filter: (mode, options) => {
    if (mode === 'reference-to-video') {
      return options.filter(o => o.value <= 10)
    }
    return options
  }
}
```

## 技术亮点

### 1. 复杂联动系统
Kling O1 模型实现了 6 条 AutoSwitch 规则，包括：
