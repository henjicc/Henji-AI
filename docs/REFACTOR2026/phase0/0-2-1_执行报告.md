### 2. `src/core/tags.ts`

**功能：** 标签查询工具函数

**提供的API：**

| 函数 | 功能 | 示例 |
|------|------|------|
| `hasTag(modelId, tag)` | 检查模型是否有某标签 | `hasTag('nano-banana', 'supports-image-editing')` |
| `hasAnyTag(modelId, tags)` | 检查模型是否有任一标签 | `hasAnyTag('vidu-q1', ['text-to-video', 'image-to-video'])` |
| `hasAllTags(modelId, tags)` | 检查模型是否有所有标签 | `hasAllTags('kling-o1', ['text-to-video', 'supports-start-end-frame'])` |
| `getModelTags(modelId)` | 获取模型的所有标签 | `getModelTags('nano-banana')` |
| `getModelsByTag(tag)` | 获取有指定标签的所有模型 | `getModelsByTag('supports-image-editing')` |
| `getModelsByAnyTag(tags)` | 获取有任一标签的所有模型 | `getModelsByAnyTag(['text-to-video', 'image-to-video'])` |
| `getModelsByAllTags(tags)` | 获取有所有标签的模型 | `getModelsByAllTags(['text-to-video', 'supports-audio-generation'])` |
| `clearTagsCache()` | 清除标签缓存 | `clearTagsCache()` |

**使用示例：**

```typescript
import { hasTag, getModelsByTag } from '@/core/tags'

// 检查模型是否支持图片编辑
if (hasTag(selectedModel, 'supports-image-editing')) {
  // 显示图片上传组件
}

// 获取所有支持图片编辑的模型
const editableModels = getModelsByTag('supports-image-editing')
```

## 七、风险与注意事项

### 1. 模型别名问题

**问题：** 许多模型有多个别名（如 `nano-banana` 和 `fal-ai-nano-banana`）

**解决方案：**
- 在 providers.json 中只保留一个主ID
- 在代码中统一使用主ID
- 或者为每个别名都配置相同的标签

### 2. Mode 参数依赖

**问题：** 部分判断依赖于 mode 参数（如 `vidu-q1` 的 `viduMode`）

**解决方案：**
- 在模型定义中明确支持的 modes
- 每个 mode 可能需要不同的标签配置
- 建议：mode 参数也纳入标签系统或配置系统

### 3. 动态行为

**问题：** 部分模型的行为依赖于运行时状态（如快速模式、分辨率）

**解决方案：**
- 标签系统支持条件标签
- 或者在运行时动态计算标签
- 或者将动态行为移到配置系统中
