## 四、注意事项

### 1. 模型别名问题

许多模型有多个别名（如 `nano-banana` 和 `fal-ai-nano-banana`），需要确保：
- providers.json 中只保留一个主ID
- 标签系统支持别名映射
- 或者在 providers.json 中为每个别名都配置标签

### 2. Mode 参数依赖

部分判断依赖于 mode 参数（如 `vidu-q1` 的 `viduMode`），需要：
- 在模型定义中明确支持的 modes
- 每个 mode 可能需要不同的标签
- 建议：mode 参数也纳入标签系统

### 3. 动态行为

部分模型的行为依赖于运行时状态（如快速模式、分辨率），需要：
- 标签系统支持条件标签
- 或者在运行时动态计算标签
