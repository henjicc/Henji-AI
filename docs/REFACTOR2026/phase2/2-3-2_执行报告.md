### 1. ParamsPanel 组件 (ParamsPanel.tsx)

**文件路径**: `src/components/params/ParamsPanel.tsx`

**代码行数**: 约 70 行

**主要功能**:
- 根据 modelId 自动加载参数 schema
- 使用 useModelParams Hook 管理参数状态
- 使用 ParamRenderer 渲染每个参数
- 按 order 字段排序显示参数
- 提供统一的布局和样式
- 通过 ref 暴露参数操作方法

**核心实现**:

#### 1.1 参数加载和状态管理

```typescript
export const ParamsPanel = forwardRef<ParamsPanelRef, ParamsPanelProps>(
  ({ modelId, onChange, className }, ref) => {
    // 使用 useModelParams 管理状态
    const {
      params,
      setParam,
      resetParams,
      getFilteredOptions,
      schema
    } = useModelParams(modelId)

    // 暴露方法给父组件
    useImperativeHandle(ref, () => ({
      getParams: () => params,
      resetParams,
      setParam
    }), [params, resetParams, setParam])

    // 参数变化时通知父组件
    useEffect(() => {
      onChange?.(params)
    }, [params, onChange])

    // ...
  }
)
```

#### 1.2 参数排序

```typescript
const sortedSchema = useMemo(() => {
  return [...schema].sort((a, b) => {
    const orderA = a.order ?? Number.MAX_SAFE_INTEGER
    const orderB = b.order ?? Number.MAX_SAFE_INTEGER
    return orderA - orderB
  })
}, [schema])
```

#### 1.3 参数渲染

```typescript
return (
  <div className={`params-panel ${className || ''}`}>
    {sortedSchema.map(paramDef => (
      <ParamRenderer
        key={paramDef.id}
        paramDef={paramDef}
        value={params[paramDef.id]}
        onChange={(value) => setParam(paramDef.id, value)}
        allParams={params}
        getFilteredOptions={getFilteredOptions}
      />
    ))}
  </div>
)
```

## 技术亮点

### 1. 完全自动化的参数渲染

只需提供 modelId，ParamsPanel 自动完成所有工作：

```typescript
// 使用非常简单
<ParamsPanel modelId="nano-banana" onChange={handleChange} />

// 自动完成：
// 1. 从 ModelRegistry 加载参数 schema
// 2. 提取默认值并初始化状态
// 3. 按 order 排序参数
// 4. 渲染所有参数 UI
// 5. 处理参数联动
// 6. 通知父组件参数变化
```

### 2. 集成 useModelParams Hook

充分利用 useModelParams 的强大功能：

```typescript
const {
  params,           // 当前参数值
  setParam,         // 设置单个参数
  resetParams,      // 重置所有参数
  getFilteredOptions, // 获取过滤后的选项（联动）
  schema            // 参数 schema
} = useModelParams(modelId)
```

### 3. 通过 ref 暴露操作方法

父组件可以通过 ref 访问参数操作方法：

```typescript
const paramsPanelRef = useRef<ParamsPanelRef>(null)

// 获取当前参数值
const params = paramsPanelRef.current?.getParams()

// 重置参数
paramsPanelRef.current?.resetParams()

// 设置单个参数
paramsPanelRef.current?.setParam('prompt', 'new value')
```


### 4. 响应式网格布局

自动适配不同屏幕尺寸：

```css
/* 桌面端：自动填充，每列最小 300px */
.params-panel {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(300px, 1fr));
  gap: 16px;
}

/* 移动端：单列布局 */
@media (max-width: 768px) {
  .params-panel {
    grid-template-columns: 1fr;
  }
}
```

### 示例 2: 使用 ref 操作参数

```typescript
function VideoGenerator() {
  const paramsPanelRef = useRef<ParamsPanelRef>(null)

  const handleGenerate = () => {
    const params = paramsPanelRef.current?.getParams()
    console.log('生成参数:', params)
    // 调用 API 生成视频
  }

  const handleReset = () => {
    paramsPanelRef.current?.resetParams()
  }

  return (
    <>
      <ParamsPanel 
        ref={paramsPanelRef}
        modelId="wan-2.6"
      />
      <button onClick={handleGenerate}>生成</button>
      <button onClick={handleReset}>重置</button>
    </>
  )
}
```
