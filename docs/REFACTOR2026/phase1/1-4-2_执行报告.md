### 1. 创建端点选择器

**文件路径**: `src/core/request/EndpointSelector.ts`

**核心功能**:

#### 1.1 EndpointSelector 类

```typescript
export class EndpointSelector {
  constructor(private config: EndpointConfig)

  select(params: Record<string, any>, context: SelectContext): SelectResult

  private selectEndpoint(params, context): string
  private evaluateCondition(condition, params, context): boolean
  private getRoute(endpointKey): RouteDefinition | undefined
}
```

**特点**:
- 支持三种选择方式（单端点、函数选择器、规则选择器）
- 安全的条件表达式求值
- 清晰的错误提示

#### 1.2 核心方法

**`select()` - 选择端点**:

**执行流程**:
1. 调用 selectEndpoint 获取端点键
2. 调用 getRoute 获取路由定义
3. 返回选择结果（endpoint + route）

**`selectEndpoint()` - 选择端点键**:

**支持三种方式**:
1. **单端点简化配置**: `{ default: '/api/generate' }`
2. **函数选择器**: `{ select: (params, context) => 'endpoint-name' }`
3. **规则选择器**: `{ select: { rules: [...] } }`

**`evaluateCondition()` - 求值条件表达式**:

**功能**:
- 使用 Function 构造函数创建求值环境
- 使用 with 语句允许直接访问 params 和 context 属性
- 捕获异常并返回 false

**安全性**:
- 仅在受信任的模型定义中使用
- 条件表达式应简单明了
- 异常时返回 false，不中断流程

**`getRoute()` - 获取路由定义**:

**支持两种配置**:
- 单端点：返回 `{ path: config.default, method: 'POST' }`
- 多端点：从 `config.routes[endpointKey]` 获取

### 3. 使用示例

```typescript
    ]
```

```typescript
}
```

**优势**:
- 简单场景用简化配置
- 复杂逻辑用函数选择器
- 声明式规则易于维护

#### 6.2 安全的条件求值

使用 Function 构造函数创建隔离的求值环境：

```typescript
const fn = new Function('params', 'context', `
  with (params) {
    with (context) {
      return ${condition}
    }
  }
`)
return Boolean(fn(params, context))
```

**优势**:
- 支持简洁的条件表达式
- 异常时返回 false，不中断流程
- 仅用于受信任的模型定义
