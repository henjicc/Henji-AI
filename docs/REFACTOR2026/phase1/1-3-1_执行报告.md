## 执行内容

### 1. 创建参数工具函数

**文件路径**: `src/hooks/utils/paramUtils.ts`

**核心功能**:

#### 1.1 `setNestedValue()`
使用不可变更新方式设置嵌套对象的值：
```typescript
const obj = { resolution: { quality: '1080P' } }
const newObj = setNestedValue(obj, 'resolution.quality', '4K')
// newObj = { resolution: { quality: '4K' } }
// obj 保持不变
```

**特点**:
- 支持点分隔的嵌套路径（如 'resolution.quality'）
- 不可变更新，不修改原对象
- 自动创建中间路径

#### 1.2 `getNestedValue()`
获取嵌套参数值：
```typescript
const obj = { resolution: { quality: '1080P' } }
const value = getNestedValue(obj, 'resolution.quality')
// value = '1080P'
```

#### 1.3 `batchSetNestedValues()`
批量设置嵌套参数值：
```typescript
const newObj = batchSetNestedValues(obj, {
  'a': 10,
  'b.c': 20,
  'd': 30
})
```

#### 1.4 `hasNestedPath()`
检查路径是否存在

### 2. 创建默认值提取器

**文件路径**: `src/hooks/utils/defaultExtractor.ts`

**核心功能**:

#### 2.1 `extractDefaults()`
从参数 Schema 提取默认值：
```typescript
const schema = [
  { id: 'prompt', default: '', ... },
  { id: 'quality', default: 'standard', ... },
  { id: 'size', default: 1024, ... }
]

const defaults = extractDefaults(schema)
// { prompt: '', quality: 'standard', size: 1024 }
```

#### 2.2 `validateParamValue()`
验证参数值是否有效：
- 基础类型检查（string、number、boolean）
- 数值范围检查（min、max）
- 选项检查（dropdown、radio）

#### 2.3 `getParamDisplayName()`
获取参数的显示名称（支持国际化）

### 3. 创建 useModelParams Hook

**文件路径**: `src/hooks/useModelParams.ts`

**核心功能**:

#### 3.1 返回值接口
```typescript
interface UseModelParamsReturn {
  params: Record<string, any>           // 当前参数值
  setParam: (key, value) => void        // 设置单个参数
  setParams: (values) => void           // 批量设置参数
  resetParams: () => void               // 重置所有参数
  resetParam: (key) => void             // 重置单个参数
  getFilteredOptions: (id) => any[]     // 获取过滤选项
  getParamDef: (id) => ParamDef         // 获取参数定义
  validateParam: (id, value) => boolean // 验证参数值
  schema: ParamDef[]                    // 参数 Schema
  defaults: Record<string, any>         // 默认值
}
```

#### 3.2 核心实现

**自动提取默认值**:
```typescript
const schema = useMemo(() => registry.getSchema(modelId), [modelId])
const defaults = useMemo(() => extractDefaults(schema), [schema])
const [params, setParamsState] = useState(defaults)
```

**模型切换自动重置**:
```typescript
useEffect(() => {
  setParamsState(defaults)
}, [modelId, defaults])
```

**支持嵌套路径**:
```typescript
setParam('resolution.quality', '4K')  // 支持嵌套路径
setParam('prompt', 'hello')           // 支持普通路径
```

**批量设置参数**:
```typescript
setParams({
  'prompt': 'A cat',
  'resolution.quality': '4K',
  'duration': 10
})
```

**重置功能**:
```typescript

```

**获取过滤选项**（为 Phase 1-3-2 预留接口）:

**参数验证**:

## 技术亮点

### 1. 统一的参数状态
替代 160+ 个 useState：
```typescript
// 旧方式（640 行）
const [prompt, setPrompt] = useState('')
const [duration, setDuration] = useState(5)
const [quality, setQuality] = useState('1080P')
// ... 160+ 个状态

// 新方式（1 个状态）
const { params, setParam } = useModelParams('wan-2.6')
```

### 2. 自动默认值提取
无需手动定义默认值：
```typescript
// 旧方式
const defaults = {
  prompt: '',
  duration: 5,
  quality: '1080P',
  // ... 手动维护
}

// 新方式
const { params, defaults } = useModelParams('wan-2.6')
// 自动从 Schema 提取
```

### 3. 嵌套路径支持
支持点分隔的嵌套路径：
```typescript
setParam('resolution.quality', '4K')
setParam('resolution.aspectRatio', '16:9')
```

### 4. 不可变更新
使用展开运算符确保不可变性：
```typescript
setParamsState((prev) => ({
  ...prev,
  [key]: value
}))
```

### 5. 性能优化
- `useMemo` 缓存 Schema 和默认值
- `useCallback` 缓存函数引用
- 避免不必要的重渲染

### 6. 类型安全
完整的 TypeScript 类型定义：
```typescript
export interface UseModelParamsReturn {
  params: Record<string, any>
  setParam: (key: string, value: any) => void
  // ...
}
```

## 使用示例

### 示例 1：基础用法
```typescript
function VideoGenerator() {
  const { params, setParam, resetParams } = useModelParams('wan-2.6')

  return (
    <div>
      <input
        value={params.prompt}
        onChange={(e) => setParam('prompt', e.target.value)}
      />

      <select
        value={params.duration}
        onChange={(e) => setParam('duration', Number(e.target.value))}
      >
        <option value={5}>5秒</option>
        <option value={10}>10秒</option>
      </select>

      <button onClick={resetParams}>重置</button>
    </div>
  )
}
```

### 示例 4：参数验证
```typescript
function QualitySelector() {
  const { params, setParam, validateParam } = useModelParams('wan-2.6')

  const handleChange = (value: string) => {
    if (validateParam('quality', value)) {
      setParam('quality', value)
    } else {
      console.error('Invalid quality value:', value)
    }
  }

  return (
    <select value={params.quality} onChange={(e) => handleChange(e.target.value)}>
      <option value="standard">标准</option>
      <option value="hd">高清</option>
    </select>
  )
}
```

          {opt.label.zh || opt.label}
