## 技术亮点

### 1. 类型安全设计
使用 discriminated union 确保每种联动类型有明确的字段：
```typescript
type Linkage =
  | ResetLinkage
  | FilterOptionsLinkage
  | FilterRangeLinkage
  | SetValueLinkage
  | AutoSwitchLinkage
  | DisableLinkage
  | HideLinkage
  | CustomLinkage
```

TypeScript 能在编译时检查：
- ResetLinkage 必须有 targets 字段
- FilterOptionsLinkage 必须有 target 和 filter 函数
- AutoSwitchLinkage 必须有 target、condition、value 字段

### 2. 灵活的触发机制
支持多种触发方式：
- 单一触发器：`trigger: 'mode'`
- 多触发器：`trigger: ['mode', 'fastMode']`
- 嵌套路径：`trigger: 'resolution.quality'`

### 3. 优先级系统
- 默认优先级确保合理的执行顺序（先重置再设置）
- 支持 priority 字段覆盖默认值
- 提供排序函数用于运行时执行

### 4. 防抖支持
- 支持 debounce 字段避免频繁触发
- 适用于滑块等连续变化的参数

### 5. AutoSwitch 的恢复机制
- noRestore: false 时，条件不满足会恢复原值
- noRestore: true 时，条件不满足不恢复
- restoreKey 用于区分多个 autoSwitch 的保存值
