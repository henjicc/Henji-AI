## 三、参数类型系统架构

### 类型层次结构

```
BaseParamDef (基础参数定义)
  ├── 共同字段: id, component, order, name, tooltip, valueType, default
  ├── API 配置: api
  └── 条件控制: visible, disabled
      ↓
├── TextParamDef (文本输入)
├── NumberParamDef (数字输入)
├── SliderParamDef (滑块)
├── DropdownParamDef (下拉选择)
├── SwitchParamDef (开关)
├── RadioParamDef (单选)
├── PanelParamDef (面板)
├── ImageUploadParamDef (图片上传)
├── VideoUploadParamDef (视频上传)
├── ResolutionParamDef (分辨率)
└── AspectRatioParamDef (宽高比)
      ↓
ParamDef (联合类型 - Discriminated Union)
```

### BaseParamDef（基础接口）

```typescript
export interface BaseParamDef {
  id: string                    // 参数唯一标识
  component: ComponentType      // 组件类型
  order: number                 // 显示顺序
  name: I18nText                // 参数名称（多语言）
  tooltip?: I18nText            // 参数说明（可选）
  valueType: ValueType          // 值类型
  default: any                  // 默认值
  api?: ApiConfig               // API 映射配置
  visible?: VisibleCondition    // 显示条件
  disabled?: DisabledCondition  // 禁用条件
}
```

## 四、核心特性

### 1. API 映射（3 种方式）

#### 方式1：简单字段映射

```typescript
{
  id: 'duration',
  // ...
  api: 'video_duration'  // UI 的 duration 映射到 API 的 video_duration
}
```

#### 方式2：转换函数

```typescript
{
  id: 'resolution',
  // ...
  api: (value) => {
    const [width, height] = value.split('x').map(Number)
    return { width, height }  // 转换为多个 API 字段
  }
}
```

#### 方式3：端点相关映射

```typescript
{
  id: 'prompt',
  // ...
  api: {
    '/api/v1/text-to-video': 'prompt',
    '/api/v1/image-to-video': 'image_prompt',
    default: 'input_text'
  }
}
```

### 2. 条件控制

#### 显示条件（VisibleCondition）

```typescript
{
  id: 'images',
  // ...
  visible: {
    condition: 'mode === "image-to-video" || mode === "motion-control"',
    reason: '仅在图生视频和动作控制模式下需要图片'
  }
}
```

#### 禁用条件（DisabledCondition）

```typescript
{
  id: 'cfgScale',
  // ...
  disabled: {
    condition: 'fastMode === true',
    reason: '快速模式下不可调整 CFG 系数'
  }
}
```

#### 智能匹配（SmartMatchConfig）

```typescript
{
  id: 'images',
  component: 'image-upload',
  // ...
  smartMatch: {
    targetParam: 'aspectRatio',
    matcher: (file) => {
      const ratio = file.dimensions.width / file.dimensions.height
      if (ratio > 1.5) return '16:9'
      if (ratio < 0.7) return '9:16'
      return '1:1'
    },
    autoApply: true
  }
}
```

### 3. 类型安全（Discriminated Union）

使用 TypeScript 的 Discriminated Union 确保类型安全：

```typescript
export type ParamDef =
  | TextParamDef
  | NumberParamDef
  | SliderParamDef
  // ...

// TypeScript 会根据 component 字段自动推断具体类型
const param: ParamDef = { component: 'slider', /* ... */ }
// param.min, param.max, param.step 都有类型提示
```

## 七、技术亮点

### 1. 类型安全 ✅

- **Discriminated Union**：根据 `component` 字段自动推断具体类型
- **强类型约束**：每个组件都有明确的必需字段
- **IDE 智能提示**：完整的 JSDoc 注释和类型定义

### 2. 灵活的 API 映射 ✅

- **简单映射**：直接字符串映射
- **转换函数**：支持复杂的字段转换
- **端点相关**：根据不同端点使用不同映射

### 3. 强大的条件控制 ✅

- **显示条件**：支持表达式和函数
- **禁用条件**：支持禁用原因说明
- **智能匹配**：自动根据上传文件匹配参数

### 4. 国际化支持 ✅

- 所有文本字段都支持 `I18nText`
- 选项、标签、说明都可以多语言

### 5. 可扩展性 ✅

- 易于添加新的组件类型
- 每个组件类型独立定义

## 十、条件表达式支持

### 支持的条件类型

| 条件类型 | 示例 | 说明 |
|---------|------|------|
| 相等判断 | `mode === "text-to-video"` | 简单相等 |
| 逻辑运算 | `mode === "image-to-video" \|\| mode === "motion-control"` | OR 条件 |
| 逻辑与 | `fastMode === true && resolution !== "4k"` | AND 条件 |
| 数组长度 | `images.length > 0` | 数组判断 |
| 函数形式 | `(params) => params.mode === 'video'` | 复杂逻辑 |
