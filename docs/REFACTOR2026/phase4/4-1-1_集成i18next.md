# 4-1-1 集成i18next

## 目标

集成 i18next 国际化框架，为应用添加多语言支持基础设施

## 背景

当前应用所有文本都是硬编码的中文，无法支持国际化。新架构要求：
- 所有用户可见文本使用 i18n key
- 支持中英双语切换
- 模型定义中的文本使用 `I18nText` 类型
- 为未来扩展更多语言预留接口

## 风险与注意事项

### 风险
- i18next 包体积较大（约 50KB），可能影响首屏加载
- 翻译资源文件管理复杂，容易出现遗漏

### 注意事项
- 使用命名空间组织翻译，避免单个文件过大
- 翻译 key 使用点号分隔，保持层次结构
- 避免在翻译中使用 HTML 标签，改用参数插值
- 对于长文本，考虑使用 Markdown 格式
- 设置合理的降级策略（中文 → 英文 → key）
- 使用 `i18next-parser` 工具自动提取翻译 key
- 建立翻译审核流程，确保质量

## 实现参考

### i18n 配置示例

```typescript
// src/i18n/config.ts

import i18n from 'i18next'
import { initReactI18next } from 'react-i18next'
import LanguageDetector from 'i18next-browser-languagedetector'

// 导入翻译资源
import zhCN_common from './locales/zh-CN/common.json'
import zhCN_models from './locales/zh-CN/models.json'
import zhCN_params from './locales/zh-CN/params.json'
import zhCN_errors from './locales/zh-CN/errors.json'

import enUS_common from './locales/en-US/common.json'
import enUS_models from './locales/en-US/models.json'
import enUS_params from './locales/en-US/params.json'
import enUS_errors from './locales/en-US/errors.json'

const resources = {
  'zh-CN': {
    common: zhCN_common,
    models: zhCN_models,
    params: zhCN_params,
    errors: zhCN_errors,
  },
  'en-US': {
    common: enUS_common,
    models: enUS_models,
    params: enUS_params,
    errors: enUS_errors,
  },
}

i18n
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    resources,
    fallbackLng: 'zh-CN',
    defaultNS: 'common',
    ns: ['common', 'models', 'params', 'errors'],

    interpolation: {
      escapeValue: false, // React 已经转义
    },

    detection: {
      order: ['localStorage', 'navigator'],
      caches: ['localStorage'],
    },

    debug: import.meta.env.DEV,
  })

export default i18n
```

### useI18n Hook 示例

```typescript
// src/hooks/useI18n.ts

import { useTranslation } from 'react-i18next'
import type { I18nText } from '@/core/types'

export function useI18n(namespace?: string | string[]) {
  const { t, i18n } = useTranslation(namespace)

  /**
   * 翻译 I18nText 类型
   */
  const tText = (text: I18nText): string => {
    if (typeof text === 'string') {
      return text
    }

    const lang = i18n.language

    // 优先使用当前语言
    if (text[lang]) {
      return text[lang]
    }

    // 降级到中文
    if (text.zh) {
      return text.zh
    }

    // 降级到英文
    if (text.en) {
      return text.en
    }

    // 返回第一个可用的值
    const firstKey = Object.keys(text)[0]
    return text[firstKey] || ''
  }

  /**
   * 切换语言
   */
  const changeLanguage = (lang: string) => {
    return i18n.changeLanguage(lang)
  }

  return {
    t,
    tText,
    i18n,
    changeLanguage,
    currentLanguage: i18n.language,
  }
}
```
