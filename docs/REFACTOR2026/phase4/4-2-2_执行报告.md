### 2. 实现 ParamCleaner 参数清理工具

**文件路径**: `src/core/export/ParamCleaner.ts`

**核心功能**:

1. **clean()** - 统一清理入口，支持多种清理选项
2. **removeDefaults()** - 移除与默认值相同的参数
3. **removeEmpty()** - 移除空值（null, undefined, 空字符串, 空数组）
4. **removeSensitive()** - 移除敏感信息（apiKey, token, password 等）
5. **removeBase64()** - 移除 Base64 数据（data URL 和长字符串）

**关键实现**:

```typescript
export class ParamCleaner {
  clean(params: Record<string, any>, options: CleanOptions = {}, schema?: ParamDef[]): Record<string, any> {
    let result = { ...params }

    if (options.removeDefaults && schema) {
      result = this.removeDefaults(result, schema)
    }
    if (options.removeEmpty) {
      result = this.removeEmpty(result)
    }
    if (options.removeSensitive) {
      result = this.removeSensitive(result)
    }
    if (options.removeBase64) {
      result = this.removeBase64(result)
    }

    return result
  }
}
```

**技术亮点**:
- 链式清理，按顺序应用多个过滤器
- 深度相等比较，支持数组和对象的默认值比较
- 智能 Base64 检测，识别 data URL 和长字符串
- 敏感信息脱敏，替换为 `***REDACTED***`

### 3. 实现 ExportService 导出服务

**文件路径**: `src/core/export/ExportService.ts`

**核心方法**:

1. **exportCurrentParams()** - 导出当前参数值
2. **exportModelConfig()** - 导出完整模型配置
3. **exportModelSchema()** - 导出模型参数 Schema
4. **exportAPIRequest()** - 导出 API 请求体
5. **exportAsPreset()** - 导出为预设格式
6. **downloadAsJSON()** - 下载为 JSON 文件
7. **copyToClipboard()** - 复制到剪贴板

**关键实现**:

```typescript
export class ExportService {
  private cleaner: ParamCleaner
  private version = '1.0.0'

  exportCurrentParams(modelId: string, params: Record<string, any>, options: ExportOptions = {}): ExportData {
    const schema = registry.getSchema(modelId)
    let cleanedParams = params
    if (options.clean) {
      cleanedParams = this.cleaner.clean(params, options.clean, schema)
    }
    return this.createExportData('current-params', modelId, cleanedParams, options)
  }

  downloadAsJSON(data: ExportData, filename?: string): void {
    const json = JSON.stringify(data, null, 2)
    const blob = new Blob([json], { type: 'application/json' })
    const url = URL.createObjectURL(blob)
    const a = document.createElement('a')
    a.href = url
    a.download = filename || this.generateFilename(data)
    a.click()
    URL.revokeObjectURL(url)
  }
}
```

**技术亮点**:
- 统一的导出接口，支持多种导出类型
- 集成 ParamCleaner，自动清理冗余数据
- 自动生成文件名，包含类型、模型 ID、日期
- 使用 Blob API 实现文件下载
- 使用 Clipboard API 实现剪贴板复制
