# 4-2-1 实现参数流转追踪

## 目标

增强测试模式，实现参数从 UI → 联动 → 转换 → API 请求的完整流转追踪，帮助调试参数传递问题

## 背景

当前测试模式（`TestModePanel.tsx`）只能显示最终的 API 请求参数，无法追踪：
- 用户在 UI 设置了什么值
- 哪些参数触发了联动规则
- 参数值如何被转换（UI 值 → API 值）
- 哪些参数被过滤或重置

在适配新模型时，经常遇到：
- 参数设置了但没有发送到 API
- 参数值被意外修改
- 联动规则没有按预期工作
- 不清楚为什么某个参数使用了特定的值

需要一个可视化的参数流转追踪工具。

interface ParamFlowRecord {
  timestamp: number
  modelId: string
  stages: FlowStage[]

// 流转阶段
interface FlowStage {
  stage: 'ui-input' | 'linkage' | 'transform' | 'api-build'
  timestamp: number
  params: Record<string, ParamValueRecord>
}

// 参数值记录
interface ParamValueRecord {
  value: any
  source?: string          // 来源：'user-input' | 'default' | 'linkage' | 'transform'
  changedBy?: string       // 被哪个联动规则修改
  transformedFrom?: any    // 转换前的值
  reason?: string          // 变化原因
}

  private records: ParamFlowRecord[] = []
  private currentRecord: ParamFlowRecord | null = null

  // 开始追踪
  startTracking(modelId: string): void

  // 记录 UI 输入阶段

  // 记录联动阶段

  // 记录转换阶段

    toValue: any,

  // 获取追踪记录

### 3. 集成到参数联动引擎

- [ ] 修改 `src/hooks/useModelParams.ts`

```typescript
function useModelParams(modelId: string, enableTracking = false) {
  const tracker = useRef(new ParamFlowTracker())

  const setParam = useCallback((key: string, value: any) => {
    if (enableTracking) {
      tracker.current.startTracking(modelId)
    }

    setParams(prev => {
      const next = { ...prev, [key]: value }

      // 记录 UI 输入
      if (enableTracking) {
        tracker.current.recordUIInput({ [key]: value })
      }

      // 执行联动
      const linkages = getLinkagesTriggeredBy(key)
      linkages.forEach(linkage => {
        const changes = executeLinkage(linkage, next)

        // 记录联动
        if (enableTracking) {
          tracker.current.recordLinkage(key, changes, linkage)
        }

        Object.assign(next, changes)
      })

      if (enableTracking) {
        tracker.current.finishTracking()
      }

      return next
    })
  }, [modelId, enableTracking])

  return {
    params,
    setParam,
    flowRecords: enableTracking ? tracker.current.getRecords() : []
  }
}
```

### 4. 集成到 RequestBuilder

- [ ] 修改 `src/core/RequestBuilder.ts`

```typescript
class RequestBuilder {
  buildRequest(
    modelId: string,
    params: Record<string, any>,
    context: any,
    tracker?: ParamFlowTracker
  ) {
    const model = registry.getModel(modelId)

    const apiParams = {}

    // 转换参数
    model.params.forEach(paramDef => {
      const uiValue = params[paramDef.id]

      if (paramDef.apiField) {
        const apiValue = convertValue(uiValue, paramDef)
        apiParams[paramDef.apiField] = apiValue

        // 记录转换
        if (tracker && uiValue !== apiValue) {
          tracker.recordTransform(
            paramDef.id,
            uiValue,
            apiValue,
            paramDef.apiField
          )
        }
      }
    })

    // 记录 API 构建
    if (tracker) {
      tracker.recordAPIBuild(apiParams)
    }

    return apiParams
  }
}
```

function StageView({ stage }: { stage: FlowStage }) {

    switch (stage.stage) {
      case 'ui-input': return '1. UI 输入'
      case 'linkage': return '2. 参数联动'
      case 'transform': return '3. 值转换'
      case 'api-build': return '4. API 请求'
    }
  }

  return (
    <div className="stage">
      <h4>{getStageTitle()}</h4>
      <table>
        <thead>
          <tr>
            <th>参数</th>
            <th>值</th>

              </td>
              <td>

              </td>
            </tr>
          ))}

      </table>
    </div>
  )
}

## 风险与注意事项

### 风险
- 追踪记录可能占用大量内存
- 频繁的参数变化可能产生大量记录
- 深度对象比较可能影响性能

### 注意事项
- 只在测试模式下启用追踪
- 限制记录数量（如最近 10 次）
- 使用浅比较避免深度遍历
- 大对象只记录摘要，不记录完整值
- 提供清空记录功能
- 导出时过滤敏感信息（如 API key）

## 实现参考

### 追踪器完整实现

```typescript
// src/core/debug/ParamFlowTracker.ts

export class ParamFlowTracker {
  private records: ParamFlowRecord[] = []
  private currentRecord: ParamFlowRecord | null = null
  private maxRecords = 10  // 最多保留 10 条记录

  startTracking(modelId: string): void {
    this.currentRecord = {
      timestamp: Date.now(),
      modelId,
      stages: []
    }
  }

  recordUIInput(params: Record<string, any>): void {
    if (!this.currentRecord) return

    const stage: FlowStage = {
      stage: 'ui-input',
      timestamp: Date.now(),
      params: {}
    }

    Object.entries(params).forEach(([key, value]) => {
      stage.params[key] = {
        value,
        source: 'user-input'
      }
    })

    this.currentRecord.stages.push(stage)
  }

  recordLinkage(
    triggeredBy: string,
    changes: Record<string, any>,
    linkageRule: Linkage
  ): void {
    if (!this.currentRecord) return

    const stage: FlowStage = {
      stage: 'linkage',
      timestamp: Date.now(),
      params: {}
    }

    Object.entries(changes).forEach(([key, value]) => {
      stage.params[key] = {
        value,
        source: 'linkage',
        changedBy: triggeredBy,
        reason: `Linkage effect: ${linkageRule.effect} triggered by ${triggeredBy}`
      }
    })

    this.currentRecord.stages.push(stage)
  }

  recordTransform(
    paramId: string,
    fromValue: any,
    toValue: any,
    transformer: string
  ): void {
    if (!this.currentRecord) return

    let transformStage = this.currentRecord.stages.find(
      s => s.stage === 'transform'
    )

    if (!transformStage) {
      transformStage = {
        stage: 'transform',
        timestamp: Date.now(),
        params: {}
      }
      this.currentRecord.stages.push(transformStage)
    }

    transformStage.params[paramId] = {
      value: toValue,
      source: 'transform',
      transformedFrom: fromValue,
      reason: `Transformed by ${transformer}`
    }
  }

  recordAPIBuild(apiParams: Record<string, any>): void {
    if (!this.currentRecord) return

    const stage: FlowStage = {
      stage: 'api-build',
      timestamp: Date.now(),
      params: {}
    }

    Object.entries(apiParams).forEach(([key, value]) => {
      stage.params[key] = {
        value,
        source: 'api-build'
      }
    })

    this.currentRecord.stages.push(stage)
  }

  finishTracking(): ParamFlowRecord {
    if (!this.currentRecord) {
      throw new Error('No tracking in progress')
    }

    const record = this.currentRecord
    this.records.push(record)

    // 限制记录数量
    if (this.records.length > this.maxRecords) {
      this.records.shift()
    }

    this.currentRecord = null
    return record
  }

  getRecords(): ParamFlowRecord[] {
    return [...this.records]
  }

  clearRecords(): void {
    this.records = []
    this.currentRecord = null
  }
}
```
