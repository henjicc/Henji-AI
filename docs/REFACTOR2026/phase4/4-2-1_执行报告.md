### 2. 实现 ParamFlowTracker 追踪器类

**文件路径**: `src/core/debug/ParamFlowTracker.ts`

**核心功能**:

1. **startTracking(modelId)** - 开始追踪
2. **recordUIInput(params)** - 记录 UI 输入阶段
3. **recordLinkage(triggeredBy, changes, linkageRule)** - 记录联动阶段
4. **recordTransform(paramId, fromValue, toValue, transformer)** - 记录转换阶段
5. **recordAPIBuild(apiParams)** - 记录 API 构建阶段
6. **finishTracking()** - 结束追踪并保存记录
7. **getRecords()** - 获取所有追踪记录
8. **clearRecords()** - 清空记录
9. **exportRecord(record)** - 导出记录为 JSON

**关键实现**:

```typescript
export class ParamFlowTracker {
  private records: ParamFlowRecord[] = []
  private currentRecord: ParamFlowRecord | null = null
  private maxRecords = 10  // 最多保留 10 条记录

  startTracking(modelId: string): void {
    this.currentRecord = {
      timestamp: Date.now(),
      modelId,
      stages: []
    }
  }

  finishTracking(): ParamFlowRecord {
    if (!this.currentRecord) {
      throw new Error('No tracking in progress')
    }

    const record = this.currentRecord
    this.records.push(record)

    // 限制记录数量
    if (this.records.length > this.maxRecords) {
      this.records.shift()
    }

    this.currentRecord = null
    return record
  }

  exportRecord(record: ParamFlowRecord): void {
    const blob = new Blob(
      [JSON.stringify(record, null, 2)],
      { type: 'application/json' }
    )
    const url = URL.createObjectURL(blob)
    const a = document.createElement('a')
    a.href = url
    a.download = `param-flow-${record.modelId}-${Date.now()}.json`
    a.click()
    URL.revokeObjectURL(url)
  }
}
```

**性能优化**:
- 限制最多保留 10 条记录，避免内存占用过大
- 使用浅拷贝避免深度遍历
- 只在启用追踪时创建追踪器实例

## 技术亮点

### 1. 分阶段追踪设计

将参数流转分为 4 个清晰的阶段：
- **UI Input**: 用户在界面输入的原始值
- **Linkage**: 参数联动引擎触发的变化
- **Transform**: 参数值转换（UI 格式 → API 格式）
- **API Build**: 最终的 API 请求体

每个阶段独立记录，便于定位问题。

### 2. 非侵入式集成

- 追踪功能作为可选参数，不影响现有代码
- 只在测试模式下启用，零性能开销
- 通过 `enableTracking` 参数控制

### 3. 自动化追踪

- useModelParams 自动追踪联动变化
- RequestBuilder 自动追踪参数转换
- 无需手动调用追踪 API

### 4. 可视化设计

- 使用颜色区分不同阶段和来源
- 高亮显示变化的参数
- 表格形式清晰展示数据流
