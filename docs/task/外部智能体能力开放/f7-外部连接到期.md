## 实现与设计决定

1. `authenticate` 返回 valid/expired/unknown，合法格式令牌仍经 `timingSafeEqual` 比较；过期与未知均 HTTP 401，分别返回 `token_expired` / `invalid_token`、可操作中文正文与 Bearer 挑战头。日志 `mcp.request.rejected` 只含原因、连接标识与期限，不含令牌。
2. 过期记录保留至原到期时间再加 30 天，列表、新建和认证沿同一个保留规则清理；撤销立即删除。清理依赖下一次访问，应用关闭期间不启动独立清理任务。
3. 续期设置为操作时刻再加 30 天，只更新 `expiresAt`；凭据、权限、连接身份均不变。续期与提醒确认沿原 `McpPlatform → preload → IPC → McpConnections`，主进程严格校验可信发送方与输入。
4. 提醒标记保存在原连接记录中，按连接、本次 `expiresAt`、expiring/expired 去重；重启不重复已确认状态，续期后的新期限独立提醒。旧期限提醒与续期/撤销竞争时无法领取。根层每分钟及窗口恢复可见时检查，一次显示一条，并避开已有通知。
5. 到期提醒复用 `NotificationProvider` / `UiToast`；新增有限 warning tone 与可访问 quiet 恢复动作，点击定位已登记的 `settings.assistant.mcp` 分区。已在 Codex/Claude 两份 skill 同步枚举说明。
6. 设置连接采用扁平记录，标题行是名称 14/500 + 右侧期限 12；权限和动作在下一行。记录间分隔线及上下 20px 留白；不用卡片、不展示内部标识。
7. 规格里的 ghost、text-text-muted 已由设计系统删除，按现行等价语义采用 quiet、text-text3；即将到期 warning、已到期 danger。复制、续期、撤销同档同尺寸。过期时隐藏无法执行的复制配置动作，续期后恢复。
8. 日期使用本地日历日期；≤3 天显示向上取整的剩余天数，到期即切换已到期。中文和英文文案进入 i18n，英文补单数。
9. 移除原连接数量 32 的产品上限。超过 50 条采用现有 `react-virtuoso` 和有限滚动视口；该阈值只决定渲染方式，不限制创建或保存。

## 能力覆盖与开源选型

- 这是认证生命周期增量；续期会延长凭据的使用权限，属于用户持有的授权决策，只允许可信应用设置入口，不向持有该令牌的外部智能体开放自我续期。提醒标记是内部派生状态，不注册业务实体或工具。导航复用已登记 Surface；因此外部目录、版本与指纹保持不变。
- 主进程唯一领域服务是现有 `McpConnections`，没有 UI/助手复制业务实现。
- 比较并复用现有 Node crypto、Zod、UiFormRow/UiToast、react-virtuoso；无需另引令牌库、通知中心或手写虚拟列表。少量到期规则只是现有授权生命周期的日期判断，不新建算法框架。
- 对照 assistant-status 第零节：本次是既有外部连接的缺陷修复与用户授权维护，不改变业务工具通/不通、不新增助手欠账，未更新台账。

## 设计自查

1. **助手只凭名称和说明能否用对？** 401 正文明确原因、设置路径和“续期后令牌不变”；助手可解释恢复方法。延长其自身权限需要用户决策，因此不提供外部自我授权工具。
2. **能否 AI 先做、人只确认？** 应用自动识别期限、提醒及定位恢复入口，人只决定是否续期；无需重新配置外部客户端。自动替用户延长权限不在授权范围内。
3. **产物能否直接流进其他工作区？** 本任务不产生媒体；保留原令牌和身份，让原有跨工作区业务调用恢复，不改变素材、文档或任务引用。
