## 3. 观察版本

videoEditDocumentContent 明确移除 revision，videoEditDocumentFromContent 默认重建为 0；它是内存计数，重启归零符合当前模型，但不适合作为跨重启版本身份。

截帧及同类自动校色返回 documentVersion，使用 rendererEpoch + 文档实例随机代次 + 实际采样 revision；同快照稳定，重启、文档重开或编辑后不同。只能比较相等性，不能跨代次按字符串/数字排序。公共读取增加 revisionEpoch，避免画布、图片、剪辑的通用 revision/scopeRevisions/revisions 被跨宿主误比较；此字段只添加到读取副本，原操作账本、回执和文件格式不改。

rendererEpoch 的唯一生成点从 feature 移至中立 core/runtimeIdentity.ts，原 feature 入口只重导出；观察服务与宿主共享同一值，不新增跨 feature 非公开导入，不提高依赖图基线。

同类检查：图片编辑 create_image_edit_preview 使用独立 previewRef/resultRefs；应用像素观察为外部 internal 且有 capturedAt；画布没有另一个对外截帧 documentRevision。通用实体读取存在数字版本同源问题，由 revisionEpoch 统一解释。未审计所有领域的写操作 revision；持久基线仍由原 rendererEpoch 隔离，不自动复用旧基线。
