# 外部智能体能力开放

## 任务目标

让外部智能体通过标准模型上下文协议（MCP）发现并可靠调用痕迹 AI 的业务能力。长期稳定的是应用能力、授权边界和结果语义；协议及客户端差异留在薄适配层，降低后续接入和升级成本。

本次建设本机 MCP 服务、必要的调用方解耦、受控读写、长任务查询、结果获取及兼容验收。保留自研助手源码和历史，可隐藏入口；助手功能兼容、模型效果和旧助手完善计划均不作为本次验收条件。正常业务界面、业务数据和应用启动仍须保持可用。
