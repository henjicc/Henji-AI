## 设计自查与覆盖分级

1. 助手只凭名称和说明能否用对？沿既有通用实体读写；图片工具说明直接说明 image/chunk、预算；前置拒绝和供应商准入错误给出原因与恢复路径。`review_application_operation` 属于协议账本恢复，不是业务 CRUD，须应用用户确认，智能体不能代答。
2. 能否 AI 先做、人只确认？剪辑自动后台加载；工具等宿主就绪；服务端自动压缩图片；已证明的旧拒绝自动恢复。无法证明的未知执行保留屏障，仅用户核对后修正账本，不自动重放。
3. 产物能否直接流进其他工作区？保留正式媒体引用、文档实例、任务和结果入口，原件不变；查看 JPEG 不另造素材或文档格式。

选型：校验复用 Zod 原生 validator；压缩复用已有 Sharp/libvips 线程池；账本复用原 SQLite 结构与 recoveryResult 字段；等待复用宿主注册监听；UI 复用 UiError。没有安装依赖、自研编码器或新增持久格式。maxEdge/传输字节上限仅是工具消息与解码预算，chunk 可读完整原件，不限制产品数量。

## 0. CI 体验退化

根因：从 JSON Schema 反构建 validator 丢失领域中文 refine；联合类型只输出 Invalid input；紧凑 describe 丢失限制说明。

红绿证据：原 `videoEditClipSpeed.test.ts` 与 `videoEditAssistantCoverage.test.ts` 共 6 条，修复前 3 条失败，修复后 6 条通过；未修改这两个文件及其断言。分别保护速度“1 到 10000”、手绘 points 和共享智能区域清空不保证重试的限制。

## 1. 关闭文档、执行事实与旧账本恢复

再次确认：普通剪辑实体和 code_material 本身已有后台加载；漏点是 code_component 的反射可用性/读取，以及语义处理器统一入口。组件首次加载必须发生在捕获 revision 之前，避免自动加载后反而产生旧版本冲突。

修复：所有带 documentRef 的剪辑语义入口后台 open(focus:false)，组件读取和集合预检后台加载；不抢活动文档。通用执行引擎计划构建、加锁/宿主解析、事务开始前的普通异常附零步事实；步骤内错误保留 partial/effects/persistence。公共能力派发前异常统一标记 notExecuted，禁止把处理器执行后的任意异常一概当未执行。

旧记录自动改判仅接受：unknown + 失败结果；无 transaction/effects/partial/persistence、无结果 data、无已有恢复事实；且已存在明确 notExecuted，或恰为旧 change_application_entities 的 CAPABILITY_REJECTED 与 requireVideoEditInstance 完整原文。安全依据是旧引擎步骤内异常会包装为“操作未完整完成”并附 partial，这条裸原文只会在步骤外逃逸。不以当前值相同、无回执或无字段单独推断。查询、同 ID 重试和同内容新请求扫描均可恢复。

其他 unknown：先查询原回执；原 rendererEpoch 已结束且新宿主就绪后，调用 review_application_operation。内核读取原目标、检查连接与写授权，由桌面弹窗请用户确认已执行/未执行/取消；取消、授权撤销和原宿主仍活跃不解锁。复用现有 recoveryResult，不改表结构；不会自动重放原请求。后台任务仍须先核对正式任务状态，不能把“窗口重载”当作后台任务结束。

回归：`failureReporting.test.ts` 的“事务派发前的普通异常附零执行事实，事务步骤异常保留 partial”；`videoEditCodeService.test.ts` 的关闭剪辑创建组件/代码素材并保持活动文档回归；`operationStore.test.ts` 的旧裸拒绝恢复、事务事实保留、换宿主人工核对、取消/撤权边界。组件回归修复前报请先打开，第一次实现还暴露 revision 时序问题，最终 51 条通过。

同源排查边界：剪辑 requireVideoEditInstance 的领域注册入口、反射读取/集合预检与实例提交守卫；未移除内部 ownership 守卫。图片“请先打开图片讲解”属于录制 collector 生命周期；画布 retry_layer_stack_result 依赖当前画布续查 hook，公开说明已经要求活动画布，本轮未将该 hook 改造成后台服务；音频与三维未发现相同文字拒绝。通用实体引擎覆盖各域，但没有把所有既有非通用语义 handler 重写成通用事务，因此不能宣称所有领域普通异常都已全局证明未执行；无执行证据仍保留 unknown，可走核对路径。
