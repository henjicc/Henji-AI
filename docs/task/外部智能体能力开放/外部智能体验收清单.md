# 外部智能体验收清单

改动了 MCP 工具、操作账本、生成/识别链路、宿主传输或字幕/剪辑能力之后，合并到 main 并重启开发实例，再让外部智能体（本机 Claude 会话，经 henji MCP 连接）按本清单跑一遍。单元测试多用替身，这份清单是唯一走“真实客户端 → MCP → 应用 → 真实供应商”的检查。

费用：一轮约几毛钱（短 TTS、一次短音频识别）。全部在 AI 付费授权的默认额度内，正常不会弹窗。

## 前置

- 开发实例完全就绪（日志出现 `app.startup.models.completed`），再通知外部智能体。
- 外部智能体先调用 `get_current_application_context`，核对 `catalogSchemaHash`：本次改了工具时它应与合并前记下的值不同，且客户端工具列表里的参数与说明应与本次改动一致；对不上就请用户在 `/mcp` 里重连。
- 测试期间不要在 main 上改前端文件，避免热更新打断执行。

## 步骤与通过标准

| # | 操作 | 通过标准 |
|---|---|---|
| 1 | 在专用测试项目新建剪辑与序列 | 写入成功；未打开的剪辑也能直接写（后台加载） |
| 2 | `prepare_generation_task` → `create_visible_generation_task`，用百炼 Qwen TTS 生成一句含两行、含中英混排的旁白 | 预检通过；`approval.decision` 为 `auto` 且 reason 写明估算值；`wait_generation_task` 返回 success |
| 3 | `place_video_edit_creative_result` 放进剪辑 | 返回片段引用，时长合理 |
| 4 | `get_video_edit_clip_pauses(clipRef)` | 返回序列帧单位的停顿图，非空 |
| 5 | `generate_video_edit_subtitles`（clipRef、timeSource auto、默认 style） | 额度内自动执行（或返回 `awaiting_user_confirmation` 且确认后自动完成）；字幕去除逗号句号、句尾 ？！… 保留、无换行符、不在词中断开、边界不早于最后一个词结束、短间隔首尾相接 |
| 6 | `segment_video_edit_subtitles` 免费整理已有字幕 | 不调用识别、不计费、一步撤销 |
| 7 | `read_application_entity` 不传 propertyIds 读一条 caption | 返回全部可读属性 |
| 8 | `observe_video_edit_frame` + `read_application_media(mode="image")` | 一次拿到小体积 JPEG；结果带 `byteLength`、`documentVersion` |
| 9 | 同一事务删除一条 caption 并修改另一条（只为删除目标提供基线） | 一次提交成功 |
| 10 | `export_video_edit` 导出成片，`query_video_edit_export` 带 taskId 查询 | 进度正常到完成；queue 含该项 |
| 11 | 重启开发实例后再查第 10 步的导出 | 仍能查到 assetRef；用不存在的 taskId 查询返回 NOT_FOUND |
| 12 | 故意制造一次执行前失败（例如传错 clipRef） | 记为 `not_executed / verified`，同内容改正后可直接重提，不被 RECOVERY_REQUIRED 拦截 |

## 结果记录

外部智能体按“修好的 / 有问题的（工具、入参、返回原文、期望）”格式回报。新问题进入下一轮任务；本清单随能力变化更新（只改这一份，不另建）。
