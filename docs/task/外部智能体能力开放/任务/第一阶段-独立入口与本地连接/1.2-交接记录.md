# 1.2 交接记录

## 已实现与接入方式

- 正式入口：设置 → 通用 → 外部智能体连接。每次应用启动默认关闭；可选本机端口、创建独立只读连接、复制配置、撤销。授权有效期 30 天；连接记录通过现有 `keystore.ts` 的 `mcp` 命名空间加密保存。端口目前为本次进程配置，重启后默认 43821；使用自定义端口时需再次选择同一端口。
- `electron/main/services/mcp/server.ts`：官方 SDK 的有状态 Streamable HTTP，仅绑定 `127.0.0.1`，路径 `/mcp`。精确 Host、拒绝所有 Origin、Bearer 凭据、会话绑定客户端、正文 256 KiB、结果 2 MiB、请求并发 8、会话上限 16、闲置会话回收。仅返回 JSON，拒绝 GET 常驻 SSE；不提供任意 IPC、文件或代码执行入口。
- `connections.ts`：独立凭据和过期检查；持久化成功后才生效新授权。接口只向 UI 返回名称、到期时间和操作引用，普通状态不返回令牌。
- `applicationHostBridge.ts`：主进程协调只读请求，执行前及返回前复核授权；绑定宿主会话和递增代次，撤销、取消与重载清理等待，旧代次不能覆盖新代次。关闭服务只取消在途，不丢失仍存活的根宿主注册。
- `electron/main/ipc/mcp.ts`：只允许正式主窗口主框架及应用来源；请求中的身份由主进程凭据查找生成。客户端不能提供权限、助手运行号或审批字段。
- `src/core/application-control/localHostContracts.ts`：中立桥契约、只读能力白名单与可信权限策略。`src/features/application-control/localApplicationHost.ts` 在可信主进程事件消费端创建真正的 grant，复用 1.1 的 Session。根 Hook 动态加载并持续挂载，不依赖助手侧栏。
- `src/platform/adapters/electron/mcp.ts`、`src/commands/mcp.ts`、`electron/preload/mcp-api.ts` 为现有 PAL 和 preload 的薄适配。复制文本扩展既有 clipboard 服务与 PAL，UI 不自建桌面调用。

## 工具与结果契约

只公开 `describe_application_entities`、`list_application_entities`、`read_application_entity`。输入 JSON Schema 直接从同一能力定义的 Zod 输入投影；参数验证、字段权限和输出验证仍由原 Session／Registry 完成。不是另写一份业务字段表。写入工具不在目录中，直接猜名称也不能执行。

结果同时提供标准文本及结构化对象，保留原 `ok/data/error` 信封。反射读取返回 `data.revisions`；不得把它与语义宿主计数混用。当前 `read_application_entity` 应显式提供发现到的 `propertyIds`；未提供时不保证返回全部字段。
