## 已实现的调用约定

1. 设置「外部智能体连接」先启用服务，创建连接时选是否允许修改、删除；默认只读。权限仅来自可信 UI 持久记录，客户端自报无效。现连接通过撤销终止授权，调整范围需新建连接。
2. 三个读取工具不变。成功 `read_application_entity`／`list_application_entities` 在正式引用和 revision 完整时返回 `baselineId`；schema 发现不授予基线。它绑定 caller、准确目标、真实领域 revision 及宿主会话。
3. 写客户端首次请求前生成 UUID `operationId`，与 `baselineIds` 及原正式修改参数传给 `change_application_entities`。不要传 `expectedRevisions`。增删需覆盖原集合父对象，删除还需每个原目标。相同身份参数或基线不同拒绝；超时后用原身份查询，不生成新身份绕过未知操作。
4. `get_application_operation({operationId})` 返回执行状态、独立验证状态及原回执。执行状态为 prepared／executing／completed／not_executed／partial／unknown。只有 completed 且正式验证通过才 `ok:true`；错误响应也保留实际 effects 和目标。
5. `retry_application_operation_save({operationId,originalOperationId})` 的新 UUID 表示保存恢复请求；仅使用原失败指定的 `retry_canvas_project_save`、原工程与原验证条件，在原宿主会话执行。保存成功但验证未通过仍不关闭原 partial。原回执永不覆盖，恢复结果另存。
