## 设计与边界

- 主进程 `paidApprovalPolicy` 统一判定 ask / auto / bypass，默认 auto、单次 ¥2、每日 ¥20；自然日按本地午夜。项目授权限定真实项目与操作类别，ask 下转为受单次/每日额度约束的 auto 判定，不突破额度。未知价格在 auto/ask 下询问、bypass 下放行，已知每日额度超过上限仍询问。
- 估价只接正式应用入口。生成金额由主进程保留正式 preparation 的 `comparableCnyAmount` 并覆盖渲染请求；识别、文本模型与讲解暂没有正式可靠估价，明确登记 null，不接受 Agent 参数自报价格。
- 继续使用现有操作账本 `application_invocations.record_json` 保存估价预留与 `approval: { decision: auto | user, reason }`。同步判定并预留避免同时通过额度检查；not_executed 不计入累计，已提交/结果未知保留预留。不是供应商最终账单结算系统。
- 设置和项目授权存在原 SQLite settings 的 `ai.paid_approval`，项目 ID 仅内部关联。项目授权是本机用户的安全偏好，不能随导入工程自动获得授权，因此不放进可移植的作品内容。设置可撤销项目授权；助手只能发现该设置及打开设置页，不能给自己提权。保留 MCP allowPaid 和已有调用方权限前置约束，不新增 Agent 工具。
- 确认沿用 t178 等待/继续回执与原 `application:host:complete` IPC。ask 立即向调用者返回 awaiting_user_confirmation；用户确认后继续原请求，拒绝/过期按未执行处理。讲解 UI 也通过该可信 IPC 使用同一策略和账本，不新增工具或账本。
- 设置使用 UiGroup、UiFormRow、Dropdown、NumberInput 和现有 Virtuoso；列表不设项目数量上限。UiButton 现有无实底档叫 quiet，本项目始终允许/拒绝/撤销使用该档，允许本次使用 primary，只有一个实底按钮。没有新增通用 UI 组件。
- 图像引用先经正式 `splitImageEditV3DocumentRef` 解码；画布内嵌图片复用原关联解析找到画布所属项目，工具箱没有项目时不提供项目授权。切换、删除、关闭讲解及取消待发送计划释放尚未执行的预留。
- 删除“本次讲解不再询问”的 UI 与运行语义；原文本/画面外发 consent 保留为本次发送期间的访问凭证，完成或失败清除，不能用旧 consent 绕过策略。

## 应用能力覆盖与选型

业务操作沿既有能力、公开实体及 t178 回执接入，无新增专用工具。安全设置为有理由的排除：助手代写授权会自行提权，登记 `security.paid_approval` 并提供设置导航。项目授权只能在可信应用设置/确认 UI 修改。

复用选择：使用项目已有 Zod、Zustand、React Virtuoso、Ui*、SQLite 设置与操作账本。没有引入新的权限框架、弹窗库、计费库或数据库：此次判定为指定的几条领域规则，新框架无法代替既有 t178 状态机及正式账本，反而会出现第二份授权状态。项目/画布关系复用既有解析入口，不复制另一套扫描规则。

设计自查：

1. 助手只凭名称和说明能否用对？既有工具说明声明按应用 AI 付费授权自动放行或请求确认，等待结果给费用、原因和原 operationId 查询指引；助手不填价格、不替用户确认。
2. 能否 AI 先做、人只确认？可自动通过的费用直接执行，超限或未知价格才进入原确认流程；确认后自动继续原操作。音色克隆额外专用提示仍是已列出的剩余项。
3. 产物能否直接流进其他工作区？沿原生成、字幕、口播及讲解领域写入和撤销链路，没有新结果副本或搬运路径；本任务不改跨工作区媒体契约。

## 持久格式与契约

setting-records 登记 paidApproval 设置嵌套 schema；sqlite 登记 paidReservation、paidApproval 及带费用的 confirmation。使用正式 `persistence:baseline -- --dev-break setting-records --dev-break sqlite --reason ...` 更新基线，保留审计历史；没有 DDL 变化或旧字段兼容迁移，SQLite 版本仍为 19。旧开发期 generationEstimate 字段不再消费。

对外契约 2.2.1 → 2.2.2，登记费用确认输出的目录指纹。操作结果只投影审批来源/原因；设置阈值和项目列表不作为结果配置对象暴露。
