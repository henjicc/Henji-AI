- 默认在结果根部给出一个 `revision` 和本次相关的 `scopeRevisions`；删除内外信封重复的 `resultingRevision/resultingScopeRevisions` 与 data 层副本。相关 scope 来自正式能力声明、输入/结果引用与真实实体版本；跨域操作保留所有实际相关 scope。`includeRevisions:true` 可选返回全表，仍只返回一份。
