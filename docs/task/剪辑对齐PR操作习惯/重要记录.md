## 记录 003：本地模型统一用原生 onnxruntime

- 日期：2026-10-06
- 状态：已确定（用户决定）
- 背景：原计划用 onnxruntime-web（WebGPU / WASM）。它通过浏览器 WebGPU 间接用显卡，不支持的算子会回落 CPU 来回拷贝，还和剪辑合成抢同一个 WebGPU 设备。
- 最终决定：痕迹AI 是桌面程序，所有本地模型推理统一用 onnxruntime-node，放在后台进程。执行顺序为 DirectML（Windows）/ CoreML（Mac）→ CPU。不再使用 onnxruntime-web。
- 补充（2026-10-06 实测）：onnxruntime-node 1.30 在 Windows 只自带 cpu、dml、webgpu 三种执行提供者，CUDA 只有 Linux 版，所以 Windows 定为 DirectML → CPU。EfficientTAM-Ti 512 每帧（四个部件合计，RTX 4090）：DirectML fp32 11.8 ms / fp16 9.6 ms，CPU 188 ms，WebGPU 30.6 ms。
- 影响：4.7d 智能区域、4.10 跟踪器都按这个运行方式实现；模型导出以 onnxruntime-node DirectML 能跑为准。
