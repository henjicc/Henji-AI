# 4.25 跨工作区流转

状态：实现及精确验证完成，待总管理者审查提交与用户实测（2026-10-07）。本任务不执行 Git 写操作、不改 SDK、不启动 Electron、不跑 Reality、不调用付费生成。

## 现有入口盘点与覆盖分级

- 剪辑接收：已有 `prepareVideoEditCreativeResult` → `placeVideoEditResultInProject` → `commitVideoEditCreativeResult`，支持固定来源、复制进入目标项目、媒体检查、保存回读和一次撤销。图片编辑器/口播已有共享发送菜单，画布和生成历史已有当前剪辑快捷入口；此次统一扩展其目标选择与落位方式。
- 剪辑输出：节目面板已有“选帧加入资产库 / 编辑当前帧”；正式离屏帧观察、Mediabunny 导出、输出收录服务已有完整像素/文件发布边界。复用这些入口，增加发送到画布的编排。
- 画布输入：复用资产到画布 `addAssetToCanvas` 与既有图片/视频/声音上传输入节点。没有新增节点定义、DOM、上传实现或持久化格式。
- 图片回填：复用图片编辑器现有 handoff 会话和 `VideoEditSendMenu`，原位置回填改为一帧的顶层图片片段；图片文档继续沿现有链接刷新机制。
- 资产库：已有拖入剪辑与正式资产引用；增加卡片菜单“加入剪辑”，接受图片/视频/声音，代码素材保留原正式导入链路。
- 分级：工程、素材、轨道与图片编辑属性仍走既有实体查询/读写；跨领域准备媒体、检查来源、落位与保存属于编排桥梁。新增 `send_video_edit_to_canvas`、`edit_video_edit_program_frame`，扩展既有 `place_video_edit_creative_result`；没有新增专用“设置值”工具或旧式 HostCommand。

## 完成行为与设计决定

1. 节目“发送当前帧到画布”与时间线“发送片段到画布…”选择当前或其他画布。当前帧保留完整序列画幅；图片/图文片段发送首帧画面，视频/代码片段按完整片段范围导出 MP4，声音导出 WAV。独立片段保留裁切、速度、效果、关键帧与链接声音，不混入其他时间线画面。
2. 源剪辑与目标画布在异步准备之前固定。期间源文档编辑/关闭或目标画布编辑/关闭均拒绝迟到写入，输出文件保留；画布新增进入原撤销栈，保存回读核实并返回撤销回执。复用输出时重新检查资产内容身份，变动则作废缓存，下一次发送重新准备媒体。
3. 当前帧直接经正式离屏渲染/PAL 写成受管 PNG，在独立图片编辑器打开，无需先弹出保存文件对话框。回填使用原时刻上方空轨或新轨的一帧图片片段，轨道、素材和片段同一步撤销。
4. 助手帧编辑返回 `frameEditSessionRef` 与 `returnPlacement`。后续放入携带该会话，复用 UI 原始绑定；原剪辑编辑、关闭或回填位置被改写时拒绝。会话不持久化，最多保留 16 个，过期后应重新打开帧编辑。
5. 画布媒体输入/正式完成结果、生成历史结果、资产库与图片编辑器共用发送菜单/服务，可背景打开指定剪辑并选择素材面板、播放头覆盖、插入；原空轨加入/替换所选入口保留。覆盖/插入复用核心时间线算法和音画落位，不另写裁切或同步锁分支。
6. 先固定剪辑目标，再解析异步来源；页面、播放头或当前工程随后切换不会改送达位置。素材面板返回正式 item 引用，资产媒体以 assetId/内容身份记录，不伪造文档或生成来源。
7. 画布保存失败保留会话修改，发送弹窗改为“重试保存画布”，只调用已有保存确认，不重复新增/出帧。助手失败保留原结构化恢复信息，应沿 `retry_canvas_document_save` 恢复，不重放流转操作。
8. 媒体仅由 PAL、正式媒体检查与既有资产收录读取/写出；节点保存裸本地路径，不持久化临时显示 URL。未新增主进程 IPC、日志文件、网络生成或编码器。

## 开源选型依据

已有 Mediabunny 编码/导出、正式合成渲染、Zustand 画布历史与共享 Ui* 已满足本次流转。沿现有依赖复用，比另引 FFmpeg 导出支路、另建节点或第二套撤销/媒体复制服务更能保持画面、声音、取消和保存契约一致。因此没有新增依赖或自研像素/编码算法，也没有新增分发许可义务。本次仅实现轻量跨领域编排。

## 设计自查

1. **助手只凭名称和说明能否用对？** 可以。能力名称说明来源剪辑、目标画布或图片编辑；参数是完整文档/序列/片段引用、整数帧、落位方式。返回真实资产/节点/素材/片段引用与保存核实结果；原帧回填明确要求会话绑定与一帧时长。
2. **能否 AI 先做、人只确认？** 可以。助手选择源和目标后由正式服务自动取帧/导出、收录、媒体校验、放位与保存；人选择工程或确认效果，随后在同一撤销栈修正。
3. **产物能否直接流进其他工作区？** 可以。剪辑输出成为正式资产与画布媒体输入；画布/生成历史/资产/图片文档进入剪辑；图片编辑后的帧回原时刻，文件与资产不因撤销节点而删除。

## 尚未验证与交接风险

- 未跑真实 Electron/Reality、图片编辑器实机往返、真实 GPU/编码/音频输出、长片性能与真实 Pi/MCP 客户端；像素与编码器在精确测试边界替换，不能把这些测试当视觉/试听验收。
- 独立图片/图文片段发送首帧静态图片；含动画要保留运动时应导出对应范围成片。调整图层、嵌套序列、依赖其他片段的跟随不作为独立流转，明确提示先导出合成；未改自动重构/嵌套模块。
- 回填用上方一帧图片覆盖原时刻，保留原片段结构；不替换整个原视频、不扩展回填时长。来源会话关闭/编辑后拒绝旧回填，重新打开当前帧即可。
- 公共能力登记、applicationDomain、时间线菜单/宿主、助手台账与总览为共享文件，含其他代理增量；总管理者须分清本任务改动，不以整个工作区差异暂存本任务。
- 本任务未改 `electron/main`、preload、SDK 或构建配置。未启动/重启开发实例；正式桌面验收需由总管理者在安全边界更新运行产物后安排。
