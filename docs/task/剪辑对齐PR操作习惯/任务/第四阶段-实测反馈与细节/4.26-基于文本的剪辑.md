# 4.26 基于文本的剪辑

状态：实现与定向检查完成，待总管理者审查。没有执行 Git 写操作、修改 SDK、真实付费识别、Reality 或启动开发环境。

## 范围与唯一入口

- 字幕/标记面板同组新增“文本”标签。显示整个序列或选中片段，按停顿、句末和片段边界分段，虚拟化段落；点词定位，拖选/Shift 选区，播放高亮复用口播容差规则。
- 删除、提取到新序列、插入到播放头统一进入 `editVideoEditText`，委托现有范围波纹删除、复制、插入和工程历史；链接音画及其他同步轨道一起处理，一次操作只占一步撤销。
- 口头禅识别抽出 `audioEditFillerBlockIds`，口播与剪辑共同使用；保留口播自定义词表，默认补齐“啊、那个”。静音必须有口播音频检测证据，复用保留短停顿、锁定内容和已应用裁切的规则，不拿词间空隙推断静音。
- 复用 4.17 的已保存口播识别结果与费用确认。新转录在同一字幕提交中保存源词；恢复已有结果不识别、不重复生成字幕。识别未完成时继续原声音文档，重新转录仍进入既有费用确认。
- 序列保存识别批次引用、素材/声道身份及词的源微秒范围。读稿按当前片段源范围、速度、倒放重新映射；片段拆分、修剪、移动、复制和摘选不需要重新识别。源与边界时间换算统一在 `clipSpeed.ts`。
- 选中片段再次转录只替换识别覆盖的源范围，保留其他稿子；素材或声道替换后旧稿失效。恢复与停顿检测绑定原声音快照，异步期间目标或口播变化则拒绝提交。

## 选型与规模

比较了 [React Virtuoso](https://virtuoso.dev/react-virtuoso/api-reference/virtuoso/) 和 [Lexical](https://lexical.dev/docs/intro)。采用项目已有 React Virtuoso 与 `UiTextToken`：本功能选择带时间戳的词并剪媒体，持久真相在剪辑文档；不需要再引入富文本编辑器及第二份文本状态。没有新增依赖，也没有自研转录、静音检测或时间线内核。

典型输入是口播短片；验证上限样本为 30 分钟、500 片段、12000 词。词源数据上限 100000；段落最多 128 词，列表虚拟化。此样本只证明映射与数据规模，不代表 Electron 的滚动、播放或识别性能已验收。批量剪辑仍受现有每序列 500 片段、每工程 32 序列限制，超过会原子拒绝，不部分提交。

业务真相属于剪辑文档；面板只持有词选区、范围与瞬态状态。普通修改走既有自动保存，助手操作显式保存并回读；保存失败保留修改、报告只重试保存，禁止重放剪辑。声音引用与识别快照沿既有字幕混音文件保存，页面关闭不重放付费任务。

## 助手覆盖分级

属于能力增量。新增 `video_edit.sequence.transcript` 与 `text_silences` 两个只读通用属性，分别给出当前词索引/原文/时间范围/可编辑性及音频证据的静音范围；它们由正式识别与时间线维护，不允许任意写入或增加第二份文本状态。

算法能力为 `ripple_delete_video_edit_text`、`extract_video_edit_text`、`insert_video_edit_text` 和免费 `detect_video_edit_text_silence`。选择器接受包含首尾的词索引范围、原文匹配及出现次序、口头禅词表或检测静音。助手先读稿，再确定“讲价格”对应的词范围；不把字面匹配冒充语义识别。返回实际处理的原序列半开帧范围与结果序列稳定引用，供既有导出/其他步骤消费。

UI、Pi/MCP 投影与执行共用领域服务。能力声明、目标绑定、撤销、保存失败恢复及结果验证进入现有注册源，无新 IPC、日志通道或 MCP 手写字段表。文本标签复用现有剪辑工作区/停靠面板 Surface，不新增独立 Surface。

## 设计自查

1. **助手只凭名称和说明能否用对？** 可以。先读当前 `transcript`，再用明确词索引或原文匹配；词索引、半开帧范围、出现次序、需要词级时间、锁轨与恢复路径在能力说明中注明。
2. **能否 AI 先做、人只确认？** 可以。助手读取全文后选择价格段，或直接批量找口头禅/检测静音并执行；人查看结果并微调，整批可一步撤销。付费识别继续走原审批。
3. **产物能否直接流进其他工作区？** 可以沿既有剪辑序列、素材引用与跨工作区流转继续使用；摘选是正式序列，不搬文件。返回序列引用可以直接交给既有导出能力。

## 仍需总管理者注意

- 工作区并行修改很多，共享接入文件包含其他任务内容；只审查本任务增量，不覆盖或整份还原共享文件。
- 句级识别只显示/跳转，不能猜词级时间做破坏性操作。多人重叠且未标明声音角色时保护相关词，可选择明确人声轨道重转录。音乐/环境/音效角色不参与对白源归属。
- 静音批量选择目前在整个序列范围使用；人可先用片段范围转录/检测限定识别材料。静音必须先检测，检测本身不删除媒体。
- 嵌套序列声音识别词尚未递归绑定到子序列源，暂不声称支持嵌套源的文本编辑；没有修改多机位、代理或嵌套实现。
- 原 4.17 混音记录缺少源快照时，仅在声音签名一致的情况下恢复；已改变的旧稿需要重新转录，不猜源映射。
- 尚未验收真实 Electron 的浮窗、拖选/连续播放体验、长片 UI 性能、真实模型词级识别、付费审批及跨工作区实际输出。没有维护或重启开发环境。
