# 4.30 动态图形标题模板

2026-10-07：实现与精确检查交回总管理者审查。未执行 Git 写操作、SDK 修改、全量测试、Reality、构建、开发实例启动/重启或真实付费调用。

## 实现与关键设计

- 新增六类内置模板：下三分之一人名条、标题卡、章节标题、片尾字幕滚动、数字计数、强调标注框。落成现有 `graphic` 片段及 `graphic_object` 文字/形状对象，使用既有源时刻关键帧与合成器，不增加另一套渲染/动画状态。
- 参数包含主文字、副标题、图形/文字内容色、字体、秒数、左侧/向上/淡入动画及计数首尾。秒数按序列有理帧率取整，入出场终点使用最后可见帧；计数使用101个保持文字关键帧，字幕逐行使用位置与不透明度曲线。
- “基本图形”加入现有 Dock 标签、面板菜单、系统浮窗白名单、焦点与快捷键作用域。单击选择，双击/按钮放到播放头；拖入时间线使用既有拖放入口及覆盖/插入规则。默认放在现有画面上方，显式落轨遵循落点规则。素材项、片段、组合与新增轨道一次事务，一步撤销。
- 模板参数区可批量修改所选组合的文字、两种颜色、字体和总时长，保持片段、素材项与图形对象稳定标识；只写实际改动的字段。其他对象、运动和曲线继续在效果控件已有图形/文字编辑器修改。模板入场/计数参数用于创建，实例动画细改使用既有关键帧控件。
- 另存所选1–8个文字/图形片段为本机模板，保留组合层次、相对时序、文本样式、图形参数与关键帧。应用按目标画幅、帧率、时长换算，重映射新对象标识。只保存自包含标题，不保存媒体/代码/效果/跟踪引用；原速标题支持，带变速/倒放/效果/跟随的组合整组拒绝。
- 复用4.15本机预设模式：Zod校验、存储成功后才发布列表、存储失败保留原库、读取损坏时禁止覆盖。最多128个自定义模板；超过24项使用已安装的 `react-virtuoso` 网格。业务真相归模板库与剪辑领域实例，面板只保留筛选及参数草稿。
- 描述生成复用 `llmConfigService` 与 `llmChatStream`/`llmCancelTask`，使用启用的文本模型。手动入口沿现有费用确认组件，助手入口R2审批。模型只返回封闭模板参数；校验完整返回、内容上限、取消、原会话和原文档基线后才原子落位。选序列和播放头在等待前固定，后续修改/关闭时拒绝迟到结果；没有执行模型代码或真实付费请求。
- 关键执行层沿现有日志入口记录模板应用、本机保存、描述生成的开始、完成、失败；不记录描述正文、凭据或新增日志通道。
- 单独定义覆盖参数schema，避免Zod4 `partial()`给省略字段填默认值、使助手只改文字时重置原时长/颜色。

## 选型、规模与边界

- 对比 [Lottie文本更新](https://github.com/airbnb/lottie-web/wiki/TextLayer.updateDocumentData) 与仓内图形/代码素材运行时。Lottie能更新动画文本，但引入它还需增加独立导出/渲染桥及格式映射；现有图形对象已满足可编辑文字、形状、关键帧和同源导出，采用既有引擎和声明式模板数据，未另造动画引擎或增加依赖。
- 停靠/浮窗沿仓内 `dockview-react` 和已有Electron浮窗宿主；[Dockview官方面板模型](https://dockview.dev/docs/core/overview/)确认面板可分组、停靠及浮出。没有调用浏览器浮窗代替现有Electron窗口。
- 典型输入为单图形片段、2–3个对象；上限每模板8片段、每图形32对象/32曲线/2048点，沿既有工程32轨/500片段边界；模板时长0.5–60秒，片尾字幕每段最多16行，超长须分段。字体沿现有图形引擎三种通用字体，不新增字体下载或任意字体执行。
- 标题按源尺寸换算后超过既有图形/字形预算时整组拒绝；文本栅格仍使用现有字形预算。只验证逻辑与契约，不宣称真实字体排版、GPU画面、成片或高规模性能已验收。
- 本机模板同步落盘，不参与剪辑文档历史；模板实例进入同一工程保存/撤销屏障。失败先保留现有状态；描述生成失败不会插入半成品，重试可能重新计费。

## 助手覆盖与设计自查

覆盖分级为能力增量。`video_edit.title_template`可通用列出、读取 `name/definition`，本机自定义模板通过通用集合创建/删除，内置模板固定。参数/样式/图形对象细改沿已有通用实体。只有应用时的尺寸/帧率/关键帧换算和自然语言生成注册为 `apply_video_edit_title_template`、`generate_video_edit_title_from_description`；两端投影同一正式声明，公共入口保存后回读核实。不新增专用设置某值工具。

1. **助手只凭名称和说明能否用对？** 能。模板目录、封闭definition/覆盖参数schema、明确原剪辑/序列/轨道引用、整数帧和秒数单位来自正式注册；公共列出→读取→应用→保存回读，以及通用创建/删除有精确结果证据。模板实例细改沿已有图形对象和文字通用属性。
2. **能否AI先做、人只确认？** 能。描述生成先选择模板与动画参数并在原序列落位，人只需现有费用确认和效果控件微调；所有实例修改同一历史，取消与迟到结果不覆盖新编辑。
3. **产物能否直接流进其他工作区？** 能。产物就是现有可编辑图形/文字片段，进入已有节目合成、选帧、导出及跨工作区流转链。未新造外部文件搬运流程；本轮没有重复实测既有跨工作区/编码链。
