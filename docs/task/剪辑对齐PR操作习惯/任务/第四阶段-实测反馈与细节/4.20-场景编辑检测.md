# 4.20 场景编辑检测

2026-10-07：实现与定向验证完成，待总管理者审查提交及真实 Electron 验收。修改了主进程与 preload；按本任务授权未构建、启动或重启开发实例，未做 Git 写操作，未改 SDK。

## 行为与选型

- 视频片段右键“场景编辑检测…”：少切 ↔ 多切灵敏度；拆分片段、添加片段标记、创建素材面板子剪辑可多选。“检测并应用”直接完成整组操作，也可先检测、人确认后应用。进度与取消走后台任务，修改灵敏度后重新检测。
- 选择随包 FFmpeg 的 [scdet](https://ffmpeg.org/ffmpeg-filters.html#scdet)，复用 `loadFfmpegPath` 唯一定位入口、`scripts/video-decoder-ffmpeg.cjs` 安装约定及现有测试分层，没有新增下载与依赖。比较了 `select=gt(scene,x)` 与自研直方图差：scdet 原生提供切换分数/时间，保留帧节奏且不必传输像素到 JS；select 更适合筛帧，本任务只要切点；自研暂无效果或性能优势，因此不新增像素算法。许可沿现有随包 FFmpeg 的 GPL 分发义务，本次未变二进制来源或打包规则。
- 解码、512 像素宽缩放和场景评分在隐藏子进程执行，限制解码/输出/滤镜线程为 2；主进程只解析有界元数据。灵敏度 0–100 映射阈值 25–1。全局最多两个不同分析；相同内容/范围/参数并发共享一次分析，单个调用取消不影响其他调用，最后一个取消才终止子进程。
- 复用 4.7d 智能区域的 `identifyMediaContent` + `ContentDiskCache` 模式。键包含算法版本、规范路径/设备/文件身份/尺寸/mtime/ctime、源范围和灵敏度，排除请求 ID；磁盘预算 16 MiB。损坏缓存重算，检测过程中源身份变化不落缓存。身份是现有文件身份策略，不额外全量读取视频作字节哈希。
- IPC 检查可信窗口、严格参数和规范真实路径的媒体根权限；取消与进度归原窗口，主导航/窗口销毁/退出清理任务。应用前重验源身份及文档快照，异步等待期间的编辑、换源、关闭使结果失效，不覆盖后来编辑。
- 拆分从后往前调用既有剃刀领域算法，保留关联声音、变速/倒放源时间、关键帧、片段标记与字幕迁移；整组只发布一次文档修改、占一步撤销。锁轨及文档上限在提交前整组拒绝。
- 子剪辑为既有 `video_edit.item` 的可选 `sourceRange`，右端不含，不复制或转码媒体。素材列表范围/时长/排序、图标详情、源监视器初始范围与所有 `makeVideoEditItemClip` 放置路径共用这一范围；旧素材无该字段时保持原行为。

## 助手覆盖分级

- 检测属于算法长任务，新增 `detect_video_edit_scenes`：输入正式 documentRef/clipRef 与灵敏度，返回原文件秒切点、当前序列帧切点及本会话 analysisId；R0、可取消、无写入，不向助手传原始文件路径。
- 整组应用属于需一次撤销的算法操作，新增 `apply_video_edit_scenes`，同 UI 领域服务，消费真实 analysisId 与三个选项，R1、可取消、保存后回读核验并返回 effect receipts。保存失败保留内存结果、明确只重试 `save_video_edit`，禁止重复应用。
- 单点拆分继续复用 `split_video_edit`；单个标记继续走 `video_edit.marker` 通用集合。子剪辑不新建实体或专用增删工具；`video_edit.item.source_range` 由既有 Fields 定义派生读写及集合创建，null 恢复整段素材，不影响已放入时间线的片段。
- 未增加 Pi/MCP 私有表或提示词分支。公共能力结果、通用属性读写/null 恢复、保存回读、撤销及媒体消费有精确测试；门禁代表路径完整，未实跑模型决策、Pi/MCP 或真实 Electron。

## 设计自查

1. **助手只凭名称和说明能否用对？** 能。能力明确目标片段稳定引用、灵敏度方向、原文件秒/序列帧单位、检测无写、结果失效与批量应用三种行为；analysisId 由检测返回，不允许猜测。子剪辑范围沿正式属性定义读写。
2. **能否 AI 先做、人只确认？** 能。助手先免费检测，按返回切点一次应用；人可确认数量或调少切/多切重新检测，整组可撤销。无需逐点手动剃刀。
3. **产物能否直接流进其他工作区或步骤？** 能进入后续剪辑：拆分/标记直接属于当前序列，子剪辑在素材面板可源预览、拖入/追加及建立序列；复用既有剪辑导出/产物收集进入资产库后供其他工作区消费。本次未新增跨工作区剪辑片段引用，也未实跑导出交付。

## 未验证与限制

- 这是传统场景评分，不识别镜头语义；闪光、运动、渐变可能需调灵敏度。缩到 512 宽的质量、长视频耗时及取消延迟未做实机性能验收。
- 每次源范围 ≤30 分钟，最多 499 切点；既有每序列 500 片段/标记、文档 500 素材项限制仍适用，有关联声音时可用切点数更少。超限整组拒绝，需降低灵敏度或缩短范围。
- 子剪辑静态缩略图仍复用原媒体首图；播放范围与时长已区分，没有新增每个镜头独立封面生成。
- 检测磁盘缓存可跨会话复用；analysisId 是当前打开文档的会话结果，关闭或文档编辑后须重新检测（可命中缓存）。
- 未做真实 Electron 菜单/模态/预览与 Pi/MCP 实机验收；未运行 Reality、全量测试、构建、开发重启或付费调用。主进程/preload 改动需总管理者在交付用户前构建并重启。
