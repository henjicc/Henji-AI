## 数据与实现决定

复用 CodeMaterial 的值类型和 linear / hold / ease 枚举；集中插值放 keyframeInterpolation.ts，片内帧适配、求值和修剪放 keyframes.ts。没有引入另一套动画运行时；代码滤镜原 curves 保持素材源时刻（微秒/有理余数），新增片段及 builtin.curves 使用片内整数帧。字段可选，旧文件不写入新字段仍可读取；缺失锚点为 .5/.5。

关键帧为 {time, value, interpolation}，time 升序且不重复，范围 0–duration−1，每项最多 256 点。首点前/末点后保持边界值；插值由左点决定到下一点的区间。linear 线性，hold 定格，ease 固定三次贝塞尔控制点 (1/3,0)、(2/3,1)，即 smoothstep；开关及选项只接受 hold。没有任意贝塞尔手柄编辑。修剪内部可保存 easeRange 以保留原曲线区间，此信息不显示在正式界面。

预览和导出共用 VideoEditRenderer，在跟随结果之后求值；转场窗口两端也使用同一求值。跟随时 x/y 曲线为实时跟踪位置上的偏移，scale 为实时跟踪缩放的乘数。不修改跟踪器实现。锚点转换复用 clipGeometry，GPU 合成使用同一中心位置。

混音以输出采样时间求音量曲线，逐样本线性/缓动，无块级台阶。音频效果参数复用同一求值函数与现有 DSP 链逐样本更新，复用参数输出和单样本缓冲。淡化与音频过渡仍乘在同一增益链。音频效果深链的实时 CPU 成本未作实机性能验收。

同步检查并处理普通/波纹修剪、滚动、内滑邻居、拆分、变速/比率拉伸、帧率切换、助手修改时长、效果复制和保存组合应用：修剪重定位曲线并保留区间值，速度/帧率转换重映射帧网格并去重。素材外滑保持片内关键帧时间。短目标片段截取复制来的效果曲线。保留完全透明代码/图形片段的资源跳过行为。

## 开源选型与 UI 复用

查阅成熟方案：[Three.js KeyframeTrack](https://threejs.org/docs/pages/KeyframeTrack.html) 提供 typed times/values、插值与变换；[GSAP Timeline](https://gsap.com/docs/v3/GSAP/Timeline/) 提供 tween 时序。此处已有持久曲线与精确源时钟，两者都需要额外绑定及序列化适配，不能直接替代现有撤销、素材有理时钟和采样混音。采用现有 CodeMaterial 曲线契约与现有 DSP/GPU 栈，只增加有界纯函数适配，没有增加依赖。贝塞尔依据 [W3C CSS Easing](https://www.w3.org/TR/css-easing-1/) 的控制点定义。

复用 UiIconButton、Dropdown、PanelTrigger、NumberInput、参数手势与领域写入。新增的是剪辑领域控件，不是通用 UI 组件；图形 SVG 只用于数据曲线/标记，在图标门禁登记理由。
