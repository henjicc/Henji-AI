# 本轮剪辑用户实测清单

整理日期：2026-10-07 早；范围：2026-10-06～10-07 的第四阶段任务及其接续记录。状态：文档整理完成，以下实测均未由本任务执行。

## 怎么测

在总管理者审查并更新应用后，用一份可撤销的测试剪辑，准备带声音视频、对白、背景音乐、运动人物、文字画面和两段同场多机位素材。先做各组的 **先测**，再做 **再测**；操作成功后通常再撤销一次、恢复并保存重开，检查结果没有重复或丢失。记录“操作、实际结果、是否可重复”，失败时附所在界面和素材特征。

以下每组 3～8 条，只写用户操作与期望。带 **可能计费** 的生成、识别、翻译仅在用户确认费用后测试，可先完成准备与取消步骤。窄面板、浮窗、石墨/纸白主题检查可复用同一份素材，不必把每条重复测一遍。模型、GPU、FFmpeg 的既有精确实测不等于本清单的真实窗口、听感与成片验收。

通用外观检查：把本次用到的面板缩窄并浮出，依次切石墨/纸白主题，打开菜单并查看悬停、选中、空内容、处理中和失败提示。期望：标签与操作可读，选中可辨，弹层能完整操作，提示不挡编辑；素材表格需要的横向滚动仍可使用。

## 素材与时间线

依据：[4.2](4.2-效果控件重整与播放头自动选中.md)、[4.4](4.4-标尺入出点与吸附反馈.md)、[4.6](4.6-工具匹配帧与缩放滚动条.md)、[4.9](4.9-监视器缩放与回放分辨率.md)、[4.20](4.20-场景编辑检测.md)、[4.29](4.29-新界面体检.md)；另承接总览既有待实测项。

1. **先测**：把含子文件夹的视频文件夹拖到素材面板，展开素材箱，再将素材移入另一箱。期望：目录层次与素材可找到，拖动标签跟手，素材可预览和放入时间线。
2. **先测**：从源监视器分别拖到节目画面的五个放置区，再在时间线做覆盖与插入；在节目显示 100% 并平移后重复一次。期望：高亮位置与实际落点一致，插入后续片段让位，带声视频音画落在对应区域且不重复发声。
3. **先测**：用 I/O 设置范围，拖标尺范围两端及中间，再拖片段接近播放头或编辑点。期望：范围和持续时间同步，吸附线只在吸附时出现，松手或取消后消失；时间码输入与拖动定位一致。
4. **先测**：在设置打开“播放头自动选中片段”，在上下叠放视频间播放、定位并隐藏或锁定上层；拖效果数值后撤销，另一次拖动按 Esc。期望：选中当前最上方可用片段，拖参数中不抢选区；撤销回拖前值，Esc 放弃本次变化。
5. **再测**：拖时间线底部缩放条的中间与两端，用 Z 点击/框选缩放、Alt 缩小；拖节目/源面板到同一浮窗，再拖单标签贴回。期望：缩放与平移可控，标签可切换、拆出和停靠，节目画面不因切标签丢失。
6. **再测**：在源/节目监视器滚轮缩放、中键平移，播放时依次选完整、1/2、1/4、1/8，再暂停并切换暂停保持选项。期望：显示比例与回放清晰度各自生效，默认暂停恢复清晰；选帧与导出仍清晰。
7. **再测**：切素材列表视图，拖列标题分界并横向滚动；缩窄面板、使用长素材名，并查看项目卡片/列表预览。期望：列内容可查看，列宽拖动行为可核对，名称和操作可辨。列宽完成证据缺失，不能预先记为通过。
8. **先测**：对一段有明显镜头切换的视频右键“场景编辑检测”，先看结果，再分别应用拆分、标记、子剪辑，撤销整组。期望：切点合理，音画同步且无漏段，子剪辑只播放自己的范围；取消分析不改剪辑。闪光/渐变不理想时可调灵敏度再测。

## 修剪与速度

依据：[4.6](4.6-工具匹配帧与缩放滚动条.md)、[4.13](4.13-片段速度与比率拉伸.md)。

1. **先测**：对链接音画分别用 B 拖两端、N 拖相接切点、Y 拖片段内容、U 移片段，再撤销。期望：波纹带动后续，滚动保持总长，外滑保位置/长度，内滑保内容并由邻段让位；声音仍同步。
2. **先测**：Ctrl+R 将同一带声片段设成 50% 和 200%，分别开/关保持音调及波纹；再倒放。期望：时长与后续位置符合选择，画面、声音、缩略帧和波形方向一致；极端速度的音色需实际试听判断。
3. **先测**：按 R 分别拖片段入端和出端，碰到邻片或吸附点后松手，再撤销；另一次按 Esc。期望：原有源内容保留、速度随长度改变，不能穿过邻片；一次拖动一步撤销，取消不留变化。
4. **再测**：在变速/倒放片段中间按 F，再在源监视器按 Shift+R；尝试锁轨和素材余量不足的修剪。期望：匹配到同一画面，越界收紧或明确拒绝，不留下失步片段或多余撤销。

## 效果与调色

依据：[4.7](4.7-内置效果框架与第一批视频效果.md)、[4.15](4.15-效果预设搜索与收藏.md)、[4.18](4.18-Lumetri颜色.md)。

1. **先测**：多选视频、声音及一个锁轨片段，拖入模糊/马赛克，再开关、调强度、换序和删除。期望：落点高亮与实际应用一致，只改适用且可编辑片段，整批可一步撤销；低回放分辨率下相对作用范围基本一致。
2. **先测**：在 Lumetri 调基本校正、RGB 曲线及色相曲线，增删/拖曲线点并重置。期望：画面及时变化，曲线不中断、不意外反向；肤色、灰色和亮暗边界需目视核对。
3. **先测**：导入一份已知正常的 .cube，分别作输入 LUT 和 Look，强度从 0 调到 100；保存重开，并导出短段比较。期望：强度与顺序可辨，重开效果不丢，导出与节目画面一致；无效文件给可理解的错误。
4. **再测**：对颜色偏差镜头运行自动校色，再选择另一片段作参考匹配，应用后撤销。期望：给出可检查的建议或匹配结果，多帧结果合理，原修改可恢复；不要求逐像素复制参考或完整 HDR/Log 等价。
5. **再测**：搜索中英文效果、收藏一项，保存多效果组合预设；跨剪辑拖放/双击应用，重启后查收藏与模板。期望：清空搜索恢复折叠，组合顺序与强度保留、应用一步撤销；保存预设时不把旧片段跟踪绑定带到新片段。

## 过渡与关键帧

依据：[4.3](4.3-过渡与淡化手柄.md)、[4.4](4.4-标尺入出点与吸附反馈.md)、[4.14](4.14-关键帧.md)。

1. **先测**：设置默认过渡，在编辑点按 Ctrl+D、Ctrl+Shift+D，对所选片段按 Shift+D；拖七种视频过渡到切点并换种类。期望：视频/声音各用对应过渡，重复应用替换，画面方向与参数符合名称。
2. **先测**：拖过渡块两端和中间，再把相邻片段移开或修短；对有空白的一端加过渡。期望：时长/位置可调，移开后保留合适的单侧过渡，过短时收紧或移除，和片段编辑一起撤销。
3. **先测**：拖视频及声音两端淡化手柄，试听并导出短段。期望：淡入淡出平滑、无突跳，预览与成片一致；一次拖动可一步撤销。
4. **先测**：为运动、不透明度和内置效果参数启用秒表，在两个时刻改值，切线性/定格/缓动插值，再关闭秒表并撤销。期望：导航到对应点，插值可辨，关闭保留当前值，撤销恢复曲线。
5. **再测**：按 P 在画面不透明度线和声音音量线上加点、拖点、Ctrl/Command 删点；拆分、修短或变速后播放。期望：点与内容时刻正确对应，声音变化无台阶；窄效果面板和浮窗仍能读标签、开插值菜单。

## 遮罩与跟踪

依据：[4.10](4.10-跟踪器与遮罩.md)。

1. **先测**：给效果建立矩形、椭圆与钢笔遮罩，移动顶点/控制柄，切相加/相减/交叉并调羽化、扩展、反转。期望：作用范围与形状吻合，片段变换后仍贴住画面，取消绘制/拖动和撤销可恢复。
2. **先测**：对运动物体点选形状跟踪，检查三个候选并确认；另用框选建立物体框跟踪，前后单步、连续跟踪、停止后继续。期望：候选可选，目标连续跟随，停止保留已有结果，续跟不丢前段。
3. **先测**：在遮挡/转身或跟丢处补点、拖框纠错，再把结果用于效果区域、手绘遮罩跟随或另一片段跟随。期望：纠错生效，绑定时不突然跳位，取消绑定和撤销可恢复，删除跟踪后仍能移除失效绑定。
4. **先测**：在有纹理的视频设 1～4 点跟踪；为屏幕四角建立平面跟踪并把图片贴上。期望：点位置连续，图片随透视贴合，无对角线裂缝；低纹理/模糊/遮挡失败可看见并纠错。
5. **再测**：缩放/平移节目画面、降低回放分辨率，再到浮窗编辑跟踪/遮罩；切到文字工具后返回。期望：控制柄命中正确，叠层互不抢操作；短段导出与节目中的区域、跟随和角点贴合一致。

## 智能区域与本地模型

依据：[4.7d](4.7d-智能区域.md)、[4.11](4.11-本地模型下载器.md)、[4.23](4.23-自动重构画幅.md)。

1. **先测**：在人脸、人物和带文字的视频应用人脸打码、背景虚化、文字模糊，等待分析并逐帧看运动/遮挡处。期望：作用范围跟随主体，完成后自动显示；文字模糊是遮挡效果，不是修补背景。
2. **先测**：首次使用未安装模型时观察下载，再到设置“文件与下载 → 本地模型”取消、重新下载、删除后重用。期望：进度/失败原因可读，取消保留续传条件，删除后按需再下载；只有校验完成才可使用。
3. **再测**：切自动/国内/国外下载源，并尝试可重复的网络失败后重试；对同一视频多个效果共享的失败区域点击“重试”。期望：恢复后全部需要该区域的效果可用，界面不阻塞；不要求助手直接重试区域（仍是覆盖缺口）。
4. **先测**：把横屏人物序列自动重构为竖屏，选择慢/默认/快，再对单片段用人脸或指定跟踪重构。期望：新序列不改原序列，主体与切点附近构图合理，整组可撤销；多主体无法兼顾时明确提示。
5. **再测**：手改一个重构运动点后重新生成，另在分析中取消或修改原片段。期望：手动点保留，旧分析不覆盖新编辑，取消不留下半个新序列；字幕/图形是否适合竖屏需另行目视调整。

## 声音（效果 / 响度 / 闪避 / 基本声音）

依据：[4.7c](4.7c-音频效果与音频过渡.md)、[4.16](4.16-音频增益与响度标准化.md)、[4.21](4.21-音频自动闪避.md)。

1. **先测**：为对白依次加降噪、均衡、压缩和限幅，开关单项、调强度和顺序，播放后从中间定位。期望：噪声减少而人声可懂，无额外延迟或断续；对同一短段导出试听，结果一致。
2. **再测**：在 44.1kHz 与 48kHz 序列分别听降噪、混响和音调变换；加指数淡化与恒定功率过渡。期望：音色、尾音、接缝可接受，无点击声；44.1kHz 降噪此前未单独试听，需重点记录。
3. **先测**：多选不同响度声音按 G，分别试相对增益、共同峰值和各自峰值对齐；撤销整组。期望：各方式区别可听可读，锁轨或目标超出允许增益时整组拒绝，不留下部分调整。
4. **先测**：测量对白并按 -16 LUFS 或 -23 LUFS 标准化，再测一次；也测一段静音/很短声音。期望：显示合理响度/真峰值，标准化达标或明确解释限制，不能测量的项不假报零；片段最高增益约 +6dB。
5. **先测**：在“基本声音”批量指定对白、音乐、音效/环境角色，对音乐生成回避，调降低量、敏感度与淡化。期望：对白时音乐降低、停顿恢复，噪声误触发可调，角色与回避结果可撤销；不期待自动识别人声身份。
6. **先测**：手改一个自动音量点，再重新生成回避；分析中取消或改原片段。期望：手动点保留，旧结果不覆盖新编辑，取消不留下部分音乐曲线。
7. **再测**：缩窄效果控件并浮出，切多个声音片段检查角色与回避；保存重开。期望：参数可操作、结果保留，试听平滑；基本声音当前范围是角色与回避，音轨效果/总线尚未实现。
8. **先测**：导出带整片响度目标的 MP4/AAC 和 WAV，播放并用可用计量工具核对文件响度/峰值。期望：导出长度与音画同步，目标与实际值合理，时间线音量不被导出设置改写；最终 AAC 真峰值此前没有实测保证。

## 字幕与文本剪辑

依据：[4.17](4.17-自动字幕.md)、[4.19](4.19-节目监视器文字.md)、[4.26](4.26-基于文本的剪辑.md)。

1. **先测，可能计费**：按整序列、入出点或选中片段准备声音，确认费用后生成字幕；取消准备/识别各试一次。期望：字幕只在目标范围，长句分段不漏字，已保存识别可继续恢复，整批落位一步撤销。
2. **先测**：导入已有长字幕免费整理，点时间线字幕与面板行，搜索后再点时间线；拆分/合并、批量样式、保存模板并重开。期望：两处选中联动、草稿不被旧值覆盖，样式与模板保留；窄面板“更多”可完整操作。
3. **再测，可能计费**：将单行字幕翻成第二语言，检查长译文、上下行及竖屏安全区；带入出点导出短片及 SRT/VTT。期望：原文/译文对应，字幕与成片从入点开始对齐；取消/失败不写半批译文，重试费用需重新确认。
4. **先测**：T 在节目画面点放标题、拖框放段落，用中文输入法改字；V 移动/缩放，调描边、阴影、底框，浮出节目面板再编辑。期望：光标与文字叠合、换行正确，输入 T/V 不触发快捷键，移动和连续输入各可一步撤销，导出样式一致。
5. **先测**：在已有词级稿的“文本”页点词、拖选/Shift 选词，删除一段后撤销，再摘选到新序列并插入播放头。期望：删的是所选词对应音画，后续波纹闭合，摘选保留内容和文本，播放高亮跟随当前词。
6. **再测**：批量选择口头禅；先检测静音再选择删除；对已修剪/变速/倒放片段核对词位置，并尝试只有句级时刻或多人重叠材料。期望：有证据才删静音，词时间随内容改变，精度不足/归属不明时明确保护，不猜逐词删除。

## 多机位与嵌套

依据：[4.24](4.24-嵌套序列.md)、[4.27](4.27-多机位剪辑.md)。

1. **先测**：多选带效果、声音、字幕/标记的片段右键“嵌套”，双击及 F 进入子序列，修改后回父序列，撤销嵌套。期望：嵌套前后画面/声音一致，修改就地反映，整组一步撤销；循环引用或锁轨等非法操作明确拒绝。
2. **再测**：同一子序列拖入两次，对其中一段变速/倒放，加父层效果；缩短子序列并导出短段。期望：两处不串画面或声音，子序列结束后的空白透明/静音，父层效果和导出与预览一致。
3. **先测**：多选 2～4 个同场视频创建多机位源序列，用声音同步并指定主音频；再试入点/时间码同步。期望：共同声音对齐，固定主音频持续；静音/无关声音自动同步失败时可改手动方式。
4. **先测**：将多机位放入父序列，开节目多机位视图；暂停点机位，播放时按 1～9 换机位，再滚动修剪切点。期望：暂停换整段，播放切后段且不中断，主声音不随机位跳变，一步撤销可恢复。
5. **再测**：运行机位建议，检查噪声、静音与音量接近区间，人工换一段；有条件再试九机位长录像和导出。期望：建议可校正，不把活动/音量当说话人身份；长录像检查同步漂移和响应，不期待固定偏移自动纠漂。

## 导出（预设 / 队列 / 代理）

依据：[4.16](4.16-音频增益与响度标准化.md)、[4.22](4.22-导出预设与队列.md)、[4.28](4.28-代理剪辑.md)。

1. **先测**：选平台/声音/母版预设，分别用适合留边和填充裁切导出含字幕、效果、过渡的短片；保存自定义预设并重开。期望：画幅、裁切、帧率、声音正确，模板保留；高质量母版是高码率 H.264，不要求 ProRes/无损。
2. **先测**：把两个序列/范围依次入队，取消一项、保留另一项，查看完成文件并收录到资产库；有待处理项时尝试正常关闭。期望：顺序导出，取消不删已完成文件，关闭先提示处理未完成项；失败可显式重试，不承诺崩溃续编。
3. **先测**：为 4K 视频建立 720p/540p 代理，观察进度、取消再创建，并开启高于 1080p 导入自动创建。期望：原片仍可用，代理成功后可切换，取消停止本批剩余项；记录实际耗时与流畅度。
4. **先测**：节目/源监视器反复切原片与代理，定位同一动作帧，试 50%/200% 和倒放；再选帧、导出及分析区域。期望：内容时间不跳、声音始终原片，选帧/导出/分析用原片；精准调色时关闭代理。
5. **再测**：用竖拍、不同帧率/不规则帧率和高码率长片重复代理回放，缩窄导出弹窗并用长队列名称。期望：方向/比例/时刻正确，代理不可用时能回原片，参数和队列动作可见；透明视频明确拒绝代理而保留原片。

## 原地生成与跨工作区

依据：[4.12](4.12-原地生成.md)、[4.25](4.25-跨工作区流转.md)。

1. **先测，可先不提交**：在视频/声音空隙、入出点和选中片段右键打开生成/替换/延长/配音面板，逐项取消参考并指定节目时间，换模型再取消。期望：落点、时长、画幅、参考和费用可理解，播放头不被指定参考时间改变，取消不改时间线。
2. **先测，可能计费**：确认后生成带声镜头；生成期间占用原空隙或移动待替换片段，完成后撤销落位。期望：音画链接且只播放一次，结果跟随当前目标或另放空轨，不覆盖新编辑，整组落位一步撤销。
3. **先测，可能计费**：替换带声镜头后移动它，再切回原版本；另一次生成中关闭剪辑，任务完成后重开。期望：原声音随版本恢复，重开只续接原任务并落位一次，不重新计费生成；失败占位可在界面重试/换模型/移除。
4. **先测**：把节目当前帧与独立视频/声音片段发到指定画布，随后切换页面；撤销目标画布新增项。期望：仍到原先指定画布，片段保留自己的画面/声音效果，当前帧保持完整画幅，新增可撤销。
5. **先测**：打开“编辑当前帧”，修改后回填；再从画布、历史、资产或图片编辑选择另一剪辑，分别仅入素材面板、覆盖和插入。期望：帧编辑只回原时刻一帧，其他来源按选择落位，原目标改变/关闭时拒绝旧回填；音画、保存与撤销一致。

## 助手

依据：[覆盖复核](助手覆盖复核.md)、[本轮契约修复](第五六批-测试失败修复.md)与[现状台账](../../../../rules/assistant-status.md)。优先内置助手；使用外部客户端时沿相同目标再核对一次，未提供可用主模型时先记录环境未就绪。

1. **先测**：在剪辑选中片段说“告诉我当前选中了什么、起止时间、速度、效果和声音角色，先不要修改”。期望：描述与界面一致，不猜目标、不触发生成或编辑。
2. **先测**：说“把所选音画放慢一半，后面跟上”，查看声音与后续位置，再让助手撤销；另要求一个锁轨编辑。期望：同源变速、链接及一步撤销，锁轨明确拒绝，不能先移后段再手算速度假装波纹。
3. **先测**：要求给选中镜头人脸打码、放标题、加两点不透明度动画，读回结果，再撤销。期望：使用已有对象和同一效果/文字/关键帧，进度可查，用户能继续手改；不用逐项手填内部参数。
4. **再测**：让助手先检测切点或读取已有词稿，明确确认后拆分/摘选；再要求按预设导出并查询完成、收录资产。期望：先读目标、解释实际修改和结果，入队不冒充已导出，保存失败不重复剪辑。
5. **先测，可先不提交**：让助手准备原地生成，取消某个自动参考并指定节目时间；另取消正在下载的本地模型。期望：实际参考与界面一致，准备不发生生成费用；模型取消保留续传且不当作删除。
6. **再测**：让助手完成嵌套/多机位、代理或跨工作区中的一个免费流程，要求读回并由用户撤销；若要求直接重试智能区域或恢复失败占位，记录其说明。期望：已覆盖路径操作与界面一致，未覆盖路径如实说明，不能宣称全部覆盖或重放付费生成。
