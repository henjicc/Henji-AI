## 改成 PR 的做法

- **效果面板**（新停靠面板“效果”，默认与效果控件同组成标签）：视频效果、视频过渡、音频效果、音频过渡、智能五个文件夹的可搜索树。条目来自效果登记表 `src/core/videoEdit/effectsRegistry.ts`（实施方案第六节“一份登记，三方共用”）；内置效果在 `VIDEO_EDIT_BUILTIN_EFFECTS` 加一条即出现在对应文件夹（4.7 接入）。过渡右键“设为默认过渡”，默认项标“默认”。
- **过渡种类**：视频交叉溶解、黑场过渡、白场过渡；音频恒定功率、恒定增益。黑场／白场在原混合着色器里加一个“经过的纯色”参数；音频过渡在混音里按曲线交叉淡化（左片段越过出点、右片段提前入点）。
- **应用方式**：把过渡拖到同类轨道两个片段相接处——落在切点上居中，切点左侧为终点切点，右侧为起点切点，拖动中显示落点虚框。Ctrl+D 在目标轨道（没有目标轨道时用全部同类轨道）离播放头最近的编辑点应用默认视频过渡，Ctrl+Shift+D 应用默认音频过渡，Shift+D 应用到所选片段两端；默认 1 秒，放不下时缩短并给相邻过渡让位；同一编辑点再次应用即替换。三条命令进快捷键表，设置页随表自动列出。
- **媒体不足**：按 PR 重复首尾帧（视频）或静音（声音），不再拒绝；代码素材仍需真实余量。
- **时间线过渡块**：盖在切点上，显示图标与名称。拖左右缘改时长（另一缘不动）、拖中间沿切点平移，结果按切点位置归为中心切点／起点切点／终点切点／自定义起点；吸附开着时吸到播放头、编辑点与标记。点选即选中（取消片段选择），效果控件显示持续时间、对齐与删除；选中后 Delete 删除。
- **淡化手柄**：画面与声音片段左上、右上角各一个手柄（悬停或已有淡化时显示），向内拖出淡入／淡出，淡化区压三角暗影。画面不透明度线性渐变，声音按恒定功率；预览、导出与混音共用渲染器同一路径。存为片段可选字段 `fadeInFrames`／`fadeOutFrames`（旧文件不受影响），拆分时淡入留左段、淡出留右段，助手可经片段属性读写。
- 所有拖动都是一次手势：文档实时预览，松手只记一步撤销，Esc／失焦撤回。
- 不能编辑的原因改为浮在时间线可见区域顶部的提示，不占位、不挡指针，指针显示禁止。

## 待确认（用户已确认按 PR 做，随 4.4 完成）

1. 移动或裁剪片段使过渡一端不再相接时不再拒绝：过渡留在被移动片段的那一端成为单侧过渡，放不下时缩短，不足两帧时删除，与引起它的编辑同一步撤销。
2. 单侧过渡：从效果面板拖到片段空白的一端、或 Ctrl+D／Shift+D 落在旁边是空白的片段一端时放单侧过渡；画面从透明（交叉溶解）或黑／白场淡入、淡出，声音按曲线淡入淡出。详见 [4.4](4.4-标尺入出点与吸附反馈.md)。
