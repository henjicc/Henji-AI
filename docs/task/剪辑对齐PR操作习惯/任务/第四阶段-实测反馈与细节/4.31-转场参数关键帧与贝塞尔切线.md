# 4.31 转场参数关键帧与贝塞尔切线（t99）

状态：实现与定向验证完成，待总管理者审查。仅修改工作区，未执行 Git 写操作。2026-10-09。

## 目标与范围

补齐 4.14 的“转场参数关键帧未新增；任意贝塞尔切线手柄未新增”。转场沿已有曲线、参数行、渲染和助手通用属性工作；片段/效果/代码/图形的可动画值共用贝塞尔契约。没有新增产品数量上限，没有修改 SDK、ie1 的调色或图片编辑实现、主进程服务。

## 设计决定与选型

- 转场内部存 `frameCurves`，正式属性为 `video_edit.transition.frame_curves`，与效果 `frame_curves` 使用同一结构。时间是转场内整数帧，0 为第一帧；同轨点升序、不重复且小于 durationFrames。开关、枚举等离散值只接受 hold；progress 仍由宿主的转场窗口驱动，不另开参数。
- 所有曲线点增加 `interpolation: bezier` 和左点 `bezier:[x1,y1,x2,y2]`。x 为相对时间（0–1），y 为值变化比例，可过冲；省略控制点采用对称缓动。数值/颜色等在消费处按已有参数范围夹取；角度保持原数值语义，不自动取最短旋转路径。
- 复用 t85 的 `UiEasingEditor`、`PanelTrigger` 和项目已有 `codeCubicBezier` 时间反解。比较过新增缓动编辑组件/独立贝塞尔依赖的方案：现有原件已支持拖动、键盘、数值及取消，现有反解函数已服务代码动效，重复引入会制造第二套曲线与历史入口，因此不增加依赖或另写求解器。
- 修剪保持 `easeRange` 与 `easeValues` 原曲线锚点，处理非单调与等值端点，重复修剪保持一致；锚点受原参数值校验，贝塞尔局部区间缺锚点被拒绝。直接改值、插值或切线时清除旧修剪锚点。保留读写未改点的自动重构/回避来源，手改点归用户所有。
- 改转场时长按相对进度重排；帧率变化按原正式帧率换算；整数帧碰撞最后点覆盖，是帧网格约束，不是产品数量限制。移动与单侧重定保留曲线，换种类清除旧参数动画。
- 面板原有 memo 缺播放头订阅，已补视图订阅；换种类重挂参数会话，避免旧字段/手势残留。
- 公开能力分级为已有实体属性写入：新增 frame_curves 属性与级联声明，并更新原动画属性说明；复用通用读/改/增删、正式校验、保存与撤销，没有新增专用 Agent 工具或能力。

## 交互说明

1. 选择时间线转场，将播放头放在转场区间；参数行用原计时器启用动画，菱形添加/删除当前点，箭头跳转上一/下一点。启用后改参数直接写当前内部帧；关闭动画保留当前画面的参数值。内置及 shaders.* 转场共用操作，真正不可动画的参数不显示动画按钮。
2. 参数行的关键帧轨/插值浮层可选“线性 / 定格 / 缓入缓出 / 自定义贝塞尔”。自定义贝塞尔复用双手柄图形与 X/Y 数值编辑，X 夹在0–1，Y允许过冲。代码/图形源时间关键帧也使用相同原件。
3. 时间线钢笔模式在不透明度/音量已有曲线上显示左右点之间的出/入切线，拖动圆形端点调整手柄；关键帧右键打开共享插值编辑器。等值段无法在值图中显示非零垂直切线，仍可在缓动编辑器内编辑。
4. 每次手柄拖动实时预览、松开只记一步撤销；Esc/取消指针/丢失捕获/失焦/目标切换撤回。手动改关键帧值保留自定义控制点。没有引入独立历史或存储。
5. 助手先读取转场目录、参数定义和 frame_curves，再整体写入；省略的参数关闭动画，{} 关闭全部动画，禁止空轨与越界时刻/值。说明区分片段内部帧与代码源微秒，修剪锚点在未改点的读写中保留。

## 设计自查

1. **助手只凭名称和说明能否用对？** 能。转场 frame_curves 明确内部帧、参数范围来源、整体替换、离散 hold、贝塞尔坐标、时长重排和种类切换规则；其他动画属性同步说明，通用事务测试包含合法创建、写入、读回和拒绝。
2. **能否 AI 先做、人只确认？** 能。助手可按用户意图生成曲线，人与助手走同一校验、渲染、保存/撤销链；用户用原关键帧行和手柄微调，不需从内部着色器参数构造另一份操作。
3. **产物能否直接流进其他工作区？** 能。结果保留在正式剪辑文档、代码资产/标题模板原曲线结构，原节目渲染与导出继续消费同一参数；无需另存曲线文件或复制媒体。跨工作区最终交付/成片本轮未真实运行。
