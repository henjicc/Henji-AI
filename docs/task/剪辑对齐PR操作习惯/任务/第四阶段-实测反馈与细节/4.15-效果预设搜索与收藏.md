## 实现与设计决定

- 搜索复用 UiSearchInput，按名称、别名（英文名／登记 ID）、分类、分组、description 关键词筛选；多个关键词全部匹配，忽略大小写与全角差异。匹配时自动展开文件夹，清空恢复原折叠状态。
- “收藏”文件夹置顶。效果、过渡和用户预设均可通过星标／右键收藏，收藏不触发效果应用；原默认过渡右键入口保留。
- 效果控件每项内置效果可“保存为预设…”，复用 UiCheckbox 选择多个效果后保存组合；按原效果链顺序保存名称、效果 ID、参数、强度、开关与作用区域。UiModal／UiInput 负责命名，手绘遮罩可选择保留。
- 跟踪器引用属于原片段，保存预设时去掉 tracker 区域绑定／形状 follow；对话框说明这一后果。保留手绘遮罩时保存归一化形状、羽化、扩展等设置，智能作用区域在新视频／图片上重新分析。
- “预设”文件夹支持双击、拖放、重命名与删除。用户预设和内置／智能效果由同一个 resolveVideoEditLibraryEffects 解析，仍通过 applyVideoEditBuiltinEffect 一次 editVideoProject 应用；整组、多片段均一步撤销。音频只加声音片段，视频只加画面片段；智能区域进一步限制为视频／图片。锁定轨道跳过，任一目标效果数超出 8 项时不发布部分修改。
- 收藏和预设使用本机独立设置键 video-edit-effects-library，不进入剪辑文件。复用 Zustand／createJSONStorage 模式，写成功后才发布状态；存储失败保留旧状态，格式损坏保留原数据并明确报错。最多 256 个预设，每组 1–8 项效果；不引入大对象数据库或新 IPC。
- 应用能力分级为“能力增量”：登记只读 video_edit.effect_preset，提供名称、媒介、creation_items；助手经 list/read 发现，再将创建项放入同一次 video_edit.effect 通用集合事务。未新增预设专用工具。预设管理是本机模板管理，有明确 writeExclusion；收藏是效果库的个人显示偏好，不改变剪辑内容。
- 实际读写层通过既有 createLogger 记录 start/completed/failed；不记录用户完整预设内容。

## 成熟开源优先与选型依据

已对照现有 settingsStore、imageEditorUiStore 的 Zustand 持久化与 services/presets/PresetService。后者是生成模型参数预设，会混入生成模型目录与使用计数，不承载剪辑效果组合。采用仓内已经安装的 Zustand／createJSONStorage 与 Zod 校验，复用既有 Ui 组件、菜单、拖放与领域编辑，不另建数据库或拖放实现。搜索对象是内置目录加至多 256 个预设，需要确定关键词过滤而非模糊评分，使用原生字符串匹配，无须为此额外引入搜索库。

## 设计自查

1. **助手只凭名称和说明能否用对？** 能。只读目录说明适用媒介，并给出可直接用于 create_items.items 的创建项；专项测试从正式 list/read 入口找到预设，经现有效果集合整组创建并回读参数。代码滤镜预设尚未覆盖，不能据此扩大结论。
2. **能否 AI 先做、人只确认？** 能。助手可按预设批量应用内置效果组合，用户在现有效果控件中校正参数并一步撤销；用户保存模板时只需命名，并决定是否保留手绘形状。
3. **产物能否直接流进其他工作区？** 应用结果成为普通片段效果链，沿既有保存、导出与成片收录流向其他工作区，无需新的预设渲染路径；本机模板也可在其他剪辑复用。其他工作区的编辑器没有新增直接导入此预设的入口。
