# 4.16 音频增益与响度标准化

状态：实现与精确验证完成，待总管理者审查；片段增益范围受现有属性限制，真实 Electron 与最终 AAC 编码未验收。本任务不提交 Git，不启动开发环境，不进行付费生成。

## 实现与边界

- 查询现有文档与混音链路后，仅使用片段 `volume` 倍率（0–2），不新增重复增益字段，不修改 `document.ts`。设置增益、相对增益、最大峰值共同缩放、所有峰值分别对齐与积分响度标准化，均完整校验后一次领域提交、一步撤销。
- 本机 PR 默认表 `C:\Program Files\Adobe\Adobe Premiere Pro 2026\Keyboard Shortcuts\en\Adobe Premiere Pro Defaults.kys` 的 `cmd.clip.audiooptions.gain`：无 Shift/Alt/Ctrl，virtualkey 2147483719 = 高位标记 + 71（G）。正式命令表登记 G，声音片段时间线菜单接入。
- 对话框支持 -14 LUFS 网络视频、-16 播客、-23 LUFS EBU R128 广播和自定义目标。测量显示积分响度、末尾三秒短期响度、真峰值；静音或不足测量窗口返回 null，不冒充零。单段独立测量保留媒体映射、变速、淡化和效果，排除邻片过渡与轨道静音/独奏。
- 测量通过现有 `VideoEditRenderSession.mixAudio` 产生 PCM，并分块写入后台 FFmpeg 会话；每块最多两秒、实际约一秒。FFmpeg 执行 K 加权、400ms 积分门限与三秒短期计量。44.1/48kHz 单/双声道以 4 倍重建信号测峰值，并与原采样峰值分别返回。
- 片段音量位于非线性效果之前，标准化后重新混音测量并迭代，不能仅用测量差值假定效果线性。目标超出现有最大 +6.02 dB、效果阻止目标、锁轨、取消、关闭或测量期间发生编辑，都拒绝整批写入，不部分提交。
- 导出设置提供目标 LUFS 与真峰值上限；整片混音暂存、两遍 loudnorm（必要时启用动态限幅）、重新测量达标后才送现有 AAC 编码器。最多三次偏移校正，积分误差要求 ±0.5 LU，PCM 真峰值允许测量舍入误差 0.05 dB，限幅预留 0.2 dB。长度严格一致。导出任务及助手查询含目标和实际 PCM 测量摘要，时间线与预览不变。字幕导出明确拒绝响度选项。

## 选型与架构决定

比较已有 FFmpeg 的 ebur128/loudnorm、独立 libebur128 与额外 JS/WASM 移植。采用已随包使用的 FFmpeg：已有成熟标准计量、重采样、两遍标准化与限幅，无新增依赖或另一份 DSP 实现；独立 libebur128 还需新增 native/WASM 运行与限幅实现。依据为 [FFmpeg ebur128](https://ffmpeg.org/ffmpeg-filters.html#ebur128)、[FFmpeg loudnorm](https://ffmpeg.org/ffmpeg-filters.html#loudnorm)、[libebur128 官方实现](https://github.com/jiixyj/libebur128)。许可沿用既有 FFmpeg 构建分发义务，未引入新的媒体编码器或专利许可判断。

这是有界 L2 跨层 I/O 和异步业务改动：core 仅放数据契约及纯增益计算；正式应用服务负责片段快照、编辑校验和一次撤销；PAL/preload 只提供会话桥接；主进程协调暂存、取消和生命周期，重 DSP 在 FFmpeg 子进程。没有使用 provider API、HostCommand/HostQuery 或另建日志查看器。

会话归属于可信 sender，每窗口最多四个；随机会话 ID 不允许跨窗口读写。每份 PCM 最多 30 分钟，48kHz 立体声原声与标准化结果合计约 691MB 临时磁盘；流式输入输出和日志尾部有界。取消、失败、窗口销毁/导航及应用退出清理会话并终止子进程。异常退出仍可能留下临时目录；本轮不增加全局启动清扫流程。导出提交后台任务后对话框关闭，沿用现有导出任务取消入口。

## 助手覆盖分级

能力增量：计量需要混音与标准计算，登记只读算法能力 `measure_video_edit_loudness`；标准化需先测量再计算并核实，登记算法能力 `normalize_video_edit_loudness`。两者经现有同源能力目录供 Pi/现代 MCP 使用，沿正式领域服务、权限、目标引用、修订基线与撤销保存。普通音量设置继续使用既有 `video_edit.clip.volume` 通用属性，不新增专用属性写工具。

测量说明明确“每段而非整片”、短期取末尾三秒、门限返回 null、真峰值区别于采样峰值。标准化说明 targetLufs 越接近零越响、预设用途、现有增益上限与不隐式添加片段限幅器。保存失败标记已应用的修改，只允许重试保存，不重放增益。导出响度复用既有 export 能力可选参数与任务查询摘要。
