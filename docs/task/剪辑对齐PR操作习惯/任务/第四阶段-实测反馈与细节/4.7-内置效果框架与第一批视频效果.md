## 实现

- **一份登记**：`src/core/videoEdit/builtinEffects.ts` 登记每个内置效果的名称、分组、用户悬停说明、给助手的语义说明与参数。参数用意图量纲：0–100 强度（或 -100–100 双向）、角度（度）、曝光档、`#rrggbb` 颜色、选项、开关；每项都有范围、默认值、单位、`tooltip`（界面）与 `description`（助手）。空间量（模糊半径、马赛克块、颗粒、偏移、羽化）一律按画面高度比例换算，渲染尺寸变了（含以后的回放分辨率 1/2–1/8）效果看起来一样。效果面板登记表 `effectsRegistry.ts` 从这里生成“视频效果”文件夹的条目。
- **存储**：片段效果链 `clip.effects` 的一项是代码滤镜（`code`）或内置效果（`builtin: { id, params }`）二选一，均为可选字段，旧文件不受影响；缺的参数按默认值渲染。预留 `mask: { regionId, invert? }` 智能区域槽位（4.7d），现在写入会被文档校验拒绝。一个片段最多 8 项效果（原为 4 项；效果链是乒乓渲染，项数不增加渲染目标）。
- **GPU 实现**：`engine/videoEditBuiltinEffectShaders.ts` 一个 WGSL 模块、多个片元入口，共用一组绑定；`videoEditBuiltinEffectPasses.ts` 把效果实例翻译成工序与 16 个 float 的参数（纯函数，可单测）；`videoEditBuiltinEffectsGpu.ts` 逐道绘制、一个效果一次提交，管线按入口与输出格式懒编译，中间纹理计入合成器原有显存预算并在不用时释放。合成场景里与代码滤镜同一条链（强度混合、调整图层、过渡两端都一样），预览与导出同一路径；输出保持输入精度（10 位素材仍是 rgba16float）。
- **第一批 18 个**：高斯模糊（按轴对半降采样到 sigma ≤ 3 再横竖两道一维高斯，降采样与放大带来的模糊从剩余 sigma 扣除，任意半径每道最多 19 次取样；可只模糊一个方向、可选边缘透明）、方向模糊与缩放模糊（两道等权取样，等效 16×16）、锐化（反锐化掩模）、亮度与对比度、曝光与色温色调（线性光增益）、色相与饱和度、黑白、反相、马赛克、暗角、胶片颗粒（种子只取帧号，同一帧逐像素一致）、色差、发光、裁剪、翻转、色度抠像。
- **效果面板**：内置效果按分组（模糊与锐化 / 颜色 / 风格化 / 画面 / 抠像）列在“视频效果”；拖到时间线片段上即应用，落在已选多个片段之一上时加到全部所选；选中片段后双击效果同样应用；整体一步撤销，声音片段与锁定轨道上的片段跳过。时间线只加了一个独立的拖放入口（`panels/videoEditEffectDrag.ts`）。
- **效果控件**：附加效果列表里内置效果展开后逐行显示“效果强度”（百分比）与各参数：数值读数拖动实时预览、松手一步撤销、Esc 回退；取色器拖动预览、关闭时提交一步；选项、开关每次一步；每行重置。开关与整项重置直接一步撤销，不再走代码滤镜的试渲染。
- **助手（通用实体读写，无专用工具）**：
  - 只读实体 `video_edit.builtin_effect`：列出全部内置效果，读出作用说明与参数（键、类型、范围、单位、默认值、取值含义）；`writeExclusion` 指向真正的写入路径。
  - `video_edit.effect`：`definition_id` 写 `effect:<ID>` 创建内置效果，`parameters` 整体写入（写什么存什么，读回一致，未写的键按默认值），越界、未知键、错类型报错并列出范围与可用键；`amount`、`enabled`、`name` 与代码滤镜共用；内置效果不接受 `version_id` 与关键帧。

## 决策

- 重新实现而不直接复用图片编辑的 vgpu 快速模糊：剪辑合成器自己持有 WebGPU 设备、纹理与显存预算，借用 vgpu 运行时会出现第二套设备；思路（降采样 + 一维高斯）相同。
- 内置效果不做试渲染：实现是应用自带的确定 GPU 代码，WGSL 由 `*.gpu.test.ts` 在真实设备上编译核对；代码滤镜仍先试渲染。
- 颜色类效果（亮度与对比度、曝光、色温色调、色相饱和度、裁剪）默认中性：调整方向取决于素材，由用户或助手按画面决定；其余效果默认就能看到合理结果（模糊 30、马赛克 30、暗角 30、颗粒 30 等）。
- 助手写参数用整体写入：通用事务按“读回等于写入”验证，合并写入会让读回多出默认键而验证失败。

## 后续（未做，原因）

- **视频过渡**（擦除、推动、滑动、缩放过渡、模糊过渡、闪白、圆形划像）：需要改过渡渲染（`transitions.ts` 与合成场景的过渡混合，另一任务正在改单侧过渡），不是在现有着色器上加入口就能完成；着色器与工序机制可直接复用。
- **LUT（.cube）**：需要导入文件、把 LUT 作为素材引用存进剪辑、上传 3D 纹理，与“参数只是数值”的框架不同，单独做。
- **代码素材调用内置效果**（实施方案第六节原则 7）：需要在代码滤镜的受限语言里加调用入口并在 GPU 侧串接工序，属于代码素材契约变更。
- **关键帧**：内置效果参数暂不支持关键帧（存储与助手接口已拒绝 `curves`），后续与代码参数关键帧统一。
- **4.7c 音频效果、4.7d 智能区域**：按实施方案顺序。
