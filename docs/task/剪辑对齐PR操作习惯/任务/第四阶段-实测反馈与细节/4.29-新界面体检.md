## 选型与设计决定

- 优先沿用已有 Ui*、UiOverflowRow、PanelTrigger、react-virtuoso 和 lucide-react。已能满足布局、选择、状态和图标统一，无需新依赖、自研控件或新增公共 UI 组件。
- 页面/停靠表面不新增边框或卡片。画面叠层才用玻璃；多机位 canvas 是媒体工作面，选项外壳静默。
- 不增减业务操作。新文案、状态块和可访问属性属于表现层覆盖，不新增实体、MCP 或专用助手能力。
- 保留费用、替换原镜头、逐字剪辑限制、预设不保存跟踪等影响用户决定的提醒；一般背景知识进标签 tooltip。

## 设计自查

1. **助手只凭名称和说明能否用对？** 本轮没有新增业务能力或改动其参数语义；既有操作入口不变。界面将“序列时钟”改为“序列时间”、将测量结果改为响度描述，不改变助手契约。
2. **能否 AI 先做、人只确认？** 既有跟踪、校色、字幕、回避、场景/构图、多机位与生成操作保留；本轮统一候选确认和处理反馈，让人更容易确认/校正。算法效果不是本次 UI 检查的验证结论。
3. **产物能否直接流进其他工作区？** 时间线落位、导出队列/资产库与跨工作区入口不变；没有新增搬文件流程。本轮未实跑生成、编码或跨工作区交付。
