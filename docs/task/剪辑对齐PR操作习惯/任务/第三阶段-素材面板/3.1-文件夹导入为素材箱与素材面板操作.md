# 3.1 文件夹导入为素材箱与素材面板操作

[返回总览](../../00-任务总览.md) · [实施方案](../../01-实施方案.md) · [重要记录](../../重要记录.md)

## 任务状态

- 状态：已完成；从资源管理器拖入文件夹由用户手动验收
- 所属阶段：第三阶段-素材面板
- 前置任务：2.2

## 实现

- `videoEditFolderImport.ts`：拖入或选择的本地路径先经主进程 `fs.readDir`（既有 IPC）判断是否文件夹并递归枚举，渲染层不碰 Node；层级上限 16、条目上限 5000。
- 文件夹按层级建同名素材箱，放在落点素材箱下；素材进对应素材箱，混合拖入的散文件留在落点。只有含可导入素材的文件夹才建素材箱。文件按自然顺序（`B 9` 在 `B 10` 前）。
- 不支持的扩展名与读不出／解码不了的文件跳过并计数（系统生成的 `desktop.ini`、`Thumbs.db`、点开头文件不导入也不计数）；素材面板用提示告诉用户跳过几个。`importVideoEditSources` 新增 `skipUnreadable` 选项，素材库引用仍严格。
- 整次文件夹导入（建素材箱 + 素材 + 可选的时间线落点）是一步编辑，一次撤销全部回退。没有文件夹时与原导入完全一致。
- 素材面板：“导入”按钮改为菜单（导入文件／导入文件夹），空白处右键加“导入文件夹”；方向键与 Home/End 移动选择、Shift 连选；Backspace 与 Delete 一样删除；Ctrl+PgUp 列表视图、Ctrl+PgDn 图标视图、Shift+\ 切换（走快捷键注册表，可改键）；Ctrl+B 新建素材箱、Shift+O 在源监视器打开由 2.2 的命令执行。
