## 实现

- 去掉单独的素材箱侧栏（PR 没有）：素材箱是列表里的一行，三角展开把内容缩进列在下面；双击素材箱进入，工具栏左端出现“返回上一级素材箱”与当前素材箱名（悬停看完整位置），素材也可拖到“上一级”按钮上移出。素材拖到素材箱行即移入；素材箱行右键有打开、新建子素材箱、重命名与移动、移除空素材箱、标签；选中素材箱行按 Delete／Backspace 移除空素材箱。
- 列表列按 PR：颜色标签、名称、帧速率、媒体开始、媒体结束、持续时间；点表头排序，再点切换升降序，没有该列数值的项排最后。视频按素材帧率出时间码，音频帧速率列显示采样率、时间码按当前序列帧率，序列按序列帧率；图片、文字、图形等留空。搜索时跨素材箱平铺。
- 颜色标签（PR 默认 16 色，同名）：素材项、素材箱、序列都可设，存于文档 `label`（空 = 按类型默认：素材箱芒果黄、序列森林绿、视频鸢尾花、音频加勒比海蓝、图片淡紫、文字与图形玫瑰红、代码天蓝、调整图层紫罗兰）。右键“标签…”弹出色板，可多选一起设，“按类型默认”恢复；一步撤销。颜色值登记在 `colorTokens.ts`（内容色，不随主题）。助手经已有实体属性 `video_edit.item/bin/sequence.label` 读写（null 为默认）。
- 图标视图保留，素材箱也显示为格子，双击进入。
