## 依据

Adobe 官方帮助“停靠、编组与浮动面板”，以及用户 PR 录屏（以录屏为准）：编组区（面板中部、标签栏）放下时整个目标组着色；停靠区（四边）只沿那条边着色一条窄带（约组尺寸的 6–10%）；在没有落点处（停靠区域外、主窗口外、副屏）松开即成浮动窗口，Ctrl 拖动强制浮动；拖到空白处时指针处显示浮动窗口预览（浅色标题条 + 面板虚影）。

## 实现

- 共享层 `src/components/dockviewDocking.ts`（剪辑与 3D 镜头参考共用）：`DOCKVIEW_HOST_DND_OPTIONS`（指针拖放、关闭应用内浮动组与 dockview 根边缘目标、内容区停靠指示收窄为 8% 窄带）；`bindDockDragGestures` 接管窗口边缘停靠（整个区域四边 20px）、Ctrl/区域外浮出与浮动预览；`resolveDockDropZone` 供独立窗口拖回主窗口时判定落点；`toggleDockGroupMaximized` 供 `` ` `` 键使用；`dockFloatingGroupsBack` 把旧布局里的应用内浮动组贴回。
- 指示外观：dockview 指示与自绘指示都是半透明强调色（`index.css` 停靠拖放指示一节、`bg-accent/35`），主题 `dndPanelOverlay: 'group'` 让编组时整组着色。
- 剪辑：`VideoEditDock` 接入上述手势，浮出走 `floatVideoEditDockSource`；面板菜单改为 PR 叫法（关闭面板／浮动面板／关闭组中的其他面板／浮动面板组／最大化面板组〔最大化时为“恢复面板组大小”〕／关闭面板组／重置布局），“浮动”即独立系统窗口；浮动面板组在本期为组内每个面板各开一个窗口（错开排列）。
- 3D 镜头参考：同一套拖放与窗口边缘停靠；没有独立窗口，Ctrl 与区域外松开不浮出。
- `` ` `` 键：可调用 `toggleVideoEditGroupMaximized(api, point?)`（`videoEditDockLayout.ts`），由快捷键注册表接入（另一执行者）。
