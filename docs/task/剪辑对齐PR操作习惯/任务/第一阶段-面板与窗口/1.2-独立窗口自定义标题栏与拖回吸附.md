## 实现

- 窗口：`electron/main/windows/video-edit-popout.ts` 改 `frame: false`，四边四角缩放用系统无边框窗口的缩放边框；仍是 about:blank、无 preload、沙箱与上下文隔离不变。
- 标题栏：共用 `src/components/WindowTitleBar.tsx`（日志窗口同用，`dragRegion` 原生／自绘两种）；剪辑浮窗左侧面板标签，右侧“贴回主窗口”与关闭；双击最大化／还原。
- 拖动：不用 `-webkit-app-region: drag`。浮窗标题栏的指针事件在主窗口 React 树里处理（`popout/videoEditPopoutDrag.ts`），窗口几何经主窗口新增的一条 IPC `window:controlPopout` 交给主进程执行（渲染层 `moveTo` 必须完整留在当前屏幕内，拖不过显示器）；主进程只允许控制发送方自己打开的浮窗。指针进入主窗口停靠区域时主窗口显示与 Dock 内相同的指示，浮窗收成只剩标题条，松开停靠；其他位置松开只移动；按住 Ctrl 不停靠。
- 关闭语义改为 PR：关闭浮动窗口即关闭其中的面板（面板菜单可重新打开）；贴回用标题栏按钮。
- Windows 无边框窗口的隐形缩放边框：渲染层看到的窗口矩形比 BrowserWindow 外框左、右、下各多约 7；主进程创建后测一次，换算渲染层记住的位置与 moveTo/resizeTo，避免重开漂移。
