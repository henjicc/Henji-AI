- 前置任务：无

## 依据

用户实机确认的 PR 滚轮（以此为准，替代方案里的初稿）：滚轮横向滚动；Alt+滚轮横向缩放；Shift+滚轮调轨道高度（纵向缩放）；Ctrl+滚轮纵向滚动（PR 画面轨区、声音轨区各自纵向滚动，我们只有一个区域，整体纵向滚动）。键位来自 `Adobe Premiere Pro Defaults.kys`：`\` 缩放到序列、Page Up/Down 翻屏、Ctrl+=/- 视频轨高、Alt+=/- 音频轨高、Shift+=/- 展开／最小化全部轨道、Shift+←/→ 五帧。

## 实现

- `timelineGeometry.ts` 的 `timelineWheelAction` 统一判定滚轮动作；`VideoEditTimelineCanvas` 用非被动 `wheel` 监听执行（阻止浏览器纵向滚动与 Ctrl+滚轮页面缩放）。
- 缩放保持一个时间点不动：Alt+滚轮保持光标处；`=`／`-`、滑块与助手改缩放时保持可见的播放头，否则保持左缘。
- Shift+滚轮纵向缩放光标所在区域（分界线以上画面轨、以下声音轨）的全部轨道：滚动中只本地预览，停下 300ms 后用 `setVideoEditTrackHeights` 写入一步历史。
- `\`、Page Up/Down 要读写时间线滚动位置，由挂载的时间线在 `videoEditTimelineViewport.ts` 登记控制入口；时间线未显示时命令不可用并说明原因。
- 轨道高度键走 `resizeVideoEditTracks`（一类轨道一步编辑，无变化不写历史）。
- 标尺上按住 Shift 拖动播放头，吸附到编辑点、序列标记与入出点（`timelineNavigation.ts`）。
