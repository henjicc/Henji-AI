## 实现

- 新序列（含新剪辑的空内容）与 PR 一样只有 V1、A1；已有文档不变。新增 `core/videoEdit/tracks.ts`：在同类轨道任意位置插入（相邻编号有空位就用，没有就整体重新编号并换算片段与调整图层范围，锁定轨道需要移动时拒绝）、在最外侧加轨不动已有编号、删除轨道连同其上片段（每类至少留一条，锁定的不删）。
- 时间线分成视频区与音频区，中间一条可拖动的分隔条（也可键盘上下调），两区各自纵向滚动、右缘各一条滚动条；V1 贴分隔条上方、A1 贴下方。Ctrl+滚轮与手形纵向拖动滚光标所在区，Shift+滚轮仍调光标所在区的轨高，拖动到区边缘时滚动起点所在区。原来的“初次定位到分界”机制随之删除。
- 视频区最上轨之上、音频区最下轨之下始终留出一条空白：片段（含 Alt 复制、Ctrl 插入）拖到这里新建轨道，预览里即出现新轨；从素材面板、资源管理器或源监视器拖到这里同样新建轨道。新轨道与编辑同一步撤销；新轨道没用上（如只放了声音）不留下。“送到剪辑”在播放头处没有空余轨道时也改为新建一条（原来报错）。
- 轨道头右键（PR）：重命名（也可双击名称）、添加单个轨道（视频加在所点之上、音频之下）、删除单个轨道、添加轨道…（视频／音频各填数量与位置）、删除轨道…（所有空轨道／目标轨道／某一条）、自定义…。音频子混合、输出通道分配、画外音不做。
- 自定义…：复用 2.5 的按钮编辑器，抽出通用面板 `VideoEditButtonBarEditorPanel` 与 `core/videoEdit/buttonBars.ts`（清洗、默认不存），监视器与轨道头共用。轨道头默认按 PR：视频轨锁定、同步锁定、切换输出；音频轨锁定、静音、独奏；目标、静音独奏等可加回。存 `settingsStore.videoEditTrackHeaderButtons`，助手设置属性 `video_edit.track_header_buttons`。
- 助手：`video_edit.track` 支持通用集合新建（kind 必填，加在最外侧）与删除（连同片段，片段删除作为级联副作用回报）。
- 2.3 复核：吸附开启时 Alt／Ctrl 修饰键拖动也吸附。3.1 复核：空文件夹（或只有不支持文件的）也建同名空素材箱。
- 顺带：删除只剩测试在用的 `VideoEditTransportControls`。
