## 做法（按 PR）

- 节目、源监视器底部按钮栏只显示选中的按钮，末尾“+”打开“按钮编辑器”：网格里是全部可用按钮，拖进下方按钮栏的落点；栏内拖动调整顺序（`useReorderDrag`），拖出栏外即移除；点网格按钮也能加入／移出。左侧“重置布局”，右侧“取消”“确定”（唯一主按钮）；确定才保存。
- 节目默认（PR 默认节目监视器）：添加标记、设置入点、设置出点、转到入点、上一帧、播放／暂停、下一帧、转到出点、提升、提取、导出帧（加入资产库）。
- 节目可选：清除入出点、转到序列开头／结尾、前进／后退五帧、J/K/L、上／下一个编辑点、四个工具模式（选择、移动画面、点标注、区域标注）。工具模式不在栏里时从“更多”切换；“更多”仍有重新加载预览、选帧加入资产库、编辑当前帧。窄面板放不下的按钮按优先级收进“更多”（播放、逐帧、入出点最后收）。
- 源默认：设入点、设出点、上一帧、J/K/L 与播放、下一帧、插入、覆盖、拖入画面／声音／链接音画（原有 J/K/L 与拖入按钮保留在默认里）；可选清除入出点、前进／后退五帧。按钮按素材类型显隐的规则不变（图片无播放与入出点，音频由播放器播放）。
- 按钮名称、快捷键提示与可用状态都来自正式剪辑命令；提升／提取的可用判定只在序列、入出点或目标轨道变化时重算，不随播放每帧试算。
- 保存：`settingsStore.videoEditMonitorButtons`（与剪辑快捷键同一持久设置），按节目／源分开，只存改过的一侧；读取时清洗不认识的按钮。助手可经设置属性 `video_edit.monitor_buttons` 读写。
