## 实现

- `src/core/videoEdit/commands.ts`：命令注册表补齐上表；支持第二组默认键（`alternates`），改键后只保留用户的键；冲突检查覆盖全部键位。新增 `sanitizeVideoEditShortcutOverrides`，设置恢复时丢弃无效项、与新默认冲突时保留用户键并让出默认键，旧改键总能读回（`settingsStore` 的 `merge`）。
- `timelineEdits.ts` 新增 `range` 编辑：提升／提取与 Q/W 共用，一步历史；提取按同步锁定轨道收拢。
- `videoEditCommands.ts`：导航、标记、入出点、微移、链接开关、剪切等命令的启用状态与执行；面板组最大化与 Shift+数字的键盘焦点由 `VideoEditApp` 执行（只调用停靠区 API，不改布局文件）。
- 快捷键设置：显示第二组键，“恢复默认”改名“恢复 PR 默认”。
- 应用能力：这些命令只走界面键盘与菜单，没有新增助手工具；助手可见的只有 `video_edit.shortcuts` 设置，其 schema 随注册表自动更新，`check:assistant-capabilities` 通过。
