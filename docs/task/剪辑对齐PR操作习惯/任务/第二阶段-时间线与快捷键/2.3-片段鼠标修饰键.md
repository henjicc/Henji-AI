## 改动前已有

- Alt+点击只选链接片段的一侧（链接选择开启时），Alt+剃刀只拆一侧——符合 PR，保留。
- Ctrl+点击切换选择、Shift+点击只加选；按住 Alt 拖动是移动单侧（造成失步）。
- 双击只对“记着来源”的片段生效（回到来源编辑）。

## 改成 PR 的做法

- Shift+点击：加入／移出选择（PR）；Ctrl 不再切换选择，而是拖动修饰键。框选的 Shift／Ctrl 加选不变。
- 拖动片段时按住的键决定动作（每次移动都重新读取，松开或按下修饰键即时切换，与 PR 拖动中按 Ctrl 切换插入一致）：
  - Alt：复制到落点（覆盖），原片段不动。
  - Ctrl：重排插入——从原位置抽出并收拢空隙，在落点插入，落点后的片段后移。
  - Ctrl+Alt：复制并插入。
  - 都不按：原来的移动。移动单侧的做法改为 PR 的“Alt 点击选中一侧，松开 Alt 再拖”。
- 双击片段：记着来源的仍回到来源编辑；其余有源文件的片段在源监视器打开（同“打开源素材”命令）。
- 实现：`timelineEdits.ts` 新增 `rearrange` 编辑（复制用覆盖或插入放置，重排先波纹删除再按收拢后的落点插入），预览与释放共用同一编辑、一步历史（`videoEditTimeline.ts` 的 `previewVideoEditTimelineRearrange`／`finishVideoEditTimelineRearrange`）。
