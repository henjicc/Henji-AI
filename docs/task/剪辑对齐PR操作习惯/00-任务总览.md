# 剪辑对齐 PR 操作习惯

## 任务目标

用户长期使用 Adobe Premiere Pro（下称 PR），要求痕迹AI 剪辑的各种操作习惯与设定都向 PR 靠齐，降低切换成本。重点：

1. 窗口与面板：拖动面板时像 PR 一样出现停靠／编组吸附区；浮出的窗口必须用我们自己的标题栏（PR 没有，但我们必须做）；其他操作细节尽量与 PR 一致。
2. 时间线：滚轮、Alt+滚轮缩放等鼠标习惯，快捷键按 PR 默认表。
3. 素材面板：把文件夹拖进素材面板，按 PR 方式整体导入为素材箱。

方案见 [01-实施方案.md](01-实施方案.md)，决策见 [重要记录.md](重要记录.md)。
