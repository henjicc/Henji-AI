## 实现与设计决定

1. `UiDisclosurePanel` 在 layout effect 中先将内部焦点还给前面的展开按钮，再同步设置 `inert` 与 `aria-hidden`，展开时解除。已核对全部调用：助手模型详情、高级设置、开发样张页；不用改调用点。
2. 验证错误按模型保存，按钮下使用 `UiError size="xs"`，提供重试；原验证结果保留并说明为上次结果。连接失败、超时与一般失败使用用户语言；完整异常仍进原日志。
3. 九种检查能力改为双语名称、逐行状态与不可用影响说明，使用 lucide 图标、success/danger/text3 令牌。删除常驻协议解释；摘要中的结构化输出枚举也改成是否支持。
4. 智能对象的放弃与应用注入子编辑器现有命令带，不传原宿主导出动作。保存期间只冻结编辑内容与编辑命令，宿主返回、保存重试仍可用；已应用后重试只保存。收尾沿共享输入路由与剪贴板处理复核，补上宿主按钮焦点下的冻结保护，阻止编辑快捷键与父编辑器撤销穿透。
5. 命令带组合处统一订阅尺寸、选区、裁剪、变换与修补预览；待确认时让宿主 primary/secondary 降为静默，应用/取消后恢复。复用共享 `UiButton` 的上下文，不在各工具分别写宿主动作判断。
6. 业务层付费展示返回金额、类别、模型名，全局确认和讲解外发展示层用 i18n 拼句。类别标签、核对标题/三个动作、锁定提示及核对失败恢复提示双语化。保留主进程现有的核对详情事实正文，不为了翻译删掉原操作与当前情况。
7. 技能与指令首次读取时用 `UiLoading`，不提前宣称列表为空；失败用列表位置的 `UiError` 与对应操作的重试；删除底部手写状态行，指令读取失败时禁用保存，防止把未读到的内容当空稿覆盖。
8. 规格中的 `ghost` 使用现有等价枚举 `quiet`；`text-text-muted` 使用已登记辅助文字令牌 `text-text3`，不新增旧别名。
9. 英文费用截图复用仅开发导航可达的组件样张页，增加无业务副作用的确认夹具按钮；测试模型验证替换隔离实例 IPC，不访问供应商。正式产品不新增入口、数据或应用能力，因此不新增 MCP/Pi 工具、不修改助手能力台账。

## 选型依据

这是现有 UI 契约修复。沿用 React、lucide-react、浏览器原生 `inert`、既有 UiLoading/UiError/UiToolbar、正式 Electron 巡检启动器；无需新增库或自行重写组件、日志、模型执行链。主动作协调只维护瞬态展示信息，作品、保存和撤销仍由原领域服务管理。

## 设计自查

- 助手只凭名称和说明能否用对？能；不增加业务操作或改变既有调用语义，人和助手仍走原领域能力。界面能力名称改为用户语言，助手工具契约不变。
- 能否 AI 先做、人只确认？能；模型验证、预览与恢复沿原执行入口，用户只确认应用、付费或核对结果；本任务不增加要求用户自行拼内部参数的入口。
- 产物能否直接流进其他工作区？能；智能对象子编辑仍应用回原图片文档，资源、跨工作区引用、保存与撤销不另开旁路。
