# u1：生成历史分隔块

状态：实现、静态/精确验证、真实 Electron 深浅主题截图验收完成，待总管理者审查与 Git 提交。

## 范围与设计决定

- 每个虚拟列表项自身绘制上分隔线，完整列表的第一个索引不绘制；无下边线，因此最后一条下方也没有线。项内 `py-5`，虚拟器 `gap: 0`，线与留白一起计入动态测量。
- 规格中的 `border-border-dark`、`text-text-muted` 已被项目令牌规则禁止；采用同语义的现行 `border-line`、`text-text3`，不复活旧别名。
- 标题使用既有 `UI_TEXT_PANEL_TITLE_CLASS`（14px、500 字重、text1），两行省略；标题行右侧复用操作条。操作条 hover/focus 显示，无法悬停的触屏常显。
- 元信息严格为「媒体类型 · 模型名 · 时间」，12px 弱化文字；进行中/取消状态保留在独立状态行，避免丢失状态反馈。输入参考预览保留，移到元信息与结果之间；结果媒体布局不变。
- 失败复用 `UiError size="xs" align="start"`，不增加表面；恢复动作直接通过 actions 提供两个 `UiButton quiet/sm`，避免 UiError 默认 secondary 重试样式与问助手不同档。
- 本任务只调整展示，不新增业务能力、实体属性或助手工具；「问助手」「继续获取结果」、收藏、下载、发送到剪辑继续走原有操作。

## 错误与同源排查

- 检查 `useTaskGeneration`（提交失败）、`continuePollingTask`（恢复失败）、`generationTaskHistory`（落盘记录读回）以及 `TaskCard`（统一列表展示）。前面三条最终都进入同一 TaskCard，统一使用 `taskErrorMessage`，不改写保存的错误事实。
- 保留 SDK 已映射的用户说明，清除运行时前缀与错误代码；KIE 内部错误按既有 SDK 文案本地化。不能理解的原始报文显示通用恢复说明，不暴露供应商英文、任务号或堆栈。原始 error 继续供既有日志与「问助手」上下文使用。
- 文件缺失分支已有用户说明，保留原 UiError；没有发现另一个历史列表内的原始错误显示出口。画布错误、助手错误不属于本任务，未修改。
- 继续获取结果源码只有一份文字，没有文字阴影。此前按钮为默认 13px 中等字重、secondary 档，比同组问助手更重。本次统一到 12px quiet；原反馈截图未随消息提供，不能断言已复现原截图的像素重影。

## 选型依据

复用已安装的 `@tanstack/react-virtual`、现有 UiError / UiButton / TaskCardToolbar 和 SDK 用户错误说明。不需要新增库或自研虚拟化、播放器、状态组件；分隔线属于列表项几何，使用 CSS border 和动态测量即可。不新增任何产品数量限制。

## 设计自查

1. **助手只凭名称和说明能否用对？** 能。现有生成记录读写、恢复结果与诊断操作名称和接口不变，展示调整不改变调用语义。
2. **能否 AI 先做、人只确认？** 能。生成、结果获取和错误诊断沿用现有助手流程，人查看清楚分隔的记录并选择恢复动作。
3. **产物能否直接流进其他工作区？** 能。原有收藏、媒体查看、发送到剪辑、拖拽逻辑保留，产物引用和结果数据不变。
