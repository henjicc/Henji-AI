# u2：字幕轨道

工作区：`D:/VibeCode/henji-wt-u2`，分支 `codex/u2`。由总管理者审查、提交；本任务不执行 Git 写操作，不改 SDK，不启停开发实例，不调用付费生成。

## 实现与设计决定

- 标尺下方固定一条 C1「字幕」行，位于 V/A 两个滚动区域上方；始终占用共享最小轨高 24px，无字幕时仍保留。两区几何扣除字幕行，字幕不参与视频素材落轨命中。
- 复用 `VideoEditTrackHeader` 的编号、名称和图标按钮布局，字幕分支只显示眼睛与锁，不提供重命名、目标轨或高度调整。
- 片段沿用 `bg-clip-title`、文字片段描边、选中强调描边；上下各留 2px，单行文字省略，悬停显示全文。只挂载可视横向范围与当前拖动的字幕。
- 无现存字幕拖动/修剪实现；复用时间线吸附、边缘滚动和正式编辑历史。领域纯函数约束整数帧、最少一帧、序列/所属片段边界与相邻句边界；移动保持时长。历史数据已重叠时保持不动，不猜测覆盖顺序，可从内容面板调整。
- 手势只预览，松手提交一次；Escape、取消、窗口失焦、序列切换和文档并发修改取消预览。Delete 走现有命令路由；选择普通片段、标记及全选/取消选择时清除字幕选择，避免误删。
- `captionTrackEnabled`、`captionTrackLocked` 为序列可选字段，省略分别为 true、false。输出开关在预览/导出共用的字幕合成入口生效；字幕文件导出仍保留内容。
- 锁轨接入现有 `assertVideoEditLockedTracks` 提交校验，因此手工编辑、批量操作、通用实体写入和片段时间级联共用同一约束。内容面板字幕写入控件禁用；显示/解锁与撤销仍可用。
- 应用能力为现有序列实体的两个属性增量，沿统一字段定义、反射读取和通用写入投影，不新增 MCP 工具。字幕属性/集合可用性反映锁定状态。
- 按本任务明确要求，内容版本 3 → 4、领域文档版本 4 → 5，新增纯迁移与 v4 黄金样本，未使用 dev-break。此具体要求优先于开发期不兼容的通用规则。

## 选型与规模

比较现有轨道头/片段令牌、时间线吸附与指针机制，以及引入通用拖拽库的成本：本任务是已有时间线内新增一种行，直接复用 React、现有几何、吸附及领域编辑入口；通用拖拽库仍需重写帧边界、时间线滚动与提交规则，故不增加依赖。字幕数量不设上限，挂载按视口过滤；不扩大为字幕搜索索引重构。现有同时合成字幕数量的 GPU 资源约束未改动。

## 设计自查

1. **助手只凭名称和说明能否用对？** 能。序列属性以「字幕轨道显示/锁定」描述节目输出和编辑约束，字幕继续用现有 start/duration/text 通用读写；锁定时返回可解释的拒绝与解锁方向。
2. **能否 AI 先做、人只确认？** 能。已有识别、整理与时间参数能力继续生成字幕，人在同一轨道选中、移动或修剪；本任务不另加付费生成路径。
3. **产物能否直接流进其他工作区？** 能。字幕继续属于同一剪辑文档，沿原字幕文件、节目渲染/导出与稳定实体引用消费，不另建私有字幕格式。
