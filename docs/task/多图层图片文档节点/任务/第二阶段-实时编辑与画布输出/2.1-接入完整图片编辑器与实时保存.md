# 2.1 接入完整图片编辑器与实时保存

## 任务状态

- 状态：待开始
- 所属阶段：第二阶段——实时编辑与画布输出
- 前置任务：1.2
- 关联任务：2.2、3.2、4.2
- 是否可以并行：可以；可与 3.1 并行，双方不得重复修改 V3 渲染契约

## 任务目标

让多图层图片文档节点通过双击或明确编辑动作进入现有完整 `ImageEditorV3`，复用全部多图层编辑能力和实时保存队列。界面不再要求用户点击保存或应用，并建立可等待、可重试的关闭协议供 2.2 完成物化回写。

## 当前情况

- `LayerStackResultNode.tsx` 当前双击和“图层”按钮打开 `LayerStackSpecialEditor`，只提供旧版轻量功能。
- `builtInTools.ts` 已允许 V3 开关开启时从图层结果启动图片编辑工具，V1 会序列化为工具 options。
- `CanvasEditToolEditorV3Host.tsx` 已挂载完整 `ImageEditorV3`，用 500ms 防抖队列实时保存，并在保存失败时提供重试。
- `NodeToolDialog.tsx` 是通用图片工具对话框，底部仍有“应用”动作，关闭会直接清空 options，且宿主的 `flushPending` 没有暴露给对话框关闭流程。
- `ImageEditorV3` 已提供 `toolbarLeading`、`toolbarActions` 注入点和单一命令栏，不需要新建工具栏或第二套编辑器。

## 实施方案

为多图层文档节点建立专用的 V3 编辑宿主生命周期，但内部继续复用 `ImageEditorV3`、现有 profile、保存队列和资源描述。宿主从节点的权威 `imageEditSession` 加载文档，不接受新节点走 V1 临时 options；旧节点迁移由 4.1 兼容入口完成。

编辑器外壳不显示“保存/应用”。关闭按钮、遮罩关闭、Escape 和窗口级关闭请求都必须进入同一异步关闭入口：停止继续提交编辑命令、清理防抖计时器、等待保存队列 `flush`，把精确文档引用交给 2.2 的物化回写，再决定是否关闭。保存失败时保留编辑器、错误状态和重试动作。

节点单击仍只选择；双击和节点工具栏“编辑”进入编辑器。UI 使用现有工作区级 Modal/Surface 和一条图片编辑命令栏，不在节点内部塞入图层面板。

## 执行步骤

1. 重新检查当前工具对话框、特殊界面宿主和全局 Surface 注册，选择最小改动且能拦截所有关闭来源的现有容器。
2. 抽取 `CanvasEditToolEditorV3Host` 中可复用的加载、保存队列、错误恢复和引用发布逻辑，避免新旧宿主复制实现。
3. 让文档节点宿主只从权威会话引用加载文档，校验 revision、previewRef、sourceUrl 和节点身份。
4. 建立显式异步关闭接口；在 flush 或后续物化进行时禁用重复关闭和文档修改，并显示用户可理解的处理中状态。
5. 更新 `LayerStackResultNode` 的双击和按钮入口；保持单击选择、拖拽、缩放、端口和节点快捷工具栏行为不变。
6. 移除该节点新流程中的“应用后创建派生节点”路径，但不影响普通上传图的现有图片编辑工具行为。
7. 添加入口、首次加载、自动保存、防抖合并、Escape/遮罩/按钮关闭、保存失败重试和重复关闭测试。
8. 按当前规则执行精确验证；本任务不运行真实模型，不删除旧编辑器文件。

## 涉及内容

### 新增文件

- 预计在 `src/features/canvas/imageEditV3/` 新增多图层文档编辑宿主或可复用生命周期控制器及测试。
- 如现有对话框无法提供异步关闭，预计在 `src/features/canvas/ui/` 新增文档编辑对话框；创建前必须确认不能复用现有 Modal 变体，禁止新增通用 UI primitive。

### 修改文件

- `src/features/canvas/imageEditV3/CanvasEditToolEditorV3Host.tsx`：抽取共享加载、实时保存和 flush 能力，普通图片工具行为保持兼容。
- `src/features/canvas/nodes/LayerStackResultNode.tsx`：编辑入口切换到完整 V3 文档宿主，单击仍选择节点。
- `src/features/canvas/tools/builtInTools.ts`：新节点直接传递会话引用；V1 options 仅保留旧节点迁移用途。
- `src/features/canvas/ui/NodeToolDialog.tsx`：仅在复用该容器时增加可配置的无应用、异步关闭模式，不能把文档节点分支散落到通用渲染逻辑。
- Surface、编辑器注册和中英文文案文件：注册稳定打开方式和用户态保存失败文案；执行时按实际目录确认。

### 可能废弃

- `src/features/canvas/ui/specialInterfaces/specialEditorRegistry.ts` 中 `layers` 的旧打开路径：本任务停止新节点使用，文件删除留到 4.2。
