# 2.2 刷新节点预览并统一合成图输出

## 任务状态

- 状态：已完成
- 所属阶段：第二阶段——实时编辑与画布输出
- 前置任务：2.1
- 关联任务：3.2、4.1、4.2
- 是否可以并行：否；它定义第三、四阶段使用的最新合成图语义

## 任务目标

在编辑器关闭时把最新已保存 V3 文档物化为受管平面图，并将会话引用、节点图片、预览和尺寸原子更新到同一节点。保证节点预览、下载和下游图片连接都读取同一个成功提交的文档 revision。

## 当前情况

- `canvasEditV3Materialization.ts` 已能用 V3 渲染计划分块物化整文档，并返回受管图片、尺寸和新的会话引用。
- `toolProcessor.ts` 和 `NodeToolDialog.tsx` 当前在用户点击应用后物化整文档，然后调用 `addDerivedExportNode` 创建新节点。
- `parseCanvasEditV3NodeSession` 和项目包适配器要求会话 `sourceUrl` 与节点 `imageUrl` 一致，因此回写必须同时更新两者。
- `layerStackResultNodeDefinition.getOutputs` 复用标准图片输出，只要 `imageUrl` 正确，下游节点无需理解 V3 文档。
- 当前没有“按节点 ID + 预期旧会话 + 新会话/图片”进行比较并原子回写的专用事务，也没有关闭期间节点被删除或文档 revision 改变的冲突处理。
- 2.1 已建立 `MultiLayerDocumentEditorDialog` 的统一关闭状态机；`onCloseReady({ nodeId, session })` 会在共享保存队列 flush 后、编辑器真正关闭前被等待。`NodeToolDialogRouter` 当前使用 no-op continuation，且只有 continuation 成功后才允许卸载宿主。

## 实施方案

复用 1.1 的文档节点服务实现关闭事务：2.1 flush 返回精确文档引用后，重新加载该 revision 的权威快照，调用现有分块物化管线，校验返回的 documentRef、revision、sourceFingerprint 和尺寸，再以预期旧节点状态做比较提交。

提交一次更新 `imageEditSession`、`imageUrl`、`previewImageUrl`、比例和必要状态，成功后才释放旧平面输出并关闭编辑器。若节点已删除、会话已被其他操作替换或 revision 不一致，停止提交并给出可恢复冲突，不覆盖更新后的节点。

节点的标准图片端口继续使用 `imageUrl`；节点预览优先使用本次受管预览。画布历史不重复记录图片编辑命令，V3 文档自身保留撤销/重做；关闭前后的节点引用同步按 1.1 冻结的历史策略执行。

## 执行步骤

1. 为关闭物化事务定义预期输入：projectId、nodeId、旧会话、flush 后文档引用和取消信号。
2. 从仓库加载精确 revision，调用 `materializeCanvasEditV3Snapshot` 或其业务层封装，校验受管图片完整性、尺寸和来源指纹。
3. 使用画布受控 mutation 比较并原子回写会话、平面图、预览和比例；禁止组件直接连续调用多个 store setter。
4. 在 `NodeToolDialogRouter` 组合根向 `MultiLayerDocumentEditorDialog.onCloseReady` 注入该事务；不要修改宿主内部 flush，不要新建第二个关闭状态机。提交成功后现有协议会关闭，失败时会保持编辑器和旧节点可用预览并提供重试。
5. 确认节点下载、复制前读取、项目保存和所有 `getOutputs` 消费方都使用最新成功提交的 `imageUrl`。
6. 处理节点删除、项目切换、重复关闭、物化取消、旧平面图释放失败和 CAS 冲突；资源释放失败进入诊断/清理候选，不回滚已成功提交的节点。
7. 添加整文档渲染、原子回写、下游输出、失败回退、并发冲突、保存重开和重开编辑器一致性测试。
8. 根据当前测试规则执行精确验证；只有本任务的真实点击关闭行为无法由测试证明时，才在任务完成边界升级真实 Electron 验证。

## 验收标准

- [ ] 关闭编辑器会先保存、再物化、再原子更新同一节点，成功前不会关闭或显示新预览。
- [ ] 节点 `imageEditSession`、`imageUrl`、预览、尺寸和文档 revision 始终对应同一物化结果。
- [ ] 编辑后不会生成额外“编辑结果”节点，原节点 ID、位置和连线保持不变。
- [ ] 节点可作为标准图片输入连接其他节点，下游拿到关闭后最新合成图。
- [ ] 物化失败、节点删除、项目切换和 revision 冲突不会覆盖新状态或丢失原可用预览。
- [ ] 保存重开、重复编辑和下载均与最新预览一致；V3 撤销历史不被画布引用同步重复表示。
- [ ] 定向测试和匹配验证通过，任务记录与总览已同步。
