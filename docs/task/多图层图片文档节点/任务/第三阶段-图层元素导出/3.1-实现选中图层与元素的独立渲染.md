# 3.1 实现选中图层与元素的独立渲染

## 任务状态

- 状态：已完成
- 所属阶段：第三阶段——图层元素导出
- 前置任务：1.1
- 关联任务：2.1、3.2
- 是否可以并行：可以；1.1 完成后可与 1.2、2.1 并行，禁止改动画布落图事务

## 任务目标

为图片编辑 V3 建立稳定的“独立导出目标”解析和渲染能力，把选中的栅格图层、图层组或标注元素渲染为透明背景的受管 PNG，同时正确处理祖先组、变换、蒙版、透明度和资源校验，且不修改原文档。

## 当前情况

- V3 文档在 `src/core/imageEdit/v3/layerTypes.ts` 中支持栅格、标注、效果、调整和组图层，组内外顺序均为自下而上。
- 编辑器会话存储 `selectedLayerIds`；标注元素位于 annotation 图层的 `annotations` 数组，标注覆盖层有自己的元素选中状态，但目前没有可供业务服务使用的稳定导出引用。
- `src/features/imageEdit/v3/export/` 已有整文档 render plan 和分块导出，`canvasEditV3Materialization.ts` 可将 tiles 物化为受管图片。
- 现有单层下载属于旧 `LayerStackSpecialEditor`，它直接围绕 V1 资源，不理解 V3 的变换、组、蒙版、稀疏瓦片和标注元素。
- 效果层和调整层依赖其下方内容，单独输出时语义不明确；紧边界裁剪与原画布尺寸输出也尚待用户确认。

## 实施方案

实现纯领域的目标解析器，根据 1.1 的稳定引用从权威文档解析目标、祖先链和依赖。对栅格层、组和标注元素生成不落盘的派生渲染视图：只保留目标内容，但保留影响目标的祖先变换、透明度、混合、蒙版和组隔离语义。原文档对象、revision 和历史不得变化。

渲染复用现有 V3 render plan、tile renderer 和主进程物化命令。首版按重要记录 006 的暂定方案输出“原文档画布尺寸 + 透明背景 PNG”；若执行前用户确认紧边界裁剪，先更新重要记录和本任务再改实现。

效果/调整图层必须通过显式支持矩阵处理：只有能定义完整依赖上下文且测试证明正确时才开放，否则按钮禁用并返回用户可理解原因。标注元素导出通过 `annotationLayerId + annotationId` 定位，不能把 DOM selection 或数组下标当稳定身份。

## 执行步骤

1. 对照 V3 图层、渲染计划、标注选择和资源描述，更新本任务的目标支持矩阵并确认两项待确认决定。
2. 实现稳定目标解析：校验文档引用、目标 ID、目标类型、祖先组、锁定/隐藏状态和资源存在性。
3. 为栅格层、组和标注元素构造不可变的派生渲染视图；保留必要祖先语义，排除无关兄弟内容。
4. 接入现有 tile renderer 和受管 PNG 物化，返回媒体 URL、尺寸、透明信息、目标显示名和可诊断元数据。
5. 处理隐藏层、空图层、缺失资源、稀疏瓦片、蒙版、裁剪/旋转、组隔离、取消和大图内存上限。
6. 为效果/调整图层实现明确的支持或拒绝规则；禁止自动退化为整文档导出。
7. 增加透明边缘、位置保持、祖先变换、组、蒙版、标注元素、缺失资源和取消测试；使用像素/瓦片断言而不是只断言调用次数。
8. 按当前测试规则执行精确验证，更新重要记录 006、007 的最终结论和 3.2 接口说明。

## 涉及内容

### 新增文件

- 预计在 `src/core/imageEdit/v3/` 或 `src/features/imageEdit/v3/export/` 新增独立导出目标解析和派生渲染计划，具体位置按“可移除 UI 后仍成立”原则确定。
- 预计在 `src/features/canvas/imageEditV3/` 新增受管独立物化适配器及测试，负责把 V3 导出结果交给画布业务服务。

### 修改文件

- `src/core/imageEdit/v3/renderPlanCompiler.ts`：仅在现有编译器缺少目标级入口时扩展通用契约，不为画布复制一套编译器。
- `src/features/imageEdit/v3/export/`：复用并扩展整文档导出能力，支持明确目标范围。
- `src/features/imageEdit/v3/store/imageEditorSessionStoreV3.ts`：仅在稳定公开当前选择所必需时修改；持久文档中不保存临时选择。
- `src/features/imageEdit/v3/editor/ImageEditorAnnotationOverlayV3.tsx`：把标注元素选择映射为稳定 ID，不能让业务服务读取 DOM。
- `src/platform/contracts/imageEditorV3.ts`、`src/commands/imageEditorV3Export.ts` 和对应主进程物化服务：仅在独立导出需要新的严格描述时扩展。

### 可能废弃

- 旧 V1 单层下载渲染逻辑：本任务完成后不再作为新文档独立导出的实现，文件移除留到 4.2。

## 验收标准

- [x] 栅格图层、图层组和单个标注元素可通过稳定引用独立渲染，原文档和历史不变。
- [x] 输出正确应用目标及祖先的变换、蒙版、透明度、混合和组语义，不包含无关兄弟内容。
- [x] 输出是受管透明 PNG，画布范围遵循重要记录 006 的最终决定。
- [x] 隐藏、空内容、缺失资源、取消和超限有明确结果，不静默导出整文档或错误内容。
- [x] 效果层、调整层的支持边界已确定、记录并由测试覆盖。
- [x] 像素/瓦片级精确测试和匹配验证通过，没有新增浏览器端重复像素算法。
- [x] 重要记录、执行记录、总览和 3.2 的实际输入输出已经同步。
