# 多图层图片文档节点任务总览

## 任务目标

将现有 Seedream 5.0 Pro 图层分离结果从“带轻量图层弹窗的特殊结果”升级为真正的多图层图片文档节点。每个节点拥有一份独立的图片编辑 V3 文档，生成后可直接进入完整图片编辑器，编辑过程实时保存，关闭编辑器后同一节点原位刷新预览，并以最新合成图作为标准图片输出接入其他节点。

本次还包括选中图层、图层组或可支持元素后一键导出为普通图片节点，以及文档复制、删除、项目包、旧数据迁移、助手能力和完整验收。不会新建独立“项目中心”，不会另做一套图片编辑器，也不在未获授权时执行真实付费模型调用。

## 重要说明

- SDK 已支持火山引擎、APIMart、KIE 的 Seedream 5.0 Pro 结构化图层结果；本计划默认复用，不重复新增供应商适配。Fal 当前没有等价的 Seedream 独立图层分离端点。
- 现有 `layerStackResultNode` 保留内部类型并演进为 V3 文档节点，以兼容旧工程；`LayerStackDocumentV1` 仅承担读取与迁移。
- 单击节点仍用于画布选中；双击节点或点击“编辑”动作进入完整编辑器。
- 编辑不提供“保存/应用”按钮；关闭前必须等待保存和合成成功，失败时不能静默丢弃或关闭。
- 每次执行任务前必须阅读本文件、[01-实施方案.md](01-实施方案.md)、当前任务文件及必要的前置任务执行记录；执行中只处理当前任务范围。
- 任务完成或阻塞时，必须同步任务文件状态和执行记录、本总览进度与最近记录；重要方案变化同步到实施方案和重要记录。
- 每个代码任务按当时的 `docs/rules/testing.md` 裁剪验证，验证通过后只精确提交本任务文件，不混入其他并行改动。
