# 1.1 交接

## 任务结论

1.1 已完成。`layerStackResultNode` 保持内部类型不变，新契约已将 V3 可编辑态的权威数据冻结为稳定 `imageEditSession`、与 `sourceUrl` 一致的 `imageUrl` 和独立 `previewImageUrl`；`layerStackDocument` 仅供 V1 读取与迁移。

节点可被唯一解析器分为生成占位、V1 待迁移、V3 可编辑和资源降级四态；会话来源冲突、只有预览图、损坏 V1 等非法混合状态会明确失败。

## 最终契约与导出符号

- `parseMultiLayerDocumentNodeState`：四态唯一解析入口。
- `isEditableMultiLayerDocumentNode` / `isEditableLayerStackResultNode`：V3 可编辑守卫。
- `parseMultiLayerDocumentExportTarget`：只接受 `raster-layer`、`layer-group`、`annotation-element`。
- `MultiLayerDocumentExportTarget`：稳定引用分别复用 `image_edit.layer`、`image_edit.group`、`image_mark.annotation`。
- `MultiLayerDocumentNodePort`：文档/资源/像素宿主窄端口；独立导出还必须实现 `releaseExportRaster` 补偿未被画布事务接管的新资源。
- `MultiLayerDocumentNodeCanvasPort`：节点投影与普通图片节点事务窄端口。
- `createMultiLayerDocumentNodeApplicationService`：六类操作的唯一编排服务工厂。
- `MULTI_LAYER_NODE_PROJECTION_HISTORY_POLICY = 'skip-canvas-history'`：节点预览指针同步不重复表达 V3 文档编辑历史；复制、删除仍由画布历史负责。
- `MultiLayerDocumentNodeApplicationError`：稳定错误分类与可恢复标记。

效果层和调整层依赖下方图层上下文，首版固定返回 `UNSUPPORTED_EXPORT_TARGET`，不进入像素端口。
