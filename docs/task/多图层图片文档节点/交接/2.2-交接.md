# 2.2 刷新节点预览并统一合成图输出——交接

## 任务结论

2.2 已完成。多图层图片文档编辑器关闭时会先等待 2.1 保存队列返回精确会话，再加载同 revision 权威快照、流式物化整文档，并以项目、节点和预期旧会话执行原位 CAS。只有节点接管成功才允许关闭；同一节点随即显示最新合成图，下载和下游标准图片端口也继续从最新 `imageUrl` 读取。

本任务没有创建派生“编辑结果”节点，没有改变节点 ID、位置、连线或画布历史，也没有提前实现 3.2 的图层导出节点、4.1 的复制/删除/项目包/迁移，旧 V1 编辑器仍留给 4.2 收口。

## 最终关闭事务

1. `MultiLayerDocumentEditorDialog` 停止新交互并调用共享 `flushPending`，得到 `{ nodeId, session }`。
2. `NodeToolDialogRouter.handleDocumentCloseReady` 使用打开时冻结的 projectId、节点 data 和旧 session，调用 `saveMultiLayerDocumentAfterEditing`。
3. 1.1 唯一 `MultiLayerDocumentNodeApplicationService.saveMaterializedProjection` 校验 flush 会话没有切换文档或倒退 revision。
4. `createMultiLayerDocumentProjectionPort.saveAndMaterialize` 用 `loadImageEditorV3Document` 加载精确 revision，复用 `materializeCanvasEditV3Snapshot` 的 512 分块渲染和 `document-preview` 受管发布。
5. 物化结果必须同时匹配 documentRef、revision、sourceFingerprint、格式、宽高和非空受管媒体 URL。
6. `createMultiLayerDocumentProjectionCanvasPort.commitMaterializedProjection` 同步比较当前项目、节点类型和完整 expectedSession，一次替换 `imageEditSession`、`imageUrl`、`previewImageUrl`、`aspectRatio` 与必要结果状态，再调用 `persistCanvasState`。
7. 节点 CAS 使用 `skip-canvas-history`，V3 文档命令仍由文档历史表示；节点投影同步不制造第二条画布撤销记录。
8. continuation 成功返回后 2.1 状态机才批准关闭；任一步失败都保持编辑器打开并允许重试。

## CAS 与资源所有权

- 准备阶段：主进程整图物化已经把新 `previewRef` 挂到精确文档 revision，画布节点尚未接管。`MultiLayerDocumentNodeMaterialization.rollback` 保存旧/新 previewRef、documentRef、revision 与指纹。
- 未接管：校验或画布 CAS 失败时，`rollbackMaterialization` 只在文档仍精确指向本次 installed previewRef 时恢复旧 previewRef，并通过现有 command repository 与 GC 回收未接管资源；文档已经变化时不覆盖其他操作，只记录清理候选。
- 已接管：节点提交成功后，`finalizeMaterialization` 重写同 revision 文档资源集合，移除被替换的旧 previewRef，再触发 GC。失败只记录 `cleanupCandidate`，绝不回滚成功节点。
- 旧本地平面图：CAS 成功后通过现有 `image.releaseLayerStackResources` 释放被替换的本地 `imageUrl` / `previewImageUrl`；失败同样只记录候选。
- 受管 URL：新会话 `sourceUrl`、节点 `imageUrl` 和 `previewImageUrl` 指向同一受管合成图；节点 standard `getOutputs` 无需理解 V3。

## 关键实现符号

- `saveMultiLayerDocumentAfterEditing`：Router 的唯一关闭业务入口。
- `MultiLayerDocumentNodeApplicationService.saveMaterializedProjection`：精确会话校验、物化、CAS、回滚和提交后收口的唯一编排。
- `createMultiLayerDocumentProjectionPort`：精确快照、整图物化、previewRef 回滚与 finalize。
- `CanvasEditV3MaterializationContractError`：物化已经产出受管结果但契约校验失败时携带补偿所需结果。
- `createMultiLayerDocumentProjectionCanvasPort`：项目/节点/旧会话 CAS 与原位 store 提交。
- `MULTI_LAYER_NODE_PROJECTION_HISTORY_POLICY`：固定为 `skip-canvas-history`。
- `NodeToolDialogRouter.handleDocumentCloseReady`：冻结打开上下文并注入 2.1 continuation。
