# 1.2 将图层分离结果原子落为图片编辑文档——交接

## 任务结论

1.2 已完成。火山引擎、APIMart 和 KIE 的结构化图层结果在应用侧规范化后，现在会先创建一份独立 V3 图片编辑文档，再将其权威会话引用和平面投影原子交接给原占位节点。新生成节点不再写入 `layerStackDocument` 作为权威状态，也不创建额外结果节点。

当前无 SDK 协议偏差，本任务没有修改 catalog、供应商请求或公共 SDK。

## 最终事务顺序与补偿语义

1. 下载、alpha、尺寸、顺序和合成图完整验证，产生只用于供应商结果规范化的 `LayerStackDocumentV1`。
2. `commitCanvasGenerationOutputs` 先按 completionId 检查既有完成态；重复通知不会触发 V3 创建。
3. 根据节点 ID 和图层栈 ID 生成稳定文档 ID，复用 1.1 `createMultiLayerDocumentNodeApplicationService.createFromLayerStack` 导入 V3，以 `expectedRevision: 0` 初始保存。
4. 获得 V3 投影后再检查取消状态，然后在同一画布事务中向原占位节点一次写入 `imageEditSession`、与 `sourceUrl` 一致的 `imageUrl`、`previewImageUrl`、宽高比和完成态，并清除 V1 字段。
5. 节点交接前的任何失败、取消或节点/来源删除竞态，都通过 PAL/commands/preload/IPC 按刚创建文档的 `documentRef + revision` 条件删除，删除成功后运行资源 GC。
6. 条件删除返回 `false` 或补偿抛错时，不会将节点标为完成，同时记录带文档引用、revision 和 `cleanupCandidate` 的失败日志。

这一条件删除只是“本事务尚未交接所有权”的失败补偿，不能代替 4.1 的引用感知正常删除。

## 实现与导出符号

- `createLayerStackV3DocumentId`：根据节点和图层栈生成稳定 V3 文档 ID。
- `createLayerStackV3Projection`：导入 V1、以 revision 0 保存 V3，返回完整节点投影。
- `createMultiLayerDocumentFromLayerStack`：生成链对 1.1 唯一应用服务的复用入口。
- `rollbackCreatedMultiLayerDocument`：按精确 revision 删除与资源回收。
- `commitPreparedLayerStack`：V3 文档与原占位节点的交接编排。
- `deleteImageEditorV3DocumentIfRevision` / `ImageEditorV3Platform.deleteDocumentIfRevision`：跨层精确补偿契约。
- IPC：`imageEditorV3:document:deleteIfRevision`。
