# 6.1 并行代码审查

## 审查结论

最终代码复审未发现剩余阻断项。安全普通栅格文档的 pointermove 已收口为目标叶子 DOM transform，不进入 PreviewOverride、React state 或 Worker 合成；松手只提交一次，cancel、锁定变化和卸载均能恢复稳定面。

任务仍需以主任务正在重跑的定向 Reality 作为最后完成门槛；本文档不将“场景脚本已修改”写成“真实 Electron 已通过”。

## 审查范围

- 快路径准入、颜色/几何/资源描述降级与隐藏复杂层语义。
- 完整 DOM 栅格栈的层序、矩阵、透明合成、稳定面切换与提交后接管。
- 代理资源超集身份、稳定帧门控、resourceRef 去重、串行读取、有界准入重试、abort/错误传播与 object URL 生命周期。
- 直显手势的 pointermove、pointerup、pointercancel、工具切换、图层变为不可移动及组件卸载语义。
- 精确单测、多尺寸 Reality 场景和 6.1 计划链接/状态。

## 关键结论

1. 准入只接受受管 resource raster、normal、opacity 1、无 mask/tiles/crop/orientation、sRGB 8-bit SDR 且无自定义 ICC；可见 group/effect/adjustment 和不受支持媒体均降级。真实快照的 descriptor MIME 可为 `null`，此时允许进入资源准备，再用权威 source metadata 限定 JPEG/PNG/WebP、8-bit SDR 与单帧；明确的非图片 MIME 仍在读取前拒绝。隐藏复杂根层不参与当前视觉输出，忽略它们不改变可见语义。
2. 拖动期间使用完整可见栈替代稳定合成，因此不会把移动层叠到旧位置合成上造成重影。文档顺序、代理像素到源像素矩阵和 CSS 透明 source-over 与受管普通栅格合成一致。
3. 稳定资源计划覆盖文档中所有可直显根 raster；切换普通层可见性只收缩 entries，不撤销并重读同批代理。资源准备只在当前 document/revision 的稳定展示就绪后获得许可；许可后的 plan 不包含 revision 或 transform，因此拖动提交不会销毁已加载代理。不同 resourceRef 串行执行 metadata 与 proxy，共享 resourceRef 只创建一份 URL；任一错误会 abort 整批，后续 await 在创建 URL 前再检查 abort。
4. `fast_proxy` 只对主进程当前两种明确准入并发错误重试，退避为 150/350/750ms，每个不同资源最多四次请求；非准入错误立即降级，不存在无限重试。退避和在途请求均响应 abort；即使卸载后才收到旧 concurrency error，也会统一转为 AbortError，不会在卸载后误写失败状态或误记诊断。
5. 资源读取失败、图片解码 `onError`、plan 变化和卸载现在共用同一 disposer，立即 abort 并撤销已创建 object URL；不再存在 entries 清空后 URL 继续驻留到编辑器关闭的缺口。
6. 首次 Reality 截图中的大小两幅全景图是 fixture 两层复用同一资源且前景矩阵为 `0.55 + (180, 100)` 的预期结果，不是 stable 与 proxy 同时显示。真实问题先后包括全局 selector、过早验收、真实 descriptor MIME 缺失与首帧后台 `fast_proxy` 准入竞争；当前脚本已使用当前 editor 范围，并在两层可见时验证逐步跟手、兄弟层不动、revision 不变和稳定帧接回。

## 已修复的阻断问题

- transform/revision 变化会使全栈代理重读：改为稳定的层 ID + resourceRef 超集身份。
- 多层文档只剩一层可见时误用节点合成 URL：改为始终使用该层 resource 代理。
- 部分失败、abort 后完成和 `<img onError>` 的 object URL 清理不完整：已用统一 disposer 和精确测试闭环。
- pointerup 手势残差可能与权威矩阵叠加或稳定旧帧闪回：改为基础矩阵更新后先清残差，同 revision 稳定帧就绪后再切回。
- Reality 使用全局 editor/command bar 查询，且未覆盖两层可见核心场景：已改为当前 editor 定位和双层拖动。
- 真实快照 descriptor 的 MIME 为 `null` 时所有文档被过早拒绝：改为 descriptor 允许未知 MIME，并在读取代理前用 source metadata 完成格式、位深、HDR 和帧数二次准入。
- 首帧已有两个后台 `fast_proxy` 时新代理立即请求会命中同类并发上限：改为稳定帧就绪后启动、按 resourceRef 去重串行读取，且只对明确准入竞争做三次退避重试，不提高主进程上限。
- 卸载后在途请求才返回 concurrency error 会被当作真失败：已先检查 abort 并转为 AbortError，新回归确认不会继续重试或误记 `prepare.failed`。

## 非阻断风险

- 快路径上限为 16 个可直显根 raster，并使用最长边 2048 的瞬态代理；更大或更复杂文档依契约降级受管合成。
- 多个层复用同一 resourceRef 时已共享一份代理 URL；不同资源仍会各保留最长边 2048 的瞬态代理，对大量独立层的内存预算需继续观察。
- 稳定合成失败时提交后代理栈会继续显示，这比切回旧帧更安全；诊断事件仍由现有合成链路记录。
