## 已经定下的事项

**2026-11-10 用户追加的三条总原则（优先于各分文件里的写法）：**

1. **思考强度**：Opus 默认 medium；high 不用；只有真正困难的任务才用 xhigh。[08](08-执行编排.md) 表里写 high 的一律按 medium 执行。
2. **大胆、少防御**：只守 AGENTS.md 的五条硬底线，其余放开。设计和实现里层层叠加的校验、兜底、开关属于要砍掉的东西。媒体回收的实现因此精简：保留“删除进最近删除”“无持久引用才删”“助手命令行运行时不回收”，砍掉修改时间证据、目录时间戳判断、演练模式与重试机制。
