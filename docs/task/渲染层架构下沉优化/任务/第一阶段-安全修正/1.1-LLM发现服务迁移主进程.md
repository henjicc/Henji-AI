## 任务目标

将 LLM 模型发现（GET /v1/models）的 HTTP 请求从渲染层迁移到 Electron 主进程，使 API key 全程不经过渲染进程内存。


- API key 在渲染层内存中出现（`keys[provider.providerId]`）

## 实施方案

1. 主进程新建 `electron/main/services/llm/discovery.ts`，实现 `discoverModels(providerId, baseUrl)` 函数：从 keystore 直接读取 API key，发 GET /v1/models，返回模型列表。
2. 在 `electron/main/ipc/llm-runtime.ts` 注册 `llm:discoverModels` IPC handler。
3. 在 `electron/preload/api.ts` 的 `HenjiLlmApi` 接口追加 `discoverModels` 方法签名。
4. 在 `electron/preload/index.ts` 的 `llmApi` 追加 `discoverModels` IPC 调用。
5. 修改 `src/services/llm/llmDiscoveryService.ts` 的 `fetchOpenAiCompatibleModels`：改为调用 `window.henjiNative.llm.discoverModels(providerId, baseUrl)`，移除 `apiKey` 参数。
6. 修改 `LlmSettingsSection.tsx:186` 处的调用，去掉传入 `keys[provider.providerId]`。

## 执行步骤

1. 新建 `electron/main/services/llm/discovery.ts`，实现：
   ```typescript
   import { getLlmProviderApiKey } from '../keystore'
   
   export interface DiscoveredModelItem {
     modelId: string
     displayName: string
   }
   
   export async function discoverModels(
     providerId: string,
     baseUrl: string
   ): Promise<DiscoveredModelItem[]> {
     const apiKey = getLlmProviderApiKey(providerId)
     const url = resolveModelsEndpoint(baseUrl)
     const headers: Record<string, string> = { Accept: 'application/json' }
     if (apiKey) headers.Authorization = `Bearer ${apiKey}`
     
     const response = await fetch(url, { method: 'GET', headers })
     if (!response.ok) throw new Error(`获取模型列表失败: ${response.status}`)
     const data = await response.json() as { data?: Array<{ id?: string; title?: string; name?: string }> }
     return (data.data ?? [])
       .map(item => {
         const modelId = item.id?.trim()
         if (!modelId) return null
         return { modelId, displayName: item.title?.trim() || item.name?.trim() || modelId }
       })
       .filter((item): item is DiscoveredModelItem => item !== null)
   }
   
   function resolveModelsEndpoint(baseUrl: string): string {
     const normalized = baseUrl.trim().replace(/\/+$/, '')
     return normalized.endsWith('/v1') ? `${normalized}/models` : `${normalized}/v1/models`
   }
   ```

2. 在 `electron/main/ipc/llm-runtime.ts` 的 `registerLlmRuntimeIpc()` 末尾追加：
   ```typescript
   registerIpcHandler<{ providerId: string; baseUrl: string }, DiscoveredModelItem[]>(
     'llm:discoverModels',
     (input) => {
       const record = parseRecord(input)
       return {
         providerId: readString(record, 'providerId'),
         baseUrl: readString(record, 'baseUrl'),
       }
     },
     ({ providerId, baseUrl }) => discoverModels(providerId, baseUrl)
   )
   ```
   并 import `discoverModels` 和 `DiscoveredModelItem`。

3. 在 `electron/preload/api.ts` 的 `HenjiLlmApi` 接口追加：
   ```typescript
   discoverModels(providerId: string, baseUrl: string): Promise<Array<{ modelId: string; displayName: string }>>
   ```

4. 在 `electron/preload/index.ts` 的 `llmApi` 对象追加：
   ```typescript
   discoverModels: (providerId, baseUrl) => nativeInvoke('llm:discoverModels', { providerId, baseUrl }),
   ```

5. 修改 `src/services/llm/llmDiscoveryService.ts` 的 `fetchOpenAiCompatibleModels`：
   - 删除 `apiKey` 参数
   - 删除 `nativeFetch` import
   - 改为：`return window.henjiNative.llm.discoverModels(provider.providerId, provider.baseUrl ?? '')`
   - `createModelFromInput` 函数保留（仍在渲染层使用）

6. 修改 `src/components/Settings/sections/LlmSettingsSection.tsx:186`：
   - 将 `fetchOpenAiCompatibleModels(provider, keys[provider.providerId])` 改为 `fetchOpenAiCompatibleModels(provider)`

7. 运行 `npm run lint` 和 `npx tsc -p tsconfig.electron.json --noEmit`，确认无报错。
