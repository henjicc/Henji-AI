# 2.2 视频缩略图改走主进程 ffmpeg

## 任务目标

将视频缩略图生成从渲染层（HTML5 Video + Canvas）迁移到主进程（ffmpeg），消除 200ms 硬编码延迟、对特殊编码格式的兼容问题，以及渲染线程占用。

---

**位置一（主要）：上传视频时生成缩略图**

截图命令：`ffmpeg -ss 1 -i input.mp4 -frames:v 1 -vf scale=480:-1 -f image2pipe -vcodec png -`（输出 PNG 到 stdout）

## 实施方案

在 `video/ops.ts` 新增 `generateVideoThumbnail` 函数，通过 ffmpeg 截取第 N 秒的帧，输出为 JPEG base64。

渲染层 `videoProcessing.ts` 中的 `generateVideoThumbnail(videoFile: File)` 改为：
1. 通过 `getPathForFile(file)` 获取本地路径
2. 如果有路径，调用 `window.henjiNative.video.generateThumbnail({ source: filePath, timeOffset })`
3. 如果没有路径（合成 Blob），保留现有 HTML5 Video 逻辑作为后备

`dragThumbnails.ts` 中的 `generateVideoThumbnail(videoUrl: string)` 接受 URL（`henji-media://` 或本地路径），可直接传给主进程处理，改造更简单。

## 执行步骤

1. 在 `electron/main/services/video/ops.ts` 新增 `generateVideoThumbnail` 函数：
   ```typescript
   export async function generateVideoThumbnail(
     source: string,
     timeOffsetSeconds: number = 1.0
   ): Promise<string> {
     const ffmpegPath = await loadFfmpegPath()
     const localPath = await resolveLocalVideoPath(source)
     
     // 先获取视频时长，确保 seek 点在范围内
     let seekTime = timeOffsetSeconds
     try {
       const info = await readVideoInfo(source)
       seekTime = Math.min(Math.max(0.1, timeOffsetSeconds), Math.max(0.1, info.durationSeconds - 0.1))
     } catch { /* 获取失败则用默认值 */ }
     
     const result = await execFileAsync(ffmpegPath, [
       '-ss', String(seekTime),
       '-i', localPath,
       '-frames:v', '1',
       '-vf', 'scale=480:-1',
       '-f', 'image2pipe',
       '-vcodec', 'png',
       'pipe:1',
     ])
     // result.stdout 是 Buffer（需要 execFile 返回 Buffer 模式）
     // 注意：当前 execFileAsync 的 stdout 是 string 类型，需确认或调整
     // 若 stdout 是 Buffer，则：
     return `data:image/png;base64,${Buffer.from(result.stdout).toString('base64')}`
   }
   ```
   **注意**：`execFileAsync` 当前 `maxBuffer` 是 32MB，足够截图；但 stdout 类型是 `string`，PNG 是二进制，需要将 `execFile` 的 `encoding` 设为 `null` 或 `buffer`。执行时需确认并按需调整 `execFileAsync`，或新增一个返回 Buffer 的变体。

2. 在 `electron/main/services/video/types.ts` 追加：
   ```typescript
   export interface GenerateVideoThumbnailPayloadDto {
     source: string
     timeOffsetSeconds?: number
   }
   export interface GenerateVideoThumbnailResultDto {
     dataUrl: string
   }
   ```

3. 在 `electron/main/ipc/video.ts` 的 `registerVideoIpc()` 末尾追加：
   ```typescript
   registerIpcHandler<GenerateVideoThumbnailPayloadDto, GenerateVideoThumbnailResultDto>(
     'video:generateThumbnail',
     parseThumbnailPayload,
     async (payload) => {
       const dataUrl = await generateVideoThumbnail(payload.source, payload.timeOffsetSeconds)
       return { dataUrl }
     }
   )
   ```

4. 在 `electron/preload/api.ts` 的 `HenjiVideoApi` 追加：
   ```typescript

   ```

5. 在 `electron/preload/index.ts` 的 `videoApi` 追加：
   ```typescript
   generateThumbnail: (payload) => nativeInvoke('video:generateThumbnail', payload),
   ```

6. 修改 `src/utils/videoProcessing.ts` 的 `generateVideoThumbnail`：
   ```typescript
   export async function generateVideoThumbnail(
     videoFile: File,
     timeOffset: number = 1.0
   ): Promise<string> {
     // 高效路径：有本地路径时走主进程 ffmpeg
     const filePath = getPathForFile(videoFile)
     if (filePath) {
       const result = await window.henjiNative.video.generateThumbnail({
         source: filePath,
         timeOffsetSeconds: timeOffset,
       })
       return result.dataUrl
     }
     // 后备路径：保留原有 HTML5 Video 逻辑（Blob 无路径时使用）
     return generateVideoThumbnailFallback(videoFile, timeOffset)
   }
   
   // 原有逻辑重命名为 generateVideoThumbnailFallback，内容不变
   ```
   需要 import `getPathForFile` from `@/platform/desktopApi`。

7. 修改 `src/utils/imageConversion/dragThumbnails.ts` 的 `generateVideoThumbnail(videoUrl: string)`：
   - 直接改为调用 `window.henjiNative.video.generateThumbnail({ source: videoUrl })`
   - 该函数接受 URL，主进程的 `resolveLocalVideoPath` 已支持本地路径和 http URL

8. 运行 `npm run lint` 和 `npx tsc -p tsconfig.electron.json --noEmit`。

## 注意事项

`execFileAsync` 的当前实现使用 string 编码输出。ffmpeg pipe 输出 PNG 是二进制数据，需要修改 `execFileAsync` 支持 Buffer 输出，或新增 `execFileAsyncBuffer` 变体。执行时先确认此点，按实际情况调整步骤 1 中的实现。
