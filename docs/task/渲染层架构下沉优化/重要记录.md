# 重要记录

## 记录 001：图片压缩的 Pica 后备路径保留策略

- 日期：2026-07-01
- 状态：已确定
- 背景：任务 2.1 将图片压缩迁移到主进程，但渲染层存在 `Blob` 无本地路径的情况（如从 URL 下载的图片、画布截图等），无法直接传路径给主进程。
- 最终决定：有本地路径时走主进程 sharp（主路径），无本地路径时保留 Pica 逻辑作为后备（不删除 `ensureCompressedJpegBytesWithPica`）。
- 选择原因：无路径的 Blob 场景频率低；若要完全迁移，需要先将 Blob 字节序列化传 IPC（对大文件反而更耗时），得不偿失。
- 影响任务：2.1
