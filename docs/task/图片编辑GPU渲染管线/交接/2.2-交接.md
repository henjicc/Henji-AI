# 2.2 接入实时交互与自动回退交接

## 完成边界

- 复杂根级栅格拖动已复用 `ImageEditorRenderSessionGpuBridgeV3` 的唯一 GPU Scene 会话，pointermove 仅在 rAF 内更新 transient transform 并请求 draft frame。
- interaction sequence 使用会话本地严格单调计数器；pointercancel、卸载、切换选层、GPU 失效与 pointerup 的 clear/权威接管共用序列门控，过期位图先 `close()` 再丢弃。
- pointermove 不发布 PreviewOverride，不改 document revision，不编译 RenderPlan，不启动 CPU region executor，不重复上传纹理，不做 GPU→CPU 像素读回；pointerup 只产生一次命令、保存和 revision。
- GPU ImageBitmap 先完整写入 staging，再原子替换安全表面和前表面。初始化失败、device lost、合成失败或呈现失败时保留最后稳定 Canvas2D/DOM 帧并自动回退；GPU 内部状态只进入日志。
- 原有 DOM raster pasteboard 保留为 CPU fallback 优化；没有新增 Worker、device、context 或第二套业务图层模型。

## 关键入口

- `src/features/imageEdit/v3/editor/useImageEditorLayerMoveGestureV3.ts`：本地单调序列、rAF 合帧、结束/取消清理和单次权威提交。
- `src/features/imageEdit/v3/execution/imageEditorRenderSessionGpuBridgeV3.ts`：串行帧请求、最新 transient 合并、三序列过期校验、ImageBitmap 接管与失败回退。
- `src/features/imageEdit/v3/execution/imageEditorPresentationSurfaceV3.ts`：GPU staging、安全表面和前表面的原子交接及 Reality 指标。
- `src/features/imageEdit/v3/execution/imageEditorRenderSessionGpuPresentationV3.ts`：RenderSession 内 GPU/CPU 稳定表面所有权薄层。
- `scripts/lib/uiInspectionMultiLayerDragPerformance.cjs`：100 事件逐呈现采样、热路径计数和一次保存/revision 门禁。

## 验证与性能

- 精确 Vitest：6 文件 31/31；覆盖 GPU 手势零 PreviewOverride、串行合帧、过期 bitmap 关闭、合成失败/device lost 回退、原子 staging 和尺寸失败保持旧帧。
- `verify:changed` L2 支持集合：7 文件 33/33、ESLint、渲染层 TypeScript 均通过；独立全量渲染层 `tsc`、全部本任务 TS/TSX ESLint 通过。
- Reality 脚本：`node --check` 通过，`scripts/lib/uiInspection.test.cjs` 20/20。
- 正式 Electron `canvas-multi-layer-document-editor`：1440×900、960×640 均通过，失败数 0；四张截图已目视确认稳定帧无黑屏、残影或裁切。
- 1440×900：100 pointermove、100 样本、interaction delta 100、呈现帧 delta 100、uniform delta 100；event-to-present p95 `4.4 ms`、p99 `6.7 ms`，相对 1.1 约提升 5.4×/4.6×。
- 960×640：同为 100/100/100/100/100；p95 `2.7 ms`、p99 `4.8 ms`，相对 1.1 约提升 9.2×/6.6×。
- 两档热路径 PreviewOverride、revision、RenderPlan、CPU task、重复 upload、GPU readback 增量均为 0；uniform 更新不超过实际呈现帧；pointerup 日志与持久化精确为一次保存和一次 revision。
- `verify:changed` 将没有同名测试的 TS 源文件交给 Vitest `related` 时触发既有 Rollup TS 解析错误；对应逻辑已由上述精确测试、独立 ESLint/tsc 与 Reality 覆盖，没有放宽产品门槛。

## 限制与风险

- GPU 接管范围仍是不超过 512×512、单瓦片、根级 sRGB 8-bit normal raster；组、蒙版、非 normal 混合、效果、HDR/ICC 和大图继续自动走 CPU/DOM。
- 当前呈现后端是 GPU ImageBitmap，经 Canvas2D staging 原子交接；直接 WebGPU Surface 只在 4.2 实现。
- Reality 使用确定性 320×240 五层夹具以进入 2.1 支持范围；真实供应商 KIE 五层结果仍需在最终验收复核。
- 外层 Playwright driver p95/p99 受进程调度影响，已单独记录且不冒充 event-to-present 指标。
