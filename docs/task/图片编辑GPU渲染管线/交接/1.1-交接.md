### 真实 Electron 五层 DOM 快路径

| 窗口 | 样本 | p50 | p95 | p99 |
|---|---:|---:|---:|---:|
| 1440×900 | 100 | 23.328 ms | 23.947 ms | 30.851 ms |
| 960×640 | 100 | 23.542 ms | 24.707 ms | 31.821 ms |

采样口径从 Playwright 驱动 `page.mouse.move` 前开始，到页面下一次 `requestAnimationFrame` 返回结束，因此包含自动化 IPC 与刷新等待；1.2/2.2 必须保持同一口径比较，不能拿纯 JS uniform 更新时间直接宣称提升。该 Reality 同时证明 100 次移动期间 revision 不变、目标层独立变化、松手只增加一个 revision。

## 供 1.2 使用的接口与约束

- 1.2 只建立会话/协议/生命周期，不修改 fixture 输出与 CPU 指纹。
- GPU 测试通过 `renderImageEditorCpuGoldenV3(fixture)` 获得 Float32 权威输出，通过 `compareImageEditorGoldenV3` 做线性和 LSB 比较。
- 保持官方 vGPU 约束：一个会话一次 `init()`；Context/Target/Draw 常驻；Frame 多 Pass 一次提交；`target.read/readFloats` 只用于测试、诊断和导出，不进入热帧。
- 8192 fixture 的 `renderSize` 是视口/瓦片目标，不代表允许分配 8192² Float32 缓冲。

## 遗留风险

- Reality 五层使用同一真实本地图像资源作五个变换层，结构与 KIE 结果一致但不包含五个不同透明素材；5.2 必须用真实供应商结果复核。
- Node CPU 数字受 JIT、温度和机器负载影响；比较时应重复采样，像素指纹才是确定性契约。
- 当前 p99 曾在失败重跑中出现单次调度尖峰，正式门槛必须看多轮分布并保留原始样本，不能只挑最好一轮。
