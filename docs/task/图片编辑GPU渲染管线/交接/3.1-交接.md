# 3.1 实现完整图层合成语义交接

## 完成边界

- 复用现有唯一 GPU Scene、Worker、device、vGPU Context、三序列和串行稳定帧交接；没有新增业务图层模型或第二套渲染会话。
- CPU RenderPlan 投影为 retained RenderGraph，覆盖嵌套组、组隔离、legacy/sparse 蒙版、裁剪、orientation、`normal/multiply/screen/overlay/soft-light` 和 `exposure/curves/temperature-tint/hsl`。
- normal 使用固定预乘混合；需要背景采样的模式使用离屏节点 shader。蒙版 target 为 `r8unorm`，节点按依赖指纹局部失效；只融合连续、无蒙版、normal、全透明度曝光。
- 标注、画笔和空间效果明确交给 3.2；大图瓦片、HDR/ICC 交给 4.1；这些未接管场景保持自动 CPU fallback。

## 关键入口与合并点

- `imageEditorGpuRasterSceneCompilerV3.ts`：高冲突点；把现有 RenderPlan 映射成 graph，不改变 CPU 真值。
- `imageEditorGpuRenderGraphExecutorV3.ts`：独立 executor、Target 生命周期、依赖指纹、固定/背景采样混合与 adjustment dispatch。
- `imageEditorGpuRasterCompositorV3.ts`：高冲突点；现有 compositor 薄门面接入 executor，并保留呈现与统计。
- `imageEditorRenderSessionGpuBridgeV3.ts`：高冲突点；只补 sparse Float32 brush tile → r8 transport，2.2 串行帧/稳定帧合同不变。
- `imageEditorGpuSceneProtocolV3.ts`：resource key 增加可选 format；4.1 合并时保留 format 参与身份。
- `imageEditorGpuAdjustmentParametersV3.ts` 与 graph WGSL：独立模块，3.2/5.1 可直接复用。

## 像素与缓存证据

- 5 种混合的线性最大误差依次为 `0.000707/0.000860/0.000851/0.001163/0.001021`；全部量化 100% 通道 ≤1 LSB、最大 1 LSB。
- 嵌套隔离组+组/子层蒙版 `0.000849`，sparse r8 mask `0.001035`；4 种调整层依次 `0.000990/0.000922/0.000985/0.000986`，量化同样 100% ≤1 LSB、最大 1 LSB。
- 五层/16 层基础 golden 保持 `0.00103194/0.00103605`，符合记录 006 的 `1.1e-3` 门槛；编码最大 1 LSB。
- 重复帧不重算 graph 节点；顶层瞬态变换只失效并重算 1 个 composite，源与 3 个无关节点继续命中；重复帧无上传、重编译或读回。

## 验证

- `tsc --noEmit` 通过；真实 `vgpu/node` WGSL 与精确 Vitest 通过。
- `verify:changed` L2 的精确测试通过；首次 related 阶段因 worktree 复用依赖时 SDK 产物未生成而失败，`electron:bundle` 已生成当前 SDK/运行产物，最终复验见任务回报。
- 正式 Electron complex graph Reality 使用隔离组、组/子层蒙版、screen/multiply/soft-light 与曝光；双尺寸各 100 次拖动，热路径 PreviewOverride、revision、RenderPlan、CPU task、上传与读回增量为 0；截图目视无黑屏、残影或裁切。

## 限制、风险与后续

1. 4.1 合并 compiler/protocol/runtime 时保留 `format` 身份和 graph executor 单一所有权；不要另建 tile graph。
2. 3.2 新 effect 需显式声明颜色域和 alpha 合同；pointwise 之外不得进入当前 adjustment fusion。
3. 5.1 导出复用 graph canonical 线性预乘输出；不得绕过 RenderPlan 或复制 adjustment shader。
4. 主任务合入后将 `00-任务总览.md` 的 3.1 改为“已完成”，并把下一步指向 3.2/4.1 合并接口；本分支按并行约定未直接修改总览。
