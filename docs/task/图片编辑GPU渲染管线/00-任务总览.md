# 图片编辑 GPU 渲染管线

## 任务目标

在不改变 `ImageEditDocumentV3`、实时保存、撤销历史、画布节点和助手能力的前提下，把图片编辑器从“CPU 分块合成 + 少量 vGPU 效果 + Canvas2D/DOM 展示”迁移为会话级 WebGPU 常驻图层场景。实时预览、复杂合成、效果、大图与正式导出最终以 GPU 为主，失败时自动回退现有 CPU 管线。

本任务包含 GPU Scene、基础与复杂图层语义、画笔/效果、大图色彩、直接呈现、GPU 分块导出及最终切换；不包含 SDK、供应商适配、文档格式变更或引入其他渲染框架。

## 重要说明

- vGPU 固定为现有 `0.3.1`，负责 Context、Target、Frame、Effect/Draw 等原语；PSD 式图层语义由项目自有 retained 2D scene 实现。
- 运行时选择顺序固定为 WebGPU Surface → GPU ImageBitmap → CPU/Canvas2D；回退细节只进入结构化日志和测试。
- 每个编号任务由独立子代理执行并提交 `交接/<编号>-交接.md`；主代理只调度、审查和集成。
