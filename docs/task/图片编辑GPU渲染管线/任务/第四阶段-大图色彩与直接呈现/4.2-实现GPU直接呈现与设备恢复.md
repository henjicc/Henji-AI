# 4.2 实现 GPU 直接呈现与设备恢复

## 任务状态
- 状态：待开始
- 所属阶段：第四阶段-大图色彩与直接呈现
- 前置任务：2.2、4.1
- 关联任务：5.2
- 是否可以并行：可与3.2并行

## 任务目标
使用 OffscreenCanvas + vGPU Surface 直接呈现，实时预览零 GPU 回读，并在初始化失败或 device lost 时无黑帧切换稳定 Canvas2D fallback。

## 当前情况
- 现有最终展示使用 ImageBitmap、Canvas2D atlas 或 DOM 栈；GPU 基础路径仍要把帧交回主线程。
- session 已有最后稳定输出和现有 CPU 管线，可作为双表面交接基础。

## 实施方案
将可见 canvas 控制转交 GPU Worker 的 OffscreenCanvas；保留隐藏 Canvas2D 稳定表面，只有新后端首帧 ready 后才原子切换。

## 执行步骤
1. 建立 OffscreenCanvas/Surface 初始化、resize、DPR 和 camera 更新。
2. 实现直接呈现和 ImageBitmap 中间路径降级。
3. 监听 device lost，销毁关联资源并启动 CPU fallback。
4. 恢复后只按最新权威 snapshot 重建一次。
5. 在双尺寸 Electron Reality 注入失败与恢复场景。
