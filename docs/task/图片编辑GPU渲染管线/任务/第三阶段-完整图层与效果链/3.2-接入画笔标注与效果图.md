# 3.2 接入画笔标注与效果图

## 任务状态
- 状态：进行中
- 所属阶段：第三阶段-完整图层与效果链
- 前置任务：3.1
- 关联任务：5.1
- 是否可以并行：可与4.2并行

## 任务目标
让稀疏画笔、标注缓存、模糊、扩散和辉光在同一 GPU 场景中执行，消除效果中间结果的 GPU→CPU→GPU 往返。

## 当前情况
- 画笔和蒙版已有 Float32 稀疏瓦片；标注由 Canvas 光栅化后进入 CPU 管线。
- `previewCustomEffectsV3.ts` 可将部分效果临时交给 vGPU，但仍需返回 CPU tile。

## 实施方案
按内容版本增量上传画笔/蒙版瓦片；标注缓存为纹理；把三类效果改成 Target 输入输出并复用稳定 ping-pong 资源。

## 执行步骤
1. 接入稀疏画笔和蒙版瓦片增量更新。
2. 建立标注纹理缓存与失效边界。
3. 迁移模糊、扩散、辉光到同一 RenderGraph。
4. 处理 halo、透明边缘和任务取消。
5. 用 SSIM、边缘和连续笔画 Reality 验证。

## 涉及内容
### 修改文件
- GPU RenderGraph、现有效果执行器、画笔/标注资源桥与专项测试。

## 验收标准
- [ ] 笔画只上传变化瓦片且撤销/重做正确。
- [ ] 三类效果热路径无 CPU readback。
- [ ] SSIM≥0.999且透明边缘无黑白边/接缝。
- [ ] 取消和失败能回退并释放资源。
- [ ] 交接与总览已更新。
