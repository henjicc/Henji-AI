# 3.1 实现完整图层合成语义

## 任务状态
- 状态：待开始
- 所属阶段：第三阶段-完整图层与效果链
- 前置任务：2.1
- 关联任务：3.2、5.1
- 是否可以并行：可与4.1并行

## 任务目标
让组、组隔离、蒙版、裁剪、方向、现有全部混合模式和调整层进入 GPU RenderGraph，并与 CPU 真值一致。

## 当前情况
- RenderPlan compiler 与 CPU executor 已定义这些语义；GPU 基础路径只覆盖普通 normal 栅格。
- 1.1 complex-mask fixture 可作为首个跨实现真值。

## 实施方案
按现有 RenderPlan 编译离屏子图；可固定混合的模式直接绘制，需要背景采样的模式用 ping-pong；蒙版采用 `r8unorm`，组结果只在依赖指纹变化时失效。

## 执行步骤
1. 编译嵌套组与隔离 Target 生命周期。
2. 实现蒙版、裁剪、方向和全部现有混合模式。
3. 实现调整层 shader 与 pointwise fusion。
4. 增加依赖指纹、局部失效和缓存测试。
5. 对照 CPU golden 与复杂 Reality 验证。

## 涉及内容
### 新增文件
- 预计 RenderGraph、混合/调整 WGSL 和组目标缓存。
### 修改文件
- GPU scene compiler 与 golden 测试。
