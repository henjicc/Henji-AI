# 3.1 实现完整图层合成语义

## 任务状态
- 状态：已完成
- 所属阶段：第三阶段-完整图层与效果链
- 前置任务：2.1
- 关联任务：3.2、5.1
- 是否可以并行：可与4.1并行

## 任务目标
让组、组隔离、蒙版、裁剪、方向、现有全部混合模式和调整层进入 GPU RenderGraph，并与 CPU 真值一致。

## 当前情况
- RenderPlan compiler 与 CPU executor 已定义这些语义；GPU 基础路径只覆盖普通 normal 栅格。
- 1.1 complex-mask fixture 可作为首个跨实现真值。

## 实施方案
按现有 RenderPlan 编译离屏子图；可固定混合的模式直接绘制，需要背景采样的模式用 ping-pong；蒙版采用 `r8unorm`，组结果只在依赖指纹变化时失效。

## 执行步骤
1. 编译嵌套组与隔离 Target 生命周期。
2. 实现蒙版、裁剪、方向和全部现有混合模式。
3. 实现调整层 shader 与 pointwise fusion。
4. 增加依赖指纹、局部失效和缓存测试。
5. 对照 CPU golden 与复杂 Reality 验证。

## 涉及内容

## 执行记录
### 2026-09-04
- 完成内容：在现有唯一 GPU Scene/Worker/device/vGPU Context 内接入 CPU RenderPlan 投影的 retained RenderGraph，覆盖嵌套隔离组、legacy/sparse 蒙版、裁剪/方向、全部 5 种混合和全部 4 种调整层。
- 实际改动：新增独立 graph executor、调整参数模块与 6 个 WGSL；normal 使用固定预乘混合，其余模式采样背景；蒙版实际使用 `r8unorm`；节点依赖指纹支持重复帧复用和受影响路径局部失效；仅融合连续、无蒙版、normal、全透明度曝光。
- 验证结果：真实 vgpu/node golden 覆盖 5 种混合、4 种调整、嵌套组/蒙版、sparse mask、crop/orientation 和缓存；量化均为 100% 通道不超过 1 LSB、最大 1 LSB。复杂 Reality 双尺寸覆盖 100 次拖动、自动回退和截图目视。
