## 任务目标
将 GPU 设为全部当前可渲染文档的默认预览与导出路径，CPU 仅作兼容回退，并完成高风险全量和真实 Electron 验收。

## 当前情况
- 前置任务完成后将同时存在 GPU Surface、GPU ImageBitmap 和 CPU/Canvas2D 三层路径。
- 1.1 已建立性能/像素基线，最终需要用真实 KIE 五层结果和全部编辑/导出场景复核。

## 实施方案
按“普通栅格→复杂图层→直接呈现→导出”完成默认开关收口，删除迁移期重复正常路径但保留 CPU fallback；结构化记录后端与恢复结果。

## 执行步骤
1. 清点所有当前可渲染 RenderPlan 节点与导出格式的 GPU 覆盖。
2. 切换默认顺序并移除只为迁移存在的分支。
3. 用真实 KIE 五层重复1.1采样，核对性能提升和热路径零计数。
4. 执行像素、HDR、大图、device lost、保存/重开、节点和项目包 Reality。
5. 按testing.md执行L3、双尺寸Electron和最终代码审查。
