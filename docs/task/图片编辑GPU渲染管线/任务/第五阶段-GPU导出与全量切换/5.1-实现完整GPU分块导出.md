# 5.1 实现完整 GPU 分块导出

## 任务状态
- 状态：待开始
- 所属阶段：第五阶段-GPU导出与全量切换
- 前置任务：3.2、4.1
- 关联任务：5.2
- 是否可以并行：否

## 任务目标
按瓦片和 halo 在 GPU 执行完整 RenderGraph，只在导出阶段回读，并继续流入现有主进程编码器覆盖全部格式。

## 当前情况
- `src/features/imageEdit/v3/export/` 与主进程输出 sink 已支持 JPEG、WebP、PNG、TIFF、AVIF、BigTIFF 的分块编码。
- 当前导出像素由 CPU 生成；GPU scene 尚无 export tile 协议实现。

## 实施方案
复用现有导出规划、halo 和编码服务，GPU Worker 仅生产有界 output tile；按顺序回读并维持取消、背压、元数据和临时文件清理语义。

## 执行步骤
1. 实现 export 请求、瓦片调度、halo 和过期任务取消。
2. 复用 RenderGraph 渲染每个输出瓦片并做唯一允许的 readback。
3. 对接现有输出 sink，不改格式和编码职责。
4. 验证边界接缝、HDR位深、取消和失败清理。
5. 与 CPU 整图/分块 golden 对比全部格式。

## 涉及内容
### 修改文件
- GPU Worker export、现有导出调度和精确格式测试。

## 验收标准
- [ ] 全部现有格式可由GPU瓦片输入编码。
- [ ] tile边界无可测接缝且颜色元数据保持。
- [ ] 预览热路径仍无readback，导出内存有界。
- [ ] 取消/失败不残留临时文件或GPU资源。
- [ ] 交接与总览已更新。
