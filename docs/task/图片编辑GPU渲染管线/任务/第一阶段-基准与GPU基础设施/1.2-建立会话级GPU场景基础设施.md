# 1.2 建立会话级 GPU 场景基础设施

## 任务状态
- 状态：已完成
- 所属阶段：第一阶段-基准与GPU基础设施
- 前置任务：1.1
- 关联任务：2.1、2.2
- 是否可以并行：否

## 任务目标
建立每编辑会话唯一的 GPU Scene Worker、vGPU Context、协议、设备生命周期、资源注册、序列校验和结构化后端诊断。

## 当前情况
- `imageEditorRenderSessionV3.ts` 已统一协调 draft/target/analysis，但执行客户端仍按现有 CPU/Worker 管线组织。
- `imageEditorGlobalRenderSchedulerV3.ts`、资源预算和日志封装可复用；尚无 retained GPU Scene 与独立 scene/camera/interaction 序列。

## 实施方案
扩展现有 session 而非新建平行业务入口；新增 GPU Worker 协议和会话拥有的单设备 Context，初始化失败立即返回现有 CPU 客户端。

## 执行步骤
1. 定义计划批准的请求/事件联合类型及三类序列校验。
2. 建立会话级 Worker、Context、设备丢失和 dispose 生命周期。
3. 建立资源身份注册与默认 256 MiB GPU 预算账本，不实现具体合成。
4. 将 composition/effect/presentation backend 结构化记录到统一日志。
5. 用 mock worker/device 覆盖初始化、过期事件、丢失和回退。

## 涉及内容
### 新增文件

### 修改文件
