# 1.1 建立基准与像素真值

## 任务状态

- 状态：已完成
- 所属阶段：第一阶段-基准与GPU基础设施
- 前置任务：无
- 关联任务：2.1、3.1、4.1、5.1、5.2
- 是否可以并行：否

## 任务目标

固定 GPU 迁移所需的可重复文档场景、CPU 像素真值、误差比较和性能采样入口，使后续实现可直接判断性能与像素是否退化。

## 当前情况

- 现有 `image-editor:v3:perf` 覆盖规划、预算和调度，`image-editor:v3:perf:real` 覆盖真实像素 I/O，但没有 GPU 迁移专用图层矩阵与 golden 比较。
- `previewWorkerRendererV3.ts` 和 `viewportCompositeRendererV3.ts` 以 CPU RenderPlan 为权威；多层普通栅格拖动由 DOM 代理栈临时呈现。
- Reality 场景 `canvas-multi-layer-document-editor` 已能验证拖动期间 revision 不变、松手一次提交和稳定帧交接，可继续复用。

## 实施方案

增加只供测试和专项基准消费的确定性场景与 CPU 渲染工具；扩展现有 Reality 五层文档夹具，以 100 次 move→rAF 记录 DOM 快路径基线，不新增生产 UI 或 GPU Scene。

## 执行步骤

1. 建立五层、16 层、隔离组+蒙版+调整层、Rec.2020 PQ HDR 和 8192×8192 场景生成器。
2. 通过现有 RenderPlan/CPU executor 生成稳定 Float32 真值，提供指纹和线性/LSB 比较器。
3. 增加 `image-editor:v3:gpu-baseline`，分别采样 RenderPlan 编译和 CPU 合成 p50/p95。
4. 将真实 Electron 多图层夹具扩为五层并记录 100 次 DOM 拖动呈现样本。
5. 运行精确单测、脚本语法、专项基准与单一 Reality 场景，记录结果。
