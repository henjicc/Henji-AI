## 任务目标
将拖动改为 GPU 瞬态矩阵更新、帧合并和松手一次权威提交，并完成 GPU ImageBitmap、DOM/CPU 与最后稳定帧的无闪烁交接。

## 当前情况
- `useImageEditorLayerMoveGestureV3.ts` 与 raster pasteboard 已实现 pointerup 单次提交和 DOM 快路径。
- 复杂文档仍会回到 PreviewOverride/CPU 合成，GPU 会话接口尚未接入手势。

## 实施方案
手势开始时绑定 interactionSequence；pointermove 只调用 `updateTransientLayerTransform` 和 `requestFrame`，每个呈现帧最多提交一次；结束后提交命令并由新 sceneGeneration 接管。

## 执行步骤
1. 接入 transient transform/clear/requestFrame 三个会话方法。
2. 实现 rAF 合帧和过期 interaction frame 丢弃。
3. 处理取消、卸载、选层变化、GPU 失败与稳定帧回退。
4. 保留 DOM 快路径作为 CPU fallback 优化。
5. 扩展 Reality 统计 100 次拖动热路径计数与延迟。
