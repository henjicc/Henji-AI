# 2.1 实现基础栅格 GPU 合成

## 任务状态
- 状态：已完成
- 所属阶段：第二阶段-基础合成与实时交互
- 前置任务：1.2
- 关联任务：2.2、3.1、4.1
- 是否可以并行：否

## 任务目标
让 sRGB 8-bit 普通栅格文档的顺序、显隐、变换、透明度和 normal 合成由常驻 GPU Scene 完成，并复用纹理。

## 当前情况
- CPU executor 已定义预乘 Alpha 和图层顺序真值；`rasterPasteboardV3.ts` 只覆盖有限 DOM 快路径。
- 1.1 提供五层、16 层 CPU golden 和性能入口。

## 实施方案
把 RenderPlan 基础栅格节点编译为稳定四边形绘制；源纹理只在内容版本变化时上传，矩阵/透明度进入稳定 uniform，输出暂时为 ImageBitmap。

## 执行步骤
1. 实现基础 scene compiler 与纹理上传去重。
2. 创建 `rgba16float` 中间 Target、预热 Pipeline 并单次 Frame 提交。
3. 支持 normal、opacity、transform、visibility 和顺序。
4. 将五层/16层 GPU 输出与 1.1 CPU golden 比较。
5. 验证重复帧零上传和资源释放。

## 涉及内容
### 新增文件
- `src/features/imageEdit/v3/gpu/imageEditorGpuRasterSceneCompilerV3.ts`：把单瓦片、根级、normal 的 sRGB 8-bit 栅格文档编译为 retained scene。
- `src/features/imageEdit/v3/gpu/imageEditorGpuRasterCompositorV3.ts`：常驻纹理、uniform、`rgba16float` Target、Draw、Surface 与单帧串行提交。
- `src/features/imageEdit/v3/gpu/shaders/imageEditorGpuRasterLayerV3.wgsl`：sRGB 解码、仿射采样、透明度和预乘输出。
- `src/features/imageEdit/v3/gpu/shaders/imageEditorGpuRasterPresentV3.wgsl`：线性预乘结果到 sRGB ImageBitmap 的呈现转换。
- 对应 compiler、compositor、协议、Bridge 测试与专用 Electron Reality 场景。
### 修改文件
- 复用 1.2 的 Runtime/Client/Bridge；接通受管瓦片读取、GPU 上传、三序列保护的 `frame-ready` 与隐藏 ImageBitmap 诊断。
- 正式可见输出继续使用 CPU/Canvas2D，`frame-ready` 的稳定帧交接留给 2.2。

## 验收标准
- [x] 五层与16层基础场景可走 GPU；正式 Electron 五层场景已产出 ImageBitmap。
- [x] 重复帧不重建 Pipeline、不重复上传纹理。
- [x] `rgba16float` 基础合成线性误差≤`1.1e-3`且8-bit最大差异≤1 LSB；原 `1e-4` 与格式精度矛盾见记录 006。
- [x] CPU fallback 与正式可见输出行为不变。
- [x] 交接与总览已更新。

## 执行记录
### 2026-09-04
- 完成内容：实现单瓦片基础栅格 scene compiler、常驻 GPU compositor、纹理去重、uniform 更新、ImageBitmap 隐藏帧和真实 Electron 诊断。
- 实际改动：同一会话继续只使用 1.2 的一个 Worker、一个设备和一个 vGPU Context；源纹理按资源键常驻，合成与呈现 Pipeline singleflight 预热，所有共享 Draw/Target 帧串行编码。
- 验证结果：五层最大线性误差 `0.00103194`、16 层 `0.00103605`，均为 1 LSB；真实 Electron 1440×900、960×640 均为 `upload=1`、`pipeline=2`、`frame=6`、`readback=0`。
- 遗留问题：当前仅接管不超过 512×512 的单瓦片根级 normal 栅格；大图 mip/瓦片由 4.1 接入，复杂图层由 3.1 接入，正式 GPU 稳定帧呈现与交互回退由 2.2 接入。
- 与原计划的偏差：`rgba16float` 的逐层半精度量化无法满足原线性 `1e-4`，按记录 006 明确调整基础门槛为 `1.1e-3`，8-bit 1 LSB 不变。
- 对后续任务的影响：2.2 的唯一呈现接点为 `ImageEditorRenderSessionGpuBridgeV3` 的 `frame-ready` 分支；不得另建 Worker/设备/Context。
