# 00 任务总览

## 任务目标

2026-07-27 用 Playwright Electron API 启动真实窗口，遍历主要页面与状态截图分析后发现：项目已经有一套完整的设计令牌与规范（`styleTokens.ts` / `motion.ts` / `henji-ui-surface` skill），**但令牌的实际消费率极低**——排版令牌全项目只被消费 19 次，手写字号 791 次；`UiEmpty` 只用了 4 次，手写空态 22 处。规范写在文档里，界面里没有落地。同时公共组件本身存在会诱导错误用法的默认形态（`Toggle` 用蓝色实心按钮表达布尔值、`UiModal` 无 Esc 关闭与焦点管理），以及一个真实的布局缺陷（智能助手侧栏打开时生成工作区底部输入面板被遮挡截断）。

本次任务要达到的结果：**让规范真正落到界面上，并修掉实测发现的具体缺陷**。做法是先修公共组件（改一处收益覆盖全项目），再修布局与信息架构，最后收敛视觉表达，并把这次的 Playwright 巡检脚本固化成可重复执行的项目命令。

### 属于本次任务

- 公共组件默认形态与可访问性缺陷修复（`UiModal`、`Toggle`、`ProgressBar`、状态组件）
- 实测发现的布局缺陷修复（助手侧栏遮挡、空态居中基准、设置弹窗信息架构）
- 选中态、页面标题、排版层级的表达统一
- 生成历史长列表的渲染治理
- 拖动助手面板卡顿问题的真实复现与定位
- 把 Playwright Electron 巡检固化为项目脚本

### 不属于本次任务

- 新增功能、新增页面、新增模型
- 配色方案本身的调整（accent 色值、主题预设配色）——上一轮 `UI设计系统统一` 已完成对比度治理，本次不再动色值
- 画布节点内部的交互重做
- 圆角档位大规模合并（沿用 `UI设计系统统一` 中 D-003 的搁置决定）
- macOS 端的真机验收

## 重要说明

- **本次所有结论都来自真实 Electron 窗口的截图与实测，不是代码推测。** 复现方式见 `01-实施方案.md` 的「巡检方法」小节，任何任务开始前都可以按同样方式重跑一遍确认现状。
- **不要新增颜色值。** 调色只允许在 `src/index.css`、`tailwind.config.js`、`src/core/theme/colorTokens.ts` 三处，且本次任务范围内不需要新增。
- **不要新增 `Ui*` 组件。** 本次任务是让已有组件被正确消费，不是造新组件。确实需要新增时，先在 `重要记录.md` 里记一条并说明现有组件为什么覆盖不了。
- **布局定位不许藏在 CSS 里。** `position`/`top`/`left`/`right`/`bottom`/`z-index` 必须写在组件 className 上。任务 2.1 的根因就是 `scrollbar.css` 里藏了一句 `position: fixed`，靠 grep 搜不出来，只能逐层量祖先链宽度才发现。详见 `重要记录.md` 记录 008。
- **涉及鼠标操作的验证交给用户。** 拖拽、悬停、右键菜单、resize 这些场景，改完写清操作步骤和验证点，不要自己上手判断"手感对了"。
- **每次改完代码必须明确告知是否需要重启 `npm run electron:dev`。**
- 本任务与既有的 `docs/task/UI设计系统统一/` 是接续关系：那一轮做的是令牌体系建设与对比度治理，这一轮做的是令牌落地与实测缺陷修复。两边的记录不合并。

### 2026-07-27（下午，用户反馈后修订）

根据用户反馈修订了 5 个任务文件和 `重要记录.md`：

- **2.1 根因下钻**：追加了祖先链实测，定位到真正的罪魁是 `src/styles/scrollbar.css:3` 的 `.app-scroll-container { position: fixed }`——一个叫「滚动条样式」的 class 把整个生成工作区钉死在视口上。不是"要不要避让"的设计选择，而是项目本来就在避让（画布是对的）但生成工作区漏了。改动量从"需要探测"降级为 **6-7 行**。同时算出复现临界值：**逻辑宽度 < 2160px 才会重叠**，解释了用户 3840×2160@150%（逻辑 2560）看不到、而 1080p 不缩放和 4K@200% 会撞。
- **3.2 方案修正**：用户澄清「开启=高亮」是有意设计，与设置→界面 的布尔项同一思路。**保留该语义映射**，改为把高亮从整行（约 600×36）收回到开关控件（约 44×24）——同一语义视觉面积差 15 倍才是问题所在。
- **4.1 解除阻塞**：改为挂载用户真实开发实例（`HENJI_ELECTRON_REMOTE_DEBUGGING_PORT=9222` + CDP），生成由用户自己发起，我只做只读测量。不再需要我持有 API Key。
- **4.2 方案定稿**：图片保持自然高度（用户确认当前视觉好），用 `aspect-ratio` 预留空间消除跳动，验收前提是截图逐像素确认视觉零变化。这部分**不依赖 4.1**，可先做。
- **2.2 决定落地**：底部「确定」及整条底部区域确定去掉。
- **新增通用规则**（记录 008）：样式表只做它名字承诺的事，布局定位不许藏在 CSS 里。这是第二次遇到同类问题（上一轮是 `storyboard.css` 藏全局主题变量）。
