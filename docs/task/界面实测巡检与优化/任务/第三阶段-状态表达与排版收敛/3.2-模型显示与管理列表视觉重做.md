## 任务目标

在**保留「开启=高亮、关闭=不高亮」这个既定语义映射**的前提下，把高亮从整行收回到开关控件本身，消除"22 个模型全开时整页一片蓝"的噪音，并顺手清掉这一页的卡片套卡片。

## 当前情况

### 设计意图（已与用户确认，不推翻）

这一页管的是模型的显示与否，设计思路和「设置 → 界面」的布尔项是同一套：**开启时高亮、文案为"显示中"；关闭时不高亮、文案为"已隐藏"**。这个语义映射是对的，本任务不改它。

### 问题不在映射，在高亮的面积

| | 高亮元素 | 尺寸 |
|---|---|---|
| 开关该有的样子（任务 1.2 的目标形态） | 一条轨道 | 约 44×24 |
| 现在的模型行 | 整行实心填充 | 约 600×36 |

同一个语义，视觉面积差约 **15 倍**。

后果（1440×900 实测截图）：
- 22 个模型全部「显示中」→ 整页几乎全是实心 accent 底
- 整行填充读起来是"这一行被选中了/这一行很重要"，而不是"这个开关处于开态"
- 用户真正需要一眼看到的是「哪几个被隐藏了」（那才是偏离默认的少数），而现在隐藏的反而是弱化的
- 「全部显示」按钮也是 accent 实心，和列表行同色，在同一屏形成竞争

### 一致性的真相

设置 → 界面 和 设置 → 模型 现在只是**都用了蓝色**，形态其实不一样：一个是按钮，一个是整行填充。任务 1.2 把 Toggle 改成滑块后，本任务复用同一个开关，两处才**真正成为同一套**。

### 其它实测问题

1. **卡片套卡片**：「快速操作」是一个卡片，内部用两条分隔线分三组；「模型列表」是一个卡片，内部每行又是卡片。与项目的「卡片嵌套上限 1 层」冲突。
2. 供应商筛选 chips（派欧云/KIE/魔搭/fal）和类型 chips（图片/视频/音频）都是未选中态，看不出单选还是多选、点了会怎样。
3. 分组头「派欧云 (22/22 可见)」右侧的「全部显示 | 全部隐藏」中间有一根装饰竖线。
4. 右侧「显示中」小字压在蓝底上，对比度需要在改造后复查。

## 实施方案

**核心：语义不变，把高亮从整行收回到开关。**

目标形态：

```
模型列表
  派欧云                              22/22 可见   [全部显示] [全部隐藏]
  ───────────────────────────────────────────────────────────────
  Nano Banana 2        图片                          显示中  [●━]
  Grok Imagine 图片    图片                          显示中  [●━]
  Seedream 5.0 Lite    图片                          已隐藏  [━○]   ← 一眼可见
```

- 每行是**一行**，不是卡片：行之间用分隔线或 hover 底色区分，不画边框不填底
- 右侧接任务 1.2 的滑块开关（开=accent 填轨道，关=中性轨道）
- 文案保留「显示中 / 已隐藏」，这是既定语义的一部分
- 隐藏的行整体弱化（模型名转 `text-text-muted` 或整行降不透明度），让"被隐藏"成为视觉上的异常项

**其它改动：**

- 「快速操作」区：去掉外层卡片，改用 `UiGroup`（零装饰，标题 + 间距）。三组之间用间距而不是分隔线区分。
- 「全部显示 / 全部隐藏 / 重置默认」从 primary 降为 `variant="muted"`——它们是批量工具不是主动作；这一页本来就没有主动作。
- 筛选 chips 接任务 3.1 词汇表的「多选选中」形态，明确语义。
- 去掉分组头装饰竖线。

**不要做的**：不要改模型显示/隐藏的业务逻辑和数据结构；不要推翻「开=高亮」的语义映射。

## 执行步骤

1. `grep -rn "显示与管理\|全部显示\|全部隐藏\|显示中" src --include=*.tsx` 定位组件文件。
2. 读组件，确认每行的数据来源和切换回调，确保改造不影响业务逻辑。
3. 确认任务 1.2 的开关是否需要一个更紧凑的行内档（模型行比设置页的字段行密集），需要就在 1.2 的组件上补一个尺寸 prop，不要另写一个。
4. 把每行的卡片外壳改为行式布局，右侧接入开关，保留「显示中/已隐藏」文案。
5. 给隐藏态加弱化表达，确认弱化后的文字对比度仍达标（`text-text-muted` 是安全的，降不透明度需要实测）。
6. 「快速操作」区改用 `UiGroup`，去掉外层卡片和内部分隔线。
7. 批量按钮降为 `variant="muted"`。
8. 筛选 chips 接入 3.1 的「多选选中」形态。
9. 去掉分组头装饰竖线。
10. 跑 `npm run check:surface:strict`（这一页是卡片嵌套重灾区，改完应该能清掉几条）+ `npm run electron:build && npm run check:ui-visual`。
11. 截图对比改前改后。
