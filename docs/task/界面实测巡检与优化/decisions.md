## 2026-07-27 第一阶段结束

- `Toggle` 直接复用已经存在的 `UiSwitch`，不新增原语；决定已同步为 `重要记录.md` 记录 010。
- `UiModal` 和独立实现的 `AlertDialog` 通过 `useDialogFocusTrap` 共享同一个弹窗栈，确保嵌套弹窗只响应栈顶的 Esc。
- `UiModal` 打开后焦点落在弹窗语义容器，不抢占第一个输入框；关闭时还原到打开前的元素。
- 状态组件新增 `xs` 紧凑档，页面/区块状态统一收口；原生 `<option>` 占位必须是字符串，画布节点内部专属提示不属于本阶段结构改造，因此保留。
- 资产库首次加载保留网格骨架屏，它承担布局预留而不是普通加载文案，不替换成居中 spinner。
- `ProgressBar` 默认色改用运行时语义类 `bg-accent`，未被调用的 `color` prop 删除；2800ms 作为数据补间档独立于四档交互动效。

## 2026-07-27 第二阶段

- 资产库只在完整工作区模式显示统一页面头；浮动面板模式保持紧凑工具面板形态。
