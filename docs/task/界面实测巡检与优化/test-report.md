### 用户统一手动测试

以下项目待所有阶段完成后统一执行，本阶段无需立即测试。

#### A. 弹窗键盘与焦点

1. 打开设置，按 Esc：设置应关闭，焦点回到标题栏设置按钮；按空格应能重新打开。
2. 在设置内打开一个二级确认框，按 Esc：只关闭二级弹窗，设置保持打开。
3. 在设置内连续按 Tab 与 Shift+Tab：焦点始终留在弹窗内部并首尾循环。
4. 点击弹窗遮罩：仍能按原行为关闭；不允许关闭的迁移/大文件选择弹窗不应被 Esc 或遮罩绕过。
5. 触发一个全局提示框：Esc 应只关闭最上层提示，不影响其后的页面或弹窗。

#### B. 布尔开关

1. 设置 → 界面 → 布局行为：确认“智能折叠”“仅滚动时折叠”显示为滑块，开关状态一眼可辨。
2. 点击开关：滑块应在 150ms 内平滑位移，无抖动、压扁或换行。
3. 用 Tab 聚焦开关并按空格：状态应切换，禁用态不可操作。
4. 打开大文件处理选择框与窄参数面板：开关不应被压扁，标签与控件保持左右排布。

#### C. 空/加载/错误状态

1. 无生成历史时打开生成页：显示图标、标题与引导说明，不再是一行孤立灰字。
2. 有历史时设置无匹配结果的筛选：只显示“无匹配结果”，不要误显示“暂无历史”。
3. 首次打开画布/工具箱/资产库：懒加载占位使用统一加载形态。
4. 检查项目列表、资产库、预设、LLM 模型列表、助手记忆/历史、日志窗口的空态与错误态：排版层级一致，无额外卡片套娃。
5. 资产库首次加载仍应显示网格骨架，不应退化成导致布局跳动的居中 spinner。

#### D. 生成进度条

1. 发起一次真实生成：进度条推进平滑，轨道两端圆角正常。
2. 设置 → 界面 → 主题外观切换强调色：生成页进度条颜色应同步变化。
3. 在画布发起生成并缩放到 50% 与 200%：进度条不变形、不溢出。

### 用户统一手动测试

以下项目待所有阶段完成后统一执行，本阶段无需立即测试。

#### E. 生成工作区跟随助手布局

1. 打开生成工作区并打开右侧助手：历史标题、空态/任务列表、底部输入面板都应以剩余可见工作区为基准；发送按钮与价格预估完整可见。
2. 拖动助手左边缘连续改变宽度：底部输入面板应实时跟随变窄/变宽，不应等松手后才跳。
3. 把助手切到左侧停靠：生成内容和输入面板应改为避让左侧；切到浮动模式后应恢复工作区满宽。
4. 把窗口缩到 960×640，分别重复右侧停靠、左侧停靠和拖动；不应出现遮挡、横向溢出或按钮被裁。
5. 有历史记录时上下滚动：滚动条外观与手感不变，内容上边界保持在标题栏下方，不出现窗口级滚动条。
6. 关闭助手：内容与输入面板回到居中满宽，观感与改动前一致。

#### F. 设置弹窗信息架构

1. 打开设置：标题应横跨整条头部；左侧只有一列导航，当前一级分类展开其二级项，内容区明显宽于改动前。
2. 逐个点击“通用 / 密钥 / 界面 / 模型”及所有二级项：只应有一个二级项显示选中态，内容正确切换且滚动回到顶部。
3. 检查“语言 / 历史记录 / 底部面板 / 资产库”等分区：分区标题应强于内部字段标签，内容区没有卡片套卡片。
4. 底部不再显示“确定/关闭”区域；分别用右上角 ×、Esc、点击遮罩关闭弹窗。
5. 修改一个即时设置（建议界面语言或智能折叠），直接按 Esc 关闭再打开：新值应保持，证明不依赖已删除的底部按钮提交。
6. 把窗口缩到 960×640 再打开设置：弹窗高度约 440px，上下留白合理；导航和内容均可独立滚动，不截断。

#### G. 工作区页面头

1. 快速切换生成 → 画布 → 工具箱 → 资产库：四个完整工作区标题应使用同一字号、字重和左侧基线，不发生位置跳动。
2. 1440×900 下标题内容区域左边缘应约为 144px；960×640 下应为 24px。打开左右停靠助手后，应以剩余可见工作区重新居中。
3. 生成页显示历史数量说明，工具箱显示副说明，资产库显示资产数量；画布项目的导入/新建操作保持在页面头右侧。
4. 资产库浮动面板不应出现完整工作区页面头；只有资产库 Tab 的完整管理界面显示页面头。
5. 主观确认 16px 页面标题在桌面应用中不显得过弱；如果需要调整，应统一修改 `UI_TEXT_TITLE_CLASS`，不要单点放大。
