### 用户统一手动测试

以下项目待所有阶段完成后统一执行，本阶段无需立即测试。

#### A. 弹窗键盘与焦点

1. 打开设置，按 Esc：设置应关闭，焦点回到标题栏设置按钮；按空格应能重新打开。
2. 在设置内打开一个二级确认框，按 Esc：只关闭二级弹窗，设置保持打开。
3. 在设置内连续按 Tab 与 Shift+Tab：焦点始终留在弹窗内部并首尾循环。
4. 点击弹窗遮罩：仍能按原行为关闭；不允许关闭的迁移/大文件选择弹窗不应被 Esc 或遮罩绕过。
5. 触发一个全局提示框：Esc 应只关闭最上层提示，不影响其后的页面或弹窗。

#### B. 布尔开关

1. 设置 → 界面 → 布局行为：确认“智能折叠”“仅滚动时折叠”显示为滑块，开关状态一眼可辨。
2. 点击开关：滑块应在 150ms 内平滑位移，无抖动、压扁或换行。
3. 用 Tab 聚焦开关并按空格：状态应切换，禁用态不可操作。
4. 打开大文件处理选择框与窄参数面板：开关不应被压扁，标签与控件保持左右排布。

#### C. 空/加载/错误状态

1. 无生成历史时打开生成页：显示图标、标题与引导说明，不再是一行孤立灰字。
2. 有历史时设置无匹配结果的筛选：只显示“无匹配结果”，不要误显示“暂无历史”。
3. 首次打开画布/工具箱/资产库：懒加载占位使用统一加载形态。
4. 检查项目列表、资产库、预设、LLM 模型列表、助手记忆/历史、日志窗口的空态与错误态：排版层级一致，无额外卡片套娃。
5. 资产库首次加载仍应显示网格骨架，不应退化成导致布局跳动的居中 spinner。

#### D. 生成进度条

1. 发起一次真实生成：进度条推进平滑，轨道两端圆角正常。
2. 设置 → 界面 → 主题外观切换强调色：生成页进度条颜色应同步变化。
3. 在画布发起生成并缩放到 50% 与 200%：进度条不变形、不溢出。

#### K. 真实生成期间拖动卡顿复现

1. 用 PowerShell 启动带只读测量端口的真实开发实例：
   ```powershell
   $env:HENJI_ELECTRON_REMOTE_DEBUGGING_PORT=9222
   npm run electron:dev
   ```
2. 在生成工作区自行同时发起 3–5 个成本较低的任务，等待多个进度条同时推进；不要清空或删除现有历史。
3. 打开智能助手并拖动停靠面板边缘连续改变宽度，分别在 1 个任务、3–5 个并发任务以及历史列表滚到中部时观察。
4. 记录卡顿属于哪一类：
   - 拖动面板跟不上鼠标；
   - 进度条一跳一跳，但面板跟手；
   - 整个界面偶发僵住；
   - 未复现。
5. 记录当时的分辨率、系统缩放比例、历史条数、并发任务数，以及是否包含图片/视频结果。
6. 若能够稳定复现，再由后续只读 CDP 测量记录帧间隔、longtask 和 tracing；在得到数据前不要实施虚拟化或其它猜测性优化。

#### L. 图片比例、滚动稳定性与视觉零变化

1. 准备至少一张横图、一张竖图和一张方图的成功历史，确认三者仍按原来的自然高度显示：不裁切、不拉伸、不增加 `object-contain` 留白。
2. 有几十条历史时快速滚到底，再快速滚回顶部：
   - 图片进入视口时不应先显示 0 高度再突然撑开；
   - 不应出现“往上滚时突然往下跳一下又回来”；
   - 滚动条长度不应因图片解码剧烈变化。
3. 滚到列表中部，切到画布再切回生成：滚动位置应保持。
4. 发起横图、竖图、方图各一个新任务：排队/准备/生成状态在能够预知比例时应提前使用目标高度，完成后不应再因图片解码发生第二次跳动。
5. 对一条升级前创建、没有尺寸元数据的旧历史执行一次“滚入视口 → 等图片加载 → 切换 Tab → 返回”：首次允许按旧行为降级，学习完成后的后续显示不应再从 0 高度撑开。
6. 用顶部筛选栏切换图片/视频/音频：列表切换应干脆，不闪；本阶段没有引入虚拟化，现有滚动位置与筛选行为不应退化。
7. 切换中英文界面，检查任务卡右上角“使用提示词 / 收藏 / 下载 / 重新生成 / 重新编辑 / 删除”的悬浮提示，确认拆分后仍正确跟随语言。
