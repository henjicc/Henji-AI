# 桌面端架构收口任务总览

## 任务目标

本任务用于把 Henji-AI 中仍偏“网页前端实现”的部分继续收口到桌面端架构：渲染层负责界面、交互和轻量预览，Electron 主进程负责模型运行、文件系统、媒体处理、网络上传、数据库与安全边界。当前主生成链路已经基本走 `GenerationService -> commands -> platform -> electron/main/services`，但仍存在图像命令静默前端回退、大媒体转 data URL、渲染层持有 SQL、通用文件和网络能力暴露过宽等问题。

最终结果是形成一组可逐步执行的治理任务：先确认边界和风险，再处理高成本媒体链路，最后治理数据和通用能力边界。本次任务包含计划、后续执行任务拆分和验收口径；不包含立即修改业务代码、不包含完整重写 Electron 主进程、不包含发布签名、公证或真实线上发布。

## 重要说明

- 后续执行代码任务时，必须优先遵守项目现有 Electron 基线：渲染层经 `src/platform`、`src/commands` 和领域服务访问桌面能力，不直接新增 Electron 或 Node 依赖。
- 涉及鼠标、拖拽、画布交互的验证，只记录操作步骤和验证点，交给用户手动测试。
- 自动生成产物 `resources/model-manifest.json`、`resources/progress-seeds.json` 不是手写主源，不作为本计划的手动修改对象。
- 每个任务完成后都要更新本总览和对应任务文件；若执行代码改动，按项目约定创建独立提交。
