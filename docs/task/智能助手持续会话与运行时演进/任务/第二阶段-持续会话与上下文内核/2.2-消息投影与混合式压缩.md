# 2.2 消息投影与混合式压缩

## 任务状态

- 前置任务：1.3、2.1

- 是否可以并行：是，可与 2.3 做方案和测试并行；共同契约需先以 2.1 为准

## 任务目标

建立“会话事实 → Agent 上下文 → Provider 消息”的独立投影链，并把当前以裁剪为主的压缩升级为确定性工作摘要与 LLM 语义摘要并存的混合方案。完成后，中文长会话即使多次压缩仍能保留目标、约束、决定、工具证据和未完成事项；摘要失败或 context overflow 时有可验证回退，不伪造已执行动作。

## 当前情况

- `AgentRunner` 当前直接维护 `ModelStepMessage[] conversation`，产品消息、工具恢复提示和发送给模型的消息没有正式类型边界。
- `electron/main/services/agent-runtime/context/compaction.ts` 过滤 system 后保留最近消息，并用 `AgentWorkingSummary` 替代较早历史；已经有工具调用/结果配对边界保护，可继续复用。
- `estimateModelMessagesTokens()` 采用字符数除以 4，对中文、JSON 工具结果和不同 Provider 的 token 误差较大。
- `runner/models.ts` 已选择 `summarizer` 角色，但仓库内没有实际调用 summarizer 的运行链路。
- `AgentWorkingSummary` 已保存计划、证据、scope revision、Artifact 引用、待审批和恢复状态，是可信操作事实，不能被 LLM 摘要替代。
- `context/prompt-layers.ts` 已标记系统层、用户指令、记忆、宿主上下文和不可信数据，可继续作为投影信任边界。
- `1.3` 完成后，Artifact 可以按需回读，不再需要为了“以后可能用到”把所有大结果塞入上下文。

## 实施方案

定义三层类型和单向转换：

```text
AgentSessionEntry[]
  → SessionProjector（筛选、信任标记、压缩条目）
  → AgentContextMessage[]
  → ProviderMessageAdapter（协议兼容与最终校验）
  → ModelStepMessage[]
```

只有登记了 projector 的会话条目进入模型上下文；UI 通知、运行状态和诊断记录默认不投影。确定性 `AgentWorkingSummary` 保存工具与副作用事实；summarizer 生成用户意图、已确认决定、长期约束、开放问题和上下文说明，并作为版本化 compaction entry 追加到会话。

压缩保留最近完整消息、尚未解决的用户消息、完整 tool-call/tool-result 配对、活动 Artifact 引用和当前保存点。优先使用 Provider 实际 usage 评估上一轮上下文；调用前的兜底估算需对中文和工具 JSON 保守，具体算法在 4.1 的 Provider 能力可用前通过样本基准确定。context overflow 只允许“生成/复用摘要后重试一次”，且不能重放未知副作用。

## 执行步骤

1. 定义三层消息的共享 schema、允许的 entry kind、信任标签和 projector 注册方式；先用类型测试阻止 UI 状态直接进入 Provider 消息。
2. 为中文长会话、工具配对、恶意工具文本、图片/资源引用、多次压缩、summarizer 错误和 context overflow 编写脚本化用例。
3. 把现有 `conversation` 初始化和构建改为从 SessionProjector 获得上下文；保留运行中尚未持久化的当前 turn overlay，并在保存点归并。
4. 实现语义摘要输入：只提供必要历史与确定性工作摘要，工具输出保持不可信来源；对输出执行 schema、长度和禁止声称执行事实的校验。
5. 将有效语义摘要作为会话 compaction entry 持久化，记录覆盖的 sequence 范围、摘要模型、usage、版本和回退原因；原始历史不删除。
6. 改进 token 预算：使用实际 usage 校准，缺失时采用经过中文/JSON 样本验证的保守估算；记录估计值、实际值和触发原因。
7. 实现一次性 overflow 恢复：移除本次失败响应的上下文影响，压缩后只重试一次；再次失败转为结构化错误，不循环压缩。
8. 验证 summarizer 超时、无效输出、Provider 不支持 usage、Artifact 丢失和旧会话无 compaction 的确定性回退。
9. 运行上下文、Runner、会话、模型步骤和评测测试，更新任务记录与总览并提交。

## 特殊风险与回退要求

- summarizer 输出始终视为不可信摘要，不得覆盖 revision、审批、工具结果、费用或完成证据。
- 工具调用与结果必须成对进入/移出上下文；孤立结果不得发给 Provider。
- 语义压缩失败时回退确定性工作摘要和最近完整消息，不阻塞用户任务。
- overflow 重试前必须确认没有未知写副作用需要先查询验证。

## 验收标准

- [x] 会话事实、AgentContextMessage 和 ModelStepMessage 三层有显式类型与单向转换，未登记 entry 不进入模型请求。

- [x] tool-call/tool-result 始终成对保留，Artifact 仅以受控引用或按需片段进入上下文。
- [x] summarizer 已真实执行并记录 step kind/usage；超时、无效输出或不可用时稳定回退。
- [x] 语义摘要不能把未执行工具描述为已完成，恶意工具文本不能提升为系统指令。
- [x] context overflow 最多压缩重试一次，不发生无限重试或未知副作用重放。
