## 任务目标

让已有资产、生成结果、画布/图片编辑/口播/三维结果与剪辑互通，并支持代码素材以可编辑形式复用。

## 实施方案

基础媒体继续复用资产库、媒体 URL、拖拽和生成任务服务，项目素材记录稳定来源及版本。代码素材的可编辑定义与预览媒体是关联的不同对象，不能假装 PNG/MP4 已保存源码。为代码资产选择最小正式格式并审查直接消费者；不另建模板素材库，也不扩成所有工作区实时嵌套。

## 执行步骤

1. 确定源文件、资产引用、项目项、生成任务结果和代码版本的稳定关系；规定重新定位、删除资产记录和复制工程后的解析行为。
2. 打通资产库→剪辑和剪辑导出/选帧→资产库→画布，复用原收录与拖拽服务；来源标识不能在导入时丢失。
3. 实现生成页或生成画布的已落盘结果添加/替换目标片段；任务预先固定工程、序列、片段和版本，切页或晚到结果不改其他内容。
4. 建立节目帧→图片编辑→结果回填、口播剪辑结果→序列、三维正式渲染→序列的最小联动；只复用现有业务，不复制生成器或音频剪辑实现。
5. 实现代码素材存入现有资产体系再引用到另一工程；保留源码、参数声明、默认值和依赖引用，预览媒体失效可重建。格式及打包路径由 2.1 契约和本任务消费者核对确定。
6. 覆盖资产移动/重新定位、源项目关闭、权限失败、任务取消和重复提交，确认原文件不会因移除引用被误删。

## 验收标准

- [ ] 资产库素材原路径进入序列，导出或选帧能回到同一资产库并加入画布，没有第二套媒体管理。
- [ ] 一个代码素材存入资产库后可在另一个工程重新调参，不能只有预览视频可用。
- [ ] 图片编辑、口播和三维各有一条正式结果进入剪辑的可验证链；模型请求用受控结果验证，不默认付费。
- [ ] 切页、晚到、取消、重复提交和资产重新定位均保持原目标及来源，相关跨域测试通过。
- [ ] 性能要求：引用流转不复制原素材、不重复探测或解码；按内容版本共享可重建预览。代码资产缩略图与资源加载按需限额，不后台渲染整个资产库。
- [ ] 填写实际文件、验证和提交，更新本任务、任务总览及受影响的后续任务；方案/重要决定变化时同步对应文件。
