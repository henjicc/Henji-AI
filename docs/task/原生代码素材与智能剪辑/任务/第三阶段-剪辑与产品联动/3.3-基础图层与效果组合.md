## 任务目标

提供纯色、可理解形状、文字、调整图层和一个基础转场，并与代码片段共用效果控件及动画规则。

## 当前情况

当前只有简单 text 片段和 brightness 属性；没有形状对象树、调整图层或转场。图片编辑已有 GPU 合成和效果实现，但属于独立文档领域，不能把它的 Store 直接接进剪辑。

基线为 2026-09-30 / adc08124。开始前重新核对实际代码；本文件记录的是计划，不代表功能已经存在。规则与全局入口见实施方案，路径相对仓库根。

## 实施方案

纯色/形状是正式生成素材或结构化图形定义，保留对象名、几何和样式供 AI 阅读；任意源码生成内容不承诺反向还原成形状树。附加滤镜消费片段画面，调整图层消费明确定义的下方合成，基础转场消费两侧片段。

## 执行步骤

1. 实现纯色和矩形/椭圆/文字的可编辑结构、样式和变换，添加项目面板创建入口。
2. 将基础形状和关键帧接入 2.3 控件，保留稳定对象引用、坐标和参数单位。
3. 实现效果链的排序、开关、重置和复制，接入一个可调代码处理模块。
4. 实现调整图层的作用轨道/时间范围与一个交叉溶解转场，明确透明度和短片段不足的边界。
5. 验证基础图层和代码生成片段叠加、保存、回读和导出；所有可编辑属性同批开放到正式应用能力。

- [ ] 创建纯色、形状、文字和调整图层后实际出画，UI 与 Agent 可操作稳定属性。
