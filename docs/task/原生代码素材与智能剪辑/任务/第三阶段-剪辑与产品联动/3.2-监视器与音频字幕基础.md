## 任务目标

建立源/节目监视器分工、音频波形与基础字幕，让截图中的时间码、标记和声音信息能真正用于编辑。

## 当前情况

VideoEditPreview.tsx 是单一节目预览，源素材无独立入出点。渲染器已有按时间戳混音，RenderSession 固定 48 kHz。口播剪辑已有 waveformViewport.ts 与 core/audioEdit/subtitles.ts，可以提取可复用算法而非复制口播业务。

基线为 2026-09-30 / adc08124。开始前重新核对实际代码；本文件记录的是计划，不代表功能已经存在。规则与全局入口见实施方案，路径相对仓库根。

## 实施方案

源与节目各自持有会话播放位置，正式工程时钟仍统一。波形由现有音频处理入口按需生成；先支持字幕导入/编辑/显示和序列标记，付费转写继续走现有口播或生成服务。

## 执行步骤

1. 实现源监视器载入、源入出点、只拖视频/音频和链接拖入；节目监视器增加精确时间码、适合窗口/100%显示和画面操纵。
2. 将音频采样率和通道设置贯穿混音与导出，接入静音/独奏/增益和电平显示。
3. 复用已有波形算法/服务，按时间范围与缩放层级显示真实波形，避免解码整库。
4. 实现序列/片段标记及字幕导入、基本文字/时间调整和输出；画面标注与导出字幕保持不同语义。
5. 验证原素材、源入出点、序列位置和标注坐标映射，接入现有应用反射。

## 验收标准

- [ ] 源入出点插入到序列后画面和声音时间正确；源预览不抢改节目播放头。
- [ ] 波形、电平、静音/独奏、字幕和标记与真实音画对应，不使用静态占位图。
- [ ] 混合采样率和片段边界导出无累积音画漂移；字幕/标注的保存与导出语义明确。
- [ ] 相关领域测试通过；Electron 实测音视频播放、监视器切换和合成呈现。
- [ ] 性能要求：后台源预览自动让出解码预算，不因打开两个监视器就各自无上限缓存；波形计算可取消，隐藏面板停止无用刷新。
