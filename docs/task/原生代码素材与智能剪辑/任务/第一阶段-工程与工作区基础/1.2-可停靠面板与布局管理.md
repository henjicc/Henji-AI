## 任务目标

把固定三栏页面变成可调整尺寸、移动、分组、窗口内浮动、关闭恢复并记忆布局的工作区。

## 当前情况

VideoEditApp.tsx 使用固定左右栏，VideoEditTimeline.tsx 独占下方。cameraStage/layout/ 已以 Dockview 管理四类面板、保存与重置布局；DockChrome 菜单当前只有重置。依赖安装版本为 dockview-react 7.0.2，package.json 为 ^7.0.2。

基线为 2026-09-30 / adc08124。开始前重新核对实际代码；本文件记录的是计划，不代表功能已经存在。规则与全局入口见实施方案，路径相对仓库根。

## 实施方案

复用既有 Dockview 和 Ui*，不引入第二套停靠库。首批注册已有业务内容的项目素材、节目画面、时间线、效果控件；源监视器在1.3具备真实基础业务后装配，3.2扩展专业监视器功能（依赖补正见重要记录011）；助手继续复用外层现有宿主，不创建空面板或第二份助手。面板只持有视图状态。窗口内浮动与真正系统子窗口分开，后者由4.1完成。

## 执行步骤

1. 核对三维 Dockview 的容器、主题和布局保存代码，确定最小复用边界；不得为了剪辑布局重构整个三维工作区。
2. 拆出剪辑面板内容并挂接现有领域实例，配置边缘拆分、中心标签组、标签排序、分隔线尺寸和落点提示。
3. 实现面板菜单的关闭、重开、组内操作、窗口内浮动、放大还原和重置；按当前 Dockview 实际支持情况定义可用状态。
4. 持久化用户布局并恢复可见范围；隐藏、移动与恢复节目面板时保持或受控迁移渲染会话，不重复运行后台预览。
5. 核对 Surface/导航覆盖；若确需新增通用 UI 原语，先按项目规则提供具体复用方案并确认，优先扩展已有组件。
