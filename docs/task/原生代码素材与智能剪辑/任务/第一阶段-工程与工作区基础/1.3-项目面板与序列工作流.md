## 任务目标

实现素材箱、原路径导入、新建序列和多序列标签，形成符合截图习惯的基础项目操作。

## 当前情况

VideoEditApp.tsx 已能列出素材、选择本地文件、查询资产库和拖入时间线；videoEditMedia.ts 以原路径检测媒体，videoEditDrop.ts 已固定异步导入前的工程和落点。当前没有素材箱、源监视器双击语义或序列设置。

基线为 2026-09-30 / adc08124。开始前重新核对实际代码；本文件记录的是计划，不代表功能已经存在。规则与全局入口见实施方案，路径相对仓库根。

## 实施方案

项目面板是工程内组织视图，资产库是全应用资产服务，两者不互相替代。菜单使用“新建项目项→序列”等清晰名称；创建大工程仍先选择磁盘位置。资产拖入同时保留稳定来源引用和可解析路径。

## 执行步骤

1. 实现素材箱树、列表/缩略图视图、搜索、排序、多选、重命名、标签和基础媒体信息。
2. 实现双击空白导入、右键导入/素材箱/序列，双击素材打开真实基础源监视器（原路径显示/播放、指定时刻定位与关闭释放）、双击序列打开时间线；3.2扩展专业入出点、时间码与音画信息，不能以占位源面板完成本任务。
3. 实现少量 1080p/4K 横屏与竖屏预设、自定义基础设置、按素材建序列和空时间线拖入建序列。
4. 接通多序列标签与独立会话位置；删除项目项不删除源文件，已被引用对象提供清晰处理规则。
5. 通过现有资产选择和拖拽协议引用资产，保留 assetId 等来源信息，避免只提取 filePath 后丢失联动身份；缺失文件走原重新定位服务。
