## 任务目标

所选代码片段的自定义参数原生显示在效果控件面板；用户和 AI 可改参数、基础关键帧和源码版本。

## 当前情况

VideoEditApp.tsx 的属性面板手写 clipNumbers，只支持变换、音量、文字和亮度。AEPR 按 params 生成宿主参数，但其 16 槽和物理索引受 Adobe 插件限制，Henji 不需要继承这些限制。

基线为 2026-09-30 / adc08124。开始前重新核对实际代码；本文件记录的是计划，不代表功能已经存在。规则与全局入口见实施方案，路径相对仓库根。

## 实施方案

效果控件分为通用片段属性、代码素材参数和附加效果；全部消费正式字段声明。首批参数为数值、颜色、布尔、枚举、文字和明确资源引用，未验证类型不发布。源码更新采用候选版本验证后提交，单实例应用与明确批量应用分开。

## 执行步骤

1. 按 2.1 单源 schema 生成 Ui* 控件、参数默认值/重置、分组、范围和说明，禁止为每个效果编写专属 UI 分支。
2. 实现基本关键帧的添加、删除、移动及线性/保持/基础缓动；统一求值，拆分片段后验证关键帧与源时间正确。
3. 提供源码查看/编辑、编译诊断、候选预览与提交；失败保留有效版本，源码文件不被任意文件监听悄悄替换。
4. 明确源码变更后的参数键删除/改类型处理，显示受影响值和曲线；不能静默清除用户动画。
5. 在 UI、通用反射、MCP 查询和历史中验证同一参数；一段拖动一次撤销，切选区不把旧参数提交给新对象。

## 验收标准

- [ ] 两个参数定义不同的代码素材显示不同控件；改参数、重置和关键帧均真实改变画面。
- [ ] AI 与手动修改同一实例，撤销、保存重开后参数和源码一致。
- [ ] 编译错误能定位并恢复，源码键变化不静默丢曲线；换选区/序列后异步提交仍绑定原对象。
- [ ] L2 参数/历史/求值精确测试和真实 Electron 参数到画面验证通过。
- [ ] 性能要求：输入反馈到正确画面的时延单独测量；标量参数变化不重编译、不使无关原视频解码缓存失效。
- [ ] 填写实际文件、验证和提交，更新本任务、任务总览及受影响的后续任务；方案/重要决定变化时同步对应文件。
