## 任务目标

所选代码片段的自定义参数原生显示在效果控件面板；用户和 AI 可改参数、基础关键帧和源码版本。

## 当前情况

1.2已把属性面板迁到VideoEditEffectsPanel.tsx，现有clipNumbers只支持变换、音量、文字和亮度；2.2正式源码创建、固定实例参数、MCP参数写入及混剪/保存/导出已接通，但没有参数控件、曲线、版本编辑或资源参数。AEPR 按 params 生成宿主参数，其16槽和物理索引不适用于Henji。

当前实施基线为2.2本地提交76b75abc；原计划基线2026-09-30 / adc08124仅供历史核对。规则与全局入口见实施方案，路径相对仓库根。

## 实施方案

效果控件分为通用片段属性、代码素材参数和附加效果；全部消费正式字段声明。首批参数为数值、颜色、布尔、枚举、文字和明确资源引用，未验证类型不发布。源码更新采用候选版本验证后提交，单实例应用与明确批量应用分开。

## 执行步骤

1. 按 2.1 单源 schema 生成 Ui* 控件、参数默认值/重置、分组、范围和说明，禁止为每个效果编写专属 UI 分支。
2. 实现基本关键帧的添加、删除、移动及线性/保持/基础缓动；统一求值，拆分片段后验证关键帧与源时间正确。
3. 提供源码查看/编辑、编译诊断、候选预览与提交；失败保留有效版本，源码文件不被任意文件监听悄悄替换。
4. 明确源码变更后的参数键删除/改类型处理，显示受影响值和曲线；不能静默清除用户动画。
5. 在 UI、通用反射、MCP 查询和历史中验证同一参数；一段拖动一次撤销，切选区不把旧参数提交给新对象。
