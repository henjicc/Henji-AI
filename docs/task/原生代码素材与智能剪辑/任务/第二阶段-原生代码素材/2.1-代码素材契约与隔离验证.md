## 任务目标

通过有限实验锁定原生代码素材的作者接口、参数声明、持久化版本和安全执行路线，输出可直接实现的契约。

## 当前情况

剪辑只有 video/audio/image/text，没有源码素材。AEPR 的 effects.ts 区分 generator/filter，参数只有 range/color；frame-renderer.ts 支持指定时间绘制和资源复用。AEPR pr-codefx.md 明确可信代码/CUDA 不具浏览器级隔离，不能直接照搬。Henji 应用能力规则禁止任意宿主脚本执行入口。

## 实施方案

代码素材是具有静态/动态输出、透明度、尺寸和时间语义的项目项；片段引用不可变源码版本，实例参数独立。生成素材与输入滤镜分开。首选评估接近 TypeScript 的受限作者 API 加既有 GPU 合成，具体编译器、表达能力和隔离形式均待本任务实测确定；不得把改字段名当作绕过执行限制。

## 执行步骤

1. 只读核对 AEPR effects.ts、frame-renderer.ts、codefx.ts 与 codefx-compiler.ts，记录可借鉴的参数、确定性、复用和快照原则及不可照搬的宿主协议。
2. 定义素材定义、源码版本、片段参数实例、资源引用、静态/动态输出、有限时长、透明度和三个时间坐标；明确裁剪/拆分后局部时间不意外重置。
3. 定义唯一参数 schema：稳定键、类型、默认值、范围、单位、动画资格、用户说明和助手说明；界面、反射和求值器共同消费。
4. 只做有界试验：静态透明图形、动态标题和单输入可调滤镜；验证指定帧、随机顺序求值、参数变化和 4K 输出。
5. 验证执行隔离、禁止宿主/网络访问、超时或失效恢复、GPU 资源限制；Worker 只代表线程隔离。若必须改变现有权限或安全规则，记录具体方案并取得所需确认再推进。
6. 把最终语言、运行后端、源码保存方式、参数演进规则和验证证据写回实施方案与重要记录；实验路线只保留一条正式实现。
