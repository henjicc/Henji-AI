# 原生代码素材与智能剪辑

## 任务目标

在 Henji-AI 独立剪辑工作区中，建立接近专业剪辑习惯的灵活面板、多序列、基础时间线及效果控件，并把 AI 编写的代码作为原生可编辑素材：可像图片或视频一样放入项目、裁剪、叠加、调参和导出。手动、内置 Pi 与外部 MCP 使用同一工程、领域服务、撤销和保存。

本计划包含原生代码素材、基础代码处理效果、资产库与其他创作工作区联动、运行时技能和本机 4K60 全分辨率性能。首期不完整复制 Premiere，不包含专业调色、多机位、通用任意宿主代码执行、插件市场、完整三维和全部高级修剪工具。具体边界见[实施方案](01-实施方案.md)。
