# 剪辑以外的 AI 能力缺口清单

2026-10-31 盘点。范围：画布、图片编辑、音频编辑/录音/音效库、镜头参考、屏幕录制、网页录制、生成、素材库、工具箱、设置、项目页、本地模型、日志。剪辑不在此列，剪辑缺口见 [助手覆盖复核](../剪辑对齐PR操作习惯/任务/第四阶段-实测反馈与细节/助手覆盖复核.md)。

判据有两条：**人能做的 AI 能不能走同一条路做到**；**AI 用起来顺不顺手**。顺手的意思是：后台能做，不用先切界面；参数是意图语义；做完能读回检查；能撤销；能一步做完。

证据来源：画布两条（界面打开依赖、蒙版）于 2026-10-31 通过外部 MCP 实测确认，其余来自代码阅读，未实跑，补之前先按 file:line 复核。行号以盘点当天为准。

起因：外部 MCP 想用画布局部重绘、配合 KIE GPT Image 2.5，把照片左下角的日期改掉，结果走不通。① `apply_canvas_image_capability` 要求画布正在界面上打开，否则报 STALE_CONTEXT；② 局部重绘必须先有蒙版，但蒙版既不能写，也不能自动生成。最理想是一步完成：OCR 选中日期 → 选区内生成式重绘 → 读回核对。现在需要五步，其中两步没有能力可调。

## 一、共性问题（先修这些，收益最大）

| # | 问题 | 涉及位置 | 建议 |
|---|---|---|---|
| A | **依赖界面打开**：后台文档做不了，必须先切页，会打断用户，也会打断其他会话 | 画布图片能力；图片文档新建；图片剪贴板、颜色分析、颜色观察；三维指定帧截图 | 统一改为走文档实例，不读全局当前 store。画布 `canvasExecutionService.ts:159`、图片 `withImageEditDocumentInstanceV3` 都已经这样做 |
| B | **做完读不回**：只拿得到结构化回执，看不到、听不到结果 | 图片文档或图层的合成画面；音频编辑处理后的声音；三维指定时刻和机位的画面 | 每个工作区补一个离屏观察能力，结果接入 `read_application_media`，对齐剪辑的 `observe_video_edit_frame` |
| C | **参数不是意图语义** | 音频用源采样帧；三维用世界坐标，“左边”没有方向；图片文字框用作品像素，而选区用画面比例 | 时间统一用秒并注明时间轴；空间统一用画面比例，或用“相对机位/参照物”的方位 |
| D | **撤销不一致** | 音频没有 undo/redo 能力；三维删除对象不可撤销；画布撤销引用遇到其他改动就失效；画布手画蒙版不进历史 | 各工作区都对齐剪辑：`undo/redo_<域>` 按步数撤销，删除返回 `undoRef` |
| E | **执行时偷读界面上次的设置**：结果取决于界面状态，AI 既看不到也改不了 | 录屏编码参数；网页录制的备份录屏选项；生成面板参数（比例、分辨率、张数） | 提升为可读写属性，或作为能力输入 |
| F | **只能存到预设目录**，与“本机路径可直接作为输入”的规则冲突 | 画布节点下载；音频导出；文档导出只回文件名；下载预设路径、导入 .hjpak、打开外部文件的豁免理由已过时 | 加 `targetPath`，返回绝对路径；删掉过时的排除理由 |
| G | **门禁看不见的缺口**：组件直接调服务、不经 store 动作的按钮，账本覆盖门禁扫描不到 | 设置里的清缓存、检查更新、拉取供应商模型；画布整理对齐；网页录制批量导出 | 门禁增加对组件内服务调用的扫描，防止缺口再生 |

## 三、建议顺序

1. **日期案例这条链**：图片编辑 OCR 选区 → 选区内生成式重绘（编辑器与画布局部重绘共用）→ 图片离屏观察 → 画布图片能力去掉界面打开依赖、蒙版可写。做完就能实测“改日期”，一步完成。
2. **共性 A、B、D**：后台可做、能读回、能撤销，三件事各工作区一次补齐。
3. **生成面板参数、重新生成复现**：日常用得最多。
4. **音频按秒编辑与测量**、**三维效果器与对象过渡**。
5. **共性 E、F、G** 与其余中低优先级。补 G 的门禁扫描，防止缺口再生。

## 四、已经覆盖得好的（不用再查）

- 画布：节点/连线增删、分组、批量计划→预览→提交、生成准备→提交→等待（后台可跑），结果可读回。
