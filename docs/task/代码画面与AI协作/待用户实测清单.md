# 待用户实测清单（2026-10-09 八小时自主改进）

[返回总览](00-任务总览.md) · 剪辑第四阶段的既有实测项见 [剪辑用户实测清单](../剪辑对齐PR操作习惯/任务/第四阶段-实测反馈与细节/用户实测清单.md)，本清单不重复。

只列需要真人在真实窗口里看、听、拖、判断的点；机器能验的都已在提交里验过。每条写“怎么做 → 期望”。

## 一、拖参数手感（t96）

1. 剪辑里选一个片段，打开“全能调色”，连续来回拖曝光、色温、曲线点、色轮中心，各拖 3–5 秒。→ 画面跟手、不拖尾不卡顿；松手后撤销一次只回到拖动前。
2. 同样拖辉光 Pro、任意 `shaders` 效果参数、代码素材的参数（颜色、数字、点位）。→ 同样跟手。
3. 在播放中拖参数。→ 播放不停、画面随值变化；暂停后画面就是最终值。
4. 4K 素材或多轨叠加时再拖一次，主观评价是否还能接受。

## 二、全能调色（t87）与 HSL 辅助

1. 效果库里搜“全能调色”，不再出现 Lumetri 字样。
2. 三路色轮、曲线（RGB/单通道/色相曲线）拖动与复位；窄面板时色轮自动换行。
3. HSL 辅助：选一段肤色/天空，开“显示蒙版”看选区是否正确，调羽化与反向，关掉蒙版后看校正效果；色相区间跨红色（340°→20°）也能选。

## 三、代码画面（t84–t90）

1. 代码素材参数面板：新控件（角度盘、点位板、区间、渐变、曲线、色轮、缓动、种子、字体）好不好用；分组与“更多”折叠、条件显示是否正常。
2. 源码编辑器：多文件切换、新建/重命名文件；“项目组件”分区查看、插入导入语句、发布为项目组件。
3. 打开项目文件夹的 `代码/` 目录，能直接用编辑器看到源码文件。
4. 让助手做一个标题，然后说“把标题改成××、颜色换成××”。→ 助手只改参数，不重写源码。

## 四、向后兼容（t94）

1. 打开以前的项目，确认都能正常打开（开发期旧格式例外，例如 10-08 之前带内联代码源码的剪辑，会提示“旧版本格式”，而不是“已损坏”）。
2. 新建并保存一个剪辑、画布、图片文档后重开，内容一致。

## 五、助手与外部智能体导出（t93 发现并修复）

1. 让助手“导出这条序列的 5 秒成片”。→ 不弹保存对话框，文件出现在项目文件夹的 `导出/` 下，重名自动加序号。
2. 界面上手动点导出。→ 仍然弹出保存对话框（界面行为不变）。

## 六、技能（skill）效果

1. 同一个需求（例如“做一个产品发布标题”）让助手做两三次或要求不同方向。→ 风格不趋同，没有被固定成一种样子。
2. 让助手做一次普通剪辑任务（粗剪、加字幕、配乐压低人声处、导出竖版）。→ 走“剪辑工作台”技能，步骤合理。

## 七、剪辑新增与修复（t98、t99、t100）

1. 转场：选中一个转场，在效果控件里给它的参数（如擦除角度、羽化）打两个关键帧，播放看转场过程中参数变化。→ 动画生效，撤销一次回退一步。
2. 关键帧贝塞尔：在时间线钢笔模式拖关键帧的切线手柄，或右键关键帧打开缓动编辑器。→ 动画快慢跟随曲线；拖到“过冲”时数值不越界。
3. 让助手“给这个片段加一个标题模板”。→ 助手报告成功（以前会误报失败）。
4. 让助手“把第 7 秒的画面送到画布”。→ 画布上的节点有图片，关闭画布再打开仍在。
5. 让助手在只有图文、没有视频的序列上“改成竖版”。→ 助手说明原因，之后还能继续让它改别的（以前会把剪辑锁住）。
6. 无声音的序列直接导出。→ 正常导出，并说明跳过了响度标准化。
7. 智能区域失败后让助手重试；原地生成失败后让助手恢复或移除占位。→ 走和界面相同的路径，不重复付费。

## 八、图片编辑（ie1、ie2、ie3，ie4 见下）

1. 图片编辑器“添加图层”菜单里有“全能调色”和“图层组”；新建全能调色层，拖色轮、曲线、HSL。→ 跟手，效果和剪辑里的全能调色一致。
2. 选区工具：框选、椭圆、套索、多边形、画笔；按住加/减/交组合；羽化、反选、取消。→ 蚂蚁线/遮罩显示清楚，拖动跟手。
3. 有选区时新建全能调色层。→ 调整只作用在选区内；“复制选区到新图层”“删除选区内容”可用并能撤销。
4. 设置 → 本地模型：图片修补模型（MI-GAN/LaMa）可按需下载、取消。
5. 移除工具：用画笔或选区圈住画面里的小物体（路人、电线、污点），松手后自动移除。→ 一步撤销；进度可取消。**已知画质不足**：大面积、规则纹理（砖墙）快速档会出错纹理，精细档有残色，请重点看你常用的场景能否接受。
6. 修补工具：选中瑕疵后拖到干净区域取样。→ 纹理搬过来、边缘自然。
7. 主体选择：点一下或框一下主体、或点“选择主体”。→ 选区贴合主体；多个主体时给候选；人像边缘细节可接受。
8. 让助手“把背景里的路人去掉”或“把人像主体选出来调亮”。→ 助手直接用主体/人像区域完成，可撤销。

## 九、已知未完成与注意

- 拖参数的“屏幕上真实延迟”没有自动化测量，只测了渲染与服务层（P95 均在毫秒级）；请以手感为准。
- 图片移除：大面积规则纹理仍可能有砖缝偏移/残色；1080p 最终瓦片画质与多尺度处理未完成。
- 自动化测试启动器用“真实资料”启动时解不开开发实例保存的密钥（只影响测试环境），所以这一轮没有跑真实付费生成。
- 开发期“旧格式不兼容”仍有效：10-08 之前带内联代码源码的剪辑会提示旧格式（科技标题那份已手工转换）。

## 十、架构体检后的改动（2026-10-09 下午，详见 [体检报告](../架构体检/体检报告.md)）

1. 启动：冷启动打开应用，首页出现速度与以前相比是否更快；首次打开图片编辑器、画布局部重绘时能正常加载（这些模块改为用到才加载）。
2. 列表：项目页、文档页、素材库在项目/素材很多时滚动流畅，选择、右键、拖拽排序正常；素材加 40 个以上标签后全部保留。
3. 图片编辑图层面板：图层很多时滚动、拖动排序（拖到列表边缘会自动滚动）、多选正常。
4. 画布复制 3D 镜头参考节点（Ctrl+C/V 或 Alt 拖动）：副本打开后是一份独立的 3D 场景，改副本不影响原节点；撤销一次副本消失。
5. 高斯模糊（剪辑与图片统一为线性光计算）：同样参数下模糊边缘比以前更柔和自然，和以前外观略有差异属预期；剪辑预览与导出成片模糊程度一致。
6. 图片编辑里拖动高斯模糊参数：4K/8K 大图是否跟手（GPU 阶段实测 4K p95 约 7–11ms，屏幕实际手感以你为准）。
7. 查看器里的快速标记（图片查看时直接标注/裁剪/旋转）：现在与图片编辑器同一内核，标注、裁剪、旋转、保存、复制结果正确；以前的 V2 图片文档会提示旧格式打不开（开发期预期）。
8. 工具箱三项（口播剪辑、图片编辑、3D 镜头参考）卡片、打开、最近文件、返回都和以前一样。
9. 声音克隆面板上传本地音频（含网络共享路径的文件）能正常试听与使用。
