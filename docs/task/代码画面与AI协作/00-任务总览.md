# 代码画面与 AI 协作

## 任务目标

用代码生成的标题、动态图形、滤镜和整个画面，要做到风格统一、质量高，人和 AI 能“指哪打哪”地协作修改。2026-10-08 用户批准，约 9 小时自主执行。

1. 代码创作 skill 参考 AEPR控制测试 的 frameflow 导演手册重写，补齐设计、动效和看片的方法。
2. 代码作者语言扩展到 v3（受限 DSL，保持只解析、不执行的安全边界），表达力向 HyperFrames 靠拢。
3. 标注 v2：画面、代码元素、时间段都能标注；状态流转为“待处理 → AI 已处理（待审查）→ 已通过 / 重开”；内置助手和外部 Agent 用同一套能力。
4. 参考 HyperFrames Studio：画面上直接选中元素，改文字、字体、颜色、大小、位置。
5. 字体系统：读取本机字体并支持导入，字体面板实时预览；文字属性面板参照 PR。
6. 风格包：令牌、规则和样例三部分组成；先建后用、边用边沉淀、从参考提取三种创建方式。
7. 引入 `shaders`（MIT）着色器效果库，作为可信的着色器层、滤镜和转场。

决策见 [重要记录.md](重要记录.md)。
