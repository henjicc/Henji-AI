## 记录 007：直接用 shaders 框架，AI 可自写着色器

- 日期：2026-10-08
- 状态：已确定（用户要求，t83 实施）
- 决定：不再逐个手工移植，直接依赖 `shaders@4.0.2`（MIT，内部 TypeGPU），在适配层里共用剪辑 GPU 设备、渲染进宿主纹理、由剪辑按帧驱动时钟、宿主画面作为 `@input/@second` 图层输入。全部可确定性重现的组件（167 个）作为效果、转场和代码素材图层使用；依赖上一帧、页面或鼠标的组件经 GPU 扫描排除。
- AI 自由度：代码素材可写完整图层树（混合、遮罩、嵌套）和自写 WGSL 着色器（函数体），不限写法；约束只放在运行阶段：编译报错带素材源码行号返回、错误范围隔离、确定性时钟、属性不收网址。
- 原因：拿到全部组件与积木库、上游升级只需换版本、适配层可替换成别的框架；手工移植只有 40 个且要逐项维护。辉光PRO 是自研配方，单独保留。

## 记录 008：参数化、组件化与代码存储

- 日期：2026-10-08
- 状态：已确定（用户授权总管理者自行安排，t84–t90 实施）
- 决定：
  - 开放参数由 AI 决定。参数是用户与 AI 共同的修改接口：改需求优先改参数，不改源码。参数类型扩到专业控件级（角度、点位、区间、渐变、曲线、调色色轮、缓动、种子、字体），支持分组、高级折叠、条件显示；AI 可用素材顶层 `types` 声明自定义组件类型（只能由基础类型字段组成、布局只能从枚举里选），保证界面风格统一。
  - 内置效果与代码参数共用一套控件与渲染，不再各写一套。
  - “Lumetri 颜色”改名“全能调色”，控件升级为专业级（三路色轮带亮度、曲线、HSL 辅助）。
  - 代码存储：一个版本可由多个文件组成（文件间 import），源码按内容哈希去重；源码落到项目文件夹 `代码/` 下，剪辑文件只存引用；项目内设组件库，同一项目的所有剪辑可 import 复用。打包、复制、移动文档时带上代码。
- 原因：复杂效果塞进单文件、单剪辑文件不利于阅读、复用和外部编辑；剪辑文件随版本数膨胀；组件化需要跨素材、跨剪辑的模块。

## 记录 009：标准 JS 成为唯一主作者接口（2026-10-20）

- 状态：用户已确认路线，实施中；替代记录 001，扩展记录 007 的自写 WGSL 范围。
- 标准 ES 模块直接在剪辑渲染 Worker 执行，复用同一 GPUDevice。对齐 Frameflow 的 draw/layers/createWebGL，增加原生 WebGPU、多 pass 与相邻帧输入；不复制 PR 的控件池、参数名限制、透明 PNG 载体或调整图层时间缺失。
- 效果与效率优先，确定性靠作者约定和正确失效的缓存，不靠语法白名单。既有 AST 元素命中和编辑能力需改为作者图层元数据及正式参数，无法等价的部分单独报告，不隐式降级。
- 联想 YOGA 先用三个关键效果做像素及性能验证，通过后再迁全片并退役旧 DSL。上一轮语义重建的未提交文件保留，由用户决定是否丢弃。当前路线确认不代表工程已迁移或性能已经达标。
- 用户补充确认（2026-10-20）：以显式图层和参数替代 DSL 自动逐元素编辑。参数由 AI 作者克制选择、按元素分组，可通过 `layer` 绑定图层；选中图层只显示相关参数，绑定的文字支持双击修改。拖动/缩放/旋转由宿主叠加变换覆盖，进入原撤销栈，AI 可后续写回源码。未声明内容走“指给 AI 改”，携带 id/name、bounds、定义位置与当前帧截图；纯 draw 效果整体视为一个元素。不拦截 Canvas 调用，不在每帧扫描源码。未等价保留的 t67/t70/文字面板功能必须逐项说明。此段是已确认契约，界面及助手闭环仍在实施。
- 运行时契约验证（2026-10-20）：采用 esbuild-wasm 0.28.2 在既有共享编译 Worker 打包 ESM，标准模块链接与 sourcemap 交给成熟实现；TypeScript 仅提取源码导航位置，不限制或执行作者语言。图层覆盖叠加 pose、纯 draw/原生 GPU 整体覆盖、按需返回 bounds/参数键/源码位置已接通候选通道。真实 Electron 两场景验证正式 WASM 资产加载、缓存命中、多文件定义定位、Canvas 图层变换及计算着色器直接写纹理后的 GPU 覆盖，截图目视正确；证据为 `.tmp/direct-author-contract` 与 `.tmp/direct-author-native-contract`。这不是正式时间线交互、热播放性能或全片迁移验收；旧作者链尚未退役。

- 编辑边界补强（2026-10-20，用户确认，无需再次逐项确认）：文字采用绑定图层的 `text`＋`textStyle` 参数，样式复用 t69；默认每段可见文字声明这两项，默认值跟随风格包。动态层 id 包含数据键/索引，驱动数组为可编辑参数或数据表，定位“工厂函数＋数据项”；单项内容改数据，外观改工厂。变换覆盖即时且长期有效，写回可选、后台或确认时批量进行，已声明参数不写回，写回新版本验证及合并前后共用撤销栈。以上为目标契约，正式编辑链与全片验收仍在实施。
