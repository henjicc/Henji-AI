## 记录 007：直接用 shaders 框架，AI 可自写着色器

- 日期：2026-10-08
- 状态：已确定（用户要求，t83 实施）
- 决定：不再逐个手工移植，直接依赖 `shaders@4.0.2`（MIT，内部 TypeGPU），在适配层里共用剪辑 GPU 设备、渲染进宿主纹理、由剪辑按帧驱动时钟、宿主画面作为 `@input/@second` 图层输入。全部可确定性重现的组件（167 个）作为效果、转场和代码素材图层使用；依赖上一帧、页面或鼠标的组件经 GPU 扫描排除。

- 原因：拿到全部组件与积木库、上游升级只需换版本、适配层可替换成别的框架；手工移植只有 40 个且要逐项维护。辉光PRO 是自研配方，单独保留。
