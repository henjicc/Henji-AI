# t86 统一参数面板

状态：实现与精确验证完成，待总管理者审查和 Git 提交。2026-10-08。

## 实现与关键决定

- 新建 panels/params 字段适配、控件渲染、分组列表与代码手势连接层。代码实例、代码关键帧值、内置效果、过渡及 Lumetri 的登记参数行共用 ParamField / ParamList；删除 CodeScalarControl、ParamControl、ColorControl、ScrubNumber 两套旧实现。
- 字段只传呈现元数据，剔除 AI description；名称悬停显示 tooltip，固定标签列、紧凑控件、组名标题。无组字段优先；更多与组折叠均卸载内容；visibleWhen 实时按权威值求值。
- 全部 t84 新类型接入 t85 原件。custom 从内部 type/custom、typeName、types.layout 和 fields 适配，支持 stack/row/grid/wheel；wheel 色轮在上，采用 md，其余字段在下。组件字段写入完整对象；字体调用 UiFontPicker 和既有字体预览事务，预览前一项回滚后读回领域值，避免合并上一次悬停草稿。
- 成对百分比 _x/_y 合成 point，接受任意声明顺序、保留边界及步长，写两个参数只提交一个事务；分量关键帧各保留入口。degrees 数字使用角度盘。像素点位按声明界限映射到相对位置盘，同时提供像素读数。
- 保留 useCodeParameterGesture 和 useVideoEditBuiltinParamGesture 的领域撤销入口；共享 begin/finish/cancel/active/write/atomic。内置手势增加作用域 identity，切换同值目标也卸载旧控件；控件卸载只回滚自身拥有的拖动。Esc、指针取消、隐藏/卸载继续恢复快照。
- 渐变的控件草稿保持原色标顺序，领域写入按 at 排序，避免跨越色标时控件选择索引跳动。没有增加产品数量上限；种子边界沿 t84 的 uint32 契约，其他边界沿原声明。
- Lumetri 面板文件未修改；其曲线采用共享 ParamField 内的 UiToneCurve 分支，保留现有样条显示、hue 首尾联动与百分比编码。代码曲线采用 UiCurveEditor 的线性语义，避免本任务提前改变 t87 的曲线语义。

## 性能与覆盖分级

- ParamList 是权威 props 的局部呈现投影，按字段 key 订阅值、该字段的关键帧及条件结果，字段行 memo；自定义组件成员也 memo，写入通过当前父对象引用合并，避免旧闭包覆盖兄弟字段。折叠内容不挂载、不订阅。
- jsdom 的 120 字段回归：单字段发布只重新调用该字段控件渲染一次，其他 119 项没有重渲染。此证据证明 React 渲染范围，不代表真实 Electron 帧率或 GPU 呈现性能。
- 应用能力分级为仅呈现变化：参数与曲线的领域契约、实体读写已由 t84 接入，本任务不新增业务状态、入口、工具或 MCP schema。所有提交继续调用现有正式服务。

## 开源选型与复用

本任务复用 t85 已选型验证的受控 SVG 原件、NumberInput、UiColorInput、UiSwitch、Dropdown、UiFontPicker、UiTextAreaField，以及既有 CodeImageParameterControl；没有增加依赖或复制控件手势实现。t85 比较的 react-colorful 与 D3 无法替代本项目已有的完整参数/撤销契约；本任务需要的是声明和领域事务之间的薄适配，采用 React.memo / useSyncExternalStore 和已有 UiGroup 足够，不另引入表单框架或第二套调色/曲线库。Lumetri 样条保留原件，线性代码曲线使用新原件。

## 设计自查

1. 助手只凭名称和说明能否用对？能。助手继续使用 t84 的完整参数声明、类型元数据和通用实体写入；UI 字段保留同一键和值形状，标题/tooltip 面向用户，AI description 不进入正式界面。没有新增需要助手猜测的专用动作。
2. 能否 AI 先做、人只确认？能。控件完全受控，AI 可先通过已有实体写入参数和关键帧，人再在统一面板校正；连续校正只记一步撤销，Esc/卸载回到校正前。
3. 产物能否直接流进其他工作区？能。参数及关键帧继续存在同一剪辑文档与代码资产中，沿既有保存、收录及素材流转路径传递；本任务没有另建私有状态或文件格式。未执行真实跨工作区操作或成片导出。
