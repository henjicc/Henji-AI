# t97 风格模板

状态：实现完成，待真实助手对话验收。2026-10-15 用户批准方案并授权按推荐执行（剪辑节奏层做成可选；模型生成默认注入风格、可关）。

## 目标

把 t68 风格包从“配色字体令牌包”升级为分层的个人风格档案，用户可以有多套，AI 每次都能照着做、做完能自查，并能随用户评价持续演进。

## 设计规则（写进助手技能，入库前校验）

1. 每一条都要可执行（映射到真实参数或能力）、可检验（取帧/读回可判断违反）、有强度（必须 / 倾向 / 可破例）。
2. 抽象概念必须翻译：含义、可检验判据、参数倾向、正例、反例、强度与破例条件；判据至少一条。
3. 写清统一与变化：`keep` 规则列全片必须一致的项，`vary` 规则列允许浮动的项与范围。
4. 优先级固定：本次明确要求 > 绑定的风格 > 共享记忆里的跨风格口味 > 技能默认值；本次临时要求不写回风格。

## 数据结构（style kit content）

- `profile`：一句话定位 `summary`、适用场景 `scenarios`、抽象概念 `concepts`（按规则 2 的字段）。
- `tokens`：原有配色/字体/字号/形状/质感/版式；`motion` 扩展为入场/出场/移动/强调/转场五种曲线（缓动名或三次贝塞尔，与代码 easing 参数同一类型）与时长、错峰、位移幅度、落地静止、读字速度、停留下限、节拍对齐。
- `rhythm`（可选，`auto` 表示不约束）：镜头时长区间、切点、主转场、音效密度、背景音乐避让、补充说明。
- `rules`：结构化条目（做 / 不做 / 统一 / 可变 + 强度 + 适用范围）；原 Markdown 规则改为 `notes` 补充说明。
- `samples`：组件角色增加字幕 `caption`。

持久格式：本机风格库 v1→v2、剪辑文档 v7→v8，迁移只把旧 `rules` 文本移到 `notes`，其余由新默认值补齐。

## 消费方

- 代码画面 `ctx.style` 自动带上扩展动效令牌。
- 文字、图形文字、程序监视器文字、标题模板内置类型、字幕默认样式按序列绑定的风格生成；用户显式参数优先。
- 关键帧：风格曲线换算为关键帧贝塞尔，标题模板入出场与助手打关键帧共用。
- 剪辑就地生成：序列绑定风格时把定位与配色摘要并入提示词，可关闭。
- 宿主上下文给结构化摘要，提示先读完整内容。

## 助手

代码创作技能新增风格模板参考（设计规则、建模板与演进流程、自查清单、关键帧曲线用法）；`preferences.md` 改为分流：只属于某套风格的偏好经确认写入该风格 `rules`，跨风格口味写共享记忆。

## 界面

风格面板顶部为同一套样张（所有风格同内容渲染），其下依次为理念、规则、配色、字体、动效（曲线编辑复用 t85 缓动控件）、节奏、质感、形状版式、组件。

## 选型

- 曲线沿用代码 easing 参数类型（缓动名或三次贝塞尔），关键帧换算用 easings.net 公开控制点；弹性、跳动没有单段贝塞尔，关键帧取最接近的回弹曲线。没有另引曲线库：作者语言已有 codeCubicBezier，界面复用 t85 的 UiEasingEditor。
- 悬停样片用正式试绘链路逐帧取 12 帧循环，不另建视频编码；只在悬停时生成，离开即释放。

## 实际改动

- 核心：`styleKit.ts`（分层 schema、迁移、文字/字幕默认、关键帧曲线、读字时长、生成描述）、`styleKitPresets.ts`（精简为三套并按设计规则重写，统一六张样张）、`subtitleStyle.ts`、`titleTemplates.ts`、`graphics.ts`、作者语言 tween 接受贝塞尔（CPU 与 GPU 滤镜）。
- 持久格式：本机风格库 v2、剪辑 v8、录制会话 v10（脚本基线内嵌剪辑快照），逐版本迁移与黄金样本。
- 消费方：字幕默认、文字图形、节目文字、内置标题模板、字幕“跟随风格”预设、就地生成注入（对话框开关、能力 applyStyle）。
- 助手：只读 `keyframe_curves`；宿主摘要；技能 style-kit 参考与 SKILL/preferences/styles/author-api/工作台入口。
- 界面：风格面板加理念、规则、扩展动效、节奏、生成、补充说明；样张六张、悬停播放入场。

## 第二阶段：剪辑预设面板

剪辑停靠面板新增“预设”（与效果同组），统一浏览风格、标题、文字、效果、转场五类预设并管理。

- 预览：所有预设共用一个常驻 `VideoEditRenderSession`（与节目监视器同一合成器），只换文档；格子显示海报帧，悬停按真实时间循环播放，详情弹窗直接实时播放。时间线按内容缓存，只有文字“跟随风格”随序列风格重建。
- 风格样片：8 秒包装样片——开场、人名条、两句字幕、本风格主转场、强调词，画面按风格强调色调色；三套内置风格各有专属开场/人名条/强调组件（`styleKitSignatures.ts`）与字幕处理（新增 `caption.treatment`：描边 / 底板 / 花字，样式面板可改）。组件新增 `hold` 参数，样片里按片段长度先走完自身出场。
- 详情：左侧样片与“包装”要素（字体、字幕、转场、镜头时长、动效、音效），右侧喜爱程度、设为默认、定位、核心概念与创作规范。
- 管理：导入/导出 `.henjipreset` 包（重名自动加序号、换新标识）、删除个人预设、设为默认、0–5 星；排序为默认 → 评分 → 原顺序，未设默认时评分最高者标“推荐”。默认风格自动套到新建序列，默认文字样式用于新字幕，转场默认沿用原设置项。
- 助手：通用实体 `video_edit.preset`（评分与默认可写、可撤销，不绑定某个剪辑文档）；`apply_video_edit_title_template` 省略模板时用默认/推荐模板。
- 选型：预览不预渲染成视频文件——正式合成器足够实时，预渲染会多一份缓存与失效逻辑；首帧只付一次会话启动成本。

## 第三阶段：风格改为给 AI 的说明书（2026-10-15，按用户决定）

用户判断：风格不该是组件或参数，而是给 AI 看的、有固定结构的提示词，最多附几段代码示例；AI 照着它做出同一风格的各种内容，不被限定死。强弱直接写在文字里，不做成单独参数。

- 风格 = `{ guide, examples }`：guide 是 Markdown 说明书，必填章节“定位、核心理念、视觉语言、动效语言、节奏与剪辑、文字与字幕、必须、避免、可以自由发挥”，可选“画面生成提示”，可追加自定义章节；examples 是 0–6 段参考代码（标题 + 演示了哪几条规矩 + 源码），只示意手法。
- 职责划分：风格是 AI 的创作规范，不给任何东西赋值；字幕、标题、转场的具体参数归文字/标题/转场预设。
- 删除：配色/字体/字号/动效/节奏/质感参数与结构化规则概念；代码语言 `ctx.style`；关键帧曲线属性；提取作品风格、提取参考配色、插入风格组件三个能力；片段级风格覆盖；字幕“跟随风格”与文字、标题、图形的自动跟随。
- 保留：序列绑定（决定助手按哪份说明书创作，不改时间线）、默认风格自动绑定新建序列、就地生成并入“画面生成提示”（可关）。
- 内置三套重写为完整说明书；原专属开场、人名条、强调降级为参考示例，取值烘焙成示例开头的常量表，不再读 ctx.style。
- 界面：风格面板按章节编辑说明书，示例可删、可把所选代码片段加为示例；预设面板的风格依次播放参考示例，详情右侧按章节显示说明书。
- 助手：绑定时宿主上下文给出整份说明书（示例按需读实体）；技能 style-kit 参考重写为“读说明书 → 从零写新内容 → 对照必须项自查 → 评价写进对应章节”。对外契约升级 2.17.0。
- 数据：按用户要求不保留旧数据。本机风格库 v3、剪辑 v9、录制会话 v11 的升级直接丢弃旧风格快照与绑定；预设包、字幕回填记录登记开发期破坏性变更。
