# t81 修复风格预览与批注缩略图一直加载

2026-10-08。工作分支 main；只修改工作区，由总管理者审查、提交和同步。未触碰开始时已存在的 SDK 修改和 `vitest.exp.config.ts`。

## 根因与排查范围

- 风格预览、批注缩略图共用 `trialVideoEditCodeFrames`。原试渲染的取消监听和单帧计时在 `await previous` 之后建立，等待项无法及时响应中止。被取消的请求仍占队列名额；四项硬拒绝会让新候选与其他取帧消费者互相影响。已改为进入队列时立即监听取消和计时，取消等待项立即返回，但释放串行位置仍等待前项，避免并发进入 renderer；取消后重启可继续排队。
- 原批注串行尾链只恢复 rejected Promise；若取帧或 PNG 转换不返回，后续项目都等在尾链上。试渲染原有 30 秒单帧超时不覆盖整项等待、编译与 PNG 输出，风格输出也有相同缺口。新增 35 秒预览任务保护，从进入预览服务到 Blob 完成；超时传递取消，当前项失败并推进后续任务。
- 批注组件原来依赖整个 document 引用。AI 写 addressed 状态、回复和文档 revision 都会取消当前帧，即使像素没有变化。现在按正式 composition 的出画内容判断更新，排除 root revision 和各序列的 annotations；WeakMap 按文档/序列共享计算，状态变化不重新取帧，代码、风格、尺寸或嵌套画面变化仍中止并重排。
- 风格组件原来依赖 kit 对象引用。等值 clone、只改风格名称/规则也重启；现在依赖 id、tokens、samples 和画幅、visible。隐藏后中止，再次可见或出画内容变化后重启，迟到结果不能提交。
- 检查 `styleKitPresets.ts`：六套内置风格的十八个样例目前均由 `makeStyleKitSample` 产生，实际含有 `width: 1920, height: 1080`，故不是本次已证明的尺寸替换不匹配。仍修复脆弱的字符串替换：使用现有 TypeScript AST 定位 export default 的顶层 width/height；空白、注释、属性顺序和引号变化均有效，不误改文字和图形尺寸。
- 检查正式 `VideoEditRenderSession.dispose`：已有 2 秒后 terminate 的释放保护，未发现这一实现无限等待；未修改 renderer、Worker 或主进程。检查试渲染消费者：代码创建/候选/绑定、观察、参考风格和 Lumetri 共用此入口，等待取消修复一并生效；其业务流程未重写，代码服务精确回归覆盖共享路径。
- 本次未运行真实 Electron，无法把截图时 GPU/字体/原生解码的具体卡点确定为唯一现场根因。以上是源码和故障注入精确测试确认的缺口，真实窗口的出画、aurora 着色器和硬件耗时留待总管理者复测。

## 实现与选型

- 复用已有 production compiler/compositor 和 TypeScript AST，不引入第二套渲染或源码解析器；已有 `codeElementBake` 负责源码定位与替换，增加顶层画幅替换函数。
- 取消/时限使用标准 AbortController、Promise.race、计时器；串行队列只增加失败收口与过期检查，无新增依赖。没有需要独立开源队列库解决的调度或并发策略；沿用项目队列的串行语义，比引入库及替换所有消费者更小。
- 35 秒是单次预览的挂起保护；共享试渲染仍逐帧计时，长编辑不设总帧数/总时长预算。移除等待四项的数量拒绝；未增加素材、样例、批注、片段或序列数量上限。
- 两个预览服务都通过既有 createLogger 记录 start/completed/failed、取消、耗时与目标；诊断字段只进日志。
- bitmap 在 drawImage 后即 close，不等待不可取消的 PNG 转换；迟到 bitmap 同样关闭，旧请求不创建 URL；显示 URL 在替换/隐藏/卸载时 revoke。
- 风格某样例失败仍生成其余样例，错误使用 UiError 的重试入口；批注在原缩略图按钮内显示取帧失败并允许重试。移动跳转回调至该按钮，保持一个按钮，避免嵌套原生按钮与点重试意外跳转。
- 应用能力分级：这是既有画面预览及失败恢复修复，未新增业务数据/实体/属性、持久化副作用、Surface 或用户创作动作；重试只重新计算派生图，不新增 MCP 同义工具，助手继续通过现有正式观察/风格/批注能力使用同一业务服务。
