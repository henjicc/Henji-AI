# t109 可见性剔除、复用与成本反馈

总任务见 t107，在 t108（GPU 原生矢量绘制）与 t110（编译执行）合并后开始。画面结果保持一致，只减少不必要的计算和绘制，并把成本告诉 AI。

## 要做

1. **看不见的不算**（求值器与渲染器配合）：
   - 先求组的 opacity、clip、mask 与变换，再决定是否展开子元素：组透明度为 0、clip 区域为空或完全落在画幅外、mask 恒为空时，整棵子树不求值、不绘制。
   - 单个图形透明度为 0、或包围盒完全在画幅外（考虑描边、阴影、辉光、模糊外扩与变换）时不输出绘制命令。
   - 剔除不能改变确定性与元素定位：被剔除的元素在命中测试与元素覆盖里按“当前不可见”处理，与现在不可见元素的行为一致；CPU 预算计费按实际求值量计（剔除省下的不计费），并在文档说明。
2. **不变的不重算**：
   - 静止帧复用：同一片段相邻帧输出的绘制命令完全相同（按稳定哈希判断）时，直接复用上一帧的渲染结果纹理，不再绘制。
   - 静态子树缓存：组内子树的绘制命令跨帧不变时，把它绘制成图层缓存，后续帧只合成；变化时失效。显存按现有纹理预算淘汰。
3. **成本分布反馈**：试渲染与取帧的性能结果在现有“最重结构”之外，给出前几名结构的 CPU 求值与 GPU 绘制耗时占比和行列号，以及剔除与复用命中的统计；超实时预算时一并返回。只经现有能力结果返回，不新增界面。
4. **验收**：
   - 基准 complex-to-simple：tangle 组淡出后的帧（约 2.5 秒后）求值与绘制接近只剩标题与线；结尾静止段（约 5.5 秒后）几乎全部命中复用。给出逐段耗时。
   - 剔除、复用、静态子树缓存各有正反例测试（含“看似静止实际有极小变化”不得误复用）。
   - 像素对比与改前一致。
   - 若成本反馈改了能力输出，`EXTERNAL_CONTRACT_VERSION` 设为 2.21.0 并更新指纹。

### 选型与边界

- 比较了 [PixiJS Culler](https://pixijs.com/8.x/guides/components/application/culler-plugin) / [cacheAsTexture](https://pixijs.com/8.x/guides/components/scene-objects/container/cache-as-texture)、[CanvasKit](https://docs.skia.org/docs/user/modules/canvaskit/) 和 [math.js compile](https://mathjs.org/docs/expressions/parsing.html)。前两者提供成熟矢量/图层缓存，但采用其场景与绘制入口需要替换已经合入的 t108 管线，尚无本项目像素、效果合成与纹理预算一致性的证据；math.js 使用另一套表达式语言和运行模型，不能直接承担现有受限 IR 的预算与源位置契约。这里的判断来自接口比较，没有虚构三者在本项目的实测性能。
- 本轮沿用 t108 原生矢量/栅格回退与 t110 闭包计划，在原实现内加剔除和有界复用，不引入另一套渲染器或表达式编译器，不新增依赖。已有 VGPU、svgpath 为 MIT，继续保留许可和版权声明。若后续采用上述候选：[PixiJS MIT](https://github.com/pixijs/pixijs/blob/dev/LICENSE) 要保留版权/许可；[Skia BSD-3-Clause](https://skia.googlesource.com/skia/+/main/LICENSE) 要保留版权、条件和免责声明，不能借权利人名义背书，并核对其第三方 notices；[math.js Apache-2.0](https://github.com/josdejong/mathjs/blob/develop/LICENSE) 要提供许可证、保留适用 NOTICE、标注修改，遵守专利授权/终止条款。本次没有专项专利检索，不把许可证当作专利清查结论。
- 渲染路径先判组 opacity、clip、恒空 alpha/luma mask，未展开子树不计运行时 CPU 工作量；绘制绑定按需求值，保留声明处索引。嵌套变换参与判断，祖先效果可能把画外内容扩散回来时保守保留。静态编译预算与可见工作的既有计费不放宽。
- 元素定位、命中和覆盖先取完整树，保持重复 ID/path，已证明不可见的元素标为透明；覆盖可以重新显示或移回元素。存在覆盖时不提前裁掉作者树。
- 整帧以稳定哈希加完整数值字符串比较复用原输出纹理；静态组在连续两帧内容相同时进入原栅格 LRU，共享 48 MiB 缓存与宿主 256 MiB 预算，资源压力下淘汰可释放缓存。组自身移动、透明度、混合只在合成时应用。可变媒体输入不复用；字体变化、极小数值变化、目标重建与其他写入均失效。
- 现有试渲染 evidence 和取帧 performance 返回前五结构、源码行列、CPU/GPU 占比与剔除/复用统计；预算内也返回。结构成本含子结构，GPU 是准备到队列完成的墙钟，可能重叠，非硬件 timestamp；滤镜 GPU 成本归入滤镜整体。契约为 `2.21.0`，指纹 `9db7eb4c3beae3921e8bbe6fbbffecdcc1a72eee8696f63264068500f0ea5cbd`。未新增工具、界面、落盘格式。
