## 选型与移植

已读 shaders 的 `gpu/porters.ts`、`gpu/composer.ts`、`std/paint`、各效果声明，以及本项目内置效果、转场、图片编辑 diffusion 配方/着色器。参考仓库 https://github.com/shader-effects-inc/shaders，固定来源提交 `dbfd42abe341e7a6ea0b8ea1f5bab018b8e8439a`。上游版权：2026 Shader Effects Inc.，MIT。VGPU MCP 当前未加载、在线文档访问失败，转读本机官方参考仓库的性能文档和已安装 API 声明；未凭记忆添加 VGPU API。

| 方案 | 结论 |
|---|---|
| (a) 运行时依赖 shaders/core | 不选。core 可使用共享设备，但仍需 TypeGPU 0.12.3、编译插件、节点/纹理注册与 std 编译的接入验证；上游 animatedTime 累积 dt、反馈模拟须改为剪辑随机寻帧。直接接 renderer 又会引入另一套资源生命周期。 |
| (b) 构建期自动生成 WGSL | 后续扩库的候选。静态代码适合可信白名单，但目前上游图编译产物绑定其 uniformStore/RTT/tonemap，需要额外离线 ABI 重写工具；不把此工具未经验证引入本轮构建。 |
| (c) 人工降低选定 std 算法到静态 WGSL | 本轮采用。明确移植来源和删减特性，静态入口不可由作者提供，现有工序执行器拥有设备与预算。代价是上游算法更新需逐项核对。不是宣称上游全部参数或外观等价。 |

首批选择无 DOM、无历史帧依赖的 40 项，优先渐变/纹理、风格滤镜、两输入转场。背景生成通过既有图形片段承载，再添加生成效果，不增加素材 kind；滤镜、关键帧、遮罩、强度、撤销和保存沿现有路径。t62 接线只消费白名单名称、封闭参数、显式秒时间与目标纹理，不接受 WGSL。

## 规模与执行边界

目标 3840×2160 / 60fps，单帧总预算 16.67ms，不能把单效果低于预算当作整条时间线保证。管线懒编译，中间纹理复用宿主 allocator；不用新的 GPUDevice、墙钟、requestAnimationFrame 或上一帧。需要 GPU 专项测试验证静态 WGSL、透明色边界与 4K 时间戳；不跑 Reality、不启动/重启开发实例、不付费。

许可：保留 MIT 原文和版权，经已有 `gen:licenses` 合并到随包 THIRD-PARTY-NOTICES；不引入 TypeGPU 或框架运行时。封面登记运行时渲染配方，提供同一正式渲染接口；当前列表面板仍用原有行结构，本任务没有增加缩略图卡片或上游大图。

## 首批目录与删减

中文名称、分类、参数范围/默认值/单位/是否可动画的唯一数据源是 `src/core/videoEdit/shaderLibrary/catalog.ts`。34 个片段效果参数可打关键帧；6 个转场沿现有转场模型，不支持参数曲线，元数据明确标记不可动画。转场强度 0 是普通交叉溶解，保持进度 0/1 的前后画面契约。

| 分类 | 本轮效果（括号内为上游来源名称） | 选择理由 |
|---|---|---|
| 渐变背景 | 线性渐变（LinearGradient）、径向渐变（RadialGradient）、角向渐变（ConicGradient）、菱形渐变（DiamondGradient）、网格渐变（MeshGradient）、流动渐变（FlowingGradient） | 标题、品牌和柔和动态底板；少量颜色与空间参数即可使用。 |
| 自然纹理 | 极光（Aurora）、柏林噪声（PerlinNoise）、分形噪声（FractalNoise）、等离子波纹（Plasma）、大理石纹（Marble）、细胞纹理（WorleyNoise） | 覆盖有机、发光、石材和抽象视觉，显式时间可随机寻帧。 |
| 几何与光场 | 线框网格（Grid）、点阵网格（DotGrid）、棋盘格（Checkerboard）、条纹（Stripes）、光束（Beam）、闪烁星场（Sparkle） | 科技、图案、星空背景；无需 DOM、鼠标或粒子历史模拟。 |
| 风格滤镜 | 镜头色差（ChromaticAberration）、扫描线（CRTScreen）、录像带（VHS）、印刷半调（Halftone）、像素化（Pixelate）、字符画（Ascii）、胶片噪点（FilmGrain） | 常用复古/印刷风格；字符画用静态程序字形，不依赖字体或 DOM。 |
| 光学与扭曲 | 条纹玻璃（FlutedGlass）、玻璃砖（GlassTiles）、中心旋涡（Twirl）、波浪扭曲（WaveDistortion）、电影暗角（Vignette）、径向拖影（ZoomBlur）、方向拖影（LinearBlur）、辉光PRO（Glow 入口、图片编辑 diffusion 算法）、万花筒（Kaleidoscope） | 对真实素材有直接价值；两种拖影复用既有管线，辉光复用成熟配方。 |
| 转场 | 噪声溶解（NoiseDissolve）、像素溶解（BlockDissolve）、菱形擦除（DiamondWipe）、斜向柔擦（LinearWipe）、漏光转场（LightLeak）、液态波纹（RippleWipe） | 覆盖柔和、有机、几何、像素、胶片、水面切换；两输入与透明端点一致。 |

人工移植保留各类核心视觉算法，但不承诺逐像素还原上游。噪声使用整数种子散列替代不稳定的正弦散列；极光、网格渐变、光束、星场和漏光收敛为固定层数、无反馈的程序图案；字符画使用内置笔画；无光标交互、DOM、历史粒子仿真。所有入口和片段源码固定在可信模块，参数中未知字段、作者 WGSL/source 都被现有封闭 schema 拒绝。

## 接入与颜色契约

- 注册到既有 builtinEffects/effectsRegistry 和转场预设，新增“着色器背景 / 着色器滤镜 / 着色器光效”分类数据，不改面板结构、素材种类或文档模型。背景的操作路径是创建既有图形/纯色片段，再添加背景效果；没有新增独立“着色器背景”素材按钮。
- 复用既有 GPUDevice、sampler、中间纹理 allocator、效果遮罩/合成和撤销。合成现场按 `frame / document.fps` 注入只读运行时秒时间，不写入文档参数，24fps 与 60fps 的同一秒测试一致。
- 接口 `TrustedShaderLibraryRenderer.render({name, params, timeSeconds, width, height, format, input, output, second?, progress?})` 接受宿主注入执行器，验证名称、时间、目标尺寸、纹理别名和转场输入。t62 需后续接线；本任务未修改作者语言或 videoEditCodeGpu。
- 延续现有合成器纹理 ABI。采样解除预乘，需颜色插值或散射的部分转线性光，输出恢复合成器颜色与预乘 alpha；生成背景是不透明输出，滤镜保留输入透明度，转场保持单侧空输入语义。GPU 测试含透明及半透明边界。
- 辉光PRO直接使用图片编辑 `compileDiffusionRecipe` 的亮通、散射权重、曝光和肩部参数；WGSL 按其 13 tap 降采样、9 tap 升采样和亮通/肩部公式接入宿主 ABI。默认 4K 21 道工序，与旧辉光 9 道工序对比后保留新入口，并保留旧效果，避免无关替换。

## 每类代表性能实测

2026-10-08，本机 VGPU/node + Dawn，适配器只报告 `D3D12 driver version 32.0.16.1047 / gpu`，未获取具体 GPU 型号，不推测型号。3840×2160、rgba8unorm，预热 3 次、采样 12 次，通过 timestamp-query 汇总每道渲染工序 GPU 时间；不含 CPU 编码、首次管线编译和完整时间线合成。数据在 `node_modules/.cache/t66-shader-library/performance.json`，不提交缓存。

| 类别代表 | 中位数 ms | P95 ms | 工序数 | 处理 |
|---|---:|---:|---:|---|
| 线性渐变 | 0.191 | 0.344 | 1 | 原尺寸 |
| 分形噪声 | 0.368 | 0.369 | 2 | 半尺寸生成 + 原尺寸混合 |
| 极光 | 0.334 | 0.342 | 2 | 半尺寸生成 + 原尺寸混合 |
| 细胞纹理 | 0.285 | 0.291 | 2 | 半尺寸生成 + 原尺寸混合 |
| 条纹玻璃 | 0.118 | 0.121 | 1 | 原尺寸 |
| 字符画 | 0.139 | 0.182 | 1 | 原尺寸 |
| 径向拖影 | 1.034 | 5.614 | 2 | 既有缩放模糊管线 |
| 辉光PRO | 1.079 | 1.384 | 21 | 多级散射 |
| 噪声溶解 | 0.581 | 2.060 | 1 | 原尺寸 |
| 旧辉光（对照） | 0.305 | 0.474 | 9 | 既有多级管线 |

本机代表效果 P95 均未超过单帧 16.67ms，不能据此保证任意 GPU、任意叠加链实时 4K60。极光、分形噪声、大理石、细胞纹理在高度超过 1080 时固定半尺寸生成，再全尺寸混合原输入；强度小于 100 时不会把原素材一并降采样。固定策略不读取帧率或墙钟，避免预览与导出不一致。其他效果未逐项实测 4K 耗时，不伪称已有全目录性能数据。

已打开并目视检查 GPU 渲染缩略图拼图 `node_modules/.cache/t66-shader-library/contact-sheet.png`：渐变、极光、几何、星场、风格滤镜外观符合用途；辉光PRO高光肩部比旧辉光保留更多层次，开销增加约 0.77ms（中位数）。这不是 Electron 界面验收，也不是与图片编辑整条链逐像素等价验证。
