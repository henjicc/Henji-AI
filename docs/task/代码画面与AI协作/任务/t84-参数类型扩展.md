## 设计自查

1. 助手只凭名称和说明能否用对？能。代码素材/固定版本提供只读 parameters 与 types，返回作者类型名、语义说明、完整默认值、边界、分组和条件显示。实例沿 clip.code_parameters、effect.parameters、item.code_parameters/code_curves 的通用实体修改，中文错误给出期待形状、范围或可用字段；没有新增专用写值工具。
2. 能否 AI 先做、人只确认？能。AI 作者先声明开放参数与字段默认值，缺省的组件声明默认值自动补齐；以后调整实例参数及动画即可，无需改源码。界面校正与复杂控件由 t86 接入。
3. 产物能否直接流进其他工作区？沿既有剪辑项目与可编辑代码资产保存/收录/导入契约承载新 JSON 值，移除代码资产图片依赖列表的 32 项人为上限。资产跨工作区的现有路径复用；本轮没有重新执行真实 Electron 跨工作区操作或成片导出。

## 选型与关键契约

- 对比 [d3-interpolate 通用值插值](https://d3js.org/d3-interpolate/value)、[bezier-easing](https://github.com/gre/bezier-easing) 和项目已有 motion/keyframeInterpolation。采用已有确定性缓动与标量插值；d3 的字符串/任意对象插值不符合 seed、文字、字体及离散组件字段必须 hold 的契约，引入另一个贝塞尔库也会重复现有 24 轮二分实现。结构分量选择是本项目声明契约的小型适配，不另造动画引擎。
- 声明/持久化复用现有 TypeScript AST 与 [Zod](https://zod.dev/api)，GPU 复用现有滤镜发射器和 uniform 通道，没有新增依赖。
- 新类型与新元数据只在 languageVersion:3 开放。v1/v2 仍使用旧声明解析、32 项参数与旧 choice 限制；未增加旧数据迁移或兼容分支。
- 支持 angle、point、range、gradient、curve、grade、font、easing、seed 与自定义组件；number/choice 控件提示、alpha、multiline 及共用 tooltip/group/advanced/visibleWhen 均进入契约。
- 内部 IR 用闭合 `type:'custom'` 加 `typeName` 与 `fields`，保证现有消费者的联合类型可穷尽，旧面板继续编译；作者语言与 AI 元数据仍使用自定义类型名。`choice` 内部保留字符串 options 和 optionLabels，AI 投影恢复 `{value,label}`。t86 应使用内部类型/字段与 program.types，不以 AI 投影当运行 IR。
- 自定义类型字段 1–16 个，只允许非 image 基础类型，无嵌套、字段分组/高级/条件显示；wheel 恰好一个 grade。声明 default 可以部分填写，实例写入必须提供完整字段。自定义类型名只禁止与基础类型重名。
- point 默认 frame，0–1、y 向下；pixels 使用明确每轴界限。沿原数值安全域，声明数字范围/步长与像素点边界限于 ±1e9。源码字节、AST/求值预算等既有执行边界仍生效，生成器参数数量没有新的产品上限。
- angle 和 grade.hue 都按数值插值，不做环绕或最短路径；point/range/grade 与自定义可插值字段做分量 linear/ease/hold，结构中的离散字段 hold。gradient/curve/font/easing/seed/choice/text/boolean 仅 hold；image 不可动画。
- sampleGradient 在 at 上线性插值、输入夹 0–1，重合 at 的最后色标胜出；sampleCurve 为分段线性，t86 曲线编辑器应匹配此契约；ease 复用 motion 的缓动名和贝塞尔实现。CPU 成本分别为 640/512/128，编译预算与运行 charge 同源。
- gradient 最多 32 色标、声明默认 maxStops=8；curve 2–64 点；持久化字符串 ≤4096。easing 的编译表达式 string/array 类型按声明 default 推断，运行实例校验接受合法名或贝塞尔四元组。
- GPU 只按最终逐像素表达式实际读取的参数或结构字段分配 vec4 槽；未使用参数和 shaderFilter 帧级属性不占槽。64 个槽 + 两个头部 vec4 + 一个 flags vec4，共 1072 字节，WGSL/打包/binding layout 同步。
- GPU 可读 number/angle/seed/boolean/color/frame point/range/grade 与对应结构字段；其他类型及三个新 CPU 函数在逐像素表达式报 TYPE，提示帧级属性或 WGSL/shader。超过 64 槽报明确技术原因，不限制素材声明总数。seed 按请求使用 f32 传入 GPU，高位整数保留 f32 的实际精度边界；CPU 与持久化仍保留原 uint32 整数。
