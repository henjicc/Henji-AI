# t70 画面直接修改与元素覆盖

状态：2026-10-08 已实现，待总管理者审查。仅修改工作区，不执行 Git 写操作，不修改 packages/ai-sdk。遵照本任务要求，未运行 Reality、Electron、真实 Pi/MCP 或付费模型。

## 设计自查

1. 助手只凭名称和说明能否用对？能。clip.element_overrides 提供按 elementId 索引的完整结构、作者坐标/倍率/角度/RGBA/源时间曲线说明；整体替换先读回并保留其它元素。宿主摘要指出有覆盖的元素及失效情况。参数文字明确通过 code_parameters 修改；写回沿不可变 code_version 创建与片段绑定。没有增加专用设置型工具。
2. 能否 AI 先做、人只确认？能。助手可以读取和修改覆盖，也可按元素标注完成复杂源码改写；人直接拖动、修改文字与字体，简单字面量由确定性算法收尾，复杂表达式创建标注并打开助手输入。用户仍审查结果，复杂分支没有自动发送或付费调用。
3. 产物能否直接流进其他工作区？能沿既有渲染、节目帧观察、导出和资产入口消费。代码资产保存覆盖，导入为素材项初始值，新片段独立复制。资产收录/导入、保存重开有精确测试；真实跨工作区往返及成片导出未运行。

## 实现与关键决定

- 只对作者语言 v3 的生成片段开放覆盖；新增片段 elementOverrides，以及可编辑代码资产导入所需的素材项初始 elementOverrides。两者插入时深复制，随后独立编辑，不把片段操作改成全素材操作。无旧数据迁移或隐藏兼容分支。
- 所有指定字段可选；curves 复用代码参数的关键帧点、源微秒/有理余量与线性/保持/ease 插值。文字、字体和隐藏只支持保持。覆盖求值后、GPU 绘制前应用，选择/命中/标注也消费同一命令树，不新增场景图。
- 变换顺序为元素自身轴缩放、绕包围盒中心或显式作者锚点旋转、作者变换、父空间 dx/dy 平移，再接祖先及片段变换。非等比缩放不会因作者已有旋转而额外产生剪切；角点固定对角，Shift保持当前比例，旋转Shift按15度吸附。
- 默认静态。已有曲线的属性在当前源时间加/改关键帧，未启用曲线的属性改静态值。监视器“自动关键帧”是显式启用/关闭该元素的五条变换轨道；关闭时冻结当前值，不对未启用的文字属性自动打帧。效果控件每条变换属性可单独启停动画。
- 拖内部移动、四角缩放、旋转手柄、方向键1作者像素/Shift10像素；吸附画面中心、5%安全框和其它可见元素边缘，阈值为6屏幕像素，Alt绕过。指针/按键连续操作共用项目手势撤销；Esc、指针取消、切帧、换元素/版本、卸载取消未提交动作。
- 双击或Enter开启就地文字输入，Enter提交、Esc取消，保留多行已有内容并避开IME正在组合的Enter。直接文本参数及其局部别名写参数；其它文字写覆盖。效果控件复用t69面板的v3可存子集和t63字体选择器，不提供无法保存的仿粗斜、多描边等控件。
- 右键提供让助手改这里、隐藏、重置、写回源码和源码查看；源码查看可等待效果控件挂载，再展开并按sourceSpan定位。覆盖列表用Virtuoso虚拟化；已消失元素保留覆盖并可重置。条件隐藏帧不等于源码删除。
- 失效状态派生，不写入覆盖。源码全分支保留字面量ID、自动调用ID及重复实例/别名身份；当前帧索引补充动态ID。复杂动态ID在隐藏分支中的存在性不能由静态源码枚举完全证明，需总管理者留意此边界。
- 确定性写回只改选中调用sourceSpan中的字面量，保留其它源码/注释。坐标表达式、关键帧、中心变换、repeat（即使当前只生成1个）或可复用绑定交给助手，避免部分错误合并。若另有基于源码偏移的call:覆盖，也走助手保守重建身份，避免字面量长度变化使其它覆盖失效。
- 成功写回复用候选编译/试帧/发布流程：新增版本、单片段绑定和清除已合并覆盖同一次撤销。失败、取消或候选期间文档改变均不发布；复杂分支创建带覆盖内容/sourceSpan的元素标注，打开助手输入，提交的说明写回标注。
- 通用clip/item属性扩展属既有实体覆盖；宿主上下文补覆盖摘要，Pi与MCP沿现有通用读写/事务。上下文仅预览前12项，可通用读取完整对象，这不是产品数量上限。
- 不给片段、素材、覆盖元素或关键帧数量设上限。保留现有v3每帧绘制/字符、GPU目标、源码/资产字节技术预算；坐标32768、倍率1024、字号1024等沿v3数值安全域，避免奇异矩阵与不可控GPU/字形资源。对象保留名称__proto__显式拒绝，其它ID按自有字典键读取，不读取或污染对象原型。

## 选型依据

已阅读本地HyperFrames canvas.mdx、animation.mdx、DomEditOverlay、useDomEditOverlayGestures、InlineTextToolbar、useInlineTextEditing及PropertyPanel参考。另查阅[Moveable官方API](https://daybrush.com/moveable/release/latest/doc/)和[TypeScript Compiler API](https://github.com/microsoft/TypeScript/wiki/Using-the-Compiler-API)。Moveable适用于DOM元素变换，本项目节目画面是GPU封闭命令树，仍需桥接作者/分组/片段几何与项目撤销；因此复用现有指针、几何和手势服务，只补编辑叠层，不引入第二套DOM场景系统。源码改写采用已有TypeScript AST和精确字面量替换，不自研源码解析器、不引入新依赖。没有新增VGPU API、GPU生命周期或WGSL实现。
