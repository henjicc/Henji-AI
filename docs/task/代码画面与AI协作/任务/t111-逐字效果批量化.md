# t111 逐字效果批量化与动态段开销

总任务见 t107。t108–t110 合并后，基准 complex-to-simple 的剩余热点：

- 3.2 秒附近（标题逐字带模糊升起）GPU 绘制约 42ms：`perChar` 的 blur/glow 目前每个字形各自走一遍效果链（单独图层、多遍高斯）。逐字模糊入场是 AI 常用手法，必须便宜。
- t109 加入剔除与复用判定后，1.0 秒附近（动态段）GPU 墙钟从约 3.4ms 回退到约 7.7ms，判定开销在每帧都付出。

## 要做

1. **逐字效果批量化**：同一个 `text` 的所有字形（含不同的 blur/glow/颜色/变换）合并成尽量少的 GPU 提交。可选思路：字形栅格进图集并按字形缓存（字形、字体、分辨率不变就不重画）；模糊与辉光对整组字形在一个图层里按实例半径做可分离高斯或按半径选择的降采样金字塔混合，在与现有结果像素容差内一致。选型以效果与性能实测为准，写进最终消息。
2. **动态段判定开销**：剖析 t109 的剔除、复用、静态子树判定在动态帧上的开销（哈希、包围盒、缓存查找），把不会命中的情况尽早跳过（例如上一帧未命中且结构含时间依赖的子树不再每帧哈希），使动态段 GPU 墙钟回到不高于 t109 之前的水平。
3. **验收**：
   - 基准 complex-to-simple 各采样段“求值 + GPU 绘制”中位数都在 16ms 以内，给出 1.0s、3.2s、5.53s 三段改前改后数字（同 t109 的基准测试方式）。
   - 逐字模糊、逐字辉光、逐字颜色与变换混合的像素对照测试，与改前结果在写明的容差内。
   - 两段标题基准不回退；现有 GPU 测试全部通过。

### 选型与实现

- 对照 [PixiJS Filters](https://pixijs.com/8.x/guides/components/filters)、[CanvasKit](https://skia.org/docs/user/modules/canvaskit/) 和 [math.js compile](https://mathjs.org/docs/expressions/parsing.html)。PixiJS/CanvasKit 有成熟矢量、文字与滤镜能力，但不是现有散射核、预乘合成、字形度量和宿主纹理预算的直接替代；没有测得它们在本项目满足像素契约的证据，不声称它们性能较差。math.js 的表达式语言/运行模型不是现有受限 IR 的预算与确定性契约，本任务也无需改动 t110 编译器。
- 选择复用已有字形栅格、WebGPU 管线和 `renderScatterPyramid`，不增加依赖、不另写滤镜核。旧路径实际使用正权重 tent 散射金字塔；保留其层数、ceil 尺寸、权重、效果顺序和 rgba8 量化。各字形仍单独过滤，避免整组模糊导致重叠字形相互污染；同一 text 的效果录入一个 encoder，通常一次提交，内存压力下提前提交释放退休纹理。
- 原字形按字体/布局/颜色/分辨率缓存；效果外扩用整数对齐 padding 桶，在过滤前裁回原来的精确尺寸。逐字字距只影响位置，独立字形只保留原有的自定义间距布尔语义。变化半径不再每次重画；padding 跨桶、字体、颜色、布局或分辨率变化仍可能重栅格化。保留最后一次字形效果结果，工作图层可复用；可选保留共用 48 MiB 上限，始终通过原宿主分配器计费，空间不足时回退原尺寸栅格。没有放宽 4096 绘制或宿主显存预算。
- 合并 clear 与随后的绘制 pass；uniform 改用 256 字节对齐的缓冲区分区，每次提交成批上传，保持提交前资源有效。透明文字和已缓存文字不额外提交空效果链。
- 动态帧与组记住最近变化的标量路径；该值继续变化时直接证明“不相等”，跳过复制视觉树、序列化和哈希。停止变化后恢复完整精度字符串比较，探针绝不作为相等证明。整帧与组缓存仍验证字体、尺寸、媒体和精确内容。纯平移包围盒走不分配角点数组的等价判断，其他变换保留原路径。
- 许可：已有 [VGPU](https://github.com/vercel-labs/vgpu) / svgpath 为 MIT，继续保留许可与版权声明；若采用候选，[PixiJS MIT](https://github.com/pixijs/pixijs/blob/dev/LICENSE) 同样要求保留声明，[Skia BSD-3-Clause](https://skia.googlesource.com/skia/+/main/LICENSE) 要保留版权/条件/免责声明、不得借权利人背书并核对第三方 notices，math.js Apache-2.0 要保留许可证及适用 NOTICE、标注修改并遵守专利授权/终止条款。未做专项专利检索，本次没有引入这些候选的新分发义务。
