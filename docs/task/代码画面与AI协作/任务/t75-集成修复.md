## 根因与修复

- 布局测试的 `6` 是面板数量而非分组数量。风格已经是效果组中的第七个标签页，默认仍为四组；更新数量期望并明确保护四组及风格的归属。
- 同源问题：风格、效果库重开与贴回，以及 Lumetri 贴回漏掉检查器归属，另开右侧列；效果控件关闭后也不能沿其他检查器标签找到原组。统一检查器清单与停靠目标选择；七类检查器分别覆盖打开、关闭重开、浮动面板与浮动组贴回，另覆盖效果控件关闭后的风格重开/贴回及效果控件自身恢复。
- Dock 测试日志替身仅提供 warn，新增本机库在加载时调用 debug 导致模块收集失败。补全日志级别；布局测试使用独立未注册实例，基本图形的字体预览需要正式工程，按已有面板内容边界补充基本图形、风格、批注替身。保留真实 Dockview、效果库和节目生命周期断言，面板业务由各自精确测试覆盖。
- 预设测试在整个效果控件上查询唯一复选框，文字面板新增填充/描边/背景复选框后查询歧义。将“保存之前没有效果复选框”的断言限定在附加效果分区，仍保留弹窗默认全选、子集保存和链顺序断言。
- 渲染初始化并发执行素材核验、字体准备及原生解码连接。字体准备现在读取代码版本，缺失版本先于异步素材错误被报告，原生通道还可能已经启动。先核验源素材，成功后才准备依赖资源并连接解码；保持代码错误正常传播，新增失败时不调用解码状态接口的断言。
- 选型依据：本任务为现有集成契约修复，继续使用已集成的 Dockview 标签与分组 API、Vitest/Testing Library 和共享渲染会话；不引入新的布局、字体或媒体实现与依赖。
