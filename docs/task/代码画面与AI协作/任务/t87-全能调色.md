## 范围与方案

彻底将调色效果、文档 LUT、实体属性、自动校色能力、Dock、GPU、Worker、日志和测试改为 color grade 语义；不保留旧标识兼容。HSL 辅助复用同一效果参数、通用实体读写、现有关键帧与撤销。面板复用 t85 原件和 t86 ParamList。

典型输入为 1080p/4K 帧，实际最大尺寸受既有设备纹理与显存预算限制，没有新增素材、片段或序列数量上限。像素运算进入现有 GPU 工序规划器，主进程不计算像素。中性 HSL 无额外工序或纹理；有校正时生成 HSL 蒙版、可分离高斯清理，再在线性光局部校正，保持预乘 sRGB 编码 ABI。参数唯一真相是文档效果；面板仅持有选择和手势草稿，沿已有自动保存与取消机制。

## 实现细节与排查边界

三色轮通过同一 ParamList 字段适配成 UiGradeWheel，百分比强度/亮度转为原件的归一化值；每个轮复位同时还原三个分量，关键帧仍分别写入三个正式参数。flex basis 布局按可用宽度变为三列、两列或一列。曲线使用 UiCurveEditor，领域样条采样器保持实际显示与 GPU LUT 一致，色相端点联动；RGB和色相通道使用分段选择，编辑区跟随面板宽度。其余行仍复用 ParamList，分为基本校正、创意、曲线、色轮、HSL辅助、晕影。

HSL 联合键控在编码色空间按感知 HSL 求选区，灰色不伪装成红色。颜色校正和局部混合在线性光执行，局部锐化先线性化再调用既有高斯。去噪与模糊是不同画面高度比例的高斯平滑，用方差合并为一次既有高斯规划。显示蒙版不经过后续晕影或锐化，关闭恢复；它是效果参数，导出同样显示，tooltip和技能说明必须先关闭。HSL 校正全0时，即便选区/羽化/反向/清理值改变也不加工序；仅显示蒙版或有效校正启用。

沿文档外壳核对时发现旧200个LUT目录限制，已移除；完整文档与宿主持久化外壳均通过300个LUT回归。保留字符串编码、纹理设备等实际技术边界，不增加产品数量上限。固定五锚点及其现有数值动画仍是当前曲线参数功能，未添加旧效果ID、旧文档字段或迁移别名。
