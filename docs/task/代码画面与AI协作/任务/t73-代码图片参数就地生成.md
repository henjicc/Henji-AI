## 选型与边界

- 复用项目已有 GenerationService、generationApplicationService、原地生成等待器、创作结果落库和媒体导入，不新增供应商调用或上传实现。
- 浮层采用已有 PanelTrigger（内部使用 Floating UI 语义的归属机制）、PromptEditor、ModelSelectorPanel、ParameterPanel、PriceEstimate；不需要另引入生成表单库。
- 候选列表采用已有 react-virtuoso 虚拟化，没有图片候选数量上限；图片元素在显示边界统一转换媒体 URL，原始路径仍交给项目文件放置服务。
- 默认目录模型为 `kie-gpt-image-2`，密钥仍由用户配置；类型和媒体校验只读模型目录，不在 UI 写模型私有分支。
- `document.ts` 仅增加 media.codeImageGeneration 可选完成来源字段，schema 在独立 core 模块；记录提示词、模型、任务、结果序号、原序列/片段/源码版本/参数归属，避免候选重开丢失。不改作者语言、片段 code 模型或渲染器。
- 正式生成任务持久登记于生成历史；界面浮层关闭和工作区切换不取消后台任务，原剪辑活动持有防止被自动回收。异常退出后可从原生成历史恢复图片并通用绑定，不自动重放付费请求；本轮未增加异常退出后的自动绑定恢复。
- 新浮层附属于现有剪辑参数 Surface；新增业务来源在现有媒体字段定义中登记为只读，由同源反射公开。生成、等待、取消及参数读写全部已有公共能力覆盖，不新增专用绑定工具。
