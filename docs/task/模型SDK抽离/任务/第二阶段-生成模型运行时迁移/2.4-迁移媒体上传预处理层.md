# 2.4 迁移媒体上传预处理层

## 任务目标

把媒体上传预处理层迁入 SDK：协议部分（识别媒体字段、上传到供应商、回填 URL）进包，读取本地字节部分抽成 `MediaReader` 接口由宿主实现。这是第二阶段唯一需要真正拆分而非平移的模块。

## 当前情况

| 文件 | 行数 | 依赖 | 说明 |
|---|---|---|---|
| `upload.ts` | 444 | `node:fs`、`node:path`、`../keystore`、`../logging` | 主入口 `preprocessRequestBody`，遍历请求体、识别媒体值、上传、回填 |
| `upload-providers.ts` | 125 | `node:buffer` | `uploadToFal` / `uploadToApiMart` / `uploadToKie` / `toDataUri` / `toBase64` |
| `media-fields.ts` | 149 | 无（**任务 2.2 已迁移**） | 媒体字段识别 |

伴随测试：`upload.test.ts`（4 用例）、`upload-providers.test.ts`（7 用例）。

`upload.ts` 的内部结构（实测函数清单）：

- `preprocessRequestBody(providerId, route, body, params, constraints, requestId)` —— 主入口
- `resolveUploadStrategy` / `buildPublicUrlUploadCandidates` / `matchPublicUrlProvider` —— 上传策略，`PUBLIC_URL_UPLOAD_PROVIDERS = ['kie']`、`UPLOAD_PROVIDER_PRIORITY = ['kie', 'fal']`
- `preprocessFieldValue` / `rewriteMediaSource` —— 递归遍历与改写
- `preprocessPpioWan27ReferenceMediaObject` —— **模型专属特例**，PPIO Wan 2.7 的参考媒体对象
- `uploadFalFile` / `uploadApimartImage` / `uploadForHostedUrl` / `uploadForPublicUrl` —— 上传路径
- `prepareMediaBinary(source, mediaKind)` —— **唯一的 fs 使用点**，读本地文件或解析 `data:` URI
- `parseDataUri` / `inferMimeFromPath` / `defaultFilename` —— 辅助
- `warnUnresolvedLocalMedia` —— 发请求前把漏配的媒体字段打日志

**跨模块耦合**：`electron/main/services/llm/runtime.ts:2` 也 import 了 `preprocessRequestBody`。本任务改造后 LLM 侧调用点必须同步更新，否则主进程编译失败。

**`node:buffer` 的用途**：`upload-providers.ts` 的 `toBase64`。需要换成可移植实现（`btoa` + 字节转换，或手写 base64 表）——UXP 与浏览器环境没有 `Buffer`。

## 实施方案

按「协议 vs 字节来源」切开：

- **进 SDK**：字段识别、上传策略、上传实现、URL 回填、`data:` URI 解析、mime 推断、特例处理。
- **进 `MediaReader`**：只有 `prepareMediaBinary` 里读本地文件那一段。`data:` URI 的解析不需要宿主参与，留在 SDK。

`preprocessPpioWan27ReferenceMediaObject` 这类模型专属特例随协议一起进 SDK。它正是「不能做成声明式配置」的证据（见 [重要记录.md](../../重要记录.md) 记录 007），迁移时在函数上方补一条注释说明这一点。

`toBase64` 用不依赖 `Buffer` 的实现替换，并加测试覆盖二进制边界（含 0x00、0xFF、非 ASCII）。

## 风险与回退

**主要风险**：`prepareMediaBinary` 从同步改异步，向上传播的范围可能超出预期。缓解：先用 `npx tsc` 找出全部受影响调用点，改完再跑测试。

**次要风险**：`toBase64` 替换后若分块逻辑有误，表现为大文件上传损坏且不报错。缓解：测试必须覆盖大于 64KB 的输入并比对结果。

**回退方式**：`git revert` 该提交。
