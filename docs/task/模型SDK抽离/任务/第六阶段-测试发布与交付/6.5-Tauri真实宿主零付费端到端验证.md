## 任务目标

在真实 macOS Tauri 2 WebView + Rust HTTP 插件宿主中，使用当前发布版 `@henjicc/ai-sdk` 与本地 loopback fixture server，零外部供应商请求、零真实密钥、零费用地跑通一条完整生成 create → poll → result 链路和一条多 chunk SSE LLM 对话链路，补齐 [01-实施方案.md](../../01-实施方案.md) 第九节唯一尚未满足的非 Electron 真宿主验收项。

## 环境与授权前提

- 用户执行时明确改用 `/Users/henji/Documents/VibeCode/say-it`。该项目复用 Tauri 2.11、Vite 6 与 macOS WebView 环境；验证在 detached worktree 内搭建可删除的最小 Tauri test crate，不改造 say-it 产品功能。
- 不得改造该项目的产品功能。验收 harness 应隔离、可删除，且修改前必须读取该项目自己的 `AGENTS.md`/规则并保留其未提交改动。
- 只允许访问 `127.0.0.1`/`localhost`。禁止读取 Henji-AI 已配置密钥，固定使用假 key；任何非 loopback 最终目标必须 fail closed。
- 禁止真实供应商请求与付费调用。本任务不需要新增付费授权。
- 若相邻项目状态不允许安全接线，可在仓库外临时目录创建最小 Tauri 2 harness，但仍必须是真实 WebView + Rust HTTP 插件运行，不能用 Node、浏览器或仅 `cargo check` 替代。
- UXP 当前缺少可启动 Photoshop 与 UXP Developer Tool，不作为本任务首选；若环境恢复，可用 UXP 真宿主完成同等验收。

## 实施步骤

1. 在真实 Tauri 宿主安装并锁定当时最新已发布的 `@henjicc/ai-sdk`，记录 registry 版本、完整性与干净安装证据。
2. 建立仅监听 loopback 的 fixture server，并以进程级网络白名单拒绝一切非回环目标。
3. Generation 使用 SDK 真实 KIE catalog、builder、provider 与 polling：测试 Transport 只把 KIE 的创建与查询 URL 精确映射到 loopback，实际传输仍走 `@tauri-apps/plugin-http`；fixture 先返回 taskId，再返回 waiting/success 与 `resultJson`。
4. LLM 直接把公开 `baseUrl` 指向 loopback `/v1/chat/completions`，fixture 分多次延时写出 SSE content/reasoning/usage/`[DONE]`，验证真实 Rust IPC 分块与 SDK parser。
5. 输出机器可读结果，至少包括原目标、映射目标、请求次数、create body 摘要、poll 次数、最终 URL、SSE event 顺序和外网拒绝计数；不得输出 Authorization。
6. 验证取消：Tauri `AbortSignal` 能终止正在等待的 poll 或 SSE body；取消后不得再次 create。
7. 更新本任务、总览、01 第九节第 10 项与交接文件；只有两条链路都在真实宿主成功后才可勾选并宣布整个模型 SDK 抽离计划全部满足。
