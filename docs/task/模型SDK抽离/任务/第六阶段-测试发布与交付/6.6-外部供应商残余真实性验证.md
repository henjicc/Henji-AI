# 6.6 外部供应商残余真实性验证

## 任务状态

- 前置任务：6.5、用户新增外网/费用授权
- 关联任务：3.2、3.3、5.2、6.3、6.4

## 任务目标

只收口现有 README 与 6.3 真实性证据仍未逐项覆盖、且必须依赖新的外部供应商环境或费用授权的两组边界：四个历史 builder override 模型的真实供应商端到端，以及设置页供应商连通性/余额真实验证。不得借本任务扩大为第二轮 KIE/LLM 示例、Fal 上传、取消或错误 Key 请求。

## 授权、凭据与费用前提

- 开始前必须由用户重新明确授权本任务的真实外网请求和最高费用；6.3 已消费的 KIE/LLM 单次授权不能沿用。
- 需要可用且余额足够的 `fal`、`kie`、`apimart`、`ppio` 凭据；凭据只从正式 keystore 读取，不输出、不写 fixture、不进入提交。
- 四个生成模型各只允许一次付费 create，固定生成一张、最小规格；按当前 catalog 上限合计 **USD 0.1275**：Fal Seedream v4 `$0.03`、Fal Seedream v4.5 `$0.04`、KIE Seedream 4.0 `$0.025`、KIE Seedream 4.5 `$0.0325`。若供应商页面显示价更高，执行前停止并重新取得授权。
- 连通性/余额只允许 `GET`：KIE 1 次、PPIO 1 次、APIMart 最多 5 次（4 个 fallback 域名，只有最后一个安全预连接失败可重试一次），预计不计生成费用。不得调用 Grsai 未确认的 POST 余额接口。
- 任何付费 create 收到服务端 taskId 后只允许轮询同一任务；**禁止重试或再次创建**。超时、网络失败、未知响应、余额不足、鉴权失败或首次 create 结果不明确时立即停止并保留首个失败。
- 首轮按 Fal 4.0 首败停止后，用户以“授权收口”新增了一个独立执行边界：Fal 4.0 最多再 create 1 次 `$0.03`，仅其 completed 后 Fal 4.5 最多 create 1 次 `$0.04`，新增上限 `$0.07`、累计上限 `$0.1575`；KIE/APIMart 各追加 1 次只读 GET 用于正式 real-profile 余额截图；全部最终门禁与 Fal 修复真实验证通过后，允许私有 `0.1.3` 唯一一次发布。

## 验证对象

| 模型 | SDK id | 供应商 | 单次目录估价上限 | 必验边界 |
|---|---|---|---:|---|
| Seedream 4.0 | `fal-ai-bytedance-seedream-v4` | Fal | `$0.03` | 真实 selector/builder、智能比例/输入分支、返回 URL |
| Seedream 4.5 | `fal-ai-bytedance-seedream-v4.5` | Fal | `$0.04` | 真实 selector/builder、智能比例/输入分支、返回 URL |
| Seedream 4.0 | `kie-seedream-4.0` | KIE | `$0.025` | 真实 create/poll、text/edit route、结果 URL |
| Seedream 4.5 | `kie-seedream-4.5` | KIE | `$0.0325` | 真实 create/poll、请求字段、结果 URL |

连通性/余额对象固定为 SDK 当前有正式 probe 的三家：KIE `GET /api/v1/chat/credit`、APIMart `GET /v1/balance`（最多四域名 + 一次安全重试）、PPIO `GET /openai/v1/models`。KIE/APIMart 必须核对余额字段与设置页展示；PPIO 只验证连通性，不冒充余额接口。
