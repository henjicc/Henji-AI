## 任务目标

产出让**没有本仓库上下文的人**能照做成功的接入指南，并提供三个运行时（Electron / Tauri / UXP）的适配器实现与最小可运行示例。这是整个计划兑现「其他项目零成本复用」的最后一步。

## 当前情况

- 任务 1.1 已验证 UXP 与 Tauri 的运行时约束，产出了 8 项能力清单——本任务的适配器实现必须以那份清单为准，不能凭想象写。
- 任务 5.3 已在 `packages/ai-sdk/examples/form-renderer/` 写了最小表单渲染器（用于验证参数契约），本任务把它完善成可用示例。
- 痕迹AI 主进程的 `electron/main/services/ai-runtime/sdk-runtime.ts`（2.1 建立）是现成的 Electron 适配器参考实现。
- 用户的 Tauri 项目与 UXP 插件项目是否已存在，**待确认**（见任务 1.1）。若不存在，示例用最小空白工程。

### 各运行时的适配差异（来自 1.1 的验证结论，执行时以实际记录为准）

| 能力 | Electron | Tauri | UXP |
|---|---|---|---|
| Transport | 全局 `fetch`（主进程） | `@tauri-apps/plugin-http` 的 `fetch` | UXP `fetch` + manifest 网络白名单 |
| CredentialStore | Electron safeStorage | Tauri store 插件或 Rust 侧 | UXP SecureStorage（Adobe 说明数据可能丢失，需允许用户重填） |
| MediaReader | `fs.readFileSync` | Tauri fs 插件 | 从 Photoshop 文档导出图层字节 |
| Logger | 项目日志体系 | 自定 | 自定或 no-op |

## 实施方案

指南分三层，避免一份大而全的文档谁都读不完：

1. **快速开始**（README 主干）：5 分钟内跑通一次生成，只讲最小路径。
2. **运行时适配指南**：三个环境各一节，讲清 4 个接口怎么实现、各环境的坑。
3. **参考**：参数类型对照表（5.3 已写）、扩展新供应商/新类型（5.1 已写）、错误码表。

示例代码必须**真的能跑**，不是文档里的伪代码。每个示例一个目录，含 `package.json` 与运行说明。

**验证方式**：指南写完后，找一个「没有本对话上下文」的执行者（新会话的 AI 或用户本人）照着做一遍，能跑通才算通过。这条不能靠作者自己觉得清楚。

## 执行步骤

1. 重写 `packages/ai-sdk/README.md` 主干：
   - 这个包是什么、解决什么问题
   - 快速开始（安装 → 提供 4 个接口 → 调一次 `generate`）
   - 支持的供应商与模型数量总览（8 个供应商 / 99 个生成模型 / 7 个 LLM 供应商预设）
   - 目录：链接到各分节文档
2. 写 `packages/ai-sdk/docs/接入指南/Electron.md`：以 `sdk-runtime.ts` 为蓝本，讲清主进程/渲染层分工与 IPC 边界。
3. 写 `packages/ai-sdk/docs/接入指南/Tauri.md`：`@tauri-apps/plugin-http` 的 fetch 用法、URL 许可配置、密钥存储方案、流式响应的支持程度（以 1.1 结论为准）。
4. 写 `packages/ai-sdk/docs/接入指南/UXP.md`：manifest 网络权限配置（列出全部供应商域名）、SecureStorage 的限制与「必须允许用户重填密钥」、打包期必须 bundle 依赖、从 Photoshop 文档取图层字节的方式。
5. 写 `packages/ai-sdk/docs/接入指南/错误处理.md`：4.3 统一后的错误码表，每个错误码对应的用户可读提示建议。
6. 完善示例（`packages/ai-sdk/examples/`）：
   - `minimal-node/`：Node 环境跑通一次 KIE 图片生成（最容易验证，不需要 GUI）
   - `form-renderer/`：从 5.3 延续，用目录契约自动生成参数表单
   - `llm-chat/`：跑通一次 LLM 流式对话
   - 每个示例含 `README.md` 说明如何填密钥与运行
7. 列出全部供应商域名清单（供 UXP manifest 与 Tauri URL 许可使用），放进 `packages/ai-sdk/docs/接入指南/供应商域名.md`。已知：`api.kie.ai`、`api.apimart.ai`、`api.apib.ai`、`api.aiuxu.com`、`api.aishuch.com`、`grsaiapi.com`、`grsai.dakka.com.cn`，以及 fal / ppio / modelscope / bailian / volcengine 的域名（执行时从各适配器源码中逐一提取，不得遗漏）。
8. 找一个无上下文的执行者照指南跑通 `minimal-node` 示例，记录卡点并回头修补指南。
