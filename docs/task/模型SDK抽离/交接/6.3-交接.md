### LLM 对话

- 供应商/模型：DeepSeek / `deepseek-v4-flash`，Base URL `https://api.deepseek.com`。
- 首次安全启动器 preflight 因默认 `Electron` identity 无法解密正式 `henji-ai` 密文而失败；
  `networkCalls=0`、无费用。修复后两个凭据的 `--check-credential` 均为 `networkCalls=0`。
- 调用次数：外网 `/chat/completions` POST **恰好 1 次**，耗时 909ms；没有重试或换模型。
- 结果：供应商流正常结束，但 16-token 上限下只产生 reasoning，`Token` 文本为空。
- 费用保守估算：`¥0.000615`（示例按字符数当 token、高峰输出价估算），实际以 DeepSeek 账单为准。
- 修补：示例现在对 DeepSeek 显式传 `reasoning: { enabled: false, effort: 'high' }`，并在无文本
  token 时明确失败；修补后的 build 和本地 SSE dry-run 通过。因用户只授权一次真实 LLM 对话，
  没有再次发起外网请求，故修补后的真实返回文本仍是明确的未复验边界。
