## 其他真实失败与修复

1. say-it 产品主 crate 首次编译在 `audiopus_sys` 失败：本机缺 `autoreconf`。这是产品音频依赖的构建前置，不属于 SDK。未安装系统工具；经授权改为 detached worktree 内可删除的最小 Tauri test crate。

3. 最小 crate 第一次 `generate_context!` 缺默认 icon。改为只读复用 say-it 现有 `src-tauri/icons/icon.png`，随后真实窗口启动。
4. 第一轮绿报告的 SDK 版本断言仍写 0.1.1，得到 false。修正为 0.1.2、增加“任一最终断言 false 即失败”，重启 fixture 后从零计数完整重跑，得到本交接记录的最终证据。

上述失败均保留，没有用最终通过覆盖首败。

## 能证明与不能证明

能证明：已发布 SDK 0.1.2 能在 say-it 所用的 macOS Tauri/Vite/WebKit 技术环境中，由真实 WebView 通过 Rust plugin-http IPC 完成生成、轮询、流式 LLM、usage parser 与取消；SDK 的网络依赖可由 Tauri Transport 注入，非 loopback 可在宿主白名单和 Transport 两层拒绝。
