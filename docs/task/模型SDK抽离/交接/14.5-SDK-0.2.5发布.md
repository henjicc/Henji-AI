## 公共契约

现有包根与 `@henjicc/ai-sdk/llm` 正式导出：

```ts
type LlmProviderSetup =
  | { kind: 'preset'; presetId: string; lifecycle: 'builtin' | 'user' }
  | { kind: 'custom'; apiKeyManagementUrl?: string }

const LLM_API_KEY_URL_MAX_LENGTH: 2048
normalizeLlmApiKeyManagementUrl(value: string): string
normalizeLlmProviderSetup(setup: LlmProviderSetup): LlmProviderSetup
resolveLlmProviderApiKeyUrl(provider: LlmProviderConfig): string | null
```

`createProviderFromPreset()` 的 options 新增可选 `lifecycle`，并在返回值显式写入稳定 `credentialId` 与 setup；`createBigmodelProvider()` 同样接受可选 lifecycle。BigModel cn/global 的 provider family、endpoint profile 和 credential slot 隔离保持不变。

API Key URL 的解析顺序固定为 endpoint profile 官方地址 → preset 官方地址 → custom 可选地址。custom 仅接受长度不超过 2048、无内嵌账号密码的绝对 HTTP(S) URL；`javascript:`、`file:`、相对地址和超长地址均拒绝。

这是兼容性补丁：新增字段与工厂参数均为可选，没有删除导出、修改现有参数或改变 24 个公开入口；0.2.4 消费代码无需迁移。SDK 不包含 14.2/14.4 的 Electron 事务、IPC 或 UI 实现。
