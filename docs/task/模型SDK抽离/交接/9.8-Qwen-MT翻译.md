# 9.8 Qwen-MT 翻译交接

> 完成时间：2026-08-28
> 范围：`packages/ai-sdk` 的百炼 Qwen-MT Flash / Plus / Lite 翻译模块与按需入口
> 资料基线：`交接/9.4-Say-It官方协议调研.md` 与包内三模型/百炼官方资料
> 网络边界：未发起真实百炼请求，未使用或写入真实密钥

## 1. 公共入口

- 新增按需入口 `@henjicc/ai-sdk/capabilities/translation/bailian`；通用
  `@henjicc/ai-sdk/capabilities/translation` 不会静态带入百炼实现。
- 三个工厂：`createQwenMtFlashTranslationModule()`、`createQwenMtPlusTranslationModule()`、
  `createQwenMtLiteTranslationModule()`；也可用 `createBailianQwenMtTranslationModule(modelId)`。
- 稳定模型 ID：`qwen-mt-flash`、`qwen-mt-plus`、`qwen-mt-lite`。模块只在宿主显式注册后可用，
  不会让所有 SDK 消费方自动安装或启用翻译模型。
- `TranslationOutput` 增加可选 `usage`；事件增加 `usage`，`delta` 增加可选
  `mode: append|replace` 和 `accumulatedText`。原有只读取 `delta.text` 的实现仍可编译，但接入方应按
  `mode` 处理供应商改写前缀的边界。

## 2. 请求与流式语义

- 默认调用百炼 OpenAI 兼容 `POST /compatible-mode/v1/chat/completions`，完整地址可由宿主替换为
  区域/Workspace 专属地址。
- 请求只发送官方已确认字段：`model`、单条 User Message、`translation_options`、`stream`；流式时
  增加 `stream_options.include_usage=true`。没有发送未经核实的 `max_tokens` 或独立输出上限。
- `sourceLanguage` / `targetLanguage` 支持 Say-It 当前语言代码到官方英文语言名的映射；`auto` 保留，
  未知语言名原样透传，避免封死未来语言扩展。
- `terminology` 映射为 `terms`；`options.translationMemory` 映射为 `tm_list`；通用 `context` 映射为
  官方英文领域提示 `domains`。未知 option 明确报错，不会静默丢字段。
- Flash / Lite 的官方流是增量片段；Plus 是累积序列。SDK 将正常序列统一成可追加 delta，Plus 若
  改写已有前缀则发 `mode=replace`，最终 `item` 和 `completed` 始终带完整译文。
- SSE 使用供应商无关的包内 UTF-8 增量解码器，不依赖宿主提供 `TextDecoder`，覆盖多字节字符和
  SSE 分隔符跨 chunk。

## 3. 宿主边界与错误

- 网络只走 `RuntimeContext.transport.fetch`，密钥只从
  `RuntimeContext.credentials.get('translation', 'bailian')` 读取。
- 日志和 trace 只记录 requestId、providerId、modelId、批次索引和 token 数；不记录密钥、原文或译文。
- 用户取消和超时由 capability client 的统一 AbortSignal 收口；401/403、429、5xx、请求错误、响应
  JSON/SSE 错误和供应商 payload 错误均归一为稳定 `AiRuntimeError`。
- 批量输入按顺序执行，保留稳定 id，usage 跨条目汇总；当前没有自行增加并发，避免宿主失去限流控制。

## 5. Say-It 接入输入

```ts
import {
  createCapabilityClient,
} from '@henjicc/ai-sdk/capabilities'
import {
  createQwenMtFlashTranslationModule,
} from '@henjicc/ai-sdk/capabilities/translation/bailian'

const module = createQwenMtFlashTranslationModule()
const client = createCapabilityClient({ runtime, modules: [module] })
```

1. Say-It 的 Rust/Tauri 宿主提供 HTTP transport、百炼翻译密钥、取消、超时、logger 和 tracer；前端与
   插件不直接持有 Key 或自行请求百炼。
2. 现有语言代码可直接传给 SDK；现有术语表传 `terminology`，若有句对翻译记忆则传
   `options.translationMemory`。不要在 Say-It 再复制语言或请求映射。
3. UI 的增量展示优先使用 `accumulatedText`；若消费 `text`，`mode=append` 时追加，`replace` 时替换。
   完成时以 `item.text` / `completed.output` 为最终真相。
4. 可以只注册一个模型，也可以按用户设置注册三者；不需要加载 ASR、Groq 或生成模型。
5. SDK 新版本发布并升级 Say-It 依赖后再接正式宿主桥。本任务没有修改 SDK 版本，也没有修改 Say-It。

## 6. 未做与明确边界

- 百炼官方资料没有给三模型独立、可稳定引用的最大输出 token 数，本实现不猜值、不设上限、不发送
  `max_tokens`；若以后官方明确，再由模型资料和测试同步补充。
- 未做真实网络、付费、区域/Workspace、账号权限、真实术语效果、真实限流或账单验证；这些需后续经
  用户授权，在 Say-It 宿主接入完成后用用户密钥验收。
- 未实现百炼实时 ASR、Groq、Say-It 宿主桥或 UI；ASR 的短音频/文件能力已由独立任务落在
  `@henjicc/ai-sdk/capabilities/speech-recognition/bailian`，两者互不隐式导入。
