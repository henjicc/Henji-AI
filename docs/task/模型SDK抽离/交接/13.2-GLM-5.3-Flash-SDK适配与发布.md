# 13.2 GLM-5.3-Flash SDK 适配与发布交接

## 结论

- SDK 版本：`@henjicc/ai-sdk@0.2.4`
- 公开按需入口：`@henjicc/ai-sdk/llm/bigmodel`
- 中国大陆继续使用存量 `providerId=bigmodel`，默认 `endpointProfile=cn`、
  `credentialId=bigmodel`、`https://open.bigmodel.cn/api/paas/v4`。
- 国际站使用独立配置实例 `providerId=bigmodel-global`，但协议族仍是
  `providerFamilyId=bigmodel`；固定 `endpointProfile=global`、
  `credentialId=bigmodel-global`、`https://api.z.ai/api/paas/v4`。
- 两区不做密钥互通假设，不回退、探测或复用另一地区凭据；端点、profile、credential 任一错配会在网络前拒绝。

## 公共 API

按需入口导出：

- `createBigmodelProvider({ endpointProfile?: 'cn' | 'global', providerId?: string })`
- `createBigmodelModels(provider)`
- `resolveBigmodelIdentity(provider)`
- `BIGMODEL_ENDPOINT_PROFILE_FAMILY`
- `BIGMODEL_GLM_5_3_FLASH_PRICING`
- 两区 profile、credential 与 provider family 常量

通用 LLM 配置/请求新增可选字段 `providerFamilyId`、`endpointProfile`、`credentialId`。
旧 `bigmodel` 配置省略新增字段时仍固定解析为国内；稳定实例 id `bigmodel-global` 即使宿主漏存新增字段，
也会保守恢复为 Global profile，避免退化成任意兼容端点。

## GLM-5.3-Flash 能力边界

- 已登记：Chat Completions、text/image/video/file 输入、text 输出、普通 SSE、强制思考
  (`thinking.type=enabled` + `reasoning_effort=low/high/max`) 与普通 Function Calling。
- 文件只接受宿主已有 `fileUrl` 或 `fileData`，两者必须且只能填一个；SDK 不新增上传协议，拒绝 `file_id`。
- SSE 接受合法空 choices/空终态，保留开放 finish reason，并按 index 拼接工具调用分片。
- 显式关闭/不声明：audio、parallel tools、structured output/`response_format`、`tool_stream`。
- 官方没有确认图片、视频、文件任意混合，本次不声明跨模态混合能力，也不添加猜测性请求分支。

## 13.3 消费项目更新输入

消费项目必须原样持久化并传入 `providerFamilyId`、`endpointProfile`、`credentialId`；不要只按
`providerId` 推导端点或共享密钥。建议直接从 `llm/bigmodel` 调 `createBigmodelProvider()` 与
`createBigmodelModels()`，不要复制 URL/价格表。

需要检查/更新的消费边界：

1. LLM 配置存储与 IPC/QuickJS DTO 不得丢弃三个新增身份字段。
2. 凭据设置为 `bigmodel` 与 `bigmodel-global` 两个独立槽，迁移不得复制现有国内密钥到 Global。
3. 模型选择列表允许同一个 `glm-5.3-flash` 出现在两个不同 provider 实例下，唯一坐标仍是 provider/model。
4. `file` 能力只连接宿主已有媒体/文件引用；不要据此新增 Files API 上传或 URL 文本输入框。
5. 若展示价格，读取 profile 分区常量并标明币种、促销观察时间与 Global 截止时间。
