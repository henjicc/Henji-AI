## 示例入口与行为

### minimal-node

- 使用 `@henjicc/ai-sdk/generation` 与 `@henjicc/ai-sdk/runtime`。
- 保留完整 generation catalog、KIE `z-image` dry-run/live 闸门和取消语义。
- `npm run dry-run` 输出 `networkCalls=0`、一次本地拦截请求、`pending` 与 `dry-run-task`，估价仍为 `$0.004`。

### llm-chat

- 从包根 `createAIClient()` 改为 `@henjicc/ai-sdk/llm/streaming` 的 `runLlmChatStream()`。
- dry-run 仍解析本地 SSE fixture，输出 `SDK OK`，不访问外网。
- 取消方式改为保存 `resolveLlmTaskId(request)` 的结果并调用 `cancelLlmChatTask(taskId)`；按需入口没有客户端实例需要 dispose。
- 新增 `npm run check:bundle` 永久门禁，拒绝 generation、catalog、完整根 client、capabilities、Groq、LLM modules，以及 BigModel preset/models/pricing。共享端点身份解析需要的 BigModel profiles 明确保留。

### form-renderer

- 使用 `@henjicc/ai-sdk/generation`、`@henjicc/ai-sdk/catalog` 与 `@henjicc/ai-sdk/runtime`。
- 保留完整 generation catalog 和五类差异模型的参数/媒体表单输出；不带 LLM/BigModel。
- 继续保持零网络、无 DOM、无框架的最小 renderer 定位。
