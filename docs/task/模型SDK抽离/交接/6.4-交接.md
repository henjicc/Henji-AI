## 首个失败与根因修复

最终清理后的首个真实 L3 失败是 `electron:build`：`runner.test.ts` 仍从已删除的 `../../llm/sdk/provider-error` 导入。根因是第一次引用搜索覆盖了生产调用而漏掉一条跨目录测试相对导入；把它改成 SDK 包根导入，并扩大删除前搜索范围后，完整 build 重跑通过。
