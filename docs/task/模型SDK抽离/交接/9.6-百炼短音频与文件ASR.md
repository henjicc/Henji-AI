- 实现本地字节/宿主媒体引用/Data URI、公网 HTTP(S) URL、官方临时 OSS 上传、异步提交/轮询/结果下载、句词时间戳与时长归一化。

- 新增 ASR `processing` 事件，文件任务可上报 `PENDING/RUNNING`；请求级 Abort/timeout、日志、凭据继续复用 9.5 client/runtime。

## 公共 API

```ts
import { createCapabilityClient } from '@henjicc/ai-sdk/capabilities'
import {
  createBailianAsrModule,
  bailianFunAsr,
  bailianFunAsrFlash20260615,
  bailianQwen3AsrFlash,
  bailianQwen3AsrFlash20260210,
  bailianQwen3AsrFlashFiletrans,
  bailianNonRealtimeAsrPresets,
} from '@henjicc/ai-sdk/capabilities/speech-recognition/bailian'

const client = createCapabilityClient({ runtime })
client.register(createBailianAsrModule(bailianQwen3AsrFlash))
```

`createBailianAsrModule(preset, options?)` 的配置边界：

- `apiBaseUrl`：DashScope `/api/v1` 或用户工作空间同结构根路径。
- `compatibleBaseUrl`：Qwen 短音频 `/compatible-mode/v1` 根路径。
- `uploadBaseUrl`：临时上传凭证根路径，默认固定为 `https://dashscope.aliyuncs.com/api/v1`，不会误跟随工作空间端点。
- `pollIntervalMs/maxPollingMs`：文件转写轮询策略；外层 `CapabilityExecuteOptions.timeoutMs` 仍可作为整个请求的总上限。

输入支持：

- `{ kind: 'bytes', bytes, mediaType, filename? }`
- `{ kind: 'media-ref', ref, mediaType? }`，由宿主 `MediaReader` 给出字节
- `{ kind: 'remote-url', url, mediaType?, filename? }`，短音频只接受 HTTP(S)，文件异步接受 HTTP(S)/`oss://`

凭据读取固定为 `credentials.get('speech-recognition', 'bailian')`。HTTP、媒体、日志和 Abort 全部由 RuntimeContext 注入；源码无 Node/Electron/Tauri 反向依赖。

## 协议与归一化要点

- Fun 短音频发 `X-DashScope-SSE: enable`；解析累计 `output.text`、单对象或数组形态的 `output.sentence`、`usage.duration`，并对同起点的重复定稿句做前缀去重。
- Qwen 短音频走官方推荐 OpenAI 兼容端点，支持顶层 `choices`，同时容忍 DashScope 备用协议的 `output.choices`。
- `fun-asr` 使用 `input.file_urls`；Qwen filetrans 使用 `input.file_url`。本地输入先按模型 ID 获取临时上传策略，校验 HTTPS upload host 和 `max_file_size_mb`，multipart 的文件字段最后追加，再以 `oss://` 调用并带 `X-DashScope-OssResourceResolve: enable`。
- 轮询只接受 `PENDING/RUNNING/SUCCEEDED/FAILED/UNKNOWN` 生命周期；顶层 `SUCCEEDED` 后仍检查 `results[].subtask_status`，不会把子任务失败误报为成功。
- `transcription_url` 必须为 HTTPS；下载后归一化 `durationMs/segments/words/startMs/endMs`，URL、密钥和 Authorization 不写普通日志。

## 9.7 实时 ASR 输入

- 可复用：5 个 preset 的命名方式、provider/scope、RuntimeContext、`SpeechRecognitionEvent`/输出归一化、媒体格式字段与错误码。
- 不可复用成“只换模型 ID”：Fun-ASR 实时 WS 与 Qwen3-ASR Realtime 的握手、事件和会话复用规则不同，应各自实现 `SpeechRecognitionRealtimeModule`。
- 9.7 需要宿主提供 `RuntimeContext.realtime`：
  - Fun：`run-task → task-started → binary/result-generated → finish-task → task-finished`，成功连接可按官方规则复用。
  - Qwen：`session.update → input_audio_buffer.append/(commit) → session.finish → session.finished`，每会话断开。
- 二进制音频块通过 `SpeechRecognitionAudioChunk` 传入；不要在 SDK 内访问麦克风、文件系统或原生 WebSocket。
- 必测实时边界：握手失败、事件乱序/未知事件、partial/final 去重、背压、外部 Abort、请求 timeout、远端关闭、finish/close/dispose 幂等。

## 已知边界

- 本任务按要求未发起真实网络/付费请求；OSS 表单、异步轮询和结果结构基于 9.4 官方资料、官方示例及 Say-It 既有 Rust 行为对照。
- Fun 短音频官方允许很大的 URL 文件，但内联 Data URI 主动限制为 10 MiB；更大输入应使用公网 URL。异步文件模型仍以官方模型上限和上传策略返回上限为准。
- Abort 会停止本地上传/请求/轮询；官方资料未提供已提交异步任务的远端取消端点，因此不会伪造“远端任务已取消”。
- 结果签名 URL 仅用于立即下载，SDK 不负责长期持久化；Say-It 宿主在 9.12 接入时应保存归一化结果，而不是保存签名 URL。
