# 8.4.1a · APIMart 渠道与 Photoshop 官方契约对齐交接

## 交付边界

- SDK 版本：`@henjicc/ai-sdk@0.1.6`（GitHub Packages version ID `1179472807`）。
- 只修改 Henji-AI；`henji-ai-ps` 仅作为旧契约读取来源。
- 未发送任何真实生成或付费请求。
- 取舍原则：SDK 表达供应商官方合法能力；插件旧值若违反官方 schema，插件删除或迁移，不在 SDK 伪造兼容。

## APIMart 三个 Nano Banana 渠道

Photoshop 的 `options.channel` 值保持 `standard | official`，adapter 映射如下；渠道只决定 SDK 参数和最终 `model`，不进入请求 body：

| 插件模型 | SDK 模型 | adapter 参数 | standard（默认） | official |
|---|---|---|---|---|
| `apimart-nano-banana-2` | 同 ID | `apimartNanoBanana2Channel` | `gemini-3.1-flash-image-preview` | `gemini-3.1-flash-image-preview-official` |
| `apimart-nano-banana-2-lite` | 同 ID | `apimartNanoBanana2LiteChannel` | `gemini-3.1-flash-lite-image-ext` | `gemini-3.1-flash-lite-image` |
| `apimart-nano-banana-pro` | 同 ID | `apimartNanoBananaProChannel` | `gemini-3-pro-image-preview` | `gemini-3-pro-image-preview-official` |

三个参数均为第一顺位 `role: 'channel'`，字段名走 `sharedFieldText('apiChannel')`，默认 `standard`，因此 0.1.5 未传渠道的调用完全保持 EXT 行为。两渠道路由均为 `POST /v1/images/generations`，body 结构相同；官方渠道不发送 `official_fallback`。

当前估价：Nano 2 常规 0.5K/1K `$0.015`、2K `$0.02`、4K `$0.025`，官方 `$0.0536/$0.0808/$0.1208`；Lite 常规 `$0.0125`、官方 `$0.032`；Pro 常规 1K/2K `$0.03`、4K `$0.04`，官方 `$0.1072/$0.192`。官方渠道实际按 token 结算，SDK 使用 APIMart 模型页当前单张估算。

## Photoshop adapter 参数映射

| Photoshop 旧语义 | SDK 参数 | 迁移说明 |
|---|---|---|
| APIMart Nano `options.channel` | 上表三个 channel 参数 | 原值 `standard/official` 原样传入 |
| Fal Seedream 5 Pro ratio + 约 1MP | `falSeedream50ProAspectRatio` + `falSeedream50ProResolution: '1MP'` | 支持 COMMON10；默认不传仍是 SDK 2K |
| Fal Seedream 5 Lite ratio + 约 1MP | `falSeedream50LiteAspectRatio` + `falSeedream50LiteResolution: '1MP'` | Fal 会把低于官方下限的 1MP 请求自动放大；新 UI 建议 2K 起 |
| Fal Qwen Image 3 ratio + 约 1MP、关闭扩写 | `falQwenImage30AspectRatio` + `falQwenImage30Resolution: '1MP'` + `falQwenImage30PromptExpansion: false` | 文生图发送 1MP 对象；编辑按官方契约省略 `image_size`。透明 PNG 合成不透明 JPEG、384–2048 边的处理仍由 UXP adapter/MediaReader 完成 |
| Fal GPT Image 2 ratio + 约 1MP + quality | `falGptImage2AspectRatio` + `falGptImage2ImageSize: '1MP'` + `falGptImage2Resolution` | 历史 ID `falGptImage2Resolution` 为兼容不改名，但语义是 `quality`；支持 `auto/low/medium/high`，不得把其他值静默映射为 low |
| Fal Z-Image 约 1MP | `falZImageTurboImageSize: '1MP'` | 比例仍走 `falZImageTurboAspectRatio`；默认 `provider` 保持 SDK 旧长边 1K/2K 语义 |

## 必须从 Photoshop 删除或收窄的旧值

- APIMart Seedream 5 Pro/Lite 官方只支持 `1:1,4:3,3:4,16:9,9:16,3:2,2:3,2:1,1:2,21:9`。插件旧 COMMON10 中的 `4:5/5:4` 必须移除；SDK 对列表外值显式报错，不再静默回退 1:1。
- APIMart Midjourney edit 官方与 SDK 上限是 6 张，不是插件旧值 8；插件 UI/校验改为 1–6。
- APIMart Z-Image Turbo 的 prompt 官方硬上限 800 字符；插件增加前置限制/报错，不能依赖请求端无声截断。
- Fal Flux Pro Erase 的 `output_format` 按项目全局约定不暴露、不发送；插件移除旧 jpeg/png 选择，SDK 0.1.5 工具契约不变。

## 核证后无需改变 SDK 的差异

- APIMart GPT Image 2 official 在图生/编辑都正式支持 `quality`、`background`、`nsfw_check`，SDK 显式发送其官方默认值是合法等价行为。
- Fal Nano Banana 2 的 `num_images=1`、`limit_generations=true`、`enable_web_search=false` 均为官方默认；Nano Banana Pro 同类显式默认合法，不需要“最小 body”分支。
- APIMart Z-Image Turbo 当前 SDK 的 800 字符限制与 `prompt_extend=false` 默认符合官方文档。
