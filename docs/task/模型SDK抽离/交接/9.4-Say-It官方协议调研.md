## 一、已核实的协议

### 1. 百炼 ASR

| 协议族 | Say-It 模型 | 官方端点/生命周期 |
|---|---|---|
| Fun-ASR 实时 WS | `fun-asr-realtime`、`fun-asr-realtime-2026-02-28` | `wss://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api-ws/v1/inference`；`run-task → task-started → binary/result-generated → finish-task → task-finished`；等完成可复用，失败不可复用 |
| Qwen3-ASR 实时 WS | `qwen3-asr-flash-realtime`、`qwen3-asr-flash-realtime-2026-02-10` | `wss://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api-ws/v1/realtime?model=<id>`；`session.update/append/(commit)/finish/finished`；每会话断开，不复用 |
| 短音频同步 | `fun-asr-flash-2026-06-15` | `POST /api/v1/services/aigc/multimodal-generation/generation`；URL/Data URI；5 分钟/2 GB；可 SSE |
| 短音频 OpenAI 兼容 | `qwen3-asr-flash`、`qwen3-asr-flash-2026-02-10` | `POST /compatible-mode/v1/chat/completions`（也支持 DashScope 同步）；URL/Base64；5 分钟/10 MB |
| 文件异步 | `fun-asr`、`qwen3-asr-flash-filetrans` | `POST /api/v1/services/audio/asr/transcription` + `X-DashScope-Async: enable`，`GET /api/v1/tasks/{task_id}`；12 小时/2 GB |

临时上传已核实：`GET https://dashscope.aliyuncs.com/api/v1/uploads?action=getPolicy&model=<exact-id>` 取凭证，multipart 上传到返回的 OSS host，组装 `oss://<key>`；模型/主账号绑定，48 小时过期，凭证接口 100 QPS，单文件通用上限 1 GB，但模型限制优先。

ASR 北京原价：非实时家族 0.00022 元/秒，实时家族 0.00033 元/秒。

### 2. Qwen-MT

`qwen-mt-flash/plus/lite` 共用 OpenAI 兼容 `/compatible-mode/v1/chat/completions` 或 DashScope `/api/v1/services/aigc/text-generation/generation`。只支持 User Message，必填 `translation_options.source_lang/target_lang`，支持术语、翻译记忆和领域提示。

- Flash/Lite 流式块是增量；Plus 流式块是累积序列。
- 北京原价（输入/输出，每百万 Token）：Flash 0.7/1.95 元，Plus 1.8/5.4 元，Lite 0.6/1.6 元。

### 3. Groq

- Chat：`POST https://api.groq.com/openai/v1/chat/completions`。
- 发现：`GET /openai/v1/models`、`GET /openai/v1/models/{model}`。
- 默认模型 `openai/gpt-oss-20b`：Production，131,072 上下文，65,536 最大输出，约 1000 tps，250K TPM/1K RPM，$0.075 输入/$0.30 输出（每百万 Token）。
- GPT-OSS 只支持 `reasoning_effort=low|medium|high`，默认 medium；**不支持 `reasoning_format`**；用 `include_reasoning` 控制 reasoning 字段是否返回。
- Groq Qwen3 的 `reasoning_effort=none/default` / `reasoning_format=parsed` 不能套到 GPT-OSS。

## 二、来源与不可核实边界

只使用官方主来源：`help.aliyun.com/zh/model-studio/**`、`console.groq.com/docs/**`。所有 API/价格页无需登录；两家 API Key/账单页需登录。

不可完整核实项：百炼 `machine-translation` 选型/语言页在本次访问时触发官方验证码，未读取正文。Qwen-MT API 页仅说 `max_tokens` 上限见选型页，因此三个模型的独立最大输出数未核实；文档明确标注了该缺口，未猜测。端点、请求字段、响应、流式差异和价格已分别从 Qwen-MT API 与官方价格页核实。

## 三、下一任务输入

1. SDK 供应商 ID 用 `bailian`，Say-It 历史 `funasr` 通过宿主兼容映射，不另建重复供应商。
2. ASR 需三种执行协议：可取消实时 WS、短音频同步 HTTP/SSE、文件异步上传+轮询+结果下载。Fun-ASR WS 和 Qwen3-ASR WS 事件系统不同，不得只换 model ID。
3. Qwen-MT 应是独立 translation capability，但复用 OpenAI 兼容传输；流式解析需标记 incremental/cumulative。
4. Groq 可复用 SDK OpenAI-compatible LLM provider，新增 `groq` preset、模型发现和 GPT-OSS 推理参数约束。
5. 全部能力按需注册；宿主可只选 ASR/翻译/LLM 中的某一类或某几个模型。
6. 实现任务完成单元/契约测试后，真实付费 ASR/翻译/Groq 请求及麦克风 WS 测试需使用用户密钥并再次明确记录授权/配合。
