## 结论

`@henjicc/ai-sdk@0.2.4` 的实际消费者同步已收口：Henji-AI 主宿主、Say-It、Photoshop UXP 与三个仓内示例均处于 0.2.4。外部宿主都精确锁定远端版本和官方 integrity；仓内示例精确声明远端版本、无 lockfile、无 workspace/file/link alias。

未来同步规则已接入：

- 唯一详细消费者事实表仍为 `packages/ai-sdk/docs/consumers.md`。
- SDK 发布后必须先读该清单，按公共导出、协议和宿主责任的实际影响逐个同步真实消费者。
- 未使用的新能力不进入宿主。
- 外部消费者必须精确锁定版本与 lock integrity，并回写 commit、验证状态、接入边界和核对日期。
- `docs/rules/model-adaptation.md` 只保留规则路由与硬要求；Codex/Claude 两份 `henji-model-adaptation` skill 保持字节一致，没有在 `AGENTS.md` 重复规则。
