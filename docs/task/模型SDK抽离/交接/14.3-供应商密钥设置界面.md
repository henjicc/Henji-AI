# 14.3 供应商密钥设置界面交接

更新时间：2026-08-28

## 结论

供应商管理已改为平铺字段布局，删除“当前编辑”头块与推荐模型重复说明；所有生产密钥输入继续复用唯一的 `ApiKeyInput`，眼睛按钮嵌入输入框右侧。自定义供应商可在同一次原子提交中保存供应商、独立 API Key 与可选密钥管理地址；内置供应商使用官方密钥入口和重置语义，不再显示虚假删除。

本次没有新增 Electron/preload/IPC，也没有扩大 WebView 或助手读取密钥的权限。设置 UI 仍只持有用户本次输入的临时明文，既有密钥不回显；提交后由 14.2 的高层事务与主进程凭据服务处理。

## 实现边界

- `src/components/Settings/components/ApiKeyInput.tsx`
  - 保持唯一公共密钥输入组件；现有全局 8 家、LLM 动态供应商、Onboarding 4 家因复用该组件自动统一。
  - `Eye` / `EyeOff` 通过 `UiIconButton` 内嵌右侧，输入预留右内边距；点击区、键盘按钮语义、禁用态、`aria-label`/`aria-invalid` 均保留。
  - 默认 `password` 不额外标敏感 DOM；切换为明文时输入节点增加 `data-observation-sensitive="true"`。
  - 可选密钥入口继续走正式 `useExternalLink`，没有 `window.open`。
- `src/components/Settings/sections/LlmProviderDialog.tsx`
  - 表单字段标签位于控件上方，不造卡片套卡片；删除/重置动作放在独立分隔行。
  - preset 名称、适配器与 API 地址按 SDK preset 真相只读展示；custom 名称可编辑，并增加 API Key 与可选密钥管理地址。
  - 新建时 API Key 可留空，表示先创建供应商、稍后配置；编辑时不回显旧值，留空明确提交 `unchanged`。
  - preset 使用 SDK 官方 `apiKeyUrl`；custom 只在配置有效 http/https 地址时显示入口，无地址不显示，危险协议由 SDK 规范化契约拒绝。
  - builtin 仅重置，custom 可删除；事务失败保留表单草稿并显示可理解错误。
- `src/components/Settings/hooks/useLlmSettings.ts`、`src/components/Settings/sections/LlmSettingsSection.tsx`
  - 管理弹窗保存/删除统一调用 14.2 的 `llmCommitProviderSettings` / `llmDeleteProviderSettings` 高层入口，不再由渲染层拼多次写入。
- `electron/main/services/llm/provider-settings.ts`
  - 修补接入高层事务后暴露的契约缺口：供应商身份字段变化时，同一 provider 的已有模型会在同一事务中同步 `providerFamilyId`、endpoint、credential、adapter、protocol 与 base URL；精确测试守住此行为。
- `src/i18n/locales/{zh-CN,en-US}/settings.json`
  - 新增供应商管理字段、动作、提示与失败文案。
- `scripts/lib/uiInspectionScenes.cjs`
  - 新增正式场景 `settings-llm-provider-manager`，在隔离临时数据中打开管理弹窗并切到新建自定义供应商，用于 UI 与 UI-audit 双门禁。

## 已知边界

- `npm run electron:build` 在进入 `electron-vite build` 前被 14.2 已记录的无关附件模态类型错误阻断：`attachment-context.ts` 两处与 `attachments.ts` 一处尚未把 `file` 纳入 `AgentInputModality`/限制表。本任务未越界修复；其余前置静态检查、SDK 构建和 152 个能力测试已通过，随后单独运行 `npx electron-vite build` 成功生成本次正式 Electron 验收所用产物。
- 未执行真实供应商网络或付费请求；本任务只验证设置、凭据事务契约和隔离数据下的真实 Electron 交互。
- 不新增二次删除确认弹窗；现有管理动作保持一次点击，并由高层事务负责失败回滚。若未来产品要求确认，必须复用正式 `AlertDialog`，不能手写第二套弹窗。
