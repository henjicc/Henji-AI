## 破坏性迁移

1. `CapabilityDescriptor.source` 现在必填：内置使用 `{ kind: 'builtin', namespace: '@henjicc/ai-sdk' }`；外部包和插件必须给出自己的稳定 namespace。
2. 百炼非实时 ASR module ID 从 `bailian.<modelId>` 迁移到 `bailian.speech-recognition.<modelId>`。SDK 不提供旧 ID alias。
3. providerId 统一为 `bailian` / `groq`；SDK 不提供 `funasr` provider alias。
4. module ID 与 `providerId/kind/modelId` 坐标现在拒绝重复注册；跨 generation、LLM、extension 的 discovery ID 冲突也会显式失败。
5. 具体供应商能力只从独立子路径按需导入；包根、通用 ASR/translation 入口不会隐式带入百炼或 Groq。

## Say-It 锁定输入

- 9.12 应锁定精确版本 `@henjicc/ai-sdk@0.2.1`，不要使用 `0.2.0`，也不要在迁移提交中使用版本范围。
- 对持久化 provider 一次性把 `funasr` 改为 `bailian`；对持久化非实时 ASR module ID 一次性执行 `bailian.<modelId>` → `bailian.speech-recognition.<modelId>`。SDK 内不要增加兼容 alias。
- 按需入口：
  - 非实时 ASR：`@henjicc/ai-sdk/capabilities/speech-recognition/bailian`
  - 实时 ASR：`@henjicc/ai-sdk/capabilities/speech-recognition/bailian/realtime`
  - Qwen-MT：`@henjicc/ai-sdk/capabilities/translation/bailian`
  - Groq：`@henjicc/ai-sdk/llm/groq`
- Say-It 的 HTTP、实时连接、媒体读取、凭据和日志继续由宿主注入；SDK 不依赖 Node/Electron 或浏览器全局 WebSocket。

## 剩余边界

- 本任务只验证协议、fixture、打包和远端消费，没有执行真实百炼/Groq 付费请求；真实凭据验证属于 Say-It 集成阶段。
- `0.2.0` 因 GitHub Packages 的 deprecate API 缺陷仍可被精确安装，但不是 `latest`。后续发布与接入文档必须继续以 `0.2.1` 为最低版本。
