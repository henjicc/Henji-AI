# 00 任务总览：模型 SDK 抽离

> 本文件是本任务的唯一总入口，只保留全局信息。技术方案见 [01-实施方案.md](01-实施方案.md)，跨任务的重要决定见 [重要记录.md](重要记录.md)。

## 任务目标

### 为什么要做

痕迹AI 目前适配了 8 个生成模型供应商共 99 个模型（图片 / 视频 / 音频），以及 7 个大语言模型供应商预设。这批适配逻辑、参数结构、API 字段与价格数据全部锁死在本仓库内部，其他项目（规划中的 Tauri 应用、Photoshop UXP 插件）想复用只能重新读文档、重新写适配。

同时本仓库内部存在一处结构性债务：模型定义写在渲染层 `src/models/`，主进程读不到（`@` 别名只配在 renderer 块），于是用 `scripts/generate-model-manifest.cjs`（702 行，TypeScript 编译器 API + `vm`）把模型序列化成 `resources/model-manifest.json`，主进程再用 `node:vm` 执行序列化后的 builder 字符串。该链路已产生 4 个模型的 builder 手抄副本、1 组镜像常量、1 份影子工具函数实现，脚本注释自述会「与源码静默分叉」。

抽离 SDK 与还清这笔债是同一件事：SDK 是独立包、内部不用 `@` 别名，主进程可以直接 import，序列化与 VM 执行的理由随之消失。

### 最终要达到什么结果

1. 仓库内新增 `packages/ai-sdk`，包含全部供应商适配、协议模板、模型目录、LLM 协议层与文档资产，不依赖 Electron、不依赖 Node 专有 API、不依赖 `@` 别名。
2. 痕迹AI 主进程与渲染层改为消费该包，行为与现在完全一致。
3. `generate-model-manifest.cjs`、`js-runtime.ts`、`manifest.ts` 及其衍生副本全部删除。
4. 生成模型与大语言模型共用同一套凭据、网络、错误与追踪抽象。
5. 新模型类型（语音识别等）可以在不改动既有类型联合的前提下扩展。
6. 该包可独立构建、发布，其他项目安装后只需提供运行时适配即可调用全部模型。

### 属于本次任务

- `electron/main/services/ai-runtime/**` 与 `electron/main/services/llm/**` 的可移植部分迁移
- `src/models/**` 全部 99 个模型定义迁移
- `src/core/llm/**` 的可移植部分迁移
- `docs/model-adaptation/**` 与 `docs/llm-adaptation/**` 文档资产迁移
- 模型类型与供应商注册机制的可扩展改造
- SDK 的构建、发布、测试体系
- UXP / Tauri 运行时约束的可行性验证

### 不属于本次任务

- 改造 Tauri 应用或 UXP 插件的业务功能（只验证 SDK 可用性，不做产品开发）
- 新增任何模型或供应商（迁移期间冻结，见「重要说明」）
- 远程模型目录热更新（见 [重要记录.md](重要记录.md) 记录 007）
- 把供应商适配改写成 YAML/JSON 声明式配置（见 [重要记录.md](重要记录.md) 记录 007）
- 痕迹AI 的界面改动（参数面板、画布节点、设置页只做必要的引用路径调整）
- `src/core/` 的 ParamDef / Linkage / 面板体系重构

## 重要说明

1. **迁移期间冻结模型新增。** 任务 3.2 会一次性移动 99 个模型文件。此期间在 `src/models/` 新增模型会与迁移冲突，且新模型不会被迁移覆盖。若必须新增，先完成 3.2 再在 SDK 目录里加。
2. **每个任务必须是一次独立 Git 提交，且提交后痕迹AI 必须能正常运行。** 本任务不允许出现「跨多个任务才能跑起来」的中间态。任务顺序就是按这个约束排的。
3. **行为不变是第二至第四阶段的硬指标。** 这三个阶段是纯搬迁，任何行为差异都是缺陷而不是改进。要改行为请另开任务。
4. **`packages/ai-sdk` 内禁止出现 `@/` 别名、`node:` 内置模块、`electron` 导入。** 这是 SDK 可移植性的底线，任务 1.2 会加一个检查脚本强制执行。唯一例外是 `packages/ai-sdk/tests/**` 与构建脚本。
5. **`src/core/` 的 ParamDef / Linkage / 面板体系不迁移。** SDK 只拥有「模型是什么」，痕迹AI 保留「模型长什么样」，切分口径见 [重要记录.md](重要记录.md) 记录 003。
