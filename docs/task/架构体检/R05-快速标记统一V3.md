## 实现与调用方追踪

开始前按 AGENTS.md 领域索引读取架构、持久化、助手覆盖/目标/现状、UI、画布、媒体、日志和验证规则；使用 henji-ui-surface、henji-application-capability，遵守共享工作区的文件范围。

| 调用方 | 退役路线 | 统一后路线 |
| --- | --- | --- |
| 查看器快速标记 | V2 coerce → 旧 ImageEditor → 旧整图 export | 共享 managed session → ImageEditorV3 quick profile → 同一 command bus/保存 owner → 权威回读 → 分块物化 |
| 工具箱 / 新建图片 | V2 factory → migrateImageEditDocumentV2ToV3 | V3 工厂直接创建受管工作副本；已有 V3 文档复制新身份 |
| 画布编辑 | 普通来源先构造或恢复 V2 | 公共 imageEdit 出口的共享准备/物化；layerStackV1 是独立现用画布格式 adapter，保留 |
| 助手预览 / 生成参考 / 收藏素材 | V2 operations 与旧 browser/worker 执行 | 语义 operations → V3 command bus → repository → 同一分块物化 → 原 persistImageSource / 正式素材提交 |
| 助手文档、图层和标注 | V2 preview-document / 操作投影及 image_mark.document Store | image_edit.document 通用几何属性、V3 图层集合、image_mark.annotation 通用增改删，同一事务撤销 |
| 保存 / 导出 / 回放 | V2 coercion、legacyOperation、旧 image.blur 节点 | 只接受 V3 引用及正式效果；指纹、文档身份、revision 和尺寸校验仍在保存/导出边界 |

预览仍是不可变结果引用：加载其 V3 文档时不安装保存 owner，既有文档/图层/标注写屏障拒绝原地修改。继续编辑预览会复制新文档并追加命令，不影响旧引用。已有 V3 文档的新建/继续编辑直接复用受管资源，不再访问可能失效的原图 URL；两条精确测试设置原图入库失败并验证仍成功且未重复入库。Viewer 的“关闭”先刷写并回传最新会话，不做物化；“保存”才更新展示图片。保存失败保留编辑结果并可重试，导出期间变更/卸载拒绝旧结果。

删除旧 preview 的 operations.max(32)、效果单例与光效互斥；删除预览注册表的 64 项淘汰上限。未给产品图片、图层或标注数量设上限；通用实体既有 maxItemsPerChange 是单次事务分批契约，不是产品总量上限，本任务未改全局事务协议。

## 开源选型与设计自查

选型：直接复用项目已经使用的 V3 command bus、repository、Zod schema、分块合成器和既有媒体 PAL；依赖审查复用 Madge/Knip。没有新增库，没有实现第二套编辑器、渲染器或协议，没有增加许可义务。小型 shared application 模块是从现有入口抽取的业务编排，不重新实现算法。

1. **助手只凭名称和说明能否用对？** 能：文档旋转、镜像、裁剪和标注都在现有通用实体说明/schema 中；Gaussian 用 sigma_fraction_height/axis/edge，效果层按正式登记选择。不可变预览的 availability 明确拒绝原地写入。没有新增“设置值”专用能力。
2. **能否 AI 先做、人只确认？** 能：预览能力批量构建 V3 命令，助手直接修改同一文档/标注实体；人用 quick/full/canvas profile 校正，均有原命令历史与事务撤销。
3. **产物能否直接流进其他工作区？** 能：保存保留 V3 引用；预览可直接作为生成媒体引用，物化结果沿原受管媒体和素材服务进入画布/素材库，不要求搬文件。

## 三入口一致性证据

`imageDocumentFromSource.test.ts` 的三入口用同一受管 64×48 图片，经查看器 shared factory、画布 adapter、工具箱 factory 进入 V3；执行同一旋转/镜像/裁剪/标注命令，repository 保存回读与 codec 结果一致；输出 32×40 RGBA 在 16/64 两种瓦片尺寸及三个入口之间逐字节相等。

证据边界：源入库由受控 PAL 夹具提供，标注 raster 用确定性 opaque impulse；真实 CPU 分块合成和输出几何参与比较。它证明入口/命令/保存/分块一致性，不代表 Electron UI、实际字体栅格或 GPU 编码像素验收。Viewer 精确组件测试另外验证 quick profile、权威保存回读、关闭后恢复、不重新入库、导出失败重试和卸载/并发修改拒绝。
