## 设计自查与选型

1. **助手只凭名称和说明能否用对？** 现有能力 ID、说明和输入输出契约不变，motion 约束与执行器同源；注入函数只属于可信宿主上下文，不作为模型参数公开。
2. **能否 AI 先做、人只确认？** 原正式能力和同一事务引擎继续执行工作，撤销与保存屏障保留；依赖扫描、基线比较和回归测试自动完成，管理者审查具体差异及共享阻塞。
3. **产物能否直接流进其他工作区？** 文档通知、素材能力、画布和剪辑现有跨域入口不变，图片投影在显式装配点接线；未新增文件搬运或隔离状态。

选型：这是依赖方向重构，不新增计算/编辑算法或运行时库。复用已有 Zod 契约、领域服务、配置点、Map/订阅状态和 Madge + TypeScript + graphlib 的 R01 门禁；不引入新的 DI 容器或事件库，以免多一套装配/状态所有权。算法正确性与规模性能实现保持原样；未声称完成所有顶层副作用治理或性能实测。
