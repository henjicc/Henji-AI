# t111 / R08：画布节点复制统一生命周期

状态：实现与定向验证完成，等待总管理者审查、提交与同步。本任务不执行 Git 写操作，不修改 SDK 或体检报告。

## 产品契约与扩展点

- 复制 3D 镜头参考节点，独立复制来源文档；新节点绑定新文档。来源为空的未配置节点仍可复制，来源失效则明确失败，不退回引用原件。
- `CanvasNodeDefinition.duplicateSource` 声明节点来源复制。它接收源节点和应用服务注入的 I/O，返回数据投影及异步补偿函数。cameraStage 与 layer-stack 都使用该钩子；正式复制服务不按节点类型分支。
- 注册声明不加载文档组合根。文档服务由正式复制入口延迟提供；layer-stack 保留原有动态加载边界，不把循环搬到新的动态导入位置。
- `commitCanvasNodesDuplication` 顺序准备整批来源，准备全部成功后同步提交节点、尺寸、组结构与内部连线，并合并成一条画布历史。普通节点保持同步；单节点入口委托该生命周期。
- 来源准备和补偿期间持有目标画布租约，暂停自动保存；提交前复核源节点的数据、类型和归组。UI 切换画布取消接管，能力路径始终绑定显式画布，不依赖当前页面。
- UI hook 只编排位置、选择、组的父子关系、连线与拖拽。复用已有后代收集函数；补齐普通组子节点重挂。Alt 拖放的纯位移合入复制历史，期间其他内容编辑不被合并。

## 失败、保存与撤销

1. 后续来源准备失败：不提交任何节点；逆序、逐项等待已创建来源的补偿。
2. 同步图提交中途失败：恢复提交前节点、连线、历史与相关选择/拖拽状态，然后补偿全部新来源。
3. cameraStage 补偿复用通用文档 `trashDocument` 的释放屏障，移入系统回收站并移除活动索引；不直接操作磁盘、不删除原件。layer-stack 复用原按 revision 删除新文档与资源回收；返回未删除也视为补偿失败。
4. 补偿失败：继续尝试其他来源，记录结构化失败，并用 `AggregateError` 保留原错误与补偿错误；不虚报“无孤儿”。
5. 外层画布批事务后续步骤失败：通过新增 `CanvasCommitOptions.afterRollbackConfirmed` 登记来源补偿；原画布恢复并确认保存后执行。没有补偿协调器的延迟来源复制在 I/O 前拒绝。
6. 并发冲突或保存未确认仍遵循原事务的保留现场契约，不强行回滚其他编辑、不删除仍被现场引用的来源。若外层回滚保存本身失败，补偿确认屏障未通过，来源仍保留，不能宣称已完成补偿。
7. 正常复制一次撤销移除副本图结构，重做使用同一新来源、不重新复制；历史仍持有文档引用，来源为重做保留。此处沿用 layer-stack 的历史资源语义，不将撤销误实现为不可恢复的文档删除。

## 应用能力覆盖判断

修复已有 `duplicate_canvas_node` 的来源与事务行为，保留名称、输入输出、能力入口和画布权限；不新增专用 Agent 工具、实体、属性或另一套 schema。能力 handler 原本就委托 `duplicateCanvasNode`，现在与 UI 的来源生命周期一致；节点与持久画布可读回新 projectId，来源内容由正式文档存储读取。

按 `assistant-status.md` 第零节，本次属于既有复制能力的缺陷修复：未增减 KNOWN_* 欠账，未改变域/实体/属性的通断，也未推翻台账中已确定的路线，因此不修改助手台账。

## 选型与规模

复用仓内现有 Zustand/ReactFlow 图写入、文档副本/回收站屏障、layer-stack fork/rollback 和画布历史工具。不引入新的事务库或文档复制库：这些库不能替代本应用已有文档实例与保存契约，新增依赖无法解决双入口生命周期问题。新增代码只协调这些既有正式入口，不自研文档格式或资源复制算法。

来源按顺序准备，避免无界并发 I/O；节点、片段或文档数量不设产品上限。沿用现有撤销栈的技术保留深度，不新增历史数量规则。未取得大规模来源复制耗时、真实磁盘吞吐或 Electron 容器证据。

## 设计自查

1. **助手只凭名称和说明能否用对？** 能。现有“复制画布节点”现在具有一致的独立来源语义，输入仍是明确节点与位置；来源失效明确失败，不要求助手额外复制文档或手改 projectId。
2. **能否 AI 先做、人只确认？** 能。助手沿正式入口自动复制来源、绑定、保存并取得撤销引用；用户无需补做 UI 特有的来源步骤，可直接检查或撤销。
3. **产物能否直接流进其他工作区？** 能。副本仍是正式镜头参考文档或既有图层文档，节点保留原媒体输出契约；镜头参考编辑器与其他文档消费入口可使用新文档，不新增搬文件流程。
