## 设计与实施

- canonical id 为 `gaussian_blur`；参数为 `sigma_fraction_height`、`axis`、`edge_mode`。sigma 以完整文档/序列画面高度为基准，输出分辨率只换算采样尺度，viewport/tile 不作为参考高度。边界显式 clamp / transparent。
- 执行域统一为 linear-light、premultiplied；工作色域由宿主保留。两宿主 interactive 使用 fp16 中间纹理，final 使用 fp32；精度与 scratchBytes 由共享 ResolvedPlan 给出。剪辑前后转换带符号 sRGB，保留负值与大于 1 值。Gaussian 只用 textureLoad，剪辑为它使用 unfilterable-float 绑定布局，fp32 不要求 float32-filterable 设备特性。关键帧、时间、媒体、纹理、Worker、缓存和取消仍属宿主。
- 图片 legacy `effect.blur-v1` 的 CPU 感知域输入输出包装保留，滤波转到线性域；GPU 输入已经线性，不再回到感知域滤波。删除 legacy codec/historyCodec/layerTypes 不属于本任务。
- 图片 V2 的 radius/mip 仅保留为现有 dispatch 内部 ABI；没有新增作品参数兼容分支。剪辑旧 strength/dimensions/repeat_edges 参数直接删除；智能区域预设、关键帧/效果库夹具和当前持久化样本同步修改。
- CPU 与 WGSL 使用同一 dyadic 全局像素中心网格；奇数尺寸不通过归一纹理宽重新拉伸网格。按每道工序反向传播 halo，真实相邻像素不足时拒绝执行，不把 tile 接缝视为画面边。
- `ResolvedGaussianPlan` 含 effectId、quality、参数、reference/outputSize、两轴 sigma、工序及 sampleScale、alignment、halo、文档像素 halo、逻辑 scratchPixels。
- FastBlur、scatter-blur、shaders.Blur 独立登记，标明 host-owned；没有伪装成标准高斯 executor，未合并视觉模型。
- 参数不设产品半径或数量上限；质量策略的 maxLevels/maxRadius 为 Infinity，降采样由实际网格能否继续缩小决定。有限数值、正整数完整网格和 mip 0～30 是现有像素 ABI 的坐标精度约束。极端数值/内存和 WebGPU 设备纹理能力仍是实际技术边界；本次实测范围不是产品上限。
- 共用 CPU 区域对齐、GPU 视口和 GPU 内存预算的旧 120px 截断已去掉。GPU 区域窗口逐工序缩小，prepare 时反复 resize 同一池 target 会破坏尚未 encode 的前序窗口，已改为各工序持有独立区域 target；final 同样独立持有 fp32 target，并在质量/工序减少时释放不用的尾部缓存。常规 interactive 整幅仍复用原池。预算按各 Gaussian renderer 的共享计划 scratchBytes 累加，不再按旧共享 fp16 金字塔估算。 编译缓存按工序与 target 格式登记，interactive/final 切换不跳过 fp32 编译。

## 质量策略与误差预算

interactive：R06 短核策略，directSigma=3、3σ 截断、双线性降采样/回放；无固定级数/核半径封顶。final：directSigma=16、4σ 截断；每次降采样前仅在缩小轴加 sigma=1.25、4σ 截断的抗混叠短核。降采样方差扣除 1/4 + 1.25²，离散回放方差扣除 factor²/6 + 1/12。final 的 minimumSigma=0，保留所有正标准差的离散核，不沿用 interactive/R06 的 0.3px 起步阈值；0.25/0.29/0.5px 与归一离散核逐值对照通过。溢出或不能精确表达整数索引的核明确报错，不返回含 Infinity/NaN 的计划。

先测无抗混叠候选：二阶矩虽然接近，final 冲激中心仍有 1.5/3.5px 偏移；因此没有把它当成 final 交付。加入 1.25 预滤波后按下表决定数值。interactive 保留 R06 的相位偏移，记录为近似档的已知误差，没有声称它与 final 像素相同。

## 给 R04 的接口请求

1. operationCatalog / 图层模型 / builtInRenderNodes / RasterSceneCompiler / GraphUniforms 从 `GAUSSIAN_EFFECT` 派生 canonical `gaussian_blur` 参数：sigma_fraction_height、axis、edge_mode。当前 radius/mip 只留执行适配接口；不要继续把作品参数定义为内部像素半径，不写旧字段迁移。
2. CPU 调度从完整文档与完整输出网格调用 `resolveImageGaussianPlan(parameters, { referenceSize, outputSize, quality })`；用 `gaussianExecutionWindows(plan, outputRegion)` 取真实 input halo，用 `executeGaussianCpu(plan, inputWindow, outputRegion)` 执行，再走宿主既有 mask/blend。禁止按 tile 尺寸重新规划。

4. 拖参数/交互预览传 interactive，图片最终导出传 final，计划和缓存 key 包含质量与完整网格。当前默认 final 是临时内部 ABI 默认值，不代表拖参数已选 interactive。
5. halo 不是简单 3σ；final 包含每级抗混叠、downsample 和 upsample support。优先用共享反向窗口；粗 tileGeometry helper 已改为保守共享 support。中间纹理格式遵循 plan.intermediateFormat，使用 plan.scratchBytes 估算；各工序窗口不同时不能提前 resize 同一 target。final/区域缓存当前由 renderer 持有，R04 可按宿主真实生命周期改善复用/回收，但不能缩精度或吞掉 halo。不得把本记录逻辑 scratch 总和当驱动峰值。
6. image_edit.layer.params 反射中的 shared $defs 已准备；创建/描述/读改必须实际绑定同一个 canonical id 和 schema。旧 `image.gaussian-blur-v2` / `effect.gaussian-blur` 不应误宣称已是新作品参数。

3. **产物能否直接流进其他工作区？** 效果只改变宿主现有图层/片段与导出结果，不新增文件搬运或工程类型，保持现有项目/素材出口；跨工作区结果继承相同高斯语义。实际跨工作区导入未在本任务运行 Reality 取证。
