# 结构化提示词编辑器升级任务总览

## 任务目标

用一个面向提示词场景的共享结构化编辑器，逐步替换当前依赖“透明 textarea + 高亮镜像层”的输入方案，根治 `@` 引用导致的滚动、换行错位、引用样式破裂及多实例撤销边界脆弱等问题，并让图片/视频缩略图引用、模板变量和未来 Markdown 能力建立在可扩展文档模型上。

本次包含编辑器内核验证、文档与序列化契约、共享 UI、媒体引用/模板变量、旧字符串兼容、核心提示词入口迁移、画布性能与回归；不包含 Word 式完整富文本、协同编辑、评论、表格、云端文档、模型接口整体改为接收富文本或把标题/搜索/API Key 等所有原生输入强制替换。

## 重要说明

- 目标组件是“提示词编辑器”，不是全功能文档编辑器；能力通过预设按需开启，普通提示词仍应像简单文本框一样轻量。
- 结构化 JSON 是推荐的编辑态单一事实来源；HTML 不作为持久化格式，生成边界在迁移期继续输出字符串。
- 媒体引用必须是不可拆分的原子节点，并保存稳定资源标识；缩略图 URL 只用于运行时解析，不直接写入文档。
- 画布中非激活节点不得长期保有大量完整编辑器实例；静态渲染、按需激活和现有 LOD 必须纳入方案。
- 每个任务完成后独立提交，并同步本总览、任务执行记录和必要的重要记录。
