## 任务目标

把媒体引用和提示词模板变量实现为真正的内联原子节点，统一候选触发、缩略图渲染、键盘操作、整体删除和失效态，彻底替代对普通字符做正则高亮的方式。

## 当前情况

- `@图N` 与 `{{变量}}` 当前只是普通文本；镜像层通过 regex 给字符加背景，换行后无法保持 token 与样式整体一致。
- `ReferenceTextarea` 已有 `@`、`/` 两种触发器和可配置候选渲染，后续仍需覆盖键盘、鼠标、portal 和画布缩放交互。
- 候选项已能拿到缩略图，但文档只记标签，未保存媒体类型和稳定资源身份。
- 媒体来源包含生成工作区上传列表、标准节点 effective media、分镜帧和上游节点，解析缩略图的职责不能塞进通用编辑器。

## 实施方案

建立 `mediaReference` 与 `templateVariable` 两个 inline atom extension。`mediaReference.attrs` 固定为 `resourceId/mediaType/fallbackLabel/sourceNodeId?`，`templateVariable.attrs` 固定为 `key/fallbackLabel`。通用编辑器通过 `PromptReferenceItem` resolver 获得当前 label、thumbnailSrc 和可用状态；缩略图不进入 JSON。NodeView 负责图标/缩略图与文字胶囊的同一行布局。

候选系统由共享 preset 配置触发字符、过滤和项目渲染。atom 在浏览器排版中作为一个不可拆分内联盒子参与换行，Backspace/Delete/选区复制粘贴均以节点为单位，不再手工计算字符范围。

## 执行步骤

1. 按文档契约实现媒体与变量 extension 的 parse/render/JSON attributes，禁止把 thumbnail URL 写入文档。
2. 实现 React NodeView：图片显示缩略图，视频显示缩略图或类型图标，变量显示稳定标签；缺失资源提供明确失效样式和可访问文本。
3. 建立可配置 suggestion adapter，覆盖 `@` 媒体和 `/` 变量，支持键盘上下/Enter/Escape、鼠标选择、空列表和 portal 定位。
4. 实现 atom 前后光标、整体 Backspace/Delete、选区复制/剪切/粘贴和纯文本粘贴降级；不能留下孤立触发字符。
5. 验证 NodeView 在窄宽度、行尾、中文前后、连续引用和缩放容器中整体换行，不再出现半截高亮。
6. 为稳定 ID 重排、引用失效、恢复、媒体类型、变量 token 和复制粘贴编写纯逻辑/组件测试；覆盖 `asset:<id>`、`canvas-output:<node>:<handle>:<index>`、`canvas-frame:<node>:<frame>` 与本地 UUID binding。
7. 在 UI 层只暴露数据 resolver 与候选 provider 协议，业务入口不得 import extension 实现。
