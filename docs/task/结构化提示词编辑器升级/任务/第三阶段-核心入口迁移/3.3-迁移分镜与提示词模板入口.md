## 任务目标

迁移分镜格子描述、分镜拆分备注和提示词优化模板三类特殊入口，验证共享编辑器能在密集小尺寸节点、动态媒体列表与 `/` 模板变量场景下复用，而不是为特殊 UI 复制一套实现。

## 当前情况

- `StoryboardGridEditor.tsx` 的每个格子挂载一个 `ReferenceTextarea`，节点放大后可能同时存在大量输入实例。
- `FrameCard.tsx` 在图片底部覆盖层内编辑 `frame.note`，需要适应很窄的宽度、动态字号/行高和拖拽排序手势。
- 两处都使用媒体引用，但媒体重排、帧替换和输入图片变化会改变 `图N` 顺序。
- `PromptOptimizationProfilesPanel.tsx` 用 `ReferenceTextarea` 的 `/` 触发器插入 `{{prompt}}` 等变量，配置仍保存 `systemPrompt/userTemplate` 字符串。
- 分镜节点属于“标准行 + 专属面板”模式；本任务只替换专属面板内输入，不改写模型/媒体/参数标准行。

## 实施方案

分镜入口使用媒体引用 preset 和按格子激活策略：未编辑格子只静态显示，单击后仅挂载当前格子的完整 editor。媒体引用保存稳定 ID，帧/图片排序只改变显示标签。继续复用当前分镜节点主文件的 historyGroup 和 effective media 语义。

提示词优化模板使用模板变量 preset。结构化变量节点序列化回现有 `{{key}}` 字符串，使 `renderPromptOptimizationTemplate()` 和 LLM 配置落盘在迁移期不需要改变业务语义。

## 执行步骤

1. 追踪两类分镜数据结构、frame ID、媒体输入、排序/替换和生成拼接逻辑，确认稳定引用 ID 与结构化字段落点。
2. 在 `StoryboardGridEditor.tsx` 接入按格激活的共享编辑器，保持格子布局、缩放和一次 focus session 一个画布快照。
3. 在 `FrameCard.tsx` 接入相同 preset，处理窄宽度、覆盖层滚动、图片拖拽手势冲突和动态字体；不在卡片内复制 extension。
4. 验证图片/帧重排、删除、替换后文档引用身份不变，显示 `图N` 与最终分镜生成文本符合当前媒体顺序。
5. 在 `PromptOptimizationProfilesPanel.tsx` 用模板变量 preset 替换 `/` 变量输入，保留候选分组、描述、system/user template 和配置保存。
6. 通过核心 serializer 将结构化变量写回 `{{key}}`，验证现有 `renderPromptOptimizationTemplate()` 输出不变。
7. 增加分镜多格激活、变量插入/删除、配置重启恢复和媒体重排测试，记录真实 Electron 鼠标验收步骤。
