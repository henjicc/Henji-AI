# 3.1 迁移生成工作区提示词入口

## 任务状态

- 状态：进行中
- 所属阶段：第三阶段（核心入口迁移）
- 前置任务：2.3
- 关联任务：3.2、3.3、4.1
- 是否可以并行：是，可与 3.2、3.3 并行

## 任务目标

将生成工作区主提示词输入迁移到共享 `PromptEditor`，支持上传图片的缩略图引用、提示词优化整段替换和现有提交/粘贴/拖放行为，同时保持生成请求、预设和历史记录的字符串语义不变。

## 当前情况

- `InputArea.tsx` 使用 `ReferenceTextarea`，按 `uploadedImages` 数组下标构造 `image-ref-N/图N`，并传递图片粘贴、拖放、提交和复杂样式。
- `MediaGenerator/index.tsx` 持有 `ReferenceTextareaHandle`，提示词优化通过 `replaceValueWithUndo()` 写回并依赖撤销/重做 replacement 值。
- `useGenerationHandler.ts` 在调用 `onGenerate` 前用 `stripReferenceAtPrefix()` 将 `@图N` 转为 `图N`。
- `GenerationWorkspace.tsx`、预设和生成历史仍消费 prompt 字符串；本任务不能迫使模型 runtime 接收编辑器 JSON。

## 实施方案

在生成工作区启用“媒体引用”preset。调用方把当前上传媒体映射为 1.2 确定的稳定引用上下文，编辑器文档保存稳定 ID，NodeView 动态显示缩略图与当前 `图N` 标签。生成、预设和历史边界统一调用核心 serializer 输出兼容字符串/模型文本。

提示词优化返回字符串时通过 parser 构造结构化文档并作为一次可撤销 transaction 写入当前编辑器；不再维护一套 textarea 原生 undo replacement 协议。

## 执行步骤

1. 追踪 `input` 状态、预设载入、历史重编、提示词优化和模型切换的完整数据流，按 1.2 契约确定结构化字段的所有者。
2. 将上传图片映射为稳定媒体引用上下文；重排/删除时更新显示序号，不改写文档中的稳定 ID。
3. 用 `PromptEditor` 替换 `InputArea.tsx` 的主 `ReferenceTextarea`，迁移 placeholder、最小高度、左侧上传区避让、提交、paste/drop 和 focus handle。
4. 将提示词优化整段替换改为编辑器 transaction，确认一次撤销恢复优化前文档，重做恢复优化结果。
5. 在生成、预设保存/加载、历史重编边界接入统一 serializer/parser，移除本入口对 `stripReferenceAtPrefix()` 的直接依赖。
6. 验证图片新增、删除、重排、重复引用和失效引用时，显示标签与模型文本符合契约。
7. 增加生成工作区组件/集成测试，并记录真实 Electron 键鼠验收步骤交由用户执行。

## 涉及内容

### 新增文件

- 预计无需新增业务组件；仅在 `MediaGenerator` 内需要小型 adapter 时新增单一职责文件。

### 修改文件

- `src/components/MediaGenerator/components/InputArea.tsx`：替换主提示词输入并提供媒体上下文。
- `src/components/MediaGenerator/index.tsx`：切换 handle、结构化状态和提示词优化替换协议。
- `src/components/MediaGenerator/hooks/useGenerationHandler.ts`：改用统一模型 serializer。
- `src/workspaces/GenerationWorkspace.tsx`、预设相关模块：按 1.2 契约兼容读取/保存，不改变外部字符串行为。

### 可能废弃

- 生成工作区专用的 undo/redo replacement props 与状态：编辑器 transaction 验证通过后删除。

## 验收标准

- [ ] 主提示词输入使用共享编辑器，图片引用带缩略图并整体换行/删除。
- [ ] 上传图片重排后引用仍绑定同一稳定媒体，显示序号和生成文本按当前上下文更新。
- [ ] 提示词优化替换可在当前输入中撤销/重做，不影响其他输入。
- [ ] 粘贴图片、拖放、提交快捷键、预设载入和历史重编行为未回退。
- [ ] 实际发送给现有模型的 prompt 与迁移契约一致。
- [ ] 相关测试、lint、TypeScript 检查通过，用户手动步骤和任务总览已更新。
