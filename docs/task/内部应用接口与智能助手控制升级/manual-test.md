# 最终手动测试（3 个）

自动化已经覆盖能力注册、Schema、权限、revision、循环终止、遮罩规则、22 个 Surface 策略、旧数据兼容、全量测试、构建和产物冒烟。这里只留 3 个必须真人操作的场景，每个都串起多条链路。

**开始前**：停掉旧进程，重新运行 `npm run electron:dev`。准备好——

- 一个能调工具的主模型；一个支持图片的观察模型（在设置 → API → 智能助手里配）
- 一张图片、一段音频（wav 或 mp3）
- 一个已有的三维工程（含默认摄像机和一个主体对象）
- 一个升级前创建的旧画布工程

失败时记下 `runId`，用 `npm run logs:query -- --chain <runId>` 查链路。

---

## 测试 1 · 三维组合任务 + 滚动接管

**做什么**：打开一个已有三维工程，对助手说一句话：

> 复用这个工程的默认摄像机，在主体两侧各放一个不同的物体、不要重叠，然后做一次环绕运镜，最后确认构图对不对。

任务跑起来之后，做两个打断动作：

1. 对话滚到一半时，用滚轮往上翻几屏
2. 助手打开三维页面后，手动切到别的工作区点两下

**看什么**：

- [ ] 只做了 **1 次** 能力发现，没有反复按关键词搜索
- [ ] 取得工程引用后才切到三维页面，没有新建重复工程或摄像机
- [ ] 两个物体没有重叠；运镜能播放，方向和"环绕"一致
- [ ] **放完之后它自己做了验证**：先跑结构化验证（对象位置/尺寸/不重叠/运镜结果），不是放完直接说"好了"
- [ ] **观察模型支持图片时，它会再截一张三维视口图，结合截图和对象参数一起判断构图**
- [ ] 往上翻之后新内容**不抢回**位置，出现"有新内容/回到底部"；点它能恢复跟随
- [ ] 你切走页面后助手**不反复抢回**三维页面，并且会说明你已接管
- [ ] 助手截的图只有三维视口——没有桌面、别的窗口、助手侧栏
- [ ] 最终答复分得清"结构化验证"和"看了画面验证"，不含裸本地路径

**补一个小对照**：把主模型和观察模型都换成不支持图片的，再跑一次同样的话。这次它应该**只做参数验证**，并且明说"没有看画面"，绝不能描述构图长什么样。

## 测试 2 · 真实模型 + 附件 + 生成链路

**做什么**：

1. 往助手输入框里**拖入**图片、**粘贴**音频，不打字直接发，让它描述看到/听到了什么
2. 把主模型换成不支持图片的，观察模型保持支持图片，再发一次同样的图
3. 用真实 API Key 让助手生成一张图；生成过程中再起一个，然后**取消**它

**看什么**：

- [ ] 三类附件都能预览、能单独移除；不打字也能发
- [ ] 第 1 步主模型直接读图，第 2 步显示走了观察模型回退，两次内容判断都对得上
- [ ] 主模型和观察模型都不支持某个模态时，请求发出**之前**就被明确挡住，不会把媒体地址退化成一段文本发出去
- [ ] 生成的"已提交/生成中/成功或失败"是真实状态；完成的图能看
- [ ] 取消的那个不会在之后被误报成完成
- [ ] 助手答复里没有裸本地路径

## 测试 3 · 整窗观察 + 隐私遮罩 + 重启恢复 + 旧工程

**做什么**：

1. **随便在哪个页面**，直接让助手"看一眼现在界面什么情况"。它应该不需要你先切页面就能截到整窗
2. 打开设置到存储路径页，先点一下助手偏好页的"打开指令文件"让路径显示出来，再让助手观察一次整窗
3. 在一个**带附件、且有一步已经写入成功**的会话里，直接重启应用，恢复同一会话；然后把那个源附件文件移走或删掉，回看历史消息
4. 打开旧画布工程，改一个节点标题 → 撤销 → 关掉重开

**看什么**：

- [ ] 第 1 步**不用先切页面**就能截到当前整窗，助手能说清界面上有什么
- [ ] 整窗图里**只有本应用窗口** —— 没有桌面、没有别的应用、没有第二个显示器
- [ ] 整窗图**该看清的都看清了**：提示词框、参数、搜索框、按钮文字都不是黑块
- [ ] 但**存储路径、快捷下载路径、"打开指令文件"那行路径是黑块**；密钥框本来就显示圆点
- [ ] 助手不会把自己侧栏里的对话当成应用状态来复述
- [ ] 主模型和观察模型都不支持图片时，助手不许说"我已经看过画面了"
- [ ] 重启后同一会话恢复：已完成的步骤不重跑，等待中的还在对账，附件仍可用
- [ ] 源附件删掉后，历史消息显示"源已失效"，不崩溃、不暴露路径
- [ ] 旧工程能读；改动是一个完整撤销单元；重开后状态一致
