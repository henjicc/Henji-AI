# 最终必要手动测试

自动化已经覆盖能力注册、Schema、权限、revision、循环终止、旧数据迁移、22 个 Surface 策略、静态检查、全量测试、构建和产物冒烟。这里只保留必须依赖真实模型、鼠标操作、WebGL 画面或长期运行的项目；不再逐阶段重复测试。

开始前停止旧进程，重新运行 `npm run electron:dev`。准备一个可调用工具的主模型、一个支持图片的观察模型、真实图片/视频/音频文件，以及包含默认摄像机和主体对象的既有三维工程。

## 1. 真实多模态与生成链路

- [ ] 分别通过文件选择、拖入、粘贴添加图片、视频、音频；确认预览、移除、无文字发送均正常。先让主模型直接读取图片，再切换为“主模型不支持图片、观察模型支持图片”，确认只在后者显示观察模型回退且内容判断正确。
- [ ] 选择一个协议无法表达其已声明模态的模型提交对应附件；确认请求发出前被明确阻止，媒体地址不会退化成普通文本发送。
- [ ] 使用真实 API Key 各提交一次最小图片、视频、音频生成；确认“已提交/生成中/成功或失败”来自真实状态，完成媒体可展示或播放，助手答复不出现裸本地路径。另取消一个仍在运行的任务，确认不会随后误报完成。

## 2. 三维组合任务、提前开屏与视觉结果

- [ ] 在既有工程要求助手：复用默认摄像机，在主体两侧无重叠放置两个不同物体，执行一次环绕运镜并验证构图。确认只进行一次批量能力发现、取得稳定工程引用后立即打开三维页面、不新建重复工程/摄像机、物体不重叠、运镜可播放，最终答复能区分结构化验证和模型视觉验证。
- [ ] 页面打开后立即手动切换到其他页面并操作界面；确认助手不反复抢回三维页面，并能说明用户已接管或当前可见状态。再用失效工程引用执行一次，确认不会在错误工程盲写。
- [ ] 人眼检查三维视口截图只覆盖专用视口，构图与运镜方向符合请求；没有桌面、其他应用窗口或助手侧栏进入截图。

## 3. 对话滚动与动态布局

- [ ] 将窗口调到约 960×640，运行一个持续输出长文本、工具记录和折叠计划卡的任务。停留底部时内容应自动跟随；用滚轮或触控板、拖动滚动条、PageUp 任一方式上移后，新内容不得抢回位置，并出现“有新内容/回到底部”。
- [ ] 在用户接管滚动后展开工具卡并缩放窗口，确认阅读位置仍可控；点击回到底部后恢复跟随，新建一次运行也恢复默认跟随。

## 4. Surface 隐私边界

- [ ] 分别观察 API Key 设置页、存储路径页、画布或图片编辑器、三维视口、一个生成结果或素材：密钥和路径必须被遮罩；画布/编辑器/三维只截专用区域；生成结果优先读取稳定媒体原件。
- [ ] 切走或关闭目标 Surface 后再次请求观察，确认明确拒绝或降级，不回退到整窗/桌面截图；当主模型和观察模型都不支持所需模态时，不得宣称已经看过画面或听过音频。

## 5. 恢复、兼容与短时稳定性

- [ ] 在包含附件、外部生成等待和至少一个已完成写入的运行中重启应用，恢复同一会话；确认已完成步骤不重复、等待状态继续对账、附件仍可用。随后移动或删除一个源附件，历史消息应显示源已失效，而不是崩溃或暴露路径。
- [ ] 打开升级前创建的画布或三维工程，执行一次读取、修改、撤销并重开；确认旧项目可读，修改形成有效撤销单元，重开后状态一致。
- [ ] 连续使用 20～30 分钟，混合执行长对话、附件、生成、页面切换、暂停/恢复和取消；确认界面持续响应，内存/CPU 没有持续单向增长，日志按 runId 能串起开始、工具、验证和终态且无真实凭据。
