# 统一手动测试清单

所有阶段需要用户执行的手动测试统一记录在此文件。

## 第一阶段

无需手动测试。第一阶段只新增调用方中立 schema、机器覆盖清单和自动化门禁，没有鼠标交互、真实 API、文件导入导出或平台行为改动。

## 第二阶段

无需手动测试。第二阶段新增调用方中立内核、单元测试和设置非破坏性适配入口，未改变现有界面交互，也未接入真实 API、文件导入导出或平台行为。后续领域迁移产生的真实交互验收继续追加在本文件。

## 第三阶段

以下项目涉及真实模型决策和 Electron 主进程运行时，统一保留到全部任务完成后执行；当前不要求逐项测试。

### 1. 多领域任务一次拆解与批量发现

1. 重启 `npm run electron:dev`，打开智能助手。
2. 输入一个同时包含三维场景修改、镜头动作和打开结果界面的明确请求。
3. 验证助手先形成多个可识别子目标，能力发现按整组需求执行，而不是逐关键词反复搜索。
4. 验证真正写入前已取得对应完整参数结构，最终答复只陈述有结构化证据的结果。

### 2. 能力缺失与部分完成主动说明

1. 输入一个包含当前应用明确不支持能力、同时又包含可完成只读查询的组合请求。
2. 验证可完成部分正常结束；缺失部分不会耗尽轮次或换词循环。
3. 验证最终答复明确区分已完成、未完成、证据、阻塞原因和继续所需的最小动作。

### 3. 缺少用户输入时暂停与恢复

1. 要求修改“那个三维对象”，但不提供能唯一定位的工程或对象。
2. 验证助手只提出一个最小且具体的问题，不猜测对象，也不执行写入。
3. 回复明确的工程和对象后，验证助手继续原 Facet，而不是重新创建无关任务。

### 4. 重复写入与 revision 冲突保护

1. 发起一次可观察到稳定对象 ID 和 revision 的三维写入任务。
2. 在运行期间制造目标 revision 变化，或要求以完全相同参数重复创建同一对象。
3. 验证相同 base revision 冲突后必须先刷新状态；已经成功的同指纹写入不会再次执行。
4. 验证助手停止时给出可读的冲突或重复原因，不把拦截描述成成功。

## 第四阶段

以下项目涉及 Electron 页面切换、鼠标接管、真实 WebGL 视口和运镜观感，统一保留到全部任务完成后执行；当前不要求逐项测试。

### 1. 三维组合任务提前开屏与实体复用

1. 重启 `npm run electron:dev`，准备一个包含默认摄像机与镜头的三维工程。
2. 在智能助手中要求：打开该工程，在主体两侧无重叠地放置两个不同基础物体，并让现有摄像机环绕主体。
3. 验证助手取得稳定工程引用后立即打开三维 Surface，再执行对象摆放和运镜，而不是结束时才打开。
4. 验证默认/活动摄像机被复用，没有机械新增重复摄像机；两个未指定坐标的物体不完全重叠。
5. 验证最终答复能指出复用/新建对象、布局、活动摄像机、轨迹或关键帧和 revision 证据。

### 2. 显式坐标、布局冲突与 revision 保护

1. 要求把一个新物体放到已占用的明确坐标，并明确表示允许重叠。
2. 验证显式意图优先于自动布局，结果同时能报告检测到的空间重叠，而不是悄悄移动对象。
3. 再次发起同一写入，并在提交前通过界面修改工程制造 revision 变化。
4. 验证旧 base revision 不会继续提交；助手先刷新状态或明确报告冲突。

### 3. 简单模式与专业模式运镜

1. 在简单模式分别执行 `orbit`、`dolly`、`truck`、`crane` 的代表性动作并播放结果。
2. 验证动作方向、距离/角度/高度、时间和缓动符合请求，结果物化为可见镜头路径。
3. 切换专业模式后执行一次环绕或推拉并播放，验证结果物化为关键帧，已有有效关键帧没有被无提示破坏。
4. 使用缺失目标和非法时间区间各发起一次请求，验证返回明确不可执行原因且不产生半成品。

### 4. 用户接管、导航失败与视觉观察降级

1. 任务打开三维 Surface 后，手动切换到其他页面或滚动/操作当前页面。
2. 验证后续步骤不会无条件抢回三维页面，最终说明用户已接管或当前可见状态。
3. 使用已删除或不可访问的工程引用发起三维任务，验证导航失败后不会在错误工程继续盲写。
4. 在三维视口可用时触发构图观察，验证只产生 Henji-AI 应用媒体引用及尺寸、来源、数据等级、遮罩和生命周期信息，不暴露裸本地路径。
5. 关闭或切换目标 Surface 后再次请求观察，验证明确降级，且在没有多模态模型判读时不会宣称画面已经由模型验证。

## 第五阶段

以下项目覆盖第五阶段所有必须由用户操作或依赖真实 API 的验收，继续保留到全部任务完成后统一执行。

### 1. 设置、导航与 Surface 用户接管

1. 重启 `npm run electron:dev`，通过智能助手读取并修改一个普通界面设置，再撤销该修改。
2. 验证界面与设置页显示一致，敏感密钥和本地路径只返回“已配置/未配置”等状态。
3. 要求助手打开设置、素材和画布 Surface；打开后手动切换页面，验证后续步骤不无条件抢回页面。

### 2. 画布、素材、图片编辑与分镜交互

1. 打开一个既有画布项目，分别执行节点新增、移动、连线、批量修改与撤销，验证旧项目正常读取且每组批量操作只形成一个撤销单元。
2. 从素材库拖入一张真实图片，验证公开结果不显示本地文件路径，画布仍能正常加载素材。
3. 使用鼠标完成裁剪/标注等图片编辑并保存为新素材；验证源文件未覆盖，失败后预览仍可重试，成功后新素材可再次入画布。
4. 读取并修改一个分镜节点，验证分镜卡与画布节点状态一致，没有独立的重复写入结果。

### 3. 真实图片、视频与音频生成

1. 配置可用的真实 API key，分别选择一个图片、视频和音频模型提交最小生成任务。
2. 验证每个任务先显示已提交/等待外部结果，再持续更新进度；模型参数与当前界面 schema 一致，没有模型专用硬编码错误。
3. 在一个可取消任务运行期间执行取消，验证任务进入取消终态且不会继续报告完成；对失败任务按现有界面流程重试或恢复。
4. 验证完成结果以稳定任务/结果/Artifact 引用被助手读取，界面能播放或展示媒体，助手输出不包含裸本地路径。

### 4. 工作流、助手恢复与 Artifact 分页

1. 执行“模型生成并放入画布”确定性工作流，验证计划只审批一次、步骤顺序固定、生成完成状态不被“已提交”提前替代。
2. 在安全步骤间暂停并恢复工作流，再执行一次取消；验证状态、可取消/可恢复标志、已完成步骤和证据一致。
3. 运行一个会产生大型结果的助手任务，关闭并重启应用后恢复同一 run，验证事件游标、外部等待和 Artifact 引用保持一致。
4. 分页读取大型 Artifact 直到 `hasMore=false`，验证没有重复页、越权字段或裸路径；诊断失败时仍通过既有诊断能力返回脱敏证据。

## 第六阶段（暂存，最终收口时继续去重）

### 1. 对话滚动与用户接管

1. 在 960×640 窗口运行一个会持续输出长文本、工具记录和折叠卡片的助手任务，停留底部时确认内容持续跟随。
2. 分别用鼠标滚轮/触控板上滑、拖动滚动条和键盘 PageUp 浏览历史，确认新内容不抢回位置，并出现“有新内容”。
3. 展开工具卡、缩放窗口后确认位置仍可控；点击“有新内容/回到底部”恢复跟随，新建 run 后也恢复默认跟随。

### 2. 复杂任务状态、证据与恢复

1. 运行一个至少包含两个独立子目标、一次外部等待和一次结构化验证的任务，确认计划卡能区分完成、进行中、等待、受阻和依赖跳过。
2. 制造一次 revision 冲突或权限不足，确认界面说明原因与可执行下一步，不显示为无响应或成功。
3. 暂停、取消或重启应用后恢复该 run，确认已完成步骤、Facet 状态、验证结论和大型证据引用保持一致。

### 3. 多模态模型声明与真实请求

1. 在智能助手模型设置中分别为主模型与观察模型配置图片/音频能力，执行真实图片和音频输入，确认主模型优先、观察模型按需回退。
2. 选择仅声明视频能力的 openai-compatible 模型提交视频，确认请求发出前明确提示协议不支持，且视频地址未作为普通文本发送。
