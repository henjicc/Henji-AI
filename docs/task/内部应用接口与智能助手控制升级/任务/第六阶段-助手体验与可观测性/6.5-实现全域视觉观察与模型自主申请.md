# 6.5 实现全域视觉观察与模型自主申请

## 任务状态

- 状态：待开始
- 所属阶段：第六阶段 · 助手体验与可观测性
- 前置任务：2.2、3.3、5.1、5.2、5.3、5.4、6.3、6.4
- 关联任务：4.4、6.2、7.1、7.2
- 是否可以并行：否；需要领域迁移、媒体上下文和多模态门禁完成后统一收口

## 任务目标

让模型在认为结构化状态不足时，可以自主申请观察任意已注册 Surface、3D/画布视口、图片编辑结果、生成结果或素材媒体，并获得经过范围限制、敏感遮罩和上下文预算处理的视觉/媒体证据。全部 Surface 必须覆盖，不能只为 3D 写特例。

## 当前情况

- Surface 注册表已有约 22 个界面目标，但没有统一观察提供者和截图范围契约。
- 4.4 会先实现 3D 视口观察样板，第五阶段会为其他领域建立稳定实体和媒体引用。
- 生成结果和素材应直接观察原始媒体或受限预览，不应通过截取整个页面读取缩略图。
- Electron 可以提供应用窗口内容捕获能力，但若不限制区域和脱敏，可能包含 API Key、路径或无关界面。
- 模型输入模态由 6.3 控制，附件/媒体引用和 provider 转换由 6.4 提供。

## 实施方案

在 Surface 注册表中要求每个 Surface 声明观察提供者、捕获范围、数据等级和敏感遮罩策略。观察能力接受稳定 Surface/entity/mediaRef 和用途，返回结构化状态、视觉媒体引用、revision、遮罩摘要和验证限制。优先级为“领域结构化观察 → 原生媒体/预览 → Surface 区域截图”。模型可以提出观察请求，但执行器负责权限、模态、范围和预算裁决。

## 执行步骤

1. 为全部注册 Surface 建立观察覆盖矩阵，逐项指定结构化提供者、原生预览或通用 Surface 截图，不允许无理由空缺。
2. 扩展 Surface 注册契约，声明稳定目标、可观察区域、数据等级、敏感 DOM/字段、支持模态、最大尺寸和失效条件。
3. 实现通用应用内 Surface 区域捕获：由渲染层提供目标边界和遮罩，主进程只捕获 Henji-AI 窗口的批准区域；禁止 OS 全屏和其他窗口。
4. 为 3D/画布/图片编辑使用专用视口或画布预览；为生成结果、素材、视频和音频优先返回稳定媒体引用及必要元数据。
5. 注册只读语义观察能力，输入包含目标引用和观察目的；可用性由 primary/observer 模态、数据等级、当前 Surface、用户取消和上下文预算决定。
6. 对图片执行尺寸/质量预算；对视频和音频使用 provider 明确支持的内容方式和时长限制，不宣称不受支持的隐式转换。
7. 将观察请求、截图范围、遮罩项、媒体摘要和使用模型写入现有结构化日志与 Artifact；模型最终回答必须区分“已视觉验证”和“仅结构化验证”。
8. 对每个 Surface 加覆盖测试，并增加密钥遮罩、越界捕获、错误模态、observer 回退、媒体失效、上下文超限和用户取消测试。
9. 准备全 Surface 人工巡检清单，逐项确认截图只包含目标区域、遮罩有效、视觉证据能被模型使用。
10. 更新覆盖矩阵、技能规则、重要记录和任务总览，独立提交。

## 涉及内容

### 新增文件

- 内部应用控制层的观察能力、Surface 捕获契约、媒体预算与脱敏模块及测试。
- 各领域必要的观察提供者；按领域放置，不建立巨型截图处理文件。

### 修改文件

- `src/features/assistant/applicationCapabilities/surfaceRegistry.ts` 或 5.1 迁移后的调用方中立 Surface 目录
- 全部注册 Surface 的根容器/提供者：仅增加稳定捕获边界和敏感标记，不复制业务逻辑。
- `src/features/assistant/hostActions.ts` 或迁移后的观察适配器
- `electron/main/`、`electron/preload/` 和 `src/platform/` 中必要的受限应用窗口捕获链路
- 3D、画布、图片编辑、素材和生成结果的预览/媒体引用入口
- Agent 工具目录、权限、Artifact、日志、模型执行和结果验证模块。

### 可能废弃

- 领域内部只供某个助手工具使用的临时截图或预览入口；统一观察提供者覆盖后删除。

## 特殊风险与回退

- 捕获范围或遮罩校验失败时拒绝观察，不回退为全窗口截图。
- 模型不支持目标模态且没有合格 observer 时返回明确不可用原因，不把媒体 URL 当普通文本伪装输入。
- 观察结果只读且可丢弃；关闭观察能力不应影响领域业务数据或页面正常使用。

## 验收标准

- [ ] 全部已注册 Surface 均有可用观察提供者和自动覆盖门禁。
- [ ] 模型可以基于任务需要自主申请观察，工具是否开放由真实模态和权限动态决定。
- [ ] 3D、画布、图片编辑使用领域预览，生成结果和素材优先使用稳定媒体引用。
- [ ] 通用截图只包含 Henji-AI 目标 Surface 区域，API Key、路径和敏感内容已遮罩。
- [ ] 不支持图片/视频/音频的模型不会收到对应内容，observer 回退有明确证据链。
- [ ] 最终结果能区分视觉验证、结构化验证和未能验证。
- [ ] 对应 lint、双端 TypeScript、Electron/能力/观察/安全测试和 UI 检查通过；全 Surface 真实视觉巡检由用户验收。
- [ ] 覆盖矩阵、重要记录和任务总览已同步，任务有独立提交。
