# 4.2 实现场景状态复用与无冲突空间布置

## 任务状态

- 状态：已完成
- 所属阶段：第四阶段 · 三维运镜端到端样板
- 前置任务：2.3、4.1
- 关联任务：4.4
- 是否可以并行：可以；与 4.3 并行

## 任务目标

让 3D 任务在写入前读取真实场景，按角色复用已有摄像机、镜头和对象；新增物体时根据尺寸、包围盒和用户意图选择无冲突位置，避免重复摄像机和物体重叠。

## 当前情况

- 默认场景已经包含摄像机和镜头，但助手曾在读取状态前再次创建摄像机。
- 当前添加对象能力没有位置参数，多个基础几何体会落在相同默认原点。
- 领域对象可表达变换信息，尚缺面向自动布置的场景摘要、包围盒和冲突检查服务。
- Blender MCP 的对象详情和 AABB 思路可参考，但不能依赖名称猜测或固定只读前十个对象。

## 实施方案

在 3D 应用服务中增加面向规划的场景观察和布置策略。助手先按实体类型、角色、稳定引用和名称别名匹配现有对象；只有明确不存在且任务需要时才创建。布置器根据对象包围盒、目标关系、构图区域和安全间距提出候选位置，结果仍通过 2.3 事务协议提交。

## 执行步骤

1. 定义 3D 场景观察摘要，包含默认/活动摄像机、镜头、对象类型、稳定引用、变换、包围盒和关系。
2. 实现基于角色和引用的对象复用规则，名称仅作为辅助；明确“必须新建”和“优先复用”语义。
3. 扩展基础几何体创建 schema，支持位置、旋转、缩放、尺寸、父级和语义布局提示。
4. 实现可测试的无冲突候选布局算法，支持并排、环绕目标、前后景和用户明确坐标。
5. 在计划阶段返回复用/创建决策和布局理由，提交前检查 baseRevision 与占用变化。
6. 增加默认摄像机复用、同名对象、两个几何体并排、用户指定重叠和并发冲突测试。
7. 将代表性失败请求加入助手评测，但不写死立方体/棱锥专用规则。
8. 更新任务记录并独立提交。
