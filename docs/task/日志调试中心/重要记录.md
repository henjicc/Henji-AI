## 记录 003：AI 访问方式采用"文件即接口"，不做 MCP server

- 日期：2026-07-10
- 状态：已确定
- 背景：用户希望 AI 编程工具能自助读取日志，提出 MCP 或某种脚本接口的设想。日志已是固定路径的结构化 JSONL 文件，AI 工具自带文件读取能力，MCP/HTTP 服务对单机桌面应用属于过度设计且引入常驻进程负担。
- 最终决定：JSONL 文件 + `scripts/query-logs.cjs` 查询脚本 + CLAUDE.md 路径/用法约定，即为 AI 访问接口；不做 MCP server。若后续确有跨机器/多工具共享需求，另立计划。
- 选择原因：零额外运行时成本、零新依赖，AI 与人共用同一套查询方式，最稳。
- 影响任务：3.1、任务范围界定
