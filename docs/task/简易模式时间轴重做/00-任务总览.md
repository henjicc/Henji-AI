# 简易模式时间轴重做 · 任务总览

## 任务目标

运镜控制简易模式当前的镜头卡时间轴（`src/features/cameraStage/simple/ShotTimelinePanel.tsx`）过于简易：卡片固定宽度、不反映真实时长，停留/过渡时长靠数字输入框，过渡细节入口挂在卡片下方，没有时间标尺和播放头，无法拖动预览。

本任务参考 Adobe Premiere Pro 的时间轴设计风格，将简易模式时间轴重做为**按时长比例铺排的"静止块 + 过渡块"轨道**：块宽 = 时长 × 像素比例、零间隙铺满；带时间标尺和可拖动播放头（scrub 实时预览）；过渡块夹在两个静止块中间、点击弹出参数气泡；块边缘拖拽调时长（按帧吸附）、块身拖拽重排、滚轮缩放。时长最小单位从秒改为帧（fps=30），停留 ≥1 帧，过渡 ≥0 帧（0 = 硬切）。随后扩展**多机位硬切**：每张镜头卡记录拍摄机位，机位不同的相邻卡之间硬切，播放/scrub/视频导出按时间表切换渲染机位。

**属于本次任务**：时间轴表现层重做（比例块轨道、标尺、播放头、选择联动、过渡气泡、过渡段视口只读）、编辑手感（trim、重排、缩放）、帧单位时长、多机位硬切（数据模型、播放视口切换、视频导出切换）、整体回归验收。

**不属于本次任务**：镜头卡数据模型的结构性重构（过渡仍挂在前一张静止卡上，见重要记录 001）、专业模式时间轴改动、跨机位带时长过渡（机位不同强制硬切，见重要记录 005）、片段缩略图、时间轴概览小地图条、轨道头锁定/可见性开关、自定义缓动曲线编辑（重要记录 006）。

## 重要说明

- 数据模型不做结构性改动：过渡仍挂在前一张静止卡的 `transitionDuration` + `transition` 字段上，时间轴上"过渡是独立块"只是表现层（重要记录 001）。
- 时长最小单位为帧：写入时量化到 `n / fps`，停留 ≥1 帧、过渡 ≥0 帧，过渡 0 帧 = 硬切（重要记录 002）。
- 播放头落在过渡段内时视口只读：隐藏 gizmo、阻断自动记录，防止把插值画面误录进选中卡（重要记录 003）。
- 过渡参数面板形态：过渡块上方弹出锚定气泡，替代现有底部抽屉（重要记录 004，用户已选定）。
- 多机位规则：相邻两卡机位不同时强制硬切，不支持跨机位带时长过渡（重要记录 005）。
- 遵守项目治理约束：新文件 ≤400 行、禁止新增裸 any、颜色走 token、UI 只用 `Ui*` primitives、关键链路补 `createLogger` 日志、鼠标交互类验证写清步骤交用户手测。
