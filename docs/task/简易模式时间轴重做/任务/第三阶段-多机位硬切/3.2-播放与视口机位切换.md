# 3.2 播放与视口机位切换

## 任务状态

- 状态：已完成
- 所属阶段：第三阶段-多机位硬切
- 前置任务：3.1、1.3
- 关联任务：3.3（导出必须与本任务的预览行为一致）
- 是否可以并行：否

## 任务目标

摄像机视角模式下，播放/scrub 时视口按 3.1 的渲染机位时间表切换渲染机位；时间轴静止块显示机位徽标并可修改机位；跨机位的过渡在 UI 上明确呈现为硬切（剪切线 + 气泡内禁用时长编辑并提示）。

## 当前情况

- 视口渲染机位：`scene/StageScene.tsx:92-95` 由 `activeCameraId` 找 `activeCamera`，`viewMode === 'camera'` 时用其渲染；画幅遮罩 `StageAspectRatioOverlay.tsx:20-21` 同样跟 `activeCameraId`。
- `activeCameraId` 同时承担"编辑机位"语义：对象列表选中摄像机会切它（`cameraStageStore.ts:328/346/370`），删除摄像机有回退逻辑（:353）。**不能简单地在播放中改写 `activeCameraId`**——需要区分"编辑机位"（用户显式选择）与"播放渲染机位"（时间表派生）。
- 播放驱动：`scene/StagePlaybackDriver.tsx` 逐帧推进 `currentTime`；scrub 走 `seek`。
- 机位选择 UI 落点：静止块（1.2 的 `StaticClipBlock`）；顶栏已有摄像机下拉（`CameraStageEditor.tsx:290-293`）语义是全局 activeCamera。
- 过渡气泡：1.3 的 `TransitionPopover`。

## 实施方案

- **渲染机位派生而非改写**：视口取"当前渲染机位" = 简易模式且摄像机视角时 `resolveRenderCameraAt(schedule, currentTime)`，否则回落 `activeCameraId`。做成一个 selector/hook（如 `useRenderCameraId`），`StageScene` 与 `StageAspectRatioOverlay` 统一消费，不新增平行状态、不在播放循环里写 store。
- 时间表来源：由 `shots` + `activeCameraId`（fallback）用 `useMemo` 派生，避免每帧重算。
- **静止块机位徽标**：块内显示机位名（无指定机位显示"跟随默认"）；点击徽标弹机位选择（复用现有 `Dropdown`），写 `updateShotCamera`。
- **跨机位过渡呈现**：布点已是硬切（3.1），时间轴上该段显示为剪切线并带机位切换标记（如 A→B）；点击气泡显示"两侧机位不同，此处为硬切"，时长输入禁用。
- 选中卡时的编辑视角：`selectShot` 应用快照后，若该卡指定了机位，把 `activeCameraId` 同步为该卡机位（用户点卡 = 进入该卡的拍摄视角编辑），这是显式用户动作，允许写 store。
- 补日志：机位切换渲染无需逐帧日志；`updateShotCamera` 补 `logger.debug`。

## 用户手测清单（鼠标交互，需用户在真实 Electron 中验证）

1. 新建工程，添加摄像机 A、摄像机 B（顶栏"+摄像机"两次），确认已建的镜头卡机位徽标显示"跟随默认"。
2. 切到镜头卡 1，点机位徽标选摄像机 A；新建镜头卡 2（"添加片段"），点其机位徽标选摄像机 B。
3. 切换到摄像机视角（顶部视角按钮），点击播放：播放头经过卡 1→卡 2 切换点时，视口画面应瞬间跳到摄像机 B 的取景（硬切，无渐变），画幅遮罩同步跟随切换（若两台摄像机画幅不同——正常不应发生，见 3.1 的画幅锁定）。
4. 拖动标尺 scrub 到切换点前后：视口应实时跟随切换，无需暂停/播放即可看到切换效果。
5. 点击卡 1 静止块：视口应自动切到摄像机 A 视角（顶栏摄像机下拉同步高亮 A）；点击卡 2 应切到摄像机 B。
6. 卡 1、卡 2 之间的过渡块应显示为一条竖线上叠加一个小摄像机图标（区别于普通硬切的纯竖线），鼠标悬浮提示"机位切换（强制硬切）"；点击弹出气泡，顶部应有"机位切换：A → B…"提示条，"时长（帧）"输入框应为禁用态（灰色不可编辑）。
7. 把卡 2 机位徽标改回摄像机 A（与卡 1 一致）：过渡块应恢复为可编辑的正常过渡样式（气泡时长输入框恢复可用，右边缘可拖拽调整时长）。
8. 撤销/重做（Ctrl+Z / Ctrl+Shift+Z）：机位徽标切换、`selectShot` 引发的 `activeCameraId` 同步不应产生额外的撤销栈条目（`activeCameraId` 本身不进撤销历史，属于预期设计）。
9. 打开一个旧工程（无 cameraId 字段，或本任务之前保存的工程）：镜头卡机位徽标应全部显示"跟随默认"，播放/scrub 行为与改动前一致（不出现意外的硬切/机位跳变）。
