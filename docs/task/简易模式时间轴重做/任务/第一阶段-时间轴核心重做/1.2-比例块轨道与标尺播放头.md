## 任务目标

把 `ShotTimelinePanel` 从"固定宽卡片一排"重做为 PR 风格比例块时间轴：静止块/过渡块按时长比例零间隙铺排、时间标尺可拖 scrub、播放头竖线贯穿、点击静止块切视角、scrub 在静止段内跟随选中。完成后旧卡片式布局被替换（增删改名、时长输入的能力不丢失）。

## 实施方案

面板纵向结构：工具条（保留 `PlaybackButtons` + 时间码 + "添加片段"按钮）→ `TimeRuler`（onScrub → `seek`）→ 块轨道（横向滚动容器）→ 播放头竖线 overlay（贯穿标尺与轨道）。

- 块轨道新组件 `ShotClipTrack.tsx`：消费 `buildClipLayout(shots, pxPerSecond)` 渲染 `StaticClipBlock` / `TransitionClipBlock`；本任务 `pxPerSecond` 先用固定初值（如 120，缩放在 2.3）；末尾接"+ 添加片段"虚线块（固定宽，不参与时间映射）。
- 静止块：名称 + 时长文本，选中态（accent 边框）、播放头所在态（顶部高亮条，沿用现有 ShotCard 的语义）；双击内联重命名（沿用 ShotCard 的 UiInput 模式）；悬浮显示删除小按钮。极窄块保底最小可视宽度约 16px（视觉溢出但命中区仍在）。
- 过渡块：更矮/不同底色，中间显示时长；0 帧硬切渲染为一条可点击的剪切竖线（本任务只画形态，点击行为 1.3 接）。
- **选中跟随播放头（关键，见重要记录 003 前置逻辑）**：监听 `playback.currentTime`，用 `findClipAtTime` 判断播放头落点；落入静止段且卡不同 → **只 set `selectedShotId`**（非 tracked 界面态），不调用 `selectShot`（避免重复应用快照污染撤销历史；静止段采样值本就等于卡快照）。需要在 store 增加一个轻量 action（如 `setSelectedShotIdOnly`）或直接 `set({ selectedShotId })` 的显式 action。
- 点击静止块仍走 `selectShot`（显式切视角 + 播放头跳卡起点）。
- 时间码显示先沿用 `formatTimecode` 秒模式（重要记录 008 待确认，完成后向用户展示定稿）。
- 停留/过渡时长的数字输入在本任务从块上移除（trim 在 2.1、过渡时长进 1.3 气泡）；过渡期间若用户需要精确输入，1.3 气泡里保留数字输入（帧）。

### 用户手测清单（鼠标交互，需用户在真实 Electron 窗口操作验证）

进入运镜控制工作区 → 简易模式（编辑器模式=simple）→ 时间轴面板：

1. 新建/已有多张镜头卡时，块宽是否与"停留 + 过渡"时长成比例（可对照工具条时间码估算）；标尺刻度是否与块边界对齐。
2. 拖动时间标尺（scrub）：暂停态下画面是否实时预览；播放头在静止段内应画面静止，在过渡段内应画面运动。
3. 单击某个静止块：是否切到该卡视角（视口画面立即变化），播放头是否跳到该卡起点。
4. 拖动播放头（scrub）经过不同静止段：对应静止块是否自动变为"选中态"（accent 高亮边框）；执行几次 Ctrl+Z，确认没有因为这个跟随过程多出撤销记录（撤销步数应只对应你手动做的编辑操作）。
5. 双击静止块名称文本：应进入内联编辑，输入新名字后按 Enter 或点击别处应提交生效；按 Esc 应取消编辑。
6. 悬浮静止块：右上角应出现删除小图标；点击应删除该卡（若删的是当前选中卡，选中应落到相邻卡）。
7. 点击轨道末尾"+ 添加片段"虚线块，或工具条右侧位置：应在当前选中卡之后插入新卡。
8. 若存在过渡时长为 0 的卡（硬切），轨道上应显示为一条可点击的细竖线（非色块）；点击应展开底部过渡细节面板（旧版逐对象参数面板，非最终气泡样式——这是 1.3 前的过渡态 UI，属预期行为）。
9. 点击有时长的过渡块（非硬切）：也应展开同一个过渡细节面板。
10. 工具条时间码文本：普通点击不应有反应；按住 Ctrl 键点击应循环切换显示格式（纯秒 → 纯帧 → 秒:帧 hh:mm:ss:ff → 循环回纯秒）。
11. 确认：本阶段暂时无法通过界面把硬切改回有时长过渡、也无法把普通过渡改成硬切（该能力等 1.3 上线），出现这个限制属预期，不是 bug。
