# 1.3 过渡参数气泡与过渡段只读

## 任务状态

- 状态：已完成
- 所属阶段：第一阶段-时间轴核心重做
- 前置任务：1.2
- 关联任务：3.2（机位不同的过渡在气泡中禁用时长编辑）
- 是否可以并行：否

## 任务目标

两件事：① 点击过渡块（含硬切剪切线）在块上方弹出锚定参数气泡，替代底部抽屉（重要记录 004）；② 播放头落在过渡段内时视口只读——隐藏 gizmo、显示提示、阻断自动记录（重要记录 003），根治插值状态误录进选中卡的问题。

## 当前情况

- 过渡细节现为底部抽屉：`simple/TransitionDetailPanel.tsx`（35 行，容器）+ `TransitionObjectRow.tsx`（逐对象行：速度预设、错峰延迟、摄像机运镜预设 orbit/dollyIn/dollyOut/truck/crane、角色动作覆盖）。只显示有差异对象（`diffShotObjects`，来自 `domain/shotCompiler.ts`，交接文档要求必须复用不另写 diff）。
- 写回：store `updateShotTransition(id, patch)`（`store/shotSlice.ts:158`）每次调用重编译并进 zundo 历史；过渡时长走 `updateShotTiming`。
- 自动记录链路：`compileSimpleEdit`（`store/shotSlice.ts:92`）在 `editorMode==='simple' && 非播放 && selectedShotId` 时把编辑捕获进选中卡——**当前没有"播放头是否在选中卡静止段内"的判断**，这是误录隐患的根源。
- gizmo：`scene/StageScene.tsx` 挂 `StageTransformControls`（选中对象时显示）。
- 播放头落点判断：1.1 的 `findClipAtTime`；1.2 已把它接进面板。
- 气泡类组件现状：项目有 `Dropdown` / `PanelTrigger` 等通用弹层组件（CLAUDE.md 要求通用优先，新增组件前先确认现有覆盖不了并向用户说明）。

## 实施方案

**气泡**：新建 `simple/timeline/TransitionPopover.tsx`，锚定在过渡块上方（约 380px 宽，max-height + 内部滚动）：

- 顶部常用区：过渡时长（帧数字输入，写回 `updateShotTiming`，0 = 硬切）+ 速度预设。
- 下方折叠区：逐对象细节，直接复用 `TransitionObjectRow`（不复制其内部实现）；无差异对象时沿用"这两个片段之间没有变化"空态。
- 弹层容器优先复用现有通用弹层组件；确认覆盖不了再新增（先向用户说明原因）。
- 硬切剪切线点击同样弹此气泡，把时长改 >0 帧即恢复为过渡块。
- `TransitionDetailPanel.tsx` 容器若无消费方则删除（`TransitionObjectRow` 保留）。

**过渡段只读**：

- 派生判断（放 `shotClipGeometry.ts` 或 selector）：`isTimeInTransition(shots, time)`。
- `StageScene.tsx`：简易模式且播放头在过渡段 → 不挂 `StageTransformControls`。
- 视口提示条（复用现有 overlay 模式，如 `StageAspectRatioOverlay` 同级）："过渡画面由前后片段决定，点击前后片段进行编辑"。
- `compileSimpleEdit` 守卫：播放头不在**选中卡静止段区间内**时直接返回 `{ objects }` 不捕获（用 `getShotTimeRanges` 判断，容差取帧的一半）。这同时覆盖了"播放头在别的卡上却把编辑录进选中卡"的情况。

### 用户手测清单（鼠标交互，需用户在真实 Electron 窗口操作验证）

1. 点击有时长的过渡块：应在块正上方弹出参数气泡（约 380px 宽），顶部显示"时长（帧）"输入框与"批量设置"速度预设按钮。
2. 修改时长输入框为 0：气泡内应出现"时长为 0 帧 = 硬切…"提示，气泡关闭后轨道上原过渡块应变为一条细竖线（硬切）。
3. 点击该硬切细线：应再次弹出同一个气泡；把时长改回大于 0，关闭气泡后应恢复为正常过渡块。
4. 展开气泡"逐对象细节"：应看到与旧版一致的逐对象行（速度/延迟/运镜或过渡动作），修改任一项应立即生效（可通过再次打开气泡验证已保存）；若两片段间没有差异对象，应显示"这两个片段之间没有变化"。
5. 点击"批量设置"选一个速度预设：应把该预设应用到当前有差异的全部对象（展开逐对象细节可逐一确认）。
6. 点击气泡外部任意位置（如另一个静止块、空白轨道区）：气泡应关闭。
7. 拖动播放头（scrub）进入某段过渡区间：视口右上角/顶部应出现"过渡画面由前后片段决定，点击前后片段进行编辑"提示条；此时若之前有选中对象，视口中的位移/旋转/缩放拖拽把手（gizmo）应消失。
8. 在过渡段内尝试通过右侧属性面板修改数值（如颜色）：数值输入应仍可操作（不报错），但退出过渡段回到静止块后确认该镜头卡的画面未被这次输入污染（即编辑没有被错误记录进卡）。
9. 播放头离开过渡段、回到某静止块内：gizmo 应重新出现，提示条消失，正常拖拽编辑应能写入该卡（可撤销）。
10. 新建一张镜头卡（点"添加片段"）后立即拖拽 gizmo 调整画面：确认新卡的画面按预期被记录（新卡此前无该能力回归，需重点验证）。
