# 2.3 滚轮缩放与阶段打磨

## 任务状态

- 状态：待开始
- 所属阶段：第二阶段-编辑手感
- 前置任务：2.1、2.2
- 关联任务：无
- 是否可以并行：否（阶段收尾）

## 任务目标

时间轴支持滚轮锚点缩放（指针位置时间点保持不动）；初始缩放自适应总时长；补齐第一二阶段的视觉与交互毛边；跑全套静态检查完成阶段回归。

## 当前情况

- 专业模式已有滚轮锚点缩放实现：`timeline/TimelinePanel.tsx:163-172`（`anchorTime` 反解 + `clampPxPerSecond`），照抄模式即可。
- `timeScale.ts`：`clampPxPerSecond`（40~600）、`TIMELINE_MIN_PX_PER_SECOND` 等常量现成。
- 1.2 的 `pxPerSecond` 是面板本地 state 固定初值，本任务把它变成可缩放 + 自适应。
- 时间码格式（重要记录 008）在 1.2 展示后应已定稿；若仍未定，本任务收口前必须与用户确认。

## 实施方案

- 滚轮缩放：Ctrl/无修饰滚轮（与专业模式行为保持一致，执行时对照 TimelinePanel 的触发条件）在轨道/标尺区域缩放，锚点为指针所在时间；缩放后调整横向滚动位置保持锚点不动。
- 初始自适应：面板挂载/总时长变化显著时，取 `clampPxPerSecond(可视宽度 / duration)` 让整条时间轴默认尽量可见。
- 打磨清单（执行时逐项过）：极窄块最小可视宽度与命中区复核；标尺缩放大时切帧刻度（`generateTicks` frames 模式）；横向滚动时播放头/标尺对齐；空态与单卡状态展示；块文本溢出截断；时长浮签样式统一。

## 执行步骤

1. `ShotTimelinePanel` 接滚轮锚点缩放（照抄专业模式模式）与初始自适应。
2. 逐项过打磨清单，修补 1.2/2.1/2.2 落下的视觉与交互毛边。
3. 与用户确认时间码格式（重要记录 008）并按定稿实现。
4. 阶段回归：`npm run test`、`npm run lint`、`npx tsc -p tsconfig.electron.json --noEmit`、`npx eslint electron --ext ts --max-warnings 0`、`npm run check:colors`、原生控件检查、文件行数检查（新文件 ≤400 行）。
5. 写用户手测清单：滚轮缩放锚点不漂移、缩放极限行为、打开工程默认全览、帧刻度出现时机、整体流畅度。
