## 实施方案

- 滚轮缩放：Ctrl/无修饰滚轮（与专业模式行为保持一致，执行时对照 TimelinePanel 的触发条件）在轨道/标尺区域缩放，锚点为指针所在时间；缩放后调整横向滚动位置保持锚点不动。
- 初始自适应：面板挂载/总时长变化显著时，取 `clampPxPerSecond(可视宽度 / duration)` 让整条时间轴默认尽量可见。

### 用户手测清单（真实 Electron 窗口，`npm run electron:dev`）

1. 打开一个已有多张镜头卡的工程：时间轴应默认自动缩放到大致铺满可视宽度（不需要手动滚动就能看到
   全部内容，或至少大部分内容）。
2. 在轨道/标尺区域按住 Alt 键并滚动鼠标滚轮：时间轴应放大/缩小，且鼠标指针所在的时间点在缩放前后
   视觉位置基本不变（不会"跳来跳去"）。
3. 持续缩小（Alt+滚轮向下）到极限：应停在某个最小密度不再继续缩小（40px/s）；持续放大到极限应停在
   某个最大密度（600px/s）。
4. 缩放到较大密度（明显超过默认值）后观察标尺：刻度标签应从"X.XXs"形式切换为"Nf"帧数形式。
5. 缩放后进行横向拖动滚动条：播放头竖线、标尺刻度、镜头卡块应始终保持对齐，不出现错位。
6. 不使用 Alt 直接滚动鼠标滚轮（无修饰键）：应正常触发页面/容器滚动，不触发缩放（确认没有误触发）。
7. 缩放几次之后，新增一张镜头卡或调整某张卡时长：时间轴不应再自动跳回"铺满"状态（因为已经手动缩放
   过），应保持用户当前选择的缩放级别。
8. 整体流畅度：在有若干镜头卡的工程里快速交替进行选卡/拖拽 trim/拖拽重排/滚轮缩放，操作响应应流畅、
   无明显卡顿或视觉跳变。
