# 全局资产库任务总览

## 任务目标

建立跨生成、画布和工具箱工作区共享的全局资产库，让图片、视频、音频结果以“引用已有持久化文件”的方式加入一个或多个库，并能从标题栏快速悬浮调用或进入完整工作区管理。第一版同时支持鼠标触边唤起、拖拽调用、生成结果收录、画布投放和 3D 镜头导出收录。

本次包含本地资产索引、多库分类、标题栏双形态入口、触边交互、跨工作区拖放和基础管理；不包含云同步、多人协作、AI 自动标签、资产版本管理、独立 Electron 子窗口和复杂文件夹树。

## 重要说明

- 资产库是应用全局能力，核心文件、数据库和文件检查必须位于 Electron 主进程；渲染层只负责界面、轻量状态和交互编排。
- 第一版的“库”是逻辑分类。同一资产可加入多个库，底层媒体不因分类重复复制。
- 生成历史不是资产库数据源。历史记录删除、数量清理不能自动删除资产记录或资产仍在使用的媒体。
- 顶部悬浮面板和完整资产工作区必须复用同一套浏览组件与状态，不建立两套功能实现。
- 鼠标操作验收由用户在真实 Electron 窗口中手动完成，任务文件需记录具体步骤和观察点。
