# 4.1 接入 3D 镜头图片与视频资产导出

## 任务状态

- 状态：待开始
- 所属阶段：第四阶段（3D 导出与整体验收）
- 前置任务：3.1、3.3
- 关联任务：4.2
- 是否可以并行：否

## 任务目标

让 3D 镜头参考的当前帧和视频导出结果可直接加入指定资产库，支持连续导出多个镜头时复用上一次目标库，并保持现有画布节点输出与后台视频渲染安全规则。

## 当前情况

- `persistSceneScreenshot()` 已将当前帧写入应用媒体目录并返回稳定 `henji-media://` URL。
- `exportCameraStageVideo()` 和后台 `camera-stage-render` 最终返回稳定 `mediaPath/mediaUrl`，画布节点已有视频渲染状态与完成事件。
- `CameraStageEditor.tsx` 同时服务工具箱独立编辑器和画布嵌入编辑器，导出图片与视频入口共存。
- 视频后台渲染期间已禁止从画布双击重新进入编辑器，资产接入不能破坏该约束。

## 实施方案

在 3D 导出完成边界调用统一资产收录服务，而不是让资产服务参与逐帧渲染。导出 UI 增加可选“加入资产库”和目标库选择，记住上一次选择；画布后台渲染可在发起时保存目标库 id，完成事件中登记结果。登记失败不应把已成功的视频渲染判为失败。

## 执行步骤

1. 为独立编辑器和画布嵌入编辑器设计一致的“加入资产库/目标库”轻量选项与默认行为。
2. 当前帧落盘成功后，将稳定路径、媒体类型、项目/摄像机/时间点来源信息交给统一收录服务。
3. 前台视频导出完成后登记 `mediaPath`；后台画布渲染在完成事件中按发起时目标库登记。
4. 连续导出复用上一次目标库，但库被删除时回退到未分类/待选择状态。
5. 资产登记失败只提示并记录日志，不删除导出文件、不覆盖渲染成功状态。
6. 测试单帧、前台视频、后台视频、重复收录、取消渲染和登记失败路径。

## 涉及内容

### 修改文件

- `src/features/cameraStage/CameraStageEditor.tsx`：资产导出选项和完成回调。
- `src/features/cameraStage/export/cameraStageScreenshot.ts`：暴露稳定实际路径或规范收录结果。
- `src/features/cameraStage/export/cameraStageVideo.ts`：在完成边界提供资产登记所需信息，不侵入帧循环。

- `src/features/canvas/domain/canvasNodes.ts`：仅在确需持久化后台目标库/收录状态时扩展配置字段。
- 3D 与资产库中英文文案。

## 验收标准

- [ ] 当前帧、前台视频和画布后台视频均可加入选定库。
- [ ] 连续导出可复用目标库，库失效时有安全回退。
- [ ] 相同导出路径重复加入不会复制文件或产生重复资产。
- [ ] 资产登记失败不改变图片/视频导出成功结果。
- [ ] 视频渲染期间仍不能双击打开 3D 编辑器，取消渲染不产生资产。
- [ ] 自动检查通过，并记录真实 Electron 导出与拖拽验证步骤。
