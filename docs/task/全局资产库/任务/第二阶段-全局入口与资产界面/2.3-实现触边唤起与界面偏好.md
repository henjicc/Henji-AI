# 2.3 实现触边唤起与界面偏好

- 是否可以并行：否

## 任务目标

实现可配置的鼠标触边自动唤起资产悬浮面板，并确保它不会干扰画布拖动、连线、框选、节点 resize、系统窗口操作和已有原生文件拖放。

## 当前情况

- `DragDropContext.tsx` 已监听全局 mousemove，并用 30px 边缘阈值触发非 Electron 原生拖放。
- 画布拥有多种 pointer 操作，但目前没有统一向应用壳层暴露“正在画布交互”的状态。
- `settingsStore.ts` 使用 Zustand persist 管理全局界面偏好，适合存储资产面板位置、点击行为和触边设置。
- 标题栏固定在顶部，顶部触边与窗口拖动区域存在冲突。

## 实施方案

新增根级 `useAssetEdgeTrigger`，使用 pointer 坐标、停留计时和统一抑制条件控制同一个资产悬浮面板。普通悬停和媒体拖拽采用不同延迟；设置支持启用、边缘位置、悬浮面板位置和 Tab 默认动作。触边状态不写入业务工作区 store。

## 执行步骤

1. 在 settingsStore 增加版本化偏好：Tab 默认动作、悬浮位置、触边启用、触发边缘、普通/拖拽延迟，并定义安全默认值。
2. 建立根级边缘热区和停留状态机，处理进入、取消、打开、指针进入面板和延迟关闭。
3. 扩展或协调 DragDropContext，识别资产拖拽与普通指针，不重复注册冲突的全局监听。
4. 为画布拖动、连线、框选、resize、模态弹窗、窗口失焦和全屏工具建立抑制信号。
5. 在设置界面增加资产库行为区，允许用户调整打开方式和触边行为。
6. 编写状态机测试，并列出真实 Electron 窗口鼠标手动验收矩阵。
