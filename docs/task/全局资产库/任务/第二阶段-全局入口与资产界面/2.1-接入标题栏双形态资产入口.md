## 任务目标

在现有标题栏增加资产入口，建立“顶部悬浮面板”和“完整资产工作区”两个互斥但可切换的展示状态，同时保持原工作区不被悬浮面板切走。

## 当前情况

- `App.tsx` 只维护单一 `activeTab` 字符串。
- `WindowControls.tsx` 内部直接声明 Tab，点击统一调用 `onTabChange`，没有特殊入口状态。
- `TabContainer.tsx` 已支持工作区懒加载与访问后保持挂载。
- 标题栏使用 Electron `drag/no-drag` 区域，新增资产按钮和悬浮锚点必须保持可点击区域声明。

## 实施方案

将工作区 id 类型化，并在 App 壳层新增资产界面状态：`closed/floating/workspace`。标题栏资产入口根据用户偏好打开悬浮或完整形态；悬浮形态记住来源工作区，完整形态作为第四个工作区进入 `TabContainer`。悬浮层在根级 portal/overlay 容器挂载一次，不放进标题栏内部。

## 执行步骤

1. 确认资产 Tab 默认点击行为并更新重要记录。
2. 抽取工作区 id 与 Tab 配置类型，避免继续使用任意字符串。
3. 扩展 `WindowControls` 资产入口事件和两种视觉状态，保持 Windows/macOS 标题栏拖拽区正确。
4. 在 `App.tsx` 管理资产悬浮/完整状态、来源工作区和关闭/展开转换。
5. 在 `TabContainer.tsx` 懒加载 `AssetLibraryWorkspace` 并保持访问后挂载。
6. 添加键盘 `Esc`、重复点击资产入口、从悬浮进入完整管理和返回原工作区的状态测试。
