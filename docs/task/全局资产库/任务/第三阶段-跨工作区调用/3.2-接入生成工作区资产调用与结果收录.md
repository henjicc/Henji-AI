# 3.2 接入生成工作区资产调用与结果收录

## 任务状态

- 状态：待开始
- 所属阶段：第三阶段（跨工作区调用）
- 前置任务：3.1
- 关联任务：3.3、4.2
- 是否可以并行：可与 3.3 并行

## 任务目标

让资产库中的图片、视频和音频可拖入生成工作区的兼容输入，同时让成功生成结果通过右键或快捷动作加入指定资产库。

## 当前情况

- 生成输入状态与上传处理位于 `GenerationWorkspace`、`InputArea.tsx` 和相关 hooks，现有流程会把用户文件写入 Uploads 并维护显示 URL/文件路径双态。
- 模型输入数量和类型由 schema/输入限制决定，不能在资产库集成中绕过。
- `TaskCard.tsx` 的成功结果包含稳定 `filePath` 时支持下载、复制和拖拽，但右键菜单没有资产动作。
- `history` 表与资产库应保持独立，删除历史不等于删除资产。

## 实施方案

将资产 drop 转换为现有上传状态能够消费的本地媒体输入，而不是另建生成参数通道。优先复用稳定文件路径并生成现有显示 URL；如现有 hook 必须消费 File，则通过 PAL 读取为 File/Blob 的适配集中封装。结果收录复用任务 3.1 的统一服务。

## 执行步骤

1. 为生成输入区域增加资产 drop target，按当前模型 schema 判断媒体类型和数量上限。
2. 将资产路径注入现有 `uploadedFilePaths/uploadedVideoFilePaths/uploadedAudioFilePaths` 与显示列表，保持生成请求构建链路不变。
3. 对不兼容类型、超出数量、缺失文件和仍在处理的资产给出明确提示。
4. 在成功结果的图片、视频、音频右键菜单和适当快捷入口加入“添加到资产库/添加到库”。
5. 确认删除生成历史不会移除资产关系或删除被收录媒体。
6. 增加不同媒体类型、数量限制、重复收录和历史删除回归测试。
