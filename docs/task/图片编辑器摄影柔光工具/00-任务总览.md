# 图片编辑器摄影柔光工具

## 任务目标

在现有统一图片编辑器中增加黑柔、白柔和辉光工具，复用 V2 图片编辑文档、工具注册、历史会话和多宿主接入能力。实时预览与原尺寸导出统一采用工作线程中的 WebGPU 算法，Electron 主进程只负责文件读取、保存和无 GPU 时的 Sharp 降级，不新增任何 Sidecar。

本次包含操作契约收口、无 Sidecar 技术验证、多尺度柔光引擎、参数面板、标注与裁剪合成、文件保存、多宿主接入、通用预设和统一验收。不包含 RAW、HDR、十六位专业输出、ACES、OpenColorIO、品牌档位精确复刻、复杂实测点扩散函数卷积和正式独立画布节点界面。

## 重要说明

- 禁止引入 Rust、其他 Sidecar、子进程、UtilityProcess 或为本功能新增原生扩展。
- WebGPU Worker 是实时预览和原尺寸导出的主执行器；Sharp/libvips 只承担兼容降级。
- 图片编辑文档继续使用版本 2，稳定操作 ID 为 `image.diffusion`，固定顺序为“朝向 → 柔光/辉光 → 标注 → 裁剪”。
- 参数半径使用图片空间归一化值，不使用屏幕像素或 CSS 尺寸。
- 首版输出范围为八位 sRGB JPEG、PNG、WebP，默认导出格式待确认。
- 代码基线提交为 `848de59`。其中旧后端命名和旧 Rust 注释将在 2.1 收口，不在计划创建阶段修改。
- 完整自动测试和人工验收集中在 4.2；前置任务只执行完成本任务所需的最小检查和技术门槛验证。
