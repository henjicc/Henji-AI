# 4.1 建立通用预设与图像基线

## 任务状态

- 状态：已完成
- 所属阶段：第四阶段——标定与统一验收
- 前置任务：2.2
- 关联任务：3.1、4.2
- 是否可以并行：可以与 2.3、3.1、3.2 并行，最终冻结需等待引擎稳定

## 任务目标

建立可追溯、无品牌误导的黑柔、白柔和辉光通用预设，生成程序化质量测试图、Golden 图索引和视觉/数值阈值。新执行者无需重新搜索论文或猜测每个模式的目标表现。

## 当前情况

- 核心已有档位、模式和专家参数，但没有正式预设表、来源元数据和调参边界。
- ProMist-5K 论文提供线性空间、六层 Gaussian、密度和焦段差异参考；数据集资产授权尚未确认。
- 当前没有程序化点光源、阶梯、色块、边缘、肤色和夜景基线。
- 项目不具备实拍滤镜标定数据，本期不能宣称具体品牌或镜头档位复刻。

## 实施方案

预设采用参数 JSON/TS 定义并记录来源、版本、适用范围和非承诺项。先通过程序化测试图标定能量、径向曲线、黑位、色彩和边缘，再用有明确使用权的真实照片做人工观察。任何外部数据只有授权明确后才可进入仓库。

## 执行步骤

1. 定义预设元数据：ID、中文/英文名、版本、模式、档位、参数、来源、适用范围和授权说明。
2. 为黑柔、白柔、辉光各建立低/中/高强度通用预设，数量以能覆盖差异为准，不机械对应真实品牌档位。
3. 生成点光源、双点光源、亮度阶梯、黑底高光、彩色色块、锐利边缘、透明边缘和噪声细节测试图。
4. 定义能量守恒核心、PSF 径向曲线、高光峰值、黑位提升、散射去饱和、色彩偏移和细节保留的指标。
5. 建立预览/导出同后端一致性和 Sharp 降级感知容差；阈值根据真实输出冻结并记录原因。
6. 使用有明确许可的照片建立少量人工 Golden；不得直接提交许可不明的 ProMist-5K 图像或派生预设。
7. 把预设选项接入 3.1 的 Inspector，确保预设最终仍转换为公开参数而非隐藏算法分支。
8. 将所有 Golden 和指标登记到 4.2 的统一测试清单。

## 涉及内容

### 新增文件

- `src/core/imageEdit/diffusionPresets.ts`：通用预设定义和查询。
- `src/core/imageEdit/diffusionPresetTypes.ts`：仅在类型复杂度需要拆分时创建。
- `src/core/imageEdit/testing/diffusionCharts.ts`：程序化测试图定义；若测试工具更适合放在测试目录，执行时确认。
- `src/core/imageEdit/__fixtures__/` 或项目统一测试资源目录：自生成且可提交的基线图。

### 修改文件

- `src/features/imageEdit/tools/diffusion/DiffusionInspector.tsx`：预设选择和来源提示。
- `src/i18n/locales/zh-CN/ui.json`、`src/i18n/locales/en-US/ui.json`：预设名称和说明。
- `src/core/imageEdit/index.ts`：导出预设公共接口。

### 可能废弃

- 代码基线中的临时默认调参，仅在正式预设冻结后调整；核心默认值仍需保持稳定或通过迁移处理。

## 数据与授权要求

- ProMist-5K 只作为论文方法参考，数据集授权明确前不得提交原图、裁剪、特征或直接派生参数资产。
- 外部真实照片必须记录来源和许可；无法确认时使用项目自有图片或程序化图。
- 预设名称不得包含未获授权的品牌商标或“精确复刻”描述。

## 验收标准

- [x] 三种模式均有覆盖低/中/高效果的通用预设，参数来源和版本可追溯。
- [x] 黑柔与白柔的黑位、微扩散、远距雾幕和去饱和差异明确。
- [x] 程序化测试图覆盖能量、PSF、边缘、色彩、透明和细节。
- [x] 数值与感知阈值已冻结或标记待确认，并有真实原因。
- [x] 未提交许可不明的数据或派生资产，未宣称品牌精确复刻。
- [x] 预设只映射公开参数，不在 UI 或 Shader 中增加预设 ID 特判。
- [x] Golden 和指标已纳入 4.2，任务总览和重要记录已同步。
