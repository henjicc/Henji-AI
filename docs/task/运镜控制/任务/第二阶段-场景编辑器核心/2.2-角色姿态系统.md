# 2.2 角色姿态系统

## 任务状态

- 状态：待开始
- 所属阶段：第二阶段-场景编辑器核心
- 前置任务：2.1、1.2

- 是否可以并行：是（与 2.3 并行，均基于 2.1 的对象框架独立扩展）

## 任务目标

在场景编辑器里支持添加人形角色对象，支持体型变体切换、预设姿势一键应用、逐关节滑杆精细调节，达到实测参考产品观察到的姿态控制能力（身体前倾/转身/侧倾、躯干前倾/扭转/侧倾、头部点头/转头/歪头、左右肩/肘/腕的前举/外展/扭转等）。

## 当前情况

- 1.2 应已验证 Mixamo 人形骨架可转换为 glTF 并在 three.js 中正确显示骨骼、动作片段可播放（具体结论见 1.2 执行记录）。
- 2.1 已提供场景对象增删改的基础框架（对象类型、变换属性、对象列表/属性面板），角色对象类型目前是占位，需要在本任务里接入真实实现。
- 实测 LibLib「3D导演台」确认姿态控制是 FK 滑杆（每个滑杆对应关节欧拉角的一个分量）+ 预设姿势库，不是通用 IK；体型变体（男性/女性/宽厚/健壮/纤细/少年/儿童/二头身）是同一套骨架的比例/网格变体，不是完全独立的模型。

## 实施方案

用 1.2 验证过的骨骼模型作为角色基础网格，姿态调节采用 FK 方式——每个滑杆直接写对应骨骼的局部欧拉角分量，不引入通用 IK 求解器（见重要记录 002 和实测结论）。预设姿势用一组"骨骼名称→欧拉角"的 JSON 数据描述，具体来源可以是从 Mixamo 静态姿势帧提取，也可以是手工调好的几组常用姿势，本任务只需要覆盖代表性的 3-5 个，不追求覆盖参考产品的全部预设。体型变体通过对基础骨骼网格做整体/局部缩放实现，一期先做 2-3 种代表性变体，不需要覆盖全部体型。

## 执行步骤

1. 在 2.1 的场景对象类型里新增角色对象类型（引用骨骼模型资源 + 当前姿态数据 + 体型变体参数）。
2. 实现角色对象的三维渲染：加载 1.2 验证过的 glTF 骨骼模型，开发调试阶段用 `SkeletonHelper` 辅助确认关节位置。
3. 实现姿态调节面板（复用 `Ui*` 滑杆组件），按实测观察到的分组结构（身体/躯干/头部/左右手臂-肩/肘/腕）逐个绑定到对应骨骼的欧拉角分量。
4. 实现预设姿势库（先做 3-5 个代表性预设，如站立、坐姿、走路静止帧、挥手），一键应用后所有滑杆同步更新为对应数值。
5. 实现体型变体切换（2-3 种代表性变体），验证切换后姿态滑杆仍然可用、网格不错位、不穿模。
6. 验证多个角色对象同时存在场景中时姿态互不干扰，各自独立可调。
