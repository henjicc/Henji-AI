# 2.3 相机与双视角渲染

## 任务状态

- 状态：待开始
- 所属阶段：第二阶段-场景编辑器核心
- 前置任务：2.1
- 关联任务：2.2（可并行）
- 是否可以并行：是（与 2.2 并行，均基于 2.1 的对象框架独立扩展）

## 任务目标

支持添加多个"机位"（相机对象），每个机位可独立设置位置/注视目标/FOV，实现"导演视角"（自由环绕总览整个场景）与"机位视角"（锁定到选中机位的实际取景画面）两种查看模式的切换，达到实测参考产品的双视角能力，为 3.2 的"机位截图导出"提供准确的取景渲染结果。

## 当前情况

- 2.1 提供了通用对象增删改框架，相机对象类型目前是占位。
- 实测 LibLib「3D导演台」确认相机属性包含：位置 XYZ、注视目标（"手动坐标"或锁定某个已有角色对象）、FOV，支持添加多个命名机位（如"机位1"），并且有"导演视角"/"机位视角"顶部 Tab 切换。
- R3F/drei 生态里多相机切换（`PerspectiveCamera` 组件配合 `makeDefault`）、视锥体辅助线（`CameraHelper`）都是现成能力，可以直接复用，不需要自己实现相机数学。

## 实施方案

相机对象作为场景对象的一种特殊类型，除了 2.1 通用变换属性外增加"注视目标"（手动坐标数值 或 锁定到某个角色对象的引用）和 FOV 属性。导演视角用一个独立的、不属于场景数据本身的自由 `OrbitControls` 相机；机位视角用选中机位的实际 `PerspectiveCamera` 渲染当前场景（参数完全来自该机位的数据）。两种视角通过顶部 Tab 切换渲染同一份场景数据，切换视角本身不修改任何场景对象数据。

## 执行步骤

1. 在 2.1 的场景对象类型里新增相机对象类型（`position`、`lookAt` 目标：手动坐标数值 或 角色对象引用、`fov`、机位名称）。
2. 渲染相机对象在三维视图里的辅助表示：用 drei 的 `CameraHelper`（视锥体线框）或自定义简易相机图标，参照实测截图观察到的橙色相机图标+视锥体线框观感。
3. 实现顶部"导演视角/机位视角"Tab 切换：导演视角用独立自由 `OrbitControls`；机位视角渲染选中机位的真实取景，`PerspectiveCamera` 的位置/朝向/fov 完全由该机位对象的数据驱动。
4. 实现相机属性面板（复用 `Ui*` 组件）：位置 XYZ 拖拽/数值输入、注视目标下拉选择"手动坐标"或某个已有角色对象、FOV 滑杆。
5. 支持添加多个机位，机位对象和其他场景对象统一纳入 2.1 的对象列表面板管理，机位列表支持切换"当前选中机位"（决定机位视角渲染哪一个）。
6. 验证机位视角画面和该机位实际的 `position`/`lookAt`/`fov` 参数完全一致：调整参数后机位视角画面应实时同步变化。
