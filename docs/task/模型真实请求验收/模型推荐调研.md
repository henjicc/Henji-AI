## 图像

优先：
1. gpt-image-2.6：AA 文生图第 1（1259）、编辑第 1（1209），约 $0.21/张，比 2.5 快约一倍、同价。
2. nano-banana-2.1：AA 第 6（1176），约 $0.034/张，2K/4K；大段或多语言文字交给 Pro。[对比](https://www.cometapi.com/nano-banana-2-1-vs-nano-banana-pro/)（2026-10）
3. grok-imagine-image-2.0：AA 第 8（1166），Arena 编辑第 7，中价。
4. seedream-5.0-pro：AA 文生图 1101、编辑 1129，偏贵。
5. seedream-5.0-flash：约 $0.018/张，无榜单分，口碑一般，只建议草稿。[OpenRouter](https://openrouter.ai/bytedance-seed/seedream-5-0-flash)
6. qwen-image-3.0：中文文字与国内题材，AA 1073。
7. flux-3（AA 1117，中价）；flux-3-klein 开放权重、约 $0.009/张（AA 1043）。[BFL](https://bfl.ai/blog/flux-3-image-klein)

可用非首选：nano-banana-pro（AA 1119，价格约 2.1 的 4 倍，只在大段 / 多语言文字或精细排版时用）、gpt-image-2.5、seedream-4.5（1030）、seedream-5.0-lite（1019）、wan-2.7-image（Arena 编辑第 33）、kling-image-o1（只有厂商自测）、midjourney（艺术风格，提示词遵从差）、z-image-turbo、z-image（base，需负向提示词或微调时）、qwen-image-2512 / edit-2511（开源旧版）。

过时：nano-banana（被 2.1 取代）、nano-banana-2（被 2.1 超过且更贵 $0.067）、nano-banana-2-lite（与 2.1 同价更差）、gpt-image-2（与 2.6 同价）、seedream-4.0、grok-imagine-image（AA 1024）、flux-1-krea-dev、majicmix-realistic、sdxl-14-checkpoint。

新而不更好：Arena 初步分数 gpt-image-2.5 Sunburst（1429）高于 2.6 Sunburst（1409），2.6 主要提升是速度；AA 上 2.6 领先。

## 视频

优先：
1. gemini-omni-1.2-flash：Arena 文生 / 图生双第 1（1541 / 1502，初步分），最长 15 秒带声音，可多轮修改，720p 约 $0.07/秒。[Google](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/)（2026-11-05）
2. wan-3.0：AA 文生视频第 1（1172），最长 30 秒、最多 10 张参考，约 $12/分钟；wan-3.0-prime 只是更快、贵约 40%。[对比](https://www.flixly.ai/blog/wan-3-0-vs-wan-3-0-prime)
3. minimax-h3：AA 文生第 3、图生第 4，$4.80/分钟，原生 2K 带声音，性价比最高。
4. seedance-2.0：AA 第 10，Arena 与 2.5 几乎并列，纯文字写实强于 Kling 4.0。
5. seedance-2.5：AA 图生第 1（1158），价格约 2.0 的 2–3 倍（约 $34/分钟），适合 15–30 秒长镜头。[Kapwing](https://www.kapwing.com/resources/is-seedance-2-5-actually-better-than-2-0-heres-what-i-found/)、[PiAPI](https://piapi.ai/blogs/seedance-2-5-vs-seedance-2-0)
6. flux-3-video：Arena 文生第 4（初步），AA 1138。[the-decoder](https://the-decoder.com/flux-3-generates-videos-with-native-audio-up-to-20-seconds-long-a-first-for-black-forest-labs/)
7. kling-video-4.0：两榜尚无分，有参考图 / 关键帧 / 30 秒一镜时首选，约 $0.157/秒。[评测](https://moelueker.com/blog/kling-4-review)（2026-10-21）
8. seedance-2.0-mini：便宜草稿档。

可用非首选：grok-imagine-video-1.5（Arena 文生第 5、AA 1055；[评测](https://curiousrefuge.com/blog/grokimagine15-review)）、happyhorse-1.1（AA 1048，多语种口型；[评测](https://workingnotworking.com/happy-horse-1-1-review/)）、kling-video-3.0 / 3.0-omni（1000 / 1021）、kling-video-3.0-turbo、kling-video-4.0-flash（720p，[对比](https://www.orcarouter.ai/blog/kling-4-0-flash-vs-kling-4-0)）、vidu-q3（二次元）、minimax-h3-max、ltx-2.3（便宜但垫底，只适合预览）、seedance-2.0-fast、wan-3.0-prime。

过时：veo-3.1（AA 963 却 $24/分钟）、gemini-omni-video（初代）、seedance-v1、seedance-1.5-pro、wan-2.5-preview、hailuo-02 / 2.3、kling-video-2.5-turbo / 2.6-pro / o1、pixverse-v4.5 / v5.5、vidu-q1 / q2、ltx-2、grok-imagine-video（1.0）、midjourney-video（只能短片段、无声音）。

新而不更好：minimax-h3-max（AA 1145 低于 H3 的 1160，价格翻倍）、seedance-2.5（Arena 与 2.0 持平，短片段不值 3 倍价）、wan-3.0-prime（只是更快）、kling-video-4.0（纯文字写实不如 Seedance 2.0）。
