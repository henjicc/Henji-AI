## 与草稿不一样的地方
- 图片编辑“参数 / 基础”两个属性页签保留：草稿只画了变换，基础页签里有不透明度与混合模式。
- 音频编辑“波形 / 多轨”切换保留在文件名后面：草稿漏画了它。
- 屏幕列表不再按桌面位置摆放：按从左到右的位置排成网格（草稿要求左上起排、名字在下）。
- 命令带里不加多条竖线：一条带最多一条分隔线，分组靠间距（左侧竖排工具栏按草稿保留组间细线）。
- 3D 镜头参考的“截图 / 导出视频”谁是蓝色跟着这份文档的输出类型走（单帧是截图、多个状态关键帧是视频），不固定导出视频：一屏仍只有一个主动作。
- 屏幕录制“麦克风设备”进页面时仍写“录音设置”，打开过一次录音设置才换成设备名：提前读设备名会拉起原生录音服务枚举设备，只为显示名字不值得。
