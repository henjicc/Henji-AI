内置助手：模式、确认、问题卡片与运行中发消息

两套方向，各画四个状态，都是右侧助手面板（宽 330）。 保守版：所有等你处理的事都作为一块出现在对话末尾，输入框不变。创新版：等你处理时输入框被这件事接管（和 Claude Code 一样），处理完才变回输入框，对话里只留一行结果。

保守版（推荐）

① 底栏“自动 ▾”就是模式，展开是三档带一句说明；选了“只计划”底栏这个字变强调色。② 改前先问：完整命令放代码块，三个按钮右对齐，“允许”是唯一主动作。③ 问题卡片：选项编号 1–4（键盘可按），最后一行“其他”自己写；计划卡片同一套样子，按钮换成“再改改 / 执行时先问 / 执行”。④ 助手在跑时打了字：发送键左边的“排队 ▾”可改成插入或打断；已排队的消息在输入框上方列出，可撤回。

创新版

① 模式不放进下拉，放在输入框上方一行三个小标签，Shift+Tab 轮换（Claude Code 的做法），当前模式一眼可见。② 等你处理的事接管输入框：命令、选项、计划都出现在输入框的位置，手不用离开键盘（数字选、Enter 提交、Esc 拒绝/跳过）；处理完对话里只留一行“已允许：运行命令 …”。③ 问题与计划共用接管面板，计划长时面板内滚动。④ 在跑时打字，发送键直接变成“插入”（最常用），旁边小箭头选排队或打断。
