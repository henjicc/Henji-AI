## 改什么

| 屏 | 改动 |
|---|---|
| 工具首页 | 去掉标题下的说明；四个工具一排，说明一行第三档，最近文件带时钟图标放卡片底部；“最近文件”行高 36，名字最亮、工具与时间第三档 |
| 屏幕录制 | 来源从窗口正中改为左上起排，名字与分辨率写在缩略图下方；“刷新来源”只留图标；右侧设置分“录制、声音、画面、会话”四组，常驻说明收进“录制模式”的悬停提示；“麦克风设备”显示当前设备名 |
| 音频编辑 | 命令带：文件名后加保存状态与撤销重做，“经典”改图标，“导出”唯一蓝色；效果树分类不加粗、数量图标灰、行高 28；逐字稿删掉的词用删除线加暗灰（不铺红底）；效果控件改属性行；历史记录空态只留一句 |
| 图片编辑 | 命令带左端显示文件名与保存状态；文件操作只留图标；吸附开关挪到右侧；工具栏当前工具中性底、其余图标灰；图层面板标签不带关闭叉、工具挪到底栏；属性面板改属性行；缩放条浮在画面上 |
| 3D 镜头参考 | 视口标签改为压在画面上的小标签；命令带新建物体一组、变换工具一组（当前中性底），截图次级、导出视频唯一蓝色；场景对象行高 28，操作只在悬停行出现 |

## 落地顺序

先公共（命令带左端文件名与保存状态、停靠面板标签与底栏、属性行），再逐个工具：首页 → 屏幕录制 → 图片编辑 → 音频编辑 → 3D 镜头参考。
