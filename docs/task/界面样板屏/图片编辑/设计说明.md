# 图片编辑样板屏 · 设计说明

状态：2026-11-12 用户确认草稿，追加一条：左上角不显示“未保存”。改动本来就实时写盘，新建的图片一开始就写在它所在的文件夹里，只是带着“还没起名”的草稿标记；这个标记不再显示成“未保存”（共用的保存状态组件一并去掉，画布、音频编辑、镜头参考同样生效）。

- 草稿：[图片编辑样板屏草稿.html](图片编辑样板屏草稿.html)（`?s=1`、`?s=2`），渲染图在 [预览/](预览/)，现状截图在 [现状/](现状/)

## 与草稿不一样的地方

- 不透明度、填充、蒙版浓度仍是“滑杆 + 读数”：沿用共用参数行（与剪辑效果控件的字重行一样），草稿画的是只有读数。
- 缩放仍是水平、垂直两个读数，没有画链条：文档里本来就分开存，没有“等比锁定”这个状态。
- 删除蒙版不在“蒙版”分组标题右端，和“添加蒙版”同一个位置（属性面板底栏，有蒙版时变成删除）。
- 效果、调整、矢量、智能对象这几类图层自己的参数仍按表单排，放在各自的分组里；只有变换、合成、蒙版改成属性行。
- 浮动面板的开关和面板显示开关一起进了“窗口”菜单（“浮动面板”子菜单）；恢复默认布局在“工作区布局”里。
