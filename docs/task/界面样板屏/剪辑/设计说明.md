## 一、从现状截图里看到的问题

不只是清单上已有的那些，按五类列：

**骨架与节奏**
- 从画面底边到第一条片段，中间横着六条：刻度尺、带白点的滚动条、播放控制条、时间线标签行、时间码行、开关行。真正干活的时间线只剩窗口的四分之一。
- 行高没有规律：素材行 28、效果控件行 40、调色行 28、轨道 24 / 26 / 40 混用，文字轨矮到名字被裁。
- 面板之间是黑缝，面板内部又有线，聚焦面板再套一圈蓝框，界面读起来是一堆盒子。

**层次与注意力**
- 缩小看，最先跳出来的依次是：蓝色导出按钮、两个一模一样的蓝色大时间码、琥珀色字幕胶囊、滚动条两端的白点、蓝色面板框。画面本身排不进前三。
- 所有文字都是同一档亮度、同一档粗细：菜单栏、工作区导航、面板标签、素材名、轨道名、参数名分不出主次。
- 所有图标同样大小、同样亮，默认状态的锁、眼睛、喇叭和正在用的工具一样显眼。

**时间线**
- 字幕、文字、画面、声音四种片段四种画法；字幕只露一个字。
- 片段名被裁、和“重试”叠在一起；选中后两端的黑白三角看不出含义。
- 刻度尺上的白色标记比播放头还亮；轨道头按钮在字幕轨、画面轨、声音轨上不在同一列。

**面板**
- 效果控件里有三条不同的左边线（分组名、小标题、参数名），数值有的靠右、有的在中间、有的是滑杆。
- 参数名被截成“比例间距…”“文字框宽…”；“字体”下面还有一行“字形样式”，与字重重复。
- 调色面板：读数贴边、直方图顶边、色轮被切、名字和数值之间空一大片、右上角三个灰图标像禁用。
- 右侧面板组 9 个标签挤成“+5”，音频电平标题被截成“音..”。

**细节**
- “编辑”后面的蓝点、风格卡片上的版本号、每个标签旁边都有的“≡”、未选片段时居中的粗体“选择片段以编辑”。

## 二、这一屏定下的尺寸与规律

### 横向条带（从上到下）

| 区域 | 高度 | 说明 |
|---|---:|---|
| 标题栏 | 40 | 菜单栏文字 12 号、暗一档；工作区导航 13 号，当前项中性底 |
| 命令带 | 44 | 返回、工程名、工具组、撤销重做、布局、导出 |
| 面板标签行 | 32 | 只放标签 |
| 画面下的刻度条 | 20 | 刻度尺与滚动条合成一条，滚动条悬停才出现 |
| 播放控制条 | 44 | 左时间码，中间三段，右边下拉与“更多” |
| 时间线刻度行 | 28 | 左上角一格里放时间码与五个开关，原来是两行 |
| 轨道 | 28 / 32 / 44 | 字幕 28，文字 32，画面与声音 44 |
| 面板底栏 | 32 | 左状态，右工具 |
| 属性行、素材行、菜单项 | 28 | 全应用同一行高 |

面板之间的缝 2 像素，面板内分区用一条发丝线。

### 文字

| 用在哪 | 字号 / 粗细 | 颜色 |
|---|---|---|
| 片段名、素材名、数值、菜单项 | 13 或 12 / 常规 | 最亮 |
| 改过的数值、当前标签、分区名 | 12–13 / 中等或半粗 | 最亮 |
| 没改过的数值、轨道名、工具按钮文字 | 12 / 常规 | 次亮 |
| 参数名、菜单栏、未选中的标签、时间与数量 | 11–12 / 常规 | 第三档 |
| 刻度数字、电平刻度 | 10 | 更暗 |

规律一句话：**内容最亮，名字退后，默认值再退后**。粗体只给分区名和时间码。

### 图标

| 状态 | 颜色 | 例子 |
|---|---|---|
| 当前工具 | 最亮，垫中性底 | 选择工具 |
| 可点的动作 | 次亮 | 播放控制、撤销 |
| 保持默认的开关、底栏工具、折叠箭头 | 暗灰（新增的一档） | 没锁的锁、看得见的眼睛 |
| 偏离默认 | 最亮 | 已锁定、已静音、已隐藏 |
| 开着的功能开关 | 强调色 | 吸附、链接、打了关键帧的秒表 |

大小：普通 16（按钮 28），轨道头与时间线开关 14（按钮 24），播放键 18（按钮 32），行内小图标 12。

### 强调色（蓝）只出现在这几处

1. 导出按钮（这一屏唯一的主动作）
2. 播放头，以及时间线左上角的时间码
3. 聚焦面板当前标签下的一条细线
4. 开着的功能开关：吸附、链接、打了关键帧的秒表与关键帧菱形
5. 键盘焦点环、菜单里的勾

节目画面下的时间码改成白色，不再是第二个蓝色大数字。

### 选中与悬停

| 对象 | 选中 | 悬停 |
|---|---|---|
| 片段 | 整块提亮一档 + 一圈 1 像素白线 | 两端出现修剪手柄 |
| 素材行、菜单项 | 中性底 | 浅一档的中性底 |
| 工具、分段 | 中性抬起底 + 最亮文字 | 中性底 |
| 面板 | 当前标签下的蓝色细线，不画整圈框 | — |

### 时间线片段

- 圆角 4，不描边，轨道内上下各留 2。
- 颜色跟素材面板的标签色走，压暗降饱和；字幕是暗琥珀、文字是暗紫、画面是暗蓝、声音是暗绿。
- 44 高的轨道：顶上 16 像素名条（比片段底色再暗一档），下面是缩略图或波形。画面片段只在开头放一张缩略图。
- 28、32 高的轨道：只有名字，垂直居中。字幕显示这句话本身，不放图标。
- 修剪手柄：两端各一根 3 像素的白色短柱。
- 淡入淡出：一片斜向压暗，顶端一个小圆点可拖。
- 关键帧：底边 5 像素小菱形。
- 读取失败：内容区换成斜纹；够宽写“波形读取失败”，窄的只在名条右端留红色警示图标。素材离线整块变灰。
- 播放头 1 像素，头部在刻度行；标记是刻度行顶上的小旗，用标记自己的颜色。

### 属性面板的一行

`[秒表 20] [名字 76] [数值 …… ] [关键帧导航，悬停出现]`

- 数值紧跟在名字后面，所有控件从同一条竖线开始。
- 数字不画框，悬停才出底；单位跟在数字后面，颜色暗一档。
- 下拉与分段在面板里用 24 高。
- 分区之间一条发丝线；分区名 12 号半粗，前面是折叠箭头和可开关的 fx。
- 颜色：复选框 + 小色块 + 色号。

## 三、相对现状改了什么、为什么

| 改动 | 原因 |
|---|---|
| 菜单栏、默认状态图标、参数名整体降一到两档亮度 | 让画面和片段成为最亮的东西 |
| 画面下三条并成两条，时间线左上角两行并成一行 | 把高度还给轨道，轨道从 24–40 变成 28–44 |
| 播放控制条分三段：标记与入出点 / 播放 / 截帧与全屏；提升、抽取、跳到编辑点收进“更多” | 十四个一样的图标找不到播放键；用不了的不摆出来 |
| “讲解”按钮收进“更多”，“超级关键帧”留在右侧 | 录讲解是低频动作 |
| 右侧面板组默认只开效果控件、效果、风格、全能调色，其余从“窗口”菜单开 | 9 个标签挤不下 |
| 音频电平面板的标签改成一个喇叭图标 | 56 像素宽放不下“音频仪表”四个字 |
| 去掉“编辑”后的蓝点、面板聚焦蓝框、非当前标签旁的“≡” | 没有说明的符号都是噪声 |
| 片段统一画法，名字进名条 | 解决裁字、叠字、三种画法 |
| 黑白三角换成斜向压暗加圆点 | 一眼能看出是淡入淡出 |
| 素材面板加“时长”列，素材箱显示数量 | 列表不只是一列名字 |
| 效果控件：字重一行取代“字形样式”；低频排版参数收进“更多” | 去重复，面板一屏放得下 |
| 调色：示波器加内边距，读数并成一行且只有超标项用警告色，三个工具搬到底栏，“色相旋转”的大圆盘改成普通数值行 | 逐条对应调色面板的问题 |
| 报错浮条、确认弹窗、菜单统一成实底加一圈描边 | 与已定的浮层规则一致 |

## 四、突破了哪些现有规则（需要用户定）

1. **属性行的数值从靠右改成紧跟名字**（现规则：数值右对齐，单位进固定的一列）。理由：靠右正是“名字和数值之间空一大片”的来源；紧跟名字是 Premiere、After Effects 的排法。草稿第 ⑦ 屏并排画了两种。
2. **新增一档“静息图标灰”**（现规则：只有三档灰）。只给默认状态的开关、底栏工具和折叠箭头用，不给文字用。没有这一档，所有图标都一样亮。
3. **面板聚焦不画整圈描边**，只让当前标签下的细线变蓝（原定：保留 1 像素描边）。理由：细线已经说明了哪个面板是当前的，整圈框是这一屏最大的一块蓝色。
4. **片段选中用白线，不用蓝色**。理由：蓝色留给播放头，选中的片段和播放头经常叠在一起。
5. **轨道头偏离默认用最亮的白，不着强调色**（现规则：偏离默认才着色）。理由：一条轨道锁了、一条静音了，就会出现一排蓝图标。
6. **属性面板里的下拉与分段用 24 高**（现规则：控件最小 28）。理由：行高 28 时 28 高的控件上下相贴。
7. **节目画面的时间码不用强调色**（现规则：时间码用强调色）。理由：同一屏不需要两个蓝色时间码。

## 五、放不下时怎么变

- 播放控制条变窄：先收“截帧、全屏”，再收“标记与入出点”，最后只剩时间码和播放一段。
- 右侧面板窄到 320：数值列跟着变窄，成对数值各 56 不变；名字超过 76 截断，悬停看全。
- 时间线变矮：轨道区滚动，刻度行与底栏不动。
- 片段变窄：先截断名字，再只留状态图标，窄于 12 像素只剩色块。
