## 改什么

| 位置 | 改动 | 原因 |
|---|---|---|
| 文档列表页 · 左栏 | 只放导航（全部、最近打开、未保存草稿）；“项目”一组只列有这类文档的项目；草稿数量用提示色 | 现状把所有项目（多是测试项目）都列出来，左栏比内容还长 |
| 文档列表页 · 页头 | “新建”挪到页头右端作唯一主动作；“打开文件…”“导入单个文件…”收进它左边的“更多” | 主动作挤在左栏顶上，高度与页头不齐 |
| 文档列表页 · 卡片 | 名字 13 号中等字重；元信息一行第三档；草稿去掉黄胶囊，元信息开头写“未保存”（提示色） | 名字加粗、黄胶囊抢眼 |
| 画布 · 左上 | 返回箭头 + 画布名 + 保存状态 | 与其他编辑器命令带左端同一组信息 |
| 画布 · 右上 | 缩放条（缩小、比例、放大、适应画布） | 缩放只能靠滚轮与快捷键 |
| 画布 · 打开 | 视野里一个节点都没有时对准全部节点 | 按旧视野打开，节点挤在角落，工具条跑到屏幕底边 |
| 节点 | 标题与价格第三档、图标灰；参数名第三档、值第二档；选中只靠强调色描边 | 标题、参数名与内容一样亮 |
| 节点工具条 | 通用动作只放图标灰；特有的事留文字 | 同上 |
| 素材找不到 | 媒体区叠红斜纹，写“素材找不到”与文件名，给“重新链接” | 现状是裂图图标加替代文字 |
| 小地图 | 176×112，半透明实底加描边 | 现状太大，盖住节点 |
| 右键添加节点 | 顶部加“搜索节点” | 节点种类多，要滚动 |

## 落地顺序

1. 文档列表页（`ProjectLibraryPage` / `DocumentLibraryPage`，画布、音频编辑、镜头参考、图片编辑同时生效）
2. 画布：打开时对准节点、左上返回条、右上缩放条、小地图尺寸
3. 节点标题与参数行的文字档、工具条图标档
4. 媒体读取失败的节点状态
5. 右键菜单搜索
