# 录屏边录边剪 · 设计说明

状态：2026-11-13 草稿，待用户确认；确认前不改源码。

- 草稿页面：[录屏边录边剪草稿.html](录屏边录边剪草稿.html)（`?s=1`…`?s=4`）；渲染图与四屏联系表在 [预览/](预览/)

## 是什么

项目级录屏。它就是剪辑项目里的一条序列，数据完全相同，只是换一种更简单的样子：一条录屏轨，录一段落一段，块与块首尾相连。简单录屏（工具里的屏幕录制，录完得到一个视频文件）不变，是另一件事。

## 取舍

| 问题 | 定法 |
|---|---|
| 入口 | 剪辑工作区命令带中间的“录制 / 剪辑”，同一条序列的两种样子；已打开的剪辑项目直接切过去 |
| 整屏 | 上半：画面加右侧录制设置；下半：播放控制 44、标尺 28、一条录屏轨 92、底栏 32 |
| 注意力 | 画面 → 右上角唯一的主动作（开始录制；录制中换成红色的停止）→ 例外（正在录的暗红块、选中的段） |
| 录屏轨 | 一个块同时带画面缩略与声音波形，不拆视频轨和音频轨；切到“剪辑”才是常规的视频轨加音频轨 |
| 画面显示什么 | 指针在结尾显示将要录的屏幕的实时画面；指针在某段上显示那一处录下的画面 |
| 接在后面 | 指针在结尾时，结尾处一个虚线空位 |
| 覆盖 | 指针在某段中间时录制，新块从指针处盖过去，盖到哪算哪，没盖到的原地不动；鼠标移到“开始录制”上时，指针后面出现一片渐隐的斜纹并提示“从指针处开始，盖住后面的内容” |
| 找回被盖住的 | 这一屏不放入口：撤销，或在“剪辑”里把那一段的边缘拖回来（原始文件都在） |
| 名称与描述 | 选中一段后右侧出现“这一段”：名称、描述、时长；块上双击也能改名。没选中时不显示这一组 |
| 掐掉一段 | 剪刀在指针处切开；删除后后面的自动接上；拖块两端掐头去尾。都不改原文件，可撤销 |
| 录制中 | 播放与剪切禁用，录制设置整组压暗；暂停再继续仍是同一块 |
| 强调色 | 只有“开始录制”、播放头与主时间码、开着的开关；选中的段是提亮加一圈细线 |
| 窗口变小 | 先收右侧设置（收成命令带上的一个按钮），再压矮画面；录屏轨与播放控制不收 |

## 实现时复用什么

剪辑的序列与片段数据、时间线的片段绘制与波纹删除、节目画面、撤销；录屏的来源选择、录制设置与“停止后放进序列”。新写的是这一屏的布局、合并显示的录屏轨、按指针位置落片（接在后面或覆盖）。

## 偏离与补充（2026-11-13 实现时定）

- 状态：用户已确认照草稿做，已实现。
- 来源一行：做成“来源”标签加字段式下拉（显示“屏幕 2 · 3840×2160”），点开是录屏页同一个来源选择器（屏幕、窗口、区域）；不在行里放缩略图，画面区已经是它的预览。
- 设置面板宽 320（与录屏页设置栏同一档），草稿是 336。
- 画面预览：指针在结尾时显示所选来源的缩略图，每 2 秒取一张新图；录制中停在最后一张，不另开一路采集流。
- 录制样子只录画面与声音：不录摄像头，也不走快速录制（录屏页里保存的这两个设置在这里不生效）。
- 每一块的名字默认是“序列名 第 N 段”，双击块或在“这一段”里改。
- “这一段”只有名称与时长：描述需要给片段加一个新字段（改剪辑与录制会话两种落盘格式），这一轮没有做。
- 覆盖录制中，正在录的暗红块压在原来的块上面；被盖住那段的后半截不单独再画名条，录完落定后照常显示。
- 窗口宽度小于 1180 时右侧设置收成命令带右端的“录制设置”按钮（点开是同一组设置），画面区随窗口压矮；录屏轨与播放控制不收。
- 剪辑样子的命令带：“录制 / 剪辑”放在中间区最前面，后面接编辑工具（剪辑样子的中间区本来就是工具组）。
- 录制中：“录制 / 剪辑”切换（含“视图”菜单里的两项）、撤销重做、播放、切开、删除都不可用。
- 录制样子里的快捷键与菜单只认播放、逐帧、上一段 / 下一段、首尾、撤销重做；剪刀和 Delete 走录屏轨上的切开、删除（与按钮同一条路，删除后后面的接上来），其余剪辑命令不响应、菜单里灰着写明原因。进入录制样子时清掉片段选择。
- 录屏轨按来源认：放着录屏画面（录屏导入的画面素材）的那条视频轨，下面垫背景、上面叠字幕或配乐都不受影响。还没有录屏画面时，第一段由导入找空轨或新建一条“屏幕”轨。不止一条轨放着录屏、或录屏轨上混着别的片段时不猜：录屏轨的位置换成一条提示（“这条序列现在不能边录边剪”，写明原因，带“切到剪辑”按钮），开始录制不可用。
- 覆盖只切被盖住的录屏块和它链接的声音；新一段的声音轨在这段范围里有别的素材时另起一条轨，不切用户的素材。
- 录制期间录屏轨被别处改过（助手、菜单），停止时不按开始时的位置覆盖，改为接在末尾，并提示原因；认不出录屏轨时这一段只进素材库并提示。
- 波纹删除或修剪被别的轨道上横跨的内容（同步锁定）拦下时，提示“别的轨道上有内容横跨这里……到剪辑里处理”。
- 一次录制拼不成一个画面（较早的会话、合并失败）时，各段在录屏轨上首尾相连，名字带序号。
- 菜单：“视图”里有“录制样子 / 剪辑样子”；录制样子显示时多一个“录制”菜单（开始录制或从指针处开始录制、暂停或继续、停止录制），暂停与停止显示全局录制快捷键。
- 剪辑样子命令带上原有的“录制”图标（去工具里的屏幕录制页、录完放进这份剪辑）保持不变。
- 正在录的暗红块里没有波形（录制中拿不到声音峰值），录完落定后照常显示缩略图与波形。
- 录制中不画指针：正在录的那一块右缘的红线就是现在的位置，草稿里压在红线上的蓝色指针去掉。
- 帧率分段写“30 / 60”（旁边已有“帧率”标签），录屏页同一组件一起改。
- 录制样子的画面只用来看：不在画面上选中、拖动、编辑文字与遮罩，也不接收拖进来的素材。
- 录制中“这一段”的名称也不可改；“录制 / 剪辑”切换显示为禁用。
