# 生成样板屏 · 设计说明

状态：**第三版已确认（2026-11-10），已按草稿实现**。参考素材缩略图保持现在的 3:4 竖幅（草稿里的方格不用）。

- 草稿页面：[生成样板屏草稿.html](生成样板屏草稿.html)（浏览器打开；地址后加 `?s=1` 到 `?s=4` 只看某一屏）
- 渲染好的图：[预览/](预览/)；现状截图：[现状/](现状/)（2026-11-10，真实资料目录只读截图，1440×900，深色；失败记录与模型面板两张是隔离数据）

## 用户的要求（2026-11-10，三轮）

1. 现状要用真实数据截图；历史记录里有参考素材，草稿要画出来。
2. 输入面板要能放在底部或左侧，两个位置可切换。
3. 第二版把历史记录改成“左输入、右结果”被否（“很难看”）：**历史记录、模型面板、筛选维持现在的样子**，只按统一风格小收拾。
4. 改动集中在两处：输入面板、错误提示。
5. 输入面板在左侧时，上下空间充足，参数尽量一次全显示出来。
6. 模型面板不要弹得那么高，贴着模型按钮。
7. 底部与左侧的切换不放在界面上，放进输入面板的右键菜单（现在右键只有“粘贴”）。

## 一、这一版改了什么

| 位置 | 改动 | 原因 |
|---|---|---|
| 输入面板 · 底部 | 位置、结构不变；参数条里参数名退到第三档，值保持最亮；预设与优化两个图标退到图标灰 | 统一风格：内容最亮，名字退后 |
| 输入面板 · 左侧（新增） | 同一个面板挪到左边竖着放，360 宽、同样的圆角与描边；从上到下：模型、参考素材、提示词、全部参数；底部固定“预估 + 生成” | 写长提示词、挂多张参考图、参数多的模型时，底部一行放不下 |
| 左侧时的参数 | 不折叠、不进浮层：选项类直接摊开（模式、分辨率、时长是分段，比例是一排小格），开关一行一个 | 上下空间够，点一下就选，不用先点开再选 |
| 切换位置 | 输入面板上右键：粘贴 / 把输入面板放到左侧（或底部）。记住上次的位置，切换时提示词、参考素材、参数原样带过去 | 不占界面上的位置 |
| 错误提示 | 一条淡红底的提示：红色警示图标、“没生成出来”、一句能做什么；按钮依次是“重试”“详情”“问助手”，供应商原话收进“详情” | 现在是“生成任务失败”加供应商原话，没有重试 |
| 生成中 | 与成品同样大小的占位格，百分比加一根细进度线 | 结果落地时列表不跳 |
| 模型面板 | 样子不变（一格一格、当前模型蓝色）；左缘对齐输入面板，贴着模型按钮上方弹出 | 现在从窗口最左弹出，和按钮不挨着 |
| 历史记录 | 结构不变（参考素材叠在左上、提示词最多两行、一行模型和时间、结果在下）；提示词从粗体降到中等字重，操作图标退到图标灰 | 提示词不该比结果图还抢眼 |

## 二、输入面板在左侧的尺寸

| 东西 | 尺寸 |
|---|---|
| 面板 | 360 宽，离窗口左、上、下各 16，圆角 12，一圈描边 |
| 模型 | 36 高的一行，点开模型面板（向右下展开） |
| 参考素材 | 61 见方，带编号，一行四张，末尾是“加”；标题右边写“已用 / 上限” |
| 提示词 | 112 高的输入区，右下角是预设与优化 |
| 参数行 | 行高 32，名称列 76，名称第三档；分段与小格 28 高，当前项中性抬起底 |
| 底部 | “预估”在左，“生成”是通栏的强调色按钮 |
| 右边的历史 | 占满剩余宽度，左右各留 32，结果图高度与底部时相同 |

参数的种类和个数跟着模型走；草稿里画的是 Seedance 2.0 Fast 的七个参数（模式、比例、分辨率、时长、生成音频、联网搜索、返回尾帧）。参数多到放不下时参数区滚动，模型和“生成”不动。

## 三、需要用户定的（实现时取草稿默认）

1. **左侧面板里的开关**：草稿沿用现在的滑块开关（开着是蓝色）。三个开关都开着时会有三处蓝色，要不要在左侧面板里改成不带蓝色的复选框。
2. **窗口窄的时候**：左侧位置在窗口窄于 1100 时放不下，草稿的做法是自动换回底部、变宽后换回来。
