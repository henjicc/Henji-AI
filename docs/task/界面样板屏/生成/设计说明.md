## 一、从真实数据的截图里看到的问题

**骨架与节奏**
- 一条记录占半屏：提示词两行粗体 + 一行模型时间 + 一张 255 高的图，一屏只看得到两条。
- 真实提示词都是六七十字的长句，标题位置最多两行，再长就截断。
- 模型面板从窗口最左边弹出，和输入区的左缘差了 190 像素。

**层次与注意力**
- 提示词是粗体白字，比结果图还抢眼。
- 蓝色有三处：“提示词增强”的滑块开关、模型面板里当前模型的整格、生成按钮。

**记录**
- 参考素材只是标题左边叠着的一小张，向上滚动时只露出半截；没写提示词的记录（图生图）没有标题，只剩一行模型和时间。
- 失败记录显示供应商原话，只有“问助手”，没有“重试”。
- 结果有竖图有方图，都从左排起，右边三分之二是空的。

**输入区**
- 只有底部一种形态；向上滚动后收成一条“移到这里展开输入面板…”的长条。
- 参数多、参考图多、提示词长的时候，底部这一条放不下，要点开一个个浮层。

## 二、这一屏定下的尺寸与规律

| 东西 | 草稿 |
|---|---|
| 内容列 | 底部形态 960 宽居中；左侧形态占满右边，左右各留 32 |
| 一条记录 | 左右两栏：左 300 是输入，右边是结果；记录之间一条发丝线，上下各留 16 |
| 输入栏 | 提示词 13 号最亮、最多四行（悬停看全文）；参考素材 32 见方带编号，超过三张写“+N”；模型 · 时间 11 号第三档；没有提示词时写“没有提示词”（图标灰） |
| 结果 | 底部形态 132 高，左侧形态 176 高；图片、视频按比例定宽，从左排起，放不下换行 |
| 生成中 | 与成品同样大小的占位格：百分比加一根细进度线 |
| 没生成出来 | 40 高淡红底的一条：红色警示图标、“没生成出来”、一句能做什么、“重试”“详情” |
| 记录的操作 | 悬停才出现在输入栏左下（图标灰）；单张图的复制、下载、收进资产库浮在图的右上角 |
| 输入区 · 底部形态 | 实底加一圈描边，圆角 12；参考图 48 见方；参数条一行，名字第三档、值次亮；提示词增强是图标开关 |
| 输入区 · 左侧形态 | 344 宽的竖排面板：顶上模型，下面依次是参考素材（72 见方）、提示词（148 高）、参数（一行一个，行高 32，名称列 88）；底部固定“预估 + 生成”，生成是通栏按钮 |
| 形态切换 | 底部形态参数条右端、左侧形态面板右上角各一个图标按钮；“视图”菜单同一项；切换时内容原样带过去 |
| 强调色 | 只有“生成”是实底；另有提示词增强开着时的图标、菜单里的勾 |
| 模型面板 | 720×404，与输入区左缘对齐、在其上方展开；三列模型行（28 高，不铺底）；当前模型中性底加勾 |

## 三、相对现状改了什么、为什么

| 改动 | 原因 |
|---|---|
| 记录改成“左输入、右结果” | 长提示词有四行的位置；右边原本空着的三分之二用来放结果，一屏从两条变四条多 |
| 参考素材画成带编号的小图，跟在提示词下面 | 和提示词里“图 1、图 2”对得上；不再只露半截 |
| 没提示词的记录写“没有提示词” | 现在这种记录没有标题，位置是歪的 |
| 输入区加左侧形态 | 写长提示词、挂多张参考图、参数多的模型，竖排放得下，不用点开浮层 |
| 左侧形态里比例、数量直接摊开成分段 | 选项不多时一眼看全，少点一次 |
| 失败记录改成“发生了什么 + 能做什么 + 重试” | 供应商原话用户看不懂；原话收进“详情” |
| 生成中用等大的占位格 | 结果落地时列表不跳 |
| “提示词增强”在底部形态改成图标开关，左侧形态是复选框 | 这一屏只该有一处蓝色实底 |
| 模型面板改成列表行，当前项中性底加勾，并与输入区对齐 | 158 个模型铺成按钮墙太吵；面板要挨着触发它的按钮 |

## 四、突破了哪些现有规则（需要用户定）

1. **模型格的选中不用强调色实底**（现规则：选项格选中是压低一档的强调实底，2026-11-08 确认过模型格）。理由：模型改成了列表行，按列表的规矩是中性底加勾；整屏只留“生成”一个蓝色实底。
2. **底部形态参数条上的布尔项用图标开关**（现规则：生成参数用滑块开关）。左侧形态里是复选框，参数面板里的开关不变。
3. **记录不走  的“标题一行、元信息一行、内容在下”**，改成左右两栏。理由见上表第一行。

## 五、放不下时怎么变

- 底部形态窗口窄于 1000：内容列跟着窗口收窄；窄于 760 时记录的两栏改成上下排（输入在上、结果在下）。
- 左侧形态窗口窄于 1100：自动换回底部形态，变宽后换回来。
- 一排结果放不下：换到第二行，高度不变。
- 提示词超过四行：截断加省略号，悬停看全文，点“编辑”带回输入区。
- 底部形态参数条放不下：从右往左收进“更多参数”，模型名和“生成”不收。
- 左侧形态参数太多：参数区滚动，顶上的模型和底部的“生成”不动。
