## 一、从现状截图里看到的问题

**骨架与节奏**
- 一条记录占半屏：单张图也铺 255 高，一屏只看得到两条记录。
- 内容列宽 1150，图片靠左、视频居中、音频靠左，三种结果三种对齐。
- 模型面板从窗口最左边弹出，和输入区的左缘差了 190 像素。

**层次与注意力**
- 提示词标题是粗体白字，下面一行模型和时间；每条都两行，标题比图还抢眼。
- 蓝色有三处：“提示词增强”的滑块开关、模型面板里当前模型的整格、生成按钮。主动作不突出。
- 记录的操作图标（重新生成、编辑、下载、收进资产库、删除）在右上角，离图一千像素。

**记录**
- 失败记录显示“生成任务失败”加供应商原话（“供应商返回 429：请求过于频繁”），只有“问助手”，没有“重试”。
- 生成中的任务没有和成品同样大小的占位，落地时列表会跳。
- 音频是一条灰色的粗波形，没有底，像悬在空中。

**输入区**
- 参数条里“分辨率”“数量”“提示词增强”名字和值一样亮；数量的上下箭头悬在数字右上。
- 滚动到顶部时输入区会收成一条空的长条。

**细节**
- 空状态是粗体“暂无历史记录”加一句说明，图标偏大。
- 模型面板里每个模型是一格灰块，三列铺满，像一墙按钮。

## 二、这一屏定下的尺寸与规律

| 东西 | 草稿 |
|---|---|
| 内容列 | 960 宽居中；筛选行、记录、输入区同一左右缘 |
| 筛选行 | 44 高，标签 12 号，当前项中性底；右端搜索与更多是图标灰 |
| 一条记录 | 一行标题（24 高）+ 一排结果；记录之间一条发丝线，上下各留 14–16 |
| 标题行 | 提示词 13 号最亮，放不下截断；模型 · 时间 · 张数 11 号第三档，跟在后面 |
| 结果 | 统一 132 高，图片与视频按比例定宽，从左排起，间隔 6，圆角 6 |
| 视频 | 中央播放键，右下角时长小标 |
| 音频 | 40 高的一条：播放键、细柱波形、时长，带内嵌底 |
| 生成中 | 与成品同样大小的占位格：百分比加一根细进度线；排队中只写“排队中” |
| 没生成出来 | 40 高淡红底的一条：红色警示图标、“没生成出来”、一句能做什么、“重试”“详情” |
| 记录的操作 | 悬停这条记录才出现在标题行右端（图标灰）；单张图的复制、下载、收进资产库浮在图的右上角 |
| 输入区 | 实底加一圈描边，圆角 12；提示词 14 号；参考图 48 见方带编号 |
| 参数条 | 模型名最亮；参数是“第三档的名字 + 次亮的值”；提示词增强是图标开关（开着是强调色图标） |
| 强调色 | 只有“生成”按钮是实底；另有提示词增强开着时的图标、菜单里的勾 |
| 模型面板 | 720×404，与输入区左缘对齐、在输入区上方展开；左栏分类，右侧三列模型行（28 高，不铺底）；当前模型中性底加勾 |

## 三、相对现状改了什么、为什么

| 改动 | 原因 |
|---|---|
| 结果从 255 高降到 132 高，标题并成一行 | 一屏从两条记录变成四五条，翻找历史不用一直滚 |
| 三种结果统一从左排起 | 现在图片靠左、视频居中，眼睛要来回找 |
| 操作改成悬停出现，单图操作贴在图上 | 操作离它作用的东西近；平时不出现，界面安静 |
| 失败记录改成“发生了什么 + 能做什么 + 重试” | 供应商原话用户看不懂也不知道下一步；原话收进“详情” |
| 生成中用等大的占位格 | 结果落地时列表不跳 |
| “提示词增强”从滑块开关改成图标开关 | 这一屏只该有一处蓝色实底 |
| 模型面板从一格格灰块改成列表行，当前项用中性底加勾 | 158 个模型铺成按钮墙太吵；选中不用整格蓝色 |
| 模型面板与输入区对齐、在其上方展开 | 现在从窗口最左弹出，和触发它的按钮不挨着 |
| 空状态改成小图标加两行小字 | 空状态不该比内容还重 |

## 四、突破了哪些现有规则（需要用户定）

1. **模型格的选中不用强调色实底**（现规则：选项格 `grid` 选中是压低一档的强调实底，2026-11-08 确认过模型格）。理由：这一屏已经有“生成”一个蓝色实底，再有一格蓝会抢；而且草稿里模型改成了列表行，按列表的规矩是中性底加勾。
2. **生成参数里的布尔项用图标开关而不是滑块开关**（现规则：生成参数用滑块开关，开着轨道铺强调色）。只对“提示词增强”这类放在参数条上的开关；参数面板里的开关不变。
3. **记录列表的标题与元信息并成一行**（现规则：`UiRecordItem` 的 title 一行、meta 一行）。理由：省一行高度，标题不再比结果抢眼。

## 五、放不下时怎么变

- 窗口窄于 1000：内容列跟着窗口收窄，左右各留 16。
- 一排结果放不下：横向排到第二行，仍是 132 高，不缩小。
- 标题太长：截断，悬停看全；元信息不截。
- 参数条放不下：从右往左把参数收进“更多参数”，模型名和“生成”不收。
- 模型面板在矮窗口：高度跟着降，列表滚动，搜索行不动。
