# 4.2 整合九宫格生成与宫格切分

## 任务状态

- 状态：已完成
- 所属阶段：第四阶段——结构化输出能力
- 前置任务：4.1
- 关联任务：1.2、5.1、5.2
- 是否可以并行：可以；可与 4.4、4.6 并行，但需协调能力目录和工具条入口

## 任务目标

将九宫格生成和宫格切分纳入统一工具条能力，同时最大化复用现有分镜生成、网格元数据、切分工具和素材组，不建立第二套九宫格节点或切分算法。

## 当前情况

- `StoryboardGenNode.tsx` 已是特殊生成节点，能够表达网格/分镜生成。
- 本地工具注册表已经有宫格切分，Electron 图片服务已有网格切分和分镜 PNG 元数据。
- 参考产品把“九宫格”和“宫格切分”分别展示：前者生成内容，后者是确定性后处理。
- 若只改工具条文案而不统一输出，用户可能得到单张网格图却无法方便访问九张结果。

## 实施方案

九宫格入口指向复用/配置后的现有分镜生成节点，固定或预设 3×3 语义；生成输出若为单张网格图，保留网格元数据并提供切分动作；若模型直接返回九图，则通过 4.1 创建素材组。宫格切分继续走本地工具，只迁移入口与输出组织。

## 执行步骤

1. 核对 `StoryboardGenNode`、分镜提示词、网格参数、元数据嵌入和切分工具的真实行为与测试。
2. 在能力目录登记九宫格生成与宫格切分，明确源节点支持条件、节点目标和输出策略。
3. 为九宫格入口配置 3×3 默认值、提示词版本和允许用户调整的范围，复用现有分镜节点而非复制组件。
4. 将切分入口桥接到现有工具对话框，并把切分的九张图片通过 4.1 组织为素材组。
5. 处理无网格元数据、非整除尺寸、用户选择其他行列、部分文件失败和撤销/重做。
6. 验证旧分镜项目、现有工具入口、分镜元数据读取和生成流程无回归。
7. 添加入口、默认参数、单网格/九图输出、切分和真实 Electron 场景测试。

## 涉及内容

### 新增文件

- 原则上不新增九宫格节点；只新增能力配置、输出适配和必要测试。

### 修改文件

- 能力目录、`StoryboardGenNode.tsx` 或其配置层、现有宫格切分工具入口。
- 分镜提示词/参数映射、输出落图服务、中英文文案和测试。
- 分镜 PNG 元数据服务仅在兼容测试证明缺口时修改。

### 可能废弃

- 旧工具条中的重复宫格切分入口可在统一入口完全覆盖后合并，但底层工具与历史调用保留。

## 验收标准

- [ ] 九宫格生成复用现有分镜节点和运行链路，没有第二套网格生成组件。
- [ ] 单张网格结果带可读取元数据并可切分；九张独立结果按顺序进入素材组。
- [ ] 宫格切分仍是无模型费用的本地确定性操作。
- [ ] 非整除尺寸、无元数据和失败状态有明确处理，不覆盖源图。
- [ ] 旧分镜项目、原切分能力和分镜元数据无回归。
- [ ] 精确测试和真实 Electron 九宫格流程通过。
- [ ] 执行记录与总览已同步。
