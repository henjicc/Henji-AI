# 4.4 实现多角度节点与角度编辑器

## 任务状态

- 状态：待开始
- 所属阶段：第四阶段——结构化输出能力
- 前置任务：4.1、4.3
- 关联任务：1.2、1.4、5.1、5.2
- 是否可以并行：可以；可与 3.2、3.3、3.4、3.5、4.2、4.6 在文件边界明确时并行

## 任务目标

实现多角度功能节点和节点外球形相机编辑器，使用户以模型实际支持的预设或参数选择视角，生成带角度标签的单图或图片组，并可保存、重开和继续连接。

## 当前情况

- 项目已有 Three/R3F 和相机舞台交互经验，但不应直接复用沉重的相机舞台业务模块。
- 1.4 提供专用界面宿主，4.1 提供多结果落图和素材组。
- 参考界面采用球体/立方体/图片平面、水平/垂直角度和景别，实际可用范围由 4.3 决定。
- 若编辑器自由拖动却只能映射离散模型角度，必须在交互上吸附或明确近似。

## 实施方案

节点保持紧凑，只显示输入图、当前视角摘要、模型/输出数量和生成状态。编辑器使用轻量 Three 场景说明相机相对主体的位置；精确 API 支持连续控制时保存数值，否则吸附到 4.3 确定的离散预设。生成结果由 4.1 组织并保存角度标签。

## 执行步骤

1. 定义版本化相机参数、预设、校验、迁移和模型请求映射纯函数。
2. 注册多角度节点，复用标准媒体输入、模型行、提示词和生成状态。
3. 实现节点外编辑器：主体参考、相机轨迹、方位/俯仰/景别、预设、提示词开关、重置和确认/取消。
4. 根据 4.3 契约实现连续限制或离散吸附，并为近似控制给出明确提示。
5. 调用生成链路并通过 4.1 创建带顺序和角度标签的图片组；单图模式保持普通结果。
6. 处理源图失效、输出数量不符、部分失败、取消、重试、项目切换和资源释放。
7. 添加参数、交互、输出标签、持久化、资源生命周期和真实 Electron 场景测试。

- 编辑器关闭后必须停止帧循环并释放几何体、材质和纹理。
- Three 初始化失败时保留预设列表作为可用降级，不阻断节点数据读取。

## 验收标准

- [ ] 工具条能创建并连接多角度节点，节点参数可保存重开。

- [ ] 单图或图片组按契约创建，顺序和角度标签正确，部分失败可恢复。
- [ ] 确认、取消、重置、提示词开关和资源释放行为正确。
- [ ] 结果可连接、素材组可展开，项目导入导出不丢失标签。
- [ ] 单元/组件测试和真实 Electron 场景通过。
- [ ] 执行记录与总览已更新。
