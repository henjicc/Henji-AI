# 3.4 接入人像质感调节能力

## 任务状态

- 状态：待开始
- 所属阶段：第三阶段——单图能力扩展
- 前置任务：2.5
- 关联任务：1.2、1.3、5.1、5.2
- 是否可以并行：可以；可与 3.1、3.3、4.1、4.3、4.5 并行调研

## 任务目标

实现面向人像的质感调节能力，在保持身份、五官、发型和构图的前提下提供少量可理解的质感预设或强度控制，并输出普通图片结果。

## 当前情况

- 参考产品将人像质感作为工具条能力，但其具体模型、提示词和控制范围不可从界面完全确认。
- 项目已有图片编辑模型、参考图输入、提示词和标准节点外壳，可复用大部分链路。
- “质感”可能包含皮肤、锐度、胶片、商业摄影或风格化，若定义过宽会让结果不可预测。
- 身份保持、人脸过度磨皮和未检测到人像的处理策略尚待定义。

## 实施方案

先用少量真实用户目标定义能力范围，再比较当前已接入图片编辑模型。首版优先离散预设加保守强度，不制作复杂专用界面；预设转为带版本隐藏提示词和固定参数，用户仍可补充文字要求。若模型无法稳定保持身份，则降低入口优先级或暂缓开放。

## 执行步骤

1. 将“人像质感”拆为可评估预设候选，排除与美颜、换脸或完全风格迁移重叠的范围。
2. 核对候选模型的图片编辑、身份保持、输入数量、价格和内容政策，形成确认清单。
3. 用不同肤色、年龄、单人/多人、半身/全身、低光样本评估身份、皮肤纹理、背景保持和伪影。
4. 确认预设、强度、默认提示词版本、无人物/多人时的行为和费用后再实施。
5. 注册标准能力节点，复用模型行、媒体输入和参数行；隐藏与预设冲突的底层参数。
6. 生成普通图片结果，保留能力编号、预设、强度和提示词版本用于复现。
7. 添加预设映射、参数迁移、错误状态和真实 Electron 样本测试。

## 涉及内容

### 新增文件

- 人像质感预设/提示词版本模块及测试；若标准外壳可直接配置，不新增专用节点组件。

### 修改文件

- 能力目录、节点定义、模型约束、提示词构建、中英文文案和测试。
- SDK catalog/presentation 仅在官方资料证明需要时修改。

### 可能废弃

- 未通过身份保持基准的预设不得登记为可用；已有普通图片编辑能力不废弃。

## 验收标准

- [ ] 首版范围、预设、强度和不包含内容有明确说明。
- [ ] 候选模型通过覆盖不同人物条件的身份与背景保持基准，失败边界如实记录。
- [ ] 节点参数可保存复现，底层模型差异未泄露成 UI 分支。
- [ ] 无人物、多人、模型不可用、取消和失败均有稳定行为。
- [ ] 输出为可继续连接的普通图片，原图不被覆盖。
- [ ] 单元/组件测试和真实 Electron 样本场景通过。
- [ ] 执行记录和总览已同步。
