# 3.2 实现打光节点与可视化编辑器

## 任务状态

- 状态：待开始
- 所属阶段：第三阶段——单图能力扩展
- 前置任务：3.1
- 关联任务：1.2、1.4、5.1、5.2
- 是否可以并行：可以；可与不修改专用界面宿主和能力目录同一文件的其他能力任务并行

## 任务目标

实现可从图片工具条创建的打光节点，以及与 3.1 控制契约一致的节点外可视化编辑器。用户确认控制后回写节点并生成普通图片结果，重新打开项目时仍能恢复参数。

## 当前情况

- 标准节点已有模型行、媒体输入、参数行和生成动作，可保留为节点基础。
- 1.4 将提供专用界面宿主，复杂灯光预览不应常驻 ReactFlow 节点。
- 参考界面同时存在手动与智能模式，但最终字段必须以 3.1 的模型能力为准。
- 当前没有灯位图形控件、打光参数版本或模式互斥迁移。

## 实施方案

节点展示源图、当前打光摘要、模型状态和生成按钮；点击摘要打开节点外编辑器。编辑器以一块主预览表面承载灯位交互，手动/智能模式共享同一层级，不再套多层卡片。参数先在草稿中编辑，确认后通过应用服务一次性写回；取消不污染节点。

## 执行步骤

1. 按 3.1 契约定义版本化打光参数、默认值、校验、迁移和请求映射纯函数。
2. 注册打光节点并复用标准模型、媒体输入和生成状态；增加打光摘要行和打开编辑器动作。
3. 实现手动界面：光向图、亮度、颜色、轮廓光及重置；只显示模型真实支持的控制。
4. 实现智能界面：提示词、参考光照图和已确认预设；处理模式切换与参数保留规则。
5. 构建无障碍键盘操作、脏状态关闭确认、节点删除/项目切换关闭和错误反馈。
6. 将参数映射到生成请求，输出普通图片并保留能力来源和参数版本。
7. 添加参数纯函数、组件、持久化、生成失败和真实 Electron 场景测试。
