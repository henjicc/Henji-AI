# 2.1 完成全景模型与提示词基准调研

## 任务状态

- 状态：待验证
- 所属阶段：第二阶段——全景试点
- 前置任务：1.1
- 关联任务：1.3、2.2、2.3、2.4、2.5
- 是否可以并行：可以；可与 1.2～1.4 并行，但真实付费测试须单独授权

## 任务目标

用官方资料和固定样本回答“哪些 GPT Image 2 供应商组合能稳定生成可浏览的 2:1 等距柱状全景、需要什么提示词和参数、成本是多少”，形成可供 2.2 直接实现的确认清单。

## 当前情况

- APIMart、KIE、Grsai 的 GPT Image 2 目录可见 2:1 能力；Fal 当前比例候选未直接暴露 2:1，需要核查官方接口和项目 schema。
- GPT Image 2 能理解图片生成/编辑任务，但官方资料不保证左右无缝、极点正确或完整球面一致性。
- PanFusion、Text2Light 可提供全景质量评价思路，但不代表它们适合作为当前产品模型。
- 用户要求尽量不消耗 Liblib 额度；本任务不会点击参考站生成。

## 实施方案

按模型适配流程先收集官方页面、字段和价格，再建立统一样本、提示词版本和评分表。静态资料完成后先向用户报告预计调用次数和预算；获得明确授权才进行真实付费生成。未经真实验证的组合不得设为默认。

## 执行步骤

1. 写清确认清单：规范模型、首批供应商、渠道、比例、分辨率、参考图限制、张数、价格和错误协议。
2. 以官方资料核对 APIMart、KIE、Grsai、Fal；标注抓取日期、原文字段和项目映射，无法确认项写“待确认”。
3. 定义提示词版本，至少要求等距柱状投影、360×180 球面、严格 2:1、左右无缝、地平线水平、极点连贯、无边框/文字，并区分纯文本和参考图编辑。
4. 建立五类固定样本和评分标准：接缝、极点、透视、主体重复、提示遵从、耗时、费用。
5. 计算最小测试矩阵和预算，向用户请求一次明确的付费测试授权。
6. 若获授权，执行真实调用并保留原图、请求参数、供应商响应、日志和评分；否则将质量结论标为待验证。
7. 给出首选、候选、排除组合和原因，更新 1.3/2.2 所需约束及重要记录。

## 涉及内容

本任务主要处理官方资料、SDK 模型目录、全景样本和任务记录。若发现 schema 不准确，按模型适配规则更新 `packages/ai-sdk/docs/model-adaptation/` 的资料后才能修改 `packages/ai-sdk/src/catalog/`。测试图片应放现有测试资源位置或临时目录，不得把无必要大图提交进仓库。

## 特殊风险与授权

- 任何真实供应商调用都会产生费用，必须在列明总次数和估算成本后获得用户显式授权。
- 不得用单一成功样本宣称模型稳定；无法完成足量测试时结论必须标注置信度。
- 第三方开源项目的许可证、权重许可和部署要求只作参考，不默认纳入产品。

- [x] 首选/候选/排除结论有证据；未真实测试项明确标为待验证。
- [x] 真实付费调用如发生，已有用户授权、完整日志和成本记录（本轮未发生真实付费调用）。
- [x] 形成可直接供 2.2 使用的默认模型、固定参数和降级策略确认清单。
