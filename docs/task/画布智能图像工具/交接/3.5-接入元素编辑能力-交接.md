# 3.5 接入元素编辑能力交接

## 结论

- 元素编辑已接入统一图片能力目录：从源图工具条创建相邻 `elementEditGenNode`、自动连线并选中，紧接着打开项目唯一蒙版编辑器。
- 没有新建蒙版画布、PNG 导出、上传器或生成服务。新代码只是专用宿主和付费前契约检查。
- 首版只开放已核验的 APIMart GPT Image 2 官方渠道和 Fal GPT Image 2 Edit；默认 APIMart 官方渠道。节点显式保存模型和渠道参数，不会在失败时静默切换。
- 无付费实现和真实 Electron 链路已完成。真实模型的局部重绘质量、稳定性和账单仍是“待真实付费验证”，不得对外写成已通过。

## 唯一数据流

```text
源图普通 image 输出
  → 工具条 image.element-edit
  → elementEditGenNode + param:__image 连线
  → ElementEditSpecialEditor（只是宿主）
  → DerivedMediaParamControl
  → MaskEditorModal / MaskEditorDocument v1
  → 与源图同尺寸、绘制区透明的 Alpha PNG
  → importLocalMedia 受管路径
  → params[蒙版字段] + params[派生文档键] 原子写回
  → GenerationNodeShell / GenerationService
  → 现有 runtime 媒体上传
  → 供应商 mask_url
  → 4.1 统一普通 image 结果提交
```

取消编辑不写回；确认时蒙版文件和可编辑文档一次写回。`stripDerivedMediaState` 在供应商请求前删除应用内部文档，只上传源图与蒙版媒体。原有本地“编辑”工具用于标记/裁剪/旋转，与 AI 局部重绘不重复，因此保留。

## 模型证据与契约

| 路线 | 一手资料结论 | 首版结论 |
|---|---|---|
| [Fal GPT Image 2 Edit](https://fal.ai/models/openai/gpt-image-2/edit/llms.txt) | 编辑端点接收 `image_urls`、可选 `mask_url`，最多 16 张输入，支持 1～4 张结果及 PNG/JPEG/WebP，按 token 计价。 | 已实现备选；产品契约收紧为 1 张源图、1 张结果、中等质量。 |
| [APIMart GPT Image 2 官方](https://docs.apimart.ai/cn/api-reference/images/gpt-image-2/official) | 官方渠道支持蒙版；蒙版需 Alpha 通道且尺寸与第一张图一致，参考图最多 16 张，输出 1～4 张。 | 已实现默认；强制 `official` 渠道，不开放普通/EXT 渠道。 |
| 其他 GPT Image 2 渠道或普通图片编辑模型 | 本轮没有同时闭环蒙版字段、Alpha 语义和项目 SDK schema。 | 排除；不允许普通重绘伪装为蒙版编辑。 |

稳定契约：`element-edit-mask-v1`，一张源图、一张蒙版、一张结果、`quality=medium`、`MaskEditorDocument.version=1`、`maskEncoding=alpha`、`maskPaintMeaning=transparent-edit`。蒙版参数由模型 schema 查找，不在 UI 按模型编号分支。

## 付费前预检

`prepareElementEditPreflight` 在 `GenerationService` 之前拒绝：

- 不是恰好一张源图；
- 当前模型没有完整派生蒙版 schema；
- 蒙版文件、可编辑文档或绘制选区缺失；
- 文档来源与当前源图不一致；
- 源图、蒙版和文档尺寸不一致；
- 蒙版不含 Alpha 通道。

任一检查失败都在提交付费请求前停止。生成失败继续使用现有 `GenerationNodeShell` 恢复契约；不覆盖源图。

## 持久化与项目包

- 项目保存会把源图、蒙版及文档 `sourceRef` 统一编码为图片池引用，重开后统一解码。
- 项目包收集现在按模型 schema 收集媒体参数，同步改写蒙版文档 `sourceRef`；打包和解包回转已有回归测试。
- 迁移保留当前已选模型的蒙版文件与文档，只保留一张内联源图；非法模型回到默认 APIMart 官方路线。
