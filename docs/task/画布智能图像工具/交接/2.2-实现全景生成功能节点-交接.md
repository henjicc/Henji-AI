# 2.2 实现全景生成功能节点—交接

## 完成结论

`image.panorama` 已从计划能力切换为默认可用的已实现能力。用户从兼容图片的工具条点击“720°全景”时，1.2 建立的统一编排器会在右侧创建并连接 `panoramaGenNode`。节点复用 `GenerationNodeShell`，不内置第二套模型行、媒体行、参数行或生成按钮。

生成结果继续使用 `exportImage`，并携带 `resultKind: panorama`交给 2.3 的球面查看器。本任务没有调用付费模型，不将“API 可表达固定全景参数”宣称为“模型已通过无缝全景质量验证”。

## 节点与创建契约

- 节点类型：`panoramaGenNode`，稳定能力编号：`image.panorama`，产品名：“720°全景”。
- 节点不出现在普通添加菜单，而由图片节点工具条的能力目录创建；工具条无全景特判。
- 节点使用标准生成执行、`rows` 目标端口、图片输入和图片输出；参考图最多 1 张。断开来源连线后可纯文本生成，有 1 张图时自动走参考图模板。
- 生成仍由顶部节点工具条的 `toolbarGenerate` 与画布执行器触发，节点 DOM 内没有额外生成按钮。
- `nodeControlRegistry` 登记了受控节点创建契约，但仅对助手开放标题、用户提示词、模型和普通参数；能力编号、模板版本、固定语义和媒体路径不允许外部伪造。

## 模型与固定语义

- 模型行直接消费 1.3 的 `modelPolicy`，仅展示规范家族 `gpt-image-2` 中通过静态组合核验的 APIMart EXT/官方、KIE、Grsai VIP 和 Fal。UI 不写模型 ID 或供应商分支。
- 节点创建、模型切换、项目重开迁移和每次生成前都会运行语义映射。固定值最后写入，因此存量参数或连线注入无法把比例改回 1:1、把分辨率改为 1K 或把数量改为多张。
- 固定产品语义：完整等距柱状投影，360°×180°，严格 2:1，原生 2K，单张，支持质量参数时固定 `medium`，最多 1 张参考图。
- 节点参数区不显示比例、分辨率、数量、渠道或 `output_format`；生成准备器也会从请求参数中移除 `output_format` / `outputFormat`。
- 无兼容模型、不兼容的模型连线覆盖或超过 1 张参考图时，生成前稳定拒绝，不会发起供应商请求。

## 提示词契约

- 纯文本：`panorama-equirectangular-text-v1`。
- 单参考图：`panorama-equirectangular-reference-v1`。
- 节点的 `prompt`/结构化提示词保留用户原文；隐藏模板只在请求准备时拼接，不覆盖用户输入。
- 模板明确定义左右接缝、上下极点、水平地平线、透视/光照连续、不重复主体和不产生边框/文字/水印。用户描述与能力的固定输出格式冲突时，固定球面几何优先。

## 结果与恢复数据

生成中占位结果与成功结果都保留以下字段：

| 字段 | 用途 |
|---|---|
| `resultKind: panorama` | 路由到 2.3 球面查看器，同时仍是可连接/复制/下载的图片结果 |
| `sourceCapabilityId: image.panorama` | 记录结果的产品能力来源 |
| `sourceCapabilityTemplateVersion` | 记录实际使用的文本或参考图模板 |
| `generationUserPrompt` | 保存用户原始提示词 |
| `generationPrompt` | 保存实际提交的模板后提示词 |
| `generationFixedSemanticParams` | 保存跨供应商固定语义 |
| `generationCanonicalModelId` / `generationModelId` | 保存规范家族与真实模型 |
| `generationMappedParams` | 保存生成时实际映射的参数 |

成功图片继续经 `persistGenerationResult` 落到受管媒体路径。新节点继承标准壳的失败节点、进度、服务端任务 ID、恢复轮询和运行态清理契约；项目迁移会恢复节点的能力编号、模板、固定语义、兼容模型及其映射参数。持久化结果如果不是精确 2:1，本次运行会明确记为失败，不会伪装成可球面浏览结果。

## 2.4 继续时的用法

1. 从兼容图片的动作工具条点击“720°全景”，确认右侧创建 `panoramaGenNode` 且连到 `param:__image`。
2. 在节点内只填写用户场景描述，不把隐藏模板人工粘贴回提示词。断开参考图可验证文本模板，保留单图可验证参考模板。
3. 使用无付费 mock/已授权样本验证“创建→生成中结果→落盘结果→球面查看”。结果必须严格 2:1，否则预期是明确失败/平面降级，不是强行打开球面。
4. 核对结果节点上述元数据未被成功回写、重试或恢复轮询覆盖，并核对复制、下载和下游图片连线回归。

## 风险与并行边界

- 真实模型是否稳定生成左右无缝、极点连续的图像仍待付费基准；本次只完成产品和请求契约。
- 严格 2:1 校验发生在图片落盘之后；不合格图会保留受管文件但不写入成功结果节点，后续如需自动清理应在统一媒体回收机制中处理。
- 本提交不包含全景查看器、资产边缘触发、设置 Store/文案、用户 assets/settings/assistant 变更或总览/重要记录。全景查看器已由 2.3 在 `cbe58b2c` 独立提交，本任务只消费其结果语义。
