## 已完成内容

1. 全景节点新建时把“生成一张完整、自然、可沉浸浏览的 360°×180° 等距柱状全景图，左右边缘无缝衔接。”写入真实提示词文档，用户可以直接提交、修改或清空。
2. `defaultPromptVersion` 保证旧空节点只回填一次；用户主动清空后的节点保存重开不会再次自动填充。
3. 固定语义只保留 equirectangular、360°×180°、严格 2:1、单张和最多一张参考图；分辨率 2K、质量 medium 改为不覆盖合法用户选择的默认值。
4. 能力策略通过 `channel / resolution / quality` 通用语义投影参数。APIMart 显示渠道与分辨率，切到官方渠道后显示质量；KIE、Grsai VIP 只显示分辨率；Fal 显示质量，分辨率固定到唯一经过核验的精确 2K 档。
5. 当前渠道缺少目标默认分辨率时，通用映射在经过能力核验的选项中选择最近档位；比例仍必须精确 2:1，不做静默拉伸或裁切。
6. 图片生成宿主没有真实输出时不再把静态输出端口当成已有图片；全景、打光、高清、人像、元素、九宫格、多角度、图层分离和普通图片生成共同移除无效“更多”。素材节点、生成中结果节点和已完成结果节点保持原行为。
