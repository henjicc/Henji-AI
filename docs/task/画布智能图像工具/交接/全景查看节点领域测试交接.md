## 审计中发现并已由实现侧修正

首次执行前发现注册修改落在了错误定义：普通图片生成曾短暂指向 `panoramaViewerNode`，全景生成仍指向 `exportImageNode`。新增的成对断言准确失败，随后实现侧已修正为：

- 普通图片生成 → `exportImageNode`
- 全景生成 → `panoramaViewerNode`

该回归现在由 `panoramaNode.test.ts` 的同一测试同时保护。
