# 3.4 接入人像质感调节能力交接

## 结论

- 首版使用现有 GPT Image 2 图像编辑家族做保守的人像质感重绘，默认显式选择 Fal `openai/gpt-image-2/edit`。
- 只提供“自然细节、商业净透、柔和胶片、电影层次”四个预设，以及“轻微、适中”两档保守强度；所有选项都是版本化提示词近似，不是可测量的修图参数。
- 产品不做人脸检测、身份识别、换脸或敏感属性改变。无人物输入不会被界面或运行时伪装成“已检测人脸”。
- 官方明确提示模型仍可能无法保持反复出现的人物或品牌元素一致性，因此界面和文档不得承诺“稳定保持身份”。真实质量仍待付费样本验证。

## 候选与首版路线

| 路线 | 首版结论 | 原因与边界 |
|---|---|---|
| Fal GPT Image 2 Edit | 默认路线 | 项目已有 catalog、上传、生成和计价链路；有图时明确走编辑端点。仍是生成式近似，不保证身份。 |
| APIMart GPT Image 2 官方渠道 | 显式备选 | 参数与图像编辑能力已核验；必须强制官方渠道，不静默使用 EXT。 |
| KIE GPT Image 2 图生图 | 显式备选 | 已有独立图生图端点和相同规范模型家族。 |
| Grsai GPT Image 2 VIP | 显式备选 | 仅 VIP 的已核验能力进入候选；渠道价格和可用性可能变化。 |
| 人像专用开源修图/美颜权重 | 首版不引入 | 没有现成受支持供应商运行时、稳定身份边界和可部署许可闭环；不得为概念相近能力擅自引入权重。 |

模型不会在失败时静默改走另一供应商。节点保存用户明确选择的模型；所选模型不再兼容或不可用时，生成前直接显示原因。

## 数据与提示词契约

稳定入口为 `src/features/canvas/capabilities/portraitTexturePolicy.ts`。

```ts
interface PortraitTextureSettingsV1 {
  portraitTextureContractVersion: 1;
  preset: 'natural-detail' | 'commercial-clean' | 'film-soft' | 'cinematic-depth';
  strength: 'subtle' | 'balanced';
  userPrompt: string;
}
```

- 提示词版本：`portrait-texture-gpt-image-2-v1`。
- 未知契约版本直接拒绝生成，不猜测历史字段；缺失字段或未知枚举才回到首版默认值。
- 用户补充文字最多 8,000 字符，并始终排在固定保留约束之前，不能覆盖身份、五官、肤色、年龄呈现、体型、构图、服装、背景、文字和标志保护约束。
- 固定约束禁止换脸、改变种族/年龄/体型、美白以及增删人物或物体；无人物时只请求对可见主体做保守影调与质感处理。
- 请求恰好携带一张源图，固定单张、中等质量输出；移除 mask、输出格式和 GPT Image 2 不应使用的 `input_fidelity`。
- 结果使用现有普通 `image` 输出节点，可继续连接后续图片能力，原图不覆盖。

## 节点与界面

- 节点使用现有模型行、媒体输入行、参数控件、标题、价格、画布执行器和统一结果提交内核。
- 节点内只展示源图、模型、四档质感、两档强度、补充要求和诚实状态文案；不建设专用弹窗或“人脸检测”状态。
- `GenerationNodeShell` 新增了通用的能力参数行扩展位；人像质感节点仅负责版本化设置写回，模型行、媒体行、价格、执行、上传、进度、端口与结果落图全部继续复用标准外壳。
- 节点创建、上游连线、保存重开和模型选择均由能力目录与节点注册表驱动，不在普通 UI 组件按模型编号分支。

## 待付费质量矩阵（未执行）

本轮禁止真实付费生成，下面是后续一次性验证计划，不计作静态实现已通过：

| 样本组 | 低成本矩阵 | 完整矩阵 |
|---|---:|---:|
| 不同肤色/年龄的单人半身、全身 | 4 样本 × 2 预设 = 8 次 | 8 样本 × 4 预设 × 2 强度 = 64 次 |
| 多人、低光、复杂头发与饰品 | 3 样本 × 1 预设 = 3 次 | 6 样本 × 2 预设 × 2 强度 = 24 次 |
| 无人物、含文字/标志的商品或场景 | 3 样本 × 1 预设 = 3 次 | 6 样本 × 2 预设 = 12 次 |
| **合计** | **14 次** | **100 次** |

以 Fal 当前 token 价只能在运行后记录真实输入/输出 token 与账单，不能仅凭图像张数给出可靠固定美元总价。评分使用 1～5 分：身份外观与五官几何、肤色/年龄呈现、背景/构图、服装/文字/标志、预设遵从、皮肤伪影。身份/几何均分低于 4，或出现敏感属性改变、增删人物、明显换脸时，该预设不得标记为质量通过。
