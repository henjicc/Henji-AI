# 4.6 实现图层分离节点与图层结果——交接

## 完成结论

4.6 已完成静态全链路实现。Seedream 5.0 Pro 的火山、APIMart、KIE 响应不再被压成 URL 字符串，而是经 SDK 模型级适配器输出版本化图层结构；普通生成调用仍保留 `primary/outputs`，已有单图和素材组链路不受影响。画布在全部层完成校验、受管落盘和合成后，只通过 4.1 的一个事务创建一个 `layer-stack` 结果节点，失败会回滚本次新建媒体，不会留下半成品节点或孤儿文件。

首版能力仍以火山 Seedream 5.0 Pro 为默认模型，APIMart/KIE 是可显式切换的备选。由于本任务按要求没有触发真实付费调用，`image.layer-separation` 已完整注册但 `defaultEnabled=false`；这不是实现缺口，而是 4.5 冻结的上线安全门槛。

## 最终协议

### SDK 结构化输出

- 新增 `StructuredGenerationLayerStackV1` / `StructuredGenerationLayerV1`，固定 `version=1`、`kind='layer-stack'`。
- 每层保留 `sourceOutputIndex`、URL/本地文件、`zIndex`、`role`、名称、描述、尺寸、格式和 bbox；结构元数据固定 bottom-to-top、sRGB、straight alpha、source-over。
- 火山读取 `data[]`；APIMart 严格 zip `url/sizes/output_formats/layers` 平行数组；KIE 只以 `resultJson.resultObject.layers_data` 为权威结构。
- 统一拒绝 0/18+ 输出、重复或不连续 z、无底图、缺 URL/尺寸、内容层非 PNG、缺 bbox、平行数组错位和损坏 JSON。
- SDK provider 运行时透传结构化结果，Electron 轮询、preload、PAL、`GenerationService` 和 `runCanvasGeneration` 均保持该字段；没有在 React 中解析供应商原始 JSON。

### `LayerStackDocumentV1`

- `stackId` 由 `completionId` 稳定派生；`layerId/resourceId` 由 `stackId + sourceOutputIndex` 派生，重复完成和恢复不会换编号。
- 层顺序固定从 0 连续、由底到顶；底图唯一且覆盖整个画布；内容层必须为含 alpha 的 PNG。
- 节点 JSON 只保存受管 `filePath`、MIME、宽高、SHA-256、位置、显隐、不透明度和层语义，不保存远程临时 URL、base64 或二进制。
- V1 只支持 8-bit sRGB、straight alpha、`normal`、source-over 和画布边界裁切；bbox 与真实图片尺寸最多容许 1px 偏差。
- `ready/degraded` 明确区分完整与缺失媒体。导入或重开遇到缺层会保留层序/名称/参数并降级，不会把素材组伪装为图层栈。

## 运行与原子性

1. `layerSeparationGenerationService` 要求结构化图层结果，普通多 URL 不会误入图层栈。
2. AI runtime 先把供应商多 URL 下载到受管路径；主进程 `layer-stack` 服务逐层重新读取并用 Sharp 检查 MIME、alpha、尺寸和 bbox，计算 SHA-256，再按 bottom-to-top 生成 PNG 合成图与 WebP 缩略图。首次建栈和重新合成都显式复用这些受管输入层，只新增合成图与缩略图，避免二次复制原层。
3. 所有资源准备成功后，`commitCanvasGenerationOutputs` 以 `strategy='layer-stack'`、`preparedLayerStack` 在一次 `runCanvasTransaction` 中替换占位节点、连接源图、选中并记录一次历史。
4. 任一准备或画布事务失败都会释放本次新建的受管文件；主进程也会回滚已落盘条目。相同 `completionId` 复用幂等完成键，不重复创建节点。
5. 取消通过带 `requestId` 的主进程合成任务与 `AbortController` 完成；日志只记录 stack/request/layer 数量、阶段和错误，不记录图片内容或短期 URL。

## 节点、界面与持久化

- 生成节点复用 `GenerationNodeShell`，只显示单图输入、模型/供应商、图层尺寸、状态与生成动作；不提供不存在的层数控制。
- 结果节点只加载合成缩略图，显示层数/降级状态并提供图片输出端口；双击或打开动作进入稳定键 `layers` 的专用界面。
- 图层界面采用单一主预览和紧凑层列表；支持选层、显隐、内容层排序、不透明度、单层导出与合成导出。底图固定最底层。
- 草稿取消不写节点；确认先请求主进程重新合成，成功后由专用界面控制器原子写回，失败保留旧文档。预览只解码合成图或当前选中层，关闭不保留额外 object URL/bitmap。
- `canvasStore`、节点迁移、媒体引用映射和项目包收集/重写均理解 `LayerStackDocumentV1`；项目包会收集合成图、缩略图和全部层资源，导入缺文件时保留结构并标记 degraded。
