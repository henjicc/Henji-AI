# 5.1 收口工具条信息架构与功能可用性交接

## 完成结论

九项图片能力已经收口到一套配置驱动、响应式且可通过键盘完整操作的工具条。工具条不照搬参考产品排序，而是按本项目真实频率、专用程度和基础动作密度决定直达项；所有能力仍复用 1.2 的注册表、原子相邻节点编排和既有本地工具，没有新建第二套执行入口或共享 UI 原语。

图层分离从 4.6 的“实现完成但默认关闭”调整为 `experimental + defaultEnabled=true`：用户已明确要在全部功能完成后自行统一测试，入口点击只创建相邻节点，不会立即扣费，费用和模型仍在节点内可见。该调整只开放可达性，不代表真实图层质量、渠道稳定性或账单已经验证。

## 九项能力审计

九项入口都只适用于“当前节点声明图片输出，且已有一张可用图片”的场景。入口本身只创建相邻功能节点或打开本地工具，不会立即产生模型费用；所有付费能力仍在新节点内展示模型、参数与价格，用户主动生成时才会请求供应商。

| 能力 | 执行与依赖 | 特殊界面 | 结果语义 | 频率判断 | 首版入口层级 |
|---|---|---|---|---|---|
| 元素编辑 | GPT Image 2 蒙版编辑；APIMart 官方为默认、Fal 为备选 | 创建后直接打开唯一蒙版编辑器 | 普通 `image` | 高：通用局部修改 | 宽屏直达 |
| 高清 | Fal Topaz；2×/4×，提交前做像素与费用预检 | 标准参数行 | 普通 `image` | 高：单步、低理解成本 | 宽屏直达 |
| 打光 | Fal IC-Light 手动模式或 GPT Image 2 智能模式 | 专用打光编辑器 | 普通 `image` | 中高：常见视觉调整 | 宽屏直达 |
| 720°全景 | GPT Image 2 已核验组合；固定 2:1、2K、单张 | 标准生成节点；结果有球面查看器 | `panorama` | 中：价值明确但场景专用 | 1440 宽屏第四直达 |
| 多角度 | Fal 连续控制/离散方位模型 | 专用相机角度编辑器 | `image-group` | 中：商品、角色等特定工作流 | 更多·结构化输出；实验标识 |
| 九宫格 | 复用现有分镜生成与图片编辑模型 | 复用分镜节点 | `image-group` | 中：内容规划与分镜 | 更多·结构化输出 |
| 人像质感 | GPT Image 2 保守重绘 | 标准节点轻量预设 | 普通 `image` | 中低：只适合人像/保守影调 | 更多·生成与变换；实验标识 |
| 图层分离 | Seedream 5.0 Pro 图层拆分 | 专用图层编辑器 | `layer-stack` | 中低：专业后续编辑 | 更多·结构化输出；实验标识 |
| 宫格切分 | 本地确定性图片服务，无模型费用 | 复用现有切分对话框 | `image-group` | 中：仅适合已有网格图片 | 更多·本地处理 |

真实模型质量、实际耗时、账户权限和账单仍遵循各能力交接中的“待真实付费验证”边界；5.1 不改变这些结论。

## 最终信息架构

- 1440 像素宽窗口：最多四个直达项，顺序为“元素编辑 → 高清 → 打光 → 720°全景”。
- 960 像素宽窗口：只保留前两个直达项，其余进入“更多”。更窄窗口继续收缩为一个直达项。
- “更多”保持单层菜单，按“生成与变换 → 结构化输出 → 本地处理”排列；不使用二级子菜单。
- 九宫格生成和宫格切分分别只保留一个产品入口：前者创建固定 3×3 分镜生成节点，后者打开本地确定性切分工具；底层兼容入口不删除。
- 查看、复制、下载、加入资产库、重新上传和删除继续位于同一基础工具条；图片能力与基础动作之间最多使用一处分隔，删除始终位于末尾危险位置。

## 状态与可访问性契约

- 节点完全不声明图片输出时隐藏图片能力。
- 节点声明图片输出、但图片仍在生成或尚未上传时，只显示“更多”入口；菜单项保持可聚焦的禁用态并显示恢复原因，不允许触发创建。
- 未实现或草稿能力隐藏，不伪装成可用入口；有明确恢复路径的关闭能力显示禁用原因，已开放的实验能力可执行且在菜单内显示实验标识。
- 菜单项显示“能力名称 + 结果说明”，不在入口层重复模型参数或价格；付费预检仍由目标节点负责。
- “更多”触发器声明菜单关系；打开后聚焦首个菜单项，支持上下方向键、Home、End、Escape 回焦、点击外部关闭和动作完成后关闭。
- 面板复用现有 `PanelTrigger` 的视口夹取与滚动，不新增共享 UI 原语。
