# 4.2 整合九宫格生成与宫格切分——交接

## 完成状态

- 状态：已完成
- 日期：2026-08-29
- 付费调用：未执行；所有结果验证均使用单元 fixture 或真实 Electron 本地切分。

## 唯一复用路径

- 九宫格生成：能力目录 `image.nine-grid` → 现有 `storyboardGenNode` → `StoryboardGenNode` → `runCanvasGeneration`。没有新增九宫格节点。
- 宫格切分：能力目录 `image.grid-split` → 现有 `split-storyboard` 工具 → `CanvasToolProcessor.processStoryboardSplit` → 唯一 `ImageSplitGateway`。没有新增切分算法或 IPC。
- 多结果落图：九张模型输出与九张本地切分结果都进入 `commitCanvasGenerationOutputs`，一次事务创建九个成员与一个 `assetGroupNode`。

## 已冻结契约

- 九宫格预设：`nine-grid-v1`；提示词模板：`nine-grid-storyboard-v1`。
- 首版固定 3×3、九格，行列按钮只读；普通分镜节点仍允许 1～9 行列。
- 模型选择继续由现有分镜节点 schema 管理，只允许带 `image-to-image` 标签的模型，不伪造供应商白名单。
- 单一模型结果：结果为普通组合图，嵌入 `gridRows`、`gridCols` 和九格说明的现有 PNG 元数据，可继续进入宫格切分。
- 九张模型结果：只接受完整九张，按从左到右、从上到下稳定编号为 `grid-cell-1`～`grid-cell-9`；0 张或部分输出直接失败，不创建半成品。
- 本地切分结果：固定使用稳定完成键，重复提交不追加第二组；无元数据或非法元数据回退 3×3；非整除像素继续由现有余数分配算法处理。
- 素材组隐藏成员在落图前叠放于首项位置，避免保存重开时隐藏成员坐标撑大画布视口；独立输出策略仍保留原有避让布局。

- `src/features/canvas/capabilities/nineGridPolicy.ts`：初始预设、规范化、单图/九图输出契约、切分完成键。
- `src/features/canvas/capabilities/builtInCapabilities.ts`：九宫格能力改为可执行并指向现有分镜节点。
- `src/features/canvas/application/canvasImageCapabilityApplicationService.ts`：按能力声明原子写入节点初始预设。
- `src/features/canvas/nodes/storyboardGen/generation.ts`：固定九宫格提示词、单图元数据、九图完整性适配。
- `src/features/canvas/application/gridSplitApplicationService.ts`：把既有切分结果委托给 4.1 原子素材组服务。
- `src/features/canvas/application/generationOutputApplicationService.ts`：允许本地确定性处理无预建占位节点落图，并收敛素材组隐藏成员布局。
- `src/features/canvas/ui/NodeToolDialog.tsx`：只替换切分结果组织方式，编辑器和底层处理器不变。
- `scripts/lib/uiInspectionScenes.cjs`：正式 Electron 场景 `canvas-nine-grid`。
