## 一眼结论

- 默认模型：Fal `fal-ai/qwen-image-edit-2509-lora-gallery/multiple-angles`。
- 默认精度：P2“原生学习控制”，不是物理相机位姿。
- 默认范围：水平模型控制角 `-90..90°`、垂直语义强度 `-1..1`、近摄 `0..10`、广角开关。
- 默认输出：4 个视角，最多 6 个；一个视角一次请求，固定 `num_images=1`，并发上限 2。
- 完整方位档：Fal `fal-ai/image-apps-v2/perspective`，使用 9 个正式离散预设，可覆盖背面。
- 两档禁止混在同一结果组；顺序严格跟随用户选择，不按完成时间排序。
- 两个正式端点均没有提示词字段，因此 4.4 首版删除无效提示词入口。
- 4.1 只接收所有视角成功后的完整描述数组并原子落图；批次状态、失败项重试和去重由 4.4 管理。

## 首版模型与请求

### 连续档 `continuous-v1`

| 项目 | 契约 |
|---|---|
| endpoint | `fal-ai/qwen-image-edit-2509-lora-gallery/multiple-angles` |
| 输入 | 1 张图片，上传后写入 `image_urls[0]` |
| 水平 | `rotate_right_left`，`-90..90`；正值向左、负值向右 |
| 垂直 | `vertical_angle`，`-1..1`；不是度数 |
| 景别 | `move_forward`，`0..10`；只能靠近，不能表达远景 |
| 镜头 | `wide_angle_lens` 布尔值；广角不等于后退 |
| 固定参数 | `num_images=1`、`guidance_scale=1`、`num_inference_steps=6`、`acceleration=regular`、`enable_safety_checker=true`、`lora_scale=1.25` |
| 不请求 | `negative_prompt`、`seed`、`sync_mode`、`output_format` |
| 结果 | `images[].url`，每次必须恰好一张 |
| 价格 | `$0.035/MP`；约 1MP 的 4 视角约 `$0.14` |

默认视角顺序：

1. 左三分之四：`yawControlDeg=45`
2. 右三分之四：`yawControlDeg=-45`
3. 左侧面：`yawControlDeg=90`
4. 右侧面：`yawControlDeg=-90`

四项的 `verticalControl=0`、`proximity=0`、`wideAngle=false`。

### 离散档 `discrete-v1`

| 项目 | 契约 |
|---|---|
| endpoint | `fal-ai/image-apps-v2/perspective` |
| 输入 | 1 张图片，上传后写入 `image_url` |
| 预设 | `front`、`left_side`、`right_side`、`back`、`top_down`、`bottom_up`、`birds_eye`、`three_quarter_left`、`three_quarter_right` |
| 结果 | `images[].url`，每次必须恰好一张 |
| 价格 | `$0.04/张`；默认 4 方位约 `$0.16` |

默认顺序：`front → right_side → back → left_side`。离散预设没有物理角度，球面编辑器只作示意并吸附，不应保存伪造的 `azimuth/elevation`。

## 控制精度

| 等级 | 说明 | 首版 |
|---|---|---|
| P3 物理相机 | 有可校验内参/外参、距离、FOV | 无可接入模型 |
| P2 原生学习控制 | 有正式数值字段，但无几何误差保证 | 连续档 |
| P1 原生离散预设 | 有正式枚举，没有数值位姿 | 离散档 |
| P0 提示词近似 | 仅图片 + 提示词 | GPT Image 2 / 魔搭 Qwen Edit，不进首版正式相机档 |

UI 用语：连续档显示“模型控制角”“俯拍/仰拍强度”“近摄程度”；离散档显示预设名。禁止使用“精确相机角度”“真实距离”“FOV”或给离散预设填假度数。

## 4.4 必须实现的数据

```ts
interface MultiAngleConfigV1 {
  version: 1
  controlProfile: 'continuous-v1' | 'discrete-v1'
  sourceImageNodeId: string
  sourceImageUrl: string
  views: Array<ContinuousViewV1 | DiscreteViewV1> // 1..6
  concurrency: 2
}
```

连续项至少保存：`id/kind/label/presetId/yawControlDeg/verticalControl/proximity/wideAngle`。

离散项至少保存：`id/kind/label/preset`。

校验要求：同组同 `kind`、ID 唯一、规范视角不重复、长度 1～6、连续值统一在纯函数 clamp。未知版本要保留可读但禁用生成，不能静默回落。

## 批次与失败

- 每个视角独立状态：`pending/running/succeeded/failed/cancelled`。
- 最多并发 2 个 Fal 请求；完成顺序不改变结果顺序。
- 任一项失败或输出数量不等于 1：不调用 4.1，不留下半成品画布节点。
- 保留成功项的 URL、request ID 和控制参数；重试只跑失败项，避免重复付费。
- 用 `batchId + view.id + providerRequestId` 去重回调。
- 项目关闭、源图变化或批次已替换后，过期回调不得落图。
- 取消仍在运行的 Fal 请求；已经完成的项目保留日志与费用证据。
