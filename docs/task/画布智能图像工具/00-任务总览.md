# 画布智能图像工具任务总览

## 任务目标

在现有画布图片节点的操作工具条中增加一组可复现的智能图像能力：全景、打光、多角度、九宫格、高清、人像质感、元素编辑、图层分离和宫格切分。点击能力后应在相邻位置创建并连接对应功能节点，节点保存输入、参数和模型语义；需要特殊交互的能力使用专用可视化界面，生成结果仍能回到画布继续连接和编辑。

本任务先建设最小共享基础，并以“全景生成 + 全景浏览”作为路线试点。用户已预先授权团队在全景试点后自主完成全部 22 项任务；路线审查改为团队根据证据自动继续、调整或回退，不再以常规用户确认作为实施门槛。本任务不包含通用工作流引擎重写、无关页面改造、未获付费授权的真实模型调用，也不承诺所有能力都由同一个模型实现。

## 重要说明

- 2.5 是自动路线审查与证据归档点，不再是必须等待用户表态的人工闸门。团队按现有架构连续完成后续阶段；只有出现无法回退或无替代方案的致命技术问题时才停止。
- 全景首版不新建独立 ReactFlow 节点类型；生成结果沿用图片结果节点并增加“全景”结果语义，双击后进入专用查看器。只有后续需要热点、导览路径或独立视角状态时，才重新评估一等全景节点。
- 所有模型限制和能力差异必须声明在能力目录或模型 schema 中，禁止在界面组件里按模型编号写条件分支。
- 真实付费生成、供应商密钥和外部写入必须在对应任务中再次获得用户明确授权。
- 已确认全景方案：`gpt-image-2`；APIMart EXT/官方、KIE、Grsai VIP 首批接入，Fal 补齐 2:1 后加入；固定 2:1、单张、原生 2K、`medium`；最多 1 张参考图并按是否有图自动路由；产品名称暂用“720°全景”。
