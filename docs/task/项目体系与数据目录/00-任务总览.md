# 项目体系与数据目录

## 任务目标

用户希望把软件里所有“能反复打开、接着编辑”的东西统一成**项目**，并以**剪辑项目为总项目**打通各功能：在剪辑里新建或打开的口播、画布、镜头参考归这个剪辑项目所有；图片编辑做成类似 Photoshop 文档的**图片文档**，既能放进剪辑当图片用，也能单独打开编辑。同时把数据目录整理到系统“文档”下的“痕迹AI”文件夹，用户作品分类存放，程序内部数据留在程序目录。

五个模块的项目页统一样式；没有项目时只显示“新建”；有历史就能直接点开；新建的项目先是草稿，有内容离开时询问是否保存，不保存就不进历史记录。

方案见 [01-实施方案.md](01-实施方案.md)，决策见 [重要记录.md](重要记录.md)。
