# 项目体系与数据目录

## 任务目标

用户希望把软件里所有“能反复打开、接着编辑”的东西统一管理，并以**项目（总项目）**打通各功能：剪辑、画布、口播、镜头参考、图片文档可以独立存在，也可以放进项目，随时移入、移出、在项目之间移动，自由组合；图片文档类似 Photoshop 文档，既能放进剪辑当图片用，也能单独打开编辑。数据目录整理到系统“文档”下的“痕迹AI”，用户作品分类存放，程序内部数据留在程序目录。

2026-10-05 用户进一步要求：趁这次把整个数据结构与数据库做解耦，做一次大型重构，以后加新东西、改东西不再牵一发动全身。方案因此改为第二版：所有工具共用一套存储底座，作品文件是唯一真相，位置一律相对记录，文档类型一处登记，数据库只在主进程。

项目页统一样式；没有内容时只显示“新建”；有历史就能直接点开；新建的先是草稿，有内容离开时询问是否保存，不保存就不进历史。

方案见 [01-实施方案.md](01-实施方案.md)，决策见 [重要记录.md](重要记录.md)。
