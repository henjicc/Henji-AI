## 目标

在剪辑里自由组合各类文档：在项目里新建或打开画布、口播、镜头参考、图片文档（嵌入模式，返回回到剪辑原位置），结果落到当前位置；
片段来源统一，任何片段都能“回到来源继续编辑”；图片文档片段保持链接、写回后自动重新渲染；跨位置引用可见并能收集；
通用单文件包导出导入取代画布工程包。

## 实现

### 片段来源统一（`src/core/videoEdit/creativeResult.ts`）

- `{ type: 'document', docRef: { docId, path }, part?, revision? }`：画布节点（`part` = 节点 ID）、口播、镜头参考、图片文档（`revision` = 放入时的文档版本）。
- `{ type: 'generation', recordId, outputIndex }`：生成记录的第几个结果。
- 旧五种写法删除，不兼容旧工程（重要记录 008）。来源解析按文档 ID 经 `resolveDocumentLink` 找（路径只是提示，改名移动后按 ID 仍能找到）。
- “回到来源继续编辑”：时间线右键与双击，`openVideoEditClipSource`；来源找不到时弹窗说明并可“重新定位”（选同类型文档，本剪辑里引用原文档的片段一次改指向它，可撤销）。生成记录找不到不能重新定位。

### 嵌入模式

- `src/features/documents/embeddedDocuments.ts` 记住文档“从哪个剪辑打开”（内存，不入库）；画布（浮在画布上的玻璃返回按钮）、口播、镜头参考、图片编辑的命令带左端显示“返回剪辑 · 项目名”，先走该工具自己的离开流程，再回到剪辑原位置。
- `DocumentOperations` 新增文档类型的创建器登记（`registerCreator / createAndOpenDocument`）与嵌入宿主登记；剪辑项目面板（`VideoEditProjectDocuments.tsx`）列出本项目其他文档、片段引用的其他位置文档（标“来自其他位置”），提供新建四类文档、打开其他位置的文档（打开 / 复制进本项目 / 移进本项目）、导入单个文件。
- 结果放回剪辑先复制进项目“生成结果”；口播剪后声音直接写进“生成结果”，不再弹保存对话框。
- 结果放进剪辑后来源文档会话标记“已被引用”：只导入了素材的口播草稿在类型上算空，被引用后离开时改为询问保存，不再直接删除（真实验收发现）。

### 图片文档链接

- 图片文档片段引用文档本身，渲染为受管预览；图片文档写回（`onImageDocumentCommitted`）后，打开着的剪辑里引用它的片段自动重新渲染、保留位置与时长（`videoEditImageLinks.ts`）。
- 工作副本回收：主进程在图片编辑运行时创建 30 秒后回收——只回收与文档同步、本次运行未用过的工作副本，最多保留 8 份，在文档锁内按版本条件删除；画布内嵌图层的工作副本不在回收范围。

### 收集素材

- 收集时一并复制剪辑引用的项目外文档（新 ID 写进项目），改写片段引用；原文档不动。

### 单文件包（`electron/main/services/documents/package-service.ts`）

- 格式选择：沿用项目已有的 `archiver`（写）+ `yauzl`（读）ZIP，不另引新库；扩展名 `.henjipack`。
- 布局：根目录 `henji-package.json`（`format: 'henji-package'`、`version: 1`、`type: document | project`、名称、导出时间、文档清单）+ `content/` 下按原相对位置存放文档与素材；项目外引用的素材收进包内素材文件夹并改写引用。
- 导入：整个项目先解到临时文件夹再移入，项目与文档换新 ID，文档间 `{ docId, path }` 引用随之改写；重名按“保留两者”命名。路径越界、条目过多或过大按格式错误拒绝。
- 入口：文档卡片右键“导出为单个文件…”、文档页与剪辑项目页“导入单个文件…”、剪辑项目页导出。删除旧画布工程包全部实现与入口。

### 助手

- 能力增量：`place_video_edit_creative_result` 新来源结构；新增 `open_video_edit_clip_source`、`export_document_package`；`open_document` 加 `fromDocumentId`，`duplicate_document` 加 `projectId`。导入单个文件不开放（要用户选文件并新建项目）。

## 遗留

- 剪辑没打开时图片文档被保存，片段不会自动重新渲染（下次“回到来源”编辑并写回时才更新）。
- 片段里记的文档路径在改名移动后会过时，按 ID 仍能找到；暂不回写新路径。
- “已被引用”标记只在本次运行内有效；被引用的口播草稿在退出时保留为草稿，下次按遗留草稿提示处理。
- 项目文档面板里的部分操作提示只写日志，界面只显示结果状态。
