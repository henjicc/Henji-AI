### 3. 新的真实验收目标 `work-root`

`scripts/lib/workRootRestart.cjs`（`npm run test:reality -- --suite restart --only work-root`），隔离资料目录、静音、零付费：

- 第一次启动（石墨）：首启建“文档/痕迹AI”及分类文件夹 → 建项目，项目里建画布 / 口播 / 镜头参考，独立画布移进项目、口播移出项目 → 打开项目（主剪辑）导入一个外部图片和一个复制进项目“素材”的图片 → 登记一条结果在“生成结果”里的生成记录 → 设置 › 文件与下载 › 作品目录 → 更换位置…（选文件夹换成替身）→ 确认“移动并重新启动”。
- 目标放在仓库 `.reality/` 下：隔离资料目录在 C 盘临时目录、仓库在 D 盘，是**真实跨盘复制**。`app.relaunch` 换成记录替身，脚本用同一资料目录做第二次启动。
- 第二次启动（纸白）：旧作品目录已删除；项目同一 ID、在新位置；五份文档都在新位置且文件存在；生成记录解析到新位置且文件存在；剪辑不缺素材，项目素材指向新位置、外部素材仍指向原文件；导出整个项目为单文件包（不指定位置，落在新作品目录“导出”）再导入，得到新位置里换新 ID 的项目；设置显示新路径并出现“恢复默认位置”。两次启动结构化日志与浏览器均无错误。
