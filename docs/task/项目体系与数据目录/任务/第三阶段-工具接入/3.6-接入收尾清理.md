## 1. 生成链路多结果改数组

一个契约：主进程 AI 运行时薄壳之后，宿主、IPC、渲染层、生成工作区任务对象与数据库全部用数组，按供应商输出顺序，不留 `|||` 拼接兼容。

- SDK 公共 DTO 的 `url` 仍用 `|||` 拼多个地址（SDK 公共契约，本任务不改 SDK）。宿主只在 `electron/main/services/ai-runtime/host-response.ts` 的 `toHostGenerateResponse` 拆成数组，这是全仓唯一认识这个分隔符的业务代码。
- 宿主响应 `HostGenerateResponse` = SDK DTO 去掉 `url` / `filePath`，换成 `urls: string[]` 与 `filePaths: string[]`（没保存时为空数组）。生成提交账本、待取结果回执、IPC、preload、PAL、commands、`GenerateResult`、`MediaResult`（生成工作区任务结果）、`VisibleGenerationTaskResult` 同步改名改型；结构化输出按 `filePaths[sourceOutputIndex]` 补路径。
- 账本与回执读出时两个数组字段不是字符串数组就按空处理（旧写法不再识别，不拆串）。
- 生成记录参数 `__resultUrl` 改存字符串数组，读写统一走 `features/generation/domain/storedResultUrls.ts`（生成页历史、结果复用、助手历史与反射共四处读者）；旧的字符串值当没有。
- 删除 `GenerationWorkspace/utils/multiFile.ts`；`normalizeMediaResultForDesktop` 按数组逐个保存（音频原来只保存第一个拼接串，顺带改正）。
- 同源问题：画布“把生成结果放进画布”在页面内存回退路径上原来把拼接串当单个地址写进节点，现按与历史记录同一约定取最后一个结果。
- 四个 Reality 场景替身（`canvasDocumentsRestart`、`uiInspectionGenerationBackground`、`uiInspectionSceneEmbeddedAgent`、`uiInspectionSceneMcpMediaChain`）按新契约返回数组。

## 2. 口播 960 宽交互场景

`toolbox-audio-edit-interaction` 原来按“整段 16 秒铺满波形宽度”换算点击位置，并在点播放后固定等 250ms 采样。产品的点击换算（`AudioEditTimeline.frameAt`）按波形当前显示区间与实际宽度计算，本身与宽度无关；脚本的固定假设在窄窗口下没有任何自检，失败时无法区分“点歪了 / 被别的层盖住 / 还没开始播 / 真没静音”。

改为（只改脚本）：

- 时间 → 坐标按 `data-view-start` / `data-view-end` 与波形实际位置换算，先滚入可见区，纵坐标限制在窗口内，并用 `elementFromPoint` 核对命中的确实是波形。
- 试听点取文档里实际静音区间开头后 0.1 秒；定位后等播放头到位，点播放后等播放头真的前进再采样，并断言采样时播放头仍在静音区间内；失败信息带 RMS 与播放头位置。

需要主代理在真实 Electron 里复跑（见文末命令）。若仍失败，新的断言会直接指出是坐标命中、播放头位置还是输出电平的问题。

## 3. 滚轮被动监听警告

React 的 `onWheel` 是被动监听，在里面 `preventDefault` 被浏览器忽略并报警，也拦不住外层滚动。原 `features/imageMark/editor/useNonPassiveWheel.ts` 上移为全应用唯一入口 `src/hooks/useNonPassiveWheel.ts`，以下同源处一并改为非被动原生监听：

- 画布小地图滚轮缩放（取值改读 store 现值，监听只绑一次）；
- 画布模型选择器供应商行横向滚动、多角度编辑器轨道预览滚轮；
- 视频查看器画面与控制条音量、音频播放器音量浮层、镜头参考状态关键帧时间轴 Alt+滚轮缩放。

## 4. 画布内嵌图层包清理

- 画布写回时渲染层带上“仍在用”的内嵌文档 `retainedDocumentIds` = 当前节点 + 撤销 / 重做记录里的节点（`retainedCanvasLayerDocumentIds`）；画布没有任何内嵌文档时也照常交给主进程（删掉最后一个多图层节点后也要清理）。
- 主进程 `CanvasLayerPackageService.commit` 写出后清理：属于这份画布（归属记录 owner 是它）、不在仍在用清单里、且没有任何别的画布内容提到的文档，删本机工作副本（只在版本没变时删）、删记录里的包、删归属记录。
- 别的画布的核对（`findCanvasLayersReferencedElsewhere`）读文档索引里全部画布（含草稿、尚未打开还指着原文档的副本）的内容；读失败时整次不清理；文件不在的画布跳过。同一批候选因别的画布在用而保留后，5 分钟内的写回不再重复核对。
- 归属索引首次按目录扫描，之后随写入 / 删除更新。

## 遗留

- SDK 公共 DTO 仍是 `url: string` 拼接（`|||`）与 `filePath?: string`；下次 SDK 版本可考虑提供数组字段，宿主届时去掉 `host-response.ts` 的拆分。按约定未改 SDK。
