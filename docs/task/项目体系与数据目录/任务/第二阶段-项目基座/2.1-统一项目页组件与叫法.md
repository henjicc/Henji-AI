# 2.1 统一项目页组件与叫法

- 状态：已完成（2026-10-05）
- 前置：无
- 方案：[01-实施方案.md](../../01-实施方案.md) 2.2“统一项目页”；决策：重要记录 003、004、007

## 目标

五个模块（画布、3D 镜头参考、口播、剪辑、图片编辑）的项目页用同一个组件；没有项目时只显示新建；用户可见叫法统一为“项目”。

## 实现

### 共用组件扩展（`src/components/ProjectLibraryPage.tsx`、`ProjectCardGrid.tsx`）

- 新建方式改为有限枚举 `create`：`named`（起名对话框，画布与 3D）/ `direct`（不起名直接交给调用方，口播导入、剪辑新建）/ `menu`（多来源；页头是带下拉的主按钮，空态把来源平铺成按钮，第一项为主按钮）。
- `secondaryAction`：页头静默、空态次级的次要动作（画布“导入项目”、剪辑“打开项目文件”）；原来的任意节点 `headerActions` 删除。
- 三种形态：读取中 / 读取失败（只有标题 + 加载或错误重试，不提前露出新建）；没有项目（只有标题 + 居中新建提示，没有数量、搜索、排序、多选，可选 `onDropFiles` 拖入文件，拖入时提示区高亮）；有项目（原一条页头）。
- 重命名、删除按能力：不传 `onRename` / `onDelete` 就没有对应菜单项；没有删除就没有多选；只剩“打开”时不显示“更多”与右键菜单。
- 卡片项：`metaLine` 可选；`status` 以危险色替换元信息（为 2.2 的“文件不存在”预留）；`icon` 覆盖无封面时的占位图标。

### 各模块

- 口播：`AudioEditHome` 改为共用页（去掉自写列表与分页）；新建 = 导入音频或视频；补齐重命名与删除。重命名新增 `renameAudioEdit`（`audioEditApplicationService.ts`），复用实例编辑与保存链路（与编辑器文件菜单、助手属性写入同一条路），不新增 IPC；项目原本不在内存时保存后释放。删除复用 `deleteAudioEdit`。无封面，占位图按音频 / 视频区分图标。刷新列表只在首次显示加载态。
- 剪辑：新增 `VideoEditProjectsPage`，新建项目（原 `createVideoEditProject`）、打开项目文件（`openVideoEditProject`）。数据为 `VideoEditProjectEntry[]`（id、名称、路径、missing、时间、封面），现在由本次已打开的实例提供；2.2 换成最近项目列表时只替换 `VideoEditApp` 里传入的 `projects`。
- 图片编辑：空态改为共用页，三个来源（打开图片 / 新建空白图片 / 粘贴剪贴板图片）+ 拖入图片。编辑器来源菜单的“从文件打开”统一为“打开图片”（中英文）。
- 画布、3D 镜头参考：改用 `create` / `secondaryAction`，其余行为不变；空态的新建按钮移到页面中央提示里（仍是唯一主按钮）。

### 图片文档列表未接入（按任务允许的退路）

`imageEditorV3:document:list` 只返回文档引用，文档本身没有名称、时间与归属；目录里混有画布节点、剪辑画面使用的受管文档。直接列出并在工具箱独立编辑会改动画布节点或剪辑引用的内容，且每张都要整份加载才能显示。这需要 3.3 的图片文档（`.henjiimg`）最近列表，本任务不做。

### 叫法

项目页与项目级动作统一为“项目”：口播（返回项目列表、项目菜单、删除项目、配方随项目保存等）、剪辑（关闭项目、项目名菜单、项目根目录、从项目移除、项目滤镜、项目素材、打开/保存/损坏/旧格式等用户可见错误、文件对话框“痕迹剪辑项目”）、3D（全部列表文案、返回项目列表）、zh-CN `ui.json` / `storyboard.json` 中三处“剪辑工程”与项目包导入提示、工具箱最近文件提示。剪辑内部“项目面板”概念保持不变。

未改（留给 4.1 能力同步）：助手 / MCP 能力描述与领域服务内部错误中的“剪辑工程”（`domains/videoEdit/**`、`videoEditMedia.ts`、`videoEditCodeService.ts` 等）。

### 选型

不新建组件：沿用 `ProjectLibraryPage` / `ProjectCardGrid`，只增加有限枚举与可选能力回调；菜单复用 `ContextMenu` + `useContextMenu().showMenuAt`，状态复用 `UiEmpty` / `UiLoading` / `UiError`。
