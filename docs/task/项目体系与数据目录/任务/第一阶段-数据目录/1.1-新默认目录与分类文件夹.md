## 任务目标

新增主进程唯一路径模块；默认用户目录改到系统“文档”下的“痕迹AI”（英文界面为“Henji AI”），按用途建分类文件夹；程序内部数据留在程序目录；媒体协议白名单包含用户目录；设置 › 文件与下载 › 数据目录显示用户目录。

## 设计决定

- **唯一来源**：`electron/main/services/appPaths.ts`。基础目录、程序目录、程序内部存储、用户目录与分类文件夹都只从这里取；程序目录部分实现在无依赖的 `appBasePaths.ts` 并由 appPaths 转出，只有 `db.ts`、`keystore.ts`、`system.ts`、`logging/writer.ts` 直接引用它（appPaths → dataRoot → db → 日志存在函数级循环，日志写入若依赖完整 appPaths 会在模块初始化时取到未定义的 `createMainLogger`，单测已复现）；`db.ts`、`system.ts`、`protocol.ts`、`keystore.ts`、`logging/writer.ts` 原先各自拼接的基础目录已删除。`db.getHenjiDataDir()`、`path-utils.getDataRootDir()/getUploadsDir()` 保留为薄别名，内部委托 appPaths。
- **程序目录** `<基础目录>/Henji-AI`（位置不变）：henji.db、密钥、日志、授权清单、`llm-config.json`、`hwaccel-cache.json`、`Thumbnails`（资产库与导入预览共用）、`ImageEditorV3`、`AudioEdit`、`debug`、`Downloads` 兜底、`history.json`/`presets.json`。不随“数据目录”设置移动。
- **用户目录**：`项目`、`图片文档`、`生成结果`、`上传素材`、`导出`、`助手技能`；英文为 `Projects`、`Image Documents`、`Generated`、`Uploads`、`Exports`、`Assistant Skills`。
- **名称只定一次**：首次需要用户目录时，按“渲染层报告的界面语言 → 系统首选语言 → getLocale”取第一个有效值，`zh*` 为中文，其余为英文；结果（绝对路径 + 语言）以 JSON 写入 settings 键 `user_data_root`，之后不随语言变化。渲染层通过新 IPC `paths:appDirectories` 带上 `uiLanguage`。
- **自定义数据目录**：`custom_data_directory` 仍生效，作为用户目录根，分类文件夹按已确定的语言建在其下；默认目录仍记录在 `user_data_root`。
- **不兼容老数据**（重要记录 008）：不检测旧数据、不保留旧的 `Media`/`Uploads`/`assistant/skills` 布局，所有安装统一新布局；本任务不移动任何文件。
- **隔离环境**：`HENJI_ISOLATED_APP_DATA` 存在时，“文档”改为 `<隔离目录>/Documents`，自动化测试不写用户真实文档；程序目录沿用启动器覆盖的 LOCALAPPDATA / appData 重定向。
- **相对路径**：生成记录等保存的相对路径以用户目录为基准（`toRelativePath`/`convertPathString` 不变）；生成结果与上传素材都在用户目录内，仍是相对路径；程序目录内的缩略图等保持绝对路径。
- **媒体协议**：白名单 = 基础目录 + 下载 + 临时 + 已授权目录 + 当前用户目录；内容寻址缓存按两种语言的“生成结果/上传素材”及 `Thumbnails` 目录名判断。
- **渲染层**：`src/utils/dataPath.ts` 不再自行拼目录，改读主进程快照（`getAppDirectories`），新增 `getProgramDataRoot`；设置页数据目录沿用 `getDataRoot`/`getDefaultDataRoot`，因此直接显示用户目录，界面未改。
- **日志**：`main.app_paths` 域记录 `app_paths.user_root.default_decided`、`.created`、`.ready`、`.create_failed`、`app_paths.documents_dir.fallback`。
