# 项目体系与数据目录：重要记录

## 记录 001：默认数据目录改到系统“文档”下

- 日期：2026-10-05
- 状态：已确定（用户）
- 背景：默认目录在 `AppData\Local\com.henji.ai\Henji-AI`，用户找不到；作品与内部数据平铺混在一起。
- 最终决定：默认目录改到 Windows“文档” / macOS“文稿”下的“痕迹AI”（英文界面为“Henji AI”，首次创建时定名、之后不随语言改），内部按用途分类文件夹。老用户不自动搬家，提供一键整理入口。

## 记录 002：程序内部数据留在程序目录

- 日期：2026-10-05
- 状态：已确定（用户采纳建议）
- 背景：“文档”常被 OneDrive 同步，数据库在同步目录里运行有冲突与损坏风险，缓存频繁写入会持续触发同步。
- 最终决定：数据库、密钥、日志、缩略图、各工具内部存储与缓存留在程序目录；“文档/痕迹AI”只放用户作品。不出现“（请勿修改）”这类命名。

## 记录 003：统一叫“项目”，剪辑项目是总项目

- 日期：2026-10-05
- 状态：已确定（用户）
- 最终决定：所有能反复打开继续编辑的东西统一叫“项目”。剪辑项目是总项目：在剪辑里用到的口播、画布、镜头参考归这个剪辑项目所有；图片编辑做成图片文档，可放进剪辑当图片用，也可单独打开编辑。用户要求一步到位，项目基座与剪辑总项目在同一计划内完成。

## 记录 004：口播、画布、镜头参考保留独立项目

- 日期：2026-10-05
- 状态：已确定（用户选择推荐项）
- 最终决定：两种归属并存。从顶部导航单独打开工具时照旧有各自的项目列表（存在程序数据库）；在剪辑里新建或打开的属于该剪辑项目，存在项目文件夹里，不进独立列表。

## 记录 005：剪辑项目一个项目一个文件夹；图片文档沿用 .henjiimg

- 日期：2026-10-05
- 状态：已确定（用户选择推荐项）
- 最终决定：剪辑项目是“文档/痕迹AI/项目/<名称>/”文件夹，内含项目文档、子项目、生成结果；项目内引用用相对路径，整个文件夹可拷走打开；发给别人用“导出项目包”。图片文档使用已有的 `.henjiimg` 单文件包格式。

## 记录 006：外部素材默认引用原文件，可一键收集

- 日期：2026-10-05
- 状态：已确定（用户选择推荐项）
- 最终决定：导入剪辑的外部视频、音频默认引用原文件；“收集素材”把用到的外部文件复制进项目文件夹并改写引用。生成结果与子项目产物一律存在项目文件夹里。

## 记录 007：新建项目先为草稿

- 日期：2026-10-05
- 状态：已确定（用户同意）
- 最终决定：新建项目先是草稿，自动备份但不进历史；离开时为空直接丢弃，有内容询问“保存 / 不保存 / 取消”；保存过的项目照旧自动保存、离开不再询问；意外退出的草稿在项目页提示恢复。
