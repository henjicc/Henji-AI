# 4.1 跨平台/多设备与画布性能验收

## 任务状态
- 状态：待验证
- 所属阶段：第四阶段-测试与收尾
- 前置任务：第三阶段全部
- 关联任务：4.2
- 是否可以并行：否（需各功能域迁移完成）
- 状态说明：本机 Electron 自动化、画布压测与 DPI 检查已完成；剩余为真实设备/真实数据/真实外部应用交互验收，可按发布节奏后置。

## 任务目标
对 Electron 版做系统性验收：功能等价、跨平台一致、老数据可读、画布性能不劣化。验收基线对齐决定 001（核心收益是「一致性 + 不劣化」，而非「显著提速」）。

## 当前情况
- 第三阶段完成后，所有能力域已具备 Electron 实现。
- 现状缺少量化性能基线；本任务需先建立基线再对比。
- 主要设备：Windows 10（主力）+ macOS（一致性目标）。

## 实施方案
分三块验收：（A）功能回归——对照 1.1 命令清单逐项核对；（B）跨平台一致性——Windows/macOS 双跑关键场景；（C）画布性能——建立可复现的压测场景（大量节点 + 多媒体），对比 Tauri 版与 Electron 版的帧率、加载耗时、内存。

## 执行步骤
1. 编写验收清单：以 1.1 命令清单与三视图（对话/画布/工具）核心流程为准，逐项标注通过/问题。
2. 老数据兼容：用真实旧 `henji.db` + Media + 项目包，验证历史、预设、设置、自定义模型、画布项目可读可用（决定 004）。
3. 跨平台：在 Windows 与 macOS 各跑一遍关键场景（生成、画布编辑、媒体播放、拖拽、剪贴板、导入导出、标题栏/窗口）。
4. 画布性能基线：设计标准压测画布（如 N 个图像节点 + M 个视频节点 + 连线），测量平移/缩放帧率、初次加载耗时、内存峰值；同场景对比 Tauri 版与 Electron 版。
5. DPI/缩放：多分辨率与高 DPI 下 UI 与画布表现核对。
6. 汇总问题清单，回流到对应 3.x 任务修复；全部通过后更新总览。

- 实际修改文件：`scripts/electron-phase4-canvas-stress.cjs`、`scripts/electron-phase4-dpi-check.cjs`、`scripts/tauri-phase4-canvas-stress.cjs`、`scripts/lib/canvasStressFixtures.cjs`、`scripts/lib/canvasPerf.cjs`、`scripts/lib/electronLaunch.cjs`（从 smoke 脚本抽出复用）、`scripts/electron-phase4-smoke.cjs`（改为复用共享 launch helper）、`package.json`（新增 `electron:canvas-stress`/`electron:dpi-check`/`tauri:canvas-stress` 脚本）、本文件、`00-项目总览.md`。
- 验证结果：
  - Electron 画布压测：80 节点 fps idle/pan/zoom=61/59/60，加载 450ms，JS heap 24→34MB；200 节点 fps=61/59/60，加载 620ms，JS heap 23→39MB；两组均 `pageErrors=[]`、`consoleErrors=[]`。
  - Tauri 画布压测（`src-tauri/target/debug` 调试构建 + `devUrl` 加载当前 vite dev 前端，与 Electron 同一份真实前端代码）：80 节点 fps=61/60/60，加载 2.7~5.0s（多次复测，冷启动方差较大）；200 节点 fps=60/60/51，加载 5325ms；均 `pageErrors=[]`、`consoleErrors=[]`。
  - 结论：两端在 80/200 节点规模下帧率均稳定在 ~60fps，与决定 001 的预期（一致性达标，非显著提速）相符；Electron 侧"点击项目卡片到画布渲染完成"明显更快，但该对比存在方法论不对等（Tauri 为未优化 debug 构建 + vite dev/HMR 前端，Electron 为 `electron-vite build` 生产构建前端），不能直接当作"Electron 比 Tauri 快 N 倍"的结论，仅作为关键交互流程不退化的参考信号；严格对等基线（Tauri release 构建 + 相同生产前端）留给真实环境验收阶段。
  - DPI 检查：1280x720@1x、1920x1080@1x/1.5x、2560x1440@2x、3840x2160@2x、1366x768@1x 共 6 组场景，`devicePixelRatio` 均与设定一致，均无横向溢出，导航按钮（生成/画布/工具箱）均完整可见可点击，`pageErrors=[]`、`consoleErrors=[]`。
