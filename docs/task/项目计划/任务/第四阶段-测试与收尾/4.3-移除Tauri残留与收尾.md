## 实施方案
分「代码与依赖移除」「脚本与配置清理」「文档更新」三步，逐步删除并验证应用仍可正常构建运行。Tauri 旧实现通过 Git 历史保留。

## 执行步骤
1. 删除 `src-tauri/` 整个目录及其构建产物引用。
2. 移除 Tauri 依赖：`@tauri-apps/api`、`@tauri-apps/plugin-*`、`@crabnebula/tauri-plugin-drag`、`@tauri-apps/cli`。
3. 移除 `tauri:dev`/`tauri:build`/`tauri:*:mac` 等脚本与 `tauri.conf.json`、`Info.plist` 等配置。
4. 清理 PAL：删除 `src/platform/adapters/tauri/*`，`runtime.ts` 简化为仅 Electron（保留抽象层接口，便于未来扩展）。
5. 清理渲染层残留：确认全仓无 `@tauri-apps` 引用、无 `convertFileSrc`/`window.__TAURI__` 残留。
6. 更新文档：改写 README、AGENTS 与 `docs/` 相关说明。
7. 更新构建链路文档与 `常用命令`，确保新成员可据文档启动开发。
8. 验证：生成 manifest/seeds、依赖锁、lint/tsc/`check:*` 与 Electron 构建链路。
