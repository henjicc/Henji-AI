# 4.3 移除 Tauri 残留与脚本文档收尾

## 任务状态
- 状态：待开始
- 所属阶段：第四阶段-测试与收尾
- 前置任务：4.2
- 关联任务：无
- 是否可以并行：否（必须在 Electron 版全面验收并可发布后执行）

## 任务目标
在 Electron 版通过验收且可打包发布后，彻底移除 Tauri 相关代码、依赖、脚本与配置，清理 PAL 中的 Tauri 适配器，更新项目文档与协作约定，完成迁移收尾。这是**不可逆**的清理步骤，须在确认无回退需求后执行。

## 当前情况
- 双壳共存期遗留：`src-tauri/`（整个 Rust 后端）、`@tauri-apps/*` 与 `@crabnebula/tauri-plugin-drag` 依赖、`tauri:*` 脚本、`tauri.conf.json`、PAL `adapters/tauri/*`、`CLAUDE.md` 中大量 Tauri/MSVC/WebView2 约定。
- 文档：`CLAUDE.md`、`docs/*`、README 等含 Tauri 描述。

## 实施方案
分「代码与依赖移除」「脚本与配置清理」「文档更新」三步，逐步删除并验证每步后应用仍可正常构建运行。删除前确认 `git` 历史保留（必要时打 tag 作为 Tauri 最终基线）。

## 执行步骤
1. 打 tag 标记最后一个含 Tauri 的提交（如 `tauri-final`）作为回退基线。
2. 删除 `src-tauri/` 整个目录及其构建产物引用。
3. 移除 Tauri 依赖：`@tauri-apps/api`、`@tauri-apps/plugin-*`、`@crabnebula/tauri-plugin-drag`、`@tauri-apps/cli`。
4. 移除 `tauri:dev`/`tauri:build`/`tauri:*:mac` 等脚本与 `tauri.conf.json`、`Info.plist` 等配置。
5. 清理 PAL：删除 `src/platform/adapters/tauri/*`，`runtime.ts` 简化为仅 Electron（保留抽象层接口，便于未来扩展）。
6. 清理渲染层残留：确认全仓无 `@tauri-apps` 引用、无 `convertFileSrc`/`asset:`/`window.__TAURI__` 残留。
7. 更新文档：改写 `CLAUDE.md`（去 MSVC/WebView2/Tauri 命令，改为 Electron 工作流与升级惯例——决定 008）、README、`docs/` 相关说明。
8. 更新构建链路文档与 `常用命令`，确保新成员可据文档启动开发。
9. 全量验证：`npm run electron:dev`、打包、自动更新均正常；lint/tsc/`check:*` 通过。

## 涉及文件
### 修改
- `package.json`（去 Tauri 依赖与脚本）、`CLAUDE.md`、README、`docs/*`。
- `src/platform/runtime.ts`（简化为 Electron-only）。
### 可能废弃（删除）
- `src-tauri/`（整个目录）、`tauri.conf.json`、`Info.plist`、`src/platform/adapters/tauri/*`、`迁移计划_新系统完全替代adapters/` 等历史对照物（视情况）。
### 新增
- 无（或新增 Electron 开发说明，若并入现有文档则不新增）。
