# 3.8 剪贴板与原生拖拽迁移

## 任务状态
- 状态：待开始
- 所属阶段：第三阶段-功能迁移
- 前置任务：2.3
- 关联任务：3.4、3.7、4.1
- 是否可以并行：可与其余 3.x 并行

## 任务目标
迁移剪贴板（读文件/写图片）与原生拖拽（拖入文件、拖出到外部应用）能力到 Electron：剪贴板用 `clipboard`，拖出用 `webContents.startDrag()`，拖入用渲染层标准 HTML5 DnD + 主进程读文件。

## 当前情况（1.1 已逐文件核实）
- 剪贴板（读文件路径）：
  - `clipboard_files::read_clipboard_files`（Windows/非 Windows 双实现，仅 Windows 真正读取 CF_HDROP）。
  - 唯一前端调用点：`src/contexts/GlobalContextMenuProvider.tsx`。
- 剪贴板（读文本）：`@tauri-apps/plugin-clipboard-manager` 的 `readText`（**动态 import**），同样仅在 `GlobalContextMenuProvider.tsx` 使用。
- 剪贴板（写图片）：`main.rs::copy_image_to_clipboard` + `image_commands::copy_image_source_to_clipboard`（用 `image` 解码 → tauri Image → clipboard）；前端调用点：`commands/image.ts`、`hooks/useMediaFileActions.ts`。
- 拖入：`src/hooks/useTauriDragDrop.ts` 监听 `tauri://drag-drop` + 用窗口坐标做命中测试 + `readFile`。
- 拖出：`@crabnebula/tauri-plugin-drag` 的 `startDrag`（**动态 import**），**核心入口集中在 `src/contexts/DragDropContext.tsx`**（被 `workspaces/GenerationWorkspace/hooks/useHistoryDrag.ts` 等消费，而非分散在 `NodeActionToolbar`/`dragThumbnails.ts`——这些是上层使用 `useDragDrop()` 的消费方，真正调原生 API 的只有 `DragDropContext.tsx` 一处）。

## 实施方案
- 剪贴板：主进程 `clipboard.writeImage(nativeImage)` 写图；读剪贴板文件用 `clipboard.read*`（Windows/macOS 文件列表格式差异需处理）。
- 拖出：参 2026 调研——`webContents.startDrag({ file/files, icon })`，**仅支持已存在本地文件**，故拖出前若是远程/内存数据需先物化到临时文件；preload 暴露 `drag:start`，渲染层在 `dragstart` 调用。Windows 行为需实测。
- 拖入：Electron 渲染层可直接用标准 HTML5 `drop` 事件拿到 `File`，多数场景**比 Tauri 的坐标命中测试更简单**；`useTauriDragDrop` 在 Electron 下可改为标准 DnD 实现（经 PAL 区分），不再需要窗口坐标换算。

## 执行步骤
1. 主进程剪贴板 service：`writeImage`（从路径/字节）、`readFiles`（剪贴板文件路径，处理双平台格式）、`readText`。
2. 主进程 `drag:start` handler：接收文件路径（或先物化的临时文件）+ 图标，调 `webContents.startDrag`。
3. PAL `clipboard` 与 `drag` 契约 Electron 适配。
4. 改造 `useTauriDragDrop`：抽象为 PAL `drag` 的「拖入」能力；Electron 适配走标准 HTML5 DnD（去坐标命中测试），Tauri 适配保留现状。
5. 改造拖出能力的**唯一原生调用点** `src/contexts/DragDropContext.tsx`（其内部的 `startDrag` 动态 import）走 PAL；上层消费方（`useHistoryDrag.ts` 等经 `useDragDrop()` 调用）不直接接触 Tauri API，无需改动。
6. 改造剪贴板消费点（唯一原生调用点 `src/contexts/GlobalContextMenuProvider.tsx`，含 `readClipboardFiles` 与 `readText`；写图片调用点在 `commands/image.ts`、`hooks/useMediaFileActions.ts`）走 PAL。
7. 双平台验证：复制图片到外部、读剪贴板文件/文本、拖入文件到画布/上传区、从画布拖出图片到桌面/外部应用。
