## 当前情况
初步盘点（基于本次扫描，需在执行时复核并补全）：

- **IPC 命令**：`src-tauri/src/main.rs::run()` 的 `generate_handler!` 注册约 42 个 `#[tauri::command]`，分布：
  - `ai_runtime::commands`：`ai_set/remove/get_provider_api_key`、`ai_get_provider_key_status`、`ai_reload_model_manifest`、`ai_get_progress_estimate`、`ai_record_progress_sample`、`ai_generate`、`ai_continue_polling`、`ai_cancel_task`（10）
  - `llm_runtime::commands`：`llm_set/remove/get_provider_api_key`、`llm_get_provider_key_status`、`llm_chat_stream`、`llm_cancel_task`（6）
  - `modelscope`：`modelscope_submit_task`、`modelscope_check_status`（2）
  - `image_commands`：split/merge/crop/metadata/prepare/load/persist/save/info 等（约 18）
  - `project_package`：`export_project_package`、`import_project_package`（2）
  - 其他：`toggle_devtools`、`copy_image_to_clipboard`、`clipboard_files::read_clipboard_files`、`logging::log_frontend_events`
- **前端调用点**：约 54 个文件、118 处 `invoke`/`@tauri-apps` import（见 `src/commands/*`、`src/services/*`、`src/utils/save/*`、`src/hooks/*`）。
- **插件**：fs、dialog、http、shell、clipboard-manager、sql、`@crabnebula/tauri-plugin-drag`。
- **窗口/事件**：`getCurrentWindow`（最小化/最大化/关闭/onResized）、`tauri://drag-*` 事件、`convertFileSrc`/`asset:` 协议、`appLocalDataDir`/`join`/`path`。

## 实施方案
用脚本 + 人工复核，逐类穷举并登记到一张「命令-调用点-插件 API-迁移归属任务」对照表。

## 执行步骤
1. 用 Grep 穷举后端命令：在 `src-tauri/src` 搜 `#[tauri::command]` 与 `#[command]`，逐一登记函数名、入参、返回、所属模块。
2. 用 Grep 穷举前端调用：搜 `invoke(`、`invoke<`、`from '@tauri-apps`，登记每个调用对应的命令名、文件、用途。
3. 登记插件 API 使用点：`plugin-fs`（readFile/writeFile/exists/mkdir）、`plugin-dialog`、`plugin-shell`、`plugin-clipboard-manager`、`plugin-sql`、`plugin-drag`、`api/path`、`api/window`、`api/event`、`api/core(convertFileSrc/isTauri)`。
4. 登记自定义协议与媒体加载路径：`convertFileSrc`、`asset:`、`readFile→Blob URL`（`src/utils/save/fileUrls.ts`）。
5. 为每一项标注「目标迁移任务编号」（3.1~3.9 / 2.x）。
6. 汇总成清单，回填本任务「执行记录」，并据此校正 `01-迁移方案.md` 与各任务的「当前情况」。
