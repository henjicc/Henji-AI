# 00 项目总览：痕迹AI 从 Tauri 迁移至 Electron

> 本文件是整个迁移计划的总入口，只记录全局状态与跳转入口。技术细节见 `01-迁移方案.md` 与各任务文件。

## 项目目标

将痕迹AI 桌面外壳从 **Tauri 2.0（Rust + 系统 WebView）** 迁移至 **Electron（Node + 打包 Chromium）**，核心诉求：

1. **跨平台/跨设备一致性**：摆脱 macOS WKWebView 与 Windows WebView2 的引擎差异，全平台统一 Chromium，保障画布在不同设备上表现一致。
2. **锁定 Chromium 能力**：稳定使用较新的 WebGPU / OffscreenCanvas / Worker 等高性能能力，为画布模式的复杂、高性能操作打底。
3. **后期开发中心全面转向画布模式**，外壳需更可控、可调试、可预期。

> 重要前提（见 `记录/重要决定.md` 决定 001）：在 Windows 上 Tauri 已使用 Chromium 内核（WebView2），换壳本身不直接提升画布性能。迁移的真实收益是**一致性与能力锁定**，而非单机性能。

## 重要说明

- **架构红线不变**：迁移期间继续遵循 `CLAUDE.md` 的解耦约束（配置驱动、生成主链路 `GenerationService → 命令桥 → 后端`、UI primitive 单点、颜色令牌等）。本次迁移只换「外壳与命令桥的实现」，不改业务分层。
- **平台抽象层是迁移成败关键**：所有 `@tauri-apps/*` 调用先收敛到 `src/platform/*` 抽象层，再做 Electron 适配，使新旧外壳可并行共存、可回滚（见决定 003）。
- **双壳共存策略**：第二、三阶段允许 Tauri 与 Electron 两套外壳同时存在，逐命令灰度切换，任一任务可独立回滚。
- 待确认信息集中在 `记录/重要决定.md`，执行被阻塞任务前必须先确认对应决定。
