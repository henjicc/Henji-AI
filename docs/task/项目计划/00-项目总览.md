# 00 项目总览：痕迹AI 从 Tauri 迁移至 Electron

> 本文件是整个迁移计划的总入口，只记录全局状态与跳转入口。技术细节见 `01-迁移方案.md`、`记录/重要决定.md` 与各任务文件。

## 项目目标

将痕迹AI 桌面外壳从 **Tauri 2.0（Rust + 系统 WebView）** 迁移至 **Electron（Node/TS + 打包 Chromium）**，核心诉求：

1. **跨平台/跨设备一致性**：摆脱 macOS WKWebView 与 Windows WebView2 的引擎差异，全平台统一 Chromium。
2. **锁定 Chromium 能力**：稳定使用较新的 WebGPU / OffscreenCanvas / Worker 等高性能能力，为画布模式打底。
3. **长期开发重心转向画布模式**，外壳需更可控、可调试、可预期。

> 重要前提（见 `记录/重要决定.md` 决定 001）：在 Windows 上 Tauri 已使用 Chromium 内核（WebView2），换壳本身不直接提升画布性能。迁移的真实收益是**一致性与能力锁定**，而非单机性能。

- **本机自动化验证已经较充分**：`electron:build`、`electron:smoke`、画布压测、DPI 检查、Windows NSIS/MSI 安装器、本地 updater E2E 均有记录。
- **剩余不应阻塞日常开发**：证书/公证、真实 GitHub Release、macOS 真机、真实旧数据/API key 都依赖外部条件，可作为发布前验收项登记。
- **4.3 需要谨慎执行**：删除 Tauri 是不可逆清理动作，建议在确认无需回退旧壳、并打好 `tauri-final` tag 后再做。当前先更新文档基线，不急于删除旧壳。

## 重要说明

- **架构红线不变**：迁移后继续遵循解耦约束（配置驱动、生成主链路 `GenerationService → 命令桥 → PAL → Electron 主进程`、UI primitive 单点、颜色令牌等）。
- **Electron 是新开发基线**：新增桌面能力优先落在 `electron/main/services/**` + `electron/main/ipc/**` + `src/platform/adapters/electron/**`。
- **Tauri 只作旧壳兼容/回退**：除 4.3 清理、回归对照或明确用户要求外，不再扩展 `src-tauri/` 和 `src/platform/adapters/tauri/`。
- **资源目录仍有迁移残留**：manifest/seeds 目前仍生成到 `src-tauri/resources/`，Electron 打包会复制这些资源；目录改名可放到 4.3。
