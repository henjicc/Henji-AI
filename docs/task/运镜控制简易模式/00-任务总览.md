# 运镜控制简易模式 · 任务总览

## 任务目标

当前运镜控制（`src/features/cameraStage/`）是一套 AE 式专业关键帧系统：逐属性码表打点、轨道树、曲线编辑器、贝塞尔缓动。对"快速随手做一段画面/视频"的用户上手门槛过高。

本任务为运镜控制新增**简易模式**：时间轴变成一排"镜头卡"（每张卡 = 整个场景的完整状态快照 + 停留时长 + 过渡时长），用户只管摆画面、加卡片，卡与卡之间的过渡由系统自动生成（差异检测 + 自动缓动 + 角色自动走跑 + 摄像机运镜预设），全程不接触关键帧概念。进阶用户可展开"过渡细节层"调速度预设、错峰延迟、运镜预设参数，并可给摄像机挂"效果器"（手持晃动等）。简易工程可单向烘焙为专业工程。

**属于本次任务**：简易模式数据模型与持久化（schemaVersion v11）、快照→关键帧编译器、摄像机运镜预设、角色自动走跑推断、镜头卡时间轴面板、过渡细节层、工程模式接入、摄像机效果器（一期仅摄像机）、单向烘焙、回归验收。

**不属于本次任务**：专业模式时间轴的任何改动、物体通用效果器（随机晃动等，二期）、新增角色动作资源、视频导出链路改动（复用现有）、多摄像机切镜/剪辑。

## 重要说明

- 核心技术路线：简易模式片段数据**编译成现有 `StageTrack` 关键帧**后播放/导出，采样引擎（`keyframeEngine`）、播放驱动（`StagePlaybackDriver`）、视频导出（`cameraStageVideo`）零改动或极小改动。
- 工程锁定模式：新建工程时选择简易/专业（默认简易），简易→专业单向烘焙不可逆，专业不能转简易。已有旧工程（v10 及以下）一律视为专业工程。
- 编译必须做差异检测（带容差）：只给前后两卡之间真正变化的属性生成轨道，未变化的对象/属性不产生关键帧。
- 摄像机过渡走"运镜行为预设"（推拉/环绕/跟随等，相对目标），不是纯位置插值——环绕等运镜两点插值做不出来。
- 效果器在采样层做**确定性**叠加（同一时间必须得到同一结果，否则视频导出逐帧 seek 会不一致），不产生关键帧。
- 遵守项目治理约束：新文件 ≤400 行、禁止新增裸 any、颜色走 token、UI 只用 `Ui*` primitives、关键链路补 `createLogger` 日志。
