## 任务目标

定义简易模式全部核心数据类型（镜头卡、过渡、运镜预设、效果器占位、编辑器模式），并完成工程序列化 schemaVersion v10 → v11 升级与向前兼容迁移。完成后：类型可被编译器/store/UI 引用；v11 工程可保存加载；v10 及以下旧工程加载后 `editorMode='pro'`、`shots=[]`，行为与现状一致。

## 当前情况

- 场景对象类型在 `src/features/cameraStage/domain/sceneTypes.ts`（153 行）：`StagePrimitiveObject` / `StageCharacterObject`（含 pose、motion）/ `StageCameraObject`（含 fov、lookAt、aspectRatio）。
- 动画类型在 `src/features/cameraStage/domain/animationTypes.ts`：`StageTrack` / `StageKeyframe` / `StageEasing`（预设 + 贝塞尔）。
- 序列化在 `src/features/cameraStage/domain/sceneSerialization.ts`（313 行，当前 schemaVersion=10）：文件头注释逐版本记录迁移历史，`parseAnimation` / `parseSceneSettings` 是宽松解析的现成范例。
- 工程持久化编排在 `src/features/cameraStage/projects/cameraStageProjectService.ts`：`serializeScene` 的输入是 `StageSceneSnapshotInput{ objects, activeCameraId, animation, sceneSettings }`，模式与 shots 需并入该快照。
- 可动画属性注册表 `src/features/cameraStage/domain/animatableProps.ts` 提供每对象可动画分组及 `getBaseValue`——快照捕获函数应复用它，不要手写逐字段拷贝。

## 实施方案

新建 `domain/shotTypes.ts` 承载简易模式类型 + 快照捕获/应用纯函数；`sceneSerialization.ts` 升 v11。effectors 只定义类型和空数组默认值（实装在 3.1）。

类型草案（执行时可微调命名，但语义不变）：

```ts
export type StageEditorMode = 'simple' | 'pro'

/** 单对象在某张镜头卡中的可动画状态快照 */
export interface StageShotObjectState {
  transform: StageTransform
  color: string
  fov?: number                    // 仅摄像机
  lookAt?: StageCameraLookAt      // 仅摄像机（运镜预设需要目标）
  pose?: StageCharacterPose       // 仅角色
  motion?: StageCharacterMotion   // 仅角色（卡内动作，如"待机"）
}

export type StageSpeedPreset = 'uniform' | 'easeInOut' | 'fastStart' | 'slowStart'

/** 摄像机运镜预设（细化在 1.3，此处先定判别联合骨架） */
export type StageCameraMove =
  | { kind: 'direct' }                                        // 默认：两态直插
  | { kind: 'orbit'; degrees: number; direction: 'cw' | 'ccw' }
  | { kind: 'dollyIn' | 'dollyOut'; /* 目标由 lookAt 决定 */ }
  // …其余预设 1.3 定稿

export interface StageShotTransition {
  perObject: Record<string, {
    speedPreset?: StageSpeedPreset
    delay?: number                 // 错峰延迟（秒，可为负=提前，编译时钳制）
    motionOverride?: StageCharacterMotion  // 覆盖自动走跑推断
  }>
  cameraMoves: Record<string, StageCameraMove>
}

export interface StageShot {
  id: string
  name: string                     // 默认"片段 N"
  hold: number                     // 停留时长（秒，≥0）
  transitionDuration: number       // 到下一卡过渡时长（秒，末卡忽略）
  objectStates: Record<string, StageShotObjectState>
  transition: StageShotTransition
}

/** 摄像机效果器（3.1 实装，本任务仅类型+默认空数组） */
export interface StageCameraEffector {
  id: string
  kind: 'handheld' | 'breathing'
  enabled: boolean
  intensity: number
  frequency: number
}
```

配套纯函数（放同文件或 `shotSnapshot.ts`，控制单文件 ≤400 行）：

- `captureShotObjectState(object: StageObject): StageShotObjectState`（复用 animatableProps 的 getValue + motion/lookAt 直读）
- `createShot(objects, name): StageShot`（默认 hold=0.5、transitionDuration=2）
- `normalizeShots(raw: unknown): StageShot[]`（宽松解析，供序列化用）

序列化改动：`StageSceneSnapshot` / `StageSceneSnapshotInput` 增加 `editorMode: StageEditorMode` 与 `shots: StageShot[]`；`StageCameraObject` 增加 `effectors: StageCameraEffector[]`（默认 `[]`）；v10 及以下加载时 `editorMode='pro'`、`shots=[]`、摄像机补空 effectors；文件头注释追加 v11 说明。
