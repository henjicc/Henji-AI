## 任务目标

在 `cameraStageStore` 建立简易模式状态与动作：`editorMode`、`shots`、`selectedShotId`、卡片增删改查/重排、"自动记录"（选中卡片时场景改动实时写回该卡）、shots 变化后自动重编译 `animation`。完成后可用控制台驱动完整数据流（加卡→改场景→自动写卡→重编译→播放），无 UI 也能验证。

## 当前情况

- `store/cameraStageStore.ts`（767 行，已超治理阈值——**本任务必须以新 slice 文件扩展，禁止往主文件堆代码**）：现有拆分范例 `store/keyframeSlice.ts`（`createKeyframeSlice(set)` 返回动作集，主文件组装）。
- 撤销历史：zundo temporal，`TrackedState = Pick<CameraStageState, 'objects' | 'animation'>`（cameraStageStore.ts 约 165 行处）。`shots` 与 `editorMode` 需加入 tracked，否则卡片操作不可撤销。
- 自动记录的挂点：现有 `updateObject` / `updateTransform` / `updatePoseJoint` 已有 AE 式自动打点参数 `autoKeyPaths`（改值即对已有轨道补点）。简易模式思路相同但目标不同：**写回选中卡的 objectStates 并触发重编译**，注意简易模式下不要走 autoKeyPaths 逻辑（避免双写 animation）。
- 重编译时机：shots 或对象结构变化后调 `compileShotsToAnimation`（1.2）并 `set({ animation })`。**必须与引发它的 set 合并为一次状态更新**（同一个 set 回调里算好 shots 和 animation 一起返回），否则撤销历史出现两步。
- 对象增删同步：新增对象需补进所有卡（以当前状态为快照）；删除对象需从所有卡的 objectStates/perObject/cameraMoves 清除（参考现有 `removeObject` 里 `removeObjectTracks` 的做法）。
- 播放态互斥：播放中（`playback.playing`）不应自动记录（scrub 采样会临时改 objects）；同理 `applySampledObjectsSilently`（scrub 落回）不能触发写卡——自动记录必须只由用户编辑动作触发（走动作参数显式传入，而不是订阅 objects 变化）。

## 实施方案

新建 `store/shotSlice.ts`（模式仿照 keyframeSlice）：

```text
状态：editorMode, shots, selectedShotId, motionSchedule（编译旁路产物，非 tracked）
动作：
  addShot()            // 以当前场景捕获快照插入 selectedShot 之后并选中新卡
  removeShot(id)
  reorderShot(id, toIndex)
  selectShot(id)       // 同时把该卡状态应用回场景对象（复用 applyShotToObjects）+ seek 到该卡时间
  updateShotTiming(id, { hold?, transitionDuration? })
  updateShotTransition(id, patch)   // 细节层用：speedPreset/delay/cameraMoves/motionOverride
  captureIntoSelectedShot(objectIds?)  // 自动记录入口：把指定对象当前状态写回选中卡
  setEditorMode(mode)  // 烘焙用（3.2），一般不直接调
内部：recompile(state) → { animation, motionSchedule }
```

主 store 改动（最小化）：

- `TrackedState` 扩为 `'objects' | 'animation' | 'shots' | 'editorMode'`。
- `updateObject` / `updateTransform` / `updatePoseJoint`：`editorMode==='simple'` 且非播放态时，在同一 set 内写回选中卡并重编译（简易模式跳过 autoKeyPaths）。
- `newScene` / `loadSnapshot`：初始化/恢复 editorMode、shots、selectedShotId；简易新场景自动带"片段 1"初始卡。
- `addPrimitive` / `addCharacter` / `addCamera` / `duplicateObject` / `removeObject`：简易模式下同步全部卡片的 objectStates。

日志：`createLogger('features.cameraStage.simple')`，事件 `simple_mode.shot.added` / `simple_mode.compile.completed`（debug 级、带 shotCount/trackCount）等。
