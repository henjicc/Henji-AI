## 任务目标

实现简易模式下替代专业时间轴的"镜头卡"面板：横向卡片条 + 添加片段按钮 + 播放控制。卡片可选中（场景跳到该状态）、重排、改停留/过渡时长、删除；播放头在卡片条上有位置指示。完成后简易模式核心闭环（摆场景→加卡→播放）可在真实窗口走通。

## 当前情况

- 专业时间轴 `timeline/TimelinePanel.tsx` 挂在 `layout/CameraStageDock.tsx` 的 `DOCK_COMPONENTS.timeline` 槽位（`TimelineDockPanel` 包装）。**本任务先在该槽位内按 `editorMode` 条件渲染新旧面板**（顶层模式接入在 2.4 完善）。
- 播放控制现成组件 `timeline/PlaybackControls.tsx`（173 行：播放/暂停/停止/循环/时间显示/缩放/曲线开关）——简易模式复用其中播放/暂停/停止/循环子集，多余控件（模式切换、px 缩放、曲线视图）不显示；执行时评估是抽子组件还是新写精简条（优先抽子组件避免重复实现）。
- store 接口由 2.1 提供：`shots` / `selectedShotId` / `addShot` / `selectShot` / `removeShot` / `reorderShot` / `updateShotTiming`，播放沿用 `playback` / `play` / `pause` / `seek`。
- UI 约束：只用 `@/components/ui` 的 `Ui*` 组件；横向拖拽重排复用 `src/components/ui/fileUploader/useReorderDrag.ts`（项目规定的统一重排交互，先读其接口）；颜色用语义类与 `styleTokens`。
- 卡片缩略图：一期**不做真实场景截图**（成本与存储未定，见重要记录 004），卡片显示序号 + 名称 + 时长信息，视觉上用对象颜色点阵或纯色块占位。
- 时长编辑：卡上直接显示 `停留 0.5s / 过渡 2s`，点击弹出数字输入（`UiInput` type number）或小步进按钮；拖拽卡片间隙调时长可后置（先数字输入，够用）。

## 实施方案

新建 `simple/` 子目录承载简易模式 UI（与 timeline/ 平级，避免混放）：

- `simple/ShotTimelinePanel.tsx`：面板骨架 = 顶部精简播放条 + 卡片横向滚动区 + 尾部"＋添加片段"大按钮。
- `simple/ShotCard.tsx`：单卡渲染（序号/名称/hold/过渡时长/选中态/删除按钮/播放头经过高亮）。
- `simple/shotTimelineUtils.ts`：卡片时间区间计算（复用 1.2 编译器导出的时间布点函数，不重复实现）。

交互定义：

- 点卡 → `selectShot(id)`（场景跳该卡状态 + seek 到该卡 hold 起点）。
- 双击名称 → 重命名（UiInput 内联）。
- 拖拽卡片 → `reorderShot`。
- 播放中卡片条按 `playback.currentTime` 高亮当前所处卡/过渡段。
- 空状态：无卡片时居中提示"点击「添加片段」记录当前画面"。
