# 2.3 过渡细节层面板

## 任务状态

- 状态：待开始
- 所属阶段：第二阶段-简易模式界面
- 前置任务：2.2、1.3、1.4
- 关联任务：2.4
- 是否可以并行：可与 2.4 并行

## 任务目标

为两卡之间的"过渡"提供可展开的细节编辑层：按对象逐行显示本段过渡中发生变化的对象，每行可调速度预设、错峰延迟；摄像机行额外可选运镜预设及参数；角色行可覆盖自动走跑推断。默认完全收起，小白用户可以永远不打开它。

## 当前情况

- 数据通路已就绪：`StageShotTransition.perObject`（speedPreset/delay/motionOverride）与 `cameraMoves` 由 1.1 定义，`updateShotTransition` 动作由 2.1 提供，编译消费由 1.2/1.3/1.4 完成——本任务纯 UI。
- 挂载位置：镜头卡面板（2.2 `simple/ShotTimelinePanel.tsx`）中，选中卡与下一卡之间的"过渡区"点击展开；展开形态执行时定（卡片条下方抽屉 or 卡间弹出面板），优先下方抽屉（空间充裕、不遮卡片条）。
- "本段过渡变化了哪些对象"：调用 1.2 编译器导出的差异检测函数（如 `diffShotObjects(shotA, shotB)`），**禁止在 UI 重新实现 diff**。
- 可复用组件：`Dropdown`（速度预设/运镜预设选择）、`UiInput`（延迟数值）、`UiOptionButton`（方向/档位）。速度预设建议配小图标或曲线缩略 SVG（颜色走 token）。
- 运镜预设选项来自 1.3 定稿的 `StageCameraMove` 联合；角色 motionOverride 选项来自 `characterMotion.ts` 的 `CHARACTER_ANIMATION_CLIPS`（含"自动（推荐）"与"无动作"项）。

## 实施方案

- `simple/TransitionDetailPanel.tsx`：抽屉容器，标题"片段 N → 片段 N+1 的过渡"，列出变化对象行。
- `simple/TransitionObjectRow.tsx`：单对象行 = 对象名 + 类型图标 + 速度预设 Dropdown + 延迟输入；摄像机行追加运镜预设 Dropdown + 参数（角度/方向/距离比）；角色行追加动作 Dropdown（自动/指定 clip/无）。
- 所有修改即时调 `updateShotTransition` → 2.1 自动重编译 → 播放立即生效。
- 空态：本段过渡无变化对象时显示"这两个片段之间没有变化"。

## 执行步骤

1. 确认 1.2 已导出 UI 可用的 diff 函数；没有则先在 shotCompiler.ts 补导出（不改逻辑只暴露）。
