### 简易模式手动验收清单（待用户在真实 Electron 执行）

1. 运行 `npm run electron:dev`，新建简易工程，放置 1 个 box、1 个角色、1 台摄像机；建三张卡：初始；角色绕 box 且 box 变色；摄像机环绕 180°并开启手持效果器；给 box 设置延迟。预期卡片时长/高亮、自动走跑与朝向、延迟变色、环绕均正确。
2. 完整播放，在角色移动、环绕中点和效果器明显时暂停，前后 scrub 后回到同一时刻。预期对象、动作、相机及效果器构图可重复，播放/scrub 不反写镜头卡。
3. 逐项测试四种速度、延迟负值/正常值/超界值、direct/orbit/dollyIn/dollyOut/truck/crane 全部参数、角色自动/无动作/指定 clip。预期即时重编译、延迟安全钳制、非 direct 使用几何终点、动作覆盖正确。
4. 新增、复制、删除、重排、重命名卡片并修改两类时长，每步撤销/重做。预期对象快照、卡片与动画原子回退/恢复，播放/scrub 不产生历史。
5. 保存简易工程，退出并重启后重开。预期模式、卡片、细节、动作与效果器保持；加载真实 v10 工程，预期按专业模式打开且旧动画一致。
6. handheld/breathing 分别比较连续播放、暂停/scrub 同一时刻、720p MP4 同一时刻。预期三路径一致、无随机跳帧，关闭后基础机位不漂移。
7. “转为专业工程”先取消，确认零变更；再确认转换，确认镜头卡消失、专业轨道可编辑、播放/动作/效果器不变、撤销不能回简易。
8. 保存烘焙工程并重启重开。预期仍为专业、轨道和效果器保留、无反向入口。

### 失败处置建议

先让 smoke 输出 console error 对应请求 URL/来源，确认是应用资源、外部服务还是环境策略；若为预期外部请求，只按明确 URL 做最小处理或在测试环境禁用，禁止按 `403` 文案全局忽略。修复后重跑全套，补 v10 夹具验证，再交用户手动验收。
