# 3.3 整体回归与验收

## 任务状态

- 状态：待开始
- 所属阶段：第三阶段-效果器与烘焙收尾
- 前置任务：全部（1.1~3.2）
- 关联任务：无
- 是否可以并行：否（收尾）

## 任务目标

对简易模式全链路与专业模式回归做一次系统验收：自动检查全绿、单元测试全过、端到端场景（含视频导出）走通、旧工程兼容确认；给用户输出一份完整的手动验收清单。

## 当前情况

- 项目快速检查命令（CLAUDE.md 约定）：`npm run gen:model-manifest`、`npm run check:colors`、`npm run check:model-i18n`、`npm run lint`、`npx tsc -p tsconfig.electron.json --noEmit`、`npm run electron:smoke`；本任务全套执行一遍，另跑本任务新增的 vitest 单测。
- 端到端基准场景（覆盖全部新能力）：简易工程 + 1 个 box + 1 个角色 + 1 台摄像机，三张卡——卡1 初始；卡2 角色位移绕过 box（触发自动走跑）+ box 变色；卡3 摄像机环绕 180° + 手持效果器开启；细节层给 box 设延迟。播放 → 导出 720p MP4。
- 专业模式回归点：打点/轨道/曲线编辑器/播放/导出与改动前一致；v10 旧工程（准备一份改动前导出的工程 JSON 作为夹具）加载正常。
- 涉及大量鼠标操作的验证按项目约定整理成步骤清单交给用户执行，AI 负责自动化部分。

## 实施方案

先自动化（检查+单测+必要时 `npm run electron:build` 验证完整类型链路），后输出用户手动验收清单（按场景分组、每项写明操作与预期），用户反馈问题逐项修复并记录。

## 执行步骤

1. 跑全套快速检查与单元测试，修复暴露的问题。
2. 治理自查：新增文件行数统计（>400 行列出拆分计划）、`any` 增量检查、原生控件检查、颜色硬编码检查（命令见 CLAUDE.md）。
3. 准备 v10 旧工程夹具并验证加载/播放/导出行为与主分支一致。
4. 视需要跑 `npm run electron:build` + `npm run electron:smoke` 验证打包链路。
5. 输出《简易模式手动验收清单》（写入本文件执行记录，不另建文档），覆盖：基准场景端到端、细节层各项、效果器三路径一致性、烘焙前后一致性、专业模式回归、撤销重做矩阵。
6. 跟进用户反馈的问题，修复后更新执行记录。
