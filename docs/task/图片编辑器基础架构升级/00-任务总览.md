# 图片编辑器基础架构升级任务总览

## 任务目标

将当前以“快速标记”为中心的 `imageMark` 能力升级为可持续扩展的统一图片编辑器基础架构。编辑器保留顶部高频标注工具栏，建立右侧工具图标栏与可调整、可折叠的参数面板，并将图片操作定义、编辑器界面、执行能力和画布宿主适配分层。

本次包含编辑文档与兼容契约、工具注册与执行端口、标注模块拆分、共享编辑器外壳、可伸缩右侧面板、工具箱/查看器/画布/智能助手兼容接入和整体回归。本次不实现黑柔、白柔、灰光、调色等具体算法，不正式新增独立图片效果节点，不建立第三方动态插件市场。

## 重要说明

- 产品上只有一个“图片编辑”宿主；标注、几何、未来发光/调色是模块化工具，不各自复制编辑器。
- 共享的是参数 schema、默认值、校验、操作数据和执行能力；完整参数面板与紧凑画布节点不强求100% UI 相同。
- UI 尺寸继续使用 CSS 逻辑像素/`rem` 与视口约束；图像效果参数必须使用图片空间的百分比或归一化值，不与用户屏幕物理像素绑定。
- 具体发光/调色算法、新主进程像素执行器和正式独立效果节点后置；本任务只建立它们所需的稳定边界。
- 任何鼠标拖拽、面板缩放、标注绘制和画布交互验收都由用户在真实 Electron 窗口中手动完成。
- 每个任务开始和完成时都同步本总览与任务执行记录；已确定编号不重排。
