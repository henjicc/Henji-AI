## 运行约束

- 显卡 18:30 前由主会话 4K60 测量占用：此前不启动 Electron、Reality 或 GPU 测试。
- 调色参数是持久格式（剪辑文档、图片文档/包/工作副本、效果预设）：升版本、逐版本迁移、黄金样本。
- 参数写入走通用属性；新增能力只限分析/匹配/自动类算法。
