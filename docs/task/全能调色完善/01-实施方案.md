# 全能调色完善：实施方案

## 1. 现状（2026-10-21 代码核对）

- 参数登记：`src/core/imaging/adjustments/colorGrade.ts`（`ImagingParam` 列表），剪辑效果定义 `src/core/videoEdit/colorGrade.ts` 与图片 schema `adjustments/schema.ts` 都从它派生；剪辑参数写入走 `normalizeVideoEditBuiltinParams`，**未知键会被拒绝**，所以删除或改名旧键必须迁移旧数据。
- 计划与执行：`adjustments/plan.ts` 输出多道全屏 pass（基本、创意、4 条 RGB 曲线、5 条色相曲线、3 个色轮各一道），三个执行端：剪辑 `videoEditBuiltinEffectsGpu.ts`、图片 `imageEditorGpuColorGradeV3.ts`、CPU `effects/cpu/colorGrade.ts`。
- 工作域：白平衡、曝光在线性光；对比度、高光/阴影、饱和度、曲线、色轮在 sRGB 编码值上。
- 自动：`suggestColorGradeAutoColor`（灰世界 + 百分位）、`suggestColorGradeMatch`（逐通道矩/直方图 → RGB 曲线）；助手只有 `analyze_video_edit_color`。
- 持久位置：剪辑文档 `document.video_edit`（v17）、可分享预设包 `video-preset-package`（v5）、本机效果库 `video-edit-effects-library`（未登记格式，内部 version 1）、图片工作副本 `image-working-copy`（v14）、图片包 `image-package`（v12）、画布图层包 `canvas-layer-package`（v12）。

## 2. 参数格式 v2

原则：键名不变 = 含义不变或仅算法改进；单位/含义彻底改变的改新键名，旧键由迁移换算后删除。

| 区段 | v2 参数 | 与 v1 的关系 |
|---|---|---|
| 白平衡 | `temperature_kelvin`（2000–20000 K，默认 6500）、`tint`（±100，正值偏洋红） | 旧 `temperature`（RGB 增益）删除，迁移按最小色度误差反解开尔文；`tint` 同向重定义为 Duv 偏移，迁移同时反解 |
| 曝光/反差 | `exposure`（EV）、`contrast`（中灰 18% 对数斜率，只作用亮度、保色相） | 键与数值语义（斜率）保留，算法改进 |
| 色调 | `highlights` `shadows` `whites` `blacks` | 键保留，改为对数亮度分区曲线、保色相 |
| 参数曲线 | `tone_highlights` `tone_lights` `tone_darks` `tone_shadows` | 新增 |
| 饱和度 | `saturation`、`vibrance`（OkLCh 彩度，自然饱和度带肤色保护） | 键保留，算法改进 |
| 色轮 | `wheel_mode`（`grading` 分级 / `primary` Lift-Gamma-Gain-Offset），`shadow_*` `midtone_*` `highlight_*` `global_*`（hue/strength/luminance），`grade_blending` `grade_balance` | 三轮键保留；新增全局轮与模式；旧 `creative_shadow_*` / `creative_highlight_*` 与色轮重复，迁移按色度向量并入阴影/高光轮后删除 |
| 混色器 | `mixer_<红/橙/黄/绿/浅绿/蓝/紫/洋红>_{hue,saturation,luminance}` | 新增，OkLCh 平滑色相权重 |
| 曲线 | `curve_*_points`、旧五点 `curve_*_0..4`、色相曲线 | 保留；色相横轴改为“显示色相”（OkLCh 色相按六个原色/间色锚点分段映射到 HSL 色相刻度，锚点处与旧横轴一致） |
| 其余 | LUT、淡化胶片、锐化、HSL 辅助、晕影 | 保留 |

## 3. 统一管线

顺序：输入 LUT → **统一调色 A**（线性：白平衡 CAT、曝光；对数：反差、色调分区、参数曲线；OkLCh：饱和度/自然饱和度）→ Look LUT → **统一调色 B**（淡化胶片、色轮分级/LGG、混色器、RGB 点曲线、色相曲线）→ HSL 辅助 → 锐化 → 晕影。无 Look LUT 时 A、B 合成一道 pass。

- 参数和曲线打包成一张浮点查找纹理（第 0 行参数，其余行为 1024 采样曲线），复用现有 `lookup` 绑定，三个执行端不改绑定布局，只把一维曲线上传扩展成二维。
- CPU 与 WGSL 各一份逐像素实现，`gradePixel` 是真值，WGSL 对照测试在 GPU 可用后补跑。
