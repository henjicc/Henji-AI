## 任务目标

打通“原生进程 D3D11 共享纹理 → 主进程导入 → 沙盒 preload 接收 → 剪辑渲染 Worker 得到 VideoFrame → WebGPU 使用”的完整通道，并带上帧元数据、背压与释放回收。本任务用原生服务**合成的测试画面**（不解码真实文件）验证正确性与性能，确定各共享格式在 WebGPU 中是否可用（重要记录 007）。

## 当前情况

- 2026-10-02 原型（临时目录，未入库）已证明：离屏渲染产生的约 4K bgra 共享纹理经 `sharedTexture.importSharedTexture` → `sendSharedTexture` → preload `setSharedTextureReceiver` → `getVideoFrame` → WebGPU `importExternalTexture`，稳定 60 帧/秒，主进程每帧 0.6ms；且 `sandbox: true` + `contextIsolation: true` 的 preload 可用 `sharedTexture`。
- 尚未验证：原生进程自建纹理的 NT 句柄跨进程导入；`nv12`/`nv16`/`p010le`/`rgbaf16` 在 WebGPU 的显示正确性；VideoFrame 从 preload 隔离世界转交到专用 Worker（`videoEditWorker.ts`）；多流并发。
- 渲染 Worker 入口：`src/features/videoEdit/engine/videoEditWorker.ts`（主线程代理 `videoEditRenderSession.ts`）；preload 入口 `electron/preload/index.ts`（`contextBridge.exposeInMainWorld('henjiNative', …)`）；渲染层访问桌面能力只能经 `src/platform/*`。
- Electron API 要点：`importSharedTexture({ textureInfo: { handle: { ntHandle }, pixelFormat, codedSize, visibleRect, timestamp, colorSpace }, allReferencesReleased })`；`sendSharedTexture` 1000ms 超时、接收端须先注册；`nv12` 句柄带 keyed mutex，rgba 类不带。

## 实施方案

原生侧：每个流一个共享纹理池（默认 6–8 张，可配置），纹理以 `D3D11_RESOURCE_MISC_SHARED_NTHANDLE`（nv12 另加 keyed mutex）创建；为每张纹理 `CreateSharedHandle`，再 `DuplicateHandle` 到 Electron 主进程（主进程 PID 由握手提供）；帧就绪时通过控制通道发送 `{ stream, slot, handle, format, codedSize, timestampUs, colorSpace }`。主进程：导入、发送到发起请求的 webContents 主 frame，`allReferencesReleased` 回调后通知原生侧该槽可复用。preload：注册接收器，把 VideoFrame 通过页面交给它的 `MessagePort`（transfer）送到渲染 Worker；只暴露最小接口，不把 `sharedTexture` 对象本身暴露给页面。

## 执行步骤

1. 首先验证 VideoFrame 跨世界转交：preload 接收 → 经 MessagePort transfer 给专用 Worker → Worker 内 `importExternalTexture` 成功；若不可行，按实施方案风险表评估备选并记录到重要记录。
2. 原生服务新增测试命令：按指定格式（nv12/nv16/p010le/rgba/rgbaf16）、尺寸（含 3840×2160、2560×2560）、帧率生成带帧号与色条的合成画面，写入共享纹理池并逐帧发出。
3. 主进程新增纹理桥模块（导入、发送、释放回调、槽位回收、超时处理、按 webContents 生命周期清理）。
4. preload 新增最小接收接口与 MessagePort 转交；`src/platform/` 增加对应平台适配，渲染 Worker 新增接收端（暂不接入渲染器，2.2 接入）。
5. 正确性：每种格式在 Worker 中读回关键像素（色条、帧号区域）与预期比较；记录不受支持的格式并更新重要记录 007。
6. 性能：单流 4K60 与多流（4 路、9 路 4K60）各测 30 秒：送达帧率、帧间隔 p95/p99/最大、主进程 CPU、GPU 进程 CPU、显存占用；释放回收无泄漏（长时间运行后纹理数与句柄数不增长）。
