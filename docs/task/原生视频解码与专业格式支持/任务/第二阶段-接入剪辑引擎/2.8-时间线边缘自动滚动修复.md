## 任务目标

时间线面板较矮时，在片段上按下的位置若落在面板顶部（或底部）的边缘自动滚动区，即使鼠标完全不动，时间线也会持续纵向滚动，导致按住的片段被“拖”到另一条轨道并被拒绝。改为与专业剪辑软件一致：只有拖动中指针实际向边缘移动（存在位移且进入边缘区）时才自动滚动；按下不动不滚动。

## 当前情况（2026-10-02 2.5 验收记录）

- 复现：960×640 窗口下时间线面板约 118px 高，在顶部自动滚动区按下片段不移动鼠标 → 持续纵向滚动。
- 位置：`src/features/videoEdit/timeline/useTimelinePointer.ts`（`animateEdge` 相关）。
- 2.5 的 Reality 场景 `scripts/lib/uiInspectionSceneVideoEditLinks.cjs` 为避开此区域调整过 960×640 的按下点；修复后恢复原按下点验证。

## 执行步骤

1. 读规则：`docs/rules/frontend-ui.md`、`docs/rules/testing.md`。
2. 修复自动滚动触发条件（需有拖动位移，且横向/纵向边缘滚动行为一致）。
3. 精确测试：按下不动不滚动；向边缘移动才滚动；离开边缘停止。
4. 真实 Electron：`npm run test:reality -- --suite ui --only video-edit-links`（恢复原按下点）与 `video-edit-timeline` 回归，副屏运行。

## 验收标准

- [ ] 按下不动不触发自动滚动；拖向边缘时正常滚动。
- [ ] 精确测试与真实 Electron 两种窗口尺寸通过；任务总览已同步。
