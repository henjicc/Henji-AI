## 任务目标

参照 Premiere Pro 的链接片段行为（2026-10-02 用户要求，重要记录 010），把时间线“链接”完善为专业剪辑软件的完整语义：

1. 任意片段之间都可以链接：视频与音频、音频与音频、视频与视频，以及多条音频、多条视频之间。
2. 联动编辑：选择、移动、修剪、删除，以及剃刀/播放头拆分时，链接组内的全部片段一起处理（拆分在同一时间点把组内跨越该点的片段都拆开，拆开后左右两半各自成组、保持链接）。
3. 取消链接：选中后解除链接；之后各片段完全独立。
4. 临时单独操作：按住 Alt 点击（或框选）只选中被点的那一条片段，不扩展到链接组；对它的移动、修剪、删除、剃刀只作用于这一条，链接关系保留。单独移动造成组内相对位置变化时，按 Premiere 的做法在片段上显示失步偏移（用户语言、帧数），而不是报错拒绝。
5. 提供 Premiere 式“链接选择”开关（时间线工具栏，默认开启）：关闭后点击只选单条，行为与按住 Alt 相同。

## 当前情况（2026-10-02 主控核对）

- 数据：`src/core/videoEdit/document.ts` 片段已有 `linkId`、`groupId`、`sourceComponent`；“拆开音画”`separate_audio` 生成画面片段 + 链接的音频片段。
- 命令：`src/core/videoEdit/commands.ts` 已有 `link`、`unlink`、`group`、`ungroup`、`split`、`split_tracks`、`razor_tool`；`link` 对任意 ≥2 个片段生成同一 `linkId`，不限类型。
- 选择：`src/core/videoEdit/timelineSelection.ts` `expandVideoEditSelection(sequence, ids, relations = true)` 总是按链接与编组扩展；调用方（`videoEditCommands.ts` `captureVideoEditCommandContext`、`videoEditService.ts` 第 292/322 行规范化选择、`videoEditTimeline.ts`、`timeline/useTimelinePointer.ts` `select`）均不传 `relations`，因此**目前无法单独选中链接组中的一条**，选择状态也会被重新扩展。
- 剃刀：`useTimelinePointer.ts` 剃刀松开时以 `clipIds: [clipId]` 执行 `split`，命令上下文会扩展链接组，所以链接片段应已联动拆分——执行时先用测试确认，并确认拆分后链接关系的处理（`timelineEdits.ts` 第 59–68 行为复制/拆分重新分配 `linkId`）。
- 约束：`timelineEdits.ts` 第 53 行在编辑会改变链接或编组相对时间时直接报错，需要改为支持“单独操作 → 失步显示”。
- 助手能力：剪辑实体属性经 `videoEditFields.ts` 注册（`linkId` 标签“音画链接”），命令经 `videoEditCommands.ts`；改动业务操作前按 `docs/rules/assistant-capability.md` 与 skill `henji-application-capability` 做覆盖分级，优先通用属性写入，不新增专用 Agent 工具。

## 实施方案

- 选择模型：选择状态记录“用户点选的片段”与“是否按链接扩展”，Alt 单选与“链接选择”开关关闭时不扩展；规范化选择（`videoEditService.ts`）不得把单选重新扩展。
- 编辑：所有编辑命令以“实际选择集”为准；链接扩展只在链接选择开启且未按 Alt 时发生。拆分对选择集内每个跨越点的片段执行，并维持拆分后两半各自的链接组。
- 失步：链接组内同源片段（同一素材、`sourceComponent` 分别为画面/声音，或 2.6 的多条声音流）相对源时间不一致时，在片段标签上显示偏移帧数（如“+3”），点击可按 Premiere 的“移入同步/滑入同步”恢复（可作为后续，执行时评估是否本任务完成）。非同源链接（如两条无关音频）不显示失步。
- 链接 UI：右键菜单与快捷键已有的“链接片段/解除链接”保持；时间线工具栏新增“链接选择”开关（按 `henji-ui-surface` 规范，用现有按钮原语与图标，不新建通用组件）。
- 不改变工程文件结构的兼容性：新增字段只能是可选字段；旧工程无需迁移。
