## 执行步骤

1. 用 `gh run view <id> --log-failed` 列全部失败用例；按“首次失败的提交”二分定位引入点。
2. 按根因修（产品缺陷修产品；测试与平台/换行符相关就让测试与平台无关），不删用例、不放宽断言。
3. 本地复现 CI 条件（必要时在 WSL/Linux 路径语义下跑相关测试，或用 path.posix 构造用例）。
4. 推送后核对 CI 全部 job 通过。
