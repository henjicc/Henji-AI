## 任务目标

把 `CameraStageEditor` 从固定三栏布局改造为 C4D/Blender 式可停靠工作区：主预览视口（中央，不可关闭）、资源管理器（场景对象列表）、属性管理三个面板可拖拽重排、tab 分组、自由调整大小、折叠/展开；布局状态自动记忆，重进编辑器恢复上次布局，并提供「重置默认布局」。默认布局对齐用户参考图：中央视口 + 右上资源管理器 + 右下属性管理（时间轴面板位在 3.2 加入）。

## 当前情况

- `src/features/cameraStage/CameraStageEditor.tsx`（105 行）是硬编码三栏 flex 布局：`<ObjectListPanel />`（固定 `w-60` 左栏）+ 视口 + `<PropertyPanel />`（固定 `w-72` 右栏），面板不可调宽、不可重排、不可折叠。
- 面板组件本体（`ObjectListPanel` / `PropertyPanel`）逻辑完整，只需去掉自带的固定宽度/边框样式，改为撑满 dock 容器。
- 视口是 R3F `<Canvas>`（`StageScene.tsx`），WebGL 上下文重挂载成本高，布局操作不能导致 Canvas 销毁重建。
- 项目当前无任何 dock 布局依赖；调研选型为 `dockview-react`（重要记录 002，待确认）。
- 主题 token 在 `src/index.css`（CSS 变量）+ `tailwind.config.js` + `src/core/theme/colorTokens.ts` 三处维护，dockview 主题化只允许在这三个入口落颜色。

## 实施方案

引入 `dockview-react`，在 `CameraStageEditor` 中用 `DockviewReact` 承载「视口 / 资源管理器 / 属性管理」三个 panel；自定义 dockview 主题类（覆盖其 CSS 变量，取值全部引用 `src/index.css` 既有 token），tab 头部样式对齐项目设计语言。视口 panel 锁定不可关闭；面板折叠用 dockview 的分组收纳/最大化能力实现，具体交互（双击 tab 折叠 vs 折叠按钮）执行时结合手感确定。布局用 dockview 序列化 API 持久化到 `localStorage`（界面态，不入 SQLite；键名含布局版本号，结构变更时自动回退默认布局）。popout 独立窗口能力禁用。

先做一次**小范围验证**再全面铺开：dockview 与 R3F Canvas 共存时的 resize 行为、panel 拖拽移动是否保持 DOM 不销毁（WebGL 上下文不丢）、主题变量覆盖效果；任一项不达预期，回到重要记录 002 降级评估备选库。

## 执行步骤

1. `npm install dockview-react`（用户确认后），记录打包体积增量。

3. 新建 `src/features/cameraStage/layout/` 模块：panel 注册表（id、标题、组件、能力约束）、默认布局定义、布局持久化（保存/恢复/重置/版本迁移）。
4. 定制 dockview 主题：新增主题类挂到编辑器根节点，CSS 变量映射到项目 token（改动仅落 `src/index.css`）。
5. 改造 `CameraStageEditor.tsx` 为 dockview 编排；`ObjectListPanel`/`PropertyPanel` 去掉固定宽度与外边框样式适配容器；视口浮层控件（视角切换等）暂保持现状（2.2 迁入工具栏）。

7. 回归：`npm run lint`、`npm run check:colors`、原生控件检查；把面板拖拽/折叠/布局记忆的手动验证步骤清单交给用户。
