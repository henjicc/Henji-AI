# 2.2 工具栏、快速添加与视口交互完善

## 任务状态

- 状态：待开始
- 所属阶段：第二阶段-工作区布局重构
- 前置任务：2.1
- 关联任务：2.3（快捷键中的撤销重做由 2.3 提供）、1.2（截图按钮迁移落位）
- 是否可以并行：可与 1.x、2.3 并行

## 任务目标

按用户参考图补齐编辑器的「专业软件感」：顶部固定工具栏（移动/旋转/缩放变换模式 + 视角切换 + 截图/保存入口）、基础对象图标快速添加栏（立方体/球体/圆柱/圆锥/棱锥/环状体/角色/机位，一图标一击即加）、视口常用交互（快捷键、对象复制、聚焦选中对象）、属性面板未选中态改为「场景/项目设置」。

## 当前情况

- gizmo 模式（移动/旋转/缩放）与视角切换目前是视口左上角浮层按钮（`CameraStageEditor.tsx` 中 `GIZMO_MODES` + `UiOptionButton`），不是正式工具栏。
- 添加对象藏在 `ObjectListPanel` 的「＋ 添加对象」下拉里（8 个选项），没有图标化快速添加栏。
- 没有任何快捷键；store（`cameraStageStore.ts`）没有对象复制动作；视口没有「聚焦选中对象」能力。
- `PropertyPanel` 未选中对象时只显示一句提示文案；参考图要求未选中时显示整个项目的设置（如场景背景、网格显隐、渲染相关设置——具体项待执行时与用户确认最小集合）。
- 场景背景色/网格颜色目前取自 `src/core/theme/colorTokens.ts` 的 `CAMERA_STAGE_COLOR_HEX` 常量，尚不可调。
- 相机对象的 gizmo 被强制为 translate（`StageScene.tsx` 中 `transformMode`），旋转机位只能靠 lookAt 设置——工具栏做出来后这个限制的交互表达要一并理顺（禁用态提示而非静默失效）。

## 实施方案

在 dock 工作区上方加一条固定工具条（不属于 dock 面板，参照参考图左上工具栏+顶部快速添加栏的布局）：左段为变换模式组（W/E/R 对应移动/旋转/缩放）、视角切换与机位下拉（从视口浮层迁入）；中段为基础对象快速添加图标组（lucide 图标 + tooltip，一击添加并选中）；右段为截图导出、保存等操作入口。视口交互：注册编辑器作用域内的快捷键（W/E/R 切 gizmo、F 聚焦选中对象、Delete 删除、Ctrl+D 复制、Ctrl+S 保存；快捷键只在编辑器获得焦点且不在输入框内时生效）；store 新增 `duplicateObject`（深拷贝对象、名称自动递增、位置轻微偏移）。`PropertyPanel` 未选中态渲染「场景设置」区块（背景色、网格显隐等最小集合，数据入 store 并随工程持久化）。

## 执行步骤

1. 新建工具栏组件（`src/features/cameraStage/toolbar/`）：变换模式组、视角/机位组、快速添加图标组、操作组，全部用 `Ui*` primitives；`CameraStageEditor` 顶部接入，移除视口浮层中的对应旧按钮。
2. store 新增 `duplicateObject`（含角色姿态/机位设置的深拷贝）并接入快捷键与对象列表右键或按钮入口。
3. 实现编辑器作用域快捷键 hook（`useCameraStageShortcuts`，参照画布 `useCanvasShortcuts.ts` 的既有模式）：W/E/R、F、Delete、Ctrl+D、Ctrl+S、Ctrl+Z/Ctrl+Shift+Z（后两个接 2.3 的历史栈，2.3 未完成时先预留）。
4. 视口实现「聚焦选中对象」（OrbitControls target 平滑对准对象包围盒中心）。
5. `PropertyPanel` 未选中态改为场景设置区块；新增场景级设置字段入 store 与序列化（`schemaVersion` 内增量字段，与 1.1 协调）。
6. 相机对象在旋转/缩放模式下的禁用态给出明确 UI 反馈。
7. 回归 lint/颜色/原生控件检查；输出快捷键与工具栏手动验证清单交给用户。
