## 任务目标

编辑器底部新增 AE 式时间轴面板（dock 面板，可折叠到最小/展开/调高）：左侧轨道树（对象 → 已打关键帧的属性行），右侧刻度区（时间刻度 + 播放头 + 关键帧菱形点位）；属性面板每个可动画属性行行首加「码表」按钮打/删关键帧；支持播放控制、scrub、关键帧拖移/删除。全部 UI 自研（`Ui*` primitives + SVG/绝对定位），不引入现成时间轴组件库。

## 实施方案

新建 `src/features/cameraStage/timeline/` 模块，按子组件拆分（面板容器、播放控制条、轨道树、刻度尺、轨道行、关键帧点、播放头），单文件控制在 400 行内。交互设计：

- **码表打点**：属性面板每个可动画属性行行首放码表 `UiIconButton`；无轨道时点击=以当前值在当前时间创建关键帧并建轨；有轨道时点击=在当前时间打/删点；码表态（无轨道/有轨道/当前时间恰有点）三态视觉区分。属性值在有轨道状态下被修改时自动在当前时间打点（AE 行为）。
- **轨道树**：按对象分组、可展开收起；行点击选中对应对象并在属性面板高亮；轨道删除入口。
- **刻度区**：时间刻度尺（秒/帧切换）、点击/拖拽 scrub、播放头竖线贯穿轨道区；关键帧菱形可单选/框选（框选可留待迭代，执行时定）、水平拖移改时间、Delete 删除、右键或双击进入 3.3 缓动编辑。
- **播放控制**：播放/暂停、回首帧、循环开关、当前时间与总时长显示、时长编辑。
- 缩放：水平 zoom（滚轮或滑杆）+ 平移，视口虚拟化暂不做（对象量级小）。
- 上游连线只读、禁用等场景不涉及；所有关键帧写操作走 3.1 的 store 动作，天然进历史栈。
