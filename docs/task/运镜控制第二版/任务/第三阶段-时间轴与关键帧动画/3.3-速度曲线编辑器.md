# 3.3 速度曲线编辑器

## 任务状态

- 状态：待验证（预设/曲线编辑弹层已落地；手柄拖拽手感待用户在 Electron 窗口验证）
- 所属阶段：第三阶段-时间轴与关键帧动画
- 前置任务：3.2
- 关联任务：3.1（缓动求值复用 keyframeEngine）
- 是否可以并行：否

## 任务目标

关键帧支持缓动（速度曲线）编辑：提供缓动预设（线性/缓入/缓出/缓入缓出）一键应用，以及自定义贝塞尔曲线的可视化编辑面板（拖拽出/入手柄调整相邻关键帧之间的插值曲线），编辑结果实时反映到播放效果并随工程持久化。

## 当前情况

- 3.1 的数据模型已定义 `StageEasing`：预设名或 `{ type: 'bezier', out: [x,y], in: [x,y] }`（关键帧出/入手柄），求值引擎已按该结构实现 cubic-bezier 插值——本任务是纯 UI 层，不改求值逻辑。
- 3.2 已有关键帧选中交互与「右键/双击进入缓动编辑」的入口预留。
- 参照对象：AE 的关键帧缓动（keyframe ease）+ 图表编辑器的简化版。第一版做「相邻关键帧区间的归一化缓动曲线编辑」（0~1 时间/值空间内拖两个手柄），不做 AE 完整图表编辑器的多维值曲线叠加显示。
- 项目内没有现成曲线编辑组件；SVG 实现（曲线路径 + 两个可拖拽手柄圆点 + 网格背景），用 `Ui*` + token 配色。

## 实施方案

新建曲线编辑弹层组件（`timeline/` 下）：选中一个或多个关键帧后经右键菜单/双击/工具栏按钮打开；顶部为预设按钮组（线性/缓入/缓出/缓入缓出，视觉上可用小曲线图标），主体为 SVG 曲线编辑区（显示当前区间的 cubic-bezier 曲线，拖拽出手柄/入手柄实时更新，数值也可精确输入），多选关键帧时批量应用。曲线修改走 store 的 `setEasing` 动作（3.1 已建，天然可撤销）。弹层形式优先复用项目现有 `Dropdown`/弹层容器模式，不新建一套浮层机制。

## 执行步骤

1. 实现 SVG 贝塞尔曲线编辑组件（网格背景、曲线、双手柄拖拽、数值输入行），几何换算独立成纯函数便于复用。
2. 实现缓动预设按钮组并定义各预设对应的 bezier 参数（与 CSS 标准 ease 系数对齐）。
3. 接入 3.2 的关键帧选中态：右键菜单/双击打开编辑弹层，多选批量应用。
4. 时间轴关键帧点增加缓动状态的视觉提示（如非线性缓动的菱形样式差异，执行时定）。
5. 联调：编辑曲线 → 播放验证速度变化 → undo/redo → 保存重开后曲线保留。
6. 回归 lint/颜色/原生控件检查；输出手柄拖拽的用户手动验证清单。
