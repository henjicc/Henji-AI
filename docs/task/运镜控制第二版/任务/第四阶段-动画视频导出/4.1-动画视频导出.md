## 任务目标

把时间轴上的关键帧动画按当前机位取景导出为本地视频文件（MP4）：渲染层按固定帧率逐帧采样渲染出 PNG 序列，主进程用 ffmpeg 编码为视频并走现有媒体机制落盘，导出的视频能像本地上传视频一样被生成链路使用。

## 当前情况

- 项目已有 `ffmpeg-static` / `ffprobe-static` 依赖与 `electron/main/services/video/` 视频处理服务（一期实施方案确认的现成基础），编码链路不需要从零搭。
- 3.1 的采样引擎是确定性的（时间 → 值），逐帧导出只需以 `frame / fps` 步进时间采样渲染，不依赖实时播放性能。
- 截图管线（1.2）已解决「渲染一帧 → 读出 PNG → IPC 落盘」的单帧版本，本任务是其批量化。
- 未确定项：导出分辨率档位、帧率（默认 30fps，随场景设置）、是否需要导出进度 UI 与取消能力（长动画帧数多，原则上需要）、PNG 序列中转目录的清理策略。

## 实施方案

（范围确认后细化）渲染层新增导出流程：锁定交互 → 离屏或固定尺寸渲染目标按帧步进（seek → 渲染 → 读帧）→ 分批经 IPC 把帧数据写入主进程临时目录；主进程新增导出服务：收帧、ffmpeg 编码（H.264 MP4）、成功后落盘媒体目录返回 `henji-media://` 引用、清理临时帧。导出过程提供进度条与取消。前后端职责分工：渲染归渲染进程（WebGL 依赖 DOM），编码/文件系统归主进程，符合项目约束。
