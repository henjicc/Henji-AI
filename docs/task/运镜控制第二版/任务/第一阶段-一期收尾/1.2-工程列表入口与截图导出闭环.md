## 任务目标

工具箱点开「运镜控制」后先看到工程列表页（新建/打开/重命名/删除），进入编辑器后可一键把当前机位取景画面导出为本地 PNG，导出的图片能在生成链路（对话或画布的图片输入位置）正常被选中使用，落地「摆场景 → 截图 → 喂给 AI 生成」完整闭环。

## 当前情况

- `src/workspaces/ToolboxWorkspace.tsx` 已是多工具卡片首页，点「运镜控制」卡片**直接进入** `CameraStageEditor`，中间没有工程列表页。
- 1.1 完成后已具备工程 list/get/upsert/rename/delete 命令桥。
- 截图未实现。三维视口是 `src/features/cameraStage/scene/StageScene.tsx` 里的 R3F `<Canvas>`；默认 WebGL 上下文未开 `preserveDrawingBuffer`，直接 `toDataURL` 会拿到空帧——需要在截图时主动渲染一帧再读，或开启 `gl={{ preserveDrawingBuffer: true }}`（执行时实测选择，注意后者的性能代价评估）。
- 图片落盘机制：`electron/main/services/ai-runtime/media-store.ts` + `henji-media://` 协议；媒体是否已上传的判断统一走 `src/utils/mediaPresence.ts` 共享函数（项目既有约束）。
- 机位视角渲染已可用（`viewMode === 'camera'` 时 `StageViewportCamera` 驱动真实 `PerspectiveCamera`）。

## 实施方案

在 `ToolboxWorkspace` 与 `CameraStageEditor` 之间插入一层「运镜控制工程列表页」：卡片式工程列表（名称、更新时间、对象数）+ 新建按钮 + 每项的重命名/删除操作，复用 `Ui*` 与项目现有列表/卡片样式。截图功能：编辑器内提供「截图导出」按钮（当前阶段放在视口浮层或顶栏，2.2 工具栏落地后迁移落位），点击时按当前机位视角渲染一帧、读出 PNG 数据，经 IPC 走 media-store 落盘，成功后给出可跳转/可复制的反馈提示。

## 执行步骤

1. 新建工程列表页组件（`src/features/cameraStage/projects/` 目录下，或等价位置），接 1.1 的命令桥实现列表/新建/重命名/删除。
2. 修改 `ToolboxWorkspace` 的 `renderTool('cameraStage')`：先渲染工程列表页，选中/新建工程后进入 `CameraStageEditor`（携带工程 id），编辑器内提供返回列表入口。
3. 实现截图管线：渲染层取当前机位一帧 PNG（实测 `preserveDrawingBuffer` 与"按需渲染后立即读帧"两种方式，择优）；若当前处于导演视角，截图仍按当前激活机位取景（无机位时禁用按钮并提示）。
4. 新增/复用 IPC 把 PNG 字节流交给 media-store 落盘，返回 `henji-media://` 引用。
5. 验证导出的图片能在生成 Tab 或画布节点的图片上传/参考图位置正常被选中使用，跑通完整闭环。
6. 视觉走查 + `npm run check:colors` + 原生控件检查无新增命中；把鼠标操作验证步骤清单交给用户。
