# 运镜控制第二版 · 任务总览

## 任务目标

一期（`docs/task/运镜控制第一版`）已经做出可交互的三维场景编辑器核心（对象增删改、角色姿态、多机位相机与双视角渲染），但一期规划中的持久化与产品闭环（原 3.1/3.2）尚未开始，且当前编辑器 UI 还是固定三栏的基础形态，缺少专业三维软件该有的工作区体验。本任务把一期未完成部分全部承接过来，并完成两块主体工作：

1. **工作区 UI 重构**：参照 C4D / Blender 的多面板工作区设计（用户已给参考图），把编辑器改造为「顶部工具栏 + 基础对象快速添加栏 + 中央主预览视口 + 右侧资源管理器 / 属性管理 + 底部时间轴」的可停靠布局——每个面板可拖拽重排、自由调整大小、折叠/展开，布局可记忆。
2. **时间轴与关键帧动画**：给场景对象的各个属性（位置/旋转/缩放/颜色/FOV/关节姿态等）加 AE 式关键帧能力（属性行码表打点 + 底部时间轴轨道），支持播放预览、关键帧编辑和速度（缓动）曲线，补上参考产品「只能出静态图」的短板。

属于本次任务：场景工程持久化（承接一期 3.1）、工程列表入口与截图导出闭环（承接一期 3.2 剩余部分）、可停靠面板布局框架、工具栏/快速添加栏/视口交互细节完善、撤销重做系统、关键帧数据模型与插值引擎、时间轴面板、速度曲线编辑器。

不属于本次任务：用户自定义模型导入（一期重要记录 007 已列为独立后续任务）、通用 IK 求解器、多人协作、云端同步、移动端适配。动画视频导出（逐帧渲染 + ffmpeg 编码）作为第四阶段列入本计划但**范围待确认**，见重要记录 004。
