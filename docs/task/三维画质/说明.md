# 三维画质：实时补全局光照，与路径追踪的耗时对照

2026-11-14，RTX 4090，场景与数字都由 `node scripts/bench-three-quality.cjs` 得出（源码直接打包宿主的统一三维渲染器 `VideoEditThreeSpace`，不经安装包，不碰资料目录）。

场景：白色墙角、红方块、蓝圆柱、金属扭结（`metal`）、实心玻璃球（`glass`）、三颗磨砂小球；一盏投影聚光（`light_softness` 0.6）+ 摄影棚中性环境光。4K（3840×2160）。

## 三张对比图

| 图 | 设置 | 每帧 |
|---|---|---|
| `1-实时-现状.jpg` | 现有缺省：环境光 + 聚光，不开遮蔽、反射、全局光照 | 约 15 ms |
| `2-实时-补完.jpg` | 全局光照 1 + 环境光遮蔽 0.6 + 屏幕反射 0.4 | 约 21 ms |
| `3-路径追踪-256采样降噪.jpg` | 成片“路径追踪”，默认 256 采样 + OIDN 降噪 | 约 64 秒 |

`对比-三张并排.jpg` 是三张缩小并排。另附 `4-路径追踪-16采样降噪.jpg`、`4-路径追踪-64采样降噪.jpg`。

观感：现状的背光面和墙面偏暗、发闷，物体之间没有光的往来；补完后墙面被地面和物体反弹照亮，红方块在墙上有红色色溢，整体通透很多，和路径追踪的明暗关系接近（与 256 采样图的 PSNR 从 19.7 dB 升到 23.3 dB）。剩下的差距：金属扭结在路径追踪里反射了明亮的墙面、地面，实时只反射得到屏幕里看得见的部分，仍偏暗；玻璃球的折射与彩色焦散只有路径追踪有。软阴影实时反而比路径追踪柔（路径追踪把聚光当点光源）。

## 实时帧率（4K，每帧墙钟时间，含 CPU 与等待 GPU 完成）

| 设置 | 平均 | P95 |
|---|---|---|
| 现状 | 14.5–15 ms | 17 ms |
| 只开环境光遮蔽 0.7 | 15.3 ms | 17 ms |
| 只开全局光照 1 | 17.5–18.6 ms | 19–25 ms |
| 全局光照 + 遮蔽 + 反射 | 20.7 ms | 26 ms |
| 同上，1080P | 10.4 ms | 12 ms |

全局光照本身已是半分辨率求值（4 个方向 × 12 步，固定噪声，保边降噪）；降到 0.35 分辨率实测几乎不省时间（时间主要在全分辨率的场景通道与降噪），2 个方向 × 8 步只省约 0.6 ms 却能看到颗粒，所以默认取 4×12、半分辨率。4K 开全三项约 48 帧/秒，达不到 60：看片时用节目监视器的回放分辨率 1/2（1080P 下约 96 帧/秒），导出不受影响。

## 路径追踪（4K，一帧从头追踪到目标采样数，含 OIDN 降噪）

| 采样 | 耗时 | 与 256 采样的差（PSNR） | 观感 |
|---|---|---|---|
| 16 | 6.1 s | 35.4 dB | 漫反射面已干净；玻璃里有色斑、焦散发花 |
| 32 | 9.9 s | 38.9 dB | 玻璃色斑明显减少 |
| 64 | 17.4 s | 42.5 dB | 肉眼与 256 很难分 |
| 256（默认） | 63.5 s | — | — |

大致每采样 0.24 秒 + 每帧约 2 秒固定开销（降噪等）。第一帧另有约 9 秒建加速结构与降噪网络。10 秒 60 帧的 4K 片子：64 采样约 3 小时，256 采样约 10.6 小时。建议成片先用 32–64 采样。

## 做法

- 新增序列三维设置 `space_global_illumination`（0–1，缺省 0 不开）：three 自带的 `SSGINode`（可见性位掩码 GI），反弹光 × 物体漫反射色（扣掉金属度）叠到三维物体上，在遮蔽之前；卡片画面不受影响。
- 成片要逐帧确定：不用 three 示例里的时间累积（TRAA），改为固定噪声、半分辨率、three 的 `DenoiseNode` 保边降噪（它的噪声图原本用 Math.random 生成，换成固定种子）。反弹源亮度截到 1，避免强高光被少数采样打中成亮点。
- 节点每帧把反弹光纹理清成白色，半分辨率双线性取到物体轮廓时会混进白边：改为清成透明黑（物体浮在空白处的情形已实测无亮边）。反弹光按场景通道覆盖率叠加，物体边缘不偏亮。
- 已知限制：反弹光不看材质是否受光（`MeshBasicMaterial` 一类也会被提亮，环境光遮蔽原本也如此）；紧挨强金属高光的磨砂面背光处有轻微颗粒。
- 设备需要 `rg11b10ufloat-renderable` 特性（合成设备现在申请它）；不支持的显卡上全局光照按不开处理。
- 环境光遮蔽（GTAO）、屏幕反射（SSR）、软阴影（`light_softness`）、环境光预设此前已有，实测质量够用，这次没改，只写进技能文档的“实时精致档”。
- 剪辑内容格式 78→79、录制会话 82→83，只新增可选字段，最低可读版本不变。

## 发现的原有问题

- 同一个路径追踪器里先降噪、之后改成不降噪（降噪失败后也会走到这里），输出节点仍绑着按降噪纹理编译的管线，换成原始浮点纹理时报“sample types (UnfilterableFloat) … (Float)”，这一帧失败。基准里先跑降噪再跑不降噪时复现；正常使用只有降噪中途失败才会碰到。未修。
