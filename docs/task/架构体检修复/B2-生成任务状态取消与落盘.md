## 设计自查

1. 助手只凭名称和说明能否用对？能。继续使用现有任务查询、取消、续取和实体读入口，cancelled 是正式状态，不新增同义工具或自定义协议。
2. 能否 AI 先做、人只确认？能。完整性验证、临时文件清理、状态同步和原结果保存恢复由服务执行；取消不要求用户逐个清理，恢复不重新提交付费生成。
3. 产物能否直接流进其他工作区？能。沿用受管本地媒体、原生成结果和画布结果引用；此次没有新增媒体形态或搬运入口。

覆盖分级为现有长任务取消/恢复语义修复；公开状态契约本来已有 cancelled，现有通用实体和语义入口足够，无新增能力、权限或外部参数。普通缺陷修复未修改 assistant-status 台账。

技术选型：直接复用仓库唯一 `fs/atomic-file.ts`，并使用 Node 的 AbortSignal、timers/promises 和 React 18 的 useSyncExternalStore。不引入新的原子文件库或状态库，避免复制已有独占发布、Windows 替换和订阅机制。没有产品数量上限或新依赖。
