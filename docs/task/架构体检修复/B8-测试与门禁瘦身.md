### 续做时修正的不一致

1. 成本 Sequencer 原来无条件改变本地 unit 排序，现在显式 opt-in；Reporter 同样按输出配置启用，非 unit 模式即使带这些变量也不启用。
2. related 解析原来只要求整个集合非空，现在每个待解析源文件都要有匹配，避免其他文件的覆盖掩盖零覆盖；统一 Windows 路径后匹配依赖。
3. 上轮依赖基线删到了 361 条，但漏记已有 `videoEditPauseMap.ts:11 → audioEditProjectInstances.ts`。先实际失败复现，再确认该边存在于基线提交和当前 main，仅登记这一条历史边及原因。当前 main 已只读复核通过。
4. 补齐本任务记录、配置跨模式隔离夹具及性能工作流触发断言。
