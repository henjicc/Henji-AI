## 实现

在独占 `core/imaging/regions/selectionAlgorithms` 中实现跨瓦片魔棒、线性工作色域颜色范围、修改 Laplacian 能量焦点启发式与选区形态学。继续使用 03 的 RegionSnapshot/RegionSource 和原图片命令总线，不新增文档、区域基础表示或历史。计算安排在 Worker，宿主负责资源装载、坐标和事务。

- 连通魔棒跨瓦片扫描行扩展，以行段入队，避免每个邻接像素一个对象；透明像素忽略隐藏 RGB，alpha 仍参与匹配。全局模式扫描全部源块。
- 色彩范围支持多点采样与线性工作色域容差，连续 float32 软覆盖不量化成字节；透明像素不加入色彩范围，HDR RGB 不裁剪。
- 扩展/收缩采用方形结构元素的可分离最大/最小值，平滑用 box mean，边界为扩展减收缩；以 halo 保证块边一致，画外覆盖为零，不声称 PS 圆盘结构元素等价。
- 焦点为 modified-Laplacian 的局部能量，范围与去噪控制阈值；分块三个扫描阶段求最大值、p99 直方图与连续输出。均匀图片得到空覆盖，清晰纹理先选出，人可继续修正；不包含参考项目 guided filter 和分量清理，不承诺语义主体或毛发精细分割。
- `tools/selectionAdvanced` 承载独立 Worker 消息端口、生命周期及原图层读取适配；重计算与反预乘在 Worker。任意 ROI 从原正式栅格加载器按 512 块拼装，不开新 IPC 或存储。
- 图片服务预览不修改作品或选区，资源 pin/release 复用原链路；原文档/选区变动、退出及显式取消会终止 Worker，异步回传后再检查基线。提交委托既有 bus.setSelection，编码端口必须由共享所有者提供无损适配，没有 GRAY8 fallback。
- 现有 SelectionService 仅追加服务出口；没有改默认工具、面板、持久 schema、版本、翻译或能力登记。命名存储仍由已实现的 channels 面板与 document.namedRegions 提供，不写第二套存储 UI。

真实规模：4K/8K 栅格，512 像素存储瓦片，源 RGBA 缓存按 32MiB 预算淘汰；输出保留稀疏 float32，连通访问记录用稀疏位图。无图层、像素或选区数量产品上限。焦点使用分块 halo 和有限直方图估计全局能量 p99，不分配全幅 RGBA 或全幅排序数组。尚无真实性能通过结论。

选型：首先阅读固定 PhotoCraft ec350d64 的 `crates/algo/src/selection.rs` 和 `segment/focus.rs`。采用其跨行连通、逐通道最大色距、modified-Laplacian 及局部能量思想，适配现有 float32 与注入取样端口；不引入完整 Rust Surface/egui/wgpu。原生 Rust/WASM 包需要新构建及内存复制链路，此任务禁止新增依赖，现有 TypeScript Worker 与区域内核可直接适配。颜色容差以线性工作色域单位表达，不冒充原参考的 sRGB 字节容差；焦点不称为主体分割，不承诺 guided-filter/语义边缘效果等价。已读取 `LICENSE-MIT`，在算法公共入口保留完整 MIT 版权、许可与免责文本；本次不引入素材或模型。没有运行参考 Rust 二进制做像素对照，不能将适配称为效果等价证明。

## 对外接口

- 公共入口 `src/core/imaging/regions/selectionAlgorithms/index.ts`，纯 core 相对导入，不依赖 features、DOM、React、Electron 或 Store。
- `SelectionPixelSource.read(ROI, RegionEvaluationContext)` 返回直通线性工作色域 RGBA float32；图层宿主从原预乘线性像素反预乘，不裁 HDR 色值。
- `solveSelection` 接收 wand/color-range/focus 意图，返回原 RegionSnapshot；`modifySelection` 接收 CoverageSource、expand/contract/smooth/border 与源像素半径。公开业务参数将短边比例换算到源像素，UI/助手共用服务。
- 上下文沿用 sourceVersion、源时间、referenceGrid、quality、signal；完成读回后再次检查取消。Worker 的取消通过终止实例隔离迟到返回，图片写回再核对文档及选区版本。
- 图片正式公共出口在原 `application/imageEditSelectionServiceV3.ts`：`previewAdvancedImageEditSelectionV3(bus, layerId, operation, options)` 返回 `{ snapshot, sourceToDocument, documentRevision, selectionRevision, selection }`，不是已提交结果。`operation.kind=solve` 的取样点是图层存储像素坐标；未来 UI/算法入口需用当前输出→原图→图层逆矩阵转换。`modify` 使用短边比例 radiusRatio，对当前整个选区求值。
- `commitAdvancedImageEditSelectionV3(bus, preview, encode)` 在基线仍一致时调用共享所有者注入的无损编码器，再走原 bus.setSelection；调用方应将默认替换、加、减、交的语义交给正式 shared adapter，当前并未假装这些高级工具组合入口已接好。
