## 对外接口

公共入口：`src/core/imaging/regions/index.ts`，只有纯 core 相对导入，不依赖 features、Store、DOM 或 Electron。

- `Coverage`：整数像素 ROI + `Float32Array`，线性 0..1 覆盖。
- `RegionProgram` / `RegionIntent`：相对参考网格的矩形、椭圆、套索、区域笔迹、压缩输入 matte，replace/add/subtract/intersect 与 paint/erase 分开保留业务语义。
- `RegionSource.read(roi, context)`：注入静态/逐帧/跟踪覆盖；`defaultValue` 是常量或时间求值端口。`readRegionSource` 检查 ROI、浮点范围和取消，包括异步返回后的取消。
- `RegionSnapshot` / `createRegionSnapshot` / `createSnapshotRegionSource`：稀疏 float32 瓦片、defaultValue、inverted；深拷贝缓冲和 Map，缺块遵循 defaultValue，画外恒零。
- `RegionFeatherPort`：support + apply，由宿主注入现有共享模糊实现；图片继续 fastBlur，不反向导入图片核心。完整 EvaluationContext 归 06，此处只冻结区域所需时间/网格/取消端口。
- `RegionEditTarget`：像素目标与指定 maskId 的蒙版目标显式区分。
- 图片图层适配：`F/regionAdapters/index.ts` 导出 `imageEditLayerMaskRegionSource(mask, grid, loadTile)`，只装载 ROI 相交的权威 mip0 资源，拷贝资源引用表以隔离后续文档修改；不创建第二仓库。
- 参数宿主：`src/features/maskEditor/index.ts` 保留 `exportMaskDocumentToPng` 同步契约，增加 `exportMaskDocumentToPngAsync(document, signal)`，同一覆盖核及编码函数。公共确认结果、参数持久文档字段均未变；DerivedMediaParamControl 无需改动。

## 剪辑接入说明

V0：现有剪辑固定遮罩几何转 RegionProgram，原片段文档和撤销栈仍归剪辑，不能搬入图片图层树。V1：参考帧覆盖转 RegionSnapshot，绑定 sourceVersion 与参考帧身份。V2：跟踪 provider 按源时间返回覆盖或明确失败，不回退上一帧；传播/光流/遮挡尚未实现。

`RegionEvaluationContext.time` 区分 static 和 frame，后者保存整数 ticks、有理 timeBase 与 frameId。剪辑适配先通过正式剪辑时间映射（sourceInUs/sourceRemainder、调速/反向/裁切）得到源时间，再无损表达为 ticks/timeBase；不重新定义时间单位，不从当前播放头读取。ROI、sourceVersion、时间、跟踪版本与质量需加入宿主缓存键。取帧/资源由既有注入端口负责，内核不 fetch/readback；切帧与取消后拒绝迟到结果。

## 成熟方案选型与规模

复用仓内已经验证的稀疏 float32、4×4 几何 AA、fastBlur halo/mip 和 mask hardness 分层。已读取本机固定 PhotoCraft `crates/algo/src/selection.rs` 与 Compositor `Compositor/Document/BrushStroke.swift`：前者文件头声明 f32 覆盖算法，资料中 GRAY8 指部分导入表示，不能笼统声称全部使用 8bit；本次不搬入其文档/导入表示。参考后者块/事务组织，不引入 Rust/egui/wgpu 或 Swift/Metal 宿主栈。本任务抽取已有算法，不新增依赖，不自研魔棒/形态学/dab；算法扩展归 08/09。平滑路径控制点仍由既有 core `tracePenPath` 生成，适配器按四分之一源像素误差展平到区域笔迹，不重新定义路径。Canvas/Konva 只呈现求值结果。

典型为 4K/8K 源图、视口缩略预览；权威计算按块，CPU 重像素仍应由既有 Worker 端口承担。预览预算跟随视口尺寸，导出逐块写 Canvas，历史用增量和会话卸载；不宣称本轮证明 200MP 编码或实时设备笔延迟。
