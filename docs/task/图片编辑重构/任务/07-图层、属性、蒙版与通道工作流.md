## 实现与选型

- 复用仓内 React Virtuoso、useReorderDrag、DockviewHost、ParamList/ParamField 和 V3 命令总线，不新增依赖或排序器。
- 对照 Compositor 的像素/蒙版附件与 PhotoCraft 的图层共同属性和分组面板，不移植其 Swift/Rust 文档与原生 UI；区域保存复用已有共享区域语义与选区 schema，不另写覆盖算法。
- 业务真相归原图片文档与命令历史，编辑焦点归会话。命名区域是可持久读回的选区快照，加载仍写同一选区历史。
- 规模验证使用密集图层树、通道虚拟列表；不设置层数、通道数和组深度上限。树索引是文档变更时的轻量视图投影，不触发像素计算；保存继续走原保存 owner。
- 验证级别 L2：图层公共命令、持久命名区域、属性与会话契约改变；精确测试覆盖原子撤销、锁组、选择目标、保存读回，Electron 场景覆盖真实拖动和面板布局。

## 对外接口

### 核心命令及通用属性

- `ImageEditDocumentV3.namedRegions: ImageEditNamedRegionV3[]` 是必填有序列表，条目 `{ id, name, selection }` 保存既有 `ImageEditSelectionSessionV3`，名称去首尾空格、不能为空，ID 不能重复；写入校验和克隆，避免调用方继续修改历史快照。
- `document.set-named-regions` 替换完整命名区域列表；逆命令、历史编解码、分页历史投影和作品保存都覆盖此字段。保存、改名、替换选区和删除通道进入作品撤销，加载进入既有独立选区撤销，二者保持同一个时间顺序。
- `layer.move-many` 接收 `{ layerId, parentId, index }[]`，index 为所有移动完成后的文档自下而上位置；整批移除再插入，整体验证剪贴基底与父组锁定，拒绝重复位置、组与后代一起移动、循环和无效索引。失败不发布，一次提交、一次撤销。现有单层命令继续复用原共同模型。
- `image_edit.document.named_regions` 通过通用实体读写上述列表；加载时把条目的 selection 写入已有 `image_edit.selection.region`，随后可调用已有选区应用能力。`image_edit.document.layer_order` 读取完整位置列表，写入部分最终位置；采用 execution 核验，在执行器读回每项父组与索引，不能拿部分请求与完整列表直接比较。无新增专用助手工具或权限。
- 会话 `editTarget: 'pixels' | 'mask'` 与 `selectImageEditTargetV3` 是 UI 焦点适配，蒙版目标切换到已有唯一 `mask-edit` 工具。通过通用属性删除蒙版后回到像素目标；焦点不落盘，不另建编辑文档。属性面板蒙版变换适配原 `ImageEditorLayerTransformPropertiesV3`，写同一 maskAttachment，共用预览、取消和历史。
- `resolveImageEditLayerMovesV3` 只把现有 useReorderDrag 命中转换为上述最终位置；选中组时剔除已选后代，保持剪贴链文档顺序。拖放结束保护选择，防止浏览器随后的 click 使多选丢失。跨组成功展开目标组；失败在原面板显示简短可行动原因。
- `ImageEditThumbnailsV3` 从原历史缩略图服务提取，历史与图层复用正式合成 Worker、资源描述和会话预算；不同消费者的合并键隔离，串行生成，有界派生缓存，关闭释放。64 项是缩略图缓存淘汰策略，不限制图层/通道/历史数量；空栅格层直接显示类型图标。

## 剪辑接入说明

命名区域保存的是选区意图，结构与共享 `RegionProgram` 的 operations / feather / inverted 相同，几何为原图参考网格的比例坐标；它不是像素瓦片 `RegionSnapshot`。

剪辑 V1 从图片文档通用属性读取某个命名区域，交给 `createProgramRegionSource(context => region.selection)`，效果蒙版适配器用 `RegionSource.read(ROI, RegionEvaluationContext)` 消费线性 Float32 覆盖。上下文已包含 sourceVersion、referenceGrid、quality、signal 和 `time: { kind: 'static' } | { kind: 'frame', ticks, timeBase, frameId }`；图片使用 static，剪辑宿主负责裁切、变速、倒放后的源 ticks 与参考网格映射。羽化通过现有 RegionFeatherPort 接入，不能重复实现栅格算法。

剪辑 V2 按上下文帧时刻解析跟踪/传播结果，复用同一个 `RegionSource`；缺帧必须报不可用，不静默返回上一帧。缓存身份包含源版本及时间，调度、取消和事务进入剪辑原 owner 与撤销栈。跨 feature 通过正式公共实体/适配边界，纯 core 不导入图片 feature；图片图层树不迁到剪辑轨道树。此次交付时间预留与接入契约，不声称剪辑时序入口已实现。
