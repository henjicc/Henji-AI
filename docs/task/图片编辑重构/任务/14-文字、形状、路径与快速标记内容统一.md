## 实现

本次按用户“当前没有并行任务、必要共享文件直接修改”的说明闭环接线。原任务拆分中的 18 单点抽取职责一并在本任务完成；没有留下未接入的接口请求。初始已有的 packages/ai-sdk 全部改动、src/core/documents/kinds/index.ts、src/core/documents/kinds/videoEdit.test.ts 及 vitest.exp.config.ts 均不纳入本任务文件。SDK 只由正式 electron:bundle 构建步骤消费，没有手工修改其源码；00、01、02 未改。

- 中立 core/imaging/vectorContent 提供 TextStyle、RichTextContent、VectorPathContent、字体字符串/字素推进宽度、富文本行布局、路径解释及覆盖。core 不依赖 feature，使用相对路径。services/vectorContent 是浏览器原生字形绘制/字体装载/外观合成的唯一适配层；不往主进程放像素计算。
- 文字保留段落与字形 runs、字体名称、段间距、方向、文本框、填充/多描边/多阴影。整体/片段可通用写入。字号与内容数组没有套用剪辑单纹理的 8192 空间上限；既有剪辑单纹理和代码执行配额只留各自宿主契约。
- 路径支持 move/line/quadratic/cubic/close、nonzero/evenodd，以及 replace/add/subtract/intersect 顺序组合。区域软覆盖与矢量蒙版直接复用 regions 抗锯齿、布尔和形态学核。路径锚点/控制柄可在属性面板编辑；蒙版保留路径 operands，继续允许稀疏笔刷覆盖，不物化成失去可编辑性的像素快照。
- 字体目录、FontKit 2.0.4 元数据解析、PAL、FontFace 装载复用既有实现。文档只保存字体家族/完整字形名称，不嵌入字体字节/文件路径；缺失字体保留文字/样式，明确提示导入或替换，准备可见内容/导出时拒绝静默替换。隐藏缺字体层不阻止其他可见内容出图。64MiB 是既有字体缓存预算，不是字体数量上限。
- 快速标记箭头、矩形、椭圆、自由路径、文字、序号和说明框确认后成为正式图层；说明框一次原子提交形状与文字，统一撤销。MarkItem 只用于瞬态手势草稿，不落盘。删除旧 annotation 文档、CRUD、渲染和独立 image_mark 应用能力域；mosaic 不再作为旧标记类型，现有马赛克效果保持正式效果链。
- 统一 TypographyPanel 供图片、剪辑标题/字幕、代码素材消费；宿主包装只提供位置、预设或有限代码字段。画布/工具箱/查看器快速编辑均消费 V3 文档和保存 owner。IME 草稿确认/取消、锁定、过期手势与失败不产生错误提交。
- CPU Worker预览、GPU内容纹理与CPU/GPU导出均调用同一 rasterizeVectorContent；矢量蒙版GPU原生图尚不支持，明确走已有CPU区域回退。边缘 halo 保留描边/阴影，16M工作像素预算是原生 Canvas临时纹理内存约束，不限制作品大小或内容数量；超限给出可恢复错误。
- 图像文档版本9，image-package8、image-working-copy10、canvas-layer-package8。旧 annotation 输入直接拒绝，不迁移、不隐藏运行兼容。官方样本生成器增加当前版本的JSON/容器黄金样本；历史黄金样本保留，开发期基线显式登记三种格式破坏性更新。

- src/core/imageEdit/v3/layerEntries/vector.ts：正式text/shape/path factory、类型与解析；vectorDraft.ts 把临时草稿转换为正式图层。共同 layer.replace/layer.add/document.atomic 及历史机制直接承载内容，不另建命令协议。
- ImageEditSparseMaskReferenceV3.vectorPaths：可编辑 operands 的可选基底，稀疏像素tile可覆盖。attachImageEditVectorMaskV3 沿已有仿射/蒙版附件契约，把含祖先变换的源路径变到目标蒙版空间，支持不链接蒙版。
- Application Control：image_edit.layer.content 为 nullable JSON，实际type决定richText/path封闭schema；图层集合创建提供text/shape/path及content。image_edit.mask.vector_paths 为 nullable operands JSON。描述、读写、权限、资源保存和撤销均通过原 change_application_entities，不新增Agent工具。content为null仅表达无内容图层读取值，正式文字/路径写入必须是相应合法对象；mask.vector_paths=null清除路径基底，保留稀疏笔刷。
- TypographyPanel 是 components/typography 的领域组合面板，controls均复用Ui组件；有限 fields 枚举与footer/transform宿主槽位，不复制字体/描边/阴影控制。双端henji-ui-surface复用表同步登记。
