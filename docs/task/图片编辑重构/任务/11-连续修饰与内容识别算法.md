2026-10-10。实现、指定静态/精确验证、完整图片目录与正式截图验收已完成；画质和未验证范围见下文。main 工作区；总管理者负责审查及 Git。本任务没有 add/commit/push/stash/reset/checkout，不启动开发实例、不付费、不手工编辑 SDK，不编辑 00/01/02。已有 SDK packs/index、documents kinds/index.ts、videoEdit.test.ts、vitest.exp.config.ts 改动保留；正式构建按既有流程调用 SDK catalog 生成器，index 在任务开始时已脏且未另存逐字基线，不能声称生成器完全没写它；管理者需按 SDK 任务独立审查，不将 SDK 或这些既有文件混入本任务。

## 实现

复用 I/paint dab、C/brush 稀疏会话、唯一 raster brush overlay slot、原 Worker/选区覆盖/资源/命令总线。图章和修复仅替换 dab 的像素运算，没有第二套手势、文档或历史。来源固定在笔前 loader，当前笔划不会反馈到供体；对齐跨笔保持偏移，不对齐每笔回到取样点。线性预乘 float32 不截断 HDR/负值；修复保持原 alpha，以 Poisson 融合供体纹理和目标边界。原选区内的全部损坏像素排除于已知边界；halo 包含跨块 dab 的完整求解域。

内容识别扩展原 ImageEditRepairServiceV3、像素 Worker、本地推理与资源事务。相干纹理搜索排除整个原选区，强周期背景优先保持规则行列相位，用选区外稀疏背景网格和边环共同判定，避免宽矩形/亚像素软边只靠边环错误匹配隔行砖缝；互补供体覆盖内部，难区域继续传播/确定性随机搜索。不能按覆盖收益强取低置信错相供体。auto 仅在周期背景及强拟合时接受纹理，否则复用 MI-GAN/LaMa；texture 不下载或调用模型。区域来源修补继续原同域入口，没有新的推理/下载/IPC/日志通道。

预览使用原 transient brush override，临时资源字节元数据进入原 GPU 合成描述；确认才写作品一次 delta。取消、选区/文档变化和关闭会拒绝迟到结果、清预览、释放租约。保存沿原 owner 屏障，预览不是保存成功。

截图目视发现供体悬浮、GPU 和画笔读取竞争：在原 commands 唯一读瓦片入口增加可取消 FIFO 背压，与主进程两个读取槽/内存预算匹配。排队取消不调用原生，已发请求结束才归还槽位；队列不设产品数量上限。共享调用方：像素/蒙版绘画、供体、GPU 上传、图层拾取、预览与导出，全部使用该入口；相关目录与命令精确测试验证，不另建读取系统。

### 成熟方案与规模

参考固定 PhotoCraft 快照 SHA ec350d64aedd019afc5eda290cc32909bc9bab7d 的 retouch/inpaint/poisson：复用笔前来源、累计覆盖、一次合成，采纳 best_offset/PatchMatch 对应与传播；将成熟多重网格/SOR Poisson 求解适配为 TypeScript Float32 Worker。局部均值融合实图有明显残色，已舍弃并保留失败图；Poisson 的皮肤/头发误差有明确改善，但复杂头发仍失败。没有引入 Rust/WASM 文档或合成栈，没有新增依赖。

PhotoCraft 为 MIT OR Apache-2.0，此次派生代码选择 MIT；poisson.ts 用 @license 保留完整版权和 MIT 通知，分发需保留。没有引入品牌或参考素材；没有独立专利法律检索，分发前走项目许可评估。比较 OpenCV Telea/NS 小瑕疵、神经修补的语义优势，规则纹理先用相干供体保留高频；参考官方 [OpenCV inpainting](https://docs.opencv.org/4.x/df/d3d/tutorial_py_inpainting.html)，PatchMatch 论文官网返回 403，具体实现依据固定源码和实测。

不限制图片/笔划/图层/作品数量。CPU 运算在原 Worker，修饰按原尺寸稀疏瓦片与 halo；源缓存 64 MiB、覆盖缓存 16 MiB 可逐出重新读，是字节预算。纹理原像素分析缓冲按 32 MiB 切换分析尺度；超预算只由代理找位移，再以 512 块原尺寸供体回填，排除整个原选区，不放大低清代理充当产物。阶段进度/取消沿原服务。4K/8K 同一跨块修复测试均读 8 块且 float 输出一致；8K×512 服务测试走 texture-donor 分块，14 个补丁、无模型调用、一次撤销。

## 剪辑接入说明

V1 参考帧：剪辑适配器注入不可变帧像素/区域与供体，EvaluationContext 传稳定 target、sourceVersion、有理源时间、referenceGrid/ROI、工作颜色与 quality，调用同一 retouch 核。宿主先求值时间/变换/跟踪；Worker 只传可序列化求值字段，AbortSignal 留宿主，由 I/O 取消和终止 Worker 传递。结果写剪辑所属命令/撤销栈，不从剪辑导入图片 feature 内部。

V2 去物体：原解码/本地推理任务链提供邻帧像素、光流/跟踪供体，遮挡失跟返回缺口；缓存身份包含源时间/版本、供体/跟踪版本、seed、ROI、颜色和质量。逐帧流式完成后原子提交所属命令。单帧核已留时间契约；闪烁、漂移、边缘和纹理稳定须另做时序实图验收，逐帧 LaMa/PatchMatch 不是视频去物体已完成。本任务不改剪辑 feature。
