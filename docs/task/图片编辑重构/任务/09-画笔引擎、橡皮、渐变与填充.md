# t119-09 画笔引擎、橡皮、渐变与填充

2026-10-10；实现与自动验收完成，专业设备/大尺寸延迟仍待人测；main 工作区；总管理者审查与 Git 提交。本任务不执行 Git 写操作，不改 SDK，不启动开发实例，不触发付费模型。

## 实现

- 把原图片画笔像素计算移到 `src/core/imaging/paint`：有种子的确定性 dab、弧长间距、逐样本平滑、尾点补齐、压力曲线、独立 pressureSize/pressureFlow、圆/扁平笔尖、角度/倾角、程序纹理/散布。鼠标默认压力为 1；随机数只依赖种子和 dab 序号，纹理只依赖工作网格坐标。
- flow 在单笔独立覆盖缓冲中累积，opacity 在笔前不可变像素上合成一次，选区覆盖只乘一次。RGBA 全程工作线性预乘 float32；橡皮按相同比例擦除 RGB 与 alpha，不丢失 HDR/负值。mask 使用相同覆盖核混合到指定值。无纹理且 hardness=1 保留原硬边定义，软笔提供过渡边缘；不把硬边定义变化伪装成 GPU 几何问题。
- 原 `C/brush` 留下瓦片装载/契约校验/稀疏会话/历史适配，删除旧分段光栅实现。原 pointer 合并、PreviewOverride、tile delta、历史和资源保存继续使用唯一入口；一笔只提交一条命令。不同事件分批与尾点测试比较实际瓦片字节。
- 图片绘画与渐变/填充通过独占 Worker 计算。Worker 只做计算，宿主拥有资源/取消/命令；失败保留具体原因，取消终止 Worker。每个请求克隆一个瓦片的 before/output/coverage；返回 output/coverage 走 transferable。尚未宣称 4K/8K 输入延迟合格。
- 纯色、线性/径向、多色标渐变在工作线性空间插值，透明色标按预乘插值。UI 提供双色起终点；助手可传多色标。按 512 瓦片读取选区、计算、保存，仅保留资源元数据，完成后原子提交一条 delta；可取消，有进度，失败/目标或选区过期不提交作品。
- 目标、颜色、覆盖值、大小/整笔透明度/流量放工具参数条；笔尖/压力细节在复用 PanelTrigger 中，提供共享核实际笔尖预览。旧 brush/eraser/mask 面板及登记移到 paint 唯一入口。没有新增控件实现、依赖、日志文件、IPC 或第二份像素历史。
- 参数蒙版的 brush/eraser 预览与正式输出收口到同一 dab/覆盖核；矩形/椭圆/套索继续使用已有 regions 几何算法。保留参数编辑的确认/取消与 marks 文档契约，不把标注矢量路径改成像素笔划。

## 选型依据

读取 t118 本地参考快照 PhotoCraft `crates/paint/src/{brush,dynamics,render}.rs`（固定参考版本见 01 证据）及仓内现有稀疏提交。采用其有种子 dab、间距、逐笔覆盖与流量/透明度分离思路，保留痕迹AI float32/资源/历史，并以实际像素测试验证。PhotoCraft 的 Rust/WASM 运行时和 GRAY8 权威存储不适合直接替换现有线性色彩及资源协议，跨 WASM 复制也不能无证据声称更快；本次使用小型 TS 算法核 + 原生 Worker，不引入新包。参考仓库按 MIT / Apache-2.0 双许可提供，保留其参考路径；本次没有嵌入 Rust/WASM 包或资源。与现有 brush/region 基础设施对照，避免新增第二份提交栈。Compositor 整笔覆盖仅作交叉参考，没有复制另一个图像文档/历史系统。程序纹理为有种子的噪声覆盖，不冒充导入任意纹理图章或自然介质仿真。

## 对外接口

- `@/core/imaging/paint`：`PaintPoint/Brush/Dab/Target/Surface/Replay`、`PaintDabGenerator.append/finish`、`rasterizePaintDabs`、`replayPaint`、`rasterizePaintFill/samplePaintGradient`。纯 core 只相对依赖 imaging/evaluation，没有 features/store/文件/IPC。
- `PaintSurface` 是目标工作网格中的区域，origin 是绝对网格坐标，before 不可变、output 可写、coverage 为当前笔划累积，clip 为可选 float32 覆盖；RGBA 为工作线性预乘色、mask 为覆盖。相同种子与输入序列跨瓦片、跨事件批次一致。
- `ImageEditBrushStrokeOptionsV3.loadCoverage/rasterize` 是宿主计算边界；未注入时用纯核，图片正式宿主注入 Worker 和已有 SelectionRasterClient。
- paint 内部服务 `fillImageEditTargetV3` 与 `paintImageEditTargetV3` 使用显式 bus/layer/destination；不依赖页面焦点。跨 feature 的调用须由 imageEdit/application 公共能力或中立 core 进入，不能导入这些内部文件。
- 新算法能力 `paint_image_edit_target`（算法级覆盖）：显式图层 ref + pixels/mask + stroke/solid/linear/radial。位置和 sizeRatio 使用目标内容比例，maskValue=覆盖；属性继续通用实体读写。Pi 与 MCP 共用同一注册、校验、执行和权限；保存沿原 owner 屏障，返回目标 ref、changed 和资源/历史核实结果，支持取消/撤销。没有手写 MCP schema 或写值工具。
- 无持久化 schema、版本、媒体资源格式改变。brush preset 是 18 的共享普通数据/动作接线；本任务公开完整 brush 意图和默认数据，不另建 preset store 或专用增删工具。00/01/02 按用户要求不改。

## 剪辑接入说明

V1 静态绘画可调用 `replayPaint`，由剪辑宿主传 `EvaluationContext`（目标、sourceVersion、参考网格、ROI、线性色彩、static/frame 源时刻、质量和取消信号），先解析关键帧/跟踪坐标与 brush，再生成同一 dab 序列并在各 ROI 上求值。`evaluationCacheIdentity` 校验并提供完整缓存身份；不得使用 viewport 或当前全局播放头做结果身份。参数蒙版已是多宿主实例；画布复用 V3 图片宿主自动获得同一内核。

V2 生效区间、跟踪绘画由剪辑宿主解析有理源时间及跟踪矩阵：只在生效区间 replay；笔划样本可按源时间截取后传入同一核。时间元数据归剪辑文档，I/paint 不依赖剪辑，不伪造本次已完成逐帧/跟踪入口。本次未修改 videoEdit；不存在跨 feature 内部导入新增。接口所需修改已在本任务完成，无悬置接口请求。

- 填充为整个目标/当前选区的区域填充，不是基于颜色连通的油漆桶；界面文案明确“区域填充”。渐变拖动显示方向范围，像素在抬笔后由 Worker 原子完成，没有逐帧渐变像素预览。
- Worker 每次瓦片克隆保留主线程预览，单笔触及的瓦片由原稀疏会话留存，尚未加入冷瓦片外存；不设置素材/笔划/层数上限，性能结论仅限本次证据。
- GPU 目录未改；原 GPU 对照测试会覆盖实际生成瓦片。本次不改变其采样/导出实现。
- 公共实体通路本已可写，本次增加算法入口，不改变实体/属性通断或 KNOWN_* 欠账；不重写 assistant-status 的能力数字快照。真实 Pi 模型决策及实际外部 MCP 客户端调用尚未验收。

## 设计自查

1. **助手只凭名称和说明能否用对？** 能。输入明确目标、像素/蒙版、内容比例空间、opacity/flow 分工、选区限制和颜色语义；正式算法与人走同一资源/命令/保存链，不需知道内部瓦片布局。
2. **能否 AI 先做、人只确认？** 能。助手可提交明确轨迹、填充或渐变并读回 ref/核实结果，人从同一历史撤销或继续校正；需要高质量自然笔手感的自由绘画仍由设备与人选择，未冒称自动理解笔意。
3. **产物能否直接流进其他工作区？** 能。写入原 V3 图层/蒙版资源和历史，沿现有图片导出、画布文档节点与参数蒙版确认流转，不创建独立文件或第二份作品；剪辑逐帧入口为后续宿主接线。
