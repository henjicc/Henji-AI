# t119-01 工具注册、输入路由与状态机

状态：实现交审，**未达到任务完成标准**。共享契约、登记和捕获路由已实现；旧工具的全局键盘监听收口及正式 Electron 截图尚未完成。不得将本记录当作全部现有工具已统一输入、已完成视觉验收或剪辑已接线的证明。

## 实现

- 新增 `src/core/imaging/interaction/`：宿主无关的坐标、压感、倾角、合并样本、源时间和手势契约，以及单指针租约状态机。纯 core 不导入 React、DOM、Store 或 features，内部只用相对路径。
- 生命周期为 idle → armed → preview → committing → idle。同步完成立即释放；异步完成核对租约，取消后的迟到结果不能清掉新手势。切帧/源版本改变取消当前手势。取消先清租约，避免释放捕获引起 lostcapture 重入。
- 登记 24 个当前工具，统一意图、宿主、图标、分组、光标、快捷键、选项和 overlay slot。重复工具、快捷键及互不相同的同名 slot 整体拒绝，Space/KeyZ/Escape 保留给临时导航和取消。登记异常进入现有日志，界面呈现恢复文案，空登记器拒绝编辑输入。
- 拆出无界面组件依赖的工具 manifest；宿主 profile 仅消费此投影，完整登记条目装配现有 Options/overlay。这样避免 profile → UI → controller → profile 的新静态值环。实现条目与 manifest 的工具 id 集合必须相等，清单失败也传播到正式失败入口。
- Rail、Options 和 Preview 消费登记器，删除其中央图标表、分组表、参数分派和 overlay JSX 分支。现有参数组件、命令总线、像素/选区/标注算法仍用原实现；没有复制领域算法。
- `useToolInputRouter` 在工作面捕获阶段批准对应 overlay 或导航/移动端口，阻止第二指针、非所属 slot 和取消后 pointerup。临时导航取消草稿，释放后恢复当前工具；事件发生时解析 Dockview 宿主范围，避免脱离 DOM 挂载时缓存错误根节点。
- 文字输入、IME、可见菜单/外部弹窗、修饰键及重复键不触发工具激活。文档层文字键保护在原生输入框处理后阻断旧 window 快捷键。
- 导航/移动复用原 Hook 的计算端口。导航禁止旧 overlay 同时接收 pointer/mouse/touch；移动松手前只在坐标改变时送末尾点；标注适配器补末尾点。裁剪取消调用现有 preview 清理并重挂裁剪 overlay，解除其旧 mouse 手势残留。
- 坐标按工作面本地点及现有 viewport 变换映射到输出 reference grid，不再在每个移动样本读取内容元素布局。保留 coalesced samples、末尾样本和指针属性。
- 未增加依赖、产品数量上限、持久化格式、付费生成、专用助手工具或第二份历史栈。

### 选型依据

采用仓内 React、Ui 控件、领域服务与已有导航/移动 Hook；参考本地 PhotoCraft `ToolEvent` 的样本分派及 Compositor `DocumentHistory` 的 begin/end/no-op 事务思想。两者的 Swift/egui 实现、中央 enum/switch 与当前 TypeScript 模块登记目标不匹配，不直接移植，也不为指针捕获引入第二个编辑器框架。纯状态机只协调租约，不实现图像算法；当前文件范围内最小适配继续使用现有撤销与渲染服务。

## 对外接口

1. 中立内核公共入口：`src/core/imaging/interaction/index.ts`。`InteractionPointerInput` 包含 phase、最终 sample、按顺序的 samples、time；sample 的 point 由宿主映射到 reference grid，client 保留原事件位置。`InteractionGesture` 提供 begin/preview/commit/cancel。commit 可以同步或异步，接收最终样本；宿主负责判断 no-op 并且不派发文档命令。
2. `InteractionTime`：静态图为 `{ kind: 'static', sourceVersion }`；时间采样为 `{ kind: 'sample', sourceVersion, ticks, ticksPerSecond }`。sourceVersion 区分输入源或文档版本；ticks/timebase 由宿主提供，不使用图片专有 timeline。
3. `ToolDefinition`、`ToolContext`、`ToolOptionsProps`、`ToolOverlaySlot` 位于 `F/toolFramework/types.ts`。Context 暴露现有 controller/bus、time 和 referenceGrid；Options 只消费现有 controller/bus。Overlay 按 slot 去重，可声明 activeOnly/requiresLayout/resetOnCancel/onCancel。
4. 新工具只新增一个 `F/tools/<工具>/` 目录和一个 `F/toolEntries/<工具>.ts[x]` 登记条目：目录内 `manifest.ts` 导出 `toolManifest`，通过声明合并扩展 `ImageEditorToolCatalog`；条目导出 `tools`，从同一 manifest 装配 Options/overlay/createGesture。两处 eager glob 自动收集，不改中央 union、Rail、参数组件或 Preview。legacy 使用显式 import，使现有静态死代码门禁能识别真实入口。
5. `ToolRegistry` 提供 get/list/shortcut/overlays。`toolManifestRegistration` 是 profile 的无组件投影；`builtInToolRegistration` 提供完整 registry/failed，`imageEditorToolRegistry` 是完整实例。
6. `useToolInputRouter(surfaceRef, controller, activeTool, bus, coordinates?)` 返回 effectiveTool、temporaryHandActive、overlayResetVersions、connect 和捕获 handlers。coordinates 的 toReference 接收**工作面本地点**，不得再次当作 client 坐标减工作面原点。connect 接收 navigation/move 的 down/move/up/cancel 端口。02 只复用 `ImageEditorToolParametersV3` 选项 slot，不修改本任务中央文件。
7. 宿主工具列表由 manifest 按 profile 过滤，原 effects/layerKinds/save 权限保持原契约。清单失败时保留 move 会话占位，完整登记器为空；占位用于让失败界面能建立会话，不意味着允许编辑。

## 剪辑接入说明

- V0：18 从 `core/imaging/interaction` 公共入口接入图片、剪辑和蒙版宿主，不引用 `features/imageEdit/v3/toolFramework` 内部。图片 ToolDefinition 的 React/文档适配留在图片 feature；共享的是样本与生命周期语义。
- 剪辑宿主把屏幕位置经现有 viewport/clip transform 映射到该片段 reference grid；使用源样本时间的整数 ticks 与 ticksPerSecond，并带片段输入源版本。不能把播放头显示时间无转换地冒充源时间。
- begin 获取片段目标与当前时间；preview 走剪辑原有 transient 通道；commit 仅在实际变化时向剪辑自己的撤销栈提交一条命令；cancel 释放草稿、捕获及任务资源。不得另外建图片历史来承载剪辑操作。
- 播放头/源版本/目标切换时调用 cancel('target-change')；内核在 preview/commit 还会核对源时间。异步算法需要宿主取消端口，并在写回前核对租约/源版本；内核忽略迟到完成不等于能阻止算法自行写回。
- 本任务未修改剪辑、画布或 maskEditor 文件，也未宣称这些宿主已完成接线；V1 静态/参考帧入口和 V2 跟踪传播仍属于原方案后续排期。

## 设计自查

1. **助手只凭名称和说明能否用对？** 每项登记提供具体意图与宿主范围，复用现有文档操作和业务服务，不把 pointer/内部 revision 当产品参数。工具面板重构属于现有能力展示适配，不新增专用 MCP 动作；18 需要在最终能力汇总中核对现有可调用操作与实体读写覆盖，本任务不宣称助手自动获得新接口。
2. **能否 AI 先做、人只确认？** 主体选区、修饰继续调用已有算法服务，人只校正/确认；框架不复制算法。取消/preview/commit 契约可让算法任务先提供草稿后一次提交，但具体自动化算法不是本任务新实现。
3. **产物能否直接流进其他工作区？** 仍写同一个图片文档/现有素材与保存链路，没有新增导出格式或孤立产物。共享 interaction 核预留时间维度，剪辑可接自己的文档和撤销栈；跨宿主调用由公共入口或宿主注入完成，当前未接线的部分明确列为待集成。
