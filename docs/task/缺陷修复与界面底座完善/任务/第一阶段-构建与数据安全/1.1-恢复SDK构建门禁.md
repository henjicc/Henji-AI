# 1.1 恢复SDK构建门禁

## 任务状态

- 状态：已完成
- 所属阶段：第一阶段-构建与数据安全
- 前置任务：无
- 关联任务：无
- 是否可以并行：可以，与其他任务无文件冲突

## 任务目标

让 `npm run check:sdk` 重新通过，从而恢复 `npm run electron:build` 与安装包构建；并让模型数量门禁不再写死数字，以后增删模型不会再把构建打断。

## 当前情况

- 2026-10-13 在本仓库跑静态门禁：lint、两套 tsc、`check:colors/surface/icons/ui-residue/model-i18n/skill-sync/main-imports/ipc-contract/dependency-graph/dead-code/media-recycle/persistence-compat/shader-components/assistant-capabilities:structure` 全部通过，**只有 `check:sdk` 失败**：`✘ generation IIFE 门禁失败：catalog 数量不是 124：123`。
- 原因：提交 `cf55836`/`495fc7e` 删除了 KIE ElevenLabs Turbo 2.5，`packages/ai-sdk/src/catalog` 下实际只剩 123 个 `*.model.ts`，但两个门禁脚本仍写死 124：`packages/ai-sdk/scripts/check-generation-iife.cjs:92、98` 与 `packages/ai-sdk/scripts/check-modular-bundles.cjs:79、285-286`。
- `check:sdk` 串在 `package.json` 的 `electron:build` 里，所以完整构建和 `electron:dist` 当前必然失败；CI 的 `build.yml` 是否执行 `check:sdk` 待确认（`grep check:sdk .github/workflows` 无结果，可能只经由 `electron:build` 间接执行）。
- `packages/ai-sdk/README.md:5、153、157、170` 写“111 个模型”，与目录 123 个不一致；111 是否指“不含 12 个 FAL 工具”的口径待确认。

## 实施方案

把期望数量改成从唯一来源派生：两个脚本都改为读取 `packages/ai-sdk/src/catalog` 生成的模型索引（`model-index.ts` 或 `npm run gen:catalog` 的产物）得到期望数，再与打包产物里的实际数量比较；保留“默认目录不得误入工具模型（tools.length === 0）”等结构性断言。若维护者坚持保留固定数字作为“意外增删”的提醒，则改为读取 `scripts/model-id-baseline.json` 这类登记文件，并在删除模型的提交里同步更新。

## 执行步骤

1. 读两个门禁脚本，确认它们分别从哪里拿到实际数量（IIFE 产物 `client.catalog.list()`、模块化产物的文件数）。
2. 确定期望数量的唯一来源（优先模型索引生成物），改写 `check-generation-iife.cjs` 第 92、98 行与 `check-modular-bundles.cjs` 第 79、285-286 行；输出文案里的数字也改为变量。
3. 核对 `packages/ai-sdk/README.md` 的模型数量口径；确认后改成与目录一致的说法，或改成不写死数字的描述。
4. 运行 `npm run build:sdk` 与 `npm run check:sdk`，确认四段检查全部通过。
5. 在 `00-任务总览.md` 记录结果，独立提交并推送（只是门禁脚本与文档，不涉及 SDK 发布）。

## 涉及内容

### 修改文件

- `packages/ai-sdk/scripts/check-generation-iife.cjs`：期望数量改为派生值
- `packages/ai-sdk/scripts/check-modular-bundles.cjs`：同上
- `packages/ai-sdk/README.md`：模型数量口径（待确认后修改）

## 风险与回退

只改检查脚本，不改 SDK 运行代码，不触发 SDK 发布（AGENTS.md 全局架构边界第 7 条）。改错时直接还原两个脚本即可。

## 验收标准

- [x] `npm run check:sdk` 退出码 0。
- [x] 在临时删除或新增一个 `*.model.ts` 的本地实验中，门禁不需要改数字也能给出正确结论（实验后还原）。
- [x] README 中的模型数量与目录一致，或已在重要记录说明口径。
- [x] `00-任务总览.md` 已同步，本任务有独立提交且已推送。
