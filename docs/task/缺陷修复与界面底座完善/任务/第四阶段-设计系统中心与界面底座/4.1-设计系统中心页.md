## 任务目标

把现有组件样张页扩展成“设计系统中心”：一处看全所有共享组件（含状态与尺寸阶梯）、全部设计令牌、常用界面模式和对应规范要点，可按主题预设切换，可搜索跳转，并能整页截图审计。以后排查任何“按钮大小、间距、颜色不对”的问题都先来这里对照。

## 当前情况

- 现有样张页：`src/features/devGallery/UiGalleryPage.tsx`（13 个分区，5 列手工分配，一屏放下）、`gallerySections.tsx`、`galleryLayout.tsx`、`forcedPseudoStates.ts`（强制悬停/聚焦，不含按下）。
- 入口只有开发导航参数 `--dev-surface=dev.ui_gallery`（`src/core/development/developmentLaunchContract.ts`）；正式界面、助手、MCP 都没有入口，这是规则要求（AGENTS.md：开发参数禁止出现在正式界面）。
- 覆盖门禁 `uiGalleryCoverage.test.ts` 只从 `src/components/ui/index.ts` 收集导出名，深路径导入的 `NumberInput`、`Tooltip`、`ProgressBar`、`PriceEstimate` 等不受检；只检查“出现过”，不检查尺寸与状态。
- 截图步骤 `scripts/ui-review/ui-gallery.json` 只截第一屏，960×640 下大部分分区不受检。
- 完全没有令牌样张：颜色、字号、行高、间距、圆角、阴影、层级、动效、图标尺寸都无法集中对照。

## 实施方案

页面结构改为“左侧目录 + 右侧滚动内容 + 顶部工具条”：

- **顶部工具条**：主题预设切换（石墨/深海/胶片/纸白，直接调用现有主题引擎，不改用户设置）、界面缩放、搜索框（按组件名、令牌名、规范关键词过滤并跳转）、“只看问题”开关（高亮未登记或违反门禁的样本）。
- **令牌**：颜色（表面层级阶梯、文字三档、强调、状态、媒体叠层，显示变量名与当前值）、排版（字号档 + 行高）、间距档、圆角、阴影、层级、控件高度、图标尺寸、动效时长与缓动（可点击重放）。数据直接读 `styleTokens.ts`、`tailwind.config.js` 映射与 `themeCssVars.ts`，不手抄。
- **组件**：每个共享组件一个卡片，固定展示“尺寸阶梯 × 状态矩阵（静息/悬停/按下/聚焦/选中/禁用/加载）”，并附一行“什么时候用 / 不要怎么用”，内容引用 skill `henji-ui-surface` 的复用表。
- **界面模式**：命令带 + 从属带、面板表单行（含成对网格）、记录列表、空/加载/错误、设置分区、浮层面板、弹窗各尺寸档，每个模式给一个正确示例与一个“禁止写法”反例（反例用明显标记，不进覆盖统计）。
- **规范速查**：三条铁律、五级容器、动作层级、选中态词汇表，直接链接到 skill 原文对应小节，不复制正文。

覆盖门禁升级：收集范围改为 `src/components/ui/**` 下所有导出组件（不只 `index.ts`），并要求每个带 `size` / `variant` 的组件在样张里出现全部枚举值；样张缺失时列出具体缺的枚举。截图步骤改为按目录分区逐段截图，确保整页受检。入口仍只走开发导航参数，并在开发者工具菜单或开发模式快捷键里提供打开方式（仅开发构建）。
