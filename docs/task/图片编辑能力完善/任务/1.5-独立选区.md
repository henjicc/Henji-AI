# ie3 / 1.5 独立选区

日期：2026-10-09。源码实现与局部检查完成，待总管理者审查。Git 操作由总管理者负责；本代理未暂存、提交、推送或切换分支。

## 完成边界

- full/canvas-edit：框选、椭圆、自由套索、多边形套索、画笔选区；新建/加/减/交；非累计羽化、反选和取消。选区工具收进同组菜单，参数仅随当前工具披露。
- 选区不等于图层蒙版。元数据存在文档实例的会话里，每次完成手势或参数修改占一项撤销，与作品命令按实际顺序撤销/重做；关闭后清理，不持久化选区。取消手势不提交。
- 有选区时新建调整/效果层自动附带独立蒙版；UI 与通用集合走同一服务。对现有层可替换作用蒙版；像素层可复制所选内容到新层或删除所选内容为透明。复制/删除保留原图资源与图层变换，乘上原蒙版覆盖率，使用非破坏稀疏 Float32 蒙版，一次作品命令提交，撤销/重做复用资源。
- 通用实体 `image_edit.selection.region` 使用闭合形状 schema；矩形/椭圆为未裁剪画面的比例坐标，套索/画笔为比例点集，半径/羽化按画面短边比例。单一字段定义派生反射、读取、写入和补偿。算法 `apply_image_edit_selection` 声明真实写入/创建影响、权限、稳定目标和回读证据。
- `exportCurrentImageEditSelectionV3` 是 1.7 的统一入口：异步生成器逐块返回同源尺寸的单通道 Uint8 遮罩（0 保留、255 选中），最终返回实际非零 ROI（left/top/width/height），空选区返回 null。1.7 应逐块编码灰度 PNG，再对接 ie2 的 maskAssets/ROI 作业协议；本任务不提交推理作业。
- 几何与羽化由独占 Worker 求值；按 512 区域处理/写入并显示进度，可取消，文档或选区变化后拒绝迟到结果。工作缓存最多八块是内存策略，不限制作品瓦片或笔迹数量。移除了旧共享几何入口 4096 tile / 8192 点拒绝；仍保留有限数值、安全整数与坐标精度的真实技术约束。

扩展/收缩按方案归属 2.1，本任务未实现。专用 mask 宿主仍沿既有“直接编辑蒙版”语义，不把它改成独立图片工作区。

## 成熟方案选型

比较了 [polygon-clipping](https://github.com/mfogel/polygon-clipping)（成熟的矢量多边形布尔运算）和 [Clipper2](https://github.com/AngusJohnson/Clipper2)（成熟的多边形裁切/偏移库）。本阶段最终消费的是抗锯齿 Float32 覆盖率，四种组合要保留软边，连续圆头画笔不能只当闭合多边形；引入矢量布尔依赖后仍须再栅格化，Clipper2 还引入绑定/数值域适配成本。

选择复用仓库已经验证的矩形面积覆盖、4×4 椭圆/套索覆盖核、四模式覆盖组合、共享 fast-blur（Kovesi box approximation / mip / halo）及现有指针捕获入口，未新增依赖，也未复制上传、持久化或颜色解码链。新增范围仅为独立会话表达、连续圆头线段覆盖和消费编排。输入延续 coalesced samples + RAF；几何草稿不需要等待像素画笔的异步瓦片队列，因此不把选区写进 raster brush working tiles。后续 2.1 若需要矢量偏移/拓扑输出，再采用成熟库，不能把本次覆盖率算子当矢量布尔算法宣称等价。

## 持久化与撤销决定

没有改变作品/历史/蒙版资源持久 schema 或版本：独立选区只在实例会话保存，应用后使用既有 sparse mask resource 和 layer.add/layer.set-mask 命令。原生历史继续只含作品命令；会话时间线交织选区历史，持久快照不会写入 selection。通用事务撤销按历史项身份核对，不能因后来手势的几何值相同而撤销新手势。新选区编辑会清除作品重做并沿原资源释放/GC 入口处理；只有这种历史变化需要保存，普通选区编辑不会让作品变脏。

蒙版替换、透明删除、复制都沿既有资源大小元数据和资源收集；已有稀疏蒙版、defaultValue/inverted 与单资源蒙版分别走正式共享读取/解码入口，没有吞掉旧蒙版或按 UI 层复制业务分支。

## 性能实测

AMD Ryzen 9 5900X，Node v24.18.0。正式 Worker 同一栅格函数、identity 图层变换、512 区域，预热一个瓦片后每组完整遍历三次；表中总时长取中位数，tile p95 取所有工作区域。套索 256 点，画笔 128 点，所选区域约占画面中部。未设作品尺寸产品上限，4096² 与 8192² 是本次测量样本。

| 尺寸 | 形状 | 无羽化总计 / tile p95（ms） | 短边 1% 羽化总计 / tile p95（ms） |
|---|---|---|---|
| 4096² | 矩形 | 121.64 / 3.37 | 553.58 / 13.38 |
| 4096² | 椭圆 | 142.96 / 3.82 | 561.90 / 11.52 |
| 4096² | 套索 | 297.79 / 10.51 | 605.90 / 12.91 |
| 4096² | 画笔 | 144.46 / 6.03 | 567.67 / 11.98 |
| 8192² | 矩形 | 528.97 / 3.08 | 1510.06 / 7.74 |
| 8192² | 椭圆 | 705.92 / 4.73 | 1523.43 / 7.94 |
| 8192² | 套索 | 1161.44 / 8.49 | 1708.89 / 9.35 |
| 8192² | 画笔 | 629.54 / 8.17 | 1423.62 / 7.08 |

大羽化沿全局对齐低频网格求值，避免 halo 随图片线性膨胀；已验证非整除尺寸下跨 512 边界与整体求值一致。以上仅 CPU 栅格数字，不包含 Worker 启动/传输、IPC、磁盘写入、GPU 合成或 event-to-present。主线程只更新当前草稿并在抬手提交一次；跟手呈现延迟没有真实窗口测量证据，不能声称 60fps。

## 设计自查

1. **助手只凭名称和说明能否用对？** 能沿 selection 的 describe/read/change 操作闭合几何、组合与羽化；应用能力描述三种任务语义、替换蒙版和保留可见范围的区别，并返回稳定图层。实际模型规划能力尚未测，不能用正式入口测试代替真实 Pi/MCP。
2. **能否 AI 先做、人只确认？** 助手可先写出或修改选区并应用同源服务，用户能查看主题遮罩、调羽化或撤销；有授权即可直接提交，没有新增确认闸门。语义主体候选/自动区域由 1.8 接入，不伪装成本阶段已经自动识别。
3. **产物能否直接流进其他工作区？** 应用结果留在原图片文档/图层与资源链，继续走已有保存、画布原位投影和图像交付；1.7 可直接消费同源遮罩/ROI。视频侧是否理解全部可编辑图层仍以原正式契约为准。
