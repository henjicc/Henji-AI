## 实现与选型

- **覆盖分级：能力增量。** `select_image_edit_region` 是求解区域的算法；选区静态读写继续走 `image_edit.selection.region`，不新增单值工具或协议专用工具。区域语义 `subject` / `portrait` / `point` / `box`，点框坐标均为未裁剪文档画面比例；点可标正负，选区支持替换/加/减/交、羽化、反选、读回和同一撤销栈。
- 通用对象采用已登记的 [EfficientTAM](https://github.com/yformer/EfficientTAM)：复用已下载、校验和会话池，只开 image encoder 与 mask decoder。与 MobileSAM 相比，仓库已有 EfficientTAM ONNX、DirectML/CPU、提示张量与三候选导出链路；引入另一套权重/依赖尚无质量收益证据。完整 SAM2 更重，静态图不需要视频记忆，故抽出静态基类，原跟踪行为不重写。现有下载项仍是五件完整模型包，不新增重复下载实现。
- 人像复用 [RVM](https://github.com/PeterL1n/RobustVideoMatting) 首帧真实抠像，快速档用 Selfie；无伪视频、无时间状态。RVM 不可用时日志说明后回退 Selfie；快速回退模型下载失败但 RVM 就绪时继续 RVM。保留软覆盖率；人像连通分量是区域候选，不做身份识别；软覆盖率低于16/255作为背景噪声抑制，不能承诺保留全部极细发丝。
- 一键通用主体在 3×3 粗网格上取候选，按遮罩 IoU 消重，返回所有保留下来的候选；8 项分页只是 UI 页尺寸，没有候选/素材数量上限。网格是一次推理的采样预算，不能保证覆盖图边小物体，也会返回物体局部及背景候选；可以继续点框，不静默替用户选一个候选。面积/置信值过滤属于模型分辨率噪声判断，不是产品数量限制。
- UI 与助手共用 `selectImageEditRegionV3`；当前像素层逐 512 瓦片读取，包含既有浮点补丁，不烘焙上方调整或蒙版。工作图长边 512 是模型训练/导出约束，**不是源图片尺寸上限**。选中遮罩以 RLE 会话形状映射回文档比例，原图资源及持久格式不变；并不把当前选区写进图片文档格式。
- 候选绑定文档/选区版本与图层；选择、变化、撤销后不可重用旧候选。取消、源变化、实例释放和切图拒绝迟到结果。复用原资源 pin/release、请求准入、原 utility 队列和统一日志，没有新日志文件、查看器或查询通道。正式能力沿原实例租约/保存屏障，必要的原画布写入权限仍校验。
- `remove_image_edit_region.region` 支持 `subject` / `portrait` 与未选择的 `candidateId`。唯一主体直接消费临时算法选区，最后仅提交一次稀疏补丁命令；歧义要求先读取候选再指定，已选择则用选区引用。当前独立选区不被中间识别步骤改写。指定来源修补仍只接受原选区/矩形，不扩大为会下载模型的语义入口。

## 1.7 画质路由

默认 `auto`：32×32 内小瑕疵沿既有经典修补；遮罩实际覆盖比例 ≥8% 或已知背景的周期纹理相关性 ≥0.6 时走精细 LaMa，其余快速 MI-GAN。显式 fast/fine 保留。周期分析取 64 格亮度边缘投影、自相关，在已有像素 Worker 执行；这是可解释启发式，不能保证识别所有规则纹理。

上下文从固定 64 像素改为 `max(64, 遮罩长边×0.5)` 并裁到源边界。模型 512 工作图的二值孔洞用已有 OpenCV 椭圆结构元外扩 3 格，清掉紧贴孔洞的污染颜色；若外扩会吃掉最后的已知背景则保留原网络遮罩。选型依据是已安装成熟 OpenCV/WASM 的 [形态学膨胀](https://docs.opencv.org/4.13.0/d9/d61/tutorial_py_morphological_ops.html)，不另写像素膨胀或新进程。最终仍用原覆盖率与 alpha 提交，外扩不扩大作品修改范围。

[LaMa 官方](https://github.com/advimman/lama) 的频域结构适合大区域，但此轮只改善上下文和污染边缘，未把大洞盲切成没有已知背景的小块。多尺度结构引导、完整分块细节恢复与进一步边缘融合列为剩余项。

## 固定砖墙画质数字与目视

使用 1.6/1.7 同一 `tests/fixtures/image-inpainting/brick-large-{source,mask,original}.png`，512×512，遮罩占 13.283%，规则纹理检测为真，自动选精细档。前后复用同一生产内核；before 关闭此次孔洞外扩并用旧 64 上下文，after 使用新上下文和外扩。选区 MAE/PSNR 与无物体原图比较；edge 是原遮罩内边界像素的 MAE；非选区/alpha 检查遍历全图。

| 版本/模型 | 选区 MAE ↓ | PSNR dB ↑ | 边界 MAE ↓ | 相对真值平均红偏差 | 原生耗时 ms |
|---|---:|---:|---:|---:|---:|
| before / MI-GAN | 32.48 | 15.05 | 17.55 | 0.59 | 815.7 |
| before / LaMa | 13.28 | 21.94 | 23.37 | 1.93 | 10914.2 |
| after / MI-GAN | 17.69 | 17.82 | 5.83 | 2.35 | 795.6 |
| after / LaMa | 8.73 | 25.70 | 5.23 | 3.20 | 1744.2 |

所有四组非选区修改数 **0**、alpha 修改数 **0**。LaMa 同模型 MAE 降约34.3%，边界误差降约77.6%；新自动默认相对旧默认 MI-GAN 的 MAE 降约73.1%。LaMa before 含冷会话、after 复用热会话，**不能把 10914→1744 当作算法提速**。红偏差未下降，它包含自然砖色偏移，不等于粉色轮廓残留量，不能声称无色偏。

已打开实际 PNG 目视：旧 MI-GAN 有污块/错乱砖纹；旧 LaMa 有粉色遮罩轮廓和局部模糊；after MI-GAN 仍有垂直暗痕和砖缝错位；after LaMa 的粉色轮廓明显减轻、纹理更连贯，但仍有砖缝轻微偏移和局部细节不足。EfficientTAM 点选选到衣服，框选选到头/衣服但发丝有孔洞；人像任务 RVM 的整体覆盖明显更合适，不能把通用二值模型当精细发丝抠像。
