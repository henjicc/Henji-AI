## 1. 产品方向与完成边界

图片编辑处理图片，剪辑处理视频；调整和效果使用同一通用底座。向 PS 对齐专业能力和编辑结果，界面仍沿痕迹AI的一条命令带、任务工具组、就地属性与助手协作设计。

首阶段交付用户可连续完成的闭环：打开图片/画布图片文档 → 添加共享调整层 → 主体/框选/画笔选区和羽化 → 移除或指定来源修补 → 回读/撤销 → 原位保存与跨工作区交付。模型按需下载；先有算法/实体操作再有 UI；不默认云端付费生成。

## 4. 设计自查

1. **助手只凭名称和说明能否用对？** 可以作为目标：参数用区域、采样来源、处理范围、羽化比例、曝光档、输出用途；实例级约束由describe给出。层/效果数值用通用实体，移除/分割等算法有闭合schema和结果证据；本轮尚未注册或运行这些拟定能力。
2. **能否 AI 先做、人只确认？** 自动校色、参考匹配、主体候选、移除先给可检查结果，人调整选区/强度/来源；全部可回读、可撤销。已有明确授权时助手可直接提交，确认按钮只是可选交互，不增加默认许可闸门。
3. **产物能否直接流进其他工作区？** 继续使用当前图片文档/图层/预览稳定引用、共享素材与正式导出服务；画布原位更新，剪辑可消费图像产物，无需手动搬文件。完整图层文档向其他工作区的“可编辑引用”能力以各消费方正式契约为准，不承诺视频侧直接理解全部图片层树。
