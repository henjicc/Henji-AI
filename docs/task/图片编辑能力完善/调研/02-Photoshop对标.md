# t97 Photoshop 核心能力对标

日期：2026-10-09。状态针对当前图片编辑用户流程：**已有**＝存在相应正式入口和实现；**部分**＝仅底座/特定宿主/简化语义；**缺失**＝本轮未找到等价实现。剪辑或云端有同类能力时单独注明，不计图片编辑已有。常用度为本项目的产品优先级判断，不是用户使用率调查。

## 1. 选区

| 能力 | 状态 | 常用度/价值 | 现状与建议 |
|---|---|---|---|
| 框选（含椭圆） | 部分 | 高：局部编辑入口 | mask 宿主已有，普通编辑器缺独立选区；第一阶段 |
| 套索 | 部分 | 高：精确手动区域 | 几何底座已有；开放独立 selection，复用采样 |
| 魔棒 | 缺失 | 中高：连通纯色区域 | 色差阈值、连通性、采样范围必须明确；第二阶段 |
| 快速选择 | 缺失 | 高：涂抹选择对象 | 现有画笔不是智能选择；分割点/刷提示迭代扩展 |
| 主体 | 部分 | 很高：抠图/局部调色 | 有人物分割和交互对象模型，尚未接图片；“自动主要主体”须显著性候选与消歧 |
| 天空 | 缺失 | 中高：风景调色 | 人物/任意对象模型不等于天空语义模型 |
| 色彩范围 | 缺失 | 中高：产品换色/肤色 | 剪辑 HSL key 可共享；需产出可用的独立选区 |
| 画笔选区 | 部分 | 很高：移除/修补前置 | 复用蒙版笔迹，但独立选择态、增减语义未齐 |
| 羽化 | 缺失 | 很高：自然边缘 | 使用画面比例/相对区域大小；保留未羽化原始 mask |
| 扩展/收缩 | 缺失 | 高：去边缘/修复边界 | 距离场或形态学，跨瓦片 halo 无接缝 |

PS 的组合与羽化语义参见 [Adobe 选区修改文档](https://helpx.adobe.com/photoshop/desktop/make-selections/refine-modify-selections/adjust-a-selection-manually.html)。

## 2. 调整

| 能力 | 状态 | 常用度/价值 | 现状与路线 |
|---|---|---|---|
| 亮度/对比度 | 部分 | 很高：基础修图 | 曝光底座；剪辑有对比度。曝光不等于完整亮度算法 |
| 色阶 | 缺失 | 高：黑白场/中间调 | 剪辑黑白与曲线不等于完整色阶 UI/参数契约 |
| 曲线 | 部分 | 很高：精确色调 | 图片 core 有；剪辑 master/RGB、色相曲线更完整 |
| 色相/饱和度 | 部分 | 很高：改色 | 图片 HSL 底座；普通宿主未开放 |
| 色彩平衡 | 部分 | 高：分区染色 | 温度/色调不是阴影/中间调/高光平衡；共享剪辑色轮后扩展 |
| 黑白 | 部分 | 中高：风格/印刷 | 降饱和可近似，不是多通道黑白混合器 |
| 可选颜色 | 缺失 | 中：精细商业修图 | 独立 CMYK/相对绝对语义；不以 HSL 冒充 |
| 渐变映射 | 缺失 | 中高：海报风格 | 稳定渐变资源和亮度映射，非纯渐变叠加 |
| LUT | 缺失 | 高：风格统一 | 剪辑 input/look .cube 可直接作为共享来源 |
| 阴影/高光 | 缺失 | 很高：宽容度修复 | 剪辑 basic 已有；第一阶段共享 |
| 自然饱和度 | 缺失 | 高：人物与风景 | 剪辑 vibrance 已有；第一阶段共享 |
| HSL 辅助/范围校正 | 部分 | 高：局部颜色 | 图片 HSL 不等于剪辑 key+羽化+清理+局部校正 |
| 自动校色/参考匹配 | 缺失 | 很高：AI 先给结果 | 剪辑统计分析已有；共享分析与参数建议，不声称深度模型 |

调整层与非破坏编辑概念参见 [Adobe 调整与填充层](https://helpx.adobe.com/photoshop/using/adjustment-fill-layers.html)、[非破坏编辑](https://helpx.adobe.com/photoshop/using/nondestructive-editing.html)。

## 3. 修复、变换与图层

| 分组 | 能力 | 状态 | 常用度/价值 | 设计边界 |
|---|---|---|---|---|
| 修复 | 污点修复 | 缺失 | 很高：灰尘/小瑕疵 | 短笔迹 ROI，模型与经典算法比较 |
| 修复 | 修复画笔 | 缺失 | 高：皮肤/纹理 | 采样纹理与目标照明融合；不是模糊画笔 |
| 修复 | 修补 | 缺失 | 高：指定来源保纹理 | 用户指定 donor 的修补与自动移除分开 |
| 修复 | 内容识别填充 | 缺失 | 高：较大移除区域 | LaMa 作为质量候选；不能承诺恢复真实遮挡内容 |
| 修复 | 移除工具 | 缺失 | 很高：照片清理 | 第一阶段 MI-GAN + 选区/遮罩 + 单次撤销 |
| 修复 | 仿制图章 | 缺失 | 高：确定性修复 | 源锚点/偏移/对齐、完整高精度像素路径 |
| 变换 | 自由变换 | 部分 | 很高：排版合成 | 仿射已有；完整句柄、约束与确认交互需补齐 |
| 变换 | 透视 | 缺失 | 中高：产品/建筑 | 单应变换、采样、逆坐标与导出一致 |
| 变换 | 变形 | 缺失 | 中：贴图/造型 | 网格、控制点，算法操作与可读参数 |
| 变换 | 液化 | 缺失 | 中：专业修图 | 位移场、画笔约束、面部语义；后续阶段 |
| 图层 | 蒙版 | 部分 | 很高：非破坏编辑 | 文档/GPU/brush 已有，普通宿主控制未开放 |
| 图层 | 调整图层 | 部分 | 很高：反复改色 | 类型/render 已有，第一阶段开放及统一调色 |
| 图层 | 混合模式 | 部分 | 高：合成 | 仅五种，且宿主开放不一致 |
| 图层 | 图层样式 | 缺失 | 中高：海报/标题 | 整图 glow 不等于描边、投影、内外发光样式 |
| 图层 | 智能对象 | 缺失 | 中高：模板/可重编辑 | resource 不等于可编辑嵌套文档；不冒充已支持 |

参见 [Adobe 修复工具](https://helpx.adobe.com/photoshop/using/retouching-repairing-images.html)、[变换](https://helpx.adobe.com/photoshop/using/transforming-objects.html)。本地学习式修复与 Adobe 云端生成填充应在产品文案中区分。

## 4. 滤镜、裁剪、文字与交付

| 能力 | 状态 | 常用度/价值 | 现状与建议 |
|---|---|---|---|
| 模糊 | 已有（种类部分） | 高：背景/质感 | fast/Gaussian；方向/径向/景深等未齐，优先共享视频 kernel |
| 锐化 | 缺失 | 很高：照片细节 | 视频已有锐化；共享 halo 与颜色语义后接入 |
| 降噪 | 缺失 | 高：夜景/手机照片 | HSL key 清理或 Gaussian blur 不等于图像保边降噪 |
| 杂色 | 缺失 | 中：风格/合成一致 | 固定 seed 的非破坏效果；不随机破坏导出一致性 |
| 镜头校正 | 缺失 | 中高：建筑/广角 | 畸变/暗角/色差与可选配置，第二/三阶段 |
| 基础裁剪/旋转 | 已有 | 很高：构图 | 复用现有几何与坐标转换 |
| 透视裁剪 | 缺失 | 中高：扫描/建筑 | 不是普通 crop 的别名 |
| 扩展画布 | 部分 | 高：排版留白 | geometry 有尺寸，缺正式操作；透明/纯色扩展先行，无云端填充默认 |
| 文字 | 部分 | 高：封面/标注 | annotation 文字已有；段落、字距、路径文字、字体交付未齐 |
| 栅格导出 | 已有（约束保留） | 很高：交付 | 九种格式、颜色/元数据检查；HDR 宿主和部分元数据另有缺口 |
| 可编辑文档/项目包 | 已有 | 高：持续协作 | 复用 V3 包与当前项目资源引用，不新建保存格式 |
| PSD 交换 | 缺失 | 中高：专业协作 | 后期单独调研成熟解析器；不能承诺无损往返所有 PS 语义 |

滤镜分类依据 [Adobe 滤镜参考](https://helpx.adobe.com/photoshop/using/filter-effects-reference.html)。取舍：保留专业编辑的选区、非破坏层与快捷操作；不复制 PS 的完整菜单、面板矩阵和历史包袱。首批用户价值集中于调色、主体选择、移除、修补，而非一次补齐全部矩阵。
