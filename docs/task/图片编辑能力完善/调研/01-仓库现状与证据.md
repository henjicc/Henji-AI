### 宿主开放情况是本轮最重要的区别

[imageEditorHostProfiles.ts](../../../../src/features/imageEdit/v3/application/imageEditorHostProfiles.ts) 是当前配置证据：

| 宿主 | 工具与控制 | 调整与 HDR |
|---|---|---|
| full | 移动/手形/缩放、裁剪、标注、栅格画笔/擦除；可创建 raster/effect | adjustments 为空、layerControls 为空；HDR disabled |
| canvas-edit | 与 full 类似；文档原位保存 | adjustments 为空、layerControls 为空；HDR disabled |
| quick | 导航、裁剪、标注、效果；开放混合模式；排除 glow | adjustments 为空；HDR disabled |
| mask | 矩形/椭圆/套索、画笔/擦除、蒙版编辑 | mask 控制；HDR limited；无调整 |

因此普通编辑器的调整层、图层蒙版、几何选区只能标“部分”。`histogram/color/history` 虽有 panel ID，但这些宿主没有开放，不能按字符串存在判已交付。

## 2. 图片效果、GPU Scene 与导出

[operationCatalog.ts](../../../../src/core/imageEdit/v3/operationCatalog.ts) 登记四个可创建效果：`image.fast-blur-v3`、`image.gaussian-blur-v2`、`image.diffusion`、`image.vgpu-glow`；四个调整：exposure、curves、temperature-tint、hsl。这里的 diffusion 是现有效果名称，不是本地修复模型，也不表示本轮引入扩散生成。

`src/features/imageEdit/v3/gpu/` 已有 retained GPU Scene、Worker/client/runtime、RenderGraph、资源注册、mip/halo、纹理与 pipeline/target 复用、序列门控和设备恢复。缓存节点输出为线性预乘 RGBA；源解码、曲线 LUT 与中间目标有各自精度契约。不能把剪辑的编码 sRGB shader 字符串直接贴入这些节点。

[renderScheduler.ts](../../../../src/core/imageEdit/v3/renderScheduler.ts) 已有预览合并、会话取消、优先级、缓存和资源 lease。[ImageEditorEffectParametersV3.tsx](../../../../src/features/imageEdit/v3/editor/ImageEditorEffectParametersV3.tsx) 已经 rAF 合并参数预览，抬手统一提交，取消清预览；它目前手写参数控件，尚未与视频 ParamList 共用。

呈现回退为 WebGPU Surface → GPU ImageBitmap → CPU/Canvas2D。导出用冻结的稳定快照，失败可整笔重启 CPU 路径，不能混拼两个后端的半成品。CPU 等价实现和导出支持是节点开放门槛。[export/capabilities.ts](../../../../src/features/imageEdit/v3/export/capabilities.ts) 负责颜色、几何和 codec 的可用性判定。

[平台契约](../../../../src/platform/contracts/imageEditorV3.ts) 登记九种栅格格式：BigTIFF、JPEG、WebP、PNG8/16、TIFF8/16、AVIF10/12。文档底座覆盖 sRGB/Display-P3/Rec.2020、sRGB/linear/PQ/HLG、整数与浮点精度、ICC/CICP；普通宿主 HDR 仍关闭，不能把底座支持写成用户已能完整编辑 HDR。AVIF 元数据与独立元素 PNG 导出仍有明确限制；不支持时拒绝，不静默降质。

## 3. imageMark、画布与项目生命周期

`src/features/imageMark/domain/types.ts` 复用 core/imageEdit 的标注类型；standalone 的 V3 host/actions/save/export 与文本编辑覆盖层可继续复用。图片编辑与标注不是两套文档、两套上传或两套输出服务。

历史依据：

- [GPU 渲染总览](../../图片编辑GPU渲染管线/00-任务总览.md)、[GPU 重要记录](../../图片编辑GPU渲染管线/重要记录.md)：已有 GPU Scene、CPU 对照、资源恢复、参数预览设施；固定 vgpu 0.3.1。
- [多图层节点总览](../../多图层图片文档节点/00-任务总览.md)、[节点重要记录](../../多图层图片文档节点/重要记录.md)：文档节点原位编辑、自动保存/关闭 flush、精确版本防迟到、资源引用感知回收、项目包携带文档；图层/组/标注独立导出有稳定引用。
- [智能图像工具总览](../../画布智能图像工具/00-任务总览.md)、[工具重要记录](../../画布智能图像工具/重要记录.md)：云端高清、重打光、元素编辑、多角度、图层分离等是另外的生成能力，不能当作本地移除/修补已实现。真实付费画质仍有历史待验证项。

旧节点记录中的“节点即项目边界”和旧格式迁移是当时结论；当前项目体系与开发期规则优先。本方案复用当前图片文档身份与宿主，不恢复旧项目概念或兼容分支。

本轮只规划，没有把任何“不通”改成“通”，也没有落实欠账增减或推翻已完成实现，故不改 [assistant-status.md](../../../rules/assistant-status.md)。后续实现若命中其第零节再更新。
