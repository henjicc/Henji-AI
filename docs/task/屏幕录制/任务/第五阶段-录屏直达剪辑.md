# 第五阶段：录屏直达剪辑

决策见 [重要记录 011](../重要记录.md)。每项都按用户原路径在真实应用验收并目视截图。

## 5.1

开录即倒计时与设置记忆：点开始立刻最小化并出现高亮框与 3；采集在倒计时内预热，结束时刻为原点；未就绪显示“准备中”而非 0。录制设置（模式、画质、帧率、声音与设备、摄像头、保存位置、上次来源）持久化，默认 60fps。

验收：点击到出现 3 的时间、首帧时间、重启后设置保留。

## 5.2

统一音画对齐：唯一对齐函数供回看、送入剪辑、成片、快速导出共用；屏幕起止改用首帧实际时间；各轨裁到共同结尾。

验收：剪辑时间线第 0 帧有画面、结尾不多出；闪白+出声测试偏差不超过 1 帧。

## 5.3

录完直达剪辑：完整模式停止后建剪辑项目或进指定项目并切到剪辑，屏幕片段挂光标日志并默认带光标效果、自动缩放、画框；快速模式存 MP4 后轻提示。删除录制工作台；隐私候选自动打码待人复核，标记转时间线标记，逐字稿/重配并入剪辑字幕与配音，GIF/图文并入导出，“生成成片”变为剪辑操作。

## 5.4

剪辑里的录屏片段：效果控件“录屏”分组（鼠标显示/样式/大小/平滑预设/点击效果/静止隐藏；缩放开关/重新生成/默认深度；画框背景/留白/圆角/阴影；画幅），常用项在前、高级收起。缩放轨：区间可拖动改长、6 档深度、自动段跟随光标、手动段固定焦点并可在预览拖焦点框、相邻段直接平移，按区间实时求值。录屏画框内置效果。缩放段与画框参数登记为通用属性。

## 5.5

快速模式视频再导入：读文件内嵌事件，识别为录屏片段（光标已烘焙，只提供缩放与点击效果）。

## 5.6

清理与兼容：删除工作台相关组件、文案与测试；旧录制会话打开即进剪辑；核查 4.23 落盘格式变更对旧会话的影响，必要时补迁移。
