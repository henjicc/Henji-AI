# 2.4 一键生成剪辑序列

## 任务状态

- 状态：待开始
- 所属阶段：第二阶段-AI成片
- 前置任务：2.1、2.2、2.3
- 关联任务：3.2、4.1–4.3

## 任务目标

从录制会话一键生成可以继续编辑的剪辑序列，包含原片轨、光标层、推近、剪停顿与等待段加速、字幕、章节与步骤标注、摄像头画中画、背景与画框，以及多画幅版本。

## 当前情况

- 剪辑已有字幕、标记、代码素材、变速、关键帧、智能区域、人像抠像（RVM/Selfie）、响度和对白闪避。

## 实施方案

1. 生成器：读取会话，产出一个新序列（或写入指定序列）。所有元素都是正式的剪辑元素（重要记录 006），整次生成是一个可撤销的事务。
2. 默认成片配方（生成前可以选，生成后可以改）：
   - 剪掉停顿和语气词；
   - 等待段加速 4–8 倍；
   - 推近跟随、光标层；
   - 字幕、步骤标注（代码素材做的标题条）、章节标记；
   - 摄像头画中画抠像（右下角，圆角或圆形，可关）；
   - 纯色或图片背景加圆角画框（扁平风格，不用渐变和投影）；
   - 响度标准化。
3. 多画幅：同时生成横版，以及可选的竖版、方版序列。
4. 工具箱会话页和剪辑入口都能触发；生成后打开剪辑。
5. 应用能力：生成成片（可选配方），返回序列的稳定引用，助手可以接着读回和修改。

## 验收标准

- 单测覆盖“配方 → 时间线元素”的映射和撤销。
- 构建产物中：录 1 分钟 → 生成成片 → 时间线元素齐全，播放和导出正常，撤销一步能回到生成前。
- 三句自查写入执行记录。
- 相关测试与门禁通过（按 `docs/rules/testing.md` 裁剪）；新增能力过能力门禁；界面改动过界面门禁；涉及 skill 或规则文档时同步更新。
- 执行记录写明改动文件、证据、计划差异和三句自查：助手能否只凭名称和说明用对？能否 AI 先做、人只确认？产物能否直接流进其他工作区？
