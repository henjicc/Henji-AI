# 3.2 多产物导出

## 任务状态

- 状态：待开始
- 所属阶段：第三阶段-隐私与多产物
- 前置任务：2.3、2.4
- 关联任务：无

## 任务目标

同一份录制会话导出多种产物：图文步骤文档、单步动图、缺陷报告，以及多画幅视频。

## 当前情况

- 已有剪辑导出、图片编辑和文档体系。

## 实施方案

1. 图文步骤文档：每一步取一张代表帧（推近后的画面，带光标和点击位置），配上步骤标题和说明。可以导出 Markdown/HTML 加图片，也可以生成多图层图片文档，进入图片编辑继续改。
2. 单步动图：每一步导出一段短 GIF 或 WebP 动图。
3. 缺陷报告：包含步骤、出错帧和应用日志片段（录痕迹AI 本身时自动关联同一时段的日志），导出为文本加图片。
4. 应用能力：导出指定种类的产物，结果可以读回。

## 验收标准

- 单测覆盖各产物的结构；在构建产物中对样例会话导出三种产物，文件都能打开，内容与步骤一致。
- 相关测试与门禁通过（按 `docs/rules/testing.md` 裁剪）；新增能力过能力门禁；界面改动过界面门禁；涉及 skill 或规则文档时同步更新。
- 执行记录写明改动文件、证据、计划差异和三句自查：助手能否只凭名称和说明用对？能否 AI 先做、人只确认？产物能否直接流进其他工作区？
