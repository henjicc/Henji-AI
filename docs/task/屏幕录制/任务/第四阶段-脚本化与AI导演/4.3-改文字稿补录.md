# 4.3 改文字稿补录

## 任务状态

- 状态：待验证
- 所属阶段：第四阶段-脚本化与AI导演
- 前置任务：2.3、2.4
- 关联任务：无

## 任务目标

在文字稿里改字，AI 用用户自己的音色重新配这一句，并对齐到画面；需要时联动 4.1 重录对应的操作段。

## 当前情况

- 已有文字稿剪辑、音色复刻和 TTS 生成链路。

## 实施方案

1. 编辑文字稿：选中句子修改后，生成这句的新配音（复刻音色或指定音色），替换旁白轨上的对应片段，前后做淡入淡出和响度匹配。
2. 时长变化时：画面段按需轻微变速或插入停留帧，保证旁白和操作对齐；可以选择联动 4.1 重录这一段。
3. 遵守现有的付费策略和额度规则；结果可撤销。
4. 应用能力：修改某一句旁白并重新配音。

## 验收标准

- 单测覆盖片段替换、对齐和撤销。
- 构建产物中用模拟 TTS 改一句旁白，时间线和导出结果都正确。
- 相关测试与门禁通过（按 `docs/rules/testing.md` 裁剪）；新增能力过能力门禁；界面改动过界面门禁；涉及 skill 或规则文档时同步更新。
- 执行记录写明改动文件、证据、计划差异和三句自查：助手能否只凭名称和说明用对？能否 AI 先做、人只确认？产物能否直接流进其他工作区？

## 执行记录

### 实施结论

- 成片把完整句子的旁白音频与文字稿/字幕绑定；普通录制和导演录制共用这条接线。面板选择成片、句子、文本与音色，能力只重配选中句子。
- 新音频实测长度后对齐：小幅延长（10% 内）调用既有有理变速；更长则用正式画面渲染获取末帧，插入停留片段并后移后续素材/字幕/标记。短句保留现有画面时长。新音频匹配旧句实测响度并加短淡入淡出。
- 替换在 detached 草稿中准备后单次提交、保存并读回；普通补录一次撤销恢复音频/字幕/画面。并发修改、锁轨、复杂动画/转场、交叠声音等明确拒绝；保存失败沿正式保存恢复，不重新付费。
- 可选操作重录复用 4.1，先产生一次画面修改再提交配音，能力返回 undoSteps=2，面板明确提示。没有另建重录/变速/导出实现。

### 计划差异与遗留

- 原始录制稿与媒体保留，补录文本更新在成片音频 clip.text 及对应字幕，方便回看原录制。UI 在会话的“改文字稿补录”区选择成片句子；不是原稿直接覆盖。
- 沿正式渲染器获取停留画面，沿现有 FFmpeg 测量/归一化响度；无新增第三方依赖、无额外许可项。
- 可选联动重录复用 4.1 两段提交，不包装为虚假的一次撤销；自动化本轮验证普通补录的一次撤销，联动重录完整链交总管理者追加验收。
- 总管理者验收：真实人声音质、已复刻音色及响度听感（合并 4.2 共用付费额度）、联动操作重录、复杂人手编辑后的阻断提示、长项目/macOS。模拟正弦音频只证明时长/响度计算和管线，不证明 TTS 质量。
- 同源排查范围：普通录制与导演录制的分句成片、变速帧舍入、字幕绑定、停留片段效果 ID、重复改同句、交叠与锁轨、一次历史撤销。未宣称任意重排/动态效果时间线均可自动补录。

### 三句自查

- 助手能否只凭名称和说明用对：能，明确选录制来源及音频片段、改一句、指定音色及是否重录，回执注明撤销次数。
- 能否 AI 先做、人只确认：能，生成、测长、淡化、响度与画面对齐自动完成，人校正文稿及听看结果。
- 产物能否直接流进其他工作区：能，音频和停留图进入原剪辑素材及序列，正式导出消费相同结果，可撤销。
