# 4.1 操作脚本与一键重录

## 任务状态

- 状态：待验证（实现与 Windows 本机闭环已完成；待总管理者集成、范围与设备验收）
- 所属阶段：第四阶段-脚本化与AI导演
- 前置任务：1.4、2.3、2.4
- 关联任务：4.2、4.3

## 任务目标

录痕迹AI 本身时，把能力调用日志变成可重放的操作脚本。某一步录坏了或界面改版后，助手按脚本在干净状态下重新执行并重录，自动替换时间线上对应的段落。

## 当前情况

- 1.4 记录的能力调用事件带稳定引用；内置助手和 MCP 走同一个能力目录。

## 实施方案

1. 脚本模型：一组步骤，每步包括能力调用、参数、等待条件和对应的旁白段落。脚本从会话自动生成，可以编辑。
2. 重放：在隔离的干净状态（临时工程或快照）里逐步执行。某步失败时停在该步并报告，不留下半成品。
3. 重录：重放的同时录制，生成新片段，按步骤边界替换序列里的旧片段。旁白保留并重新对齐，时长有变化时调整剪切点。
4. 应用能力：生成脚本、重放、重录某一步或全部步骤。

## 验收标准

- 单测覆盖脚本生成、重放失败处理、片段替换和撤销。
- 构建产物中：录一段应用内操作 → 生成脚本 → 重录第二步 → 时间线上对应段落被替换，其余不变。
- 相关测试与门禁通过（按 `docs/rules/testing.md` 裁剪）；新增能力过能力门禁；界面改动过界面门禁；涉及 skill 或规则文档时同步更新。
- 执行记录写明改动文件、证据、计划差异和三句自查：助手能否只凭名称和说明用对？能否 AI 先做、人只确认？产物能否直接流进其他工作区？

## 执行记录

### 实现与逐项结论

- 从 1.4 的能力事件取得调用身份、完成状态和步骤时间；原事件日志继续不保存输入/输出。新增受限脚本输入旁路：只捕获明确允许的剪辑属性，在首次操作前保存源文档快照，同一文档后续调用不覆盖起点。
- 操作脚本包含步骤、参数、能力完成后的停留时间、旁白段 ID、阻断原因；生成与编辑复用 `screen_recording.understanding.result` 通用事务及撤销，不增加专用字段写工具。
- 重放创建独立临时项目，复制快照、映射文档引用、定位序列与片段，逐步调用正式 `change_application_entities`；继承调用者授权，不生成额外授权。只预演到指定步也会先执行前置步骤。失败或取消立即停止；清理关闭临时文档、回收临时项目并恢复先前剪辑。
- 重录单步/全部步骤均使用正式采集链。新片段齐备且目标版本仍未变化后，在独立导入草稿中拆开步骤边界并替换画面，全部提交为一次剪辑撤销。旁白、字幕、其他序列和片段时间点保留；原片与新录制均保留。保存失败只提示重试保存，不建议再次重录。
- UI 增加脚本生成、步骤选择、标题/参数/停留时间校正、目标剪辑选择、预演与重录入口；Pi/MCP 与 UI 共用三项新能力。失败使用既有错误展示/根通知与日志系统。
- 持久化 `document.screen_recording` 升级 v4，新增不可变黄金样本并登记开发期断代；公共工具契约升级 2.13.0，登记新能力输出样本与指纹。

### 计划差异与选型

1. 1.4 的安全日志没有参数，不能把历史日志当成可完整执行的请求。本次新增严格白名单捕获，已录但缺少快照/参数的会话明确阻断；不猜参数、不补做付费调用。
2. 首批可重放范围为 `video_edit.clip` 的 x/y/scale/rotation/opacity 和 `video_edit.sequence` 的 name/width/height。其他写操作、付费操作、失败/取消调用一律阻断。只读与导航能力、录制控制不生成业务步骤。当前 UI 中绕过正式能力注册器的直接领域操作仍不能自动脚本化；本轮不冒充全应用操作覆盖，需总管理者确认后续扩展范围。
3. 为保持旁白和非目标段完全不动，新画面调速适配原步骤时段，不对整条序列做 ripple。超过正式剪辑变速范围则拒绝。锁轨、倒放、转场与已确认打码步骤拒绝自动替换；旧光标效果移除，避免旧事件映射到新画面。重录媒体及临时项目回收沿正式文档体系，不新建文件/日志/IPC 管理通道。
4. 调研 [rrweb 官方录制回放方案](https://github.com/rrweb-io/rrweb/blob/main/docs/recipes/record-and-replay.md) 与 [Playwright 官方 Electron 支持](https://playwright.dev/docs/api/class-electron)：rrweb 重建 DOM 不执行领域事务，也不能安全重放桌面剪辑；因此复用既有能力事务、文档快照、FFmpeg 采集与 Playwright Electron 验收。没有新增第三方依赖，无新增许可登记项。
5. 本任务按用户指示使用 `codex/rec-4.1` 独立 worktree，仅本地提交，交总管理者合并推送；不启动 electron:dev，不跑 test:reality / build / dist，不调用付费模型、不写真实用户资料目录、不改 local-inference 和模型清单。

- 产物能否直接流进其他工作区：能。替换进入正式剪辑文档并可一步撤销，新旧媒体沿素材与文档引用体系复用。
