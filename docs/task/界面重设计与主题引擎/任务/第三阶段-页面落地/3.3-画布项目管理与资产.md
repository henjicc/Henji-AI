**与设计稿/计划的偏差（技术取舍，记录在此）**

- **视图切换（网格/列表）未做**：列表视图需要另一套行布局，并要把视图偏好持久化（设置 store 迁移，属数据变更），超出“只改视觉与布局”；项目辨识主要靠封面，网格足够。如需要，建议另立任务。
- **缩略图不是“节点结构预览”**：项目摘要里没有节点几何数据，按设计稿画节点框需要改摘要/封面服务（数据与 IPC），仍用现有封面截图；没有封面时用设计稿同款点阵占位。
- **页面标题仍是“项目管理”、主按钮仍是“新建项目”**（设计稿“画布”“新建画布”）：巡检场景 `uiInspectionSceneCanvasConnections` 按 `/^(新建项目|New Project)$/` 定位，改名需要同步场景文件；文案统一可在 4.1/4.2 或主控协调后一次改。
- **封面圆角 8 而不是设计稿的 10**：令牌只有 6/8/12（重要记录 004），取输入与菜单档 8，与 3.2 生成记录图片网格一致，不新增圆角令牌。
