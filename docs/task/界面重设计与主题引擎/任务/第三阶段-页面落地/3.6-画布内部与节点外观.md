## 任务目标

画布内部用户评价“整体还行”，本任务只做令牌化与组件统一，不改交互：画布背景与网格、节点外壳、端口与连线、节点工具条与浮层改用语义令牌与 2.1/2.2 组件；画布音频节点用 2.3 波形；浅色预设下画布可用。改动画布节点前按 AGENTS.md 读 `docs/rules/canvas.md` 与 skill `canvas-node-builder`，遵守画布性能约束。

## 执行步骤

0. 先查 1.1 基线截图时 `canvas-image-capability-toolbar` 在 1440×900 下“等待空图片节点出现”12 秒超时的原因（改动前的既有失败，场景过时或真实缺陷），按根因修复后再开始迁移，避免把既有失败混入本任务的视觉回归。
1. 盘点画布内的颜色与控件（以 1.1 清单为准）；逐类迁移。
2. Reality：画布节点交互、拖动性能、缩放性能场景回归与截图（石墨、纸白）。

## 验收标准

- [ ] 画布内无写死界面色，浅色预设可用；节点与浮层使用统一组件。
- [ ] 画布性能场景不低于基线；截图目视通过；任务总览已同步。
