**工具页统一骨架（扩展现有组件，不新建平行实现）**

- `UiToolbar`（原有组件，无调用点）新增 `variant="command"`：44 高、`bg-panel` + 下边 `border-gap`、横向 10px。左端 children 放返回、文件上下文、主工具组；`center` 占两端之间的剩余宽度并居中，放视图切换、路径上下文、工具参数；`trailing` 放次要动作 + 唯一主动作；可选 `subordinate` 是从属带，与命令带共用底色和下边框，自己不带底色和边框；`barProps` 只放 `data-*` 状态。行与容器保留 `data-command-stack` / `data-command-bar`，所以图片编辑既有场景与测试的结构断言不变。
