## 任务目标

- 工具首页按设计稿 `设计稿/Toolbox.dc.html`：工具卡（图标、名称、说明、最近文件）+ 最近文件列表。
- **统一工具页骨架**（设计稿 `设计稿/ToolAudioEdit.dc.html`）：一条命令栏（返回、文件名菜单、保存状态、视图切换、查找/撤销/重做、次要动作、唯一主动作“导出”）+ 主工作区 + 右侧属性面板 + 底部时间/波形区；口播剪辑、图片编辑、3D 镜头参考三个工具共用骨架组件。
- 口播剪辑：逐字稿删改着色用令牌（删除、语气词、选中、停顿标记）；底部精细波形 + 放大条（2.3）；去掉常驻快捷键说明条，改为快捷键入口。
- 图片编辑、3D 镜头参考：命令栏与属性面板对齐骨架；参数面板用 2.2 组件。
