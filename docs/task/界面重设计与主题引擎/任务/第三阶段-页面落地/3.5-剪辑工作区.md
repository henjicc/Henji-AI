## 任务目标

按设计稿 `设计稿/VideoEdit.dc.html`：

- 一条命令栏（关闭工程、工程名菜单、规格、撤销/重做/布局、唯一主动作“导出”）；“拆分/删除/文字/面板/快捷键”等移入时间线工具栏、菜单或快捷键。
- 面板之间 1px 缝隙分隔，面板头为文字标签（选中下划线），面板菜单悬停显示。
- 项目面板：一行搜索 + 视图 + 导入；列表行缩略图 + 名称 + 规格。
- 节目监视器：图标式播放控制（跳到开头、上一帧、播放、下一帧、跳到结尾）+ 时间码 + 适应下拉 + 工具图标开关 + 更多菜单（重新加载、选帧加入资产库、编辑当前帧等）；纵向电平条。
- 时间线：只留一条工具栏（序列标签、工具、链接选择、吸附、时间码、缩放）；轨道头与片段用 2.4 成果；播放头强调色。
- 效果控件：分组标题 + 数值拖动字段（2.2）+ 关键帧菱形。

**三、2.4 交接的两个场景（按当前契约修正，未放宽判据）**

- `video-edit-timeline`：原生计划 104689d0 起源监视器画面是 canvas，没有 `<video muted>`。改为：先把源素材定位到 1 s 正向播放，等源电平出声（峰值 > 0.01、RMS > 0.003，证明电平是活的、素材有声）；停止后回到 2 s、等电平归零；反向浏览开始后读源状态 `playback_direction === -1`，整个反向窗口每 50 ms 采样源电平，要求 ≥ 10 个样本且每个声道峰值与 RMS 都 < 1e-5。同一段的 `video.paused` 断言改为“停止后 300 ms 内源画面的 `presentedTimeUs` 不再变化”；失败现场证据改读源 canvas 的 dataset。

**二、composite-pressure 与 HEAD 对照**

- 本任务三次拖动：56.81 / 57.46 / 57.75 次/秒（门槛 58）。三次都只在第 127–129 帧出现一次 GPU 提交停顿（138–185 ms，解码 0）；正向 / 反向播放 59.66–59.77 / 59.58–59.89 次/秒，0 遗漏。
