#### 一、选型

- **不新建浮层组件，扩展 `PanelTrigger`**：12 个自绘浮层里，真正需要“浮层”语义的分三类——跟随指针或外部按钮的动作菜单、锚定外部元素的表单面板、有自己触发器的面板。前两类缺的只是“没有内置触发器”。给 `PanelTrigger` 加有限的锚点/受控能力后，三类都落到同一个实现上：定位（`resolveFloatingPanelPosition`，视口夹取、上下翻转）、浮层归属（4.3 的 `overlayOwnership`）、Escape 只关最上层、跨文档挂载（剪辑系统浮窗）、收起动画、`surface` / `panelPadding` / 宽度。另建一个“锚点浮层”组件会和 `PanelTrigger` 形成两套点外/定位/动画实现，违反“同功能唯一入口”。
  - 新增 props：`anchor`（`Element` 或矩形；元素锚点按实时位置定位，点在锚点上不算点外）、`open` / `onOpenChange`（受控；浮层自己发起的收起在动画结束后回调 `false`，收起中再次打开或换锚点会取消收起并就位）、`panelWidth="content"`（按内容自然宽度，受视口约束）、`alignment="bottomRight"`（右缘对齐锚点）。`resolveFloatingPanelPosition` 的 `horizontalAlign` 加 `right`。
  - 没有 `ResizeObserver` 的环境（jsdom）跳过尺寸监听，只靠滚动与窗口事件重新定位。
- **`ContextMenu` 重建在 `PanelTrigger` 锚点模式上**（唯一的右键/按钮动作菜单实现）：菜单项改 `UiOptionButton variant="menu"`（悬停、禁用、玻璃自适应、选中体系与其他菜单一致），分隔线 `ui-glass-adaptive-divider`，宽度按内容（`min-w-44 max-w-sm`，176–384），方向键 / Home / End 移动、Enter 执行；新增 `surface`（默认实底，画布上的菜单传 `glass`，原来全部是玻璃，违反“玻璃只压在媒体与画布上”）；文本框里右键（全局粘贴菜单）不抢输入焦点。`useContextMenu` 只记录菜单项与锚点（`showMenu` 指针位置；`showMenuAt` 带上按钮元素），删除自带的估算定位（每项 40px 估高）与第二份点外/右键关闭监听。`MenuItem` 加可选 `title`（被截断的路径悬停看全）。
- **`Dropdown` 加 `onOpenChange`**：视频查看器需要在倍速菜单打开期间保持控制条可见。
- 成熟方案：4.3 已比较过 Floating UI `FloatingTree` / Radix `DismissableLayer`（整体迁移会替换现有定位与动画，改动面过大），本任务沿用 4.3 的自研薄层并只扩展既有组件，不引入新依赖。
