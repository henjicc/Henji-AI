## 任务目标

5.1 盘点发现两类绕过共享组件的实现，4.3 对共享组件的修复不会对它们生效：

1. 12 个自己用 portal 画的浮层（预设面板、节点标题/下载/右键菜单、资产卡菜单、口播撤销菜单等，清单见 5.1 执行记录）。
2. 靠全局私有 CSS 画外观的组件：视频查看器控制条（16 个私有类）、右键菜单、生成历史自带的 7px 滚动条（与全局滚动条两套）、自定义尺寸输入框用 CSS 类覆盖 `UiInput` 外观（绕过 `check:surface` 规则 E）。

把它们收敛到 `PanelTrigger` / `Dropdown` / `ContextMenu` / `Ui*` 与语义令牌的唯一实现；顺带删除 5.1 确认的死代码（`UniversalResolutionSelector.tsx`、`ParamRow.tsx`、只被测试引用的 `ViewerMarkEditorV3Host.tsx`、无模型使用的 `resolution` 面板注册、默认不可达的图片编辑旧版回退路径，删除前再确认一次引用）。

## 执行步骤

1. 逐个确认 12 个自绘浮层的定位、关闭、键盘行为与特殊需求（如跟随鼠标的右键菜单），能用共享组件就迁移；共享组件缺能力就扩展有限枚举，不保留第二套实现。
2. 私有 CSS 外观改为组件与令牌；滚动条统一一套；删除零引用的私有类。
3. 删除死代码。
4. 精确测试 + `check:surface` / `check:colors` / `check:icons`；`electron:bundle` 后对每个迁移过的浮层四预设截图目视（嵌套点击、Esc、宽度、选中态）。

## 验收标准
