按实施方案第十三节，对本区域每个界面 × 状态逐项核对，清除旧界面残留并修复发现的问题，直到核对清单全部打勾。范围：生成页命令带与搜索筛选、生成记录（图片/视频/音频，进行中/完成/失败/空，10000 条长列表）、输入区与参考素材行、底栏。**全部模型逐个核对参数**：顺序、单行与“更多参数”收纳、选项菜单宽度与选中态、上传控件、费用提示；预设、提示词优化、模型选择、自定义模型管理等浮层。具体行以 5.1 清单为准。

## 执行步骤

1. 从 5.1 清单复制本区域的行到下方“核对清单”，补上清单遗漏的界面或状态。
2. 用 5.2 的操作工具写本区域步骤（复用已有场景），按实施方案第十三节截图：四预设 × 1440 + 石墨 × 960，覆盖各交互态与数据变体。
3. 逐张目视 + 像素对比度审计 + 对照本区域文件的代码残留，问题填“问题记录”并分级。
4. 按根因修复（共享组件、令牌、模型展示补丁优先），排查同源问题，补精确测试；改到共享组件时在执行记录写明影响的其他区域。
5. `electron:bundle` 后用同一步骤复跑、复验截图目视；有回归价值的固化为 `ui:tour` / Reality 场景。
6. 清单逐行打勾；同步总览，交主控提交。
