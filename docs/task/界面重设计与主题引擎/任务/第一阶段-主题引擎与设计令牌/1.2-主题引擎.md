## 任务目标

实现重要记录 002 的主题引擎：输入种子，输出全部语义令牌；预设即种子；旧主题数据可迁移；提供运行时读取令牌与订阅变化的接口（供 Canvas/WebGL/WebGPU 面板使用）。

## 当前情况

## 实施方案

- 新增 `src/core/theme/themeEngine.ts`（纯函数）：`deriveThemeTokens(seed): ThemeTokens`；`THEME_PRESETS`（graphite/ocean/film/paper）；对比度工具；色彩转换按“成熟开源优先”比较 culori / colorjs.io 与自写实现（体积、精度、性能），选型写入执行记录。
- `runtimeTheme` 改为“种子 + 覆盖 → 令牌 → CSS 变量”；保留现有 `--*-rgb` 变量名作为别名指向新令牌，保证未迁移代码不变色到异常。
- `RuntimeThemePayload` v2：`{ version: 2, seed, overrides?, uiRadiusPreset }`；v1 导入时拟合为种子，误差大的令牌放入 overrides；迁移函数与旧设置读取都走同一入口。
- 令牌读取接口：`getThemeTokens()` 与 `subscribeThemeTokens(cb)`，供非 DOM 渲染面使用。
- 按重要记录 010 修正：文字档按目标对比度求解（不照抄设计稿数值）；输出补齐 1.1 第七节“缺口”令牌（状态浅底/文字、`onDanger`/`onWarning`、按模式派生的玻璃与遮罩、固定媒体叠层、`color-scheme`）；首帧与主进程窗口底色取 `window`（主题种子同步到主进程可读位置）；v1 迁移忽略“色调”。迁移细节见 1.1 执行记录第八节“1.2 主题引擎”。

- `accentText`、`dangerText`：设计稿数值为起点，不达标才求解（只有纸白·更强的 `accentText` 被调整）。

- **实底按钮（主控决定 2026-10-03，修订版）** `solveSolidRamp`：判定位置是文字实际所在处——按钮标签垂直居中，取静息渐变中点（`accentHi` 与 `accent` 的 OKLab 中点）与悬停渐变中点（`accentHoverHi` 与 `accentHover` 的中点），两者都 ≥ 4.5；渐变顶端高光与按下态不参与判定。悬停提亮收小：`accentHover` 偏移 +0.04 → 0（底色不提亮，悬停靠顶部高光表达），`accentHoverHi` +0.075 → +0.07（只为色域裁剪留余量：保持 0.075 时深海实测提升 0.0206），悬停中点相对静息中点的亮度提升名义 0.0175、实测 0.0166–0.0185（12 色相 × 4 亮度 × 2 模式扫描最大 0.0199）。主按钮：优先白字，可整体压暗但相对设计稿推导亮度降幅 ≤ 0.04（`ACCENT_MAX_DARKEN`），上限内不达标改用墨水 `N(0.17, 0.01)`（同样按两个中点判定，不达标往亮处求解）。危险实底（`danger`/dangerSolid）：必须白字，按需压暗到刚好达标，不设上限。危险悬停/按下同偏移，新增令牌 `dangerHover`/`dangerHoverHi`/`dangerPressed`。结论：石墨、纸白 → 白字（L −0.028）；深海、胶片 → 墨水（实底不变，与设计稿推导一致）；危险 → 全部白字（深色 L −0.045，纸白不变）。
- `onSuccess`/`onWarning`（非按钮实底，如徽标）：白字 ≥ 4.5 优先，否则墨水，以实底本身判定；`solveSolidFillL` 只在两者都不达标时压暗实底（当前四预设均未触发）。对任意强调色，实底按钮规则都成立（单测扫 12 色相 × 4 亮度 × 深浅两模式，校验两个中点 ≥ 4.5 与悬停提升 ≤ 0.02）。
- 玻璃/遮罩（新增）：深色**保持现有 index.css 数值**（`rgba(0,0,0,.66)`，白纱 .16/.10/.14/.22/.18/.12/.08，区域 window 18%、表面 panel 58%，遮罩 .42/.2/.55），接线后深色观感不变；浅色反向派生：底 = panel 82%，受光边/悬停/按下/选中/分隔/控件纱 = text1 的 12/6/12/9/10/4%，高光白 60%，区域 window 35%、表面 panel 70%，遮罩用 shade 基色 `rgb(28,32,40)` .28/.12/.40。
- 固定媒体叠层（新增，不随主题）：`mediaControl rgba(10,11,13,.56)`、`mediaControlHover .78`、`onMedia` 白、`mediaScrim rgba(0,0,0,.55)`、`mediaLine rgba(255,255,255,.16)`。
- `colorScheme` = 模式；信息色复用强调色，不另设。
- CSS 变量：运行时只写新变量；旧变量全部作为**静态别名**写进 index.css（如 `--app-rgb: var(--window-rgb)`）。原因：运行时内联样式优先级最高，会盖掉 `:root[data-ui-blur='off']` 对 `--ui-glass-*`/`--ui-scrim-*` 的退化规则；别名在 CSS 里则两者各自生效，4.2 删别名只删 CSS。
