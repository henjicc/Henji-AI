## 执行步骤

1. 读 skill `henji-ui-surface`、`henji-application-capability`，以及 `docs/rules/assistant-capability.md`。
2. 改造外观分区：预设卡（显示该预设的小样）、强调色色板（含自定义色）、对比度分段选择；逐色编辑移除（数据层以 overrides 保留兼容）。
3. 助手能力覆盖分级：外观设置属性的读写（预设、强调色、对比度）按通用属性登记，不新增专用工具。
4. Reality：设置外观分区截图（两种窗口尺寸）；切换预设后全局生效截图。
