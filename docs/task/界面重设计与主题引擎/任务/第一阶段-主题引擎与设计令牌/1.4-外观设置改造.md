## 任务目标

把设置中的外观分区改为种子式：预设（石墨/深海/胶片/纸白）、强调色、层级对比度；保留圆角预设与毛玻璃开关；导入导出走 v2 格式并兼容 v1；为将来的主题编辑器预留“高级”入口位置（本任务不实现种子编辑界面，见重要记录 002）。

## 当前情况

`src/components/settings/sections/ThemeSection.tsx`：逐色编辑 9 色、色调预设、圆角预设、强调色、导入导出。

注意（来自 1.2）：主题引擎会按对比度规则调整强调实底（如石墨种子 `#3A6FDF` 推导出的按钮实底为 `#3266D6`），强调色色样与预设小样必须显示**推导后的令牌色**（`accent`），而不是种子原值。

### 2026-10-03 第一段：代码与静态验证（子 Agent，未提交；未运行 bundle/Electron/ui:tour）

**方案（主控已批准）**

- 外观状态改为“选择”：`themeSelection = { preset, accent, contrast, custom }`（`src/core/theme/themeSelection.ts`，纯函数 + 测试）。`preset` 为四预设或 `custom`；`accent = null` 跟随底色自带强调色；`contrast` 三档是相对底色的倍数（预设底色对比度为 1，档位值即最终值；自定义底色“标准”档保留拟合值）；`custom` 是不能用预设表达的底色（v1 自定义九色拟合结果、导入的非预设主题），切到预设后保留，可切回——否则迁移用户点一次预设就永久丢失配色，助手写入的撤销（写回 `before`）也会失败。
- `resolveThemeSelection` 派生生效种子与覆盖；`selectionFromThemeSeed` 是种子 → 选择的唯一入口（v12 迁移、导入共用）：底色等于预设、无覆盖、对比度正好是一档 → 预设（强调色等于预设自带的视为跟随），否则 → 自定义底色。

- 截图：`HENJI_DEV_DISPLAY_POINT=2561,1 npm run ui:tour -- --size <尺寸> --theme-preset <预设> --only settings-theme,settings-about-alt-theme --out .ui-tour/after-1.4/<目录>`，隔离临时资料。四套全部通过、无运行时错误：`graphite`（1440×900）、`paper`（1440×900）、`graphite-960`（960×640）；另因 `settings-about-alt-theme` 会关掉毛玻璃，单独跑 `--only settings-theme` 两套看玻璃弹窗内的效果：`graphite-glass`、`paper-glass`（1440×900）。每套 `settings-theme` 4 张（`-preset`/`-accent-contrast`/`-switched-preset`/恢复后）。
- 目视结论：预设小样按当前强调色与对比度推导（选玫红后四格小样的强调半边都变玫红）；色样为推导后的强调实底，“跟随预设”半预设色半灰；预设格、分段的选中是中性抬升，石墨、纸白、玻璃内外都清楚可辨（纸白下分段轨道与选中段对比明显）；选中色样外圈一环清楚；960×640 下四个预设格仍一行、色样一行，无换行与裁切；切换预设后强调色与对比度保留，界面与窗口底色即时换主题；关于页在胶片无毛玻璃下正常。
- 验收中发现并修复：
  1. **选中色样外圈不显示**：`UI_BUTTON_RESET_CLASS` 带 `!outline-none !ring-0`，`outline`/`ring` 全被清掉。`swatch` 改为 32 外框 + 2px 边框 + 2px 内衬 + `bg-clip-content`（颜色只铺内圈），选中边框 `text1`、悬停 `line-strong`；调用点改用 `backgroundColor`/`backgroundImage`（`background` 简写会重置 clip）。也不再受父级裁切影响。
  2. **“跟随预设”色样半边看不见**：另一半由 `raised` 改为 `text3`（深浅两模式都可见）。
  3. **场景**：目录平滑滚动未停就点单选，分区停在视口底部 → 场景先等滚动停稳再把分区顶到内容区顶部；纸白下 `panel` 不随对比度变化，对比度断言改看 `--raised`。
