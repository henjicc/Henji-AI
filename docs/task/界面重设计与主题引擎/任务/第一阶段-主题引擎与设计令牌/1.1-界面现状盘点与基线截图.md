## 任务目标

为后续迁移提供“改动地图”和“改前基线”，避免边改边找：

1. 颜色盘点：所有颜色来源（`index.css` 变量、`tailwind.config.js`、`styleTokens.ts`、`colorTokens.ts` 281 行常量、组件内 rgba/hex、Canvas/WebGL/WebGPU 中的界面色、图片或 SVG 资源里的深色专用颜色），逐项标注归属：界面色（迁入语义令牌）/ 内容色（如标注默认色，保留登记）/ 待定。
2. 组件盘点：`UiButton`/`UiIconButton`/`UiOptionButton`/`UiChipButton` 等的各 variant、size、appearance 使用次数与文件分布；47 处调用点外观覆盖逐条列出；按钮在每个页面的主次层级问题清单。
3. 字号、控件高度、圆角、阴影、z 层级的现有使用分布。
4. 波形、缩略图相关实现与使用点清单（与重要记录 005、006 对照）。
5. 基线截图：用 Reality 界面场景（生成、画布项目与画布、工具首页与三个工具、剪辑、资产、设置、助手）在 1440×900 与 960×640 截全量“改前”截图，存放位置写入执行记录（不入库的放 `.ui-tour/` 子目录并记录路径）。
6. 输出旧令牌 → 新语义令牌映射表初稿（供 1.2/1.3 使用）。
