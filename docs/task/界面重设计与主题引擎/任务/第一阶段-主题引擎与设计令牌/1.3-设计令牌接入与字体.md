**颜色令牌：Tailwind 映射（最终版）**

规则：类名里的颜色名 = 主题 CSS 变量名去掉 `--`（`themeCssVars.ts`）。不透明令牌走 `--x-rgb`（支持 `/60` 透明度修饰），自带透明度的令牌走 `var(--x)`（不支持修饰）。

| 组 | 新类（示例） | 变量 |
|---|---|---|
| 表面 | `bg-gap` `bg-window` `bg-canvas` `bg-panel` `bg-raised` `bg-control` `bg-control-hover` `bg-control-pressed` `bg-hover` `bg-selected` `bg-media` | `--x-rgb` |
| 线 | `border-line` `border-line-strong` `border-edge` | `--line-rgb`、`--line-strong-rgb`、`var(--edge)` |
| 文字 | `text-text1` `text-text2` `text-text3` `text-text-disabled` | `--text1-rgb` … |
| 强调 | `bg-accent` `bg-accent-hi` `bg-accent-hover` `bg-accent-hover-hi` `bg-accent-pressed` `text-accent-text` `ring-accent-ring` `bg-accent-tint` | `--accent*-rgb`、`var(--accent-tint)` |
| 状态 | `bg-danger-solid` `bg-danger-hi/hover/hover-hi/pressed` `text-danger-text` `bg-danger-tint`；`success`/`warning` 同为 `-solid/-text/-tint` | 实底 `var(--danger)` 等（过渡期无 `-rgb`，见下） |
| 实底上的字 | `text-on-accent` `text-on-danger` `text-on-success` `text-on-warning` `text-on-media` | `--on-*-rgb` |
| 媒体叠层（固定） | `bg-media-control` `bg-media-control-hover` `bg-media-scrim` `border-media-line` | `var(--media-*)` |
| 遮罩 | `bg-scrim` `bg-scrim-soft` `bg-scrim-solid` | `var(--scrim*)` |
| 片段与波形 | `bg-clip-video` `border-clip-video-line` `bg-clip-audio` `border-clip-audio-line` `bg-clip-title` `border-clip-title-line` `text-clip-wave`；`text-wave` `text-wave-played` `text-wave-cut` | `--clip-*-rgb`、`--wave*-rgb` |

- 玻璃 `glass*` 与 `shade` 不出 Tailwind 颜色类：玻璃由 `.ui-glass*` 消费，`shade` 由阴影档位消费。
