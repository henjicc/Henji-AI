## 实施方案

- 数据：主进程生成多级精度峰值（例如每 64/512/4096 个采样一个桶，含峰值与响度），按内容身份（路径 + 大小 + 修改时间 + 声音流序号）缓存为二进制；按视口精度与时间范围取数据；剪辑区间请求、口播剪辑放大都走同一接口。数据格式与生成方式先按“成熟开源优先”调研（如 audiowaveform/BBC peaks 格式等），选型写入执行记录。
- 绘制：`WaveformView` 用 Canvas 2D 按设备像素绘制；大于约 2000 像素宽时按可视区绘制；精细档在采样级显示采样点与零线。
- 迁移全部六处使用点；删除旧实现与旧缓存读写（旧缓存文件可清理或忽略）。
