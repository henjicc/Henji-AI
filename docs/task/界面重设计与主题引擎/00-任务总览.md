# 界面重设计与主题引擎

## 任务目标

用户认为现有界面“整体混乱、按钮背景不统一、质感参差”，希望整体“简洁、克制、高级”。本计划按用户确认的设计稿（重要记录 001）重做界面体系：**主题引擎**从少量种子推导全部颜色、界面不写死颜色并为主题编辑器预留接口；**基础组件**统一（按钮默认静默、主按钮材质、数值拖动等），调用点不再各自定外观；**字体与尺寸**体系化；**统一精细波形**与剪辑片段缩略图；生成、画布项目、工具、剪辑、资产、设置各页面按设计稿落地；最后用四个预设全量验收并把规则固化到技能与检查脚本。

设计稿：<https://claude.ai/artifact/K7FQP9WXbPXBSM1oU6VuTr>（本地源码副本见 [设计稿/](设计稿/)）。

## 重要说明

- 以设计稿为准；背景只表达“唯一主动作”或“当前选中”；界面只引用语义令牌（重要记录 001–003）。
- 页面任务只改视觉与布局，不改业务逻辑、数据结构与 IPC；保留无障碍名称以减少测试场景改动。
- 视觉验收一律真实 Electron 截图、逐张目视，至少“石墨”“纸白”两个预设（重要记录 009）。
- 与原生视频解码计划共用一个主控：最多两个写代码的子 Agent；构建、Electron、Reality 全局串行，原生计划优先（重要记录 008）。
- 每个任务独立验证后精确提交到 `main` 并推送（同原生计划重要记录 009）。
- 规则以根 `AGENTS.md` 与 skill `henji-ui-surface` 为准；执行规则见实施方案第十二节。
