# UI 设计系统统一 - 任务总览

## 任务目标

Henji-AI 的 UI 已经组件化（`src/components/ui` 下有一整套 `Ui*` primitives），但 AI Agent 新建界面时仍然容易做出不美观的页面：不该有背景边框的地方总带着壳、页面层层套卡片、视觉碎片化。经过审计确认，根因不是"Agent 不守纪律"，而是**表达能力缺失**——表面令牌把 `border` 和 `bg` 绑死不可分拆，容器词汇表里只有"卡片"这一个概念，没有"分组"这一层，导致 Agent 想分组只能画卡片；同时字号/圆角/阴影/层级四类视觉数值没有登记制度，出现了 176 处内联字号和 `z-[2147483647]` 这类失控写法。

本任务要达到的结果：建立一套**可被 AI Agent 理解并执行**的 UI 设计系统——五级容器词汇表、登记制视觉令牌、零装饰布局与状态组件、可自动检查的门禁规则——并把存量页面按这套系统迁移，同时收敛已发现的渲染性能问题。

**属于本次任务：**

- 视觉令牌登记制（字号、圆角、阴影、z-index、间距、排版层级）
- 五级容器体系（Region / Group / Divided / Surface / Card）与配套组件
- 自动化门禁（`check:surface`、ESLint 规则、CI 接入）
- 存量页面去卡片化迁移（助手侧栏、生成工作区、媒体查看器、日志、画布节点豁免）
- 弹窗统一走 `UiModal` / `AlertDialog`
- 已定位的渲染性能问题收敛（长列表虚拟化、resize 重排、装饰性能开销）
- Skill `henji-ui-surface` 的持续完善

**不属于本次任务：**

- 重新设计视觉风格（配色、品牌、整体改版）——本任务只做统一与克制，不做美术方向调整
- 明暗主题切换能力扩展（`themeTonePreset` 等现有主题机制不动）
- 国际化文案调整
- 业务功能改动、生成链路改动、Electron 主进程能力改动
- `src/workspaces/canvas/` 历史目录的迁移或删除（属于画布单源约束的独立议题）
- 引入新的 UI 框架或组件库（如 shadcn/Radix），本任务坚持在现有 Tailwind + 自建 primitives 基础上演进

## 重要说明

1. **本计划有两次前置提交作为基线**，接手时不要重复做：
   - `eb74657`：`UiPanel` 的 `inset`/`bare` 变体、`scripts/check-surface-tokens.cjs`、skill `henji-ui-surface`、生成进度瞬态 store（`src/stores/generationTaskProgressStore.ts`）
   - `4800cf0`：`text-4xs/3xs/2xs` 字号令牌与 156 处迁移、`shadow-panel`、z-index 语义档位定义、排版五档令牌、`UiRegion/UiGroup/UiPageHeader/UiFormRow/UiToolbar`、`UiEmpty/UiLoading/UiError`、Settings 试点去卡片化
2. **任何界面工作开始前必须先读 skill `henji-ui-surface`**，它是规则的唯一权威来源；本计划的任务文件只描述"改什么"，不重复规则本身。
3. **视觉数值登记制**：字号只用 `text-4xs/3xs/2xs/xs/sm/base+`；圆角只用 `rounded-lg/xl/full`；阴影只用 `shadow-panel` 且仅浮层可用；层级只用 `z-dropdown/panel/modal/toast/drag`。
4. **表面方向铁律**：内层背景只能比外层更暗，不能更亮（`bg-app`10 < `bg-panel`23 < `bg-surface-dark`38 < `bg-layer`64）。卡片嵌套上限 1 层。
5. **`check:surface` 当前基线是 20 处违规 / 8 个文件**。每个迁移任务完成后该数字必须下降，且不得新增。第二阶段全部完成后应降到只剩已标注豁免项。
6. **画布节点是合法卡片**（符合卡片四条准入条件），处理方式是加 `ui-surface-allow` 豁免注释，**不是**改造成非卡片。
7. **涉及鼠标交互与视觉观感的验证一律交给用户手动执行**，任务文件里必须写清操作步骤与验证点，不要由 AI 自行断言"看起来没问题"。
8. **每次改完代码必须明确告知用户是否需要重启 `npm run electron:dev`**。
9. 性能类任务**禁止编造性能数据**。无法实测时如实说明"需要用户在真实窗口验证"，并给出可复现的测量方法。
