### 相关文件与背景

- `src/components/AudioPlayer.tsx`（362 行）：项目**唯一**在用的音频播放器。消费者：`src/components/mediaViewer/AudioViewerModal.tsx`、`src/components/params/panels/minimaxVoiceClone/AudioPreviewCard.tsx`、`src/workspaces/GenerationWorkspace/components/TaskCard.tsx`。
  - `:258` 播放器外壳：`bg-panel/70` + border + rounded-xl。在不同宿主里语义不同——在 `AudioViewerModal` 里它是主体内容，在 `TaskCard` 里它是结果展示，在 `AudioPreviewCard` 里它嵌在另一个卡片内。
  - `:312` 是一个 tooltip 气泡（`absolute -top-6`），带 border + `bg-surface-dark/95`。**tooltip 是浮层，边框背景是合法的**，应加 `ui-surface-allow` 豁免而非改造。
- `src/components/mediaViewer/VideoViewerControls.tsx:96`：视频控件条，`bg-panel/90` + border + rounded-xl。它悬浮在全屏视频之上，**属于浮层，卡片是合法的**，但应改用 `<UiPanel>` 而非手写。
- `src/components/mediaViewer/ImageInfoPanel.tsx`：有 2 处 `backdrop-blur`（3.3 处理，本任务不碰）。
- 前置提交已删除重复的 `src/workspaces/GenerationWorkspace/components/AudioPlayer.tsx`（144 行死代码），播放器已是单一实现，**不要再新建播放器**。

**当前问题**：

1. `AudioPlayer` 外壳在所有宿主里都画同一张卡片，导致嵌在 `AudioPreviewCard`（本身是卡片）内时出现卡片套卡片。
2. 播放器与视频控件条都手写了 `bg-panel` 表面而非用 `UiPanel`。
3. 合法浮层（tooltip、控件条）与真正的违规混在一起，需要区分处理——不能一律改造。

**可复用**：`UiPanel` 及其 `variant`、`ui-surface-allow` 豁免机制。

## 实施方案

关键判断：**`AudioPlayer` 的表面应该由宿主决定，而不是播放器自己硬定。**

给 `AudioPlayer` 增加一个**有限枚举**的表面变体 prop（如 `surface?: 'card' | 'plain'`，默认 `card` 保持现有调用点不变）：

| 宿主 | 传值 | 理由 |
|---|---|---|
| `AudioViewerModal` | `card`（默认） | 是弹窗内主体，需要边界 |
| `TaskCard` | `plain` | 任务卡内的结果展示，外层已有层级 |
| `AudioPreviewCard` | `plain` | 已嵌在卡片内，再画卡片就是套娃 |

这样既解决套娃，又不需要改动播放器内部逻辑，且默认值保证向后兼容。

其余按性质分类处理：

| 元素 | 性质 | 处理 |
|---|---|---|
| `AudioPlayer` 外壳 | 依宿主而定 | 加 `surface` 变体，`card` 态用 `UiPanel` |
| `AudioPlayer` tooltip（`:312`） | 合法浮层 | 加 `ui-surface-allow` 注释豁免 |
| `VideoViewerControls`（`:96`） | 合法浮层 | 改用 `<UiPanel>` |
| `mediaViewer` 三个 Modal 外壳 | 见 2.3 | 由 2.3 决策，本任务不动 |

## 执行步骤

1. 先读 skill `henji-ui-surface`，特别是卡片准入条件（用于判断哪些是合法浮层）。
2. 记录基线：`node scripts/check-surface-tokens.cjs 2>&1 | grep -A4 -E "AudioPlayer|VideoViewerControls"`
3. 确认 `AudioPlayer` 的全部调用点：`grep -rn "AudioPlayer" src --include=*.tsx`
4. 给 `AudioPlayer` 增加 `surface?: 'card' | 'plain'` prop，默认 `'card'`：
   - `card` → 用 `<UiPanel>` 承载外壳（替换手写的 `bg-panel/70 rounded-xl border`）
   - `plain` → 无边框无背景，只保留内边距与宽度类
   - 保留现有 `compact` prop 的宽度逻辑（`w-full min-w-0` / `w-[36rem]`），两个 prop 互不干扰
5. 在 `TaskCard.tsx` 与 `AudioPreviewCard.tsx` 的调用点传 `surface="plain"`。
6. 给 `AudioPlayer:312` 的 tooltip 加行级豁免注释，写明"tooltip 浮层，边框背景合法"。
7. `VideoViewerControls.tsx:96` 改用 `<UiPanel>`。注意它悬浮在视频上，需确认 `UiPanel` 的 `shadow-panel` 是否合适；若控件条原本无阴影且加了阴影影响观感，用 `className` 覆盖或在此处用 `variant="bare"` + 自定义背景（**若走后者需在记录中说明理由**）。
8. 检查 `AudioPreviewCard.tsx` 自身是否也存在卡片嵌套（`check:surface` 早期报告曾命中该文件），一并处理。
9. 跑检查：`node scripts/check-surface-tokens.cjs`、`npx tsc -p tsconfig.json --noEmit`、`npm run lint`、`npm run check:colors`、`npx vitest run`。
