### 像素等价性验证（针对声称"纯登记、不改观感"的替换）

用 `npx tailwindcss` 实际生成 CSS 后逐条比对：

- `text-2xs/3xs/4xs/13/14/15` 均只产出 `font-size`，不带 `line-height` → 与原 `text-[Npx]` 等价 ✅
- `text-[12px] leading-6` → `text-xs leading-6`：实测生成的 CSS 中 `.leading-6` 位于 `.text-xs` **之后**，因此 `leading-6` 胜出，行高不变 ✅
- `shadow-panel` 取值刻意等于 Tailwind `shadow-2xl` → 换名无变化 ✅
- `rounded-[24px]` → `rounded-3xl`：Tailwind `rounded-3xl` = 1.5rem = 24px，精确相等 ✅
- 新令牌全部确认生成：`border-veil*`、`bg-veil*`、`from/to-veil*`、`shadow-node-selected/node-error/thumb/thumb-sm`、`rounded-hairline`、`border-1.5`、`z-*` 十档 ✅
