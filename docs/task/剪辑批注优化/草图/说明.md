# 剪辑批注草图说明

草图在 `剪辑批注草图.html`，渲染图在 `预览/`（1440×900，2 倍图）。用石墨令牌、随包字体和 lucide 图标画的，用 `node scripts/ui-draft.cjs` 重新渲染。画面标签的避让算法写在草图脚本 `placeTags` 里，实现时照搬。

## 两套都有的部分

- 颜色按批注在序列里的序号自动轮换，8 色：红、蓝、黄、绿、紫、橙、青、粉，相邻两条色相隔得远。都是中高亮度，序号一律用深色字。拟加主题令牌 `--annotation1…8` 与 `--annotation-ink`（固定值，和媒体叠层一样不随主题）。参数条里的色样删掉，只留形状和粗细。
- 画面标签：overlay 实底加 line-overlay 描边，不加投影；最多两行，宽度封顶 208，折行后按最长一行收窄。偏好方向放不下就换到对边，再整体推回画面内，离边 8 像素。
- 箭头改成 1.5px 细线，用批注颜色，从标签上离目标最近的点指向标记点。
- 播放中画面上什么都不画；暂停、拖动播放头、逐帧跳转时才出现。

## A 保守版（A1–A3）

- 改了什么：列表每条一行（同色序号、截断正文、时间码、状态），悬停看全文；选中的那条就地展开成文本框，取代原来那一行，失焦保存、Esc 撤回并收起；删除和驳回不再悬停浮在行上，放进展开态和底栏。画面标签用左侧色条加文字。发送区改成一行标题加动作，不再折行。
- 为什么：直接解决这次反馈的四个问题，结构不动、风险最小。
- 取舍：顶部发送区仍占一块；列表和画面之间只靠颜色对应，时间线记号不改。

## B 创新版（B1–B3）

- 改了什么：列表当成一条竖着的时间线，按时间分组，播放头是列表里唯一的强调色细线，“跟随播放头”开着时自动滚到这里。悬停列表一行，画面上只亮这一条，其他压暗；反过来也一样。画面标签、列表、时间线标尺都用同色序号，时间段批注在标尺上画同色细条。“发送给助手”并进底栏右端作为唯一主动作，整体说明放到点发送后的弹出面板里。快速标注画完一笔，标签本身就变成输入框，不再弹单独的气泡；画面标签和列表展开态是同一份文字，哪边都能写。播放中进度条上留同色小圆点，列表里刚经过的那条短暂提亮。
- 为什么：批注本来就是“某一时刻的某个位置”，把列表、画面、时间线三处用同一套序号、颜色和播放头串起来，找、看、改都在一处完成；顶部少一块区域，列表更高。
- 取舍：改动面大（列表分组与跟随、悬停联动、标签就地输入、时间线记号都要改），实现和验证时间大约是 A 的两到三倍；列表里状态只剩圆点，状态词要靠悬停或筛选看。
