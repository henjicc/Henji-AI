# 7.3 工具箱与素材能力全面接入

## 任务状态

- 状态：实现完成，待手动验收
- 所属阶段：第七阶段 · 内置能力全面接入
- 前置任务：5.4、6.2
- 关联任务：7.4、8.1
- 是否可以并行：可与 7.1、7.2 并行；内部可按领域分批

## 任务目标

把工具箱、3D 镜头、分镜、图片编辑和素材库能力接入统一宿主命令/工具体系。Agent 通过语义参数和稳定对象 ID 操作，不模拟拖拽/点击，不复制各模块业务逻辑。

## 当前情况

- 工具箱 `activeToolId` 是局部状态；3D 有 cameraStageSessionStore、项目命令和 render 服务。
- 分镜、图片编辑、素材库已有部分 commands/store/service，但命令粒度、undo、上下文和稳定 ID 不统一。
- 这些能力包含大量交互状态，不能直接把整个 store 暴露给模型。

## 实施方案

先在 1.2 清单基础上逐域补稳定命令和查询。3D 使用机位、镜头参数、对象变换、预设和渲染等语义工具，不提供逐帧拖动；分镜使用项目/镜头/文本/顺序/生成命令；图片编辑使用结构化操作计划和 preview；素材库使用查询、集合、标签、引用和导入/移除命令。删除、覆盖、渲染等按风险审批。

## 执行步骤

1. 收口工具箱 activeToolId，提供 open/list/current tool 的宿主命令和快照。
2. 3D：实现项目/对象/机位/镜头/预设/渲染的查询与语义命令，参数单位和范围明确。
3. 分镜：实现项目、镜头列表、增删改排、文本/媒体引用和生成命令，保留稳定 shotId。
4. 图片编辑：把现有能力映射为可预览操作；提交前展示目标图片、操作序列和输出策略，原图覆盖视为高风险。
5. 素材库：实现 search/get/add-to-library/tag/use/remove 等命令；文件导入/删除遵循现有路径授权。
6. 每个领域提供 ContextProvider，只注入当前对象/选择摘要和 revision；详情按需查询。
7. 写操作返回 artifact/object ID、preview、undo/compensation；长任务支持 progress/cancel。
8. 每个领域接入现有日志：统一 runId/toolCallId，携带领域对象 ID、耗时、状态和脱敏摘要。
9. 为鼠标/3D/图片编辑交互写真实 Electron 用户手动验收步骤；自动测试只覆盖可确定部分。
