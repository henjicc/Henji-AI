# 画布闭环操作脚本

## 状态

- 自动化与接线：已完成
- 真实 Electron / 鼠标交互：待用户手动验收
- 日期：2026-07-23

## 固定代表性组合

- 上游：`uploadNode`（上传图片节点）
- 下游：`imageNode`（AI 图片生成节点）
- 连接：`source` → `param:__image`
- 布局：首节点 `viewport_center`，第二节点 `right_of_node`

节点类型、默认数据、媒体端口和生成模型约束来自注册表与 `canvas-agent-node-catalog/v1`，不让模型生成像素轨迹或自由猜测数据字段。

## 标准用例

### 前置

1. 新建一个空画布项目并记住项目名称。
2. 打开智能助手，确保 Agent 模型已通过 capability smoke。

### 输入示例

> 在当前画布项目添加一个“上传图片”节点，再在它右侧添加一个“AI 图片生成”节点，提示词填“纸雕风格的橙色小猫”，把两者连接起来并定位到生成节点。

### 期望链路

1. 确定性路由为 `canvas`。
2. 首轮按需执行 `list_canvas_projects/open_canvas_project`、`search_canvas_node_types/get_canvas_node_schema`。
3. 两次 `add_canvas_node` 都携带明确 `projectId` 和确定性 `placement`，返回稳定 `nodeId + undoRef`。
4. `connect_canvas_nodes` 从注册表解析媒体端口，拒绝类型不兼容、重复、自连和循环连接，成功返回 `edgeId + undoRef`。
5. `focus_canvas_node` 选中节点并把它定位到可视区域；工具卡“定位”可重复打开项目并定位。
6. 同一模型步骤内连续写操作继承前一结果的 scope revision，不把自身改动误判为外部冲突。
7. 项目保存后的节点、边和历史与画布 Store 一致。

## 撤销用例

依次要求助手：

1. 使用连接工具返回的 `undoRef` 撤销连接；
2. 使用第二个节点的 `undoRef` 撤销生成节点；
3. 使用第一个节点的 `undoRef` 撤销上传节点。

期望后进先出恢复为空画布；如果中间发生其它画布修改，旧 `undoRef` 返回 `STALE_CONTEXT`，不撤销不相关操作。

## 冲突与非法输入

1. 助手读取 schema 后暂停运行并切换到另一项目，再恢复：不得操作新项目。
2. 请求创建目录外节点类型：返回 `INVALID_INPUT/NOT_FOUND`，不得落盘。
3. 请求把本地路径直接写入上传节点：strict schema 拒绝。
4. 请求重复连接、反向形成循环或连接不兼容端口：宿主拒绝并显示可恢复错误。
