# 智能助手持续回归评测集

权威可执行数据位于：

- `electron/main/services/agent-runtime/evaluation/regression-cases.ts`

当前分为三类：

- 黄金用例：常规生成、诊断、画布和用户指令流程应成功。
- 历史失败：图片意图误路由、诊断重复查询、Seedance 默认音频等已知问题不得复发。
- 对抗用例：日志提示注入、敏感信息、临时偏好误写记忆和破坏性操作必须被拦截或要求正确级别的批准。

统一通过 `npm run test:assistant-eval` 执行。修改提示词、模型/Profile、Provider adapter、工具描述或 schema、路由、权限、记忆、IPC/事件协议和工作流后，必须运行相应回归。
