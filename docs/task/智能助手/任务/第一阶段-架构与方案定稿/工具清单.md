# 智能助手工具能力清单与权限分级

## 1. 清单约束

- 清单版本：`agent-tools/v1`
- 定稿日期：2026-07-23
- 所有工具版本首版均为 `1`；不兼容输入/输出变化必须升版本。
- 所有工具返回 `ToolResult<T>`，成功时包含 `summary`、稳定 ID 和可选 `artifacts/undo`，失败时包含稳定错误码、`retryable` 和恢复建议。
- 工具 schema、权限和 handler 的权威来源在 main Tool Registry；模型只看到当前任务需要的裁剪投影。
- frontend 工具只调用 `HostCommand/HostQuery`；backend 工具直接调用 main service，禁止 main 导入 `src/commands` 或 renderer store。

```ts
type ToolResult<T> =
  | { ok: true; data: T; summary: string; artifacts?: ArtifactRef[]; undo?: UndoRef }
  | { ok: false; code: ToolErrorCode; message: string; retryable: boolean; recoveryHint?: string }
```

## 2. 权限与字段图例

| 等级 | 含义 | 默认审批 |
|---|---|---|
| R0 | 低敏只读或无持久副作用的导航 | 自动；仍受 schema、上下文和预算限制 |
| R1 | 可逆写入或受限敏感读取 | 每个 run 首次按具体 scope 授权；明确用户意图可满足该次授权 |
| R2 | 付费、外发、覆盖或明显影响状态 | 每次展示 preview 后确认 |
| R3 | 删除、任意目标落盘、导入、不可逆或高敏操作 | 每次明确确认，不允许永久授权 |
| R4 | 通用 Shell、任意文件、任意网络、读取凭据、绕过权限 | 不注册，工具层拒绝 |

表格缩写：`RO` 只读、`D` 破坏性、`OW` 会向外部 Provider/网络发送数据、`I` 可安全幂等、`P` 支持 preview、`U` 支持撤销。`是/否/条件` 均是注册表字段，不由模型决定。

授权 scope 由 `permission + tool + targetIds + dataClasses + destination` 组成；高风险没有“始终允许”。诊断读取和素材原文虽是 read，也可能因敏感性进入 R1/R2。

| `run_shell(command)` | R4 | 等同交出整机权限 | 针对具体业务定义受限工具；首版完全不提供 |
| `read_file(path)` / `write_file(path,data)` | R4 | 任意路径、凭据与覆盖风险 | 使用 `ArtifactRef`、系统选择器产生的 `PathRef` 和业务专用工具 |
| `http_request(url,...)` | R4 | SSRF、数据外泄、绕域名限制 | Provider adapter 或白名单业务服务 |
| `invoke_ipc(channel,args)` | R4 | 绕过 preload 白名单和 schema | 每项能力独立 preload 方法 |
| `get_api_key/read_secret` | R4 | 凭据绝不进入模型/renderer | main 在调用瞬间向受信 provider adapter 注入 |
| `click/type/drag` | R4 | 脆弱且绕过业务层权限与状态 | `HostCommand`/domain action；鼠标仅供用户手动验收 |

## 7. 日志、摘要与敏感字段规则

所有注册工具自动产生：

```text
main.agent_tool / agent_tool.execute.started
main.agent_tool / agent_tool.execute.completed
main.agent_tool / agent_tool.execute.failed
```

frontend 工具额外产生 `features.assistant.frontend_tools / assistant_frontend_tool.execute.*`。统一 `requestId=runId`、`taskId=toolCallId`，context 只含 `toolName/version/risk/durationMs/errorCode/targetId 哈希或稳定业务 ID/resultCount`。

MVP 额外日志：

| 工具 | 额外 event | 允许摘要 | 禁止字段 |
|---|---|---|---|
| 目录/模型工具 | `agent_tool.catalog.search.completed` | query 长度、类别、命中数、catalogVersion | query 原文、完整 schema |
| `switch_workspace` | `assistant_frontend_tool.navigation.completed` | from/to、revision | 用户文本 |
| `create_visible_generation_task` | `assistant_frontend_tool.generation_task.completed` | taskId/modelId/providerId/mediaCount/status | 完整 prompt、媒体路径、params 原文、密钥 |
| `get/cancel_generation_task` | `assistant_frontend_tool.generation_task.read/cancelled` | taskId/status/progress/errorCode | 结果 URL 查询参数、provider body |
| `query_diagnostic_events` | `agent_tool.diagnostics.query.completed` | 被诊断 requestId、时间窗、命中/裁剪数 | 日志正文、context/error 原文 |

工具结果进入模型前统一：output schema → secrets/path/URL 脱敏 → 8 KiB 或 100 记录阈值 offload → 最多 1 KiB/20 条预览 → 标记 `trust='untrusted_observation'` 和数据分类。
