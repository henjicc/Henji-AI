- 前置任务：6.2、6.4、6.5、7.4

## 任务目标

针对最终内置能力集、模型 Profile、utility process、记忆和跨工作区 Workflow 做全量效果与安全回归，给出可复现报告和明确失败项；未通过不得进入最终生产化验收。

## 当前情况

- 6.2 已有持续评测机制，7.x 已接入最终工具集，6.4/6.5 改变了进程和上下文/记忆行为。
- 新能力可能导致工具目录膨胀、跨域权限组合、日志量和 Provider 差异问题。

## 实施方案

组合 deterministic、mock Provider、真实 Provider smoke 和用户真实 Electron 操作。评测按能力域、模型、上下文规模、风险和故障类型分层；既看最终答案，也核对界面/数据库真实状态、工具参数、日志证据和撤销恢复。

## 执行步骤

1. 冻结版本：模型/Profile、prompt、工具/schema、权限、Workflow、checkpoint 和评测集版本。
2. 运行生成/画布/工具箱/3D/分镜/图片编辑/素材/诊断和跨域 Workflow 黄金用例。
3. 运行参数边界、权限、间接注入、数据外泄、审批重放、重复副作用、renderer/utility crash 和恢复用例。
4. 对每个 Agent 候选模型运行 tool-call/structured-output/usage/fallback 矩阵，记录不支持项。
5. 校验真实 UI、SQLite、文件/素材和画布状态，不只根据模型文本判断成功。
6. 校验日志完整性/脱敏：run/model/tool/approval/context/checkpoint/workflow 事件关联，敏感探针零命中。
7. 输出成功率、工具/参数、安全、恢复、延迟、token/费用和失败分类报告。
8. 修复后只重跑受影响集 + 全局烟测，直至达到门槛。
