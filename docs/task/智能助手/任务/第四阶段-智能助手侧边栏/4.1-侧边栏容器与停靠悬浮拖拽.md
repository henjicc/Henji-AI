# 4.1 侧边栏容器与停靠悬浮拖拽

## 任务状态

- 状态：待验证
- 所属阶段：第四阶段 · 智能助手侧边栏
- 前置任务：1.1
- 关联任务：4.2、4.3
- 是否可以并行：可与 3.x 并行（纯前端容器，先不接运行时）

## 任务目标

实现智能助手的全局侧边栏容器：默认从右侧唤起，支持左 / 右停靠、悬浮于面板之上、以及自由拖动定位；具备唤起 / 收起、记忆位置与形态。本任务只做"容器与摆放形态"，对话与执行内容在 4.2 填充。

## 当前情况

- 应用根：`src/App.tsx`（`NotificationProvider` 包裹，标题栏 `WindowControls` + `TabContainer` + 若干全局叠层如 `AssetLibraryFloatingPanel`、`SettingsModal`、`GlobalAlertDialog`）。
- 已有可参考的"悬浮 / 停靠 / 边缘触发"实现：素材库 `src/features/assets/AssetLibraryFloatingPanel.tsx` 与 `useAssetEdgeTrigger`，以及 `assetPanelPosition` 等设置（`settingsStore`）。可借鉴其停靠 / 悬浮与位置持久化模式。
- UI primitive 单点：业务组件只用 `@/components/ui` 的 `Ui*`；颜色走语义类 / `styleTokens`；拖拽排序等有现成 `useReorderDrag`（如需拖动可参考但本容器是面板拖动，不是列表排序）。
- 主题 / 圆角 / 强调色等运行时样式经 `runtimeTheme` 应用，需自适配。
- 根级 Provider / 全局叠层只在根层单点挂载（CLAUDE.md 约定）。

## 实施方案

在应用根层新增单点挂载的助手侧边栏容器组件，状态（是否打开 / 停靠侧 / 悬浮 / 自定义坐标 / 尺寸）用一个 `assistantUiStore`（Zustand）管理，位置 / 形态持久化复用 `settingsStore` 风格（或新增最小设置项）。容器分三种形态：左停靠、右停靠、悬浮（可拖动 + 可记忆坐标）。样式全部走 `Ui*` 与语义色 / `styleTokens`，主题自适配。拖动交给容器标题栏，边界约束避免拖出可视区。此任务需要真实鼠标交互验证，改完写清操作步骤交用户验证。

## 执行步骤

1. 阅读 `src/features/assets/AssetLibraryFloatingPanel.tsx`、`useAssetEdgeTrigger`、`settingsStore` 中素材面板位置相关字段，复用其停靠 / 悬浮 / 持久化范式。
2. 新增 `src/features/assistant/store/assistantUiStore.ts`：`open/dock('left'|'right')/floating{ x,y }/size`，及唤起 / 收起 / 切换形态动作。
3. 新增 `src/features/assistant/AssistantSidebar.tsx`（容器骨架，内容区留给 4.2）与拖动 / 停靠交互；用 `Ui*` 与语义色实现，主题自适配。
4. 在 `src/App.tsx` 根层单点挂载 `AssistantSidebar`（与其它全局叠层并列），提供一个全局唤起入口（如标题栏按钮或快捷键，样式对齐现有）。
5. 实现位置 / 形态持久化（复用设置持久化范式），重启后恢复。
6. 处理层级与遮挡：悬浮态在面板之上但不挡关键系统弹窗（settings / alert）；停靠态与工作区布局协调不遮内容。
7. 写清手动验证步骤（右侧唤起、切换左 / 右停靠、切悬浮并拖动、收起、重启恢复）交用户验证。
