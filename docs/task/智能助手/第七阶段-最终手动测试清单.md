# 第七阶段最终手动测试清单

## 启动条件

- [ ] 先停止旧开发进程，再执行 `npm run electron:dev`；本轮改动包含 main、utility、preload/宿主命令和 renderer，必须重启后测试。
- [ ] 使用已完成 capability smoke 的真实 Agent Profile；确认 API key 已由应用密钥设置提供，不把密钥粘贴到助手用户指令或对话中。
- [ ] 打开日志窗口，准备按 `runId/toolCallId` 抽查事件；记录 Provider、模型、耗时、费用和失败原因。

## 1. 生成与模型目录

- [ ] 在生成工作区输入“生成一张剪纸风格的猫咪照片”，确认先搜索模型、读取 schema、校验参数，再按批准方式创建可见任务。
- [ ] 在非生成工作区重复上一步，确认先切换生成工作区，不出现连续的空能力目录卡。
- [ ] 分别测试图片、视频、音频；确认助手只说“已提交/生成中”，Provider 完成前不宣称成功。
- [ ] 在任务进行中取消，确认任务状态、历史记录和助手答复一致；抽查日志中的 `runId/taskId/modelId/providerId` 且无密钥。
- [ ] 在中央描述文件 `src/core/modelCatalog/generationModelDescriptions.ts` 手工补充一条描述并重启，确认同一通用模型的不同供应商变体读取同一描述；tags/schema 仍是能力硬约束。

## 2. 画布与项目

- [ ] 列出项目、创建项目、打开/关闭、重命名；确认助手使用项目 ID，不依赖界面文本。
- [ ] 在明确项目中搜索并添加代表性节点，复制、修改参数、选择、分组、定位、删除；确认参数由节点 schema 校验。
- [ ] 连接和断开边，尝试错误端口、重复边和循环边，确认返回可读错误且不污染画布。
- [ ] 执行批量 plan → preview → commit，确认一次历史组可撤销；用户先手动修改画布后再提交，确认 revision 冲突不会覆盖新修改。
- [ ] 关闭并重新打开项目，确认持久化结果、节点 ID、边 ID 与撤销边界正确。

## 3. 工具箱、3D、分镜、图片编辑和素材

- [ ] 切换工具箱工具，读取工具箱状态；确认不模拟点击或拖拽。
- [ ] 3D：创建/打开/重命名/删除工程；添加、复制、更新、删除对象；创建/更新镜头卡。删除操作确认必须审批。
- [ ] 读取大型 3D/分镜项目，确认助手只展示计数、稳定 ID 和有限摘要，不输出完整 `sceneJson/nodesJson/edgesJson`。
- [ ] 图片编辑：选择图片，创建旋转/翻转/裁剪/标记预览；确认原图不变、非法标记/超界裁剪被拒绝；批准 commit 后生成新素材。
- [ ] 素材：按类型/标签/集合/关键词查询，读取详情、选择、加标签、加入/移出集合；删除素材确认高风险审批且不可误删其他素材。

## 4. 三个跨工作区工作流

- [ ] `model_to_generation_canvas`：计划 → 预览 → 批准 → 生成提交 → 打开画布 → 创建节点；检查 taskId、projectId、undoRef 和步骤顺序。
- [ ] `asset_edit_to_canvas`：读取素材 → 图片编辑预览 → 保存新素材 → 打开画布 → 创建输入节点；确认通过 `previewRef/assetId` 传递，不复制大文件。
- [ ] `camera_shot_to_generation_canvas`：打开 3D 工程 → 创建镜头卡 → 生成提交 → 打开画布 → 创建运镜节点。
- [ ] 在每条工作流中分别测试审批拒绝、暂停/恢复、用户取消、Provider 失败、renderer 重载和 revision 冲突；确认已完成/未完成/可补偿列表准确。
- [ ] 对可补偿流程执行 rollback，确认只回滚助手自己产生的可恢复步骤，不假装撤销 Provider 外部副作用。

## 5. 批准、安全与记忆

- [ ] `每次询问`：每个 R1/R2/R3 写操作都逐次出现审批；R3 删除/不可逆操作始终询问。
- [ ] `助手判断`：只读查询和低风险动作可自动执行，高风险写操作仍需审批。
- [ ] `充分访问`：R0～R2 按规则自动执行，R3 仍需审批，R4 始终禁止。
- [ ] 输入提示注入、自动批准、越权删除等内容，确认安全边界和真实能力约束不能被覆盖。
- [ ] 在设置中编辑 `user-instructions.md`，确认普通路径/网址可保留，密钥、令牌、Cookie、密码等在进入模型前脱敏；旧 `model-preferences.json` 不被读取。
- [ ] 普通对话不能擅自写入长期记忆；记忆候选必须经过用户确认，确认删除/清空需要二次确认。

## 6. UI、日志与长稳

- [ ] 在长 Markdown、工具轨迹和审批卡对话中滚动，确认 Markdown 列表/代码/链接可读，工具活动默认单行折叠，执行思路默认折叠。
- [ ] 在画布、生成、3D、工具箱分别测试左右停靠宽度、悬浮位置、宽高和右下角调整；确认拖动跟手、文字不拉伸、工作区实时避让。
- [ ] 抽查日志窗口/JSONL：`runId/toolCallId` 可串起 workflow/step/tool/approval，日志不含 API key、token、Cookie、密码或完整文件内容。
- [ ] 连续使用 30～60 分钟，观察 CPU、内存、utility 重启提示、事件顺序和恢复状态；终止 utility 后确认活动 run 进入 `recovery_required`，不会自动重放未知副作用。
