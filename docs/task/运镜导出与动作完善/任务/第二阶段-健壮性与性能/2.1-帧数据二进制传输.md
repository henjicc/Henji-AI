## 任务目标

逐帧传输从 base64 dataURL 改为二进制字节，消除 33% 体积开销、渲染层 base64 编码与主进程整串正则解析，1080p 导出速度与内存占用不劣于现状。

## 当前情况

- 渲染层 `src/features/cameraStage/export/cameraStageVideo.ts`：`captureFrame()` 得到视口 PNG dataURL → `cropDataUrlToAspectRatio()`（`export/cameraStageAspectCrop.ts`）内部 canvas 处理后 `canvas.toDataURL('image/png')` 再产出 dataURL → `appendVideoFrameExport({ sessionId, frameIndex, dataUrl })`。
- 主进程 `electron/main/services/video/frame-export.ts` 的 `decodePngDataUrl()` 用正则 `^data:image\/png;base64,(...)$` 匹配整串后 `Buffer.from(base64)`。1080p 单帧 PNG 数 MB，正则+解码是纯浪费。
- IPC 链路六处载荷定义（改契约必须一次改齐）：
  1. `src/platform/contracts/video.ts` — `AppendVideoFrameExportPayload`
  2. `src/platform/adapters/electron/video.ts` — 透传
  3. `src/commands/video.ts` — 透传
  4. `electron/preload/index.ts` + `electron/preload/api.d.ts` — `videoApi.appendFrameExport` 与 `HenjiVideoAppendFrameExportPayload`
  5. `electron/main/ipc/video.ts` — `parseAppendFrameExportPayload`
  6. `electron/main/services/video/types.ts` + `frame-export.ts` — `AppendVideoFrameExportPayloadDto` 与写文件
- 可参照先例：`video:generateThumbnailBytes` 已经走 `Uint8Array` 返回（`generateVideoThumbnailBytes`），Electron IPC 结构化克隆对 typed array 原生支持，无需额外序列化。
- 注意：`cropDataUrlToAspectRatio` 还有截图导出的调用方（`export/cameraStageScreenshot.ts` 一带），不能直接改它的返回类型破坏截图功能。

## 实施方案

- 载荷 `dataUrl: string` → `bytes: Uint8Array`。
- 渲染层：裁剪 canvas 后不走 `toDataURL`，改 `canvas.toBlob('image/png')` → `blob.arrayBuffer()` → `new Uint8Array(...)`。实现方式二选一（执行时定，倾向 a）：
  a. `cameraStageAspectCrop.ts` 内部抽出"dataURL → 裁剪后 canvas"的共用函数，dataURL 出口（截图用）与 bytes 出口（视频用）各自封装，截图调用方零改动；
  b. 视频导出单独复制一份裁剪逻辑（违反复用原则，不推荐）。
- 主进程：`parseAppendFrameExportPayload` 校验 `bytes instanceof Uint8Array` 且非空；`appendVideoFrameExport` 直接 `fs.promises.writeFile(framePath, bytes)`；删除 `decodePngDataUrl`。

## 执行步骤

1. 在 `cameraStageAspectCrop.ts` 抽出共用裁剪函数，新增 `cropDataUrlToAspectRatioBytes()`（返回 `Uint8Array`），原 `cropDataUrlToAspectRatio()` 保持签名与行为不变。
2. 按"当前情况"列出的六处清单逐一把 `dataUrl` 字段改为 `bytes: Uint8Array`。
3. `frame-export.ts`：写文件直接用 bytes，删除 `decodePngDataUrl` 与相关正则。
4. `cameraStageVideo.ts`：调用新 bytes 出口，`appendVideoFrameExport({ sessionId, frameIndex, bytes })`。
5. 跑 `npm run lint`、`npx tsc --noEmit`、`npx tsc -p tsconfig.electron.json --noEmit`、`npx eslint electron --ext ts --report-unused-disable-directives --max-warnings 0`。
