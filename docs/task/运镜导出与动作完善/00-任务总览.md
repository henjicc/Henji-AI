# 运镜导出与动作完善 - 任务总览

## 任务目标

运镜控制第二版的 4.1 动画视频导出与角色内置动作片段已经落地（提交 `6f64213`、`44013eb`），功能可用，但代码审查发现导出正确性、链路健壮性、性能三类问题：动作片段由墙钟驱动导致导出结果不确定、动作与关节关键帧播放互相覆盖、逐帧 IPC 传 base64 开销大、导出会话与半成品文件可能残留等。

本任务的最终结果：导出的 MP4 内容确定、可复现；导出链路在取消、崩溃、刷新等异常场景下不残留垃圾；帧传输性能优化到位；（视优先级）编码进度真实可见、导出分辨率不依赖视口大小。

**属于本任务**：运镜控制（cameraStage）视频导出链路与角色动作播放的修缮、加固、优化。
**不属于本任务**：动作片段接入时间轴关键帧、导出格式扩展（WebM/GIF/透明背景）、运镜控制新功能——这些列入实施方案的"后续方向"，另立计划。

## 重要说明

- 导出链路横跨五层：渲染层 → `src/commands/video.ts` → `src/platform/contracts|adapters` → `electron/preload` → `electron/main/ipc|services/video`。凡是改 IPC 载荷结构的任务（2.1、3.1），五层必须同一任务内一次改齐，禁止只改一半。
- 涉及 Electron 主进程的改动需要重启 `npm run electron:dev`；仅渲染层改动热更新即可。每次改完按项目约定明确告知用户。
- 导出、播放等鼠标交互验证一律交给用户手动测试，任务文件里写清操作步骤和验证点。
- 1.1 的行为取舍（暂停时动作是否定格）见 [重要记录.md](重要记录.md) 记录 001，动手前需用户确认。
