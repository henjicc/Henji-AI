## 任务目标

按实施方案第二、三、四节对“生成工作区”做一轮完整巡检并修复。范围：生成页命令带、生成记录（各类型、进行中/失败/空）、输入区与底栏。**逐个模型**过参数：顺序、单行收纳、选项菜单宽度、上传控件、费用提示、预设与提示词优化浮层。具体页面与状态以 1.2 盘点表为准。

## 执行步骤

1. 按盘点表写本区域探针（复用 1.1 工具与已有场景），四预设 × 1440 + 石墨 × 960，覆盖各交互态。
2. 逐张目视 + 对比度审计，问题填入下方台账并分级。
3. 按根因修复（共享组件、令牌、展示补丁优先），同源排查，补精确测试。
4. `electron:bundle` 后同一探针复跑、复验截图目视；有回归价值的固化为场景。
5. 提交推送，更新总览。
