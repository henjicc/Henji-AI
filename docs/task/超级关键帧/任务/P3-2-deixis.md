# t150 / P3-2 指代解析与可校正稿

日期：2026-10-11。状态：剪辑录制及本地指代审阅的局部宿主验收通过，P3 完整阶段尚未完成；总管理者负责审查与 Git。无 Git 写操作、真实付费、SDK 源码改动或开发实例启动。

## 设计与开工边界

- 唯一真相是所属剪辑文档的会话、不可变页和已有 bindings/corrections；core 只计算，界面与公共读写委托同一领域服务。首版只产生审阅候选及当前状态差异计划，不实时执行口述，不调用意图模型。
- 原采集/AudioWorklet、页 I/O、ASR 毫秒 DTO、JSONL、UiTextToken、Virtuoso 和正式 Electron Reality 均复用现有入口。参考 [Eisenstein / Christoudias 一手论文](https://aclanthology.org/N04-1004/) 的时序/显著性路线，与逐词最近点对照；论文没有可直接消费本项目实体/visit/撤销/隐私页的生产模块，也不提供本任务中文鼠标准确率。首版只自有受控槽位和证据编排，不安装新 NLP/ASR 模型，不把规则测试外推成真实理解能力。
- 按真实词区间选择证据；句级保持整句窗口。候选窗口是计算预算，跨 gap/seek/visit、重叠对象、低置信度、否定与缺关键槽必须拦截；不能用当前图层或作品像素填历史空缺。
- 工作预算以会话页的时间索引缩小读取，长词稿沿现有分页/虚拟化；不限制会话、词、目标或素材总数。取消/切会话/删除后丢弃迟到审阅结果，保存失败保留词稿与绑定。
- 本任务禁止持久格式改动。因此完整历史标注快照、一般差分、P1 draft/take 关联若需扩 schema，明确交总管理者串行登记格式、资源 live set 与导入导出；本单不旁路存成动态私有字段。
- 验证级别 L2：共享 core/词绑定/异步保存；真实采集与呈现依赖 Electron，按 testing.md 第三节与本次用户授权执行定向 Reality。用户指定九目录回归及原生套件按其明确范围执行，不扩全仓。构建、Reality 与长测后台运行，逐轮原子获取并立即释放截图锁。

## 设计自查

1. **助手只凭名称和说明能否用对？** 绑定以真实词/句、角色和证据为语义；通用实体读写只接受已存在会话及稳定引用，不开放 consent 伪造。正式私密正文权限与公共入口的完成状态须用结果测试证明，未验之前不宣称已通。
2. **能否 AI 先做、人只确认？** 本地证据先给候选，人确认重叠/粗时间/指代。否定保持保护语义，缺证据不猜，不付费求解。
3. **产物能否直接流进其他工作区？** 已有普通关键帧、正式作品导出与媒体桥承接最终产物；私密录音/词稿/绑定不自动进素材库。图片宿主由 t149 所有，本单不修改，跨宿主验收未完成前单列未验。

## 验收记录

### 已实现范围

- `alignment` 沿实际词/句墙钟区间选择指针、命令、姿态差分、标注与几何事实，再用实际呈现时间及 visit 校验。先指后说可保留；菜单/时间线点击、gap、未呈现、低置信度和跨访问不能自动确认。默认证据窗口为词前 800ms、词后 250ms，这是首版时间相关范围，不是会话或指针数量上限。
- `deixis` 给出 target/source/destination/dwell/exit 槽，句内源点和终点按真实词区间分别选择；跨词边界的指代保留全部 word 引用。同名和重叠对象保留全部历史候选，显式确认只接受原候选的对象、位置、证据和 visit。支持明确数字/基础汉字时长和退出方向；不支持的表述被拦截，不调用意图模型。
- `intentPlan` 只对照当前对象和摘要产生差异。已经发生的 move/undo/redo 仅作来源，没有可重放指令；目标已满足为零差异；对象删除、过期基线、缺槽、冲突、否定保护和尚未编译的停留/退出要求均拦截。当前只提出位置差异，尚未形成时间轴关键帧候选或应用按钮。
- 共用 `ExplanationReview` 接到剪辑审阅：点词看历史图、录制位置和历史对象，重叠需确认，改绑定重算整句候选。词稿列表保持分页/虚拟化，证据审阅使用独立区域，避免嵌套虚拟列表使确认按钮不可达。切词、关闭、删除或会话切换会丢弃迟到结果并释放图像 URL。
- 私密正文仍保存在原会话不可变页，校正以最新 correction 引用读回；文字校正串行，拒绝迟到旧稿，音频/时间/身份只取验证过的原始页，调用方只能修改文字。绑定共用同一领域服务校验，不另存助手正文副本。
- 指向时的历史像素由同一 Worker 呈现回执的位图复制，主线程只保留最新一帧；下一帧、迟到回执和关闭会释放位图。正式截图/序列仍走 Electron `capturePage`。录制时关闭两帧流水，防止历史复制等待期间下一次绘制覆盖目标；其真实表现以最终宿主截图为准，不能用纯单测替代。
- 第五轮实际证明指向时的历史 PNG 非黑图，但第六轮及第七轮逐张检查证明 GPU canvas 的异步读回仍会出现黑图，第七轮脚本通过也没有被登记为视觉通过。按 [WebGPU 官方 canvas 生命周期与映射说明](https://gpuweb.github.io/gpuweb/explainer/) 核对后，最终改为同一次绘制提交内 `copyTextureToBuffer`，读回已拥有的缓冲区，再处理真实行填充与 BGRA/RGBA 通道。普通预览没有读回；离屏中间目标不截取，映射失败和晚到均释放。沿普通及 composite 最终合成的共用 compositor 入口，不改 VGPU API、shader 或图片文件；当前会话没有 VGPU MCP，官方网站访问失败，回退官方 WebGPU 资料和已安装 VGPU 的一手类型核对，没有凭记忆改新 API。
- 录制或暂停录制期间用同一回执的位图绘制稳定节目 canvas，仍由原 GPU 渲染器给出真实像素，不重渲染历史、不改正式截图。结束录制后停止额外截取和串行历史复制，当前静帧可继续显示；普通新帧移除旧图，关闭释放。默认预览流水未改；最终截图和性能边界见后续记录。
- 最新复制路径每次只保留一个在途录制帧，缓冲区按实际帧尺寸及 256 字节行对齐分配并在映射后销毁；历史位图缩到 1280×720 像素工作预算。完整帧读回与通道转换在 Worker 内，普通预览不承担此开销；4K/长会话性能、物理 P95 尚未验，不能把可见画面验证当性能达标。
- 第五轮重叠确认仍失败：Virtuoso 默认内联 `height:100%` 覆盖了 `h-40`，没有挂载选项。改为固定高度外层容器，内部沿已有虚拟化，不限制候选数。
- 差异基线固定同一次 sequence/frame；读取期间改变作品/时间或正在播放会清空修改并要求重新确认。共用 Review 用宿主状态键丢弃迟到旧基线；播放期状态键固定，避免逐帧扫描词稿/摘要。历史指代绑定保持历史身份，新的当前差异另行计算。
