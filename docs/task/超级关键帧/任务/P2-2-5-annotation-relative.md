## 设计与接线

- 标注是有来源身份、画幅身份、目标引用、时间跨度的中立证据。角色须明确选择：箭头/首笔画为路径，闭合圈/区域为到达或停留，文本保留为意图提示。装饰图层名称不用于识别角色。
- 剪辑“按标注整理”可直接产生候选；不为标注意图伪造录制采样、墙钟或呈现回执。候选仍走原生编译、Worker、资源保存、一次应用/撤销。处理标注只追加回复并标待审查，不替用户 resolved，不改作者/历史。
- 图片读取正式 vector/text 图层及祖先仿射，使用已有路径展开与输出几何处理裁剪/旋转。返回派生证据，不创建作品形状或恢复旧 image_mark。圈内多个候选全部保留给调用者确认。
- 参照明确选另一个片段，提供局部偏移和画幅偏移；消费现有片段关键帧求值和 clipGeometry。没有元素级活绑定，因此明确烘焙当前区间为普通曲线；后续参照移动必须重整理，旧候选不能应用。保持原父组，不改 tracker。
- 保存复用原有 recipeRefs 与不可变 recipe 资源；新增 `video-motion-constraints` 资源由严格 schema 读取。候选 requestKey 包含标注内容/几何、参照原始及当前摘要，关闭重开仍保留原始参照。
- 开源/复用选型：沿 P1 已采用的 `fit-curve`、正式标量贝塞尔求值、共享 affine inverse/compose、正式 vector flatten；这些现成实现已覆盖拟合、变换和路径展开，本单只写宿主 DTO 与约束编排，不引入第二套求解器、播放器、路径库或矩阵库。参考元素发送紧凑正式曲线到 Worker，按需求值；不在界面线程展开按时长增长的参照帧数组。没有产品数量上限。

## 设计自查

1. **助手只凭名称和说明能否用对？** 领域入口明确“哪个标注、路径/到达/停留角色、起止帧”“相对哪个元素、局部/画幅偏移”。公共实体属性与工具投影属于 t156 / 总管理者文件所有权，本单交付同源入口，不能声称已完成助手公开注册。
2. **能否 AI 先做、人只确认？** 已确认角色后本地免费生成候选；人校正时间、参照、钉点并应用。文本只提供证据，不在没有语义模型的情况下假称理解任意口述。硬冲突拒绝，原稿保留。
3. **产物能否直接流进其他工作区？** 动作落正式剪辑曲线，同一保存/导出与历史；图片为中立证据供正式图层布局和指代服务消费，不复制作品图形。图片 UI 与下游接线由 t157 / t156 接收，尚不能称双宿主闭环完成。
