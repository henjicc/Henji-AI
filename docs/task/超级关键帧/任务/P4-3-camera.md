# t160 / P4-3：cameraStage 三维机位共核

状态（2026-10-11）：**3D 适配、原生候选与领域提交完成；界面、采集与公共能力接线未完成，整项 P4-3 不登记完成。** 总管理者审查和 Git 提交。本轮未执行 Git 写操作、Reality、构建、开发实例启停或付费调用，未修改 SDK 和其他任务文件。

## 表达能力核实

- 唯一持久真相是完整 `StageStateKeyframe`：绝对秒时间、全对象快照、摄像机选择、连续性和逐对象过渡。`animation.tracks` 仍由正式编译器派生，本轮不新增轨道实体或持久格式。
- `StageSpatialPath` 已有世界坐标的分段三次贝塞尔、内部节点和相对切线；首尾位置来自相邻状态。`createCameraPresetPath` 已支持环绕、推拉、横移、升降；本轮直接调用，不复制几何。
- 摄像机正式光学量是垂直 FOV（度），不是毫米焦距；朝向由 `lookAt` 派生，roll 保留，Three.js 使用 YXZ。object 模式跟随目标实际位置；lookAt 当前是摄像机全局设置，不是可逐帧变换的目标轨道。候选拒绝与全局设置不一致的快照。
- 正式过渡支持逐对象 `delay`，可让摄像机先停再推，同时保留其他对象的时间与状态；无需插入额外场景卡或改全局时间。已有贝塞尔弧线和停顿在平滑候选中保留。
- 时间按原生 fps 验证为正式帧；内部度量为世界位置/参考尺度、视线目标/参考尺度、单位四元数角距和 FOV 差，不调用二维 clip 编译器。

## 实现与接口

1. `cameraAdapter.ts` 新建 3D 纯契约，复用现有双时钟校验、候选身份和协作取消。录制样本按访问、时钟段、方向改变和同帧重访拆段；倒退段只排序作品帧，不反转姿态含义；navigate、不确认和无呈现不造路径。没有修改既有 core 文件。
2. `createCameraCandidates` 编排平滑推拉、环绕、带停顿的推近三族。宿主注入正式编译/求值；钉点锁住时间、位置、朝向、视线和 FOV。冲突候选返回引用与原因，保留其余候选，不自动解钉。逐四分之一帧复核可表示性，拒绝路径中途穿过注视点。
3. `compileCameraMotionCandidates` 将连续、同摄像机状态卡编译为原生路径；既有路径、非目标对象、非选段状态、FOV 与 roll 都保留。选段之后还有状态卡时，自动保护选段末端，避免改变后续区间。
4. `prepareCameraStageMotion(projectId, request, control?)` 只生成临时审阅句柄及标签/拒绝原因，不改文档。源身份含场景、完整状态卡、对象、摄像机、fps 和请求选项；SHA-256 复用仓内工具。正式引用采用 `camera_stage.scene` 与 `camera_stage.camera` 的项目限定身份。
5. `applyCameraStageMotionCandidate(projectId, review, candidateId)` 只接受服务发出的原句柄，防止调用方伪造原生状态。应用前和异步摘要后双重检查当前源，一次确定性领域提交进入现有历史/文档订阅；复用已有 undo token 与保存屏障。保存失败返回 `saved:false`，保留已发生的应用；再次调用同候选只重试保存。应用后外部改动/撤销使旧句柄失效。
6. 准备和应用沿现有 logger 记录 start/completed/failed。没有新增 Store、IPC、日志通道、播放器或落盘候选格式。

`CameraMotionCandidateRequest` 明确摄像机、连续状态卡、钉点、场景参考尺度、环绕角度/方向、推近距离比例、停顿比例。环绕和推近是显式待确认的风格候选，不宣称这些意图变化必须贴合原稿位置。平滑当前整理原生过渡速度并保留路径，不宣称已实现高密度录制的去抖/稀疏化。

## 选型、规模与技术限制

- 直接复用项目已有 Three.js 的 `Quaternion.angleTo` / `Vector3.distanceTo`，依据 [Three.js 官方文档](https://threejs.org/docs/)，以及仓内 `cameraUtils.test.ts` 的 YXZ/lookAt 对照；不自写四元数或欧拉插值。
- 比较沿用原生贝塞尔与引入 CatmullRomCurve3：已有原生路径能表达所需三族并直通保存/导出，后者还需转换和时序重参数化，当前没有必要引入第二条样条链。未添加依赖；没有复写相机数学、播放器或二维拟合器。
- 纯适配无数量上限；正式数值限制为有限世界坐标、非零视线、单位四元数、0–180 度之间的 FOV，以及四分之一帧仍能由 JS 安全整数精确表示。0/负推近比例、非正角度、0/1 边界停顿比例直接拒绝，不夹紧掩盖错误。
- 本轮只测短段、有限机位单元夹具，不声称已达到长录制内存/延迟预算。全候选目前在调用线程编译与校验；接用户录制前须按上述 Worker/分批接口完成规模接线，不能因为测试快就直接在 UI 同步处理一小时数据。
