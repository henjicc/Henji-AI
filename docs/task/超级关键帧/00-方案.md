## 1. 产品决定与范围

用户摆出意图，算法先整理，大模型补充语义，用户选结果。剪辑支持「分时摆放」和「录制轨迹」；图片支持同一内核的静态布局。录制不等于播放，时间指针完全由用户掌控，可以 scrub，也可手动播放、暂停、讲话/操作后继续拖或播放。两端均提供 2–3 个有差异的候选、「保真 ↔ 美化」、钉住点、就地预览、一步应用与一步撤销，保存原草稿供再次优化。若约束只能产生一个不同结果，显示原因与原稿对照，不伪造三个相同候选。

P1 的首次价值必须是「摆/慢录飞入、在一点停顿、轻微过冲回弹 → 本地亚秒级候选 → 钉住终点仍保留节奏 → 一步应用/撤销」，并同时交付图片「几张图与标题粗摆 → 钉住主图 → 按边缘规整」。仅去抖、减点或把轨迹磨圆不能作为 P1 完成。回弹等明确动作可由用户点选语义，算法无需大模型；不能从两个端点无证据断言用户想弹跳。

录制讲解采集麦克风、当前应用内指针、时间指针、正式命令及元素状态差分；会话连续记录墙钟/时间轴双时钟。语音主路线经 `@henjicc/ai-sdk` 的带时间戳 ASR 转成文字；设置复用既有默认模型机制增加「默认转写模型」。其余数据全部转为结构化文本，必要时附有时间戳/指针标注的单帧或 contact sheet（§6.1）。原音只发送到获授权的转写供应商，不发送给后续意图模型；本地 ASR 为用户可选的离线后备。录制不自动执行口述命令；用户先校正，再提交给同一个应用执行入口。

四条产品原则的落点：

| 原则 | 本任务决定 |
|---|---|
| 先操作，再界面 | 草稿与录制会话为可寻址实体；整理运动、编译动作和解析讲解为同源算法；钉住、校正文稿、选候选走通用写入。 |
| AI 先做，人校正 | P1 即可免费生成候选；P2 才引入大模型，不把曲线编辑和布局参数作为起步门槛。 |
| 就地发生 | 在当前节目监视器或图片宿主展示预览，应用直接落在原片段/图层，不另开生成页面。 |
| 读回、可撤销 | 应用后读回曲线/变换及保存事实；整组候选只占一个原有历史单位；失败保留草稿。 |

证据与技术选型见 [01-调研与证据.md](01-调研与证据.md)，可独立派发的实施单见 [02-实施拆分.md](02-实施拆分.md)。下文的新字段、文件位置、能力名称均为**提案**，不代表当前已登记接口。

## 3. 数据模型与唯一状态源

### 3.1 墙钟、时间轴与音频采样域

墙钟表示真实经过时间，以会话起点为零的单调微秒 `monoUs`，不受 scrub、播放速度、系统日期调整或暂停影响；UTC 只记录创建时间。时间轴表示用户当时看见的序列位置 `timeline={sequenceRef,frame,fps:[num,den],visitRef}`，图片静态宿主为明确的 `null`。每个指针、命令、差分、标注、时间指针和控制事件均携带 `{seq,monoUs,timeline,clockSegmentRef}`；缺呈现证据也为 `null` 并写 unavailable 原因，不用请求帧顶替。语音另存原音频半开采样区间 `[startSample,endSample)`，不是视频帧。

`ClockAnchor` 保存 `{monoUs,audioSample?,audioSegmentRef?,audioRate?,presentedFrame?,requestedFrame?,sequenceRef?,playbackDirection,playbackRate,playing,epoch}`。`clockSegments` 保存墙钟半开区间、时间轴起止、模式 `play/hold/scrub/seek/gap` 与实测呈现锚点。播放按速率分段并用回执校正；暂停播放是 frame 不变的 hold；scrub 保存有序实际呈现关键点，seek 是跳变，不跨跳变插值；倒退使用递减 frame，不能假设全局单调或一一映射。音频启停/设备切换另建采样段；**暂停录制**才产生采集 gap，墙钟不重新归零。源素材时间复用 `src/core/videoEdit/time.ts:24` 的有理微秒契约，代码元素采用其宿主的源时钟。

关键帧/动作按时间轴时间编译，口语与操作的对应按墙钟匹配。ASR 音频相对毫秒先通过音频段 offset/重采样映射还原为采样区间，再映射到墙钟；绝不把异步转写完成时刻当说话时刻。词/句的墙钟区间可能跨多个时钟段，须保存 `timelineSpans[]` 和证据序号；不能只取起始帧就代表整句。播放暂停期间说的话对应该 hold 段的画面，不按说话时长推进关键帧，也不自动推断作品 dwell；作品停顿仍需时间轴区间或明确口述时长后确认。

P1 支持用户手动选择 1x/0.5x/0.25x 播放采集，也支持不播放而 scrub；不修改素材变速或片段时长。动作时间沿实际呈现帧；monoUs 与音频采样仍是真实时间。录完正常速预览，不再乘速率缩放一遍；无呈现回执时积分值只作 estimated 时间，不能自动绑定。慢录同帧样本仅在同 take 内按最终确认姿态归并，pins 冲突不能挪到邻帧。口述「慢一点」属于待审阅的动作时间意图，不改变采集时钟。

每个指针事件记录：窗口内 CSS/DIP 坐标 `viewPoint`、文档坐标 `documentPoint`、当前显示画幅归一化坐标 `compositionPoint`、`surfaceRef`、`geometrySnapshotRef`。几何快照含画幅、letterbox 有效矩形、缩放/平移、裁剪/方向、图层祖先变换、像素比及窗口归属。通过共享逆变换换算；图像外留白、奇异矩阵、失焦或缺帧标为 unavailable，不能夹到边缘后假称命中。

图片的 documentPoint 是未裁剪文档单位；compositionPoint 是当前输出画幅的比例。负坐标或 >1 的位置可表示画幅外意图，是否可提交由宿主真实 schema 决定。剪辑片段 x/y 的原有含义不能当作指针绝对坐标；以当前合成状态反求位移、枢轴和局部缩放。

采集必须关联**实际已呈现**帧及其命中几何；请求播放头 `requestedFrame` 与呈现回执分别记。等待新帧时若仍显示旧帧，记录旧帧及延迟质量；没有可靠回执则不自动绑定。记录覆盖拖动、播放、暂停、倒退，改变方向/跳转只拆动作计算段，不结束录制会话；`visitRef` 区分多次访问同一帧。

### 3.1.1 找位置、示范、倒退与撤销

- 默认拖时间指针是 **navigate（找位置）**，仅记录定位轨迹与画面证据，不从播放头运动生成元素动作。元素拖动/旋转/缩放是 **demonstrate（示范）**，在当前实际时间轴位置写草稿姿态；暂停时摆多个姿态只作同帧候选，不能把墙钟等待变成动画。
- 提供「示范运动」显式模式及修饰键临时切换（键位由既有快捷键登记核对，不预占冲突键）。示范模式下，scrub 同时存在元素预览姿态变化才记录连续运动；单指针操作可先摆姿态再拖时间、反复摆放，均用同一时间轴锚点。纯指针比划须用户明确标为路径示范，不能将 hover 当目标运动。模式/修饰键变化也记录双时间，触控板/键盘有显式控件替代。
- 倒退找位置只增加证据；倒退示范按墙钟先后保留完整原稿，按时间轴方向拆 monotonic take，编译时在各 take 内将时间排序升序并保留正确姿态/方向，不全局排序合并，不将负速度再次反转。跨 take 重访同帧的不同值须选择采用哪次示范或明确替换；同帧 hard pins 互斥仍拒绝，不默认最后写入覆盖其他 take。零时间跨度的姿态变化可确认最终姿态，不能推断其动画时长。
- 讲解中的正式编辑/撤销/重做均走原命令总线，记录 `operationRef`、undo/redo 指向的原操作、双时间与实际前后差分。事件账本只追加，不擦除曾发生的动作；当前有效状态由正式回执及末态决定。失败/取消的命令不是已发生变更。动作草稿模式的草稿撤回与作品 undo 分开标记；候选应用才占作品历史。口述「撤销刚才」仍为未执行意图，提交只补尚需完成的差异，不能重放已撤销/已执行的命令。

### 3.2 MotionDraft（动作/布局草稿）

| 字段 | 语义与所有者 |
|---|---|
| `id,version,ownerRef,mode` | 文档拥有；mode 为 animated/static。version 为持久格式版本，与作品 revision 分开。 |
| `targets[]` | 完整 ApplicationRef、可编辑属性、采集时对象几何与基态摘要。引用包含文档/序列归属，不靠名称匹配。 |
| `takes[]` | 一次分时摆放或明确示范；每段有墙钟区间、时间轴范围/方向、visitRef、画幅基准、双时钟锚点、navigate/demonstrate 来源与不可变 samplePages。区分动作草稿预览与讲解事实记录；seek/倒退/重访拆计算段但会话不断开。 |
| `samples`（分页资源） | `{sampleId,seq,monoUs,timeline,clockSegmentRef,targetRef,position,rotationTurns,scaleXY,pivot,gestureKind,quality}`；位置/尺寸为比例语义，保留实际原值供无损复核。静态 timeline=null，monoUs 仍表示操作先后。 |
| `pins[]` | `{sampleId,targetRef,properties,timeLocked,valueLocked}`；默认钉住该点的全部采集属性及时间。图片锁定位置/尺寸/角度；部分锁在高级编辑明确选择。 |
| `constraints[]` | typed union：对齐、等距、直线/弧线、对称、目标区域、字幕/节拍锚点等；有 soft/hard、来源引用和采集时效。P2 加已确认参考元素局部坐标约束，含 referenceRef/参考时钟/几何身份及 bake 或正式宿主已有绑定语义，不自动改父子层级。没有开放 patch。 |
| `recipeRefs[],candidateRefs[]` | 配方与编译结果的不可变资源引用；带 sourceDraftDigest、算法版本和目标基态摘要。 |
| `applications[]` | 候选 → 正式历史/操作回执关联、输出曲线范围/图层、保存状态；手改后的曲线拥有权由正式宿主维护。 |
| `label,fidelity,selectedCandidateRef` | 用户可改设置，走通用实体属性。fidelity=1 保真、0 美化；界面用百分比语义。 |

原始采样不被滤波、模型或滑杆覆盖。草稿修订创建新输入身份；候选只能引用对应输入。模型不能新增/删除钉住点，不能改变目标集或临时放宽 hard 约束。

图片随手摆可以录下多个图层的粗布局，优化取每个图层最后确认姿态；过程轨迹留作讲解证据，不编译成图片动画。group 作为目标时保持组内相对关系；对子图层操作须反求祖先变换。P1 不自动重排父子层级；P2/P4 可提出明确层级配方，用户预览后应用，禁止猜测新分组。

| `annotationRefs` | 剪辑标注或图片正式文字/路径图层，附创建/修改的双时间、snapshotDigest、时间轴有效区间及角色；文本投影包含几何/文字，不复制作品图形。 |
| `visualEvidenceRefs` | 可选单帧/contact sheet 的受管引用、来源状态/几何/实际帧、双时间、指针坐标、选帧原因与图像预算；复用正式观察/附件，不连续录屏，不默认外发。 |
| `bindings[]` | 词/句跨度 → entity/point/region/path/timeRange/set；墙钟证据窗口、时间轴访问段、来源事件/图像、歧义候选、人工修正、置信类别。句级不伪造 wordId。 |
| `segmentExclusions,corrections` | 用户排除录音片段、合并/拆分词和修正指代，保持原 sample 区间可追溯。 |
| `submittedPlanRef,appliedReceiptRefs` | 审阅后的计划与正式执行事实；不是可重放的鼠标脚本。 |

语音、指针、命令、差分、标注及时间指针分流采集后按 `(monoUs,seq)` 合并，页含双时钟区间、条数与校验摘要；同墙钟序号用于稳定排序。pointermove 可用 coalesced events；不假设每条输入都得到一次渲染。命中是当时文档事实，不用现在的图层树回填。隐私 gap 不补造采集事件；恢复时重新取呈现/音频锚点。

**录制中的实际编辑已经发生。** 普通操作仍进入原撤销栈；讲解模式只记录事实。提交时用当前状态和会话末态计算尚需完成的差异，不能把录过的命令再执行一遍。口述「撤销刚才」「别动这个」作为未执行意图处理；录制时真正按撤销键则记录已发生的 undo。

### 3.4 存放、落盘与 dev-break

提议在所属剪辑/图片文档增加同一 `creativeIntents` 头结构，存 draft/session 目录、页引用和应用关联。中立模型由一个纯 schema 定义，两端 descriptor、领域读写和导出使用该定义；不把原始轨迹放 assistant history、localStorage 或第二套 Zustand Store。文档唯一实例拥有状态、历史和保存；页面只订阅。

| 载荷 | 拟定存放与生命周期 |
|---|---|
| 图片页/候选/可选音频 | 既有图片受管资源及 `.henjiimg` 包内资源；扩展 retainedResources/live set，保存、导出/重开与历史均引用同一资源。 |
| 剪辑页/候选/可选音频 | 文档相邻项目 `.henji/intents/<documentId>/` 的受管内容资源；由现有 documents 文件/资源搬运与项目包服务管理，owner 头只存相对/受管引用。此子目录与资源种类是新增设计，尚非现成接口。 |
| 采集中页 | 已有工作副本/临时资源机制内的 append 分块；完成后校验、独占发布，再原子更新 owner 头。默认原音暂存见第 9 节。 |
| 未完成资源 | 以会话/操作租约保护；重启仅恢复已封页数据，尾页截断明确提示；孤儿资源在保存确认和 live-set 校验后回收。 |

页按字节/时间工作预算切分，起步可选约 1 MiB 页与每秒 checkpoint（**待压测**），不限制草稿点数、会话时长、目标数或作品规模；头目录分页，索引按时间/引用查，UI 虚拟列表。单次内存、模型上下文、安全整数、有理时钟、设备输入和磁盘余量是真实技术约束；资源不足时可暂停/释放/分段续做，不截掉已采集数据。

必须完成：双端 writer/reader → 文档 descriptor → 资源收集/GC → 单文档导入导出/项目复制移动/包 → 历史引用 → application-control 读取。单独图片跨项目导出要携带页，不允许只在原项目里可重新优化。录制数据不默认进素材库；明确导出才进入正式跨域媒体来源。

实现期在 `src/core/persistence/formats.ts` 登记共享页/配方格式（拟 ID `creative-intent-page`、`motion-recipe`）及双方实际变化格式；更新 `document.video_edit`、`document.image_document`，并按真实影响核对 image-working-copy/image-package/project-package 等登记。提高版本，生成当前黄金样本，用 `persistence:baseline -- --dev-break <实际受影响格式> --reason <具体原因>` 留审计，不写旧数据迁移、不手工覆盖他人的 baseline。当前本轮不执行这些命令。依据 `docs/rules/persistence.md:23` 起的开发期策略。

保存成功以原持久化屏障确认为准；写盘失败保留内存修改和未发布页，重试只保存，不重复编译/应用。资源 I/O 由主进程协调，计算走 Worker/utility process；共享 core 被主进程引用时只用相对导入。复用现有结构化 logging，不另建日志文件/查询 IPC。

## 4. P1：纯算法优化与钉住约束

### 4.1 原稿到候选

1. 校验时间/变换/目标有效性，按 takes、跳转、缺口、姿态不连续处分段。目标开始已有 curves 时，基态用当前求值姿态，不能只读静态 clip.x/y。
2. 留存原样本；另建计算视图。按采样间隔重采样，unwrap 旋转，缩放在正值域处理；冻结点击、松手、停驻、反向、钉住点与已确认端点。
3. 实时显示采用成熟 One Euro Filter 基线，原样本另存；预测事件仅作瞬时显示，不落原稿。最终离线拟合按误差/速度/时间约束处理。`simplify-js` 仅为分段减点；`fit-curve` 为空间拟合基线，硬锚点拆段仅保位置连续，不能假定切线连续。固定约束先消元/拆段，需要光滑接合时联合切线；比较带线性约束的 OSQP，禁止拟合后逐点 snap 改坏邻段。证据与替代选型见 03 第 4 节。
4. 空间 C(u) 与有序时间 u(t) 分开，停顿单列 dwell；非停顿段比较单调映射，不全局弧长匀速化。硬事件先冻结，短段比较 DP/事件规则，长段分页/剪枝不全量二次方匹配。直线/圆弧/镜像用误差、停驻和方向判别；图片固定尺寸/角度时的线性对齐/边缘等距优先比较 LUME Kiwi，不宣称能解所有非线性遮挡。保留锁定图层、分组和用户确认顺序。
5. 本地候选保留原稿，并描述具体差异，例如「保留停顿、减少抖动 / 轻微过冲回落 / 按指定焦点推近」。P1 接受用户明确点选动作意图，提供 move_line/follow_path/dwell/overshoot/spring_settle/scale_focus 的确定性子集；识别只对有证据的停顿/过冲，不以两端点猜弹性。图片 P1 为「贴近摆放 / 对齐等距」，不擅自改文字、尺寸、层级；语义「重点突出」到 P4-2。
6. 按第 6 节编译，并对**正式宿主求值后的结果**验证误差、硬锚点、范围和碰撞提示。编译失败的候选不可应用，原稿继续可用。

目标函数（设计表达，具体权重**待标定**）：

`E = w_f * 原始姿态误差 + w_j * 加速度/jerk + w_t * 节奏偏离 + w_g * 几何/布局偏离 + w_r * 配方复杂度`。

fidelity=1 时，以选定 take 内正式帧最后确认姿态作原稿对照，保留姿态/节奏；跨 take 重访先解决采用/替换，不全局按最后样本覆盖。稀疏拟合达不到编译误差就保留密集合法帧点，不能一面承诺完全保真一面强制少点。原连续亚帧采样仍另存，不声称宿主整数帧可无损表示全部输入。fidelity 降低可放宽 soft 误差与增强已明确原语，默认不删除显著停顿/峰谷。滑杆不线性混合两条不相容配方，而是重算该候选族的权重；缓存同源参数结果，只在用户明确请求语义重解时再调用模型。fidelity 不影响 pins 和其他 hard constraints。

P1 拟定显示误差预算：保真编译在 4K 画幅短边约 0.05% 内，位置由画幅比例表达；钉住属性按宿主序列化的数值精度相等，钉住时间精确落在正式帧。该预算是**拟定验收值，未实测**，须从导出像素/正式求值验证，不能靠拟合器自身的 error 参数代替。

动作测试集、正式曲线编译与原稿意图误差的区分、停顿/峰谷时刻、稀疏关键帧参考、拒识、人眼与省操作门槛统一按 03 第 5 节。pins 是硬等式，不以巨大 soft 权重模拟；所有评分不能抵消硬失败。P1 过该基准才可验收。

### 4.2 冲突与拥有权

- 钉住点之间同帧同属性冲突、不可能同时满足的 hard 对齐、目标不再存在时，返回具体冲突引用和可解方式；用户决定解钉/改时间。不能自动移点、合并 pins 或改锁。
- 多个原始样本落同视频帧：普通样本按该帧最后确认姿态归并；两个不同硬姿态在同帧即冲突。不偷偷抖到邻帧。
- 应用前复核目标、草稿和几何输入身份；网络等待不锁编辑。状态变化后候选标为「画面已变化，请重新预览」；重新优化保留原 take。
- 再次优化默认生成新候选，不覆盖已经手动编辑的普通关键帧；应用覆盖范围须预览。曲线引用用 owner/target/property/timeRange 和正式操作身份，不为每个现有无 ID 的 keyframe 假造独立实体 ID。
- P1 不自动触碰 opacity/volume、deformation 或源码。第一批覆盖片段位置/统一缩放/旋转，图片平移/缩放/旋转与静态对齐；图片已有非均匀仿射不能被降成统一 scale。进阶能力明确扩展目标属性，不开放任意字段。

## 5. 词、指针、操作与标注的对齐和指代解析

### 5.1 对齐步骤

1. SDK ASR 词/句时间通过音频段 offset/重采样映射换成 sample、monoUs 区间，携带 uncertaintyUs；再读分段时间轴与实际呈现证据。句级只作粗窗口。采集音频以 AudioWorklet sample counter 为准，不能用 MediaRecorder 数据块抵达时间推算说话时间。
2. 在词附近取指针停驻/点击/拖拽关键事件及其**当时**命中几何、已呈现帧。起步搜索窗口为词前 700ms、后 500ms，最多在同一语句/无 gap 范围内扩到约 2s（**待确认**）；这是对齐预算，不是会话数量上限。
3. 遍历同期可见目标，计算空间距离/路径重叠、停驻、点击/选中、正式命令目标、语义属性和上下文显著性。UI 浮层覆盖时优先报告控件位置，不穿透假称指向图层；pointed 与 hovered 分开。
4. 标注几何及时间先给确定约束，文字说明给软语义；用户修正的绑定最高优先。显式指代对象优先于当前选中，单靠 hover 不自动成为 hard 约束。
5. 用句内顺序匹配多个指代，保留候选及证据；采用有序槽位匹配/动态规划或 beam 搜索比较整句 target/source/destination/dwell/exit，不能逐词独立取最近点。初始评分如 `时间 .30 + 几何 .25 + 停驻/点击 .20 + 操作目标 .15 + 语义/历史 .10`，仅用于排序，**不是校准概率**。确认阈值须由中文讲解样本标定；低置信、两个候选接近或语音对齐质量差，留 unresolved 让用户点选。DTW/HMM 只作适当离线对照，不能据未校准分数自动确定对象。
6. 输出绑定后的意图及「已发生操作 / 尚未执行意图」分离计划。任何执行前用当前正式状态读回，不能拿历史指向位置改错新对象。

研究支持结合时序、显著性和历史；上述窗口、权重与阈值是痕迹AI的工程提案，不是论文结论。鼠标运动与人体手势差别大，不沿用论文准确率作为验收标准。

### 5.2 语言规则

| 说法 | 绑定规则 | 歧义/恢复 |
|---|---|---|
| 「这里」「那边」 | 优先绑定同词时段的停驻位置/区域；若鼠标在时间线上，解析为时间点/区间，不能当画幅位置。 | 只有区域不自动选图层；缺指针时用明确标注或请用户点选。 |
| 「这个」「那个标题」 | 当时命中实体 + 名称/类别 + 操作目标；父组/子元素保留候选。 | 重叠对象、同名、不可独立编辑的栅格内部内容需校正或进入 P4 主体识别。 |
| 「从这到那」 | 在语句顺序上建立 source/destination 两槽，分别对齐两个指代及相关拖拽起止；箭头尾/尖端可补证据。 | 同一指针停驻不能无证据填两个不同槽；缺目的地就留缺口。 |
| 「在这里停一下再弹回来」 | 位置约束 + 时间停驻/当前呈现帧 + dwell/bounce 配方；帧与录音时刻分开。 | 缺「一下」时长则给候选或用户校正，不能假称用户指定精确帧。 |
| 「这里停一下」「这段慢一点」「再弹出来」 | 录后解析位置/时间作用区间/动作类型，区分录制暂停与作品停顿；生成可预览时间配方。 | 慢一点不改采集时钟；弹出可能是离场或缩放出现，关键属性/方向不明先确认。第一版不实时执行口述。 |
| 「这几个对齐」「这边一样」 | 圈选/多选集合为目标，位置指向为对齐参照；保持集合顺序。 | 集合用完整稳定引用，分页不是截取前 N 个当全部。 |
| 「刚才那个」「别动它」 | 结合本会话已确认话题及最近正式操作，绑定对象；可形成锁定建议。 | 跨删除/重建不按名称复活引用；pins 只有用户明确确认的锁定意图才落地。 |

### 5.3 标注参与方式

剪辑复用 `video_edit.annotation` 的 target/frame/clipId/thread；图片读取 `image_edit.layer` 的 text/shape/path content、祖先 transform 和实际输出几何。会话只增加引用关联与意图角色 `source/destination/keep/align/path/note`，不再保存一份箭头/圈的形状。

- 箭头尖端指向实体或目的点，尾端指来源；曲线箭头可提示路径。箭头作为方向建议，除非用户确认，不自动当不可改变的路径。
- 圈/闭合路径用现有矢量/区域核做真实包含与重叠，文字用原文本内容；没有几何语义可识别的装饰路径保留 unresolved。
- 标注有时间范围；只对同期元素起作用。图片的静态标记还要核对文档几何与图层版本，裁剪/旋转不能把旧圈重新解释到新位置。
- AI 将处理回复写 addressed 并追加讨论，不能自己 resolved；现有剪辑状态约束见 `src/core/videoEdit/annotations.ts:45`。图片标注属于作品内容，默认保留；是否隐藏/删除由用户明确选择。
- 纯文本模式拿不到栅格内部主体边界，不宣称「看懂画面」。P4 的本地主体/跟踪可补结构化区域；结构不足或涉及外观/草图时按 §6.1.2 附图，不能把一张图当完整跟踪结果。

## 6. AI 输入、动作配方与普通关键帧编译

### 6.1 紧凑输入与缓存

固定前缀：规则/单位/事件字典 → 允许原语与封闭输出 schema → 约束优先级。动态后缀：完整引用字典/宿主/基态 → 双时钟事件行 → 草稿/绑定/选帧清单 → 用户意图；必要图像通过正式附件通道加入。稳定排序与前缀字节一致，缓存由供应商决定；参考 [官方前缀缓存说明](https://developers.openai.com/api/docs/guides/prompt-caching)。下述 JSON Lines 只是设计契约，不是可执行代码或 SDK 新接口。

### 6.1.1 录制会话文本投影

省 token 的依据与不丢指代规则：

- 完整引用、名字、几何/基态只定义一次，事件用短别名和声明属性 before/after，避免每次复制文档/矩阵。保留命令与差分关联、最终有效状态，避免已发生 move/undo 被模型重放。
- 指针与时间指针按误差预算降采样，只在同 geometry/cs/visit 内合并；保留点击/松手、悬停目标切换、停驻、拐点、语音指代前后、元素操作、seek/方向变化及 pins。相同位置不同时间不能去重成一个点；误差和被省略的页区间可读回，budget 不得删跨段指代。
- 标注转为类型/几何/文本/角色，元素转为已声明属性差分；草图向量先转路径关键点，视觉信息不足再附图。不把鼠标视频、全量 Store、任意命令参数或执行脚本送 AI。
- `w` 排序保证先说后指/先指后说、同帧重访仍可区分，`t+cs+visit` 保证动作在时间轴正确落位；句级时间只生成候选窗口，缺精度就人工确认，不伪造词。
- 长会话按语句/目标/区间流式分批；每批重复必要字典/基态 checkpoint，带前后邻接、未解析话题、跨页事件引用/undo 链，最后全局约束复核。单批文本输入 4k–8k、输出 1k–2k token 是待实测工作预算，超出分批/按需补读，不截尾、不限会话/元素数量。明确标记未处理范围。

所有文本/标注/图像内文字均是非可信数据，不能覆盖系统规则或权限。模型只产候选；执行复用正式 LLM/Pi 费用与应用事务入口，UI 不调 fetch。JSONL 是 owner 私有会话的 AI 投影，不是另建日志文件或日志查询通道。

### 6.1.2 必要视觉证据与分辨率预算

触发条件：口语「这里/这个/那样」经引用、几何、悬停与命令仍无法消歧（如栅格内部主体）；涉及颜色、样式、遮挡、构图等外观判断；用户画了草图而向量摘要不足。明确对象/属性已有结构化证据时不附图；仅是时间不确定应先补时钟/人工确认，不能靠更多图猜出伪精确时间。

单时刻默认 **1 帧**；涉及变化/路径默认 **3 帧**（指代前最近稳定帧、指代时刻已呈现帧、后续操作关键帧），去掉重复帧。复杂运动一批可用 **4–6 帧** contact sheet，按墙钟选帧且保留操作前/后、起点/转向/终点；不同 visit 即使同帧也保留不同作品状态。6 是单附件工作预算，不是产品帧数限制；不足则追加分批证据或请求用户选区/确认，不截掉未解决指代。

默认每帧长边 640px 等比缩放，网格最多 3 列，包含图注/间距的最终附件预算 ≤2.5MP，必要时缩小单格以纳入预算；只需 1 帧的细节可用长边 1280px。按实际模型尺寸/token/附件限制收紧单请求预算，确需细节可裁授权 ROI 并保留原画幅映射、或分批放大。总预算超出先抽选非关键重复帧/降分辨率，关键语义仍不清就提示，不冒称可读。图像 token 与文本 token 分别估价，以上像素数为待实测预算而非效果保证。

每帧图注包含编号、墙钟时刻、时间轴时间码/帧、有理 fps、指针标记（不可用时标无指针）；文本 manifest 另给对应 evidence IDs、cs/visit、q、来源状态与选帧理由。坐标随缩放/ROI 映射，不能把指针覆盖关键外观；保留不带叠层的源用于复核。单帧/contact sheet 用既有图像/合成/附件组件，不自研图像管线；拼网格是呈现编排，不新增模型执行器。

来源优先当时受管素材+作品快照经正式宿主重建；不可重建且需要当时外观时，在已说明范围内采集少量应用内视口关键帧，保存私有受管资源，不录桌面或连续屏幕视频。历史图不存在/资源已变就标缺证据，不能用现在帧冒充过去。复用正式观察范围及 sensitive 遮罩；发送前可预览/移除并核验图像外发授权。纯文本模型遇必需图像，提示选择现有支持图像的模型或手动绑定，不能把附件引用文本当看过图像。

### 6.2 动作配方 schema（设计契约）

固定根字段 `version,mode,candidates,unresolved`，每级 `additionalProperties:false`；version=`motion-recipe/1`。正常返回 2–3 个不同候选；约束只能生成一个时允许一项，并在 unresolved 说明原因；全部不可行时不生成成功配方，返回领域失败。有限枚举/数值约束由 Zod 唯一声明并投影；以下定义供实施落成真实 schema，不是当前运行接口。

基础类型：`Point=[x,y]` 为两个有限数，使用请求指定的画幅比例坐标，允许画幅外坐标；`ScaleXY=[sx,sy]` 两值均大于零；`Pose={p:Point,scaleXY:ScaleXY,turns:finite,pivot:Point}` 为封闭对象。旋转单位为完整圈，宿主度数在适配时转换。所有 point、pivot、半径和间距都必须引用同一请求几何基准，不混用窗口像素与文档单位。`Target` 为本请求 refs 中已获可编辑权限的别名；`SampleId`、`draftSegmentId` 必须属于输入草稿，不能由模型臆造。

| 类型 | 封闭字段与规则 |
|---|---|
| Candidate | `id,label,recipe`；id 请求内唯一；label 为简短用户说明，不含内部状态。 |
| AnimatedRecipe | `actions[]`、`preservePauseSampleIds[]`；actions 非空、不设总数产品上限，单次返回受上下文预算分批。 |
| Action 公共字段 | `primitive,target,spanF:[start,end],timing:{kind:'linear'\|'bezier',bezier?:[x1,y1,x2,y2]},params`。target 从本请求可编辑 refs 动态枚举，spanF 递增且在请求可编辑域；x 控制点 0–1、y 有限。 |
| Action params | 由 primitive 判别的 strict object，见下一表；所有向量长度固定、数值有限。不能传源码、表达式、脚本、任意属性或任意 patch。 |
| StaticRecipe | `operations[]`；strict union：align `{targets,axis,edge,reference}`、distribute `{targets,axis,gapRatio,reference}`、symmetry `{pairs,axis,reference}`、pose `{target,p,scaleXY,turns}`、layer_order `{parent,orderedTargets}`。axis=x/y，edge=start/center/end，引用只可来自已声明目标/参照；层级操作须 capability availability 明确允许。 |
| Unresolved | `{wordIds,utteranceIds,reason,candidateTargets}`；仅句级时 wordIds 为空、以 utteranceIds 引用真实句子，不造词时间；不能请求私有路径/音频/额外授权。 |

根 mode 与 recipe 必须一致，animated 只允许 AnimatedRecipe，static 只允许 StaticRecipe；引用集合和属性可用性由本次宿主动态注入。没有语音词的约束冲突，Unresolved.wordIds 为空数组，reason 仍须说明可行动原因。StaticRecipe 的 targets 不少于操作所需数量，orderedTargets 必须是同一 parent 下获准重排的完整集合，不可遗漏兄弟层后偷偷改变层级。

原稿 pins 和 hard constraints **不由模型输出**。编译器将原始约束作为不可覆盖输入；模型只给软意图配方。所有同目标同属性的动作区间不得重叠，除非编译器具有明确的已声明组合规则；第一版按顺序分段，重叠拒绝，不猜 additive/replace 优先级。

完整首批 14 个运动原语（P1 实施其中明确子集，P2 补全识别；单位由意图字典解释，比例不是像素）：

| primitive | params 的全部字段 | 编译/识别要点 |
|---|---|---|
| `move_line` | `from,to` 两个 point | 明显直线；端点 + 同步 x/y 时间缓动。 |
| `move_arc` | `from,to,bendRatio` | 中间弯曲方向由有符号 bendRatio 指定；几何弧采样再编译。 |
| `follow_path` | `draftSegmentId` | 原草稿段的空间样条与原时间映射；引用必须存在。 |
| `orbit` | `center,radiusXY,startTurns,sweepTurns` | 椭圆/圆中心与角范围；保护象限/极值和圈数。 |
| `overshoot` | `from,to,amountRatio,settleFraction` | 位移峰值 + 回落；端点等值仍须生成峰值。 |
| `bounce` | `from,to,heightRatio,count,decay` | 分段抛物线/落地峰谷；count 为正整数，计算按实际时间分批，不写小产品上限。 |
| `spring_settle` | `from,to,damping,cycles` | 明确阻尼和振荡，有限区间解析采样；不是调用任意物理脚本。 |
| `swing` | `pivot,amplitudeTurns,cycles,decay` | 以枢轴往返旋转，经过零点和极值。 |
| `pulse` | `baseScaleXY,amountRatio,cycles` | 缩放脉冲，保持正尺度；不改不透明度。 |
| `spin` | `pivot,startTurns,sweepTurns` | 保留完整圈数，不能用最短角距离消掉多圈。 |
| `sway` | `center,axis,amplitudeRatio,cycles` | 小幅往复，轴方向需明确，不能被平滑成停留。 |
| `zigzag` | `from,to,amplitudeRatio,count` | 保留拐点与节拍，可选公共 easing；不圆滑掉用户硬拐点。 |
| `scale_focus` | `pivot,fromScaleXY,toScaleXY` | 以指定锚点缩放，图片静态 pose 共用枢轴数学。 |
| `dwell` | `pose` | 保持 pose 的时间区间，编译边界 hold；停顿是意图，不是多余点。 |

数值语义校验：decay ∈ [0,1]，damping ≥0，settleFraction ∈ (0,1)，尺度分量 >0，cycles/count >0；radius/amplitude/height 的尺度随画幅或对象基准明示。所有 p/pose/from/to 有完整类型定义，旋转为 turns，绝不混用度/弧度。模型不能改变允许属性，不能绕过宿主变换范围。无法区分 bounce/spring 时保留 follow_path 候选与歧义说明。

### 6.3 编译规则

1. 解析封闭 schema → 别名转正式引用 → 验证允许属性/动态可用性 → 合并原稿硬约束 → 构建位置/旋转/尺度随有理时间的函数 → 宿主量化 → 原有 schema 校验 → 正式求值误差检查。
2. 普通片段曲线时间为 `sequenceFrame - clip.start`；代码元素参数沿原 sourceInUs/sourceRemainder 映射，受速度/倒放/修剪影响。源/序列映射用正式时间服务，不独立写一套时钟。
3. 空间曲线 C(u) 与时间映射 u(t) 分离。现有 bezier 是标量值进度随时间的缓动；两点相同进度的 x/y 曲线只能形成直线。弧线/环绕先在极值、硬锚点和拐点拆段，对 x/y 各自拟合可表示的缓动，误差过大就自适应增加普通关键帧。不能把空间控制柄直接塞入 `[x1,y1,x2,y2]`。
4. 局部值相等却中间变化时拆出极值；反弹/弹簧保留峰谷。离散属性 hold。边界沿正式求值规则；修改范围外曲线保持原样，在交界处增加必要边界点、检测跳变，原 easeRange/easeValues 用正式切片保持。
5. 对钉住点先按宿主帧网格创建精确节点，再分段拟合；每个硬锚点必须在正式求值下相等。同帧冲突明确拒绝。
6. 旋转 unwrap 后转换到宿主单位。当前普通片段 rotation 为 [-360,360]（`src/core/videoEdit/keyframes.ts:20`），不支持任意多圈无缝值：第一版超过其表示域的 spin 明确拒绝并说明；若后续放宽，需正式公共字段、渲染/导出及持久版本一起改，不能 wrap 角度造成突跳。
7. 不靠 clamp 掩盖 pins/原语不可表示。尺度/位置范围继承当前宿主声明；超范围返回目标、属性、允许域与调整建议。片段只有统一 scale 时不能假装支持 scaleXY。
8. 图片编译输出完整仿射/正式图层顺序命令，复用 inverseAffine/composeAffine 与原图层命令；不烘焙像素、不新建动画求值器。
9. 原语识别/候选均不进入播放/导出实时路径。应用后的普通关键帧/图层变换就是作品真相，配方是可重新优化的来源记录；手改曲线不被配方自动覆盖。

### 6.4 循环、错峰、相对动作与动作预设（t140 采纳）

不在 14 原语里塞递归执行脚本。P2 在同一 strict recipe 中增加封闭组合声明，编译期展开成原来的 actions；模型只可引用已声明模板，禁止任意表达式。所有数值有限，具体字段由 P2-1/P2-4/P2-5 合成唯一 schema；下表是设计提案，并非已注册接口。开发期直接以新目标修改读写/导入导出，不留旧协议兼容分支。

| 组合/资产 | 必需语义 | 编译与兜底 |
|---|---|---|
| cycle | templateRef、单周期时长/相位、loop 或 pingpong、repeatSpan、接缝/转向策略 | templateRef 属于本配方/授权预设，模板为非递归原语序列。只在有限可编辑区间展开，不传 Infinity；检测闭合位置与速度，单程不自动循环。尾部截断须预览，不能悄悄改pins |
| stagger | templateRef、orderedTargetRefs、relativeBasis、间隔/起始方式、目标应用区间 | 多元素各按自己基态复用位移与尺度比，顺序可读/可改；批量编译后全局约束验证、一次提交。超片段范围先给可选处理，不静默裁尾 |
| relative_motion | referenceRef、referenceClock、坐标基准/偏移、bake 或宿主已有正式绑定 | 按参考随时间变换反求局部动作，引用环/奇异逆变换拒绝；默认不重排父子层级。烘焙候选绑定参考输入身份，参照变更须重预览 |
| motion_preset（拟资产类型） | label/tags、封闭recipe、属性/宿主适用面、比例/锚点基准、时长映射与确认约束 | 作为非媒体结构资产进既有素材库/正式读写，不另建库；不带私人录音、词稿、原目标引用与用户pins。语义锁需参数化并在新目标上重新确认；引用模板须随导出物化/钉版本 |

应用预设前检查可动画属性、尺度/角度表示域、时间与几何基准；助手沿通用实体查/增删/标签写入，实例化与编译走现有算法入口。不为「保存为预设」新增同义工具。静态图片接静态布局/姿态，动画预设只有用户选定某时刻的姿态或导出媒体才可进入图片宿主，不能凭跨域复用承诺图片动画。参考产品的错峰/循环语义见 [Motion stagger](https://motion.dev/docs/stagger) 与 [animate repeat](https://motion.dev/docs/animate)，不引入其第二套播放运行时。

## 7. 共享内核、服务与宿主适配

拟新增 `src/core/creativeIntent/`：持久 schema、时钟/几何快照契约、采样分页索引、约束、拟合、原语配方、指代解析、输入压缩。该目录为**拟建模块**。时间维度为可选的有理轴，static 是无时间轴的姿态/布局特例；语音事件始终有会话时间。

中立内核输出 typed intent/candidate；宿主提供 adapter：readTargets、mapTime、resolveGeometry、preview、compileToNativeChanges、commitAtomic、readResult、flushPersistence、retainResources。adapter 不重复算法/schema，core 不导入 Store、UI、Electron、助手或 provider；只调用中立 transforms/vector/regions 现有模块。

剪辑 adapter 在 `features/videoEdit/application/`，委托 videoEditService 和 keyframes；图片 adapter 在 `features/imageEdit/v3/application/`，委托 command bus/图层服务，工具箱与画布 full/canvas-edit 共用。轻只读宿主可读/预览，不偷偷开放写；新增入口按原 host profile availability 判断。

CPU 拟合/重采样/事件压缩放 Worker；ASR 请求、结果解析与协议走 SDK 能力模块，主进程只协调受管音频、授权、凭据、上传 transport 与长任务。可选本地 ASR 才复用 local-inference 的隔离进程/模型管理。实时 overlay 和 contact sheet 复用正式合成/图像组件，不另造 GPU 管线；本任务不引入未经验证的 VGPU API。

长任务绑定 owner、实例代次、输入身份和取消信号，页面切换不能把结果写到新文档；关页面不默认结束已经提交的算法任务。麦克风失焦/离开授权宿主则暂停采集并明显告知；网络取消后的迟到候选只能保存到原操作，不自动应用。

具体预算见 03 第 6 节：P1 ≤10s/1200样本/1目标，暖Worker全部候选含编译、校验、实际预览 P95≤900ms；录制输入至姿态显示 P95≤50ms。长录制分页写盘，采集链增量RSS拟≤128MiB、长段计算≤256MiB；超预算要有背压暂停/续录、可取消和渐进处理，不设置录制时长或元素数量上限。这些是待测工作预算，不是当前性能事实。

P4 扩展宿主只复用适合的内核：cameraStage 的三维路径/时间事件通过既有机位服务与完整 state_keyframe 应用，不能另持久化派生轨道；代码参数只接正式可动画属性与源时钟；蒙版路径先解决拓扑/点对应和正式逐帧表达；白板先确认真实入口与坐标/历史契约。二维仿射与三维朝向/光学量不强行共用同一种Pose，每个adapter独立验证表达误差、撤销与保存。HDR/高级色彩不在此方案范围。

### 8.1 超级关键帧 / 随手摆

- 剪辑现有节目操作命令组加入「超级关键帧」，分段选择「分时摆放 / 录制轨迹」。录制开始不自动播放，用户自由 scrub 或手动播放/暂停，可选0.5x/0.25x；「找位置 / 示范运动」明确状态与显式控件，修饰键只作临时切换。停止后正常速看草稿。动作采集只改草稿/预览，应用才写作品；讲解中的普通编辑仍写作品，开始前区分。普通移动模式仍按下暂停。
- 录轨迹支持位置/旋转/缩放模式切换与原快捷键注册中的修饰键（最终键位待冲突核对），也提供显式控件供触控板/键盘使用；切换起点增量归零并保留当前姿态，不让鼠标跳跃生成突跳。各属性用同一采样时钟，未操作属性不补造动作。
- 图片现有变换工具组加入「随手摆」，多选后粗摆；一次草稿可覆盖多个图层，锁定层显示不能修改原因。摆放预览期间不刷整页，不反复保存每条 pointermove。
- 草稿点/轨迹叠在当前合成画面；钉住用 Pin 图标与可聚焦按钮，支持键盘和明确属性范围；曲线面板可通过时间定位点。静态侧钉住图层姿态。
- 「整理」为草稿状态唯一主动作；本地候选提供残影/路径叠加、同范围/同时间/同视角的原稿A/B交替。名称描述实际变化，不把“更有动感”作为质量保证；只有一份候选覆盖合成，切换不叠加两份变换。P2 增可选分屏、按正式帧步进洋葱皮；可见叠层按工作预算采样显示、全量可分页定位，不能挡对象命中或把显示抽样当草稿数据丢弃。
- 候选状态唯一主动作为「应用」，取消恢复基态；应用后用原撤销栈撤销一次，曲线仍可在原关键帧面板编辑，原稿入口继续可读。保存失败用原错误/恢复提示，不能提示「已保存」。
- 滑杆松手结束一次参数预览，网络语义不逐 tick 调用；钉住点用不能移动的视觉反馈。窄面板按原 command overflow 收纳，不堆第三条参数带。

### 8.2 录制讲解

进入「录制讲解」时说明：「记录麦克风、本应用内操作、指向和时间位置；你可以拖时间指针或自行播放、暂停。语音将交给所选转写模型；必要时保留少量画面用于说明。发送前可检查文字、指向和画面。」显示默认转写模型的供应商、音频外发范围和估价，未配置时提供原设置入口；原音保存默认关闭。用户选择离线后备时才展示本地模型下载/空间说明，不将未实现后备假称可用。

录制中命令带持续显示 Mic 图标、「正在录制」、墙钟经过时间、「暂停录制/结束录制」；时间码仍在原播放控件，不显示内部时钟段编号。播放/暂停完全沿原控件，暂停播放仍录音和操作；暂停录制才释放麦克风/产生 gap，不自动改播放状态。恢复保持同一墙钟原点。失焦/断开显示已暂停录制与恢复操作。系统音频、摄像头、其他窗口、密码输入区不采集；不全局监听键盘正文。

停止进入原右侧停靠审阅区（不弹第二层卡片）：左侧或主区仍是实际画面，右侧同步可校正词稿、指代列表、操作摘要。点「这里」定位到录制时位置/帧，选中候选实体或重圈区域；低对齐质量用「请确认这里指的是谁」等行动文案。文本改写、词区间、指代校正共用通用实体写入，不能通过文字改时间后继续假称精确对齐。

历史画面优先由当时受管源、呈现帧、几何/姿态证据重建；源/作品状态已变化且无法重建时只展示保存的位置/绑定记录并说明，不能展示当前作品冒充过去，不能为补该能力暗中录屏。原音未保留或已删除时明确回听不可用；ASR错字建议不得无确认重写指代或否定语义。录制时口述时间指令在此校正作用段/停顿时长，再生成预览，不即时执行。

转写前核验所选供应商音频上传授权与费用；发送给意图模型前显示「将发送文字、操作与时间记录」及必要单帧/contact sheet 预览和估价，用户可排除某句/操作/图像。复用已有额度与授权，不另建逐次审批体系。可选「整理动作」或「执行讲解中的修改」；关键目标未解析不可应用。纯文本模型不能读取图像时给切模型/手动绑定入口。可删除本次录制及私密文本，语义见下节。

## 9. 隐私与成本

### 9.1 数据默认策略（提案）

- 录音默认本地临时受管资源，仅供转写/当前会话回听；用户关闭审阅或确认稿件后删除，异常中断暂存最长 24 小时并在下次启动清理。未同意持久保留时不打进项目包或图片包，清理失败告知并可重试。
- 用户可显式选择「保留原音供校正」，作为所属文档私有资源保存，直到删除会话/关闭保留；无产品时长上限。导出包含保留音频需明确提示可选择移除。不要把用户明确保留的音频按缓存回收。
- 转写、指针/时间指针/命令/差分/标注与草稿作为作品私有意图数据保留；必要图像按会话资源声明保留/清理，导出和删除纳入同一 live set。默认不写长期记忆、全量日志或自动共享。权限继承 owner 并分别核验音频 ASR、文本与图像外发；MCP 未获私密授权不得读全稿/证据图。
- 隐私敏感控件应继承 observation sensitive 标记并停止采样/记录其正文；文件路径/密钥/令牌、任意 Store 参数不可入事件。删除/脱敏操作摘要，不删除作品本身。
- 普通草稿删除可撤销；「彻底删除录音/私密讲解」为明确的隐私擦除动作，须清理工作副本、包资源、历史引用及本地助手会话副本，不能撤销复活已承诺删除的私密数据。已发送供应商的数据无法由本地删除保证收回，发送前必须说明，不宣称安全擦除磁盘物理扇区。
- 麦克风只由用户明确开始，助手/MCP 不得伪造 consent。暂停录制释放采集轨道，播放暂停不释放。SDK 转写只发给用户选定且授权的供应商；失败不自动切供应商/重发付费提交，可恢复查询的沿原任务恢复。离线后备须用户选择且已安装，不因无凭据或网络失败静默切换路线。
- P4 可选本地候选选择反馈，默认关闭且另获知情同意；仅保留匿名候选特征/选择及后续撤销修改，不保留作品内容、音频、词稿或绝对轨迹，不上传。选择不等于质量真值，调权离线通过留出集后才更新，提供清除/停用/恢复默认。不得让反馈、预设或历史复活已擦除的私密记录。

以上保留时长与交互是产品提案，尚无实现；P3 需要核对 Windows 权限、打包后的后台进程退出与异常重启清理。

### 9.2 单次费用量级

本地 P1、规则指代与编译无云端 token 费用；SDK ASR 按选定模型的音频计价单列估价/实际 usage，意图文本和必要图像按所选模型另计。离线 ASR 无云端费用但有下载/磁盘/CPU 开销。不能把原来的“本地 ASR 免费”用于 SDK 主路线；本轮不新增报价或调用供应商，执行期沿既有费用服务查实际计价，分块最小计费/重试也需计入。

仅作估算例：2026-10-10 查阅 [OpenAI GPT-4.1 mini 官方模型页](https://developers.openai.com/api/docs/models/gpt-4.1-mini)，普通文本输入 $0.40/百万、缓存输入 $0.10/百万、输出 $1.60/百万。

| 请求工作量 | 未命中缓存 | 固定前缀 2k token 命中缓存 |
|---|---:|---:|
| 输入 4k、输出 1k | $0.0032 | $0.0026 |
| 输入 8k、输出 2k | $0.0064 | $0.0058 |

公式 `cost=(uncachedInput*P_in+cachedInput*P_cache+output*P_out)/1e6`。候选尽量同一请求生成；若一轮修正需第二次调用，费用相应增加，长会话按实际批次数加总。上表不是报价、非 RMB 换算、未包含重试或独立审核模型费用，token 数未实测；价格与渠道需执行时重新查正式估价。滑杆/钉住只重跑本地算法，不自动产生模型费用。本轮没有实际调用。

## 12. 设计自查三问

1. **助手只凭名称和说明能否用对？** 设计上可以：双时钟/visit/词句粒度明确，先读草稿/绑定、生成候选、读回约束、经通用事务应用；默认转写模型沿设置通用属性，navigate 不编译运动，已执行/撤销事实不重放。实际仍需正式 describe → invoke/change → read 证明，不把文档当已实现能力。
2. **能否 AI 先做、人只确认？** 能：算法先整理运动/布局，SDK ASR 先转写、结构事件先绑定，必要图像补消歧；人只校正不明确指代/外观/示范冲突并确认候选。用户控制时间指针，AI 不代为启动播放或即时执行口述；失败保留原稿。
3. **产物能否直接流进其他工作区？** 能：剪辑落成现有可编辑关键帧与曲线；图片落成正式图层变换/顺序。媒体继续通过现有物化、导出及正式资源引用进入画布/剪辑/素材库，配方通过同一中立引用和宿主适配复用；图片图层/讲解会话本身不冒充媒体，须走正式导出桥梁。跨域真实接收与导出重开仍待实施验证。
